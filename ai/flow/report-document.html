Cowork에 폴더 열어 주기

Cowork

Cowork는 폴더를 열어 주면 파일을 읽고 엑셀·워드 결과물을 만듭니다. 글로벌 인스트럭션에 역할과 보고서 톤을 적어 두면 매번 설명하지 않아도 됩니다.

따라 하기

  1. Claude 데스크톱 앱에서 Cowork(또는 협업) 탭을 엽니다.
  2. 작업할 폴더를 고르고 접근 권한은 항상 허용을 선택합니다.
  3. 회의록, 엑셀, 메모 같은 자료를 그 폴더에 복사해 넣습니다.
  4. 설정의 지침 항목에서 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 규칙을 적고 저장합니다.
예시 프롬프트
나는 마케팅팀 대리야. 보고서는 간결한 존댓말로 쓰고, 날짜는 2026-11-09 형식으로 적어. 파일을 삭제하기 전에는 반드시 나에게 확인해.
  • 정식 제공 대상은 Pro, Max, Team, Enterprise입니다.
  • 웹 버전은 로컬 파일 접근이 안 되므로 데스크톱 앱에서 하세요.
  • 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.

보고서 초안 요청하기

Cowork

결과물과 포함할 항목을 구체적으로 적으면 Claude가 계획을 먼저 제안합니다. 계획을 확인하고 진행시키면 폴더 안에 보고서 파일이 만들어집니다.

따라 하기

  1. 원하는 결과물과 포함할 항목을 구체적으로 적어 요청합니다.
  2. Claude가 제안한 계획을 확인하고 진행시킵니다.
  3. 완성된 파일을 지정한 폴더에서 열어 내용을 검토합니다.
  4. 근거가 의심되는 숫자는 원본 자료와 대조합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘.
  • 원본 파일은 그대로 두고 정리본을 새 파일로 저장하라고 적어 두세요.
  • 파일명에 날짜를 넣어 달라고 하면 정리가 쉽습니다.

Docs에서 댓글로 고치기

Claude Docs

자료를 첨부해 문서를 만들고, 고칠 부분에 댓글을 달면 Claude가 수정합니다. 브리프나 보고서 초안을 빠르게 만들 때 알맞습니다.

따라 하기

  1. 참고 자료를 첨부하고 만들 문서를 설명하는 프롬프트를 입력합니다.
  2. Docs가 열리면 Claude가 던지는 질문에 모두 답합니다.
  3. 나온 초안을 텍스트 편집기처럼 직접 수정합니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  5. 우측 상단 공유로 팀원을 초대하거나 내보내기로 Word·PDF로 저장합니다.
예시 프롬프트
첨부한 신메뉴 사진을 바탕으로 사장님께 보고할 런칭 브리프를 만들어 줘.
  • 대화창에 /docs를 입력해 바로 시작할 수 있습니다.
  • Docs 댓글에서 Claude를 멘션해 수정을 요청할 수도 있습니다.

Word에서 추적 변경으로 교정

Word

Word 오른쪽 Claude 패널은 댓글 요약, 사실 확인, 서식 정리, 분량 줄이기를 맡습니다. 모든 수정이 추적 변경으로 남아 직접 수락하거나 거절할 수 있습니다.

따라 하기

  1. Word 오른쪽의 Claude 패널을 열고 댓글을 검토자별로 정리해 달라고 요청합니다.
  2. 변경 내용 추적을 켜고 유지하라고 요청합니다.
  3. 서식은 원하는 최종 상태를 말하고 Don't change anything else.를 덧붙입니다.
  4. 분량 목표를 말하되 지킬 부분(인용문, 날짜)을 함께 알려 줍니다.
  5. 패널에 /를 입력해 교정용 스킬로 오탈자와 문법을 교정합니다.
예시 프롬프트
We need to get this under 1,000 words, but don't cut any more than you need to. Keep the quotes and dates as they are.
  • Word 웹, Windows, Mac에서 쓸 수 있고 Microsoft AppSource에서 설치합니다.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.

보고서 양식을 스킬로 저장

Claude 앱

스킬은 어떤 단계와 규칙으로 일할지를 저장한 작업 지시서입니다. 평소 양식을 스킬로 저장하면 요청할 때마다 같은 형식의 보고서가 나옵니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 형식을 분석해 보고서 만드는 스킬을 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 스킬을 고릅니다.
  5. 결과를 직접 읽고 고치며, 부족한 규칙은 스킬에 다시 반영합니다.
예시 프롬프트
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
