목표 말하고 초안 맡기기

Claude 앱

이제 채팅과 Cowork를 고르지 않고 하나의 Claude에 목표만 말하면 됩니다. 마감, 분량, 독자와 참고 자료를 함께 주면 Claude가 방법을 찾아 초안을 만듭니다.

따라 하기

  1. Claude를 열고 새 대화를 시작합니다.
  2. 무엇을 얻고 싶은지 목표를 한두 문장으로 적습니다.
  3. 참고 자료와 조건(마감, 분량, 독자)을 같은 대화에 덧붙입니다.
  4. 문서 형식이 정해졌다면 /docs를 입력해 바로 만듭니다.
  5. 작업이 도는 동안 다른 일을 하다가 결과를 확인합니다.
예시 프롬프트
다음 주 팀 회의에서 공유할 3분기 고객 문의 동향 보고서가 필요합니다. 첨부한 문의 목록에서 많이 나온 유형 5개와 대응 제안을 정리해 주세요.
  • 작업은 클라우드에서 계속 돌아가므로 노트북을 닫아도 되고, 휴대폰으로 진행 상황을 볼 수 있습니다.
  • 예전 방식: 채팅과 Cowork를 따로 골라 썼지만 지금은 하나로 합쳐졌습니다.

팀과 Claude Docs로 다듬기

Claude Docs

Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집합니다. 고칠 부분에 코멘트를 달고 Claude를 멘션하면 그 부분만 고쳐 줍니다.

따라 하기

  1. 만든 문서를 Claude Docs에서 열고 팀원과 공유합니다.
  2. 오타나 짧은 문구는 직접 고칩니다.
  3. 큰 수정이 필요한 부분에 코멘트를 달고 Claude를 멘션해 요청합니다.
  4. 수정 결과를 확인하고 필요하면 코멘트를 다시 남깁니다.
  • 코멘트는 문서의 어느 부분에든 달 수 있습니다.
  • 브랜드 색·톤을 함께 알려 주면 결과가 더 잘 맞습니다.

Word에서 댓글 정리하기

Claude for Word

사내 검토가 Word로 돈다면 Claude for Word 패널에서 마무리합니다. 먼저 추적 변경을 켜 두면 모든 수정이 기록으로 남아 내가 수락하기 전까지 원문이 유지됩니다.

따라 하기

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치합니다.
  2. Word에서 초안을 열고 오른쪽 Claude 패널을 엽니다.
  3. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고 Allow once를 누릅니다.
  4. 문서에 달린 댓글을 검토자별로 정리하고 서로 충돌하는 요청이 있는지 묻습니다.
예시 프롬프트
이 문서에 달린 미해결 댓글을 검토자별로 요약해 줘. 누가 무엇을 요청했는지, 서로 충돌하는 요청이 있는지도 알려 줘.
  • Word 웹·Windows·Mac에서 쓸 수 있고 Pro, Max, Team, Enterprise 플랜에 포함됩니다.

근거 문서와 수치 대조하기

Claude for Word

보고서의 성능·수치 표현이 근거 문서와 맞는지 Claude가 대조하게 합니다. 맞지 않는 부분은 수정 카드로 제안되고, 적용하면 추적 변경으로 남습니다.

따라 하기

  1. 근거 문서가 있는 위치(예: Box)를 알려 주고 대조를 요청합니다.
  2. 맞지 않는 표현과 수치를 찾아 고치게 합니다.
  3. 수정 카드를 하나씩 읽고 적용 여부를 정합니다.
  4. 틀리면 곤란한 수치는 원문을 직접 열어 한 번 더 확인합니다.
예시 프롬프트
이 문서의 성능·수치 표현을 Box에 있는 근거 문서와 대조해서, 맞지 않는 부분을 찾아 고쳐 줘.
  • 숫자, 이름, 인용처럼 중요한 내용은 직접 원문과 대조하는 습관을 지키세요.

서식·분량 맞추고 교정하기

Claude for Word

내용을 확정한 뒤 서식, 문장, 분량, 맞춤법을 차례로 다듬습니다. 한 번에 하나씩 요청하고 지킬 부분을 분명히 말해야 원하지 않는 변경을 막을 수 있습니다.

따라 하기

  1. 원하는 최종 서식을 말하고 Don't change anything else.를 덧붙입니다.
  2. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인합니다.
  3. 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 주고 단어 수를 확인합니다.
  4. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬로 오탈자와 문법을 교정합니다.
  • 카드가 너무 많이 잘라 내면 이유를 말하고 다시 제안하게 합니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.

변경 사항 확정하기

Claude for Word

모든 수정이 추적 변경으로 남아 있으므로 마지막에 한꺼번에 검토하고 수락합니다. 수락한 변경은 되돌릴 수 없으니 필요한 댓글 스레드는 남겨 둡니다.

따라 하기

  1. 추적 변경으로 표시된 수정을 하나씩 수락하거나 거절합니다.
  2. 남은 변경을 모두 수락하게 할 때 leave the comment threads open이라고 덧붙여 댓글 스레드를 남깁니다.
  3. Claude가 확인을 요청하면 내용을 읽고 승인합니다.
  4. 완성 문서를 공유하기 전에 직접 한 번 더 읽습니다.
  • 수락한 변경은 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.

한 장 요약·발표본 만들기

Claude 앱

완성된 보고서 하나로 회의용 슬라이드와 한 장짜리 요약을 함께 만들 수 있습니다. 앞선 대화 내용이 그대로 바탕이 되므로 내용을 다시 설명하지 않아도 됩니다.

따라 하기

  1. 완성 보고서를 대화에 붙여 넣거나 같은 대화에서 이어 갑니다.
  2. 필요한 결과물 종류(슬라이드, 한 장 요약 문서)를 구체적으로 요청합니다.
  3. 마음에 들지 않는 부분에 코멘트를 달아 고칩니다.
  4. 팀에 공유하거나 내보내기(export)로 전달합니다.
예시 프롬프트
위 보고서를 바탕으로 ① 팀 회의용 슬라이드 5장 ② 결정이 필요한 항목을 맨 위에 둔 한 장짜리 요약 문서를 만들어 주세요.
  • 쌓아 둔 FAQ나 회의 내용도 한 장짜리 안내문으로 바꾸기 좋은 출발점입니다.
