자료 모아 핵심 정리하기

Adobe Acrobat AI

보고서에 쓸 자료가 여러 곳에 흩어져 있으면 먼저 한곳에 모아 핵심을 정리합니다. 요약 속 숫자를 눌러 원문 근거를 바로 확인할 수 있습니다.

따라 하기

  1. Adobe Acrobat에서 PDF 스페이스를 새로 만듭니다.
  2. 보고서 파일, 기사 링크, 메모를 자료로 넣습니다.
  3. AI 어시스턴트에게 보고서 목적과 읽을 사람을 알려 주고 핵심 정리를 요청합니다.
  4. 요약 속 숫자를 눌러 원문의 해당 부분을 확인합니다.
예시 프롬프트
넣은 자료로 '3분기 고객 이탈 원인 분석' 보고서를 쓰려고 해. 읽을 사람은 본부장이야. 이탈 원인으로 볼 수 있는 내용과 관련 수치를 출처와 함께 정리해 줘.
  • AI 요약은 틀릴 수 있으니 보고서에 옮기기 전에 숫자 근거를 원문과 맞춰 보세요.

맥락 주고 문서 초안 받기

Claude 앱

정리한 내용과 보고서의 목적, 독자, 형식을 함께 알려 주면 초안의 질이 올라갑니다. 대화창에서 바로 문서 형태로 만들 수 있습니다.

따라 하기

  1. 모델을 Opus 5.5로 고릅니다.
  2. 정리한 자료 요약을 대화창에 붙여 넣습니다.
  3. 내가 누구이고, 읽을 사람은 누구이며, 좋은 결과는 어떤 모습인지 적습니다.
  4. /docs를 입력하거나 문서로 만들어 달라고 요청합니다.
  5. 목차와 흐름이 맞는지 먼저 확인합니다.
예시 프롬프트
저는 고객지원팀 매니저이고 본부장에게 올릴 3분기 고객 이탈 원인 보고서를 쓰고 있습니다. 위 자료 요약을 바탕으로 '요약 → 현황 → 원인 → 대응안' 순서의 2쪽 이내 문서 초안을 만들어 주세요. 근거가 약한 내용은 '확인 필요'로 표시해 주세요.
  • 이제 채팅과 Cowork를 고를 필요 없이 원하는 결과만 말하면 됩니다.

팀원과 함께 검토하기

Claude Docs

Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집할 수 있습니다. 팀원 의견을 코멘트로 받고, Claude를 멘션해 그 부분만 고치게 합니다.

따라 하기

  1. 완성된 초안을 팀원에게 공유합니다.
  2. 팀원이 고칠 부분에 코멘트를 남기게 합니다.
  3. 코멘트에서 Claude를 멘션해 해당 부분 수정을 요청합니다.
  4. 특정 문단만 바꿀 때는 그 문단을 선택하고 바꿀 내용을 말합니다.
  • 작업이 클라우드에서 돌아가므로 다른 일을 하다 돌아와 결과를 확인해도 됩니다.

Word에서 댓글 정리하기

Claude for Word

Word로 넘어온 초안에 댓글이 많으면 Claude 패널에서 검토자별로 정리합니다. 이후 모든 수정이 추적 변경으로 남도록 먼저 설정합니다.

따라 하기

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치하고 Word 오른쪽 Claude 패널을 엽니다.
  2. 열린 댓글을 요약하고 서로 충돌하는 요청이 있는지 물어봅니다.
  3. Turn on Track Changes and keep it on for everything you do in this document.라고 요청합니다.
  4. 확인창에서 Allow once를 누릅니다.
예시 프롬프트
이 문서에 열려 있는 댓글을 검토자별로 요약해 줘. 누가 무엇을 요청했는지, 서로 충돌하는 요청이 있는지도 알려 줘.
  • Word 웹, Windows, Mac에서 쓸 수 있고 Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.

근거 문서와 사실 확인하기

Claude for Word

보고서 속 수치와 주장은 근거 문서와 대조해야 합니다. Claude가 원본과 맞지 않는 부분을 찾아 수정 카드로 제안합니다.

따라 하기

  1. Box 등에 있는 근거 문서를 Claude가 참고하게 합니다.
  2. 문서 속 수치·성능 주장을 근거 문서와 대조해 달라고 요청합니다.
  3. 맞지 않는 내용은 고치게 합니다.
  4. 수정 카드를 하나씩 확인하고 적용해 추적 변경으로 반영합니다.
예시 프롬프트
이 보고서의 수치와 주장을 근거 문서와 하나씩 대조해 줘. 맞지 않는 부분은 수정 카드로 제안하고, 근거를 찾을 수 없는 문장은 따로 알려 줘.
  • Claude가 고친 내용은 바로 반영되지 않고 추적 변경으로 남으니 수락 전에 꼭 확인하세요.

서식·문장·분량 다듬기

Claude for Word

내용이 확정되면 서식과 문장, 분량을 다듬습니다. 바꿀 범위를 분명히 말해야 원하지 않는 곳까지 바뀌지 않습니다.

따라 하기

  1. 서식은 원하는 최종 상태를 구체적으로 말하고 Don't change anything else.를 덧붙입니다.
  2. 고쳐 쓸 문단을 선택하고 읽을 사람의 언어로 다시 써 달라고 요청합니다.
  3. 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 줍니다.
  4. 화면 아래 단어 수를 확인합니다.
  5. 지나치게 많이 잘라 낸 카드는 이유를 말하고 다시 제안하게 합니다.
예시 프롬프트
이 문서를 1,000단어 아래로 줄여 줘. 다만 필요 이상으로 자르지 말고, 인용문과 날짜는 그대로 남겨 줘.
  • 카드가 지나치게 많이 잘라 내면 이유를 말하고 다시 제안하게 합니다.

교정하고 변경 수락하기

Claude for Word

마지막으로 오탈자와 문법을 교정하고 추적 변경을 수락합니다. 수락하면 되돌릴 수 없으므로 Claude가 먼저 확인을 요청합니다.

따라 하기

  1. 패널에 /를 입력해 copy edit 스킬을 고릅니다.
  2. 오탈자와 문법 교정을 실행합니다.
  3. 검토 카드와 추적 변경을 하나씩 보며 수락하거나 거절합니다.
  4. 모두 확인되면 변경 사항을 모두 수락하게 합니다.
  5. 팀이 변경 내용을 볼 수 있게 하려면 수락할 때 leave the comment threads open이라고 말합니다.
  • 변경을 수락하면 되돌릴 수 없으니 수락 전에 한 번 더 확인하세요.

팀 교정 기준을 스킬로 만들기

Skills

매번 같은 교정 지시를 반복한다면 팀 기준을 스킬로 만들어 둡니다. Word 패널에서 스킬 이름으로 불러 같은 기준을 적용하고, 사람이 고친 내용을 다시 반영해 개선합니다.

따라 하기

  1. 팀의 과거 수정 이력, 잘된 보고서 예시, 스타일 가이드를 모읍니다.
  2. Claude 계정에서 스킬을 만들고, 규칙 목록보다 어떻게 판단해야 하는지(원칙) 중심으로 씁니다.
  3. Word 패널에서 /brand-guidelines처럼 스킬 이름으로 불러 실행합니다.
  4. 스킬 결과에 사람이 추가로 고친 내용을 모아 둡니다.
  5. 모은 수정 내용을 스킬에 다시 반영하고, 바꾸기 전에 팀원이 검토하게 합니다.
  • Every는 편집장이 과거에 고친 3만 건으로 교정 스킬을 만들었습니다.
  • 개발을 모르는 동료에게는 익숙한 문서 형태로 스킬을 보여 주면 쓰기 쉽습니다.
