코워크로 폴더 업무 맡기기

Cowork

코워크는 작업 전체를 맡기는 방식이며 계획을 제안하고 승인 후 실행합니다. 처음엔 범위가 분명한 폴더 작업으로 감을 잡습니다.

따라 하기

  1. Claude 데스크톱 앱(macOS 또는 Windows)을 설치합니다.
  2. 코워크를 시작합니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. 맡길 작업을 설명하고 변경 전에 계획을 먼저 보여 달라고 요청합니다.
  5. 계획을 읽고 괜찮으면 승인합니다.
예시 프롬프트
다운로드 폴더의 파일을 종류별로 정리하는 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • 파일을 바꾸기 전 권한 요청이 오면 내용을 확인한 뒤 허용하세요.
  • 웹 버전은 로컬 파일 접근이 안 되므로 데스크톱 앱을 씁니다.

Cowork

따라 하기

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. 협업 항목의 지침에서 편집을 누릅니다.
  3. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 규칙을 적습니다.

예시 프롬프트
역할: 마케팅팀 보고서 담당자. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적어 줘. 파일을 삭제하기 전에는 반드시 나에게 확인해 줘.
  • 메뉴 이름이 바뀌었을 수 있으니 화면에서 확인하세요.

자료로 보고서 초안 만들기

Cowork

회의록·엑셀·메모를 폴더에 모아 두면 Cowork가 모두 읽고 보고서나 엑셀로 정리합니다. 원본을 건드리지 않게 지시하는 것이 핵심입니다.

따라 하기

  1. 작업 폴더를 고르고 항상 허용을 누릅니다.
  2. 매출 데이터, 메모, 주간 회의록을 폴더에 넣습니다.
  3. 폴더 안 자료를 모두 읽고 한 페이지 워드 보고서로 정리해 달라고 요청합니다.
  4. 계획과 실행 진행 상황을 지켜봅니다.
  5. 완성된 보고서의 내용과 숫자를 확인합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘. 원본은 그대로 두고 새 파일로 저장해 줘.
  • 엑셀 정리 시 날짜 형식·빈칸·중복 규칙을 적고 정리본은 새 파일로 저장하게 하세요.

잘 쓴 보고서를 스킬로 저장

Claude

스킬은 어떤 단계와 규칙으로 일할지 저장한 작업 지시서입니다. 잘 쓴 보고서 하나를 올려 스킬로 만들면 이후 이번 주 자료만 넣어도 같은 구성이 나옵니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 형식을 분석해 보고서 만드는 스킬을 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력하고 주제를 적습니다.
  5. 마음에 안 들면 배운 점을 스킬에 반영해 달라고 요청합니다.
예시 프롬프트
이 보고서 형식을 분석해서 '주간 보고서' 스킬을 만들어 줘. 앞으로 이번 주 자료만 주면 같은 구성과 말투로 초안을 써 줘. 답변은 한국어로 해 줘.
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 스킬은 팀과 공유하면 누구나 같은 결과를 냅니다.

메일·드라이브 커넥터 연결

Claude

커넥터를 연결하면 파일을 일일이 올리지 않고 대화창에서 드라이브·메일 자료를 바로 쓰게 시킬 수 있습니다. 연결은 처음 한 번이면 됩니다.

따라 하기

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가 → 커넥터 둘러보기를 누릅니다.
  3. Gmail, 구글 캘린더, 구글 드라이브 등을 검색합니다.
  4. 서비스 옆 +를 누르고 내 계정으로 인증합니다.
  5. 채팅에서 + → 커넥터로 켜짐 상태를 확인합니다.
예시 프롬프트
구글 드라이브에서 이번 주 회의록 파일을 찾아 핵심 결정 사항만 요약해 줘.
  • 여러 구글 계정을 쓴다면 연결된 계정이 어느 것인지 확인하세요.

예약 작업으로 매주 실행

Cowork

반복할 일을 시각과 함께 요청하면 Claude가 프롬프트 초안과 주기를 만들고 승인 후 예약됩니다. 7월 업데이트 이후 예약 작업은 클라우드에서 실행됩니다.

따라 하기

  1. 새 작업에서 협업을 누르고 프로젝트를 만듭니다.
  2. 반복할 일을 시각과 함께 구체적으로 요청합니다.
  3. Claude가 만든 프롬프트 초안과 주기를 확인하고 필요하면 고칩니다.
  4. 승인 버튼을 눌러 예약을 확정합니다.
  5. 좌측 예약됨에서 스케줄과 지난 실행 기록을 확인합니다.
예시 프롬프트
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 주간 보고서 스킬로 초안을 만들어 줘. 이메일은 보내지 말고 초안으로만 남겨 줘.
  • 예약 작업은 유료 플랜에서만 쓸 수 있습니다.
  • 예전에는 컴퓨터와 앱이 켜져 있어야 실행됐습니다.

Claude

자동으로 만든 보고서도 이름을 걸고 보내는 문서라면 근거를 직접 대조해야 합니다. 발송은 하지 않고 초안으로만 남기게 하면 안전합니다.

따라 하기

예시 프롬프트
