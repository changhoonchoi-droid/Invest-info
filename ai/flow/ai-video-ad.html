콘셉트와 장면 정하기

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

영상 생성은 크레딧이 들기 때문에 먼저 대화로 콘셉트와 장면 구성을 정해 두는 편이 낫습니다.

따라 하기

  1. 제품, 대상, 전달할 메시지를 한 문장으로 적습니다.
  2. Claude에게 장면 3~5개 구성안을 요청합니다.
  3. 마음에 드는 안을 골라 장면별 설명을 확정합니다.
예시 프롬프트
30대 직장인을 위한 운동화 15초 광고를 기획해 줘. 장면 4개로 나누고 장면마다 화면 설명과 한 줄 문구를 써 줘.
  • 장면이 너무 많으면 파트를 나눠 생성하세요.

영상 서비스를 Claude에 연결

Claude

목록에 없는 서비스는 사이트에서 MCP 주소를 복사해 커스텀 커넥터로 붙여 넣어 연결합니다. 한 번 연결하면 대화창에서 이미지·영상 생성을 바로 부릅니다.

따라 하기

  1. 서비스 사이트의 MCP 메뉴에서 Claude를 선택해 MCP URL을 복사합니다.
  2. Claude 설정 → 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  3. 이름과 MCP 서버 URL을 붙여 넣고 계속을 누릅니다.
  4. 서비스 계정으로 로그인하고 + → 커넥터에서 켜졌는지 확인합니다.
  5. 크레딧 잔액을 물어 연결을 시험합니다.
예시 프롬프트
힉스필드 MCP로 크레딧 잔액과 요금제를 확인해 줘.
  • 공식 MCP만 쓰고 출처 불분명한 비공식 MCP는 피하세요.
  • 생성은 서비스 쪽 크레딧이 소모됩니다.

제품·인물 이미지 고정하기

힉스필드

영상에서 얼굴과 제품 모습을 일정하게 유지하려면 먼저 이미지를 만들어 기준으로 삼습니다. 생성 전에 가능한 모델부터 체크시키면 크레딧을 아낍니다.

따라 하기

  1. 제품 사진을 업로드하고 먼저 생성 없이 쓸 수 있는 모델을 확인시킵니다.
  2. 모델, 비율, 해상도를 적어 대표 이미지를 요청합니다.
  3. 인물이 필요하면 전신 이미지를 만들고 캐릭터 시트를 요청합니다.
  4. 얼굴·의상·비율이 유지됐는지 확인하고 다운로드합니다.
예시 프롬프트
먼저 생성하지 말고 Artlist에서 쓸 수 있는 이미지 모델을 확인해 줘. 첨부한 운동화 사진으로 정사각형 2K 대표 이미지를 만들 계획과 예상 크레딧을 알려 줘.
  • 영상용 모델은 전신으로 만들어야 하반신이 임의로 표현되지 않습니다.

캐릭터 시트로 장면 영상 만들기

힉스필드

캐릭터 시트를 레퍼런스로 넣으면 여러 장면에서 같은 인물이 유지됩니다. 본 생성 전에 짧고 낮은 화질로 먼저 시험하세요.

따라 하기

  1. 상단에서 비디오를 선택합니다.
  2. 프롬프트에 @로 캐릭터 시트를 지정하고 동작을 적습니다.
  3. 모델을 Seedance 2.5로 고르고 길이·비율을 정합니다.
  4. 생성하기 후 마음에 들면 다운로드합니다.
  5. 장소를 바꾸려면 첫 영상을 레퍼런스로 함께 넣습니다.
예시 프롬프트
@캐릭터시트 의 인물이 해 질 녘 서울 거리를 천천히 걸어오는 장면, 카메라는 정면에서 천천히 후진, 16:9, 15초.
  • 인물 묘사 문장을 모든 프롬프트에 똑같이 붙이면 일관성이 좋아집니다.

긴 광고 영상 만들고 고치기

Artlist

Seedance 2.5는 최대 30초 영상에 이미지 레퍼런스를 여러 개 넣을 수 있습니다. 수정은 만든 영상을 첨부하고 바꿀 부분만 적습니다.

따라 하기

  1. 제품 사진을 여러 각도로 준비합니다.
  2. 배경 이미지를 만들고 제품과 합친 이미지를 만듭니다.
  3. 비디오에서 Seedance 2.5를 선택하고 길이를 30초로 정합니다.
  4. 이미지 레퍼런스로 넣고 프롬프트를 써 제너레이트를 누릅니다.
  5. 수정은 먼저 만든 영상을 레퍼런스로 첨부해 다시 생성합니다.
예시 프롬프트
앞부분을 더 따뜻한 분위기로 바꿔 줘. 나머지 장면과 제품 모습은 그대로 유지해 줘.
  • 영상 생성은 크레딧이 많이 드니 이미지로 구도를 먼저 확정하세요.
  • 사진 순서가 정해진 영상은 Kling 4.0의 시작·중간·끝 프레임 방식도 있습니다.

결과 점검하고 저장하기

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

AI 영상은 로고, 제품 형태, 한글 문구가 달라질 수 있습니다. 올리기 전에 직접 확인하고 원본을 다운로드해 보관합니다.

따라 하기

  1. 제품 형태와 로고가 원본과 같은지 확인합니다.
  2. 영상 속 한글 문구를 직접 읽어 확인합니다.
  3. 화면 캡처가 아니라 다운로드로 저장합니다.
  4. 브랜드 가이드가 엄격한 광고는 실제 촬영이 필요한지 판단합니다.
  • 남의 얼굴·목소리를 쓸 때는 동의를 받으세요.

각 유튜브 채널의 공개 영상과 자막을 AI(Claude)가 요약·정리했습니다. 자세한 내용과 최신 화면은 원본 영상을 확인하세요. 영상의 저작권은 각 채널에 있습니다.
