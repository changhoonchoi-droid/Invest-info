Claude가 답을 만드는 원리 알기

Claude 앱

Claude는 정해진 답을 꺼내 오지 않고, 대화 맥락을 보고 다음 단어를 예측하며 답을 새로 씁니다. 이 원리를 알면 같은 질문에 답이 달라지는 이유와, 틀린 내용을 자신 있게 말할 수 있는 이유를 이해하고 쓸 수 있습니다.

따라 하기

  1. Claude는 내 메시지, 올린 문서, 메모리, 대화 기록 전체를 보고 답한다는 점을 기억합니다.
  2. 새 대화는 앞 대화를 기억하지 못하므로, 필요한 배경은 새 대화에서 다시 알려 줍니다.
  3. 답이 마음에 들지 않으면 다른 버전을 여러 개 써 달라고 합니다.
  4. 학습 시점 이후의 일은 검색 없이는 확실히 모르므로, 최신 정보는 검색 결과나 원문으로 확인합니다.
  5. 자신 있게 말한 답도 틀릴 수 있으니 숫자·사실·인용은 직접 확인한 뒤 씁니다.
예시 프롬프트
아래 거래처 회신 메일 초안을 정중한 버전, 짧은 버전, 친근한 버전 세 가지로 다시 써 줘.
  • 새 대화에서 이전 내용을 모르는 것은 오류가 아니라 원래 그렇게 동작하는 것입니다.

따라 하기

  1. 계정이나 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 저장된 메모리 중 틀리거나 필요 없는 것은 고치거나 지우고, 필요 없으면 메모리를 끕니다.
  3. 업무 정보를 넣을 계획이면 학습 사용 거부(옵트아웃) 설정이 있는지 찾아 켜 둡니다.
  4. 실명이 필요 없는 작업은 이름을 [고객명] 같은 자리표시자로 바꿔 입력합니다.
  5. 회사가 Claude를 조직 단위로 도입했는지 확인하고, 기밀 자료는 조직용 계정에서만 다룹니다.
  6. 정한 기준을 팀원과 공유합니다.
예시 프롬프트
[고객명]님께 납기 지연을 사과하는 메일을 정중하게 다듬어 줘. 지연 기간은 [N]일이야.

작업에 맞는 모델 고르기

Claude 앱

작업 비용과 품질은 모델과 effort(생각하는 깊이)에 따라 달라집니다. 작업 종류를 먼저 나누고 그에 맞는 모델로 시작하면 사용량을 아끼면서도 결과가 좋아집니다.

따라 하기

  1. 할 일이 심층 조사처럼 답이 열린 일인지, 요약·메일 초안처럼 반복되는 일인지 나눕니다.
  2. 방향 찾기·복잡한 판단은 Opus 5.5, 방향이 정해진 뒤 빠른 수정은 Sonnet 5.5로 합니다.
  3. 여러 자료를 오래 붙들고 원인을 찾는 긴 작업은 Fable 5.1을 medium effort로 시작합니다.
  4. 결과가 부족할 때만 effort를 한 단계씩 올리거나 더 강한 모델로 바꿉니다.
  • 토큰 단가가 아니라 작업 한 건당 비용으로 비교하세요. 똑똑한 모델이 적은 단계로 끝내 오히려 쌀 수 있습니다.
  • 예전에는 고르기 어려우면 높은 effort를 권했지만, 최신 영상은 medium으로 시작해 필요할 때 올리라고 권합니다.

맥락을 담아 첫 요청하기

Claude 앱

Claude는 받은 맥락이 많을수록 내 상황에 맞는 답을 씁니다. 내가 누구인지, 무엇을 하는지, 좋은 결과가 어떤 모습인지를 첫 메시지에 적는 것만으로 답의 질이 달라집니다.

따라 하기

  1. 첫 메시지에 내 역할과 지금 하는 작업을 적습니다.
  2. 좋은 결과의 모습(분량, 대상 독자, 형식)을 함께 적습니다.
  3. 가격·뉴스처럼 최신 정보가 필요하면 웹 검색을 해 달라고 요청합니다.
  4. 검색으로 답했다면 제시된 출처를 직접 열어 확인합니다.
  5. 초안이 나오면 다른 어조나 여러 버전으로 다시 써 달라고 합니다.
예시 프롬프트
저는 중견 제조사의 마케팅팀 대리이고, 다음 주 팀장님께 올릴 신제품 홍보 메일 초안을 쓰고 있습니다. 대상은 기존 거래처 구매 담당자이고, 좋은 결과는 5문장 안팎의 정중하지만 간결한 메일입니다. 어조를 달리한 초안 3가지를 써 주세요.
  • '더 좋게 만들어', '실수 없이 만들어' 같은 막연한 요청보다 구체적인 상황과 기준을 주세요.
  • Claude가 웹 검색을 했다고 단정하지 말고 직접 물어보세요.

작업 하나를 통째로 맡기기

Claude 앱

9월 업데이트로 채팅과 Cowork가 하나의 Claude로 합쳐져, 모드를 고르지 않고 원하는 결과를 말하면 Claude가 방법을 찾습니다. 되돌리기 쉬운 파일 정리 같은 일부터 맡겨 보며 계획 검토와 승인 흐름을 익힙니다.

따라 하기

  1. Claude 데스크톱 앱에서 새 대화를 엽니다. 채팅인지 Cowork인지 따로 고르지 않아도 됩니다.
  2. Claude가 작업할 폴더에 접근을 허용합니다.
  3. 어떻게 할지가 아니라 원하는 결과를 구체적으로 적고, 실행 전에 계획부터 보여 달라고 합니다.
  4. 제안된 계획을 읽고 고칠 점을 말한 뒤 승인합니다.
  5. 파일을 바꾸기 전에 권한을 물으면 내용을 확인하고 허용할지 정합니다.
  6. 작업이 도는 동안 다른 일을 하고, 이동 중에는 휴대폰 앱으로 진행 상황을 봅니다.
예시 프롬프트
다운로드 폴더에 있는 이번 달 견적서 PDF를 거래처별 하위 폴더로 정리하고, 거래처·날짜·금액을 표로 정리해 줘. 파일을 옮기기 전에 계획부터 보여 줘.
  • 처음에는 잘못돼도 되돌리기 쉬운 작업으로 연습합니다.
  • 예전 방식: 데스크톱 앱에서 Cowork 탭을 따로 골랐지만 지금은 하나로 합쳐졌고, 예전 Cowork 작업도 그대로 남아 있습니다.

AI는 그럴듯하지만 사실이 아닌 내용(환각)이나 듣고 싶은 말에 맞춘 답(아첨)을 똑같이 확신 있게 말합니다. 틀렸을 때의 피해가 클수록 더 꼼꼼히 확인하는 습관이 필요합니다.

따라 하기

  1. 틀렸을 때 무슨 일이 생기는지 따져 확인 강도를 정합니다.
  2. 질문 전에 모르면 모른다고 말해 달라고 허용합니다.
  3. 답에서 수치·인용·날짜·이름, 최신 소식이 들어간 부분을 표시합니다.
  4. 그 부분의 출처와 확신 정도를 물어봅니다.
  5. 출처 링크를 직접 열어 실제로 그 내용이 있는지 확인합니다.
  6. 중요한 내용은 새 대화에서 다시 물어 답이 같은지 비교합니다.
예시 프롬프트

  • 신뢰는 스위치가 아니라 다이얼입니다. 브레인스토밍은 느슨하게, 상사에게 보일 통계는 반드시 검증하세요.

Claude 앱

AI 답변은 고정관념이나 한쪽 관점에 치우칠 수 있습니다. 같은 주제를 두 관점에서 물어 비교하면 결과물의 균형을 직접 맞출 수 있습니다.

따라 하기

  1. 답이 한쪽으로 치우쳤다고 느끼면 그 점을 바로 짚어 반박합니다.
  2. 솔직한 논의를 원한다고 말하고 균형 잡힌 답을 다시 요청합니다.
  3. 같은 주제를 반대 관점에서 묻는 질문 두 개를 만들어 각각 새 대화에서 묻습니다.
  4. 두 답변의 길이, 근거의 깊이, 성의를 나란히 비교합니다.
  5. 한쪽이 얕으면 질문을 고치거나 결과물에서 균형을 맞춥니다.
예시 프롬프트
주제: 주 4일 근무제. 질문 1: 주 4일 근무제를 찬성하는 가장 강력한 근거를 정리해 줘. 질문 2: 주 4일 근무제를 반대하는 가장 강력한 근거를 정리해 줘.
  • 정치 주제가 아닌 일반 업무 대화에서도 똑같이 유용합니다.
  • 한국어 답변 품질이 다를 수 있으니 중요한 내용은 영어 답변과도 비교해 볼 만합니다.
