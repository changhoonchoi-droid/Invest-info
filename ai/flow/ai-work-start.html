AI에게 나를 알려 주기

Claude 데스크톱 앱

AI는 나에 대한 맥락을 알수록 쓸모 있는 답을 줍니다. 첫날에는 내 업무 폴더를 읽기 전용으로 보여 주고, 서로 질문을 주고받으며 Claude가 도와줄 수 있는 일을 찾습니다.

따라 하기

  1. '나에 대해 아는 것을 한 문단으로 설명해 봐'라고 물어 AI가 나를 얼마나 아는지 확인합니다.
  2. 데스크톱 앱에서 업무 폴더 접근을 허락합니다.
  3. 파일은 읽기만 하라고 못 박고 내 업무 맥락을 파악하게 합니다.
  4. '너는 뭘 할 수 있니?'라고 묻습니다.
  5. '나에 대해서 궁금한 거 100개까지 물어봐 봐'라고 해서 AI의 질문에 답합니다.
  6. '이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?'라고 물어 쓸 곳을 찾습니다.
예시 프롬프트
컴퓨터 보고 나에 대해 파악해 줘. 파일은 읽기만 하고 절대 고치거나 지우지 마.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤 답을 보며 고쳐 달라고 합니다.
  • AI가 처음이라면 모바일 앱의 음성 대화로 말을 걸어 보는 것부터 시작해도 됩니다.
  • 하루 30분, 매일 AI에게 묻고 AI가 나에게 묻게 하는 습관을 들이세요.

맥락 담아 질문하기

Claude 앱

AI는 내 메시지, 올린 문서, 대화 기록을 모두 보고 답을 만듭니다. 내가 누구이고 어떤 결과를 원하는지 적을수록 뻔한 답이 줄어듭니다.

따라 하기

  1. 내 직무·상황과 지금 하는 작업을 먼저 알려 줍니다.
  2. 좋은 결과의 모습(분량, 대상 독자, 형식)을 함께 적습니다.
  3. 글로 정리하기 어려우면 휴대폰 음성 메모로 하고 싶은 말을 녹음해 받아 적은 글을 붙여 넣습니다.
  4. 답이 마음에 들지 않으면 여러 버전이나 다른 어조로 다시 받아 고릅니다.
  5. 더 좋은 답에 필요한 정보를 AI가 먼저 질문하게 합니다.
  6. 새 대화는 앞 대화를 모른다고 보고, 필요한 배경을 다시 알려 줍니다.
예시 프롬프트
나는 중견기업 마케팅팀 3년 차 직장인이고, 다음 주 팀장 보고용으로 신제품 홍보 아이디어를 정리하고 있어. 좋은 결과는 A4 한 장 분량에 아이디어 3개와 각각의 예상 비용이 들어간 형태야. 더 좋은 답을 위해 필요한 정보가 있으면 먼저 나에게 질문해 줘.
  • AI는 답을 꺼내는 것이 아니라 새로 만들기 때문에 같은 요청도 여러 번 받아 고를 수 있습니다.
  • 매번 반복해서 알려 주는 정보가 생기면 프로젝트 지침으로 옮겨 둡니다.

최신 정보는 웹 검색 켜기

Claude 앱

Claude는 학습 시점 이후의 일을 검색 없이는 확실히 알지 못합니다. 최신 정보는 웹 검색을 켜고, 시장 조사처럼 깊이 파야 하면 딥 리서치(연구) 모드를 씁니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 달아 답합니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 조사할 범위와 기간, 원하는 결과 형식을 적어 요청합니다.
예시 프롬프트
국내 직장인의 생성형 AI 업무 활용 현황을 조사해 줘. 최근 1년 안의 공신력 있는 기관 자료 위주로 정리하고, 주장마다 출처 링크와 발표 시점을 달아 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 답에 달린 출처 링크를 눌러 실제 내용과 맞는지 확인하세요.

Claude 앱

AI는 맞을 때와 틀릴 때 모두 똑같이 자신 있게 말합니다. 상사에게 보일 숫자·인용·날짜처럼 틀리면 곤란한 내용은 출처를 받아 직접 열어 보고 씁니다.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 따져 확인 강도를 정합니다.
  2. 질문하기 전에 '모르면 모른다고 해도 괜찮다'고 미리 알려 줍니다.
  3. 주장마다 근거 출처를 붙이고 확신도를 표시해 달라고 요청합니다.
  4. 제시된 출처를 직접 열어 그 내용이 실제로 있는지 확인합니다.
  5. 새 대화를 열거나 다른 AI에게 같은 답의 오류와 출처를 검증시킵니다.
예시 프롬프트

  • AI가 실제로 없는 논문이나 출처를 그럴듯하게 만들어 낼 수도 있습니다.

따라 하기

  1. 추천을 묻기 전에 내 우선순위(속도·비용·품질 등)를 먼저 적어 둡니다.
  2. 원하는 답을 흘리지 말고 가장 강력한 찬성·반대 논거를 중립적으로 묻습니다.
  3. AI가 고른 안에 대해 '어떤 조건이 바뀌면 조언이 달라지나요?'라고 묻습니다.
  4. 다른 안이 더 나아지는 조건이 지금 내 상황에 해당하는지 직접 판단합니다.

따라 하기

  1. 생각 정리·아이디어·패턴 분석은 채팅을 씁니다.
  2. 엑셀·워드 보고서처럼 파일을 만들거나 폴더를 정리할 때는 데스크톱 앱의 코워크를 씁니다.
  3. 대시보드 웹사이트나 앱을 만들 때는 Claude 코드를 씁니다.
  4. 발표 자료로 마무리할 때는 Claude 디자인(슬라이드)을 씁니다.
  5. 기획안 뼈대처럼 방향을 찾는 일은 Opus 5.5, 문장 손보기 같은 빠른 수정은 Sonnet 5.5로 처리합니다.
  6. 자주 하는 작업별로 잘 맞았던 도구와 모델을 메모해 둡니다.
  • 같은 자료로 채팅 분석 → 코워크 보고서 → 코드 대시보드 → 디자인 슬라이드처럼 이어서 쓸 수 있습니다.
