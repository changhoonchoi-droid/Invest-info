자동화할 업무 하나 고르기

Claude 앱

한꺼번에 다 자동화하려 하면 실패하기 쉽습니다. 가장 시간을 많이 잡아먹는 절차 하나를 골라, 언제·무엇을 확인해·어떤 결과물을 남길지 한 문장으로 정리합니다.

따라 하기

  1. 매일·매주 반복하는 업무 중 시간이 가장 많이 드는 것 하나를 고릅니다.
  2. 그 절차가 왜 생겼는지 적고 지금도 그 이유가 유효한지 확인합니다.
  3. Claude로 줄이거나 대신할 수 있는 부분과 사람이 꼭 확인할 부분을 나눕니다.
  4. '언제, 무엇을 확인해, 어떤 결과물을 남길지'를 한 문장으로 적습니다.
  5. 메일 발송처럼 되돌리기 어려운 단계는 따로 표시해 둡니다.
예시 프롬프트
나는 마케팅팀에서 매주 월요일 주간 지표 리포트를 만들어. 지금 하는 순서를 적어 줄 테니, 이 중 AI에게 맡길 수 있는 부분과 사람이 꼭 확인해야 할 부분을 나눠 줘. 필요한 정보가 있으면 먼저 질문해 줘.
  • 절차는 저절로 사라지지 않고 쌓이므로 의식적으로 점검해야 합니다.
  • 확신이 높은 일만 자동으로 처리하고, 나머지는 사람이 보도록 분류만 시키는 것이 안전합니다.

필요한 도구 연결하기

커넥터

보고서 재료가 있는 메일·Slack·드라이브를 커넥터로 이어 두면 Claude가 직접 자료를 찾습니다. 웹사이트에서 숫자를 모아야 한다면 Claude in Chrome도 연결합니다.

따라 하기

  1. Claude 입력창 옆 플러스 버튼을 누르고 커넥터 → 커넥터 추가 → 커넥터 둘러보기로 들어갑니다.
  2. Gmail, 구글 캘린더, 노션, Slack 등 필요한 서비스를 검색합니다.
  3. 서비스 옆 플러스 버튼을 누르고 계정으로 로그인해 인증합니다.
  4. 웹 데이터가 필요하면 크롬 웹스토어에서 Claude in Chrome을 설치하고 로그인합니다.
  5. 데스크톱 앱 설정 → 커넥터에서 Claude in Chrome의 구성을 눌러 활성화합니다.
  6. 간단한 요청으로 연결한 도구의 자료를 읽어 오는지 확인합니다.
예시 프롬프트
Gmail에서 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리해 줘.
  • 민감한 웹 작업에는 실행 전에 확인을 받는 Ask before acting 모드를 켜세요.
  • 브라우저 자동화는 캡차·로그인을 직접 처리해야 하니 80% 자동화, 20% 사람 확인을 기대하는 게 현실적입니다.

코워크로 한 번 직접 시키기

Cowork

예약부터 걸면 잘못된 결과가 매주 반복됩니다. 먼저 같은 일을 일반 요청으로 한 번 맡겨 계획과 결과물을 확인하고 고칩니다.

따라 하기

  1. 데스크톱 앱에서 새로 생성을 누르고 입력창 아래 협업을 고릅니다.
  2. 결과를 저장할 폴더를 추가하고 접근 권한을 허용합니다.
  3. 한 문장으로 정한 업무와 결과물 형식, 파일 이름 규칙을 적어 요청합니다.
  4. 파일을 바꾸기 전에 계획을 먼저 보여 달라고 덧붙입니다.
  5. 제안된 계획을 확인하고 고칠 점을 말한 뒤 승인합니다.
  6. 완성된 파일을 열어 내용과 수치를 확인하고 마음에 들 때까지 다듬습니다.
예시 프롬프트
Slack #마케팅 채널과 공유 드라이브의 지난주 캠페인 자료를 보고, 채널별 지표를 표로 정리한 주간 리포트를 워드로 만들어 줘. 파일명에는 날짜를 넣고, 작업 전에 계획을 먼저 보여 줘.
  • 원본 파일은 그대로 두고 결과는 새 파일로 저장하라고 적어 두세요.
  • 예전 방식: 상단 코워크 탭에서 폴더에서 작업으로 폴더를 열었습니다.

업무 방식을 스킬로 저장하기

Cowork

스킬은 업무 방식을 적어 둔 매뉴얼입니다. 만족스러운 결과가 나온 과정을 스킬로 저장하면 매주 같은 지시로 같은 품질의 리포트가 나오고, 팀과도 나눌 수 있습니다.

따라 하기

  1. 만족스러운 결과가 나온 세션에서 방금 한 작업을 스킬로 만들어 달라고 요청합니다.
  2. 확인할 자료, 표 형식, 보고서 순서가 스킬에 들어갔는지 확인합니다.
  3. 입력창에 /를 입력해 스킬이 목록에 보이는지 확인합니다.
  4. 테스트용 자료로 스킬을 실행해 결과를 보고 다듬습니다.
  5. 실행할 때마다 배운 점을 스킬에 반영해 달라고 요청합니다.
예시 프롬프트
방금 만든 주간 리포트 작업 과정을 스킬로 만들어 줘. 확인하는 자료, 표 형식, 보고서 순서를 포함하고, 다음에 같은 요청이 오면 이 방식대로 해 줘.
  • 필요한 직무 플러그인이 있으면 + → 플러그인 → 플러그인 추가로 설치해 명령어·스킬을 바로 쓸 수 있습니다.
  • 스킬은 일반 텍스트 파일이라 언제든 열어서 동작 방식을 확인할 수 있습니다.
  • 팀 스킬은 소유자·검토자·폐기 기준·테스트 방식을 먼저 정해 두세요.

예약 작업 걸기

Cowork

예약 작업은 반복할 일을 한 번 설명해 두면 매일·평일·매주 같은 주기로 Claude가 알아서 실행하는 기능입니다. 2026년 7월 업데이트 뒤로는 클라우드에서 돌아 기기가 꺼져 있어도 실행됩니다.

따라 하기

  1. 왼쪽 사이드바의 예약 페이지에서 새 작업을 만들거나 입력창에 /schedule을 입력합니다.
  2. 앞서 만든 스킬을 써서 반복할 일을 자연어로 설명합니다.
  3. Claude가 만든 예약 작업 프롬프트 초안을 검토하고 고칩니다.
  4. 주기를 매시간·매일·평일·수동 중에서 고르고 실행 시각을 정합니다.
  5. 내용이 맞으면 제안을 수락합니다.
  6. 예약 페이지에서 작업이 추가됐는지 확인하고 바로 한 번 실행해 봅니다.
예시 프롬프트
매주 월요일 오전 8시에 지난주 Slack #마케팅 채널과 공유 드라이브 자료로 주간 지표 리포트 스킬을 실행해서, 날짜를 넣은 워드 파일로 저장해 줘. 메일은 보내지 말고 초안으로만 남겨 줘.
  • 클라우드 실행은 내 PC의 로컬 폴더에 접근하지 못하니, 자료는 커넥터로 닿는 드라이브·Slack에 두는 편이 안전합니다.
  • 실행마다 새 세션으로 돌아 그때의 최신 파일 상태를 기준으로 합니다.
  • 구글 워크스페이스를 쓴다면 제미나이 스파크의 스케줄로도 메일 정리를 예약할 수 있습니다(구글 AI 프로 이상).

확인 지점과 멈춤 조건 정하기

Cowork

자동화가 늘수록 어디서 사람이 확인하고 언제 멈출지를 미리 정해야 안전합니다. 메일 발송처럼 되돌리기 어려운 지점만 내 승인을 받게 하면 확인 부담은 줄고 사고는 막을 수 있습니다.

따라 하기

  1. 메일 발송·파일 삭제처럼 되돌리기 어려운 단계는 실행 전에 내 확인을 받도록 프롬프트에 적습니다.
  2. 외부로 나가는 메시지는 발송하지 말고 초안으로만 남기게 합니다.
  3. 결과에 숫자가 있으면 원본 출처와 맞는지 확인하는 단계를 넣습니다.
  4. 자료가 없거나 진전이 없으면 억지로 만들지 말고 멈춰 알리게 합니다.
  5. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  • 승인이 필요한 단계는 모바일로도 요청이 오며 데스크톱 앱과 똑같이 처리할 수 있습니다.
  • 자기 결과를 검사하게 하면 관대해지기 쉬우니, 중요한 결과는 다른 AI나 사람이 검증합니다.

실행 기록 보고 다듬기

Cowork

처음 몇 번은 결과를 직접 확인하고, 신뢰가 쌓이면 맡기는 범위를 넓힙니다. 예약 페이지에서 기록을 보고 지시문과 스킬을 고치면 회차마다 품질이 올라갑니다.

따라 하기

  1. 실행 뒤 예약 페이지나 코워크 탭에서 지난 실행 기록과 결과 파일을 확인합니다.
  2. 빠진 자료나 틀린 형식이 있으면 지시문이나 주기를 수정합니다.
  3. 반복되는 지적은 스킬에 반영해 달라고 요청합니다.
  4. 결과가 안정되면 맡기는 범위를 조금씩 넓힙니다.
  5. 완성된 스킬을 팀과 공유해 누구나 같은 리포트를 만들게 합니다.
예시 프롬프트
