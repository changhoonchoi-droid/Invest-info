페이지 목적과 구성 정하기

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

만들기 전에 방문자가 이 페이지에서 무엇을 하게 할지 정하면 AI에 줄 요청이 구체적이 됩니다. 이 단계는 영상 자료에는 없지만 흐름을 잇기 위한 준비입니다.

따라 하기

  1. 누가 보고 어떤 행동(신청·문의·구매)을 하게 할지 한 문장으로 적습니다.
  2. 필요한 섹션을 떠올려 나열합니다.
  3. 참고하고 싶은 사이트 2~3개의 주소를 모읍니다.
  4. Claude에게 섹션 구성 초안을 물어 내 생각과 비교합니다.
예시 프롬프트
우리 동네 필라테스 스튜디오 홍보 랜딩 페이지를 만들 거야. 방문자가 체험 수업을 신청하게 하는 게 목표야. 필요한 섹션 구성을 제안해 줘.
  • 섹션 이름과 업종, 분위기를 미리 정해 두면 뒤 단계 요청이 쉬워집니다.

Readdy로 한 줄 요청해 만들기

Readdy AI

업종과 요청을 입력하면 몇 분 만에 반응형 홈페이지가 나옵니다. 참고 사이트 링크나 캡처를 함께 주면 더 가깝게 만들어 줍니다. 요청 한 번마다 크레딧이 차감됩니다.

따라 하기

  1. Readdy AI에 접속해 구글 계정으로 로그인하고 계정 메뉴의 언어에서 한국어를 선택합니다.
  2. 처음부터 시작을 선택하고 업종, 비즈니스 이름, 대상, 분위기와 섹션을 입력합니다.
  3. 보내기를 눌러 AI가 계획·개발을 마칠 때까지 기다립니다.
  4. 완성된 PC·모바일 화면을 확인합니다.
  5. 편집 선택을 눌러 바꾸고 싶은 부분을 클릭한 뒤 일상 언어로 변경을 입력합니다.
  6. 섹션 전체를 바꾸려면 상위 선택을 눌러 파란 박스가 전체를 감싸게 합니다.
  • 수정 요청은 한 번에 하나씩 입력해야 어긋남이 적습니다.
  • 요청 한 번마다 25 크레딧이 차감됩니다.
  • 참고 사이트 주소나 명함, 템플릿으로 시작할 수도 있습니다.

캡처로 원하는 느낌 맞추기

Google AI 스튜디오

디자인은 말보다 이미지가 정확하게 전달됩니다. 마음에 드는 사이트를 전체 캡처해 붙여 넣으면 비슷한 느낌의 페이지를 만들어 줍니다.

따라 하기

  1. 프레이머 리소스의 마켓플레이스에서 마음에 드는 템플릿을 골라 프리뷰를 누릅니다.
  2. 스크롤 캡처 도구로 웹사이트 전체를 캡처해 복사합니다.
  3. 구글 AI 스튜디오 프롬프트 입력창에 이미지를 붙여 넣고 비슷한 느낌의 랜딩 페이지를 요청합니다.
  4. 빌드를 눌러 결과를 확인하고 원본과 비교합니다.
  5. 고칠 위치는 미리보기에서 어노테이트 앱을 켜 화면에 직접 표시하고 요청을 적습니다.
예시 프롬프트
해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘
  • 위치를 글로 설명하기 어려울 때 어노테이트가 효과적입니다.
  • 완성된 컴포넌트 코드를 레퍼런스로 함께 붙여 넣으면 디자인 품질이 올라갑니다.
  • 영상 자막이 불분명해 일부 버튼 이름은 화면에서 확인이 필요합니다.

오류를 AI에게 잘 전달하기

AI 코딩 도구

화면이 깨지거나 에러가 나면 단서를 충분히 줄수록 AI가 잘 고칩니다. 오류 메시지, 발생 상황, 원래 기대한 동작을 함께 전달합니다.

따라 하기

  1. 문제 화면에서 마우스 오른쪽 버튼을 눌러 검사를 엽니다.
  2. 개발자 도구의 콘솔 탭의 오류 메시지를 복사하거나 캡처합니다.
  3. AI 프롬프트 창에 오류 메시지를 붙여 넣습니다.
  4. 언제 발생하는지와 원래 기대하는 동작을 적습니다.
  5. 가능하면 발생 화면 스크린샷도 첨부합니다.
예시 프롬프트
스크롤할 때 아래 오류가 나요. 원래는 부드럽게 내려가야 하는데 화면이 멈춥니다. 오류 메시지와 스크린샷을 첨부합니다.
  • 언제·어디서·어떻게 발생했는지 단서를 많이 줄수록 해결이 잘 됩니다.

Claude

따라 하기

  1. 페이지에 들어간 숫자·후기·가격·영업시간 문구를 목록으로 뽑습니다.
  2. 실제 사실과 다른 부분을 직접 고치도록 수정 요청을 합니다.
  3. 구체적 사실이 나온 곳은 Claude에게 출처나 확신도를 물어 교차 확인합니다.
예시 프롬프트
이 페이지 문구에서 숫자, 후기, 가격처럼 사실 확인이 필요한 부분을 모두 뽑아 목록으로 정리해 줘.
  • 생성 문구를 그대로 쓰지 말고 우리 가게의 실제 정보로 바꾸세요.

도메인 연결하고 공개하기

Readdy AI

공개 게시에는 유료 결제가 필요하므로 요금을 먼저 확인합니다. 공개 직전에 PC와 모바일 화면을 다시 점검합니다.

따라 하기

  1. PC·모바일 화면에서 깨지는 곳이 없는지 마지막으로 확인합니다.
  2. 공개 게시에 유료 결제가 필요하므로 크레딧과 요금제를 확인합니다.
  3. 도메인 메뉴에서 도메인을 연결합니다.
  4. 공개한 주소를 열어 실제로 보이는지 확인합니다.
  • 예전 방식: 가입 시 매달 250 크레딧이 무료였다고 소개됐으나 최근 영상에서는 유료 플랜 기준 크레딧을 안내합니다.
