모드가 뭔지 알고 고르기

Claude Code

모드는 Claude Code가 작업할 때 보내는 신호를 받아 지켜보거나, 살짝 고치거나, 대신 처리하는 작은 프로그램입니다. 스킬과 MCP가 밖에서 지식과 도구를 건넨다면 모드는 작업 환경 자체를 바꿉니다.

따라 하기

  1. 만들고 싶은 기능이 지켜보기, 살짝 고치기, 대신 처리하기 중 어디에 해당하는지 정합니다.
  2. 창이나 버튼 같은 화면 요소가 필요하면 스킬이나 MCP 대신 모드를 고릅니다.
  3. 토큰 사용량 표시처럼 간단한 것부터 시작하기로 정합니다.
  • 모드는 2026년 10월 1일 공식 발표된 새 기능이라 사용 방법이 바뀔 수 있습니다.

사용 패턴으로 추천받기

Claude Code

무엇을 만들지 막막하면 내 세션 로그에서 자주 반복하는 말과 작업을 찾게 합니다. 근거와 함께 추천을 받으면 실제로 쓸모 있는 모드를 고를 수 있습니다.

따라 하기

  1. 세션 로그를 훑어 자주 반복하는 말과 작업을 파악해 달라고 요청합니다.
  2. 흐름을 돕고 비용을 아끼며 집중하게 해 줄 모드 다섯 개를 추천해 달라고 합니다.
  3. 추천과 함께 나온 패턴·근거를 읽어 봅니다.
  4. 마음에 드는 번호를 골라 둡니다.
예시 프롬프트
내 Claude Code 세션 로그를 최대한 훑어서 내가 자주 반복하는 말과 작업을 파악해 줘. 그걸 바탕으로 흐름을 돕고, 비용을 아끼고, 집중하게 해 줄 모드 다섯 개를 근거와 함께 추천해 줘.
  • 창이나 버튼 같은 화면 요소는 모드로만 만들 수 있습니다.

말로 첫 모드 만들기

Claude Code 데스크톱

모드를 만드는 전용 스킬이 들어 있어 코드를 몰라도 말로 만들 수 있습니다. 데스크톱 앱에서 프로젝트 폴더를 열고 원하는 모드를 설명합니다.

따라 하기

  1. Claude Code 데스크톱 앱 좌측 상단의 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼에서 폴더 열기를 눌러 프로젝트 폴더를 만들어 엽니다.
  3. 만들고 싶은 모드를 말로 설명해 요청합니다.
  4. 핫 리로딩 안내가 나오면 Enable for this session을 누릅니다.
  5. 모드가 잘 보이는지 확인해 달라고 요청해 결과를 봅니다.
예시 프롬프트
토큰 사용량을 아이콘과 함께 화면에 보여 주는 모드를 만들어 줘.
  • 응용 예: 턴이 끝날 때마다 할 일 세 가지를 카드로 띄우고 클릭하면 실행되는 '다음 작업 추천' 모드도 만들 수 있습니다.
  • 코드로 직접 만들고 싶다면 플러그인의 hook.json에 TypeScript 파일을 연결하는 방식도 있습니다.

플러그인으로 설치해 늘 쓰기

Claude Code 데스크톱

말로 만든 모드는 만든 대화 안에서만 작동합니다. 플러그인으로 설치하면 다른 세션과 프로젝트에서도 쓰고, 마켓플레이스 저장소로 팀과 공유할 수도 있습니다.

따라 하기

  1. 모드를 만든 대화로 돌아갑니다.
  2. 모든 세션에서 쓸 수 있도록 플러그인으로 설치해 달라고 요청합니다.
  3. 새 세션이나 다른 프로젝트를 열어 모드가 적용되는지 확인합니다.
예시 프롬프트
방금 만든 모드를 내 모든 세션에서 쓸 수 있도록 플러그인으로 설치해 줘.
  • 모드는 플러그인이라 마켓플레이스 저장소에 올려 팀과 공유할 수 있습니다.

따라 하기

  2. /claude-api prompt-audit를 실행합니다.
  3. CLAUDE.md와 스킬의 지침이 어떻게 바뀌었는지 확인합니다.
예시 프롬프트

  • API를 쓰지 않고 Claude Code만 써도 사용할 수 있습니다.

서브에이전트 비용 줄이기

Claude Code

코드베이스를 읽기만 하는 탐색용 서브에이전트에는 Opus급 추론이 필요 없습니다. Sonnet이나 Haiku로 돌리면 비용과 사용 한도를 아낄 수 있습니다.

따라 하기

  1. 코드베이스를 읽기만 하는 서브에이전트가 어느 것인지 정합니다.
  2. 해당 커스텀 서브에이전트 파일의 frontmatter에서 모델을 Sonnet으로 지정합니다.
  3. 모든 서브에이전트 기본 모델을 바꾸려면 settings.json에 CLAUDE_CODE_SUBAGENT_MODEL 환경 변수를 설정합니다.
  • 읽기 전용 서브에이전트는 경우에 따라 Haiku까지 내려도 됩니다.
  • Opus 5.5의 기본 effort는 medium이고, 프로젝트 전체를 바꾸는 수정에는 high를 쓰세요.
