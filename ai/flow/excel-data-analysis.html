작업 폴더와 원칙 정하기

Cowork

데이터 작업에서 가장 큰 사고는 원본을 덮어쓰는 것입니다. 코워크에 작업 폴더를 열어 주기 전에 '원본 유지·삭제 전 확인' 같은 규칙을 글로벌 지침에 적어 둡니다.

따라 하기

  1. Claude 데스크톱 앱을 열고 코워크(또는 새로 생성 → 협업)로 들어갑니다.
  2. 입력창 아래 프로젝트 또는 폴더에서 폴더 추가를 눌러 작업 폴더를 엽니다.
  3. 폴더 접근 권한 창에서 항상 허용을 선택합니다.
  4. 분석할 엑셀 파일들을 그 폴더에 넣습니다.
  5. 설정의 협업 탭에서 지침 편집을 눌러 역할·날짜 형식·삭제 전 확인 규칙을 적고 저장합니다.
예시 프롬프트
나는 회사 재무팀 대리야. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적어 줘. 원본 파일은 절대 고치지 말고, 파일을 지우거나 덮어쓰기 전에는 반드시 나에게 확인해 줘.
  • 코워크는 Pro(월 20달러) 이상, 데스크톱 앱에서만 로컬 폴더를 다룰 수 있습니다.
  • 개인정보가 든 데이터라면 학습 사용 끄기와 회사 정책을 먼저 확인하세요.

여러 파일 합쳐 정리하기

Cowork

코워크는 폴더 안 파일을 직접 읽고 스스로 계획을 세워 엑셀을 합치고 정리합니다. 계획을 먼저 받아 확인한 뒤 승인하면 실수를 미리 잡을 수 있습니다.

따라 하기

  1. 합칠 파일과 정리 기준(중복, 빈칸, 열 이름 통일)을 적어 요청합니다.
  2. 원본은 그대로 두고 정리본은 날짜를 넣은 새 파일로 저장하라고 적습니다.
  3. 바꾸기 전에 계획을 먼저 보여 달라고 덧붙입니다.
  4. 제안된 계획을 확인하고 고칠 점을 말한 뒤 승인합니다.
  5. 완성된 정리본을 열어 행 수와 수식이 맞는지 확인합니다.
예시 프롬프트
설문 응답 엑셀 세 개를 하나로 합치고, 중복 응답과 빈칸을 정리해 줘. 원본은 그대로 두고 정리본은 날짜를 넣은 새 파일로 저장해 줘. 파일을 바꾸기 전에 계획을 먼저 보여 줘.
  • '원본은 그대로 두고 정리본은 새 파일로 저장해 줘'는 프롬프트에 반드시 적습니다.
  • 영수증 이미지 폴더로 경비 보고서를 만드는 일에도 같은 방식이 통합니다.

Excel에서 묻고 근거 확인하기

Claude in Excel

Claude in Excel은 통합 문서 전체를 읽고 질문에 답하며, 답의 근거가 된 셀로 바로 이동하게 해 줍니다. 숫자를 하나씩 확인하며 분석할 수 있어 보고용 수치에 안심하고 쓸 수 있습니다.

따라 하기

  1. Excel에서 정리본 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C로 Claude 사이드바를 엽니다.
  3. 확인하고 싶은 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽습니다.
  5. 응답의 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
  6. 오류가 있으면 '5월에 왜 오류가 나?'처럼 물어 원인 셀을 찾습니다.
예시 프롬프트
출장비와 식대를 전체 비용의 40% 이하로 유지하려고 했어. 월별로 목표를 지켰는지 확인하고, 계산에 쓴 근거 셀을 보여 줘.
  • Pro·Max·Team·Enterprise 플랜용 베타이며, 민감한 데이터는 조직의 데이터 처리 정책을 따르세요.
  • 회사 데이터가 BigQuery에 있다면 데이터 팀에 BigQuery MCP 연결을 요청해 Claude Code에서 말로 지표를 조회할 수 있습니다.

피벗 테이블과 차트 만들기

Claude in Excel

피벗 테이블과 차트를 말로 요청하면 Claude가 시트에 바로 만들어 줍니다. 차트 종류와 제목까지 대화로 바꿀 수 있어 보고용 그림을 빠르게 준비합니다.

따라 하기

  1. 사이드바에 '지역·제품별 총매출 피벗 테이블을 만들어 줘'처럼 요청합니다.
  2. 만들어진 피벗 테이블로 지역별 매출 차트를 요청합니다.
  3. 누적 막대 등 원하는 차트 종류와 제목을 지정해 고칩니다.
  4. 차트 숫자가 피벗 테이블 값과 맞는지 확인합니다.
  5. PowerPoint 파일도 함께 열려 있으면 같은 대화에서 슬라이드 차트까지 갱신하게 합니다.
예시 프롬프트
지역별·제품별 총매출 피벗 테이블을 만들어 줘. 이어서 이 피벗 테이블로 지역별 매출 누적 막대 차트를 만들고, '3분기 지역별 매출' 제목을 달아 줘.
  • Excel과 PowerPoint를 잇는 이 흐름은 Skills로 저장해 다음 달에도 다시 실행할 수 있습니다.
  • 요청하지 않은 요소(이동평균 등)가 추가될 수 있으니 차트를 꼭 확인하세요.

분석 결과를 보고서로 만들기

Cowork

정리본과 분석 결과를 바탕으로 코워크가 비교 시트와 워드 보고서까지 만들어 줍니다. 핵심 요약을 맨 앞에 두라고 지시하면 바로 보고에 쓸 수 있는 문서가 나옵니다.

따라 하기

  1. 같은 작업 폴더에서 정리본을 기준으로 만들 결과물을 적어 요청합니다.
  2. 비교 시트·키워드 순위처럼 필요한 분석 항목을 구체적으로 적습니다.
  3. 보고서 형식(핵심 요약 먼저, 분량)과 파일 이름 규칙을 적습니다.
  4. 계획을 확인하고 승인합니다.
  5. 완성된 워드 보고서의 수치가 엑셀과 맞는지 확인합니다.
예시 프롬프트
정리본으로 채널별 만족도 비교 시트와 불만 키워드 탑 10을 만들고, 이를 바탕으로 핵심 요약을 맨 앞에 둔 2장짜리 워드 보고서를 만들어 줘. 파일명에는 날짜를 넣어 줘.
  • 보고서의 숫자는 원본 데이터와 다시 맞춰 보는 숫자 검산을 습관처럼 하세요.

팀용 대시보드 웹페이지 만들기

Claude Code

팀원 누구나 브라우저로 보는 대시보드는 Claude 코드로 만듭니다. 데스크톱 앱 코드 탭에서 폴더를 열고 CSV를 첨부해 무엇을 보여 줄지만 말하면 됩니다.

따라 하기

  1. Claude 데스크톱 앱에서 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼에서 폴더 열기로 대시보드용 폴더를 지정하고 워크스페이스 신뢰를 진행합니다.
  3. 정리본을 CSV로 저장해 첨부합니다.
  4. 보여 줄 그래프와 거르기 기능을 풀어 써서 요청합니다.
  5. 오른쪽 내장 브라우저에서 결과를 확인하고, 필요하면 기본 브라우저에서 열기로 엽니다.
  6. 고칠 점은 다시 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 문항별 응답 비율을 그래프로 보여 주고, 연령대별로 걸러 볼 수 있게 해 줘.
  • 어떻게 만들지는 AI에게 맡기고, 무엇을 보여 줄지에 집중합니다.
  • 회사 밖으로 데이터가 나가지 않도록 공유 범위는 회사 정책에 맞춰 정하세요.

매주 자동 갱신 걸기

Cowork

매주 같은 분석을 반복한다면 과정을 스킬로 저장하고 예약 작업으로 걸어 둡니다. 실행마다 그때의 최신 파일을 기준으로 돌아 새 데이터가 자동 반영됩니다.

따라 하기

  1. 이번 정리·분석 과정을 스킬로 만들어 달라고 요청합니다.
  2. 입력창에 /schedule을 입력하거나 예약 페이지에서 새 작업을 만듭니다.
  3. 어느 폴더의 새 파일로 무엇을 만들지 자연어로 설명합니다.
  4. 주기를 고르고 프롬프트 초안을 확인한 뒤 수락합니다.
  5. 바로 한 번 실행해 결과 파일을 확인합니다.
예시 프롬프트
매주 월요일 오전 8시에 공유 드라이브 설문 폴더에 새로 들어온 엑셀을 지난주와 같은 방식으로 정리하고, 채널별 만족도 변화를 요약한 보고서를 날짜를 넣은 새 파일로 저장해 줘. 원본은 고치지 마.
  • 예약 작업은 클라우드에서 돌아 내 PC 로컬 폴더에는 접근하지 못하니, 자료는 커넥터로 연결한 드라이브에 두세요.
  • 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행을 할 수 있습니다.
