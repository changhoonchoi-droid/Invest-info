따라 하기

  1. 분석할 데이터에 고객 이름·연락처 같은 개인정보가 있는지 확인합니다.

  4. 개인 계정이라면 메모리와 학습 사용 설정을 먼저 점검합니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본으로 꺼져 있습니다.

엑셀에 물어 현황 파악하기

Excel(Claude 애드인)

Claude in Excel은 통합 문서 전체를 읽고 질문에 셀 단위 근거와 함께 답합니다. 목표를 구체적으로 적어 물으면 계산 과정까지 보여 줍니다.

따라 하기

  1. Excel에서 통합 문서를 엽니다.
  2. Windows는 Control + Alt + C, Mac은 Control + Option + C로 Claude 사이드바를 엽니다.
  3. 확인하고 싶은 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽습니다.
  5. 응답의 인용 상자를 눌러 근거 셀로 이동해 확인합니다.
예시 프롬프트
출장비와 식대를 전체 비용의 40% 이하로 맞추려고 했어. 이번 분기에 목표를 달성했는지 계산 과정과 근거 셀을 보여 줘.
  • Pro, Max, Team, Enterprise 플랜의 베타 기능이며, 수정 전에 허락을 구하고 변경 내용을 설명합니다.

오류·수식 원인 추적하기

Excel(Claude 애드인)

물려받은 엑셀 파일의 오류나 낯선 수식은 원인을 찾는 데 시간이 많이 듭니다. Claude에게 물으면 원인 셀까지 추적하고 수식을 부분별로 설명해 줍니다.

따라 하기

  1. 오류가 난 곳을 짚어 원인을 물어봅니다.
  2. Claude가 알려 준 원인 셀로 이동해 확인합니다.
  3. 낯선 수식은 어떻게 동작하는지 부분별 설명을 요청합니다.
  4. 고치기 전에 Claude가 허락을 구하면 변경 내용을 읽고 허용합니다.
예시 프롬프트
5월 합계 셀에 왜 오류가 나는지 원인 셀까지 찾아 줘. 그리고 '달성률' 열의 수식이 어떻게 계산되는지 부분별로 설명해 줘.
  • 영어로 Why is there an error in May?처럼 짧게 물어도 됩니다.

피벗 테이블·차트 만들기

Excel(Claude 애드인)

판매 데이터 같은 표를 말로 요청해 피벗 테이블과 차트로 바꿉니다. 차트의 종류, 축, 제목, 색상도 요청으로 바꿀 수 있습니다.

따라 하기

  1. 판매 거래 데이터가 있는 시트에서 Claude 사이드바를 엽니다.
  2. 지역별·제품별 총매출 피벗 테이블을 요청합니다.
  3. 지역이 행, 제품이 열로 구성됐는지 확인합니다.
  4. 피벗 테이블로 지역별 매출 차트를 만들어 달라고 합니다.
  5. 누적 막대 차트로 바꾸고 제목을 넣는 식으로 차트를 다듬습니다.
예시 프롬프트
지역별·제품별 총매출을 보여 주는 피벗 테이블을 만들어 줘. 그다음 이 피벗 테이블로 지역별 매출을 누적 막대 차트로 그리고 '3분기 지역별 매출' 제목을 넣어 줘.
  • 데이터 정리, 수식으로 연결된 예측 모델도 맡길 수 있습니다.
  • 외부에 공유할 결과물은 조직의 기준에 맞는지 반드시 검증합니다.

큰 데이터는 말로 조회하기

Claude Code

엑셀에 담기 어려운 제품 데이터는 데이터 팀이 BigQuery MCP로 Claude Code에 연결해 두면 SQL 없이 말로 조회할 수 있습니다. 회사에 데이터 웨어하우스가 있는 경우에 쓰는 선택 단계입니다.

따라 하기

  1. 데이터 팀에 BigQuery MCP로 제품 데이터 테이블을 Claude Code에 연결해 달라고 요청합니다.
  2. Claude Code에서 보고 싶은 지표와 기간을 말합니다.
  3. 조회할 데이터 테이블 이름을 알려 줍니다.
  4. 파일 수정 권한 요청이 나오면 확인하고 허용합니다.
  5. 만들어진 그래프를 확인하고 '요금제별로 나눠 그려 줘'처럼 이어서 요청합니다.
예시 프롬프트
지난 3개월 동안 다크 모드를 쓰는 사용자 비율을 그래프로 그려 줘. 그다음 요금제별로 나눠서 다시 그려 줘.
  • 요청하지 않은 7일 이동평균 같은 요소가 덧붙을 수 있으니 그래프를 꼼꼼히 확인하세요.
  • SQL을 짜는 일보다 결과를 해석하는 일이 더 중요합니다.

숫자와 해석 검증하기

Excel(Claude 애드인)

보고에 들어갈 숫자와 해석은 반드시 검증합니다. 피벗 합계를 원본과 맞춰 보고, Claude가 내린 해석의 근거와 확신 정도를 물어 과장된 결론을 걸러 냅니다.

따라 하기

  1. 피벗 테이블 합계가 원본 데이터 합계와 같은지 검산해 달라고 합니다.
  2. 인용 상자로 근거 셀을 열어 직접 확인합니다.
  3. Claude의 해석마다 근거와 확신 정도를 묻습니다.
  4. 차트에 요청하지 않은 요소가 들어갔는지 확인합니다.
예시 프롬프트
피벗 테이블의 지역별 합계가 원본 시트 합계와 같은지 검산해 줘. 그리고 네가 낸 해석마다 근거가 된 셀과 확신 정도(높음·중간·낮음)를 표시해 줘.
  • 자신 있는 말투나 깔끔한 차트는 정확성의 증거가 아닙니다.

분석 결과를 슬라이드로 옮기기

PowerPoint(Claude 애드인)

검증한 분석 결과를 회사 템플릿의 보고 슬라이드로 옮깁니다. 표는 매트릭스로, 차트는 비교하기 좋은 형태로 바꿀 수 있고 결과는 직접 편집할 수 있는 PowerPoint 도형과 차트로 만들어집니다.

따라 하기

  1. 회사 템플릿을 PowerPoint에서 열고 Claude 애드인을 엽니다.
  2. + 버튼으로 분석한 엑셀 파일을 올립니다.
  3. 슬라이드 수와 담을 결론을 적어 보고 슬라이드를 요청합니다.
  4. 차트 슬라이드를 선택해 두 지표가 함께 보이는 묶음 가로 막대 차트처럼 원하는 형태로 바꿉니다.
  5. 슬라이드의 숫자가 엑셀 결과와 같은지 확인합니다.
예시 프롬프트
올린 엑셀의 3분기 지역별 매출 분석으로 보고 슬라이드 3장을 만들어 줘. 1장은 결론 한 줄과 핵심 수치 3개, 2장은 지역별 매출 차트, 3장은 다음 분기 확인할 점으로 해 줘.
  • 열려 있는 Excel과 PowerPoint 파일을 하나의 대화에서 이어서 작업할 수도 있습니다.
  • Claude는 슬라이드에 추가한 데이터의 출처도 알려 줍니다.
