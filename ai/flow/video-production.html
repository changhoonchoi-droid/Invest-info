영상 기획과 장면 정리

Claude

영상 생성은 크레딧이 많이 드니 먼저 Claude와 기획을 정리합니다. 긴 글처럼 구조를 먼저 확정한 뒤 장면별 대본·프롬프트로 내려갑니다.

따라 하기

  1. 영상의 목적, 대상, 길이, 분위기를 정리해 Claude에게 알려 줍니다.
  2. 구조를 먼저 만들어줘라고 요청하고 순서가 마음에 안 들면 바꿔 달라고 합니다.
  3. 구조가 확정되면 장면별 설명을 만들어 달라고 요청합니다.
  4. 장면별 설명을 영상 생성용 프롬프트로 다듬어 달라고 요청합니다.
예시 프롬프트
선글라스 신제품 15초 SNS 광고를 만들 거야. 먼저 장면 구조만 3~4컷으로 만들어 줘. 구조가 확정되면 컷별 영상 프롬프트로 바꿔 달라고 할게.
  • 영상보다 이미지로 먼저 구도를 확정하면 크레딧이 덜 듭니다.

영상 도구를 Claude에 연결하기

Claude

목록에 없는 서비스는 서비스 사이트에서 MCP 주소를 복사해 커스텀 커넥터로 붙입니다. 한 번 연결하면 Claude 대화창에서 이미지·영상 생성을 바로 부릅니다. Claude 계정과 서비스 계정이 각각 필요합니다.

따라 하기

  1. 연결할 서비스 사이트(예: Higgsfield, Artlist)의 MCP 메뉴에서 Claude를 선택해 MCP 링크를 복사합니다.
  2. Claude의 설정 → 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  3. 이름 칸에 서비스 이름을, MCP 서버 URL 칸에 복사한 링크를 붙여 넣습니다.
  4. 계속을 누르고 서비스 계정으로 로그인해 연결합니다.
  5. 채팅창 + → 커넥터에서 서비스가 파란색(사용 중)인지 확인합니다.
  6. '힉스필드 MCP로 크레딧 잔액과 요금제를 확인해 줘'처럼 요청해 연결을 시험합니다.
예시 프롬프트
힉스필드 MCP로 크레딧 잔액과 요금제를 확인해 줘.
  • 이미지·영상 생성은 서비스 쪽 크레딧이 소모됩니다.
  • 공식 MCP만 쓰고 출처 불분명한 비공식 MCP는 피하세요.
  • 크레딧을 쓰기 전에 항상 승인을 묻도록 하면 비용을 아낄 수 있습니다.

일관된 캐릭터 이미지 만들기

힉스필드

영상에서 얼굴·의상이 흔들리지 않으려면 먼저 모델 이미지와 같은 인물의 캐릭터 시트를 만들어 레퍼런스로 씁니다. 영상에 쓸 모델은 전신으로 만드세요.

따라 하기

  1. 힉스필드에 로그인하고 상단에서 이미지를 선택합니다.
  2. 모델의 외모·의상·분위기를 구체적으로 적고 전신 사진을 요청합니다.
  3. 모델을 GPT Image 2.5로 고르고 비율·품질·해상도를 정해 생성하기를 누릅니다.
  4. 만든 이미지를 첨부해 같은 인물의 캐릭터 시트를 요청합니다.
  • 영상에 쓸 모델은 전신으로 만들어야 하반신이 임의로 표현되지 않습니다.
  • 해상도를 올리면 크레딧과 생성 시간이 늘어납니다.

제품 사진으로 배경·렌더링 만들기

Artlist

제품이 주인공인 광고라면 제품 사진을 여러 각도로 준비하고 배경 장면과 합친 렌더링 이미지를 먼저 만듭니다. 이 이미지가 영상의 레퍼런스가 됩니다.

따라 하기

  1. 제품 사진을 정면·측면·후면 등 여러 각도로 준비합니다.
  2. Artlist의 AI 툴킷에서 이미지를 선택하고 배경 장면 이미지를 생성합니다.
  3. 배경과 제품 이미지를 레퍼런스로 넣어 제품이 놓인 3D 렌더링 이미지를 만듭니다.
  • 영상 생성은 크레딧이 많이 들므로 이미지로 구도를 먼저 확정하세요.

레퍼런스로 영상 생성하기

Artlist

제품·배경·캐릭터 이미지를 레퍼런스로 넣고 짧은 프롬프트로 영상을 만듭니다. 시작·끝 프레임이 아니라 이미지 레퍼런스로 넣어야 합니다.

따라 하기

  1. 비디오로 바꾸고 올 모델스에서 Seedance 2.5를 선택한 뒤 유즈 모델을 누릅니다.
  2. 길이를 정하고 화질을 높게 설정하며 소리가 필요하면 오디오를 켭니다.
  3. +를 눌러 이미지 레퍼런스로 제품·배경·렌더링 이미지를 추가합니다.
  4. 프롬프트를 쓰고 제너레이트를 누릅니다.
  5. 마음에 들면 다운로드하고, 아니면 프롬프트를 고쳐 다시 생성합니다.
예시 프롬프트
첨부한 SUV가 비 오는 서울 도심 야경을 달리는 30초 광고. 앞부분은 차분하게, 마지막에 차량 정면 클로즈업. 제품 디자인은 레퍼런스 그대로 유지.
  • 스타터 요금제에서는 Seedance 2.5를 쓸 수 없다고 합니다.
  • 영상 모델을 비교할 때는 같은 프롬프트로 첫 결과만 채점하고 길이가 다르면 1분 기준 가격으로 환산하세요.

영상 일부만 바꾸기

Newtake

영상 전체를 다시 만들면 크레딧이 많이 듭니다. 수정할 부분만 지정해 교체하면 비용과 시간을 아낄 수 있습니다. AI가 다시 생성하는 방식이라 모든 세부가 완전히 같지는 않습니다.

따라 하기

  1. 만든 영상을 선택하고 왼쪽 위 구간 리메이크를 누릅니다.
  2. 바꿀 구간을 지정하고 바꿀 제품·모델 이미지를 연결합니다.
  3. 수정 문장을 입력해 생성합니다.
  4. 원본과 결과를 비교해 확인합니다.
예시 프롬프트
선글라스를 안경으로 바꿔 줘. 인물은 연결한 모델 이미지의 인물이야.
  • 구간이 짧을수록 크레딧이 덜 듭니다.
  • 프롬프트에 어떤 이미지의 인물인지 구체적으로 써야 엉뚱한 인물이 섞이지 않습니다.

따라 하기

예시 프롬프트
[whispers] 사실은 말이야... [curious] 이거, 어떻게 만든 건지 궁금하지 않아?

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

AI 영상은 제품 디테일이 어긋날 수 있습니다. 광고에 쓰기 전 제품 형태, 브랜드 가이드, 사용한 이미지·음성의 권리를 점검합니다.

따라 하기

  3. 로고 같은 이미지는 직접 쓰기 전 저작권을 확인합니다.
  4. 최종본을 내보내고 용도(시안/게시)를 구분해 둡니다.
  • 이 단계는 일반적인 점검 사항이며, 회사 규정이 있으면 그에 따르세요.
