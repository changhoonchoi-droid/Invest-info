설치 방법 고르고 로그인

Claude Code

Claude Code는 터미널, VS Code, JetBrains, 데스크톱 앱, 웹에서 쓸 수 있습니다. 처음에는 데스크톱 앱으로 시작하고 익숙해지면 CLI로 넘어가는 것을 영상에서 추천합니다.

따라 하기

  1. Claude Desktop 상단의 Code 토글(또는 코드 탭)로 전환합니다.
  2. VS Code는 확장 패널에서 Claude Code를 검색해 Anthropic이 만든 확장을 설치합니다.
  3. 터미널을 쓴다면 Windows PowerShell에서는 Invoke-RestMethod 명령으로 설치합니다.
  4. 작업할 프로젝트 폴더로 이동해 Claude Code를 실행합니다.
  5. 처음 실행 시 테마를 고르고 Claude 계정 또는 API 키로 로그인합니다.
  • 실행한 폴더와 그 하위 폴더 전체에 접근 권한이 생기므로 폴더 위치를 확인하고 실행합니다.
  • Homebrew와 winget으로 설치하면 자동 업데이트가 되지 않습니다.

폴더 열고 첫 결과물 만들기

Claude Code

폴더를 지정하고 파일을 첨부해 요청하면 개발 지식 없이도 웹사이트 같은 결과물을 만들 수 있습니다. 어떻게 만들지는 AI에게 맡기고 무엇을 만들지에 집중하세요.

따라 하기

  1. 클로드 데스크톱 앱에서 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정합니다.
  3. 폴더 선택 후 워크스페이스 신뢰를 진행합니다.
  4. 설문 결과 CSV 같은 자료 파일을 첨부합니다.
  5. 만들고 싶은 결과물과 필요한 기능을 풀어 써서 요청합니다.
  6. 우측 내장 브라우저에서 결과를 확인하고 수정할 점은 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코워크·코드·디자인은 프로 플랜 이상에서 사용할 수 있다고 소개됩니다.

권한 모드로 안전하게 쓰기

Claude Code

Claude Code는 기본적으로 파일 수정이나 명령 실행 전에 허락을 묻습니다. Shift + Tab으로 모드를 바꿔 맡기는 범위를 조절합니다.

따라 하기

  1. Claude Code 실행 중 Shift + Tab을 누릅니다.
  2. 기본(승인) 모드에서는 파일 수정·셸 명령 전에 매번 허락을 묻습니다.
  3. Auto accept edits 모드는 파일 수정은 묻지 않고 명령 실행은 계속 묻습니다.
  4. 입력창 아래에 현재 모드가 표시되는지 확인하고 작업합니다.
  • 모든 단계를 직접 확인하고 싶으면 승인 모드를 유지합니다.
  • 권한을 건너뛰면 실수를 미리 잡기 어려우니 신중히 사용합니다.

계획 모드로 방향 먼저 잡기

Claude Code

계획 모드에서는 Claude가 파일을 수정하지 않고 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전에 방향을 고칠 수 있어 큰 작업에 알맞습니다.

따라 하기

  1. 프로젝트 루트 디렉터리에서 Claude Code를 엽니다.
  2. Shift+Tab을 눌러 입력창 아래에 plan mode가 표시될 때까지 전환합니다.
  3. 구현하려는 내용과 알고 싶은 점을 구체적으로 요청합니다.
  4. Claude가 내놓은 계획을 검토하고 부족하면 추가나 수정을 요청합니다.
  5. 계획이 좋으면 승인하고 파일 수정을 자동 수락할지 매번 물을지 고릅니다.
예시 프롬프트
앱 전체에 다크 모드를 넣고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마에 어울리는 대비 색을 쓰는 계획을 먼저 세워 줘.
  • 코드가 쓰이기 전인 계획 단계가 방향을 고치기 가장 좋은 시점입니다.
  • 프롬프트는 가능한 한 구체적으로 씁니다.

CLAUDE.md로 규칙 정하기

Claude Code

CLAUDE.md는 프로젝트 루트에 두는 마크다운 파일로, 세션을 시작할 때마다 자동으로 읽힙니다. 스택, 명령어, 코드 스타일을 적어 두면 첫 응답부터 품질이 좋아집니다.

따라 하기

  1. 프로젝트 루트 폴더에서 Claude Code를 실행합니다.
  2. /init 명령을 실행해 CLAUDE.md를 생성합니다.
  3. 스택, 명령어, 코드 스타일 규칙을 확인하고 필요한 내용을 고칩니다.
  4. 금지 규칙과 주요 폴더 안내를 추가합니다.
  5. 작업 중 반복해서 바로잡은 규칙은 메모리에 저장하라고 명시적으로 요청합니다.
예시 프롬프트
방금 알려 준 규칙(커밋 메시지는 한국어로 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 매뉴얼이 아니라 지도처럼 씁니다.
  • AI가 자동 생성한 파일은 사람이 검수합니다.
  • CLAUDE.md는 권고이고 어길 수 없는 규칙은 Hooks로 강제합니다.

컨텍스트 확인하고 정리하기

Claude Code

컨텍스트는 Claude의 작업 기억으로, 읽은 파일과 대화가 모두 공간을 차지합니다. 한도에 가까워지면 자동 압축되어 세부가 사라질 수 있어 직접 관리하는 편이 좋습니다.

따라 하기

  1. /context를 실행해 컨텍스트 크기와 많이 차지하는 항목을 확인합니다.
  2. 같은 기능 작업을 계속하면 /compact로 지금까지 내용을 요약합니다.
  3. 새 기능을 시작할 때는 /clear로 대화를 비웁니다.
  4. 다음 세션에도 기억시킬 내용은 CLAUDE.md에 적습니다.
  5. 쓰지 않는 MCP 서버는 끕니다.
  • 압축하면 이전 대화의 세부 내용이 사라질 수 있습니다.
  • 답만 필요한 조사는 별도 컨텍스트 창을 쓰는 서브에이전트에 맡길 수 있습니다.

검증하고 마무리하기

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 마지막에 리뷰와 커밋 메시지까지 맡겨 한 작업을 매듭짓습니다.

따라 하기

  1. 계획에 무엇이 올바른 결과인지 성공 기준을 분명히 적습니다.
  2. 웹 UI라면 Claude in Chrome 확장을 설치해 Claude가 탭에서 직접 테스트하게 합니다.
  3. 직접 확인해 만족하면 서브에이전트 코드 리뷰어로 코드를 점검합니다.
  4. Claude에게 내 스타일에 맞는 커밋 메시지를 만들게 한 뒤 푸시합니다.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청합니다.

스킬로 반복 작업 저장하기

Claude Code

스킬은 작업 방법을 한 번 가르쳐 두면 관련 상황에서 자동 적용되는 SKILL.md 파일입니다. 이름과 설명만 먼저 불러오므로 컨텍스트도 아낍니다.

따라 하기

  1. 잘 쓴 결과물 하나를 준비해 Claude에 업로드합니다.
  2. '이 양식으로 주간 보고서 스킬을 만들어 줘'라고 요청합니다.
  3. 만들어진 스킬을 저장하고 세션을 재시작합니다.
  4. /를 입력해 스킬이 목록에 보이는지 확인합니다.
  5. 스킬 이름을 불러 호출하고 이번 주 자료만 넣습니다.
예시 프롬프트
이 보고서 양식으로 '주간 보고서' 스킬을 만들어 줘. 앞으로 이번 주 자료만 주면 같은 구성과 말투로 초안을 써 주게 해 줘.
  • 프로젝트 스킬은 저장소를 받은 팀원 모두가 자동으로 받습니다.
  • 배포처럼 위험한 작업은 슬래시로 직접 호출하는 방식이 안전합니다.
