음성 메모로 내용 쏟아내기

Claude

빈 슬라이드 앞에서 막막할 때는 하고 싶은 말을 먼저 녹음해 텍스트로 만듭니다. 메모가 엉망이어도 괜찮습니다.

따라 하기

  1. 휴대폰 음성 메모 앱에 발표할 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 상황, 청중, 기준(시간 등)을 말로 덧붙입니다.
예시 프롬프트
지금 상황을 설명할게. 나는 중소기업 영업팀 대리이고, 다음 주 고객사 제안 발표를 준비 중이야. 기준은 10분 안에 끝나고 비전문가도 이해할 수 있어야 해.
  • 맥락을 많이 줄수록 결과가 좋아집니다.
  • 결과는 직접 읽고 판단하세요.

PDF 자료로 근거 요약하기

Adobe Acrobat

보고서와 기사를 PDF 스페이스에 넣고 요약하면 숫자를 눌러 원문 근거를 볼 수 있어 사실 확인이 중요한 발표에 알맞습니다.

따라 하기

  1. 어도비 사이트 로그인 후 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 자료를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적과 청중을 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문 근거를 확인합니다.
  • 근거가 없는 내용은 확인 필요로 표시해 달라고 요청하세요.
  • 유료 구독이 필요합니다.

한 채팅에서 슬라이드 초안

Claude

Claude에서 문서, 디자인, 슬라이드를 한 대화 안에서 같은 자료로 이어서 만듭니다. 방향은 큰 모델로 잡고 빠른 수정은 가벼운 모델로 합니다.

따라 하기

  1. Claude 데스크탑에서 자료를 첨부합니다.
  2. 슬라이드를 만들어 달라고 요청하고 Claude의 질문에 답합니다.
  3. 초안이 나오면 고칠 부분을 드래그한 뒤 댓글을 눌러 지시합니다.
  4. 시장 조사는 차트로 넣어 달라고 지시합니다.
  5. /slides를 입력해 바로 시작할 수도 있습니다.
예시 프롬프트
아래 출시 브리프를 바탕으로 발표용 슬라이드를 만들어 줘. 시장 조사는 차트로 넣어 줘.
[브리프 내용을 여기에 붙여넣기]
  • 방향은 Opus 5.5, 문구·차트·색상 수정은 Sonnet 5.5가 권장됩니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.

디자인 시스템 먼저 정하기

Claude Design

AI가 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 색, 글꼴, 글씨 크기를 먼저 정하면 매번 같은 톤이 나옵니다.

따라 하기

  1. claude.ai/design의 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. 회사의 디자인 규칙을 붙여 넣고 폰트 파일을 업로드합니다.
  3. Continue to generation으로 생성합니다.
  4. 초기 화면에서 디자인 시스템을 선택하고 PPT 주제를 요청합니다.
  5. Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 다운로드합니다.
  6. 받은 PPTX의 폰트와 레이아웃을 확인합니다.
  • '깔끔하게' 같은 표현 대신 색 역할, 글씨 크기, 장당 글자 수를 수치로 적으세요.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • Claude 디자인은 베타이며 Pro 이상이 필요합니다.

PowerPoint 안에서 고치기

Claude in PowerPoint

Claude in PowerPoint는 슬라이드 마스터와 글꼴·색상을 읽어 브랜드에 맞게 슬라이드를 만들고 고칩니다. 선택한 개체만 바꾸므로 나머지는 건드리지 않습니다.

따라 하기

  1. 템플릿을 PowerPoint에서 엽니다.
  2. Claude 애드인을 열고 슬라이드 수, 주제, 어조를 적어 요청합니다.
  3. + 버튼으로 보고서나 데이터 파일을 올립니다.
  4. 수정할 슬라이드나 텍스트 상자를 선택하고 그 부분만 바꿔 달라고 요청합니다.
  5. 글머리표가 많은 슬라이드는 블록형 레이아웃으로 바꿔 달라고 요청합니다.
  6. 생성된 슬라이드가 글꼴·색상·간격과 맞는지 확인합니다.
예시 프롬프트
핀테크 산업을 평가하는 10장짜리 덱을 만들어 줘. 데이터 중심의 애널리스트 어조로 써 줘. 필요하면 질문해 줘.
  • 요청 끝에 '필요하면 질문하라'를 덧붙이면 먼저 되묻고 만듭니다.
  • 결과는 기본 도형과 차트라 직접 편집할 수 있습니다.

팀과 공유하고 내보내기

Claude

완성한 자료를 팀원과 함께 보고 고치거나 파일로 내보내 전달합니다. 접근 수준을 정해 필요한 만큼만 권한을 줍니다.

따라 하기

  1. 우측 상단 공유로 팀원을 초대합니다.
  2. 팀원별로 보기, 댓글, 수정 접근 수준을 고릅니다.
  3. 댓글이 달리면 Claude에게 내용 업데이트를 요청합니다.
  4. 내보내기로 PDF, 파워포인트 등 파일로 저장합니다.
  • 추가한 사람은 기본적으로 댓글 작성자가 됩니다.
  • 외부에 공유할 결과물은 조직의 데이터 정책에 맞는지 확인하세요.

작업 방식을 스킬로 저장

Claude Code

만족스러운 결과가 나온 작업 방식을 스킬로 저장하면 다음에 대본과 디자인 시스템만 넣어도 같은 디자인의 PPT가 나옵니다.

따라 하기

  1. 작업이 끝난 대화에서 지금까지의 작업을 스킬로 만들어 달라고 요청합니다.
  2. 스킬의 설명이 언제 쓰는 스킬인지 분명한지 확인합니다.
  3. Claude Code를 껐다 켜서 스킬을 적용합니다.
  4. 다음 발표 때 /로 스킬 이름을 불러 실행합니다.
예시 프롬프트
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • 스킬은 재시작해야 같은 세션에서 인식됩니다.
