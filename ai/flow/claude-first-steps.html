가입하고 첫 질문하기

Claude 앱

무료로 가입해 작은 일부터 말하듯 질문해 봅니다. 질문을 완벽하게 만들 필요 없이 친구에게 말하듯 던지고, 답을 보며 고쳐 달라고 이어 가는 것이 핵심입니다.

따라 하기

  1. Claude 사이트에 접속해 구글로 계속하기 또는 이메일로 계속하기를 누릅니다.
  2. 질문창의 모델 선택 메뉴에서 기본 작업용으로 Sonnet을 고릅니다.
  3. 마이크를 눌러 말로 질문하고, 상황을 충분히 설명합니다.
  4. 답을 보고 '더 짧게', '표로 바꿔 줘'처럼 이어서 고쳐 달라고 요청합니다.
예시 프롬프트
나에 대해 아는 것을 한 문단으로 설명해 봐. 그리고 나에 대해 궁금한 것을 100개까지 물어봐 줘.
  • 처음에는 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시작하세요.
  • 답이 의심되면 근거 자료를 요구하거나 다른 AI로 교차 검증하세요.

Claude 앱

업무에 쓰기 전에 대화와 메모리가 어디에 쓰이는지 이해하고 설정으로 직접 통제합니다. 기밀 자료를 다룬다면 요금제와 데이터 처리 조건도 함께 확인합니다.

따라 하기

  1. 설정에서 데이터 컨트롤 부근의 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. Improve the model for everyone 항목을 찾아 끕니다.
  3. 저장된 메모리를 수정·삭제하고, 필요 없으면 메모리를 끕니다.
  4. 필요 없는 실명은 빼고 자리표시자로 바꿔 입력합니다.
  5. 기밀·규제 데이터는 비즈니스·엔터프라이즈 플랜과 사내 규정을 먼저 확인합니다.
  • 영상에서도 메뉴 위치가 정확하지 않다고 했으니 설정 안에서 데이터 컨트롤 부근을 찾아보세요.
  • 사내 AI 사용 규정이 있다면 그것이 우선입니다.

Claude 앱

맥락을 충분히 주기

Claude 앱

완벽한 프롬프트보다 내 상황과 좋은 결과의 기준을 알려 주는 것이 결과를 좌우합니다. 타이핑 대신 음성으로 길게 말하면 시간도 줄고 생각도 정리됩니다.

따라 하기

  1. 음성 받아쓰기로 상황, 목적, 기준을 길게 말합니다.
  2. 관련 파일이나 화면 캡처를 많이 붙입니다.
  3. AI가 낸 결과를 직접 읽고 맞는지 판단합니다.
  4. 부족한 부분은 기준을 더 알려 주어 다시 요청합니다.
예시 프롬프트
지금 상황을 설명할게. 나는 중소기업 영업팀 대리이고, 다음 주 고객사 제안 발표를 준비 중이야. 첨부한 자료를 보고 발표 흐름을 제안해 줘. 기준은 10분 안에 끝나고 비전문가도 이해할 수 있어야 해.
  • 중요한 것은 맥락을 많이 주는 것과 결과를 판단하는 능력입니다.

웹 검색 켜고 조사 맡기기

Claude 앱

최신 정보가 필요하면 웹 검색을, 깊은 조사가 필요하면 연구(딥 리서치) 모드를 켭니다. 출처 링크가 달리므로 시장 조사나 경쟁사 비교에 유용합니다.

따라 하기

  1. 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  4. 비교 기준과 출력 형식을 적어 요청하고 출처 링크를 확인합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 서비스 5개를 가격, 장단점, 도입 사례 기준으로 비교해 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 모델은 훈련 시점 이후의 사실을 검색 없이는 확실히 알지 못합니다.

답변 검증하는 습관 들이기

Claude 앱

AI는 틀린 내용도 확신 있게 말하고 사용자에게 맞춰 동의하기도 합니다. 질문의 중요도에 따라 출처 요청, 재질문, 교차 검증으로 확인 강도를 조절합니다.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 스스로 묻고 확인 강도를 정합니다.
  2. '모르면 모른다고 말해 달라'고 먼저 허용합니다.
  3. 주장마다 출처를 요청하고, 제시된 출처를 직접 열어 확인합니다.
  4. 새 대화를 열어 오류를 찾아 달라고 하거나 다른 AI로 교차 검증합니다.
  5. 숫자·날짜·인용·최신 정보는 믿을 만한 자료로 다시 확인합니다.
예시 프롬프트
이 결정에 대한 가장 강력한 찬성과 반대 논거는 무엇인가요? 모르는 부분은 모른다고 말해도 괜찮고, 각 주장마다 출처를 함께 알려 주세요.
  • 깔끔한 문단이나 자신 있는 말투는 정확성의 증거가 아닙니다.
  • AI가 없는 출처를 그럴듯하게 만들어 낼 수도 있습니다.

프로젝트로 작업 나누기

Claude 앱

프로젝트는 작업별로 맥락을 모아 두는 공간입니다. 지침과 관련 문서를 한 번 넣어 두면 같은 설명을 반복하지 않아도 됩니다.

따라 하기

  1. 화면 왼쪽 프로젝트 옆 +로 새 프로젝트를 만듭니다.
  2. 강의, 보고서, 리서치처럼 용도별로 프로젝트를 나눕니다.
  3. 커스텀 지침에 대상, 톤 등 원하는 응답 방식을 적고 지침 저장을 누릅니다.
  4. 관련 문서를 파일로 업로드합니다.
  5. 프로젝트 안에서 대화를 시작하고, 새 채팅에서는 이전 내용을 가져오라고 요청합니다.
예시 프롬프트
이 프로젝트는 신입 사원 교육 자료를 만드는 작업이야. 대상은 입사 1년 차 직장인이고, 톤은 친절하고 쉬운 존댓말로 해 줘. 업로드한 문서를 근거로 답하고, 근거가 없으면 모른다고 말해 줘.
  • 채팅창이 바뀌면 기억 일부가 사라지니 꼭 기억할 내용은 기록해 두라고 요청하세요.

커넥터 연결하고 메모리 정리

Claude 앱

구글 드라이브, Gmail, 캘린더, 노션을 커넥터로 연결하면 파일을 일일이 올리지 않고 채팅에서 바로 자료를 찾습니다. 메모리에는 내 선호를 쌓되 민감한 정보는 남기지 않습니다.

따라 하기

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가, 커넥터 둘러보기를 차례로 누릅니다.
  3. 연결할 서비스를 검색해 옆의 +를 누르고 로그인해 권한을 승인합니다.
  4. 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청해 봅니다.
  5. 메모리에 저장된 내용을 확인하고 틀린 것은 수정하거나 지웁니다.
예시 프롬프트
구글 드라이브에서 '11월 견적서' 파일을 찾아 내용을 요약하고, 거래처에 보낼 안내 이메일 초안을 써 줘.
  • 메뉴 이름과 위치는 앱 버전에 따라 다를 수 있습니다.
  • 프로젝트는 맥락을, 스킬은 작업 방식을, 커넥터는 외부 도구를 맡는다고 구분하면 쉽습니다.
