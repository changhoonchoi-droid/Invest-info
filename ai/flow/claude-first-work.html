따라 하기

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 필요하면 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다.
  4. 질문창의 모델 선택에서 기본 작업용으로 Sonnet을 고릅니다.
  5. 마이크를 눌러 말로 질문하거나 타이핑으로 질문합니다.
  • 타이핑 대신 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.
  • 질문을 완벽하게 만들려 하지 말고 던진 뒤 답을 보고 고쳐 달라고 하세요.

학습·메모리 설정 확인하기

Claude

회사 업무에 쓰기 전에 대화가 모델 학습에 쓰이는지, 메모리에 무엇이 저장되는지 확인합니다. 몇 번의 클릭으로 끌 수 있습니다.

따라 하기

  1. 설정(Settings)에서 데이터 컨트롤 또는 개인정보 관련 메뉴로 들어갑니다.
  2. 모델 개선·학습에 대화를 쓰는 토글을 찾아 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 설정을 함께 확인합니다.
  4. 저장된 메모리를 수정·삭제하거나 필요 없으면 끕니다.
  5. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 확인합니다.
  • 메뉴 위치와 이름은 화면에서 직접 확인하세요.
  • 불필요한 실명은 빼고 자리표시자로 바꿔 입력합니다.
  • 회사의 AI 사용 규정이 있으면 그것을 우선합니다.

AI에게 나를 알려 주기

Claude 데스크톱 앱

AI는 내가 누구이고 무슨 일을 하는지 알수록 답이 좋아집니다. 하루 30분씩 서로 질문을 주고받는 습관이 맥락을 쌓아 줍니다.

따라 하기

  1. Claude 데스크톱 앱을 설치하고 폴더 접근을 허락합니다.
  2. 컴퓨터를 보고 나에 대해 파악해 달라고 요청합니다.
  3. '너는 뭘 할 수 있니?'라고 물어 기능을 확인합니다.
  4. '나에 대해서 궁금한 거 100개까지 물어봐 봐'라고 요청해 인터뷰를 받습니다.
  5. '이제 나를 알았으니 나를 도와줄 수 있는 게 뭐야?'라고 묻습니다.
예시 프롬프트
컴퓨터 보고 나에 대해 파악해 줘. 파일은 읽기만 하고 절대 고치지 마.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.

업무별 프로젝트 만들기

Claude

프로젝트는 작업별로 맥락을 모아 두는 공간입니다. 지침과 문서를 한 번 넣어 두면 그 안의 대화마다 같은 설명을 반복하지 않아도 됩니다.

따라 하기

  1. 화면 왼쪽 프로젝트 옆 +를 눌러 프로젝트를 만듭니다.
  2. 용도별로 나눕니다(예: 보고서, 교육 자료, 리서치).
  3. 커스텀 지침에 대상 독자와 톤을 적습니다.
  4. 지침 저장을 누릅니다.
  5. 관련 문서를 파일로 업로드하고 프로젝트 안에서 대화를 시작합니다.
예시 프롬프트
이 프로젝트는 신입 사원 교육 자료를 만드는 작업이야. 대상은 입사 1년 차 직장인이고, 톤은 친절하고 쉬운 존댓말로 해 줘. 업로드한 문서를 근거로 답하고, 근거가 없으면 모른다고 말해 줘.
  • 프로젝트는 맥락, 스킬은 작업 방식, 커넥터는 외부 도구를 맡습니다.
  • 채팅창이 바뀌면 기억 일부가 사라지니 새 채팅에서 이전 내용을 가져오라고 요청하세요.

드라이브·메일 연결하기

Claude

커넥터를 연결하면 파일을 내려받아 올리지 않아도 Claude가 구글 드라이브, Notion, Gmail의 내 자료를 직접 읽고 씁니다.

따라 하기

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가, 커넥터 둘러보기를 차례로 누릅니다.
  3. 연결할 서비스를 검색합니다.
  4. 서비스 옆 +를 누르고 내 계정으로 로그인해 인증합니다.
  5. 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청합니다.
예시 프롬프트
구글 드라이브에서 지난주 회의록 파일을 찾아서, 참석자에게 보낼 요약 이메일 초안을 써 줘.
  • Gmail 같은 이메일 커넥터가 켜져 있어야 메일 관련 작업이 됩니다.

웹 검색 켜고 조사 시키기

Claude

모델은 검색 도구 없이는 훈련 이후의 사실을 확실히 알지 못합니다. 웹 검색을 켜면 최신 정보를 출처와 함께 받고, 깊은 조사에는 딥 리서치를 씁니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 출처 링크가 달린 답을 받습니다.
  4. 깊은 조사는 + 버튼에서 연구를 눌러 딥 리서치를 켭니다.
예시 프롬프트
국내 사무용 협업 도구 시장의 주요 경쟁사 세 곳을 비교하고, 출처 링크와 함께 표로 정리해 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.

답변 검증하는 습관 들이기

Claude

AI는 그럴듯하지만 틀린 내용을 만들 수 있습니다. 틀렸을 때 생길 일을 기준으로 확인 강도를 정하세요.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 스스로 묻고 확인 강도를 정합니다.
  2. '모르면 모른다고 말해 달라'고 미리 허용합니다.
  3. 주장마다 근거 출처를 요청하고 링크를 직접 열어 확인합니다.
  4. 의심스러우면 얼마나 확신하는지 묻습니다.
  5. 새 대화나 다른 AI로 교차 검증합니다.
예시 프롬프트
아래 답변에서 숫자·날짜·인용마다 근거 출처를 알려 줘. 확실하지 않은 부분은 모른다고 말해도 괜찮아. 틀릴 가능성이 높은 부분도 짚어 줘.
  • 숫자·날짜·인용, 최신 사건은 특히 다시 확인하세요.
  • 깔끔한 문단이나 자신 있는 말투가 정확성의 증거는 아닙니다.
