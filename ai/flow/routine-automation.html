자동화할 업무 고르기

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

처음에는 순서와 결과물이 정해진 업무 하나만 고릅니다. 완료 기준이 분명할수록 자동화가 쉽습니다.

따라 하기

  1. 매주 반복하는 업무를 적어 봅니다.
  2. 그중 입력과 결과물이 분명한 하나를 고릅니다.
  3. 결과물의 좋은 예(지난 보고서 등)를 찾아 둡니다.
  4. 잘못되면 곤란한 업무는 처음에 제외합니다.
예시 프롬프트
내가 매주 반복하는 업무 목록이야. 이 중 자동화하기 쉬운 순서대로 순위를 매기고 이유를 알려 줘: …
  • 발송·결제처럼 되돌리기 어려운 업무는 나중으로 미루세요.

양식을 스킬로 저장하기

Claude

스킬은 반복 업무의 양식과 작업 방식을 저장해 두는 기능입니다. 매번 같은 설명 없이 같은 포맷의 결과가 나옵니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. "이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘"라고 요청합니다.
  3. 결과에서 스킬 저장을 누릅니다.
  4. /와 스킬 이름으로 호출해 주제를 넣어 봅니다.
예시 프롬프트
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 브랜드 컬러·폰트·섹션 구성까지 설명해 저장하면 포맷이 일정합니다.

코워크에 폴더 업무 맡기기

Cowork

코워크는 폴더를 열어 주면 계획을 세워 파일을 읽고 엑셀·워드 결과물을 만듭니다. 데스크톱 앱에서 Pro 이상 요금제로 쓸 수 있습니다.

따라 하기

  1. Claude 데스크톱에서 Cowork(협업) 탭을 엽니다.
  2. 작업할 폴더를 고르고 접근 권한을 허용합니다.
  3. 자료를 폴더에 넣고 원하는 결과를 구체적으로 요청합니다.
  4. Claude가 제안한 계획을 확인하고 승인합니다.
  5. 폴더에 저장된 결과 파일을 열어 확인합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘.
  • 엑셀은 원본은 그대로 두고 정리본은 새 파일로 저장이라고 적으세요.
  • 내 역할·말투는 설정의 지침에 적어 두면 매번 말하지 않아도 됩니다.

메일·드라이브 커넥터 연결

Claude

커넥터를 연결하면 Claude가 내 메일과 파일을 읽고 쓸 수 있습니다. 연결은 처음 한 번만 하면 됩니다.

따라 하기

  1. 대화창 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail, 구글 캘린더, 구글 드라이브 등을 검색합니다.
  3. 서비스 옆 +를 누르고 내 계정으로 인증합니다.
  4. 채팅에서 드라이브 파일을 찾아 메일 초안을 써 달라고 시험합니다.
예시 프롬프트
구글 드라이브에서 계약서 파일을 찾아 핵심 조건을 요약하고, 상대방에게 보낼 확인 메일 초안을 써 줘.
  • 여러 구글 계정을 쓴다면 연결된 계정을 미리 확인하세요.

예약 작업으로 매일 돌리기

Cowork

결과가 마음에 들면 같은 내용을 예약 작업으로 등록합니다. 7월 업데이트 이후 예약 작업은 기기가 꺼져 있어도 클라우드에서 실행됩니다.

따라 하기

  1. 먼저 한 번 직접 요청해 결과를 확인합니다.
  2. 같은 내용을 매일 정해진 시각에 실행하는 예약 작업으로 등록해 달라고 합니다.
  3. Claude가 만든 프롬프트 초안과 주기를 확인하고 승인합니다.
  4. 좌측 예약됨에서 스케줄을 확인합니다.
예시 프롬프트
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고 우선순위 브리핑을 만들어 줘. 같은 내용을 매일 아침 7시 50분에 실행하는 예약 작업으로 등록해 줘.
  • 메일은 자동 발송보다 초안으로 남기게 하는 편이 안전합니다.

완료 기준과 확인 지점 정하기

Claude

자동으로 돌릴수록 무엇이 완료인지, 어디서 사람이 확인할지 미리 정해야 합니다. 되돌리기 어려운 지점은 사람 확인을 거치게 합니다.

따라 하기

  1. 업무의 완료 기준을 누가 봐도 참·거짓을 가릴 수 있게 적습니다.
  2. 발송, 큰 비용 지출 같은 지점은 사람 확인을 거치게 정합니다.
  3. 피드백을 줄 때마다 스킬이나 규칙으로 남깁니다.
  4. 처음 몇 번은 결과를 직접 확인합니다.
  • 가장 소모적인 절차 하나가 지금도 필요한지 점검하는 것부터 시작해도 좋습니다.

플러그인으로 직무에 맞추기

Cowork

플러그인은 스킬·커넥터·슬래시 명령을 묶은 직무별 패키지입니다. 미팅 전 브리핑이나 후속 정리처럼 매번 반복되는 일에 효과가 큽니다.

따라 하기

  1. 설정의 협업 탭에서 내 역할과 작업 스타일을 지침에 적어 저장합니다.
  2. 코워크에서 + → 플러그인을 선택합니다.
  3. 플러그인 추가에서 직무에 맞는 것을 설치합니다.
  4. 플러그인 관리에서 제공되는 명령어를 확인해 실행합니다.
  • 명령어 이름은 플러그인 관리 화면에서 확인하세요.
  • 발송이 필요한 결과는 승인 단계를 거쳐 보내세요.
