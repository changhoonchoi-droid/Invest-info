코워크로 폴더 업무 맡기기

Claude 코워크

코워크는 폴더 접근을 허용하면 계획을 세워 파일을 읽고 엑셀·문서 결과물을 만듭니다. 예약 작업의 바탕이 되므로 먼저 손으로 한 번 돌려 봅니다. 데스크톱 앱과 유료 플랜이 필요합니다.

따라 하기

  1. Claude 데스크톱 앱을 열고 Cowork(또는 협업) 탭을 누릅니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 골라 접근을 허용합니다.
  3. 정리할 자료(회의록, 엑셀, 메모 등)를 그 폴더에 넣습니다.
  4. 원하는 결과물과 규칙을 한 번에 적어 요청하고, 변경 전에 계획을 보여 달라고 합니다.
  5. 제안된 계획을 확인하고 필요하면 수정을 지시한 뒤 승인합니다.
  6. 완성된 파일을 열어 내용을 검토합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘. 원본 파일은 그대로 두고 결과는 새 파일로 저장해 줘.
  • 처음에는 범위가 분명한 작업부터 시작하고 결과를 항상 검토합니다.
  • 원본 보존은 프롬프트에 반드시 적어 둡니다.
  • 웹 버전은 로컬 파일 접근이 안 되므로 파일 작업은 데스크톱 앱에서 합니다.

글로벌 지침 정해 두기

Claude 설정

매번 같은 말을 반복하지 않도록 역할, 보고서 톤, 날짜 형식을 지침으로 저장합니다. 자동 실행 때도 같은 기준이 적용되어 결과가 일정해집니다.

따라 하기

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 누릅니다.
  4. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  5. 저장을 누릅니다.
예시 프롬프트
나는 마케팅팀 과장이다. 보고서는 존댓말로 간결하게 쓰고, 날짜는 2026-11-16 형식으로 적는다. 파일을 삭제하거나 덮어쓰기 전에는 반드시 먼저 물어본다.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하세요.
  • 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.

커넥터로 메일·드라이브 연결

Claude 커넥터

커넥터를 연결하면 파일을 일일이 올리지 않고도 내 업무 자료를 바탕으로 일을 시킬 수 있습니다. 예약 작업에서도 같은 커넥터를 씁니다.

따라 하기

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가를 누른 뒤 커넥터 둘러보기를 선택합니다.
  3. Gmail, 구글 캘린더, 구글 드라이브, 노션 등 연결할 서비스를 검색합니다.
  4. 서비스 옆 +를 눌러 계정으로 로그인하고 인증합니다.
  5. 채팅창 + → 커넥터에서 연결한 서비스가 켜져 있는지 확인합니다.
예시 프롬프트
구글 드라이브에서 '11월 견적서' 파일을 찾아서, 내용을 바탕으로 거래처에 보낼 안내 메일 초안을 써 줘.
  • 연결은 처음 한 번만 하면 되고, 채팅마다 켜고 끌 수 있습니다.
  • 이메일 커넥터가 켜져 있어야 메일 브리핑 예시가 동작합니다.

보고서 양식을 스킬로 저장

Claude 스킬

스킬은 반복 업무의 양식과 작업 규칙을 저장합니다. 한 번 만들면 매번 긴 지시 없이 같은 형식과 품질의 보고서를 받습니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 그 형식을 분석해 보고서용 스킬을 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 다음부터 /와 스킬 이름을 입력해 스킬을 고르고 주제를 적어 요청합니다.
  5. 결과가 어긋나면 어떤 점이 달랐는지 말해 스킬을 고치게 합니다.
예시 프롬프트
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
  • Claude Code에서는 스킬을 못 알아보면 껐다 다시 실행합니다.

아침 브리핑 직접 만들어 보기

Claude 커넥터

예약하기 전에 같은 요청을 직접 실행해 결과가 쓸 만한지 확인합니다. 이 단계에서 프롬프트를 다듬어 두면 자동 실행 후 시행착오가 줄어듭니다.

따라 하기

  1. Gmail 또는 Microsoft 365 커넥터가 연결되어 있는지 + → 커넥터에서 파란 불을 확인합니다.
  2. 어제 오후 6시 이후 메일과 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  3. 답장이 필요한 순서, 형식 등 마음에 안 드는 부분을 말해 고칩니다.
  4. 결과가 만족스러우면 그 프롬프트를 그대로 예약에 씁니다.
예시 프롬프트
어제 오후 6시 이후에 온 메일과 오늘 캘린더 일정을 보고, 답장이 필요한 순서대로 브리핑을 만들어 줘.
  • 자동으로 발송하지 말고 초안으로 남기게 하면 안전합니다.

예약 작업으로 자동 실행

Cowork 예약 작업

반복할 일을 자연어로 설명하면 정해진 주기에 Claude가 실행합니다. 예약 작업은 유료 플랜에서 쓸 수 있고, 최근 영상 기준으로는 클라우드에서 돌아 컴퓨터를 꺼도 실행됩니다.

따라 하기

  1. 반복할 일과 시각을 자연어로 설명합니다.
  2. Claude가 만든 예약 작업 프롬프트 초안과 주기를 검토합니다.
  3. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  4. 내용이 맞으면 제안을 수락하고 승인 버튼을 눌러 확정합니다.
  5. 왼쪽 예약됨(예약 페이지)에 작업이 추가된 것을 확인합니다.
  6. 설정 후 한 번 직접 실행해 제대로 되는지 확인합니다.
예시 프롬프트
어제 오후 6시 이후에 온 메일과 오늘 캘린더 일정으로 답장이 필요한 순서대로 브리핑을 만들어 줘. 이 작업을 매일 아침 7시 50분에 실행하도록 예약해 줘.
  • 실행마다 새 세션으로 돌아 최신 파일과 도구 상태를 기준으로 합니다.
  • 예전 방식: 컴퓨터가 켜져 있고 앱이 열려 있어야 실행되었지만 7월 업데이트 이후 클라우드 실행이 가능해졌습니다.
  • 승인이 필요한 부분은 모바일에도 요청이 옵니다.

미팅 전후 업무까지 확장

Claude 스킬

캘린더·Slack·이메일에 흩어진 정보를 스킬 하나로 모아 회의 준비 문서를 만들고, 미팅 뒤에는 녹취록으로 후속 메시지까지 만듭니다. 업무에 익숙해진 뒤 더하세요.

따라 하기

  1. 캘린더, Slack, 이메일 등 필요한 도구를 Claude에 연결합니다.
  2. 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 미팅 전에 알고 싶은 내용을 설명해 스킬 파일 초안을 만듭니다.
  4. 미팅 전 /를 입력해 스킬을 고르고 회의 상대와 시간을 알려 브리핑을 받습니다.
  5. 미팅 후 녹취록 처리 스킬로 할 일과 후속 메시지를 만들게 합니다.
  6. 각 결과를 확인하고 승인한 뒤 발송합니다.
예시 프롬프트
오늘 오후 1시 거래처 미팅 준비를 도와줘. 캘린더와 최근 메일, 지난 회의록을 보고 상대 회사 현황과 오늘 확인할 질문 3개를 정리해 줘.
  • 발송 전에 항상 승인 단계를 거쳐 내용을 확인하세요.
  • 이름을 걸고 보내는 답장이므로 브리핑의 근거를 원문에서 직접 확인합니다.

한 주 돌려 보며 고치기

Claude 코워크

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

자동화는 만들고 끝이 아니라 처음 몇 번은 결과를 확인하며 다듬어야 합니다. 맞지 않는 부분은 지시문이나 스킬에 반영해 같은 실수를 막습니다.

따라 하기

  1. 예약 페이지에서 지난 실행 기록과 결과 파일을 확인합니다.
  2. 빠진 항목이나 어긋난 형식은 예약 작업의 지시문이나 스킬에 추가합니다.
  3. 결과가 안정되기 전까지는 발송 대신 초안으로 남기게 합니다.
  4. 신뢰가 쌓이면 맡기는 범위를 조금씩 넓힙니다.
예시 프롬프트
지난 한 주 실행 결과를 보고, 빠졌거나 어긋난 부분이 있으면 예약 작업의 지시문을 고쳐 줘.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 더 맡기세요.
  • 중요한 문서는 AI 티가 나는 문장을 직접 읽고 고칩니다.
