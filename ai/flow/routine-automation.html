Cowork 설치하고 폴더 열기

Cowork

Cowork는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서를 만드는 기능입니다. 유료 플랜의 데스크톱 앱에서 씁니다. 처음에는 중요하지 않은 폴더로 연습하세요.

따라 하기

  1. Claude 데스크톱 앱을 설치합니다.
  2. 앱에서 협업(영문 Cowork) 탭을 엽니다.
  3. 프로젝트 또는 폴더에서 작업할 폴더를 고르고 접근 권한 창에서 항상 허용을 누릅니다.
  4. 작업을 말로 설명하고 Claude가 제안하는 계획을 확인해 승인합니다.
  5. 완성된 파일을 폴더에서 열어 내용을 검토합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘.
  • 엑셀을 정리할 때는 "원본은 그대로 두고 정리본은 새 파일로 저장해 줘"라고 반드시 적습니다.
  • 로컬 파일 접근은 데스크톱 앱에서만 됩니다.

전역 지침으로 반복 설명 줄이기

Claude 데스크톱 앱

역할, 보고서 톤, 날짜 형식 같은 규칙을 한 번 적어 두면 모든 코워크 작업에 적용됩니다.

따라 하기

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 누릅니다.
  4. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  5. 저장을 누릅니다.
예시 프롬프트
나는 마케팅 팀 과장이다. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적는다. 파일을 삭제하기 전에는 반드시 나에게 확인한다.
  • 지침 탭의 정확한 이름은 화면에서 확인하세요.
  • 특정 폴더에만 규칙을 주려면 CLAUDE.md 파일에 폴더 지침을 추가하세요.

Gmail·캘린더 커넥터 연결하기

커넥터

커넥터를 연결하면 Claude가 내 메일과 일정을 읽고 정리할 수 있습니다. 연결된 자료는 내 권한 범위 안에서만 가져옵니다.

따라 하기

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가 → 커넥터 둘러보기를 선택합니다.
  3. Gmail, 구글 캘린더, 노션 등 연결할 서비스를 검색합니다.
  4. 서비스 옆 + 버튼을 누르고 내 계정으로 로그인해 인증합니다.
  5. + → 커넥터에서 연결 표시(파란 불)가 켜졌는지 확인합니다.
  • 여러 구글 계정을 쓴다면 연결된 계정이 어느 것인지 미리 확인하세요.

메일 브리핑 한 번 받아 보기

Claude

자동화하기 전에 수동으로 한 번 돌려 결과가 쓸 만한지 확인합니다. 답장은 바로 보내지 않고 초안으로 받습니다.

따라 하기

  1. 어제 오후 6시 이후 메일과 오늘 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  2. 결과의 출처를 눌러 실제 메일과 일정을 확인합니다.
  3. 빠진 것이나 과한 것을 말해 지시문을 다듬습니다.
예시 프롬프트
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 확인해서, 답장이 필요한 메일을 우선순위 순으로 정리한 아침 브리핑을 만들어 줘.
  • 답장은 초안으로 받아 직접 확인한 뒤 보내세요.

보고서 양식을 스킬로 저장하기

스킬

스킬은 보고서 양식, 문체, 업무 절차를 저장해 두는 기능입니다. 한 번 만들면 /로 불러 매번 같은 품질과 포맷의 결과를 받습니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 그 형식을 분석해 스킬로 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 저장합니다.
  4. /와 스킬 이름을 입력해 선택하고 이번 주 자료만 넣어 써 봅니다.
  5. 결과가 마음에 안 들면 피드백을 스킬에 반영해 달라고 요청합니다.
예시 프롬프트
이 보고서 양식으로 '주간 보고서' 스킬을 만들어 줘. 앞으로 이번 주 자료만 주면 같은 구성과 말투로 초안을 써 주게 해 줘.
  • 처음에는 테스트용 자료로 돌려 보고 다듬은 뒤 실제 업무에 쓰세요.
  • 중요한 문서는 직접 읽고 고칩니다.

예약 작업으로 자동 실행하기

예약 작업

예약 작업은 정해 둔 시간마다 Claude가 같은 업무를 실행하는 기능입니다. 아침 브리핑, 주간 지표 리뷰처럼 매번 하는 일에 알맞습니다.

따라 하기

  1. 반복할 일을 시각과 함께 자연어로 설명하거나 /schedule을 입력합니다.
  2. Claude가 만든 예약 작업 프롬프트 초안을 읽고 필요하면 고칩니다.
  3. 주기를 매시간·매일·평일·수동 중에서 확인하거나 바꿉니다.
  4. 내용이 맞으면 제안을 수락해 등록합니다.
  5. 왼쪽 예약됨(또는 예정된) 페이지에서 등록된 스케줄과 지난 실행 기록을 확인합니다.
  6. 처음 몇 번은 결과를 직접 확인하고 지시문을 다듬습니다.
예시 프롬프트
평일 아침 7시 50분마다 실행해 줘. 어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고, 답장이 필요한 메일과 오늘의 핵심 일정을 정리한 브리핑을 만들어 줘.
  • 영상마다 설명이 다릅니다. 최근 영상은 클라우드에서 돌아 컴퓨터가 꺼져 있어도 실행된다고 하지만, 예전 방식은 데스크톱 앱이 열려 있어야 했습니다. 내 환경에서 한 번 확인하세요.
  • 메일 발송 같은 외부 행동은 '초안으로 남겨 줘'라고 지시하면 안전합니다.

직무별 플러그인 더하기

Cowork

플러그인은 스킬, 커넥터, 슬래시 명령을 묶은 직무별 패키지입니다. 자동화가 익숙해지면 내 직무에 맞는 것을 설치해 업무 범위를 넓힙니다.

따라 하기

  1. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  2. 플러그인 추가에서 내 직무에 맞는 플러그인을 설치합니다.
  3. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  4. 결과를 검토하고 회사 방식에 맞게 수정합니다.
  • 명령어 이름은 플러그인 관리 화면에서 정확한 표기를 확인하세요.
