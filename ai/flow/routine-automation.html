자동화할 업무 고르기

Claude 앱

모든 일을 같은 방식으로 자동화하면 비용이 낭비되거나 결과가 불안정해집니다. 매번 같은 단계를 거치는 반복 업무가 예약 작업에 가장 잘 맞습니다.

따라 하기

  1. 매일·매주 하는 업무를 적어 봅니다.
  2. 각 업무가 매번 같은 단계를 거치는지 판단합니다.
  3. 단계가 정해진 반복 업무(회의 준비, 정기 보고, 폴더 변경 요약 등) 하나를 고릅니다.
  4. 실제로 필요한 결과물(문서 형식, 저장 위치)을 정확히 적어 둡니다.
예시 프롬프트
제가 매주 반복하는 업무는 다음과 같습니다: [업무 목록]. 이 중 매번 같은 단계를 거쳐서 예약 작업으로 맡기기 좋은 일과, 사람이 판단해야 해서 맡기기 어려운 일을 나눠 주세요.
  • 단계를 미리 알 수 없는 일은 예약 작업보다 그때그때 맡기는 편이 낫습니다.
  • 처음에는 작고 결과를 확인하기 쉬운 업무부터 시작하세요.

커넥터와 폴더 연결하기

Cowork

흩어진 정보를 모으려면 Claude가 그 도구들을 볼 수 있어야 합니다. 미리 연결해 둔 커넥터는 나중에 예약 작업에서도 그대로 쓰입니다.

따라 하기

  1. Claude 데스크톱 앱을 엽니다.
  2. 업무에 필요한 커넥터(캘린더, Slack, 이메일 등)를 연결합니다.
  3. 이전 회의록이나 보고서 양식이 든 폴더를 Claude가 볼 수 있게 지정합니다.
  4. 연결된 도구 목록을 확인합니다.
  • 예전 방식: 채팅과 Cowork를 따로 골랐지만, 9월 업데이트로 하나의 Claude로 합쳐졌고 기존 Cowork 작업도 그대로 남아 있습니다.
  • 회사 정보를 연결하기 전에 회사 보안 규정을 확인하세요.

한 번 직접 맡겨 보기

Cowork

예약 작업으로 돌리기 전에 같은 일을 대화로 한 번 끝까지 맡겨 봅니다. 기존 문서 형식을 템플릿으로 따르라고 하면 결과가 평소 양식과 맞습니다.

따라 하기

  1. 어떤 일인지, 언제까지인지 알려 주며 요청합니다.
  2. 확인할 출처(캘린더, Slack 스레드, 이메일, 이전 회의록)를 함께 적습니다.
  3. 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  4. Claude가 세운 계획을 확인한 뒤 진행되게 둡니다.
  5. 빠진 출처가 있으면 작업 중에 바로 추가로 요청합니다.
예시 프롬프트
내일 오전 10시 [고객사명] 정례 회의를 준비해 줘. 캘린더에서 참석자를 확인하고, 관련 Slack 스레드와 이메일, 회의록 폴더의 지난 회의록을 검토해서 안건 문서를 만들어 줘. 형식은 지난 회의록 형식을 그대로 따라 줘.
  • 중간에 지시를 더해도 처음부터 다시 하지 않고 방향만 바꿔 이어서 작업합니다. 처음부터 완벽하게 쓰려고 하지 않아도 됩니다.

결과 문서 검토하기

Cowork

완성된 문서의 최종 책임은 사용자에게 있습니다. 자동화하기 전에 결과가 원하는 수준인지 확인해야 예약 작업도 같은 품질로 돕니다.

따라 하기

  1. 작업 폴더에 저장된 문서를 엽니다.
  2. 빠진 정보, 틀린 이름·날짜·숫자가 없는지 확인합니다.
  3. 빠진 내용은 Claude에 추가를 요청하거나 직접 고칩니다.
  4. 결과가 마음에 들 때까지 같은 대화에서 이어서 고칩니다.
  • 공유하기 전에 꼭 직접 검토하세요.

예약 작업으로 등록하기

Cowork

한 번 해 보고 마음에 든 작업을 예약 작업으로 바꿉니다. Claude가 써 준 프롬프트 초안과 실행 주기를 확인하고 승인하면 등록됩니다.

따라 하기

  1. 방금 한 작업을 예약 작업으로 만들어 달라고 요청합니다.
  2. Claude가 쓴 예약 작업 프롬프트 초안을 읽고 필요한 부분을 고칩니다.
  3. 실행 주기를 매시간·매일·평일·수동 중에서 확인하고 필요하면 바꿉니다.
  4. 내용이 맞으면 제안을 수락해 등록합니다.
  5. 왼쪽 사이드바의 예약(scheduled) 페이지에 작업이 추가됐는지 확인합니다.
예시 프롬프트
방금 만든 회의 준비 문서 작업을 평일 오후 4시마다 다음 날 회의를 기준으로 자동 실행하는 예약 작업으로 만들어 줘.
  • 예약 작업은 실행할 때마다 새 세션으로 돌아가 그 시점의 최신 파일과 도구 상태를 기준으로 합니다.
  • 영상 기준으로는 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행되며, 놓친 작업은 다시 켰을 때 실행됩니다. 지금 쓰는 앱에서 실행 조건을 확인하세요.

즉시 실행으로 시험하기

Cowork

정해진 시간을 기다리지 말고 바로 한 번 돌려 보면 문제를 일찍 찾을 수 있습니다.

따라 하기

  1. 예약(scheduled) 페이지를 엽니다.
  2. 등록한 작업에서 즉시 실행을 누릅니다.
  3. 결과 문서가 대화로 했을 때와 같은 수준인지 확인합니다.
  4. 다르면 지시문을 고쳐 다시 실행합니다.
  • 예약 작업은 대화 맥락 없이 새 세션에서 돌기 때문에, 대화 중에 말로 덧붙였던 조건이 지시문에 들어 있는지 확인하세요.

실행 기록 보며 다듬기

Cowork

자동화는 등록으로 끝나지 않습니다. 처음 며칠 동안 실행 기록과 결과를 살펴보고 지시문과 주기를 조정해야 믿고 맡길 수 있습니다.

따라 하기

  1. 예약 페이지에서 지난 실행 기록을 확인합니다.
  2. 결과 문서를 열어 빠진 내용이나 잘못된 부분을 찾습니다.
  3. 지시문이나 실행 주기를 수정합니다.
  4. 결과가 안정되면 확인 주기를 늘립니다.
  • 처음 며칠은 결과를 매일 확인해 기준을 조정하세요.
  • 폭주하거나 불필요하게 도는 작업이 없는지 가끔 점검하세요.
