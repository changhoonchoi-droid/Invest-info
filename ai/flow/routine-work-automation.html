자동화할 업무 하나 고르기

Claude 앱

무엇을 맡길지 정하지 않고 도구부터 켜면 효과가 작습니다. 팀에서 가장 부담이 큰 절차 하나를 골라, 아직 필요한지와 Claude가 줄일 수 있는 부분이 있는지 먼저 따져 봅니다.

따라 하기

  1. 팀에서 가장 번잡하거나 부담이 큰 업무 절차나 회의 하나를 고릅니다.
  2. 그 절차가 지금도 원래 목적에 맞게 돌아가는지 팀원과 따져 봅니다.
  3. 매번 순서가 같은 반복 업무인지, 상황마다 단계가 달라지는 업무인지 나눕니다.
  4. Claude에 맡길 부분과 사람이 검증·리뷰할 부분을 정합니다.
  5. 한 번에 한 단계씩만 바꿔 나갑니다.
  • 절차는 문제를 풀려고 만들지만, 시간이 지나면 점검 없이 방치되기 쉽습니다.
  • 말로 길게 논쟁하는 대신 결과물을 먼저 만들어 보여 주는 방식도 써 봅니다.

캘린더·Slack·메일 연결하기

Cowork

커넥터를 연결하면 Claude가 여러 도구의 정보를 모아 결과물을 만듭니다. 한 번 연결해 둔 커넥터는 나중에 예약 작업에서도 그대로 쓸 수 있습니다.

따라 하기

  1. Claude 데스크톱 앱을 열고 Cowork 작업을 시작합니다.
  2. 업무에 필요한 캘린더, Slack, 이메일 커넥터를 연결합니다.
  3. 회의록이나 보고서가 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  4. 설정의 연결된 앱 목록에서 연결 상태를 확인합니다.
  • 9월 업데이트로 채팅과 Cowork가 하나의 Claude로 합쳐졌습니다. 기존 Cowork 작업은 그대로 유지됩니다.
  • 연결한 도구의 정보에 Claude가 접근하게 되므로 회사 보안 규정을 먼저 확인합니다.

회의 준비를 한 번 맡겨 보기

Cowork

자동화하기 전에 같은 일을 한 번 직접 시켜 결과를 확인합니다. 작업 중에 출처를 더하거나 방향을 바꿔도 처음부터 다시 하지 않고 이어서 진행합니다.

따라 하기

  1. 준비할 회의와 시간을 알려 줍니다.
  2. 캘린더 검색, 참석자 조사, Slack 스레드 확인, 이전 회의록 검토, 안건 작성을 요청합니다.
  3. 형식은 기존 문서를 템플릿으로 따르라고 지시합니다.
  4. Claude가 세운 계획을 확인하고 작업이 진행되게 둡니다.
  5. 빠뜨린 출처가 있으면 작업 중에 추가로 요청합니다(예: 이메일도 확인).
  6. 작업 폴더에 저장된 안건 문서를 열어 검토하고, 빠진 내용은 추가를 요청하거나 직접 고칩니다.
예시 프롬프트
오늘 오후 1시 Acme Corp와의 통화를 준비해 줘. 캘린더에서 일정과 참석자를 찾고, 관련 Slack 스레드와 지난 회의록을 확인해서, 회의록 폴더에 있는 기존 안건 문서 형식대로 안건을 만들어 줘.
  • 완성된 문서의 최종 책임과 수정은 사용자 몫입니다. 사실관계는 꼭 직접 확인합니다.
  • 생각나는 수정은 작업 중에 바로 말해도 됩니다.

예약 작업으로 등록하기

Cowork 예약 작업

한 번 해 보고 결과가 마음에 들면 같은 일을 정해진 주기로 자동 실행하게 만듭니다. Claude가 예약 작업 프롬프트 초안을 써 주므로 사용자는 내용과 주기를 확인하고 승인하면 됩니다.

따라 하기

  1. 마음에 든 작업의 대화 끝에서 이 작업을 정기 예약 작업으로 만들어 달라고 요청합니다.
  2. Claude가 만든 예약 작업 프롬프트 초안을 읽고 필요한 부분을 고칩니다.
  3. 주기를 매시간·매일·평일·수동 중에서 확인하고 필요하면 바꿉니다.
  4. 내용이 맞으면 제안을 수락해 등록합니다.
예시 프롬프트
방금 한 회의 준비 작업을 평일 오전 8시 30분마다 자동으로 실행하는 예약 작업으로 만들어 줘. 그날 외부 회의가 없으면 '오늘 외부 회의 없음'이라고만 남겨 줘.
  • 실행할 때마다 새 Cowork 세션으로 돌아서 그 시점의 최신 파일과 도구 상태를 기준으로 합니다.
  • 미리 설정해 둔 커넥터는 예약 작업에서도 그대로 쓸 수 있습니다.

첫 실행 결과 확인하기

Cowork 예약 작업

등록만 하고 두지 말고, 바로 한 번 실행해 결과가 제대로 나오는지 봅니다. 처음 며칠은 결과를 매일 확인하면서 지시문을 다듬습니다.

따라 하기

  1. 왼쪽 사이드바의 예약(scheduled) 페이지에 작업이 추가됐는지 확인합니다.
  2. 작업을 즉시 실행해 결과를 확인합니다.
  3. 지난 실행 기록을 보고 빠지거나 틀린 부분을 찾습니다.
  4. 필요하면 예약 페이지에서 지시문과 주기를 고칩니다.
  5. 정해진 시간에 컴퓨터를 켜 두고 데스크톱 앱을 열어 둡니다.
  • 6~7월 영상 기준으로 예약 작업은 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있을 때만 실행됩니다. 놓친 작업은 다시 켜면 바로 실행되고 늦어졌다고 알려 줍니다. 지금 동작은 앱 안내에서 확인하세요.

로그인 필요한 웹 업무 맡기기

어사이드(Aside)

메일 확인이나 사내 사이트 조회처럼 로그인해서 클릭하고 입력해야 하는 웹 업무는 AI 브라우저 어사이드에 말로 맡길 수 있습니다. Claude를 이미 유료로 쓰고 있다면 연결만 하면 되고 어사이드 비용은 따로 들지 않습니다.

따라 하기

  1. Claude 데스크톱 앱을 설치하고 로그인합니다.
  2. 어사이드 브라우저를 설치하고, 지금 결제 중인 Claude(또는 GPT)를 연결합니다.
  3. 어사이드 하단에서 사용할 모델을 고릅니다.
  4. 로그인이 필요한 사이트에서도 일을 시키려면 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져옵니다.
  5. 메일 확인처럼 간단한 일을 말로 시키고, 어사이드 창에서 AI가 실제로 클릭하고 입력하는지 지켜봅니다.
예시 프롬프트
받은 메일함에서 오늘 온 메일을 확인해서 답장이 필요한 것만 골라 요약해 줘.
  • 로그인 정보를 넘기면 AI가 그 계정으로 작업할 수 있으니, 처음에는 조회처럼 위험이 적은 일부터 맡깁니다.
  • Codex와 연결할 때 켜는 전체 액세스는 모든 권한을 여는 설정입니다. 회사 PC라면 사내 보안 규정을 먼저 확인하세요.

사람이 확인할 지점 정하기

Claude 앱

맡기는 일이 많아지면 하나하나 승인하는 내가 병목이 됩니다. 되돌리기 쉬운 일은 넉넉히 맡기고, 대외 발송처럼 되돌리기 어려운 지점에만 확인을 둡니다.

따라 하기

  1. 자동화한 업무 가운데 되돌리기 쉬운 일과 어려운 일을 나눕니다.
  2. 문서 초안 만들기처럼 되돌리기 쉬운 일은 맡겨 둡니다.
  3. 메일 발송, 데이터 수정처럼 되돌리기 어려운 일은 실행 전에 내 확인을 받도록 지시문에 적습니다.
  4. 같은 지적을 반복하게 되면 그 내용을 지시문이나 스킬에 규칙으로 남깁니다.
  • 사람이 모든 단계를 붙잡지 않고 확인 지점만 지키는 방식을 'Human on the loop'라고 부릅니다.
  • 처음에는 결과를 직접 확인하고, 믿을 만해지면 권한을 더 맡기세요.
