요금제와 시작 채널 정하기

Claude Tag

Claude Tag는 Team과 Enterprise 요금제에서 Slack 베타로 제공됩니다. 처음에는 채널 하나에서 시작하고, 프로젝트 상태를 추적하려면 공개 채널이 좋습니다.

따라 하기

  1. 회사 계정이 Team 또는 Enterprise 요금제인지 확인합니다.
  2. Claude Tag를 처음 써 볼 Slack 채널 하나를 고릅니다.
  3. 그 채널에서 Claude에게 맡길 일(정리, 초안 작성, 문의 응대 등)을 정합니다.
  • 처음에는 채널 하나에서만 시작해 보세요.
  • Microsoft Teams 등으로 확대할 계획이 있습니다.

채널에 Claude 추가·도구 연결

Claude Tag

채널에 Claude를 추가하고 작업에 필요한 도구를 연결합니다. Claude는 별도 계정으로 일하며 채널별로 접근 범위가 나뉩니다.

따라 하기

  1. 고른 Slack 채널에 Claude를 추가합니다.
  2. Google Drive, Asana처럼 작업에 필요한 도구를 Claude Tag에 연결합니다.
  3. 다른 공개 채널의 정보가 필요하면 그 채널에 접근 권한을 줍니다.
  • DM과 비공개 채널은 비공개로 유지되고, 다른 공개 채널은 접근 권한을 준 경우에만 참고합니다.
  • 사용자를 대신해 응답하거나 개별 도구에 접근할 때는 매번 권한을 묻습니다.

채널 규칙 기억시키기

Claude Tag

Claude Tag는 채널마다 지침을 기억합니다. 스타일 가이드나 확인 절차를 처음에 알려 두면 매번 같은 설명을 반복하지 않아도 됩니다.

따라 하기

  1. 반복할 지침을 Remember for this channel: ... 형태로 말해 저장시킵니다.
  2. 스타일 가이드나 체크리스트 문서를 알려 주고 작업할 때 참고하라고 합니다.
  3. 무엇을 지켜볼지, 어떻게 처리할지 같은 선호를 말로 알려 줍니다.
  4. Claude를 태그해 지금 기억하는 내용을 읽어 보고 필요하면 고칩니다.
예시 프롬프트
Remember for this channel: 고객 문의 답변 초안은 항상 공유 드라이브의 스타일 가이드를 따르고, 보내기 전에 나에게 먼저 확인받아 줘.
  • 채널의 누구든 기억 내용을 읽고 고칠 수 있으니 팀 규칙처럼 관리하세요.
  • 참고 문서가 바뀌면 기본적으로 최신 내용을 따릅니다.

개입 빈도·자율 범위 정하기

Claude Tag

채널 성격에 따라 Claude가 대화에 끼어드는 빈도와 스스로 처리할 수 있는 범위를 정합니다. 관리자는 채널마다 접근 범위와 자율성을 조절할 수 있습니다.

따라 하기

  1. 채널마다 Claude가 맡을 일과 스스로 처리할 수 있는 범위를 정합니다.
  2. 매번 태그하기 번거로우면 항상 응답하라고 지시합니다.
  3. 너무 자주 또는 너무 드물게 끼어들면 개입 빈도를 조정해 달라고 말합니다.
  4. 외부로 나가는 응답처럼 중요한 일은 사람 확인을 거치게 합니다.
  • Claude가 스스로 작업을 검증할 수 있게 해 두면 중간 확인 요청이 줄어듭니다.

태그해서 목표 맡기기

Claude Tag

채널이나 스레드에서 Claude를 태그하면 대화 기록, 공유 문서, 연결된 도구를 참고해 일합니다. 할 일을 하나하나 주기보다 달성할 목표를 맡깁니다.

따라 하기

  1. 채널이나 스레드에서 Claude를 태그합니다.
  2. 참고할 범위(기간, 문서, 도구)와 원하는 결과물을 구체적으로 적습니다.
  3. Claude가 단계별로 진행하는 상황을 채널에서 확인합니다.
  4. 같은 스레드에서 다른 팀원도 이어서 지시할 수 있게 합니다.
예시 프롬프트
@Claude 최근 3일 동안의 스레드, Google Drive 회의록, Asana의 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 담당자별로 만들어 줘.
  • 공개된 채널에서 요청하면 잘 쓰는 사람의 요청 방식이 동료에게 자연스럽게 퍼집니다.

알림 받고 결과 확인하기

Claude Tag

Claude는 일이 끝나거나 사람의 입력이 필요할 때 알려 줍니다. 기다리지 말고 다른 일을 하다가 알림이 오면 결과를 확인하고 답합니다.

따라 하기

  1. 작업을 맡긴 뒤 다른 일을 합니다.
  2. 완료 알림이나 결정 요청 알림이 오면 내용을 확인합니다.
  3. 결과물에서 사실과 다른 부분이 없는지 검토합니다.
  4. 필요하면 같은 스레드에서 추가 요청을 합니다.
  • 며칠씩 걸리는 일도 후속 확인까지 이어서 합니다.

변경 내역과 기억 점검하기

Claude Tag

Claude는 모든 변경과 요청자를 기록합니다. 정기적으로 변경 내역과 채널 기억을 점검해 팀 규칙이 제대로 지켜지는지 확인합니다.

따라 하기

  1. 작업이 끝나면 기록된 변경 내역과 요청자를 확인합니다.
  2. Claude를 태그해 지금 기억하는 채널 규칙을 읽어 봅니다.
  3. 오래되거나 틀린 규칙은 고칩니다.
  4. 잘 굴러가면 다른 채널로 범위를 넓힙니다.
예시 프롬프트
@Claude 이 채널에서 지금 기억하고 있는 규칙을 모두 보여 줘.
  • Claude Code 팀원 한 명은 작업의 70~80%를 Tag에서 처리하고 나머지만 직접 다듬는다고 합니다.
