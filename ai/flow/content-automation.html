  • 사용량이 빨리 닳으면 모델을 한 단계 가벼운 것으로 바꿉니다.

규칙 파일과 편집 도구 설치

Claude Code

스타터 팩 폴더에는 규칙을 적은 CLAUDE.md와 설치 안내가 들어 있습니다. 구조를 먼저 파악하게 한 뒤 설치를 시킵니다. 이 단계는 개발 도구 설치가 필요합니다.

따라 하기

  1. 스타터 팩 폴더를 압축 해제하고 클로드에서 그 폴더를 선택합니다.
  2. 너는 어떻게 만들어져 있어?라고 물어 폴더 구조와 CLAUDE.md 규칙을 파악합니다.
  3. install.md에 따라 설치를 시키고 하이퍼프레임즈·리모션 설치도 이어서 요청합니다.
  4. 새 세션을 열어 설치된 스킬이 보이게 합니다.
  • CLAUDE.md는 Claude가 명령을 받으면 가장 먼저 읽는 규칙 파일입니다.

레퍼런스와 원본 편집시키기

Claude Code

레퍼런스 폴더에 완성 편집본, 원본 폴더에 촬영 영상을 넣고 같은 스타일로 편집시킵니다. 레퍼런스와 촬영 방식이 비슷해야 결과가 잘 맞습니다.

따라 하기

  1. 레퍼런스 폴더에 완성 편집본, 원본 폴더에 촬영 영상을 넣습니다.
  2. 레퍼런스를 참고해 원본을 똑같이 편집하되 애매하면 물어보라고 시킵니다.
  3. 결과를 확인하고 고칠 점을 이어서 요청합니다.
예시 프롬프트
레퍼런스 폴더의 편집본을 참고해서 원본 폴더의 촬영 영상을 똑같은 스타일로 편집해 줘. 애매한 부분은 먼저 물어봐.
  • 시간이 걸리므로 자기 전에 걸어 두면 편합니다.
  • 캡컷 레이어 템플릿을 많이 모아 둘수록 디테일 정확도가 올라갑니다.

편집 매뉴얼을 스킬로 저장

스킬

영상 종류별 템플릿과 편집 업무 매뉴얼(SOP)을 스킬로 저장하면 같은 품질로 반복할 수 있습니다. 라이브 한 편에서 롱폼과 쇼츠를 뽑는 파이프라인도 같은 원리입니다.

따라 하기

  1. 성공한 편집 방식을 정리해 스킬로 만들어 달라고 요청합니다.
  2. 영상 종류별(롱폼, 쇼츠 등) 템플릿을 스킬로 나눠 저장합니다.
  3. 새 세션에서 /로 스킬이 보이는지 확인합니다.
  4. 결과를 보고 개선점을 스킬에 반영합니다.
예시 프롬프트
방금 편집한 방식을 롱폼 영상용 편집 매뉴얼 스킬로 만들어 줘. 자막 스타일, 컷 길이, 인트로 규칙을 포함해 줘.
  • 남의 영상을 가공할 때는 번역·자막만 달지 말고 내 해석을 더하세요.

구글 드라이브와 예약으로 자동 편집

구글 드라이브 커넥터

드라이브 폴더에 새 영상이 올라오면 정해 둔 스타일로 편집하게 만듭니다. 같은 형식의 영상을 반복해서 만드는 사람에게 맞습니다.

따라 하기

  1. 설정에서 구글 드라이브 커넥터를 연결합니다.
  2. 레퍼런스 편집본과 촬영 원본을 폴더에 넣고 규칙을 CLAUDE.md에 적어 둡니다.
  3. 왼쪽 상단의 예약됨을 엽니다.
  4. 영상을 올리는 드라이브 폴더를 지정하고 한 시간마다 확인하도록 설정합니다.
  5. 새 영상이 올라오면 자동으로 편집하도록 지시합니다.
  • 연결된 계정이 어느 것인지 미리 확인하세요.

사람은 위에서 확인하도록 설계

Claude Code

자동화가 병목이 되지 않으려면 사람이 중간 버튼을 누르는 대신 위에서 보고받고 필요할 때만 개입하도록 설계합니다. 목표, 트리거, 하지 말아야 할 일, 비용 상한을 정합니다.

따라 하기

  1. 자동화가 이룰 목표를 한 문장으로 정합니다.
  2. 언제 시작할지 트리거를 정합니다.
  3. 하지 말아야 할 일을 규칙으로 적고 크레딧 같은 비용은 상한을 정합니다.
  4. 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 합니다.
  5. 피드백을 줄 때마다 스킬이나 규칙으로 남깁니다.
  • 상한 숫자는 영상 제작자 본인의 값이므로 내 요금제에 맞게 정하세요.
  • 만드는 AI와 검사하는 AI를 분리하면 자기 결과에 관대해지는 문제를 줄입니다.
