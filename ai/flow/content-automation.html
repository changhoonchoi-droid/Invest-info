파이프라인 단계 쪼개기

Claude

자동화는 한 번에 만들지 않고 단계로 쪼개야 합니다. 어디에 사람 확인을 둘지, 어디서 비용 상한을 둘지를 먼저 정합니다.

따라 하기

  1. 수집할 대상(유튜브·X·레딧·인스타 등 계정)을 정합니다.
  2. 선별 기준(조회수·댓글 수 등)을 숫자로 정합니다.
  3. 제작 결과물(카드뉴스, 쇼츠, 롱폼)을 정합니다.
  4. 되돌리기 어려운 지점과 크레딧이 크게 나가는 곳에 상한과 확인 단계를 정합니다.
  5. Claude에게 이 흐름을 단계별 설계서로 정리해 달라고 요청합니다.
예시 프롬프트
매일 아침 레퍼런스 계정에서 조회수가 기준을 넘은 게시물만 골라 카드뉴스 기획으로 만들려고 해. 수집·선별·제작·정리 4단계로 설계서를 만들고, 사람이 확인할 지점을 표시해 줘.
  • 업로드는 자동화하지 않는 선택도 있습니다. 영상 제작자는 인기 음악이 앱에서만 넣을 수 있어 수동으로 뒀습니다.
  • 크레딧 상한 숫자는 영상 제작자의 값이니 내 요금제에 맞게 정합니다.

규칙과 환경 세팅

Claude Code

반복 실행되는 작업은 규칙이 흔들리면 결과가 들쭉날쭉합니다. 규칙 파일과 모델 선택을 먼저 정리합니다.

따라 하기

  1. /init으로 CLAUDE.md를 만들고 콘텐츠 톤·금지 규칙을 적습니다.
  2. 반복 작업은 Sonnet 같은 가벼운 모델로, 열린 조사는 상위 모델로 나눕니다.
  3. 결과가 부족하면 모델을 바꾸기 전에 effort를 먼저 올립니다.
  4. 서브에이전트는 저렴한 모델부터 적용합니다.
  • 토큰 단가가 아니라 작업당 비용으로 비교합니다.

제작 방식을 스킬로 저장

스킬

한 편씩 만들지 않고 시리즈별 스킬로 저장하면 같은 품질이 반복됩니다. 피드백을 줄 때마다 스킬에 남깁니다.

따라 하기

  1. 잘 나온 결과물 한 편을 기준으로 삼습니다.
  2. 작업 방법을 스킬로 만들어 달라고 요청합니다.
  3. 슬래시(/)로 스킬 이름을 불러 새 자료만 넣어 실행합니다.
  4. 빠진 항목이 있으면 스킬에 계속 더합니다.
예시 프롬프트
첨부한 카드뉴스를 기준으로 '카드뉴스 스킬'을 만들어 줘. 앞으로 레퍼런스 링크만 주면 같은 구성으로 기획안을 써 줘.
  • 남의 영상을 쓸 때는 단순 번역 대신 내 의견을 묻는 인터뷰 단계를 넣어 차별점을 만듭니다.
  • 만든 AI와 검사하는 AI를 분리하면 자기 결과에 관대해지는 문제를 줄입니다.

외부 서비스와 연결하기

Claude Code

외부 서비스의 CLI나 MCP를 연결하면 자연어로 그 서비스 작업을 시킬 수 있습니다. MCP는 도구 정의가 컨텍스트를 차지하므로 안 쓰는 것은 끕니다.

따라 하기

  1. 서비스 설정의 개발자 메뉴에서 CLI 설치 명령을 복사합니다.
  2. Claude Code에 붙여 넣고 설치해 달라고 요청합니다.
  3. MCP는 claude mcp add로 추가하고 /mcp로 연결을 확인합니다.
  4. 쓰지 않을 서버는 /mcp에서 비활성화합니다.
  5. 자주 쓰는 MCP 작업은 스킬로 바꿔 토큰을 아낍니다.
  • 작업이 길어지면 토큰을 꽤 소모합니다.
  • 기획·이미지·스토리라인을 미리 정해 주면 품질이 올라갑니다.

영상 편집 매뉴얼 만들기

Claude Code

영상 편집은 템플릿과 업무 매뉴얼을 만들어 두면 Claude Code가 편집을 맡을 수 있습니다. 라이브 한 편을 롱폼·쇼츠로 나누는 사례가 있습니다.

따라 하기

  1. 편집 템플릿과 작업 순서를 매뉴얼로 정리합니다.
  2. 매뉴얼을 스킬로 저장합니다.
  3. 영상 파일을 지정한 폴더에 올립니다.
  4. Claude Code에 편집을 요청하고 결과를 확인합니다.
  • 구체적인 도구·메뉴는 영상 화면에서 확인해야 합니다.

검증 루프와 상한 두기

Claude Code

무인 자동화는 틀려도 아무도 모르기 쉽습니다. 완료 조건을 참·거짓으로 판정할 수 있게 쓰고, 종료 조건과 사람 확인을 겹쳐 둡니다.

따라 하기

  1. 작업의 완료 조건을 참·거짓으로 판정할 수 있게 적습니다.
  2. 종료 조건(최대 반복 횟수, 시간·비용 한도, 진전 없음 중단)을 겁니다.
  3. 수동 확인 절차는 verify 스킬처럼 스킬로 만듭니다.
  4. 진행 상황을 적는 상태 파일을 둡니다.
  5. 핵심 결과는 사람이 직접 확인한 뒤 공개합니다.
  • 실수가 나오면 다시 시키지 말고 CLAUDE.md나 스킬에 적어 같은 실수를 막으세요.

루틴·예약으로 돌리기

Claude Code

루틴은 프롬프트, 저장소, 커넥터, 트리거를 정해 두면 노트북이 꺼져 있어도 원격 세션이 자동 실행됩니다. 영상 사례에서는 1~2시간마다 드라이브 폴더를 확인하게 했습니다.

따라 하기

  1. 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나)을 정합니다.
  2. 터미널에서 /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문(시각, 알림 여부)에 답합니다.
  4. 필요한 저장소를 컨텍스트로 연결합니다.
  5. 만들어진 루틴을 웹에서 확인하고 실행 결과 세션을 열어 봅니다.
예시 프롬프트
/schedule 매일 아침 7시에 지정한 계정의 새 게시물을 모아 조회수 기준을 넘은 것만 정리해 줘.
  • 처음에는 결과를 직접 확인하고, 신뢰가 쌓이면 더 많은 권한을 맡깁니다.
  • 매일 피드백을 모아 중요도별로 분류하고 확신이 높은 것만 고치게 하는 방식도 있습니다.

노션에 정리하고 개선하기

Notion

결과는 기획·자료·원본 링크와 함께 노션에 올려 모아 둡니다. 피드백이 쌓이면 스킬이나 규칙으로 반영해 갈수록 품질을 높입니다.

따라 하기

  1. Notion 커넥터를 연결합니다.
  2. 결과를 저장하고 기획·자료·원본 링크와 함께 올리게 합니다.
  3. 결과를 검토하며 피드백을 줄 때마다 스킬이나 규칙으로 남깁니다.
  4. 정기적으로 스킬을 갱신합니다.
  • 원본 링크를 남겨 두면 출처 확인이 쉽습니다.
