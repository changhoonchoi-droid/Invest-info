가입하고 첫 대화 해 보기

Claude

Claude는 웹에서 바로 쓸 수 있고 무료로도 충분히 시작할 수 있습니다. 완벽한 질문보다 답을 보고 고쳐 달라고 주고받는 연습이 먼저입니다.

따라 하기

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기로 가입합니다.
  3. 질문창 모델 선택에서 기본 작업용으로 Sonnet을 고릅니다.
  4. 궁금한 것을 친구에게 말하듯 입력해 보냅니다.
  5. 답이 마음에 안 들면 고쳐 달라고 이어서 요청합니다.
예시 프롬프트
내 업무는 마케팅팀 보고서 작성이야. 내가 Claude에게 어떤 일을 맡기면 좋을지 5가지만 알려줘.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.
  • 타이핑이 번거로우면 마이크로 말로 질문해도 됩니다.

개인정보 설정 점검하기

Claude

회사 일에 쓰기 전에 대화가 모델 학습에 쓰이는지, 메모리에 무엇이 저장되는지 확인합니다. 정책은 제공사마다 다르므로 쓰는 도구의 설정을 직접 봐야 합니다.

따라 하기

  1. 계정 설정에서 메모리, 대화 기록, 연결된 앱, 학습 항목을 확인합니다.
  2. 데이터 컨트롤 부근에서 모델 개선(학습) 사용 항목을 끕니다.
  3. 저장된 메모리를 수정하거나 지웁니다.
  4. 필요 없는 실명은 자리표시자로 바꿔 입력합니다.
  5. 기밀 데이터는 비즈니스·엔터프라이즈 플랜과 데이터 처리 조건을 확인합니다.
  • 학습 끄기 메뉴 이름은 제품마다 다르니 설정 안에서 데이터 컨트롤 부근을 찾아보세요.

AI에게 나를 알려 주기

Claude

AI의 답은 내가 준 맥락만큼 좋아집니다. 하루 30분 정도 서로 질문을 주고받으면 내 업무에 맞는 답이 나옵니다.

따라 하기

  1. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 현재 상태를 확인합니다.
  2. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청합니다.
  3. 하나씩 답하며 내 업무와 상황을 알려 줍니다.
  4. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 봐. 하나씩 물어보고, 내가 답하면 다음 질문으로 넘어가 줘.
  • 폴더를 보여 줄 때는 읽기만 하고 고치지 말라고 지시하세요.

웹 검색·딥리서치 켜기

Claude

웹 검색을 켜면 출처 링크와 함께 답을 받을 수 있습니다. 시장 조사처럼 깊은 조사는 딥 리서치를 씁니다.

따라 하기

  1. 입력창의 + 버튼을 누릅니다.
  2. 웹 탭으로 웹 검색을 켭니다.
  3. 깊은 조사는 + 버튼에서 연구로 딥 리서치를 켭니다.
  4. 조사 주제와 범위를 적어 요청합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 비교해 줘. 가격, 강점, 약점을 표로 정리하고 출처를 붙여 줘.
  • 최신 영상에서는 /딥리서치 명령도 소개합니다.

답변 검증하는 습관 들이기

Claude

AI는 그럴듯하지만 사실이 아닌 내용을 만들 수 있습니다. 중요도에 따라 확인 강도를 정하고 출처를 직접 열어 봅니다.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 보고 확인 강도를 정합니다.
  2. "모르면 모른다고 말해도 돼"라고 미리 허용합니다.
  3. 주장마다 출처를 요청하고 직접 열어 확인합니다.
  4. 숫자·날짜·인용은 원문과 다시 비교합니다.
  5. 새 대화나 다른 AI로 교차 검증합니다.
예시 프롬프트
이 결정에 대한 가장 강력한 찬성 논거와 반대 논거를 각각 알려 줘. 모르는 부분은 모른다고 말해도 괜찮아.
  • AI가 없는 출처를 만들어 낼 수도 있습니다.

Claude

따라 하기

  1. 먼저 무료로 쓰며 불편을 확인합니다.

  3. 질문창 모델 선택에서 일상 작업은 Sonnet을 씁니다.
  4. 품질이 중요한 작업만 Opus 등으로 바꿉니다.
  5. 한 달 정도 써 보고 계속할지 정합니다.
  • 요금과 한도는 바뀔 수 있으니 공식 요금 페이지에서 확인하세요.
