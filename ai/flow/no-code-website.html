만들 사이트 정리하기

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

AI 빌더는 처음 설명이 결과를 좌우합니다. 사이트 종류, 대상, 분위기, 넣을 섹션을 Claude와 먼저 정리해 입력 문장을 만듭니다.

따라 하기

  1. 사업 내용과 방문자 대상을 적습니다.
  2. 필요한 섹션(소개·서비스·가격·문의 등)을 Claude와 정합니다.
  3. 분위기와 참고할 사이트를 정합니다.
  4. 빌더에 넣을 한 문단짜리 요청문으로 정리해 달라고 합니다.
예시 프롬프트
동네 필라테스 스튜디오 홈페이지를 만들려고 해. 대상은 30대 직장인 여성이고 소개·수업 안내·가격·예약 문의 섹션이 필요해. AI 빌더에 그대로 넣을 수 있게 한 문단으로 정리해 줘.
  • 복제하고 싶은 사이트 링크나 참고 이미지가 있으면 함께 준비합니다.

로고·이미지 준비하기

Gemini

사이트에 쓸 로고와 사진은 Gemini 나노바나나로 만들 수 있습니다. 로고는 엠블럼만 이미지로 받아 글자는 디자인 도구에서 얹으면 한글이 깨지지 않습니다.

따라 하기

  1. 제품 사진이나 참고 이미지를 준비합니다.
  2. Gemini에서 이미지를 올리고 바꿀 부분과 '다른 부분은 바꾸지 말고' 조건을 적습니다.
  3. 로고는 엠블럼만 이미지로 받습니다.
  4. 미리캔버스에서 글자를 배치하고 JPG 고해상도로 다운로드합니다.
예시 프롬프트
수정할 사진은 그대로 두고 오른쪽 배경의 사람만 없애 줘. 다른 부분은 바꾸지 말고 빈 곳은 자연스럽게 채워 줘.
  • 화면 캡처 대신 다운로드해야 화질이 깨지지 않습니다.
  • 구글 이미지 검색 결과는 허가받지 않은 이미지라 무단 사용하면 문제가 될 수 있습니다.

AI 빌더로 첫 화면 생성

Readdy AI

Readdy AI나 Hostinger AI 빌더는 몇 분 만에 여러 페이지짜리 사이트를 만들어 줍니다. 요금제와 결제 기간은 미리 확인하세요.

따라 하기

  1. Readdy AI에 접속해 로그인하고 계정 메뉴의 언어에서 한국어로 바꿉니다.
  2. 입력창에 사이트 종류, 대상, 분위기, 섹션을 적고 전송합니다.
  3. 복제하고 싶은 사이트 링크를 붙여 넣어도 됩니다.
  4. 생성된 PC·모바일 화면을 확인합니다.
예시 프롬프트
동네 필라테스 스튜디오 홈페이지를 만들어 줘. 대상은 30대 직장인 여성, 분위기는 밝고 차분하게, 소개·수업 안내·가격·예약 문의 섹션을 넣어 줘.
  • 요청 한 번마다 크레딧이 차감됩니다(Readdy는 25크레딧).
  • 스크린샷을 구글 AI 스튜디오에 붙여 '비슷한 느낌의 랜딩 페이지 만들어 줘'라고 해도 됩니다.

말로 부분 수정하기

Readdy AI

고칠 요소를 직접 골라 말로 요청하면 해당 부분만 바뀝니다. 한 번에 하나씩 요청해야 어긋남이 적습니다.

따라 하기

  1. 편집 선택을 눌러 고칠 요소를 클릭합니다.
  2. 일상 언어로 변경을 요청합니다.
  3. 전체 분위기 변경은 채팅에 요청합니다.
  4. 말로 설명하기 어려우면 캡처 이미지를 첨부합니다.
  5. Hostinger에서는 확인/거절로 생성 요청을 확정합니다.
  • 수정 요청은 한 번에 하나씩 입력합니다.
  • 숫자·후기 같은 생성 문구는 실제 사실에 맞게 고쳐야 합니다.

Claude Artifacts

견적 계산기나 퀴즈처럼 작동하는 작은 앱이 필요하면 Artifacts로 말만 해서 만들고 링크로 공유할 수 있습니다. 홈페이지에 링크로 연결하는 방식은 자료에 없어 보충 단계입니다.

따라 하기

  1. 새 아티팩트를 누르고 처음부터 시작하기를 선택합니다.
  2. 만들 앱을 설명합니다.
  3. 우측 패널에서 직접 사용해 봅니다.
  4. 고칠 부분은 채팅으로 요청하고 게시해 링크를 받습니다.
  5. 받은 링크를 홈페이지의 버튼이나 안내 문구에 걸어 둡니다.
예시 프롬프트
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 인포그래픽에도 쓸 수 있습니다.
