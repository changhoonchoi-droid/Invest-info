기획은 Claude가, 이미지·영상 생성은 연결한 서비스의 크레딧이 맡습니다. 먼저 콘셉트·대상·분위기를 정하면 비용을 아낍니다.

따라 하기

  1. 제품과 타깃, 쓰일 곳(상세페이지·인스타·쇼츠)을 적습니다.
  2. 분위기 참고 이미지나 링크를 모읍니다.
  3. Claude에게 콘셉트와 장면 구성안을 요청합니다.
  4. 구도는 이미지로 먼저 확정합니다.
  • 영상 생성은 이미지보다 크레딧이 많이 듭니다.

생성 도구를 커넥터로 연결

Claude 앱

Artlist나 힉스필드를 커넥터로 붙이면 채팅 한 곳에서 이미지까지 만듭니다. 공식 MCP만 쓰는 것이 안전합니다.

따라 하기

  1. + → 커넥터 → 커넥터 둘러보기에서 Higgsfield를 검색해 연결합니다.
  2. 목록에 없으면 설정 → 커넥터 → 커스텀 커넥터 추가에 서비스의 MCP URL을 붙입니다(Artlist 방식).
  3. + → 커넥터에서 파란색(사용 중)인지 확인합니다.
  4. 크레딧 잔액을 확인해 달라고 요청해 연결을 확인합니다.
예시 프롬프트

  • 공식 MCP만 쓰고 비공식은 피합니다.
  • ChatGPT에 연결하는 방법도 있습니다.

제품 이미지 만들고 고치기

Claude + Artlist

제품 사진 한 장으로 대표 이미지, 배너, SNS용 이미지, 모바일 상세 시안을 만듭니다. 바꿀 것과 유지할 것을 나눠 적어야 로고·형태가 유지됩니다.

따라 하기

  1. 제품 사진을 올리고 비율·해상도를 적어 요청합니다.
  2. 바꿀 것과 유지할 것을 나누어 구체적으로 적습니다.
  3. 로고·형태·한글 문구가 유지됐는지 확인합니다.
  4. 마음에 안 들면 같은 요청을 다시 보냅니다.
  5. 다운로드로 저장합니다.
예시 프롬프트
다른 부분은 바꾸지 말고 배경을 깔끔한 스튜디오로 바꿔 줘. 빛과 조명도 자연스럽게
  • 화면 캡처 대신 다운로드해야 화질이 깨지지 않습니다.
  • 빠른 수정에는 Haiku 5.5가 유리합니다.

Artlist

이미지를 먼저 만들고 영상으로 넘기면 인물과 분위기가 안정적입니다. 같은 프롬프트도 결과가 달라 여러 번 생성해 고릅니다.

따라 하기

  1. AI 비디오의 이미지 비디오로 들어갑니다.
  2. 사진을 올리거나 만든 이미지를 고릅니다.
  3. 자동 생성된 프롬프트를 확인하고 고칩니다.
  4. 모델·길이·비율·해상도를 고르고 애니메이트를 누릅니다.
예시 프롬프트

  • 해상도와 길이가 늘수록 크레딧이 크게 늘어납니다.
  • 본 생성 전에 짧고 낮은 화질로 시험합니다.

같은 인물·제품으로 이어 만들기

Higgsfield

캐릭터 시트와 레퍼런스를 쓰면 장면이 바뀌어도 얼굴과 옷이 유지됩니다. 광고·숏드라마에 필요합니다.

따라 하기

  1. 전신 모델 이미지를 만들고 캐릭터 시트를 요청합니다.
  2. 비디오에서 캐릭터 시트를 레퍼런스로 첨부해 @로 지정합니다.
  3. 모델·길이·비율·품질을 정해 생성하기를 누릅니다.
  4. 다음 장면은 첫 영상을 레퍼런스로 넣고 장소만 바꿉니다.
예시 프롬프트
첨부된 이미지를 기준으로 동일한 인물의 캐릭터 시트를 만들어 줘. 얼굴, 헤어스타일, 의상, 신체 비율은 동일하게 유지해.
  • 인물 묘사 문장은 모든 프롬프트에 똑같이 붙입니다.

30초 광고 시안 만들기

Artlist

제품·배경 이미지를 레퍼런스로 넣어 30초 광고 시안을 만들고, 피드백은 영상을 첨부해 수정 요청만 합니다.

따라 하기

  1. 제품 사진을 여러 각도로 준비합니다.
  2. 배경 이미지를 만들고 제품과 합친 이미지를 만듭니다.
  3. 비디오에서 Seedance 2.5를 고르고 길이를 30초로 늘립니다.
  4. 이미지 레퍼런스로 제품·배경 이미지를 추가해 생성합니다.
  5. 수정은 만든 영상을 첨부하고 바꿀 부분만 적습니다.
  • 시작·끝 프레임이 아니라 이미지 레퍼런스로 넣어야 합니다.
  • 엄격한 브랜드 가이드가 필요한 광고는 실제 촬영이 필요할 수 있습니다.
