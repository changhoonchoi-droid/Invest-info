사이트 목적과 구성 정리

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

빌더에 입력할 내용을 먼저 정리하면 시안 품질이 좋아집니다. 사이트 이름, 색감, 제목, 구성을 미리 적어 둡니다.

따라 하기

  1. 사이트를 누가 보고 어떤 행동을 하게 할지 한 문장으로 적습니다.
  2. 사이트 이름, 원하는 색감, 대표 제목을 정합니다.
  3. 들어갈 섹션(소개, 서비스, 후기, 문의 등)을 나열합니다.
  4. 마음에 드는 참고 사이트나 화면 캡처를 모아 둡니다.
  • 이름과 분위기를 구체적으로 적을수록 카피와 디자인이 맞춰집니다.

AI 빌더로 첫 시안 만들기

Hostinger AI 빌더

Hostinger, Readdy AI처럼 말로 설명하면 홈페이지를 만들어 주는 도구를 씁니다. 사업 소개나 랜딩 페이지 시안을 빠르게 얻기에 좋습니다.

따라 하기

  1. 첫 화면 입력창에 사이트 이름, 색감, 제목, 구성을 적어 보냅니다.
  2. 스크린샷이나 참고 사이트 링크가 있으면 함께 넣습니다.
  3. AI가 확인을 물으면 내용을 읽고 확인을 누릅니다(Hostinger).
  4. 2~3분 뒤 생성된 사이트를 확인합니다.
예시 프롬프트
해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘
  • 설문 데이터로 팀 대시보드 같은 사이트를 만들려면 Claude 데스크톱 코드 탭에서 폴더와 CSV를 올려 요청하는 방법도 있습니다.
  • 공개 게시와 도메인 연결에는 유료 결제가 필요할 수 있습니다.

참고 화면으로 분위기 맞추기

디자인은 말보다 이미지가 정확합니다. 참고할 화면 캡처를 붙여 넣고, 위치 설명이 어려우면 화면에 직접 표시하는 기능을 씁니다.

따라 하기

  1. 참고할 사이트의 화면 캡처를 준비합니다.
  2. 빌더 입력창에 캡처를 붙여 넣고 비슷한 느낌으로 만들어 달라고 요청합니다.
  3. 위치 설명이 어려우면 어노테이트 기능으로 화면에 직접 표시합니다.
예시 프롬프트

  • 남의 사이트를 그대로 복제해 쓰지 말고 분위기 참고용으로만 쓰세요.
  • 생성된 임의 내용은 내 것으로 바꿔 줍니다.

제미나이(나노바나나)로 이미지를 만들고 고칠 수 있습니다. 로고는 엠블럼만 이미지로 만든 뒤 미리캔버스에서 텍스트를 얹어 완성합니다.

따라 하기

  1. 수정할 사진이나 참고 이미지를 업로드합니다.
  2. 바꿀 것과 유지할 것을 나누어 구체적으로 요청합니다.
  3. 로고는 참고 로고와 함께 주제·상징물·스타일·색상·분위기를 적어 요청합니다.
  4. 엠블럼만 저장해 미리캔버스의 업로드로 넣고 텍스트를 추가합니다.
  5. 결과를 다운로드로 저장합니다.
예시 프롬프트
다른 부분은 바꾸지 말고 배경을 깔끔한 스튜디오로 바꿔 줘. 빛과 조명도 자연스럽게
  • 화면 캡처 대신 다운로드해야 화질이 깨지지 않습니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 반드시 확인합니다.
