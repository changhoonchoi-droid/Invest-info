어떤 도구로 만들지 고르기

Claude

Claude에는 목적이 다른 네 도구가 있습니다. 웹사이트나 앱, 대시보드는 코드에서 만듭니다. 코워크·코드·디자인은 Pro 이상이 필요합니다.

따라 하기

  1. 생각 정리나 분석은 채팅에서 합니다.
  2. 파일 업무는 코워크에서 합니다.
  3. 웹사이트·앱·대시보드는 코드에서 합니다.
  4. 발표 슬라이드는 디자인에서 마무리합니다.
  5. 내 플랜이 Pro 이상인지 확인합니다.
  • 처음에는 데스크톱 앱으로 시작하고 익숙해지면 터미널로 넘어가는 것이 추천됩니다.

화면 시안 먼저 만들어 보기

Claude Design

코드를 짜기 전에 Claude Design으로 화면 시안을 만들어 보면 방향을 빨리 잡을 수 있습니다. 회사 디자인 시스템이 있으면 스타일이 일관됩니다.

따라 하기

  1. 웹에서 Claude Design에 접속합니다.
  2. 디자인 시스템이 있으면 먼저 생성하거나 선택합니다.
  3. 만들고 싶은 화면을 말로 설명해 프로토타입을 요청합니다.
  4. 마음에 들면 결과물을 Claude Code로 넘겨 구현합니다.
  • 디자인 시스템 없이 쓰면 결과물이 'AI스럽다'는 평가가 있습니다.
  • 사용량 한도가 채팅·Claude Code와 별도로 관리됩니다.

폴더 열고 자료 첨부하기

Claude Code

폴더를 지정하고 파일을 첨부하면 개발 지식 없이도 대시보드를 만들 수 있습니다. 어떻게 만들지는 AI에게 맡기고 무엇을 만들지에 집중하세요.

따라 하기

  1. 클로드 데스크톱 앱에서 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정합니다.
  3. 폴더 선택 후 워크스페이스 신뢰를 진행합니다.
  4. 설문 결과 CSV 같은 자료 파일을 첨부합니다.
  • 실행한 폴더와 하위 폴더 전체에 접근 권한이 생기니 위치를 확인하세요.

계획 확인하고 만들기

Claude Code

계획 모드에서는 Claude가 파일을 고치지 않고 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전에 방향을 고칠 수 있습니다.

따라 하기

  1. Shift+Tab을 눌러 입력창 아래에 plan mode가 표시되게 합니다.
  2. 만들고 싶은 결과물과 필요한 기능을 풀어 써서 요청합니다.
  3. Claude가 내놓은 계획을 읽고 부족하면 수정을 요청합니다.
  4. 계획이 좋으면 승인하고 자동 수락할지 매번 물을지 고릅니다.
  5. 우측 내장 브라우저에서 결과를 확인하고 기본 브라우저에서 열기로 크롬에서도 엽니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘. 먼저 계획부터 세워 줘.
  • 기본 모드는 파일 수정 전에 매번 허락을 묻습니다. 모든 단계를 확인하고 싶으면 유지하세요.
  • 프롬프트는 가능한 한 구체적으로 씁니다.

CLAUDE.md로 규칙 남기기

Claude Code

CLAUDE.md는 Claude Code가 세션을 시작할 때마다 읽는 규칙 파일입니다. 작업 중 반복해서 바로잡은 내용을 저장하면 같은 실수가 줄어듭니다.

따라 하기

  1. 프로젝트 폴더에서 /init을 실행해 CLAUDE.md를 생성합니다.
  2. 내용을 읽고 필요한 부분을 고칩니다.
  3. 건드리면 안 되는 폴더 같은 금지 규칙을 추가합니다.
  4. 반복해서 바로잡은 규칙은 메모리에 저장하라고 명시적으로 요청합니다.
예시 프롬프트
방금 알려 준 규칙(차트 색은 파란 계열만 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 매뉴얼이 아니라 지도처럼 씁니다.
  • 자동 생성된 파일은 사람이 검수하세요.

결과 검증하고 고치기

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 마지막에는 직접 열어 보며 수정할 점을 말로 요청합니다.

따라 하기

  1. 계획에 무엇이 올바른 결과인지 성공 기준을 적습니다.
  2. 웹 화면이라면 Claude in Chrome 확장을 설치해 탭에서 직접 테스트하게 합니다.
  3. 직접 확인해 고칠 점을 프롬프트로 요청합니다.
  4. 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청합니다.
  • 이 가이드의 커밋 단계는 Git을 쓸 때만 필요하니 건너뛰어도 됩니다.
