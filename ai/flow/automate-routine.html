폴더 업무 먼저 맡겨 보기

Cowork

자동화 전에 한 번 직접 시켜 봐야 결과의 품질을 판단할 수 있습니다. 정리처럼 범위가 분명한 작업부터 시작합니다.

따라 하기

  1. Claude 데스크톱 앱에서 Cowork 탭을 누릅니다.
  2. 작업할 폴더를 선택하고 항상 허용을 고릅니다.
  3. 작업을 설명하고 변경 전에 계획을 먼저 보여 달라고 요청합니다.
  4. 계획을 확인하고 승인합니다.
  5. 폴더에 생긴 결과 파일을 열어 확인합니다.
예시 프롬프트
Organize my downloads folder. Scan the contents and propose a plan.
  • 작업 중에는 데스크톱 앱을 열어 두세요.
  • 결과는 항상 검토합니다.

글로벌 지침으로 기본 규칙 정하기

Cowork

자주 쓰는 규칙을 적어 두면 모든 코워크 작업에 공통 적용되어 결과물이 일관됩니다.

따라 하기

  1. 왼쪽 위 Claude 설정을 엽니다.
  2. 협업 탭으로 이동합니다.
  3. 지침 항목의 편집을 누릅니다.
  4. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  5. 저장을 누릅니다.
예시 프롬프트
나는 마케팅팀 직장인이다. 보고서는 간결한 존댓말로 쓰고, 날짜는 2026-11-07 형식으로 쓴다. 파일을 삭제하기 전에는 반드시 나에게 확인한다.
  • 화면 이름이 다르면 설정에서 협업·Cowork 항목을 찾아보세요.
  • 폴더마다 다른 규칙은 CLAUDE.md에 적습니다.

업무 도구 커넥터 연결하기

Cowork

커넥터를 연결해야 코워크가 내 메일·일정·문서를 읽고 정리할 수 있습니다. 이메일을 다루는 작업은 Gmail 커넥터가 켜져 있어야 합니다.

따라 하기

  1. 플러스 버튼에서 커넥터 → 커넥터 추가 → 커넥터 둘러보기로 들어갑니다.
  2. Gmail, 구글 캘린더, 노션 등을 검색합니다.
  3. 플러스 버튼을 누르고 계정으로 로그인해 인증합니다.
  4. 연결된 커넥터가 켜져 있는지 확인합니다.
  • 설정한 커넥터는 예약 작업에서도 그대로 쓰입니다.

업무 방식을 스킬로 저장하기

Cowork

스킬은 반복 업무의 절차를 저장한 것입니다. 한 번 만들면 같은 지시로 같은 품질의 결과를 얻습니다.

따라 하기

  1. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  2. 필요한 직무 플러그인을 설치합니다.
  3. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  4. 내 업무용 스킬은 알고 싶은 내용을 설명해 초안을 만들게 하고 테스트하며 다듬습니다.
  5. 입력창에 /를 입력해 스킬을 골라 실행합니다.
예시 프롬프트
미팅 전에 알고 싶은 정보(최근 90일 통화, 매출 추이, 열린 기회, 이해관계자)를 모아 계정 브리핑 문서로 정리하는 스킬을 만들어 줘.
  • 스킬은 일반 텍스트 파일이라 동작을 열어 볼 수 있습니다.
  • 명령어 표기는 플러그인 관리 화면에서 확인하세요.

예약 작업 걸기

Cowork

반복할 일을 문장으로 설명하면 예약 작업으로 등록됩니다. 아침 브리핑이나 주간 지표 리뷰에 쓰기 좋습니다.

따라 하기

  1. 반복할 일을 자연어로 설명하거나 /schedule을 입력합니다.
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 작업 이름, 프롬프트, 빈도를 확인하고 필요하면 주기를 바꿉니다.
  4. 승인 버튼을 눌러 예약을 확정합니다.
  5. 왼쪽 사이드바의 예약 페이지에 추가되었는지 확인합니다.
예시 프롬프트
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 7월 업데이트 이후 웹·모바일에서는 기기가 꺼져 있어도 클라우드에서 실행됩니다.
  • 로컬 파일이 필요한 작업은 데스크톱 앱에서 하세요.

발송 대신 초안으로 남기기

Cowork

자동화가 잘못 보내는 사고를 막으려면 외부 행동은 초안까지만 하게 합니다. 사람이 확인한 뒤 보내면 안전합니다.

따라 하기

  1. 프롬프트에 '발송하지 말고 초안으로만 남겨 줘'를 넣습니다.
  2. 첫 실행 결과를 열어 초안을 확인합니다.
  3. 문제가 있으면 지침을 보완해 다시 실행합니다.
예시 프롬프트
핵심 요약 5개를 이메일 초안으로 작성해 줘. 발송은 하지 말고 초안으로만 남겨 줘.
  • 발송 같은 외부 행동은 승인 단계를 거치게 하세요.

결과 보고 지침 개선하기

Cowork

예약 작업은 만든 뒤가 더 중요합니다. 실행 기록을 보고 틀린 곳을 스킬과 지침에 반영해야 점점 좋아집니다.

따라 하기

  1. 예약 페이지에서 지난 실행 기록을 확인합니다.
  2. 실행 후 배운 점을 스킬에 반영하도록 요청합니다.
  3. 지시문이나 주기를 수정합니다.
  4. 필요하면 즉시 실행으로 다시 테스트합니다.
  • 스킬을 팀이 함께 쓰려면 소유자·검토자·폐기 기준을 먼저 정하세요.
