데이터 흐름과 보안 점검하기

Claude 앱

분석 자료에 고객 정보나 사내 수치가 있다면 먼저 설정을 점검합니다. 외부 공유 결과물은 조직 기준에 맞는지 확인해야 합니다.

따라 하기

  1. Settings에서 학습·메모리 설정을 확인합니다.
  2. 필요 없는 실명·식별 정보는 제거하거나 자리표시자로 바꿉니다.
  3. 기밀 데이터는 비즈니스·엔터프라이즈 플랜 조건을 확인합니다.
  4. 결과물을 외부에 공유할 기준을 정합니다.
  • 일상 용도에는 일반 소비자용 버전으로 충분한 경우가 많습니다.

채팅으로 데이터 패턴 파악하기

Claude 채팅

같은 자료를 채팅→코워크→코드→디자인 순으로 이어 쓰는 흐름이 있습니다. 첫 단계는 채팅에서 패턴을 파악하는 것입니다.

따라 하기

  1. 분석할 파일을 채팅에 첨부합니다.
  2. 무엇을 알고 싶은지 목적을 적습니다.
  3. 패턴과 이상한 값을 정리해 달라고 요청합니다.
  4. 근거 수치를 표로 달라고 합니다.
  5. 의심스러운 숫자는 원본과 대조합니다.
예시 프롬프트
첨부한 설문 결과 파일에서 응답자 분포와 항목별 평균, 눈에 띄는 이상치를 표로 정리해 줘. 근거가 된 행도 알려 줘.
  • 채팅은 무료로도 쓸 수 있습니다.

Excel에서 분석·피벗 만들기

Claude in Excel

통합 문서 전체를 이해하고 셀 단위 인용과 함께 답합니다. 오류 추적과 피벗 테이블 작성도 맡길 수 있습니다.

따라 하기

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. 계산 과정을 읽고 확인합니다.
  5. 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
  6. 피벗 테이블을 요청하고 이어서 차트를 만들게 합니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.
  • Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • Pro 이상 플랜의 리서치 프리뷰 베타입니다.

SQL 없이 제품 데이터 조회하기

Claude Code

데이터 팀이 BigQuery MCP를 연결해 두면 SQL을 몰라도 조회하고 그래프까지 만들 수 있습니다. 해석하는 역할이 중요해집니다.

따라 하기

  1. 데이터 팀이 BigQuery MCP를 Claude Code에 연결해 둡니다.
  2. 보고 싶은 지표와 기간을 말합니다.
  3. 조회할 테이블을 알려 줍니다.
  4. 만들어진 그래프를 확인합니다.
  5. '요금제별로 그려 달라'처럼 후속 요청을 합니다.
  6. 파일 수정 권한 요청이 나오면 허용합니다.
  • 요청하지 않은 7일 이동평균 같은 요소가 추가될 수 있으니 확인합니다.

대시보드 웹사이트로 보여 주기

Claude Code

파일을 첨부하고 원하는 기능을 풀어 쓰면 개발 지식 없이도 대시보드를 만들 수 있습니다. 어떻게 만들지는 AI에게 맡깁니다.

따라 하기

  1. 데스크톱 앱 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼에서 폴더 열기로 작업 폴더를 지정합니다.
  3. 워크스페이스 신뢰를 진행합니다.
  4. CSV 같은 자료 파일을 첨부합니다.
  5. 만들고 싶은 결과물과 기능을 요청합니다.
  6. 우측 내장 브라우저에서 확인하고 수정은 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코드 탭은 Pro(월 20달러) 이상에서 사용합니다.

아티팩트로 팀과 함께 보기

아티팩트

문서·트래커 같은 아티팩트를 팀원과 공유해 함께 편집합니다. 팀원마다 보기·댓글·수정 권한을 정할 수 있습니다.

따라 하기

  1. 새 아티팩트를 누르고 만들 내용을 설명합니다.
  2. 우측 패널에서 결과를 직접 사용해 봅니다.
  3. 팀원을 추가하고 접근 수준을 고릅니다.
  4. 입력·체크만 필요한 사람은 contributor로 지정합니다.
  5. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
예시 프롬프트
이 분석 결과를 바탕으로 우선순위별 체크박스가 있는 트래커를 만들어 줘. 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자가 됩니다.
  • 링크를 공유해 별도 웹페이지로 보게 할 수도 있습니다.
