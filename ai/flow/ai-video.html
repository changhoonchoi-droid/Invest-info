대본을 표로 쓰기

Claude

영상 모델은 앞 컷을 기억하지 못하므로 대본을 컷 단위로 짜 두어야 합니다. 시리즈로 만들 때는 내 말투와 해석을 더해 차별점을 만듭니다.

따라 하기

  1. 작업 폴더를 만들고 단계가 끝날 때마다 결과 파일을 남깁니다.
  2. 대본을 표 하나로 씁니다. 한 줄이 한 컷이고 칸은 컷 번호, 샷 크기, 인물, 대사, 길이입니다.
  3. 남의 영상을 참고할 때는 Claude가 뽑은 질문에 말로 답하는 인터뷰로 내 해석을 더합니다.
  4. 크레딧 상한을 정하고 되돌리기 어려운 지점만 내 확인을 받게 합니다.
예시 프롬프트
이 영상을 보고 시청자가 궁금해할 질문을 뽑아서 나를 인터뷰해 줘. 내 답변을 바탕으로 롱폼 대본을 만들어 줘.
  • 단순 번역과 자막만으로는 차별점이 생기지 않습니다.
  • 영상 제작자의 크레딧 상한 숫자는 본인 값이니 내 요금제에 맞게 정하세요.

Claude에 힉스필드 연결하기

Claude

힉스필드 MCP를 연결하면 기획은 Claude가, 이미지·영상 생성은 힉스필드 크레딧이 맡습니다. 클로드 계정과 힉스필드 계정이 각각 필요합니다.

따라 하기

  1. 채팅창에서 +를 누릅니다.
  2. 커넥터에서 커넥터 추가 → 커넥터 둘러보기를 선택합니다.
  3. 검색창에 Higgsfield를 입력합니다.
  4. 클로드에 연결을 누르고 힉스필드 계정으로 로그인합니다.
  5. 크레딧 잔액과 요금제를 확인해 달라고 요청해 연결을 확인합니다.
예시 프롬프트
힉스필드 MCP로 크레딧 잔액과 요금제를 확인해 줘
  • 목록에 없을 때는 설정 → 커넥터 → 커스텀 커넥터 추가에 힉스필드 사이트의 MCP 링크를 붙여 넣습니다.
  • 공식 MCP만 쓰고 비공식 MCP는 피하세요. 품질·화질을 최대로 올리면 크레딧이 많이 소모됩니다.

모델 이미지·캐릭터 시트 만들기

Higgsfield

영상을 일관되게 만들려면 이미지를 먼저 만드는 것이 좋습니다. 전신 이미지를 만들고 캐릭터 시트까지 만들어 두면 이후 영상에서 얼굴과 의상이 유지됩니다.

따라 하기

  1. 힉스필드에 로그인하고 상단에서 이미지를 선택합니다.
  2. 모델의 외모·의상·분위기를 구체적으로 적고 전신 사진을 요청합니다.
  3. 모델을 GPT Image 2.5로 고르고 비율·품질·해상도·생성 장수를 정해 생성하기를 누릅니다.
  4. 선택한 이미지를 기준으로 동일한 인물의 캐릭터 시트를 만들어 달라고 요청합니다.
  5. +로 앞서 만든 이미지를 레퍼런스로 첨부하고 생성하기를 누릅니다.
예시 프롬프트
첨부한 이미지를 기준으로 동일한 인물의 캐릭터 시트를 만들어 줘. 얼굴, 헤어스타일, 의상, 신체 비율을 동일하게 유지해 줘.
  • 전신으로 만들어야 하반신이 임의로 표현되지 않습니다.
  • 해상도·장수·품질을 올리면 크레딧이 더 듭니다.

캐릭터 시트로 영상 생성

Higgsfield

캐릭터 시트를 레퍼런스로 넣으면 얼굴과 의상이 바뀌지 않는 영상을 여러 장면으로 만들 수 있습니다. 같은 프롬프트도 결과가 매번 달라 여러 번 생성해 고릅니다.

따라 하기

  1. 상단에서 비디오를 선택합니다.
  2. 프롬프트에 이미지 1을 주인공으로 지정하고 원하는 동작을 적습니다.
  3. 레퍼런스에 캐릭터 시트를 첨부하고 프롬프트에서 @로 지정합니다.
  4. 모델을 Seedance 2.5로 고르고 길이·비율·품질을 정합니다.
  5. 생성하기를 누르고 마음에 들면 다운로드, 아니면 프롬프트를 고쳐 다시 생성합니다.
  6. 장소를 바꾸려면 첫 영상을 레퍼런스로 함께 넣고 장소만 바꿉니다.
  • 스타터 요금제에서는 Seedance 2.5를 쓸 수 없고, 영상 속 추천은 플러스 요금제입니다.
  • 영상이 길거나 품질이 높을수록 크레딧과 생성 시간이 늘어납니다.

목소리와 감정 입히기

ElevenLabs

AI 나레이션을 만들거나 짧은 녹음으로 내 목소리를 복제할 수 있습니다. 감정은 파라미터가 거의 없어 대사 안의 감정 태그와 문장부호로 조절합니다.

따라 하기

  1. ElevenLabs에서 스피치 만들기 기능을 열고 대사를 입력합니다.
  2. Eleven v4로 생성해 들어 보고 Multilingual v2와 비교합니다.
  3. 감정은 대사 안에 whispers, curious 같은 태그를 넣어 조절합니다.
  4. 말줄임표와 느낌표로 억양을 보강합니다.
  5. 내 목소리는 Create Voice에서 Instant Voice를 고르고 약 30~40초 녹음합니다.
  6. 컷 번호와 맞는 이름으로 대사 파일을 저장합니다.
예시 프롬프트
[whispers] 이건 아직 비밀인데... [curious] 혹시 들어 보실래요?
  • 다른 사람의 목소리는 동의 없이 복제하지 않습니다.
  • 즉석 복제는 40초 녹음으로 약 70% 비슷한 수준입니다.

일부 구간만 고치기

Newtake

영상을 통째로 다시 만들지 않고 구간 리메이크로 바꿀 부분만 재생성합니다. 표정·포즈·배경은 유지되고 구간이 짧을수록 크레딧이 덜 듭니다.

따라 하기

  1. 만든 영상을 선택하고 왼쪽 위의 구간 리메이크를 누릅니다.
  2. 바꿀 구간을 늘리거나 줄여 지정합니다.
  3. 바꿀 제품이나 모델 이미지를 끌어다 연결합니다.
  4. 바꿀 내용을 입력하고 생성합니다.
  5. 원본과 결과를 비교해 확인합니다.
예시 프롬프트
선글라스를 안경으로 바꿔 줘.
  • 프롬프트에 어떤 이미지의 인물인지 구체적으로 써야 엉뚱한 인물이 섞이지 않습니다.
  • AI가 다시 생성하는 방식이라 모든 세부가 완전히 같지는 않습니다.

검수하고 올리기

Claude

입과 소리가 맞는지, 내용이 사실인지 확인한 뒤 올립니다. 검수 없이 올리지 말고 아는 지식 범위에서만 게시하는 것이 안전합니다.

따라 하기

  1. 컷별로 입 모양과 소리가 맞는지 검사합니다.
  2. 고칠 컷만 같은 시작 스틸과 시트로 다시 만들고 이전 버전은 새 이름으로 남깁니다.
  3. Claude가 쓴 내용은 다른 AI가 독립적으로 검증하게 합니다.
  4. 자막·수치·인명을 직접 확인합니다.
  5. 피드백은 매번 스킬이나 규칙으로 남깁니다.
  • AI로 만든 콘텐츠는 매편 내용이 실질적으로 달라야 가치가 생깁니다.
