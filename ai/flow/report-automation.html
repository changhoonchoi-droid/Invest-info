Cowork로 폴더 업무 맡기기

Cowork

Cowork는 폴더 접근을 허용하면 Claude가 계획을 세워 파일을 읽고 결과물을 만드는 기능입니다. 자동화 전에 범위가 분명한 작업으로 감을 익힙니다.

따라 하기

  1. Claude 데스크톱 앱을 열고 Cowork(협업)를 선택합니다.
  2. 하단 프로젝트 또는 폴더에서 작업할 폴더를 고르고 항상 허용을 누릅니다.
  3. 회의록, 메모 등 필요한 자료를 그 폴더에 넣습니다.
  4. 원하는 결과물(예: 한 페이지 워드 보고서)을 만들어 달라고 요청합니다.
  5. Claude가 제안하는 계획을 확인하고 진행 상황을 지켜봅니다.
  6. 완성된 파일을 열어 내용을 검토합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘.
  • 엑셀 정리처럼 원본이 있는 작업은 '원본은 그대로 두고 정리본은 새 파일로 저장'이라고 꼭 적으세요.
  • 웹 버전은 로컬 파일 접근이 안 되므로 데스크톱 앱에서 하세요.

글로벌 인스트럭션 적기

Cowork

글로벌 인스트럭션에 규칙을 적어 두면 이후 모든 코워크 작업에 적용됩니다. 매번 자기소개나 보고서 톤을 반복하지 않아도 됩니다.

따라 하기

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 눌러 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누릅니다.
예시 프롬프트
나는 마케팅 팀 과장이다. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적고, 파일을 삭제하기 전에는 반드시 나에게 확인해 줘.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가합니다.
  • 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.

보고서 양식을 스킬로 만들기

Claude

반복 보고의 핵심은 매번 같은 구성과 말투입니다. 잘 쓴 보고서를 올려 스킬로 저장하면 이번 주 자료만 넣어도 초안이 나옵니다.

따라 하기

  1. 잘 쓴 보고서나 결과물 하나를 채팅에 첨부합니다.
  2. '이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘'라고 요청합니다.
  3. 결과 화면에서 스킬 저장을 누릅니다.
  4. /와 스킬 이름을 입력해 스킬을 고르고 이번 주 자료를 넣어 시험합니다.
예시 프롬프트
이 보고서 양식으로 '주간 보고서' 스킬을 만들어 줘. 앞으로 이번 주 자료만 주면 같은 구성과 말투로 초안을 써 주게 해 줘.
  • 스킬 대신 메모리에 형식을 저장해도 같은 포맷을 유지할 수 있습니다.
  • AI 티가 나는 문장은 교정 스킬로 다듬되 중요한 문서는 직접 읽으세요.

Gmail·캘린더 커넥터 연결

Claude 데스크톱 앱

커넥터를 연결해 두면 파일을 일일이 올리지 않고 Claude가 메일과 일정을 직접 확인합니다. 예약 작업의 재료가 되므로 먼저 연결합니다.

따라 하기

  1. Claude 데스크톱에서 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail 또는 Microsoft 365를 선택해 클로드에 연결하고 계정을 고릅니다.
  3. 필요하면 구글 캘린더, 노션도 같은 방식으로 연결합니다.
  4. + → 커넥터에서 연결 표시(파란 불)를 확인합니다.
  • 연동 업체가 200개가 넘으니 쓰는 서비스가 있는지 검색해 보세요.
  • 민감한 업무 데이터는 조직의 데이터 처리 정책을 따르세요.

아침 메일 브리핑 예약하기

Cowork

한 번 직접 실행해 결과를 확인한 뒤, 같은 내용을 예약 작업으로 등록합니다. 예약 작업은 유료 플랜에서만 쓸 수 있습니다.

따라 하기

  1. 어제 오후 6시 이후 메일과 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  2. 결과가 마음에 들면 같은 내용을 아침 7시 50분마다 실행하는 예약 작업으로 등록해 달라고 요청합니다.
  3. Claude가 만든 프롬프트 초안과 주기를 확인하고 필요하면 고칩니다.
  4. 승인해 예약을 확정합니다.
  5. 좌측 예약됨에서 스케줄을 확인합니다.
예시 프롬프트
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고 오늘 할 일 브리핑을 만들어 줘. 그리고 이걸 매일 아침 7시 50분에 실행하는 예약 작업으로 등록해 줘.
  • 7월 업데이트 이후 영상 기준으로 기기가 꺼져 있어도 클라우드에서 실행됩니다.
  • 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행이 가능합니다.

주간 리포트·미팅 브리핑 예약

Cowork

주간 메일 정리, 미팅 브리핑, 주간 리포트처럼 매번 같은 절차를 도는 업무는 플러그인과 스킬, 예약 작업의 조합이 잘 맞습니다. 메일은 발송하지 않고 초안으로만 남기게 하면 안전합니다.

따라 하기

  1. 새 작업에서 협업을 누르고 새 프로젝트를 만듭니다.
  2. 언제, 무엇을 할지 구체적으로 요청합니다.
  3. + → 플러그인에서 직무에 맞는 플러그인을 설치하고 필요한 커넥터를 연결합니다.
  4. 테스트용 데이터로 스킬을 먼저 실행해 결과를 다듬습니다.
  5. 승인해 예약을 확정하고 좌측 코워크 탭에서 결과를 확인합니다.
  6. 발송이 필요한 결과는 승인 단계에서 내용을 확인한 뒤 보냅니다.
예시 프롬프트
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘
  • Gmail 같은 이메일 커넥터가 켜져 있어야 이 예시가 동작합니다.
  • 숫자는 데이터 출처까지 추적되는지 검증하는 교정 스킬을 따로 두면 안전합니다.

결과 점검하고 스킬 다듬기

Cowork

예약 작업은 실행마다 새 세션으로 돌기 때문에 첫 몇 주는 결과를 직접 확인해야 합니다. 배운 점을 스킬에 반영하면 다음 주에 더 나아집니다.

따라 하기

  1. 예약 페이지에서 지난 실행 기록과 결과를 엽니다.
  2. 이름으로 나가는 메일·답장은 근거를 원문에서 직접 확인합니다.
  3. 어긋난 부분을 Claude에게 알리고 스킬에 반영해 달라고 요청합니다.
  4. 지시문이나 실행 주기가 맞지 않으면 예약 페이지에서 수정합니다.
예시 프롬프트
이번 주 실행 결과에서 내가 고친 부분을 정리해서, 다음부터 반영되도록 주간 보고서 스킬에 업데이트해 줘.
  • 스킬은 일반 텍스트 파일이라 언제든 열어 동작을 확인하고 고칠 수 있습니다.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 맡기는 범위를 넓히세요.
