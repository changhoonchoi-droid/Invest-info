커넥터로 업무 도구 잇기

Claude 앱

커넥터는 구글 드라이브, Gmail, 노션 같은 업무 도구를 채팅에 붙이는 기능입니다. 예약 작업에서도 그대로 쓰이므로 자동화의 출발점입니다.

따라 하기

  1. 대화창 아래의 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가 → 커넥터 둘러보기를 선택합니다.
  3. Gmail, 구글 캘린더, 노션, 구글 드라이브 등을 검색합니다.
  4. 서비스 옆 +를 눌러 내 계정으로 로그인하고 인증합니다.
  5. 채팅에서 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청해 동작을 확인합니다.
예시 프롬프트
구글 드라이브에서 '11월 영업 보고' 파일을 찾아 내용을 요약하고, 팀장님께 보낼 이메일 초안을 써 줘.
  • 예약 작업을 쓰려면 이메일 같은 커넥터가 미리 켜져 있어야 합니다.
  • 목록에 없는 서비스는 MCP URL로 커스텀 커넥터를 추가할 수 있습니다.

플러그인 설치하고 손으로 시험

Cowork

플러그인은 스킬·커넥터·슬래시 명령을 직무별로 묶은 패키지입니다. 자동화 전에 수동으로 한 번 돌려 결과 품질을 확인합니다.

따라 하기

  1. Cowork 설정에서 필요한 커넥터(캘린더, Slack, 이메일 등)를 연결합니다.
  2. 작업 폴더를 지정해 Claude가 파일을 읽고 저장할 수 있게 합니다.
  3. + 버튼에서 플러그인을 선택해 직무에 맞는 플러그인을 설치합니다.
  4. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  5. 회의·고객 정보를 적어 브리핑 문서를 만들고 근거를 원문에서 확인합니다.
예시 프롬프트
Prep me for today's call with Acme Corp at 1PM. 캘린더, Slack, 이메일, 이전 회의록을 확인해서 안건 문서를 만들고, 기존 문서 형식을 템플릿으로 따라 줘.
  • 처음에는 테스트 계정으로 돌려 보고 다듬은 뒤 실제 업무에 씁니다.
  • 내 이름으로 보내는 답장은 특히 근거를 직접 확인하세요.
  • 플러그인 명령어 이름은 플러그인 관리 화면에서 확인하세요.

작업 방식을 스킬로 저장

Claude 앱

마음에 드는 결과가 나오면 그 방식을 스킬로 저장합니다. 자동 실행 때 매번 같은 품질이 나오게 하는 기반입니다.

따라 하기

  1. 결과물을 마음에 들 때까지 수정합니다.
  2. 만족스러운 방식을 스킬로 만들어 달라고 요청합니다.
  3. 요청에 작업 순서와 검증 기준을 함께 적습니다.
  4. /와 스킬 이름으로 호출해 같은 결과가 나오는지 확인합니다.
예시 프롬프트
방금 만든 결과물의 작업 순서와 검증 기준을 정리해서, 다음에도 같은 방식으로 만들 수 있는 스킬로 만들어 줘.
  • 스킬 설명(description)에 언제 쓰는지 분명히 적어야 자동 선택됩니다.
  • 항상 지킬 규칙은 CLAUDE.md나 전역 지침에 적습니다.

예약 작업 걸기

Cowork

예약 작업은 매일·매주 같은 일을 정해진 시각에 Claude가 실행하게 합니다. 7월 업데이트 이후에는 클라우드에서 기기가 꺼져 있어도 실행된다고 소개됩니다.

따라 하기

  1. 반복할 일과 시각을 자연어로 설명하거나 입력창에 /schedule을 입력합니다.
  2. Claude가 만든 프롬프트 초안과 주기를 확인·수정합니다.
  3. 승인 버튼을 눌러 예약을 확정합니다.
  4. 왼쪽 사이드바의 예약 페이지에서 작업이 추가됐는지 확인합니다.
  5. 처음 몇 번은 실행 기록을 열어 결과를 점검합니다.
예시 프롬프트
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 실행마다 새 세션으로 돌기 때문에 필요한 맥락은 프롬프트나 폴더에 두세요.
  • 메일은 발송하지 말고 초안으로 남기도록 지시하세요.
  • 승인이 필요한 부분은 모바일에서도 요청이 옵니다.

결과 점검하고 범위 넓히기

Cowork

처음에는 결과를 직접 확인하고 신뢰가 쌓이면 권한과 범위를 늘립니다. 팀 채널에서 함께 쓰려면 Claude Tag로 확장할 수 있습니다.

따라 하기

  1. 예약 작업의 실행 기록과 결과 문서를 열어 정확성을 확인합니다.
  2. 틀린 부분은 프롬프트나 스킬에 규칙으로 반영합니다.
  3. 안정되면 대상 업무를 하나씩 추가합니다.
  4. 팀 협업이 필요하면 한 채널에서만 Claude Tag를 시작합니다.
  • Claude Tag는 Team·Enterprise 요금제에서 베타로 제공됩니다.
  • 처음에는 한 채널에서만 시작하세요.
