데스크톱 앱 설치하고 폴더 열기

Claude 데스크톱 앱

코워크는 데스크톱 앱에서 폴더를 열어 줘야 파일을 읽고 결과물을 만듭니다. 처음에는 읽기만 하게 해서 안전하게 시작합니다.

따라 하기

  1. Claude 사이트 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다.
  2. Pro 이상이면 앱에서 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허락합니다.
  4. 작업을 설명하면 Claude가 먼저 계획을 제안하니 확인 후 승인합니다.
  5. 파일을 바꾸기 전 권한을 요청하면 내용을 보고 허용합니다.
예시 프롬프트
다운로드 폴더의 파일을 종류별로 정리할 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • 처음에는 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 코워크는 Pro, Max, Team, Enterprise에서 macOS와 Windows 앱으로 제공됩니다.

글로벌 지침으로 규칙 고정

Cowork

매번 같은 말을 반복하지 않도록 모든 코워크 작업에 적용되는 기본 규칙을 적습니다. 내 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 넣습니다.

따라 하기

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. 협업 항목에서 지침 탭을 찾아 편집을 누릅니다.
  3. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누르면 이후 모든 코워크 작업에 적용됩니다.
예시 프롬프트
나는 마케팅팀 대리다. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 쓴다. 파일을 삭제하기 전에는 반드시 나에게 확인한다.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가합니다.
  • 메뉴 이름은 버전마다 다르니 화면에 보이는 이름을 따라가세요.

폴더 업무 하나 맡겨 보기

Cowork

자동화 전에 한 번 직접 시켜 보고 결과를 확인합니다. 계획을 먼저 보여 달라고 하고, 원본 보존과 파일명 규칙을 프롬프트에 적어 두는 것이 안전합니다.

따라 하기

  1. 코워크 버튼을 눌러 프로젝트 또는 폴더에서 폴더 추가로 작업 폴더를 엽니다.
  2. 폴더 접근 권한 창에서 항상 허용을 선택합니다.
  3. 할 일을 구체적으로 적고 파일을 바꾸기 전에 계획을 보여 달라고 덧붙입니다.
  4. 정리 규칙과 원본 보존 여부를 함께 적습니다.
  5. 계획·실행·검증이 진행되는 것을 보고 결과 파일을 열어 확인합니다.
예시 프롬프트
이 폴더의 엑셀 세 개를 하나로 합쳐 줘. 파일을 바꾸기 전에 계획을 먼저 보여 주고, 원본은 그대로 두고 정리본은 새 파일로 저장해 줘. 파일명에는 날짜를 넣어 줘.
  • 웹 버전은 내 컴퓨터 파일에 접근할 수 없으므로 폴더 작업은 데스크톱 앱에서 하세요.
  • 버전마다 버튼 이름이 달라(협업 등) 화면에 보이는 이름을 따라가세요.

커넥터로 메일·일정 연결

Cowork

예약 작업이 메일과 일정을 읽으려면 커넥터가 먼저 연결돼 있어야 합니다. 연결은 처음 한 번만 하면 됩니다.

따라 하기

  1. 플러스 버튼에서 커넥터 → 커넥터 추가 → 커넥터 둘러보기로 들어갑니다.
  2. Gmail, 구글 캘린더, 노션 등을 검색해 플러스 버튼을 누릅니다.
  3. 계정으로 로그인해 인증합니다.
  4. 채팅창 + → 커넥터에서 켜짐 상태를 확인합니다.
  • 이 실습은 Gmail 같은 이메일 커넥터가 켜져 있어야 합니다.
  • 메일·메시지는 승인 단계를 거쳐 발송하게 하세요.

스킬로 보고서 양식 고정

Claude 앱

스킬은 반복 업무의 양식과 규칙을 저장해 둔 기능입니다. 평소 쓰는 보고서를 분석시켜 스킬로 저장하면 매번 같은 포맷의 결과가 나옵니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 형식을 분석해 회사 보고서 만드는 스킬을 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력하고 주제를 적어 요청합니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
예시 프롬프트
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 브랜드 컬러, 강조 방식, 폰트, 섹션 구성을 함께 알려 주면 좋습니다.
  • 중요한 보고서는 AI 티가 나는 문장을 직접 읽고 고치세요.

예약 작업으로 정기 실행

Cowork

반복할 일을 말로 설명하면 Claude가 예약 작업 초안을 만들어 줍니다. 주기를 확인해 승인하면 정해진 때마다 실행됩니다. 처음 한 번은 직접 실행해 결과를 확인하세요.

따라 하기

  1. 새 작업에서 협업을 누르고 반복할 업무와 주기를 말로 요청합니다.
  2. Claude가 만든 프롬프트 초안과 주기(매시간·매일·평일·수동)를 확인·수정합니다.
  3. 승인 버튼을 눌러 예약을 확정합니다.
  4. 왼쪽 사이드바의 예약 페이지에서 작업이 추가된 것을 확인합니다.
  5. 즉시 실행으로 처음 한 번 결과를 확인하고, 지난 실행 기록도 봅니다.
예시 프롬프트
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 7월 업데이트 이후 작업은 클라우드에서 돌아 기기가 꺼져 있어도 실행된다고 소개되었습니다. 로컬 파일을 다루는 작업은 데스크톱 앱이 필요합니다.
  • 예전 방식(6월 영상): 컴퓨터가 켜져 있고 앱이 열려 있어야 실행됐습니다.
  • 슬래시 명령 /schedule로도 만들 수 있습니다.

회의 준비·주간 리포트로 확장

Cowork

캘린더·Slack·메일을 모아 회의 안건 문서를 만들거나, 준비·교정·액션 아이템 스킬을 예약과 묶어 주간 리포트를 만듭니다. 숫자 수집은 Claude가, 서사와 초점은 사람이 정합니다.

따라 하기

  1. 캘린더, Slack, 이메일을 연결하고 이전 회의록 폴더를 지정합니다.
  2. 회의 이름과 시간을 알려 주고 기존 문서 형식을 템플릿으로 따르게 지시합니다.
  3. 리뷰 준비, 교정, 액션 아이템 관리용 스킬을 각각 만듭니다.
  4. 일요일 저녁에 실행되는 예약 작업을 설정합니다.
  5. 월요일 아침 결과를 확인하고 이번 주 초점을 지시한 뒤 ship it으로 최종 문서를 만듭니다.
예시 프롬프트
Prep me for today's call with Acme Corp at 1PM. 캘린더, Slack, 이메일, 이전 회의록을 확인해서 안건 문서를 만들어 줘. 기존 문서 형식을 템플릿으로 따라 줘.
  • 처음에는 테스트용 계정으로 돌려 보고 다듬으세요.
  • 교정 스킬은 초안의 모든 숫자가 검증된 출처로 추적되는지 확인합니다.

Cowork

따라 하기

  4. 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  5. 메일 발송 등 되돌리기 어려운 지점은 다음 단계 전에 내 확인을 받도록 정합니다.
  • 영상의 상한 숫자는 제작자 본인의 값이므로 내 요금제에 맞게 정하세요.
