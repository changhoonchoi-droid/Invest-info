데스크톱 앱 설치하고 폴더 열기

Claude 데스크톱 앱

Cowork 같은 기능은 데스크톱 앱에서만 쓸 수 있습니다. 앱을 설치하고 Claude가 볼 폴더 접근을 허락합니다.

따라 하기

  1. Claude 사이트 아래쪽의 데스크톱 앱 다운로드로 앱을 설치합니다.
  2. 앱에 로그인합니다.
  3. Claude가 볼 폴더 접근을 허락합니다.
  4. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청합니다.
  5. 파악한 내용에서 틀린 부분을 바로잡아 줍니다.
예시 프롬프트
이 폴더의 파일을 읽기만 하고 절대 수정하거나 삭제하지 마. 내가 어떤 일을 하는 사람인지, 어떤 프로젝트가 있는지 정리해 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.

자동화할 업무 고르기

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

처음에는 범위가 분명하고 실패해도 부담이 적은 업무가 좋습니다. 매주 같은 형식으로 반복되며 사람이 마지막에 검토할 수 있는 일을 고릅니다.

따라 하기

  1. 내가 매주 반복하는 업무를 적어 봅니다.
  2. 그중 입력 자료와 결과물 형태가 늘 비슷한 것을 고릅니다.
  3. 결과를 누가 어떻게 확인할지 정합니다.
  4. Claude에게 후보를 보여 주고 자동화하기 좋은 순서를 물어봅니다.
예시 프롬프트
내가 매주 하는 일 목록이야. 이 중 자동화하기 좋은 순서를 정해 주고, 각각 필요한 자료와 확인할 점을 알려 줘.
  • 처음에는 정리처럼 범위가 분명한 작업부터 시작하고 결과를 항상 검토하세요.

Cowork로 한 번 직접 시키기

Cowork

자동화하기 전에 먼저 한 번 직접 시켜 보며 결과물이 원하는 모양인지 확인합니다. Claude가 계획을 먼저 제안하므로 읽고 승인합니다.

따라 하기

  1. Claude 데스크톱 앱에서 Cowork(또는 협업)을 선택합니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 고릅니다.
  3. 원하는 결과물을 구체적으로 적어 요청합니다.
  4. Claude가 제안하는 계획을 확인한 뒤 승인합니다.
  5. 폴더에 저장된 결과 파일을 열어 확인합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘.
  • 원본은 그대로 두고 정리본은 새 파일로 저장해 달라고 적어 두세요.
  • 웹 버전은 로컬 파일 접근이 안 되므로 폴더 작업은 데스크톱 앱에서 하세요.

글로벌 지침 설정하기

Cowork

매번 같은 말을 반복하지 않도록 역할과 보고서 톤 같은 규칙을 저장합니다. 이후 모든 Cowork 작업에 적용됩니다.

따라 하기

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래 협업 항목에서 지침을 찾아 편집을 누릅니다.
  3. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누릅니다.
예시 프롬프트
나는 마케팅팀 대리야. 보고서는 존댓말로 간결하게 쓰고, 날짜는 2026-11-10 형식으로 적어 줘. 파일을 삭제하기 전에는 반드시 나에게 먼저 확인해 줘.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 실제 화면에서 확인해야 합니다.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md에 폴더 지침을 추가합니다.

스킬로 보고서 양식 고정하기

Claude

평소 쓰는 보고서 양식 파일을 분석시켜 스킬로 저장하면 다음부터 같은 형식이 나옵니다. 매주 같은 서식의 문서를 만드는 업무에 효과가 큽니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. "이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘"라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 저장합니다.
  4. 다음부터 입력창에 /와 스킬 이름을 입력해 주제와 함께 요청합니다.
  5. + 메뉴의 스킬에서 저장된 스킬을 확인합니다.
예시 프롬프트
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 중요한 보고서는 직접 읽고 수정하세요.

커넥터로 메일·캘린더 연결하기

Claude

예약 작업에서 메일이나 캘린더를 쓰려면 커넥터가 미리 켜져 있어야 합니다. 한 번 연결해 두면 예약 작업에서도 그대로 쓸 수 있습니다.

따라 하기

  1. 플러스 버튼에서 커넥터 → 커넥터 추가 → 커넥터 둘러보기로 들어갑니다.
  2. Gmail, 구글 캘린더, 노션 등을 검색합니다.
  3. 플러스 버튼을 누르고 내 계정으로 로그인해 인증합니다.
  4. 채팅에서 연결이 되었는지 간단한 요청으로 확인합니다.
예시 프롬프트
내 구글 캘린더에서 이번 주 일정을 가져와서 요일별로 정리해 줘.
  • 이메일 같은 커넥터가 켜져 있어야 예약 작업이 동작합니다.

예약 작업으로 정기 실행하기

Cowork

직접 시켜 본 일을 정해진 시각에 자동으로 하도록 등록합니다. Claude가 만든 프롬프트 초안과 주기를 확인한 뒤 승인하면 예약이 확정됩니다.

따라 하기

  1. 반복할 일을 자연어로 설명합니다. 입력창에 /schedule을 입력해도 됩니다.
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 주기를 매시간·매일·평일·수동 중에서 필요에 맞게 바꿉니다.
  4. 내용이 맞으면 승인 버튼을 눌러 예약을 확정합니다.
  5. 왼쪽 사이드바의 예약 페이지에서 작업이 추가되었는지 확인합니다.
  6. 첫 실행 결과를 열어 보고 지시문이나 주기를 고칩니다.
예시 프롬프트
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 7월 업데이트 이후 클라우드에서 실행되어 기기가 꺼져 있어도 돌아간다는 설명이 있습니다. 예전에는 컴퓨터와 앱이 켜져 있어야 했습니다.
  • 예약 페이지에서 실행 기록 확인, 수정, 즉시 실행이 가능합니다.

결과 확인과 승인 규칙 정하기

Cowork

자동화가 만든 결과는 처음에는 사람이 확인해야 합니다. 이름을 걸고 나가는 메일은 발송 전 승인 단계를 두고, 신뢰가 쌓이면 맡기는 범위를 넓힙니다.

따라 하기

  1. 자동 결과의 근거를 원문에서 직접 확인하고 고칩니다.
  2. 메일은 발송하지 말고 초안으로 남기게 지시합니다.
  3. 발송 같은 되돌리기 어려운 동작은 내 승인을 받도록 적습니다.
  4. 반복되는 준비 절차는 스킬로 저장해 /로 불러 씁니다.
  5. 처음에는 테스트 계정으로 돌려 봅니다.
예시 프롬프트
회의 후 녹취록을 처리해서 할 일과 후속 메시지를 만들어 줘. 메시지는 보내지 말고 내가 승인하기 전까지 초안으로만 남겨 줘.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
