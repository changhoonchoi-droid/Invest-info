자동화할 업무 하나 고르기

Claude 앱

모든 일을 한꺼번에 자동화하기보다 순서가 정해진 반복 업무 하나부터 시작합니다. 단계를 미리 알 수 없는 탐색형 업무는 예약 작업보다 사람이 함께하는 편이 낫습니다.

따라 하기

  1. 매일·매주 같은 순서로 하는 업무를 적어 봅니다(예: 회의 준비, 폴더 변경 요약, 정기 보고).
  2. 그중 순서가 정해진 반복 업무와 단계를 미리 알 수 없는 업무를 나눕니다.
  3. 반복 업무 가운데 가장 시간이 많이 드는 것 하나를 고릅니다.
  4. 그 업무를 '모으기 → 정리하기 → 저장하기' 순서로 적어 봅니다.
  • 확신이 낮은 판단은 자동으로 처리하지 말고 사람에게 넘기라는 조건을 함께 정해 두세요.

커넥터와 폴더 연결하기

Cowork

Cowork가 여러 도구에 흩어진 정보를 모으려면 커넥터와 폴더가 연결돼 있어야 합니다. 미리 연결해 둔 커넥터는 나중에 예약 작업에서도 그대로 쓰입니다.

따라 하기

  1. Claude 데스크톱 앱을 열고 Cowork 작업을 시작합니다.
  2. 업무에 필요한 커넥터(캘린더, Slack, 이메일 등)를 연결합니다.
  3. 회의록이나 참고 문서가 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  4. 기존 문서 형식이 있으면 템플릿으로 쓸 파일을 같은 폴더에 둡니다.
  • 9월 업데이트로 채팅과 Cowork가 하나의 Claude로 합쳐졌고, 기존 Cowork 작업은 그대로 남아 있습니다.

한 번 직접 맡겨 보기

Cowork

예약 작업으로 만들기 전에 같은 일을 한 번 맡겨 결과가 원하는 대로 나오는지 확인합니다. 작업 중에 지시를 더해도 처음부터 다시 하지 않고 이어서 고칩니다.

따라 하기

  1. 맡길 일과 원하는 결과물을 한 번에 요청합니다.
  2. 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  3. Claude가 세운 계획을 확인한 뒤 작업이 진행되게 둡니다.
  4. 빠진 출처가 있으면 작업 중에 바로 추가합니다(예: 이메일도 확인해 줘).
  5. 방향이 다르면 이어서 수정을 요청합니다.
예시 프롬프트
오늘 오후 2시 ○○사와의 회의를 준비해 줘. 캘린더에서 회의를 찾고, 참석자를 조사하고, 관련 Slack 스레드와 이전 회의록을 검토해서 기존 안건 문서 형식대로 안건을 작성해 줘.
  • 처음부터 완벽하게 길게 쓰지 않아도 됩니다. 중간에 지시를 더하면 방향만 바꿔 이어 갑니다.

결과 문서 검토하고 보완하기

Cowork

완성된 문서의 최종 책임은 사용자에게 있습니다. 결과를 직접 읽고 빠진 내용을 보완하면서, 자동화할 때 넣을 지시도 함께 다듬습니다.

따라 하기

  1. 작업 폴더에 저장된 문서를 엽니다.
  2. 사실과 다르거나 빠진 내용이 있는지 확인합니다.
  3. 빠진 내용은 Claude에게 추가를 요청하거나 직접 고칩니다.
  4. 다음에도 반복할 지시(형식, 출처, 분량)를 메모해 둡니다.
  • 보내기 전에 꼭 직접 확인하세요. 깔끔해 보여도 틀린 내용이 있을 수 있습니다.

예약 작업으로 등록하기

Cowork

결과가 마음에 든 작업을 예약 작업으로 만들면 정한 시간에 새 Cowork 세션으로 실행됩니다. 실행할 때마다 그 시점의 최신 파일과 도구 상태를 기준으로 합니다.

따라 하기

  1. 방금 한 작업을 예약 작업으로 만들어 달라고 요청합니다.
  2. Claude가 써 준 프롬프트 초안을 읽고 필요한 부분을 고칩니다.
  3. 실행 주기를 매시간·매일·평일·수동 중에서 확인하고 필요하면 바꿉니다.
  4. 내용이 맞으면 제안을 수락해 등록합니다.
  5. 왼쪽 사이드바의 예약(scheduled) 페이지에 작업이 추가됐는지 확인합니다.
예시 프롬프트
방금 만든 회의 준비 문서 작업을 평일 오후 4시마다 다음 날 회의를 대상으로 자동 실행하는 예약 작업으로 만들어 줘.
  • 예약 작업은 컴퓨터가 켜져 있고 Claude 데스크톱 앱이 열려 있어야 실행됩니다.

첫 실행 결과 확인하기

Cowork

등록한 뒤 바로 한 번 실행해 예약 작업이 대화에서 할 때와 같은 결과를 내는지 확인합니다. 문제가 있으면 정기 실행 전에 지시를 고칩니다.

따라 하기

  1. 예약 페이지에서 등록한 작업을 즉시 실행합니다.
  2. 작업 폴더에 결과 문서가 저장됐는지 확인합니다.
  3. 내용과 형식이 시험 때와 같은지 비교합니다.
  4. 다르면 예약 페이지에서 지시문을 고칩니다.
  • 컴퓨터가 꺼져 있어 놓친 작업은 다시 켰을 때 바로 실행되고, 지연됐다고 알려 줍니다.

실행 기록 보며 개선하기

Cowork

자동화는 등록으로 끝나지 않습니다. 실행 기록을 보며 지시를 다듬고, 결과물은 사람이 확인한 뒤 쓰는 원칙을 지킵니다.

따라 하기

  1. 예약 페이지에서 지난 실행 기록을 확인합니다.
  2. 자주 빠지는 내용이나 틀리는 부분을 지시문에 반영합니다.
  3. 필요하면 실행 주기를 바꿉니다.
  4. 결과물을 외부에 보내거나 공유하기 전에는 사람이 확인하고 승인합니다.
  5. 예상보다 자주 실행되거나 결과가 이상하면 작업을 멈추고 지시를 점검합니다.
  • 같은 방식으로 폴더 변경 요약, 주간 보고 초안 같은 다른 업무도 하나씩 늘려 갑니다.
