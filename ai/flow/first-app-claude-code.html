인터뷰받아 스펙 만들기

Claude Code

결과를 처음부터 자세히 정해 주기보다 Claude가 질문하며 요구사항을 끌어내게 하면 더 좋은 스펙이 나옵니다. 최신 모델에서는 플랜 모드 대신 오토 모드를 씁니다.

따라 하기

  1. Shift+Tab을 눌러 auto mode로 전환합니다.
  2. 프롬프트에 만들 것과 대상 사용자만 적고 결과는 지나치게 정하지 않습니다.
  3. ask user question 도구를 쓰라고 분명히 적습니다.
  4. Claude가 띄우는 질문에 차례로 답합니다.
  5. 완성된 스펙을 직접 읽고 검토합니다.
예시 프롬프트
회사 동료들끼리 점심값을 나누는 앱을 만들고 싶어. 대상 사용자는 같은 팀 직장인이야. ask user question 도구로 나에게 질문하면서 요구사항을 정리한 뒤, 검토하기 쉬운 HTML 파일로 스펙을 써 줘.
  • 스펙은 긴 마크다운보다 정보가 빽빽한 HTML 파일로 받으면 검토하기 쉽습니다.
  • 스펙을 빠르게 여러 번 다듬을 때는 /fast 모드가 유용합니다.

따라 하기

  1. Claude Code에서 작업할 저장소(폴더)를 연결합니다.

  4. 마음에 드는 시안에 잘된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.

  • Claude가 작업하는 동안 다른 일을 하다 돌아와 결과를 확인해도 됩니다.

권한 규칙 정하고 구현하기

Claude Code

Claude Code는 파일 수정이나 명령 실행 전에 권한을 요청합니다. 꼭 막을 동작은 막아 두고, 확정한 디자인과 스펙으로 구현을 맡깁니다.

따라 하기

  1. 어떤 상황에서도 실행되면 안 되는 동작을 적어 deny 규칙에 넣습니다.
  2. 실행 전에 항상 확인받고 싶은 동작은 ask 규칙에 넣습니다.
  3. 매번 확인할 필요가 없는 동작만 allow 규칙에 넣습니다.
  4. 확정한 디자인과 스펙을 바탕으로 구현(build)을 지시합니다.
  5. 처음에는 좁게 허용하고, 자주 막히는 항목을 보며 조금씩 넓힙니다.
예시 프롬프트
확정한 프로토타입과 스펙 파일을 바탕으로 이 앱을 구현해 줘. 구현이 끝나면 실행 방법을 알려 줘.
  • ask 규칙에 넣은 동작은 자동 모드에서도 확인을 받습니다.
  • 회사 시스템과 연결되는 고위험 작업은 자동 모드에 맡기지 말고 직접 검토하세요.

verify 스킬로 직접 확인시키기

Claude Code

테스트를 통과해도 변경이 의도대로 동작하는지는 알 수 없습니다. verify 스킬로 Claude가 앱을 직접 실행해 확인하고, 문제가 있으면 고친 뒤 다시 확인하게 합니다.

따라 하기

  1. Claude Code에 포함된 verify 스킬을 처음 사용합니다.
  2. Claude가 앱을 실행하고 변경 사항을 직접 확인하는 과정을 지켜봅니다.
  3. 성공한 확인 절차가 프로젝트에 스킬로 저장됐는지 확인합니다.
  4. 스킬에 언제 실행할지, 실패하면 무엇을 할지, 무엇이 통과 기준인지 적습니다.
  5. 다음 화면 수정부터는 Claude가 확인과 수정을 반복하는지 봅니다.
예시 프롬프트
verify 스킬로 방금 바꾼 화면을 앱에서 직접 실행해 확인하고, 문제가 있으면 고친 뒤 다시 확인해 줘
  • 확인 기준이 측정 가능할수록 Claude가 혼자 더 멀리 진행합니다.
  • 웹은 브라우저, 백엔드는 엔드포인트 호출, 모바일은 iOS 시뮬레이터로 확인할 수 있습니다.

Claude가 같은 실수를 반복하면 매번 다시 시키지 말고 CLAUDE.md나 스킬에 규칙으로 적어 둡니다. 규칙은 짧고 서로 부딪히지 않게 유지합니다.

따라 하기

  1. Claude가 실수하면 무엇이 잘못됐는지 한 문장으로 정리합니다.
  2. 그 규칙을 CLAUDE.md나 해당 스킬에 적어 둡니다.
  3. 꼭 필요한 규칙만 짧게 적고 서로 부딪히는 지침이 없는지 확인합니다.
  4. 새 모델로 바꿨다면 /claude-api prompt-audit를 실행해 지침을 점검합니다.
예시 프롬프트
/claude-api prompt-audit
  • 지침끼리 부딪히면 모델이 엉뚱한 값을 쓸 수 있습니다.

클라우드 세션에 작업 맡기기

Claude Code

코드를 GitHub에 올려 두면 클라우드 세션이 저장소를 복제해 별도 브랜치에서 작업합니다. 퇴근 전에 큰 수정을 맡기고 휴대폰으로 확인한 뒤 풀 리퀘스트를 엽니다.

따라 하기

  1. 작업할 코드를 GitHub 저장소에 올려 둡니다.
  2. GitHub 계정을 연결하고 Claude GitHub App을 설치해 접근할 저장소를 고릅니다.
  3. 데스크톱 앱에서 Local 대신 Cloud를 선택하고 저장소, 환경, 시작할 브랜치를 고릅니다.
  4. 맡길 일을 설명하고 노트북을 닫습니다.
  5. 휴대폰 Claude 앱의 Code 탭에서 질문에 답하거나 방향을 조정합니다.
  6. 변경 내용(diff)을 검토하고 문제가 없으면 Create PR을 누릅니다.
  • 클라우드 세션은 커밋하고 푸시한 내용만 씁니다. 개인 설정, 스킬, 플러그인이 필요한 작업은 로컬에서 실행하세요.
  • Pro·Max·Team, 그리고 프리미엄 좌석 또는 Chat + Claude Code 좌석이 있는 Enterprise에서 쓸 수 있고, 사용량은 플랜 한도에 합산됩니다.
