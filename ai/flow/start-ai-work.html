Claude 설치하고 나 소개하기

Claude 데스크톱 앱

AI는 나에 대한 맥락을 알수록 쓸모 있는 답을 줍니다. 첫날 나를 소개하고 인터뷰를 받게 하면 이후 도움의 품질이 달라집니다.

따라 하기

  1. Claude 데스크톱 앱을 설치합니다.
  2. 폴더 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청합니다.
  4. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 확인합니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
예시 프롬프트
이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?
  • 파일은 읽기만 하고 고치지 말라고 지시하면 안전합니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작합니다.
  • AI를 전혀 모르면 ChatGPT 앱의 보이스 모드로 말하듯 시작해도 좋습니다.

요금제와 구독 시점 정하기

Claude 앱

구독료의 기준은 금액이 아니라 쓰다가 한도에 막히는지입니다. 무료로 시작해 불편해질 때 유료로 올리면 됩니다.

따라 하기

  1. 먼저 무료 플랜으로 업무에 써 봅니다.
  2. 사용 중 한도(리밋)에 자주 막히는지 확인합니다.
  3. 막히면 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다.
  4. Pro로도 부족하면 Max를 검토합니다.
  5. 쓴 만큼 돈·시간·성과가 나는지 따져 계속 쓸지 판단합니다.
  • 무료 플랜에서는 Opus를 쓸 수 없습니다.
  • 코워크·코드·디자인은 Pro 이상에서 쓸 수 있습니다.

내 정보 설정 점검하기

Claude 설정

입력한 정보는 대화, 메모리, 제공사 시스템, 향후 학습으로 갈 수 있습니다. 업무에 쓰기 전에 설정을 점검하면 유출 걱정을 줄일 수 있습니다.

따라 하기

  1. 설정에서 계정·개인정보(데이터 컨트롤) 메뉴로 들어갑니다.
  2. 메모리, 대화 기록, 연결된 앱, 학습 관련 토글을 확인합니다.
  3. 학습 관련 항목이 보이면 끕니다.
  4. 저장된 메모리를 고치거나 지우고, 필요 없으면 끕니다.
  5. 메일 문구를 다듬을 때는 실명을 자리표시자로 바꿉니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 씁니다.
  • 메뉴 이름과 위치는 바뀔 수 있으니 설정 안에서 데이터 컨트롤 부근을 직접 찾아보세요.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.

웹 검색·딥 리서치로 조사하기

Claude 채팅

웹 검색을 켜면 외부 자료를 찾아 출처와 함께 답합니다. 시장 조사처럼 깊은 조사에는 딥 리서치를 씁니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 질문하고 답에 달린 출처 링크를 확인합니다.
  4. 깊은 조사는 + 버튼에서 연구를 눌러 딥 리서치를 켭니다.
  5. 조사 주제와 원하는 결과 형태를 적어 요청합니다.
예시 프롬프트
국내 중소기업 대상 AI 구독 서비스 시장을 조사해 줘. 출처 링크와 함께 표로 정리해 줘.
  • 최신 정보는 검색을 켜고 묻습니다.

일에 맞는 도구 고르기

Claude 앱

Claude에는 목적이 다른 네 도구가 있습니다. 어떤 일에 어떤 도구를 쓸지 기준을 잡으면 헤매지 않습니다.

따라 하기

  1. 생각 정리와 데이터 패턴 분석은 채팅으로 합니다.
  2. 파일 정리와 엑셀·워드 보고서는 코워크로 합니다.
  3. 웹사이트·앱 제작은 코드로 합니다.
  4. 발표 자료는 디자인으로 만듭니다.
  5. 한 자료로 채팅 → 코워크 → 코드 → 디자인 순서로 연습해 봅니다.
  • 코워크는 데스크톱 앱에서만 쓸 수 있습니다.
  • 9월 업데이트 이후 채팅과 코워크가 합쳐져 한 대화에서 이어서 작업합니다.

답변 검증 습관 들이기

Claude 채팅

AI는 틀린 내용도 자신 있게 말할 수 있습니다. 업무에 쓰려면 근거를 요구하고 중요한 내용은 직접 확인해야 합니다.

따라 하기

  1. 답이 의심되면 검증 가능한 근거에 기반해 답하도록 요구합니다.
  2. 웹 검색을 켜고 출처 링크를 직접 엽니다.
  3. 중요한 내용은 다른 AI에게 같은 내용을 검증시킵니다.
  4. 여러 버전을 요청해 비교합니다.
예시 프롬프트
방금 답변의 근거가 되는 자료와 출처를 알려 줘. 확인되지 않는 내용은 확인되지 않았다고 표시해 줘.
  • 숫자·날짜·인용은 특히 다시 확인합니다.
