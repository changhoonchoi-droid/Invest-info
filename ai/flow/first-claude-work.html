  • 메뉴 이름은 제품마다 달라 설정 안에서 직접 찾아야 합니다.

AI에게 나를 알려 주기

Claude 앱

AI는 내 상황을 알수록 답이 좋아집니다. 먼저 AI가 나에게 질문하게 하면 맥락을 빠르게 쌓을 수 있습니다.

따라 하기

  1. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 확인합니다.
  2. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청합니다.
  3. 질문에 음성으로 길게 답합니다.
  4. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 봐. 그다음에 이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?
  • 하루 30분 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 파일은 읽기만 하고 고치지 말라고 지시하면 안전합니다.

요금제와 모델 고르기

Claude 앱

구독 기준은 금액이 아니라 쓰다가 한도에 막히는지입니다. 모델도 작업 성격에 맞게 나눠 쓰면 사용량을 아낍니다.

따라 하기

  1. 먼저 무료 플랜으로 업무에 써 봅니다.
  2. 자주 막히면 유료 플랜을 검토합니다.
  3. 질문창의 모델 선택 메뉴를 엽니다.
  4. 일상 작업은 Sonnet, 복잡한 작업은 Opus 이상을 고릅니다.
  5. 요금제 화면에서 내 플랜의 한도를 확인합니다.
  • 유료는 한 달만 써 보고 계속할지 정합니다.
  • 무료 범위는 영상마다 설명이 달라 앱 안 요금제 화면이 정확합니다.

웹 검색·딥 리서치 켜기

Claude 앱

검색 없이는 학습 이후의 정보를 알 수 없습니다. 웹 검색을 켜면 출처 링크를 받고, 깊은 조사는 리서치 모드를 씁니다.

따라 하기

  1. 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 깊은 조사는 +에서 리서치(예전 이름 연구)를 켭니다.
  4. 조사 목적과 범위를 적어 요청합니다.
  5. 출처 링크를 직접 열어 확인합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장을 조사해 줘. 주요 제품 5개의 가격, 장단점, 도입 사례를 표로 정리하고 출처를 달아 줘.
  • 최신 영상에서는 /딥리서치 명령도 설명합니다.
