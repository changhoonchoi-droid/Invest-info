개인정보·메모리 설정 점검

Claude

입력한 정보는 대화, 메모리, 제공사 시스템, 모델 학습 중 한 곳 이상으로 갈 수 있습니다. 업무에 쓰기 전에 한 번 점검해 두면 안심하고 쓸 수 있습니다.

따라 하기

  1. 계정·개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 저장된 메모리 중 틀리거나 필요 없는 것은 수정하거나 지웁니다.

  4. 실명이 필요 없는 작업은 이름을 자리표시자로 바꿔 입력합니다.
  5. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜과 데이터 처리 조건을 확인합니다.

  • 개인정보와 기밀 정보는 입력하지 않는 것이 기본입니다.

따라 하기

  1. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 현재 이해 수준을 확인합니다.

  4. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.

내 업무용 프로젝트 만들기

Claude

프로젝트에 역할·대상·톤·형식을 적어 두면 새 채팅에서 주제만 입력해도 같은 형식으로 답이 나옵니다. 반복되는 보고서·메일 업무에 알맞습니다.

따라 하기

  1. 왼쪽 사이드바에서 프로젝트를 찾아 새 프로젝트를 누릅니다.
  2. 작업 단위로 이름을 정합니다(예: 주간 보고서).
  3. 지침 입력 화면에 역할, 대상 독자, 톤, 분량을 적습니다.
  4. 원하는 결과 예시를 함께 붙입니다.
  5. 지침 저장을 누르고 새 채팅에서 주제만 넣어 결과를 확인합니다.
  6. 기대와 다르면 지침을 고쳐 다시 시험합니다.
예시 프롬프트
당신은 직장인 업무 이메일 작성 도우미입니다. 내가 상황만 알려 주면 제목 1줄, 본문 5문장 이내, 마무리 인사 순서로 정중한 어조의 이메일을 써 주세요. 예시: [여기에 평소 쓰던 좋은 이메일 하나 붙여넣기]
  • 지침은 구간별로 나눠 쓰면 더 정확합니다.
  • 예시를 함께 주면 결과가 좋아집니다.

요금제·모델 고르기

Claude

요금은 금액이 아니라 쓰다가 한도에 막히는지로 정합니다. 가벼운 일은 Sonnet, 복잡한 조사는 상위 모델로 나눠 쓰면 사용량을 아낍니다.

따라 하기

  1. 무료 플랜으로 업무에 며칠 써 봅니다.
  2. 한도에 자주 막히면 Pro로 올립니다.
  3. 질문창의 모델 전환 메뉴를 엽니다.
  4. 메일·요약은 Sonnet, 복잡한 조사는 유료 플랜의 상위 모델을 고릅니다.
  5. 결과가 부족하면 같은 질문을 상위 모델로 다시 돌려 비교합니다.
  6. 유료로 올렸다면 한 달 뒤 본전이 나오는지 따져 계속할지 정합니다.
  • 요금과 제공 범위는 바뀔 수 있으니 결제 전 공식 요금 페이지를 확인하세요.

웹 검색·딥 리서치 켜기

Claude

모델은 훈련 이후 사실을 검색 없이는 확실히 모릅니다. 최신 정보는 웹 검색, 시장 조사처럼 깊은 조사는 딥 리서치를 씁니다.

따라 하기

  1. 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 깊은 조사는 /딥리서치를 입력하거나 + → 리서치를 선택합니다.
  4. 조사 목적과 범위를 적어 요청합니다.
  5. 출처 링크를 열어 중요한 숫자는 직접 확인합니다.
예시 프롬프트
/딥리서치 국내 중소기업이 쓰는 협업 툴 시장 현황과 주요 경쟁사 3곳을 비교해서 정리해 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석에 유용합니다.

답변 검증하는 습관

Claude

AI는 그럴듯하지만 틀린 내용을 말하거나 사용자에게 맞춰 동의할 수 있습니다. 중요도에 따라 확인 강도를 정하는 습관이 필요합니다.

따라 하기

  1. 틀렸을 때 생길 일을 떠올려 확인 강도를 정합니다.
  2. 미리 모르면 모른다고 말해 달라고 허용합니다.
  3. 출처를 요청하고 직접 열어 실제 내용을 확인합니다.
  4. 원하는 답을 흘리지 말고 중립적으로 질문합니다.
  5. 새 대화를 열어 같은 답의 오류를 찾아 달라고 합니다.
  6. 중요한 작업은 믿을 만한 자료나 다른 AI로 교차 확인합니다.
예시 프롬프트
방금 답에서 구체적인 숫자와 인용마다 출처를 붙여 줘. 확신이 낮은 부분은 따로 표시해 줘.
  • 숫자·날짜·인용은 특히 다시 확인합니다.
  • 자신 있는 말투가 정확성의 증거는 아닙니다.
