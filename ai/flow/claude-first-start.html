가입하고 첫 대화 해 보기

Claude

Claude는 무료로 시작할 수 있으니 먼저 써 보고, 한도에 막힐 때 유료를 고민하면 됩니다. 완벽한 질문보다 친구에게 말하듯 던지고 고쳐 달라고 하는 습관이 중요합니다.

따라 하기

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 질문창의 모델 선택에서 기본 작업은 Sonnet을 고릅니다.
  4. 질문창의 마이크를 눌러 말로 질문합니다.
  5. 답을 보고 "더 짧게", "표로 정리해 줘"처럼 고쳐 달라고 이어서 요청합니다.
예시 프롬프트
나는 마케팅 팀 직장인이야. 오늘 팀장님께 보낼 주간 보고 메일 초안을 쓰려고 하는데, 먼저 필요한 정보를 3가지만 물어봐 줘.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.
  • 타이핑 대신 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.

데이터 학습 설정 점검하기

Claude

업무에 쓰기 전에 내 대화가 모델 학습에 쓰이지 않는지, 메모리에 무엇이 저장되는지 확인합니다. 한 번만 점검해 두면 안심하고 쓸 수 있습니다.

따라 하기

  1. Claude 설정에서 개인정보·데이터 컨트롤 관련 항목을 찾습니다.
  2. 모델 개선(학습) 사용 토글이 있으면 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 항목을 함께 확인합니다.
  4. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  5. 필요 없는 실명은 빼고 자리표시자로 바꿔서 입력합니다.
  • 메뉴 위치와 이름은 화면마다 다를 수 있으니 설정 안에서 데이터 관련 항목을 직접 찾아보세요.
  • 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜과 데이터 처리 조건을 확인하세요.

Claude에게 나를 알려 주기

Claude

AI는 내 업무와 상황을 알수록 답이 정확해집니다. Claude가 나에게 질문하게 하면 설명할 내용을 떠올리기도 쉽습니다.

따라 하기

  1. AI가 나에 대해 아는 것을 한 문단으로 설명해 보라고 요청합니다.
  2. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  3. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 봐. 내 업무와 일하는 방식을 파악해서 나중에 도움이 되게 하고 싶어.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓아 줍니다.

프로젝트로 업무 공간 만들기

Claude

프로젝트에 역할·톤·형식을 적어 두면 새 대화에서 주제만 입력해도 같은 형식으로 답이 나옵니다. 반복되는 업무마다 배경을 다시 설명하지 않아도 됩니다.

따라 하기

  1. 왼쪽 사이드바에서 프로젝트를 찾아 새 프로젝트를 누릅니다.
  2. 프로젝트 이름을 업무 단위로 정합니다(예: 주간 보고).
  3. 지침 입력 화면에서 역할, 대상 독자, 톤, 형식을 적습니다.
  4. 평소 쓰던 좋은 결과물 예시를 함께 붙입니다.
  5. 프로젝트 안에서 새 채팅을 열고 주제만 입력해 결과를 확인합니다.
  6. 결과가 기대와 다르면 지침을 고쳐 다시 시험합니다.
예시 프롬프트
당신은 직장인 업무 이메일 작성 도우미입니다. 내가 상황만 알려 주면 제목 1줄, 본문 5문장 이내, 마무리 인사 순서로 정중한 어조의 이메일을 써 주세요. 예시: [여기에 평소 쓰던 좋은 이메일 하나 붙여넣기]
  • 예시를 함께 주면 결과가 좋아집니다.
  • 지침은 구간별로 나눠 쓰면 더 정확합니다.

웹 검색·딥 리서치로 조사하기

Claude

최신 정보나 시장 조사가 필요할 때 웹 검색과 딥 리서치를 켭니다. 출처 링크가 달려 확인하기 쉽습니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 깊은 조사가 필요하면 + 버튼에서 리서치(또는 연구)를 눌러 딥 리서치 모드를 켭니다.
  4. 조사할 주제와 원하는 결과 형태를 적어 요청합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 조사해서 가격, 강점, 약점을 표로 정리하고 출처 링크를 달아 줘.
  • 메뉴 이름이 화면마다 리서치·연구로 다를 수 있습니다.
  • 의심되는 답은 근거 자료를 요구하세요.

답변 검증하고 다듬기

Claude

AI는 그럴듯하지만 틀린 내용을 말할 수 있습니다. 중요도에 따라 확인 강도를 정하고, 숫자·날짜·인용은 직접 대조합니다.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 스스로 묻고 확인 강도를 정합니다.
  2. 미리 모르면 모른다고 말해 달라고 알려 줍니다.
  3. 주장마다 근거가 되는 출처를 요청합니다.
  4. 제시된 출처를 직접 열어 내용을 확인합니다.
  5. 결과를 "더 짧게", "표로" 등으로 다듬어 최종본을 만듭니다.
예시 프롬프트
아래 답변에서 주장마다 근거가 되는 출처를 찾아 줘. 확실하지 않은 부분은 모른다고 말해도 괜찮아. 틀릴 가능성이 있는 부분도 알려 줘.
  • 숫자·날짜·인용·최신 사건은 특히 다시 확인합니다.
  • AI가 없는 출처를 만들어 낼 수도 있습니다.
