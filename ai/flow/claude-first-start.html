가입하고 첫 질문하기

Claude 앱

Claude는 무료로 시작할 수 있어 부담이 없습니다. 먼저 가입하고 데스크톱 앱까지 설치해 두면 이후 폴더 접근 같은 기능을 쓸 수 있습니다.

따라 하기

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기로 가입합니다.
  3. 필요하면 데스크톱 앱 다운로드로 앱을 설치합니다.
  4. 질문창의 모델 선택에서 기본 작업용으로 Sonnet을 고릅니다.
  5. 질문창의 마이크를 눌러 말로 첫 질문을 해 봅니다.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤, 답을 보고 고쳐 달라고 하면 됩니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.

업무용 안전 설정 확인하기

Claude 앱

회사 일에 쓰기 전에 대화가 모델 학습에 쓰이는지, 메모리가 켜져 있는지 확인합니다. 민감한 정보는 설정과 관계없이 입력하지 않는 것이 안전합니다.

따라 하기

  1. 설정(Settings)에서 데이터 컨트롤 쪽 메뉴로 들어갑니다.
  2. 모델 개선(학습) 관련 항목을 찾아 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 설정도 함께 확인합니다.
  4. 저장된 메모리가 있으면 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  5. 실명 같은 정보는 자리표시자로 바꿔 입력하는 습관을 들입니다.
  • 영상에서 메뉴 위치와 이름을 정확히 기억하지 못한다고 했습니다. 화면에서 비슷한 항목을 찾아보세요.
  • 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 확인합니다.

AI에게 나를 알려 주기

Claude 데스크톱 앱

AI가 좋은 답을 하려면 나에 대한 맥락이 필요합니다. 첫날 질문을 주고받으며 내 일과 기준을 알려 주면 이후 답변 품질이 달라집니다.

따라 하기

  1. Claude 데스크톱 앱에서 폴더 접근을 허락합니다.
  2. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 현재 수준을 확인합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청합니다.
  4. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 인터뷰를 받습니다.
  5. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 봐. 한 번에 다섯 개씩 물어봐 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 하루 30분씩 서로 질문을 주고받는 습관이 맥락을 쌓아 줍니다.

말로 맥락 많이 주기

Claude 앱

완벽한 프롬프트보다 상황과 기준을 충분히 알려 주는 것이 중요합니다. 음성 입력과 자료 첨부를 쓰면 시간도 줄고 생각도 정리됩니다.

따라 하기

  1. 타이핑 대신 음성 받아쓰기로 상황, 목적, 기준을 길게 말합니다.
  2. 관련 파일이나 화면 캡처를 많이 붙입니다.
  3. AI가 낸 결과를 직접 읽고 맞는지 판단합니다.
  4. 부족한 부분은 기준을 더 알려 주어 다시 요청합니다.
예시 프롬프트
지금 상황을 설명할게. 나는 중소기업 영업팀 대리이고, 다음 주 고객사 제안 발표를 준비 중이야. 첨부한 자료를 보고 발표 흐름을 제안해 줘. 기준은 10분 안에 끝나고 비전문가도 이해할 수 있어야 해.
  • 중요한 두 가지는 맥락을 많이 주는 것과 결과를 판단하는 능력입니다.

프로젝트 만들고 지침 넣기

Claude 앱

프로젝트는 작업별 맥락을 모아 두는 공간입니다. 지침과 관련 문서를 한 번 넣어 두면 대화마다 같은 프롬프트를 반복하지 않아도 됩니다.

따라 하기

  1. 화면 왼쪽 프로젝트 옆 +를 눌러 새 프로젝트를 만듭니다.
  2. 강의, 리서치, 보고서처럼 용도별로 프로젝트를 나눕니다.
  3. 커스텀 지침에 대상, 톤 등 원하는 응답 방식을 적습니다.
  4. 지침 저장을 누릅니다.
  5. 관련 문서를 파일로 업로드하고 프로젝트 안에서 대화를 시작합니다.
예시 프롬프트
이 프로젝트는 신입 사원 교육 자료를 만드는 작업이야. 대상은 입사 1년 차 직장인이고, 톤은 친절하고 쉬운 존댓말로 해 줘. 업로드한 문서를 근거로 답하고, 근거가 없으면 모른다고 말해 줘.
  • 프로젝트는 맥락을, 스킬은 작업 방식을, 커넥터는 외부 도구를 맡는다고 구분하면 이해하기 쉽습니다.

메모리와 이어 가기 활용

Claude 앱

메모리는 계정에 저장된 정보를 참고하는 기능입니다. 선호를 기록해 두고, 채팅창이 바뀌어 기억이 사라질 때는 이전 대화를 가져오게 합니다.

따라 하기

  1. 사용하는 제품에서 메모리 기능이 켜져 있는지 확인합니다.
  2. 기억시킬 내용을 AI에게 기록해 두라고 요청합니다.
  3. 저장된 내용을 확인하고 틀린 것은 편집·삭제합니다.
  4. 새 채팅에서는 이전 대화 내용을 찾아 달라고 요청합니다.
  5. 가져온 내용이 맞는지 직접 읽고 확인합니다.
예시 프롬프트
앞으로 보고서를 쓸 때는 결론을 먼저 쓰고, 문장은 짧게 써 줘. 이 선호를 기억해 줘.
  • 민감한 정보는 메모리에 남기지 않는 것이 안전합니다.
  • 채팅창이 바뀌면 기억 일부가 사라집니다.

답변 검증 습관 들이기

Claude 앱

AI는 그럴듯하지만 사실이 아닌 내용을 말할 수 있습니다. 틀렸을 때의 위험에 따라 확인 강도를 정하고, 출처를 직접 열어 보는 습관이 필요합니다.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 스스로 묻고 확인 강도를 정합니다.
  2. 주장마다 근거가 되는 출처를 요청합니다.
  3. 제시된 출처를 직접 열어 실제 내용을 확인합니다.
  4. 찬성과 반대 논거를 중립적으로 묻습니다.
  5. 의심스러우면 새 대화나 다른 AI로 교차 검증합니다.
예시 프롬프트
이 결정에 대한 가장 강력한 찬성과 반대 논거는 무엇인가요? 모르면 모른다고 말해 줘도 괜찮아. 각 주장의 출처도 알려 줘.
  • 숫자·날짜·인용은 특히 다시 확인하세요.
  • 최신 정보는 웹 검색을 켜고, 했는지 직접 물어봅니다.
