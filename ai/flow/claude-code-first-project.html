권한 모드 이해하기

Claude Code

기본은 파일 수정·명령 실행 전에 허락을 묻습니다. 모드를 바꿔 맡기는 범위를 조절하고, 처음에는 승인 모드로 모든 단계를 확인하는 편이 안전합니다.

따라 하기

  1. 실행 중 Shift + Tab을 누릅니다.
  2. 기본 모드는 파일 수정·명령 실행 전에 매번 묻습니다.
  3. Auto accept edits는 수정은 묻지 않고 명령 실행은 묻습니다.
  4. Plan mode는 읽기만 하며 계획을 세웁니다.
  5. 입력창 아래 표시로 현재 모드를 확인합니다.
  • 권한을 건너뛰면 실수를 미리 잡기 어려우니 신중히 사용합니다.

계획 모드로 방향 잡기

Claude Code

계획 모드에서는 파일을 수정하지 않고 읽고 조사해 계획을 세웁니다. 코드가 쓰이기 전이 방향을 고치기 가장 좋은 시점입니다.

따라 하기

  1. Shift+Tab을 눌러 plan mode가 표시될 때까지 전환합니다.
  2. 구현하려는 내용과 알고 싶은 점을 구체적으로 요청합니다.
  3. Claude가 내놓은 계획을 검토합니다.
  4. 부족하면 추가·수정을 요청합니다.
  5. 좋으면 승인하고 수정 자동 수락 여부를 고릅니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들 계획을 먼저 세워 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 프롬프트는 가능한 한 구체적으로 씁니다.

자료 첨부해 결과물 만들기

Claude Code

개발 지식 없이도 파일을 첨부하고 풀어 써서 요청하면 웹사이트를 만들 수 있습니다. 어떻게 만들지는 AI에게 맡기고 무엇을 만들지에 집중하세요.

따라 하기

  1. 설문 결과 CSV 같은 자료 파일을 첨부합니다.
  2. 만들고 싶은 결과물과 필요한 기능을 풀어 써서 요청합니다.
  3. 우측 내장 브라우저에서 결과를 확인합니다.
  4. 기본 브라우저에서 열기로 크롬에서 열어 봅니다.
  5. 수정할 점은 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 생각 정리는 채팅, 파일 정리는 코워크, 웹사이트·앱 제작은 코드, 발표 자료는 디자인으로 고릅니다.

CLAUDE.md로 규칙 정하기

Claude Code

CLAUDE.md는 세션 시작 때마다 자동으로 읽히는 규칙 파일입니다. 스택, 명령어, 코드 스타일을 적어 두면 첫 응답부터 품질이 좋아집니다.

따라 하기

  1. 프로젝트 루트에서 /init을 실행해 CLAUDE.md를 생성합니다.
  2. 명령어·코드 스타일 규칙을 확인하고 고칩니다.
  3. 금지 규칙과 주요 폴더 안내를 추가합니다.
  4. 반복해서 바로잡은 규칙은 메모리에 저장하라고 명시적으로 요청합니다.
예시 프롬프트
방금 알려 준 규칙(커밋 메시지는 한국어로 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 지도처럼 씁니다.
  • 자동 생성된 파일은 사람이 검수합니다.
  • CLAUDE.md는 권고이고, 어길 수 없는 규칙은 Hooks로 강제합니다.

컨텍스트 관리하기

Claude Code

읽은 파일과 대화가 컨텍스트를 차지하고, 한도에 가까워지면 자동 압축되어 세부가 사라질 수 있습니다. 직접 관리하면 긴 작업도 안정적입니다.

따라 하기

  1. /context로 크기와 많이 차지하는 항목을 확인합니다.
  2. 같은 기능을 이어갈 때는 /compact로 요약합니다.
  3. 새 기능을 시작할 때는 /clear로 비웁니다.
  4. 다음 세션에도 필요한 내용은 CLAUDE.md에 적습니다.
  5. 쓰지 않는 MCP 서버는 끕니다.
  • 압축하면 이전 대화의 세부 내용이 사라질 수 있습니다.

원격 제어로 어디서나 잇기

Claude Code

내 컴퓨터에서 도는 세션에 웹이나 모바일로 접속해 이어 작업합니다. 도구와 파일은 내 컴퓨터에서 실행되므로 컴퓨터가 켜져 있어야 합니다.

따라 하기

  1. 프로젝트 디렉터리에서 claude remote-control을 실행합니다.
  2. 표시된 URL을 Claude Code 웹에서 엽니다.
  3. 스페이스바로 나오는 QR 코드를 휴대폰으로 스캔합니다.
  4. 이미 실행 중인 세션은 /remote-control을 입력해 URL로 접속합니다.
  • 영상 기준 일부 플랜부터 제공됐으니 내 플랜에서 되는지 확인하세요.
  • 컴퓨터를 꺼도 돌리려면 클라우드 세션이 대안입니다.
