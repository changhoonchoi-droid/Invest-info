Claude Code 설치하고 로그인하기

Claude Code

터미널이 낯설다면 데스크톱 앱이나 편집기 확장으로 시작해도 됩니다. 실행한 폴더 전체에 접근 권한이 생기니 위치를 확인합니다.

따라 하기

  1. macOS·Linux·WSL은 안내된 curl 설치 명령을 실행합니다.
  2. Windows PowerShell은 Invoke-RestMethod 명령을 사용합니다.
  3. VS Code는 확장 패널에서 Anthropic이 만든 Claude Code를 설치합니다.
  4. 데스크톱 앱은 상단 Code 토글(코드 탭)로 전환합니다.
  5. 프로젝트 폴더로 이동해 실행합니다.
  6. 처음 실행 시 테마를 고르고 Claude 계정으로 로그인합니다.
  • Homebrew와 winget 설치는 자동 업데이트가 되지 않습니다.
  • 처음에는 데스크톱 앱으로 시작하고 익숙해지면 CLI로 넘어가는 것을 추천합니다.

권한 모드 이해하기

Claude Code

기본적으로 파일 수정이나 명령 실행 전에 허락을 묻습니다. 모드를 바꿔 맡기는 범위를 조절하되, 처음에는 승인 모드가 안전합니다.

따라 하기

  1. 실행 중 Shift + Tab을 누릅니다.
  2. 기본 모드는 수정·명령 전에 매번 묻습니다.
  3. Auto accept edits는 파일 수정은 묻지 않고 명령은 묻습니다.
  4. Plan mode는 읽기 전용으로 계획을 먼저 세웁니다.
  5. 입력창 아래에 표시되는 현재 모드를 확인합니다.
  • 권한을 건너뛰면 실수를 미리 잡기 어렵습니다.

계획 모드로 방향 잡기

Claude Code

계획 모드에서는 Claude가 파일을 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전이 방향을 고치기 가장 좋은 시점입니다.

따라 하기

  1. 프로젝트 루트에서 Claude Code를 엽니다.
  2. Shift+Tab으로 plan mode 표시가 나올 때까지 전환합니다.
  3. 구현할 내용과 알고 싶은 점을 구체적으로 요청합니다.
  4. Claude가 내놓은 계획을 검토합니다.
  5. 부족하면 추가·수정을 요청합니다.
  6. 좋으면 승인하고 자동 수락 여부를 고릅니다.
예시 프롬프트
앱 전체에 다크 모드를 넣고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마에 어울리는 대비 색을 쓰는 계획을 먼저 세워 줘.
  • 프롬프트는 가능한 한 구체적으로 씁니다.

CLAUDE.md로 프로젝트 규칙 정하기

CLAUDE.md

CLAUDE.md는 세션을 시작할 때마다 자동으로 읽힙니다. 스택, 명령어, 스타일을 적어 두면 첫 응답부터 품질이 좋아집니다.

따라 하기

  1. 프로젝트 루트에서 Claude Code를 실행합니다.
  2. /init으로 CLAUDE.md를 생성합니다.
  3. 스택·명령어·스타일 규칙을 확인하고 고칩니다.
  4. 금지 규칙과 주요 폴더 안내를 추가합니다.
  5. 참고 문서는 @와 파일 경로로 연결합니다.
  6. 반복해서 바로잡은 규칙은 저장하라고 명시적으로 요청합니다.
예시 프롬프트
방금 알려 준 규칙(커밋 메시지는 한국어로 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 지도처럼 씁니다.
  • 자동 생성된 파일은 사람이 검수합니다.
  • 어길 수 없는 규칙은 Hooks로 강제합니다.

실행 결과 검증하기

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 웹 화면은 크롬 확장으로 직접 테스트하게 할 수 있습니다.

따라 하기

  1. 계획에 올바른 결과의 성공 기준을 적습니다.
  2. 웹 UI라면 Claude in Chrome 확장을 설치합니다.
  3. 테스트 스위트를 프로젝트에 둡니다.
  4. 직접 확인해 만족하면 서브에이전트 코드 리뷰어로 점검합니다.
  5. 오류가 나면 콘솔 메시지와 발생 시점, 기대 동작을 함께 전달합니다.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하게 하세요.

컨텍스트 관리하고 커밋하기

Claude Code

컨텍스트가 차면 세부 내용이 사라질 수 있습니다. 작업 상황에 맞게 정리하고 마지막에 커밋 메시지까지 맡깁니다.

따라 하기

  1. /context로 컨텍스트 크기를 확인합니다.
  2. 같은 기능을 이어 갈 때는 /compact로 요약합니다.
  3. 새 기능을 시작할 때는 /clear로 비웁니다.
  4. 쓰지 않는 MCP 서버는 끕니다.
  5. 내 스타일에 맞는 커밋 메시지를 만들게 한 뒤 푸시합니다.
  • 압축하면 이전 대화의 세부 내용이 사라질 수 있습니다.
  • 다음 세션에도 기억시킬 내용은 CLAUDE.md에 적습니다.
