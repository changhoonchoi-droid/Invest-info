설치하고 첫 로그인하기

Claude Code

터미널이 낯설면 데스크톱 앱으로 시작하고 익숙해지면 터미널로 넘어가는 것을 영상은 권합니다. 실행한 폴더와 하위 폴더 전체에 접근 권한이 생깁니다.

따라 하기

  1. Windows PowerShell은 Invoke-RestMethod 설치 명령을, macOS·Linux는 curl 명령을 실행합니다.
  2. VS Code는 확장에서 Anthropic의 Claude Code를 설치합니다.
  3. 데스크톱은 Code 토글(코드 탭)로 전환합니다.
  4. 작업 폴더로 이동해 실행합니다.
  5. 테마를 고르고 Claude 계정으로 로그인합니다.
  • Homebrew·winget 설치는 자동 업데이트가 되지 않습니다.
  • 폴더 위치를 확인하고 실행합니다.

권한 모드 이해하기

Claude Code

기본은 수정·명령 전에 허락을 묻습니다. Shift + Tab으로 모드를 바꿔 맡길 범위를 조절합니다.

따라 하기

  1. 실행 중 Shift + Tab을 누릅니다.
  2. 기본 모드는 매번 허락을 묻는지 확인합니다.
  3. Auto accept edits는 수정만 자동 수락합니다.
  4. Plan mode는 읽기만 하며 계획을 세웁니다.
  5. 현재 모드가 입력창 아래에 표시되는지 확인합니다.
  • 처음에는 승인 모드로 단계를 직접 확인합니다.
  • 권한을 건너뛰면 실수를 미리 잡기 어렵습니다.

CLAUDE.md로 규칙 정하기

Claude Code

스택·명령어·코드 스타일을 적어 두면 첫 응답부터 품질이 좋아집니다. 자동 생성된 파일은 사람이 검수합니다.

따라 하기

  1. 프로젝트 루트에서 Claude Code를 실행합니다.
  2. /init으로 CLAUDE.md를 생성합니다.
  3. 스택·명령어·스타일 규칙을 확인하고 고칩니다.
  4. 금지 규칙과 주요 폴더 안내를 추가합니다.
  5. 반복해서 바로잡은 규칙은 저장하라고 요청합니다.
예시 프롬프트
방금 알려 준 규칙(커밋 메시지는 한국어로 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 매뉴얼이 아니라 지도처럼 씁니다.
  • 어길 수 없는 규칙은 Hooks로 강제합니다.

계획 모드로 계획 받기

Claude Code

계획 모드에서는 파일을 수정하지 않고 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전이 방향을 고치기 가장 좋은 때입니다.

따라 하기

  1. Shift+Tab으로 plan mode로 전환합니다.
  2. 구현할 내용과 알고 싶은 점을 구체적으로 요청합니다.
  3. Claude가 읽고 조사해 내놓은 계획을 검토합니다.
  4. 부족하면 추가·수정을 요청합니다.
  5. 좋으면 승인하고 자동 수락 여부를 고릅니다.
예시 프롬프트
앱 전체에 다크 모드를 넣고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마에 어울리는 대비 색을 쓰는 계획을 먼저 세워 줘.
  • 프롬프트는 가능한 한 구체적으로 씁니다.

컨텍스트 관리하며 구현

Claude Code

읽은 파일과 대화가 모두 작업 기억을 차지합니다. 한도에 가까워지면 자동 압축되어 세부가 사라질 수 있어 직접 관리합니다.

따라 하기

  1. /context로 사용량과 큰 항목을 확인합니다.
  2. 같은 기능을 이어갈 때는 /compact로 요약합니다.
  3. 새 기능을 시작할 때는 /clear로 비웁니다.
  4. 다음 세션에도 필요한 내용은 CLAUDE.md에 적습니다.
  5. 쓰지 않는 MCP 서버는 끕니다.
  • 프롬프트가 너무 짧으면 탐색이 늘어 오히려 컨텍스트를 더 씁니다.

검증하고 커밋하기

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 반복되는 확인 절차는 스킬로 저장합니다.

따라 하기

  1. 계획에 성공 기준을 분명히 적습니다.
  2. 웹 UI는 Claude in Chrome으로 직접 테스트하게 합니다.
  3. 테스트 스위트를 두어 계속 검증하게 합니다.
  4. 확인 절차를 스킬로 저장해 재사용합니다.
  5. 커밋 메시지를 만들게 한 뒤 푸시합니다.
  • 같은 실수는 다시 시키지 말고 CLAUDE.md나 스킬에 적습니다.
  • 확인 기준이 측정 가능할수록 Claude가 더 멀리 혼자 갑니다.
