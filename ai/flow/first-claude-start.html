무료로 시작해 요금제 정하기

Claude 앱

AI 구독은 금액이 아니라 한도에 막히는지로 정합니다. 먼저 무료로 써 보고 불편해질 때 유료로 올리면 낭비가 없습니다.

따라 하기

  1. 무료 플랜으로 Claude를 일주일 정도 씁니다.
  2. 사용 한도에 자주 걸려 일이 막히는지 확인합니다.
  3. 막힌다면 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다.
  4. 코워크·코드·디자인은 Pro 이상에서 쓸 수 있음을 기억합니다.
  5. 가격과 한도는 바뀔 수 있으니 결제 전 공식 요금 페이지를 확인합니다.
  • 무료 플랜에서는 Opus를 쓸 수 없습니다.
  • Pro로도 부족하면 그때 Max를 검토합니다.

개인정보 설정 점검하기

Claude 앱

입력한 정보는 대화, 메모리, 제공사 시스템, 모델 학습으로 갈 수 있습니다. 회사 일에 쓰기 전에 설정을 확인해 통제력을 지킵니다.

따라 하기

  1. Settings에서 메모리, 대화 기록, 연결된 앱, 학습 관련 토글을 확인합니다.
  2. 모델 개선에 대화를 쓰는 항목을 찾아 끕니다.
  3. 저장된 메모리를 읽고 틀린 것은 고치고 필요 없는 것은 지웁니다.
  4. 메일 문구 다듬기처럼 필요 없는 실명은 자리표시자로 바꿉니다.
  5. 기밀·규제 데이터는 비즈니스·엔터프라이즈 플랜과 데이터 처리 조건을 확인합니다.
  • 항목 이름은 서비스마다 다르니 설정 안에서 직접 찾아보세요.
  • 설정은 한 번으로 끝내지 말고 주기적으로 다시 점검합니다.

나를 알려 주며 첫 대화하기

Claude 앱

AI를 잘 쓰는 핵심은 나에 대한 맥락을 주는 것입니다. 첫날 몇 가지 질문으로 AI가 나를 파악하고 도울 일을 제안하게 만듭니다.

따라 하기

  1. Claude 앱에서 "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 묻습니다.
  2. "너는 뭘 할 수 있니?"라고 묻습니다.
  3. "나에 대해서 궁금한 거 100개까지 물어봐 봐"로 인터뷰를 받습니다.
  4. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 줘. 내가 하나씩 답할게. 다 끝나면 네가 나를 도와줄 수 있는 일을 알려 줘.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던지세요.
  • 하루 30분 정도 주고받는 습관이 맥락을 쌓습니다.

프로젝트에 지침 저장하기

Claude 앱

새 대화는 빈 상태로 시작하므로 매번 반복하는 정보는 프로젝트에 넣어 둡니다. 대상 독자, 말투, 참고 문서를 한 번만 적으면 됩니다.

따라 하기

  1. Claude에서 프로젝트를 새로 만듭니다.
  2. 커스텀 지침 칸에 대상, 말투, 분량을 적습니다.
  3. 지침 저장을 누릅니다.
  4. 참고할 문서를 파일로 업로드합니다.
  5. 프로젝트 안에서 새 대화를 열어 작업을 요청합니다.
  6. 결과가 다르면 지침을 고쳐 다시 저장합니다.
예시 프롬프트
대상: 40대 직장인. 톤: 쉽고 친근한 존댓말, 전문 용어는 한 줄 풀이를 붙일 것. 형식: 소제목 3~5개. 업로드한 자료에 없는 수치는 지어내지 말 것.
  • 용도별로 프로젝트를 나누면 편합니다.

웹 검색으로 최신 정보 조사하기

Claude 앱

AI는 훈련 이후의 사실을 검색 없이는 확실히 모릅니다. 웹 검색과 연구 모드를 켜면 출처 링크가 붙은 답을 받습니다.

따라 하기

  1. 입력창의 + 버튼을 누릅니다.
  2. 웹 탭으로 웹 검색을 켭니다.
  3. 깊은 조사는 +에서 연구를 눌러 딥 리서치를 켭니다.
  4. 주제와 원하는 결과 형태를 요청합니다.
  5. 출처 링크를 직접 열어 확인합니다.
예시 프롬프트
국내 사무용 협업 도구 시장의 주요 경쟁사 세 곳을 비교하고, 가격과 장단점을 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석에 유용합니다.

답변 검증하고 다듬기

Claude 앱

AI는 그럴듯하지만 틀린 내용을 말할 수 있습니다. 틀렸을 때의 위험에 따라 확인 강도를 정하고 초안을 다듬습니다.

따라 하기

  1. 틀렸을 때 어떤 일이 생길지 보고 확인 강도를 정합니다.
  2. 모르면 모른다고 말해도 된다고 미리 알려 줍니다.
  3. 주장마다 출처를 요청하고 직접 열어 확인합니다.
  4. 초안은 여러 버전이나 다른 어조로 요청합니다.
  5. 중요한 내용은 새 대화나 다른 AI로 교차 확인합니다.
예시 프롬프트
나는 영업팀 대리이고, 내일 거래처에 보낼 안내 메일을 쓰는 중이야. 정중하지만 짧게, 세 가지 버전으로 초안을 써 줘. 모르는 부분은 모른다고 말해 줘.
  • 숫자·날짜·인용은 반드시 직접 확인합니다.
  • 자신 있는 말투는 정확성의 증거가 아닙니다.
