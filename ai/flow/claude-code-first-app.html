Claude Code 설치하고 로그인

Claude Code

Claude Code는 터미널, VS Code, JetBrains, 데스크톱 앱, 웹에서 쓸 수 있습니다. 터미널이 낯설면 데스크톱 앱으로 시작하고 익숙해지면 CLI로 넘어가는 것을 영상에서 추천했습니다.

따라 하기

  1. macOS·Linux·WSL에서는 안내된 curl 설치 명령을 한 번에 실행합니다.
  2. Windows PowerShell에서는 안내된 Invoke-RestMethod 명령을 사용합니다.
  3. VS Code는 확장 패널에서 Claude Code를 검색해 Anthropic이 만든 파란 체크 표시 확장을 설치합니다.
  4. 데스크톱 앱은 Claude Desktop 상단의 Code 토글(또는 코드 탭)로 전환합니다.
  5. 처음 실행 시 색상 테마를 고르고 Claude 계정 또는 API 키로 로그인합니다.
  • Homebrew와 winget으로 설치하면 자동 업데이트가 되지 않습니다.
  • 실행한 폴더와 그 하위 폴더 전체에 접근 권한이 생기므로 폴더 위치를 확인하고 실행하세요.
  • 웹(claude.ai/code)은 GitHub 저장소만 지원합니다.

데스크톱 앱으로 첫 결과물

Claude 데스크톱 앱

폴더를 지정하고 파일을 첨부해 요청하면 개발 지식 없이도 대시보드 같은 웹사이트를 만들 수 있습니다. 어떻게 만들지는 AI에 맡기고 무엇을 만들지에 집중하세요. 코드 기능은 프로 플랜 이상에서 쓸 수 있습니다.

따라 하기

  1. 클로드 데스크톱 앱에서 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정하고 워크스페이스 신뢰를 진행합니다.
  3. 설문 결과 CSV 같은 자료 파일을 첨부합니다.
  4. 만들고 싶은 결과물과 필요한 기능을 풀어 써서 요청합니다.
  5. 우측 내장 브라우저에서 결과를 확인하고 필요하면 기본 브라우저에서 열기로 크롬에서 엽니다.
  6. 수정할 점은 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 생각 정리는 채팅, 파일 정리는 코워크, 웹사이트·앱 제작은 코드, 발표 자료는 디자인으로 고릅니다.

계획 모드와 권한 모드 쓰기

Claude Code

기본 상태에서는 파일 수정이나 명령 실행 전에 허락을 묻습니다. 계획 모드에서는 Claude가 읽기만 하며 계획을 세우므로 코드가 쓰이기 전에 방향을 고칠 수 있어 큰 작업에 알맞습니다.

따라 하기

  1. Claude Code 실행 중 Shift + Tab을 눌러 모드를 전환합니다.
  2. 기본(승인) 모드는 파일 수정·셸 명령 전에 매번 허락을 묻습니다.
  3. Auto accept edits 모드는 파일 수정은 묻지 않고 명령 실행은 계속 묻습니다.
  4. 입력창 아래에 plan mode가 표시되면 구현하려는 내용을 구체적으로 요청합니다.
  5. 제시된 계획을 검토하고 부족하면 수정을 요청합니다.
  6. 계획이 좋으면 승인하고 파일 수정을 자동 수락할지 매번 물을지 고릅니다.
예시 프롬프트
앱 전체에 다크 모드를 넣고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마에 어울리는 대비 색을 쓰는 계획을 먼저 세워 줘.
  • 모든 단계를 직접 확인하고 싶으면 승인 모드를 유지합니다.
  • 권한을 건너뛰면 실수를 미리 잡기 어려우니 신중히 사용하세요.

CLAUDE.md로 규칙 저장하기

CLAUDE.md

CLAUDE.md는 프로젝트 루트에 두는 마크다운 파일로 Claude Code가 세션마다 자동으로 읽습니다. 규칙을 적어 두면 첫 응답부터 품질이 좋아집니다.

따라 하기

  1. 프로젝트 루트 폴더에서 Claude Code를 실행합니다.
  2. /init 명령을 실행해 코드베이스를 바탕으로 CLAUDE.md를 생성합니다.
  3. 스택, 개발 서버·테스트·린트 명령어, 코드 스타일 규칙을 확인하고 필요한 내용을 고칩니다.
  4. 금지 규칙과 주요 폴더 안내를 추가합니다.
  5. 작업 중 반복해서 바로잡은 규칙은 Claude에게 저장하라고 명시적으로 요청합니다.
예시 프롬프트
방금 알려 준 규칙(커밋 메시지는 한국어로 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 매뉴얼이 아니라 지도처럼 씁니다.
  • 자동 생성된 설정 파일은 사람이 검수하세요.
  • CLAUDE.md는 권고이고, 어길 수 없는 규칙은 Hooks로 강제합니다.

에러를 잘 전달해 고치기

Claude Code

바이브코딩 중 에러가 났을 때는 단서를 많이 줄수록 잘 고쳐집니다. 콘솔 메시지와 언제 발생하는지를 함께 전달합니다.

따라 하기

  1. 문제 화면에서 마우스 오른쪽 버튼을 눌러 검사를 엽니다.
  2. 개발자 도구의 콘솔 탭의 오류 메시지를 복사하거나 캡처합니다.
  3. 프롬프트 창에 오류 메시지를 붙여 넣습니다.
  4. 언제 발생하는지와 원래 기대하는 동작을 적습니다.
  5. 가능하면 발생 화면 스크린샷도 첨부합니다.
예시 프롬프트
스크롤할 때 아래 오류가 나요. 원래는 부드럽게 내려가야 하는데 화면이 멈춥니다. 오류 메시지와 스크린샷을 첨부합니다.
  • 코딩 중 에러가 나면 고쳐 달라고 요청하면 됩니다.

검증하고 커밋까지 마무리

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 마지막에 리뷰와 커밋 메시지까지 맡겨 작업을 매듭짓습니다.

따라 하기

  1. 계획에 무엇이 올바른 결과인지 성공 기준을 분명히 적습니다.
  2. 웹 UI라면 Claude in Chrome 확장을 설치해 Claude가 탭에서 직접 테스트하게 합니다.
  3. Claude가 계속 검증할 수 있는 테스트 스위트를 프로젝트에 둡니다.
  4. 직접 확인해 만족하면 서브에이전트 코드 리뷰어로 코드를 점검합니다.
  5. Claude에게 내 스타일에 맞는 커밋 메시지를 만들게 한 뒤 푸시합니다.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청하세요.
  • 통과 기준이 측정 가능할수록 Claude가 더 멀리 혼자 갑니다.

컨텍스트 확인하고 정리하기

Claude Code

컨텍스트는 Claude의 작업 기억으로, 한도에 가까워지면 자동 압축되어 세부 내용이 사라질 수 있습니다. 직접 관리하면 긴 작업에서도 품질이 유지됩니다.

따라 하기

  1. /context를 실행해 컨텍스트 크기와 가장 많이 차지하는 항목을 확인합니다.
  2. 같은 기능 작업을 계속해야 하면 /compact로 지금까지 내용을 요약합니다.
  3. 새 기능을 시작할 때는 /clear로 대화를 완전히 비웁니다.
  4. 다음 세션에도 기억시킬 내용은 CLAUDE.md에 적습니다.
  5. 쓰지 않는 MCP 서버는 끕니다.
예시 프롬프트
/context
  • 압축하면 이전 대화의 세부 내용이 사라질 수 있습니다.
  • 프롬프트를 너무 짧게 쓰면 Claude가 코드베이스를 더 뒤져 오히려 컨텍스트를 더 씁니다.

어디서나 세션 이어가기

Claude Code 원격 제어

원격 제어는 내 컴퓨터에서 실행 중인 세션에 웹이나 모바일 앱으로 접속해 이어 작업하는 기능입니다. 도구와 파일은 내 컴퓨터에서 실행되므로 컴퓨터가 켜져 있어야 합니다.

따라 하기

  1. 프로젝트 디렉터리로 이동합니다.
  2. 터미널에서 claude remote-control을 실행합니다.
  3. 화면에 표시된 URL을 Claude Code 웹에서 엽니다.
  4. 스페이스바를 누르면 나오는 QR 코드를 휴대폰으로 스캔합니다.
  5. 이미 실행 중인 세션은 /remote-control을 입력해 표시된 URL로 접속합니다.
  • 같은 Claude 계정으로 로그인되어 있으면 앱에서 바로 세션을 찾을 수 있습니다.
  • 영상 기준 Max, Team, Enterprise에 제공되고 Pro에는 순차 확대 중이었으니 내 플랜에서 되는지 확인하세요.
  • 컴퓨터를 꺼도 이어 가려면 클라우드 세션이 대안입니다.
