AI에게 나를 알려 주기

Claude

비서의 품질은 내가 준 맥락에 달렸습니다. AI가 나에게 질문하게 해 내 일과 기준을 알려 줍니다.

따라 하기

  1. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 확인합니다.
  2. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청합니다.
  3. 하나씩 답하며 내 역할과 기준을 알려 줍니다.
  4. "네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 봐. 하나씩 물어보고, 내가 답하면 다음 질문으로 넘어가 줘.
  • 마이크로 길게 말하면 타이핑보다 맥락을 더 많이 줄 수 있습니다.

프로젝트로 작업 공간 나누기

Claude

프로젝트는 작업별로 대화와 맥락을 모아 두는 폴더 같은 기능입니다. 용도별로 나누면 같은 설명을 반복하지 않아도 됩니다.

따라 하기

  1. 왼쪽 사이드바에서 프로젝트의 새 프로젝트를 누릅니다.
  2. 이름을 작업 단위로 정합니다 (예: 주간 보고서).
  3. 프로젝트 안에서 새 채팅을 열어 대화를 시작합니다.
  4. 작업이 다르면 별도 프로젝트로 나눕니다.
  • ChatGPT 프로젝트는 영상 기준으로 유료에서 쓸 수 있으니 플랜을 확인하세요.

지침으로 말투·형식 고정

Claude

프로젝트 지침에 역할, 대상, 톤, 형식을 적어 두면 새 채팅에서 주제만 입력해도 같은 형식이 나옵니다.

따라 하기

  1. 프로젝트의 커스텀 지침 입력 화면을 엽니다.
  2. 역할과 대상 독자, 톤을 적습니다.
  3. 구간별 분량과 원하는 결과 예시를 붙입니다.
  4. 지침 저장을 누릅니다.
  5. 새 채팅에서 주제만 입력해 결과를 확인하고 지침을 고칩니다.
예시 프롬프트
당신은 직장인 업무 이메일 작성 도우미입니다. 내가 상황만 알려 주면 제목 1줄, 본문 5문장 이내, 마무리 인사 순서로 정중한 어조의 이메일을 써 주세요. 예시: [여기에 평소 쓰던 좋은 이메일 하나 붙여넣기]
  • 예시를 함께 주면 결과가 좋아집니다.
  • 처음 세팅에는 시간을 들여 맞춰 가세요.

참고 파일 올려 두기

Claude

관련 문서를 프로젝트에 올려 두면 대화가 자료를 바탕으로 이어집니다. 회사 양식이나 기준 문서가 있는 업무에 알맞습니다.

따라 하기

  1. 파일을 올릴 프로젝트를 엽니다.
  2. 관련 문서를 파일로 업로드합니다.
  3. 새 채팅에서 올린 자료를 바탕으로 질문합니다.
  4. 답이 자료와 맞는지 직접 검증합니다.
  • ChatGPT에서는 파일 추가보다 지침이 더 중요했다는 후기가 있으니 비교해 보세요.

메모리 확인하고 관리하기

Claude

메모리는 AI가 계정에 저장해 다음 대화에서 참고하는 정보입니다. 내용을 열어 보고 지우거나 추가해 내가 통제합니다.

따라 하기

  1. 설정에서 메모리 항목을 찾습니다.
  2. 메모리가 켜져 있는지 확인합니다.
  3. 틀리거나 오래된 항목은 삭제합니다.
  4. 꼭 기억시킬 내용은 직접 추가합니다.
  • 민감한 업무 내용은 메모리에 남기지 않도록 주의하세요.

반복 작업을 스킬로 추가

Claude

자주 하는 보고서 같은 양식은 스킬로 저장하면 /로 불러 항상 같은 포맷으로 만듭니다.

따라 하기

  1. 평소 쓰는 양식 파일을 첨부합니다.
  2. "이 형식으로 스킬을 만들어 줘"라고 요청합니다.
  3. 스킬 저장을 누릅니다.
  4. /와 스킬 이름으로 호출해 주제를 넣습니다.
예시 프롬프트
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • AI 티가 나는 문장은 직접 고치세요.

메일·일정 커넥터 연결

Claude

커넥터를 연결하면 비서가 내 메일, 일정, 파일을 읽고 초안을 쓸 수 있습니다.

따라 하기

  1. + → 커넥터 → 커넥터 둘러보기를 엽니다.
  2. Gmail, 구글 캘린더, 구글 드라이브를 연결합니다.
  3. 내 계정으로 로그인해 인증합니다.
  4. 드라이브 파일을 찾아 메일 초안을 써 달라고 시험합니다.
예시 프롬프트
구글 드라이브에서 계약서 파일을 찾아 핵심 조건을 요약하고, 상대방에게 보낼 확인 메일 초안을 써 줘.
  • 메일은 보내기 전에 직접 확인하세요.

예약으로 먼저 일하게 하기

Cowork

예약 작업을 등록하면 비서가 정해진 시각에 먼저 일합니다. 기기가 꺼져 있어도 클라우드에서 실행됩니다.

따라 하기

  1. 먼저 브리핑을 한 번 요청해 결과를 확인합니다.
  2. 같은 내용을 매일 아침 시각을 정해 예약 작업으로 등록해 달라고 합니다.
  3. 주기와 프롬프트 초안을 확인하고 승인합니다.
  4. 좌측 예약됨에서 스케줄을 확인합니다.
예시 프롬프트
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고 우선순위 브리핑을 만들어 줘. 같은 내용을 매일 아침 7시 50분에 실행하는 예약 작업으로 등록해 줘.
  • 메일은 자동 발송보다 초안으로 남기게 하는 편이 안전합니다.
