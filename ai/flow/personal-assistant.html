나를 알려 주고 인터뷰받기

Claude 데스크톱 앱

비서의 출발점은 나에 대한 맥락입니다. Claude가 폴더를 읽고 나를 인터뷰하게 하면 빠르게 쌓입니다.

따라 하기

  1. Claude 데스크톱 앱을 설치하고 폴더 접근을 허락합니다.
  2. '컴퓨터 보고 나에 대해 파악해 줘'라고 요청합니다.
  3. '나에 대해서 궁금한 거 100개까지 물어봐 봐'라고 요청해 인터뷰를 받습니다.
  4. '이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?'라고 묻습니다.
예시 프롬프트
내 폴더를 읽기만 하고 고치지는 말고, 어떤 일을 하는 사람인지 파악해서 한 문단으로 설명해 줘. 그다음 나에 대해 궁금한 걸 질문해 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 답이 의심되면 근거 자료를 요구하거나 다른 AI로 교차 검증합니다.

AI가 기억하는 범위 이해하기

Claude

입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있습니다. 구조를 알아야 무엇을 넣어도 되는지 판단할 수 있습니다.

따라 하기

  1. 새 대화를 열면 모델은 이전 내용을 모르는 빈 상태로 시작한다는 점을 확인합니다.
  2. 메모리는 모델이 아니라 계정에 저장된 정보를 참고하는 방식임을 이해합니다.
  3. 메모리 기본값이 켜짐인지 꺼짐인지 설정 화면에서 확인합니다.
  4. 모델 학습에 내 대화를 쓰는지 설정과 안내에서 확인하고 원하는 대로 정합니다.
  5. 다루는 정보의 민감도에 맞는 제품과 플랜을 고릅니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 학습 사용 정책은 제공사마다 다르니 제품마다 따로 확인하세요.

업무별 프로젝트 만들기

Claude 프로젝트

프로젝트는 강의, 보고서, 책 쓰기처럼 작업별로 대화를 모아 두는 폴더 같은 기능입니다. 용도별로 나누면 같은 설명을 반복하지 않아도 됩니다.

따라 하기

  1. 왼쪽 사이드바에서 프로젝트를 찾아 + 또는 새 프로젝트를 누릅니다.
  2. 프로젝트 이름을 작업 단위로 정합니다.
  3. 프로젝트 안에서 새 채팅을 열어 대화를 시작합니다.
  4. 작업이 다르면 별도 프로젝트를 만들어 나눕니다.
  • ChatGPT의 프로젝트는 영상 기준(2025년 6월)으로 유료 버전에서 쓸 수 있다고 하니 현재 조건은 직접 확인하세요.

프로젝트 지침 쓰기

Claude 프로젝트

지침에 역할, 대상, 톤, 형식을 적어 두면 새 채팅에서 주제만 입력해도 같은 형식의 답이 나옵니다. 처음 세팅에 시간을 들여 AI와 맞춰 가는 것이 좋습니다.

따라 하기

  1. 프로젝트에서 지침 입력 화면을 엽니다(Claude는 커스텀 지침).
  2. AI의 역할과 대상 독자, 톤을 적습니다.
  3. 구간별 분량과 원하는 결과 예시를 함께 적습니다.
  4. 지침 저장을 눌러 저장합니다.
  5. 새 채팅에서 주제만 입력해 결과를 확인하고, 다르면 지침을 고칩니다.
예시 프롬프트
당신은 직장인 업무 이메일 작성 도우미입니다. 내가 상황만 알려 주면 제목 1줄, 본문 5문장 이내, 마무리 인사 순서로 정중한 어조의 이메일을 써 주세요. 예시: [여기에 평소 쓰던 좋은 이메일 하나 붙여넣기]
  • 지침은 구간별로 나눠 쓰면 더 정확합니다.
  • 영상에서는 처음 세팅에 주말 하루 이틀 정도를 권합니다.

참고 파일 올리기

Claude 프로젝트

관련 문서를 프로젝트에 올려 두면 그 안의 대화가 자료를 바탕으로 이어집니다. 회사 양식이나 기준 문서가 있는 업무에 씁니다.

따라 하기

  1. 파일을 올릴 프로젝트를 엽니다.
  2. 관련 문서를 파일로 업로드합니다.
  3. 프로젝트 안에서 새 채팅을 열어 올린 자료를 바탕으로 질문합니다.
  4. 답변이 자료와 맞는지 직접 읽고 검증합니다.
  • 영상 제작자는 ChatGPT에서 파일 추가 효과가 크지 않았다고 합니다. 지침이 더 중요할 수 있으니 직접 비교해 보세요.

메모리 관리하고 대화 이어 가기

Claude

메모리는 AI가 계정에 저장해 다음 대화에서 참고하는 정보입니다. 열어 보고 지우거나 추가해 내가 통제하고, 새 채팅에서는 이전 내용을 가져오라고 요청해 맥락을 잇습니다.

따라 하기

  1. 설정에서 메모리 항목을 찾아 켜져 있는지 확인합니다.
  2. 저장된 메모리 목록에서 틀리거나 오래된 항목은 삭제합니다.
  3. 꼭 기억시킬 내용은 직접 추가합니다.
  4. 이어 갈 작업의 프로젝트 안에서 새 채팅을 엽니다.
  5. 기존 대화에서 필요한 내용을 찾아 달라고 요청하고 맞는지 확인합니다.
예시 프롬프트
이 프로젝트의 이전 대화에서 지난주에 정한 보고서 구성과 톤 기준을 찾아 요약해 주세요. 그 기준대로 이번 보고서 초안을 이어서 써 주세요.
  • 민감한 업무 내용은 메모리에 남기지 않도록 주의하세요.
  • 중요한 결정은 지침이나 메모리에 따로 남겨 두면 안전합니다.

스킬로 업무 방법 저장하기

Claude

스킬은 작업 방법을 한 번 가르쳐 두면 관련 상황에서 자동으로 적용되는 파일입니다. 이름과 설명만 먼저 불러오므로 컨텍스트도 아낍니다.

따라 하기

  1. 잘 쓴 보고서나 결과물 하나를 Claude에 업로드합니다.
  2. '이 양식으로 주간 보고서 스킬을 만들어 줘'라고 요청합니다.
  3. 만들어진 스킬을 저장하고 세션을 재시작합니다.
  4. /를 입력해 스킬이 목록에 보이는지 확인합니다.
  5. 스킬 이름을 불러 호출하고 이번 주 자료만 넣습니다.
예시 프롬프트
이 보고서 양식으로 '주간 보고서' 스킬을 만들어 줘. 앞으로 이번 주 자료만 주면 같은 구성과 말투로 초안을 써 주게 해 줘.
  • 항상 불러오는 CLAUDE.md와 달리 스킬은 요청이 맞을 때만 로드됩니다.

커넥터로 내 도구 연결하기

Claude

커넥터를 연결하면 파일을 일일이 올리지 않고 채팅에서 바로 찾아 쓰고, 결과를 메일 초안으로 만들 수 있습니다.

따라 하기

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가, 커넥터 둘러보기를 차례로 누릅니다.
  3. 연결할 서비스를 검색해 옆의 +를 누르고 로그인해 인증합니다.
  4. 채팅에서 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청합니다.
예시 프롬프트
구글 드라이브에서 계약서 파일을 찾아 내용을 요약하고, 담당자에게 보낼 이메일 초안을 써 줘
  • 타이핑 대신 마이크로 상황을 충분히 말하면 결과가 좋아집니다.
