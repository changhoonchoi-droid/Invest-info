영상 도구를 열기 전에 대상, 분위기, 장면 구성을 글로 정해 두면 크레딧 낭비가 줄어듭니다. 구조를 먼저 확정한 뒤 장면별 설명으로 넘어가세요.

따라 하기

  1. 역할과 대상 고객, 제품의 장점을 알려 줍니다.

  3. 분량과 분위기를 정합니다.
  4. 확정되면 장면별 설명으로 만들어 달라고 요청합니다.
예시 프롬프트

  • 분량을 지정하면 결과가 더 맞게 나옵니다.

Claude

따라 하기

  1. 서비스 사이트의 MCP 메뉴에서 Claude를 선택해 MCP URL을 복사합니다.
  2. Claude 설정 → 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  3. 이름과 MCP 서버 URL을 입력하고 계속을 눌러 로그인합니다.
  4. 채팅창 + → 커넥터에서 파란색(사용 중)인지 확인합니다.
  5. 크레딧 잔액을 물어 연결을 시험합니다.
예시 프롬프트

  • 공식 MCP만 쓰고 출처 불분명한 비공식 MCP는 피하세요.

제품 대표 이미지 만들기

Claude

영상 일관성을 위해 제품·모델 이미지를 먼저 고정합니다. 생성 전에 체크만 시켜 예상 크레딧을 확인하면 아낄 수 있습니다.

따라 하기

  1. 사용 가능한 이미지 모델을 확인해 달라고 하되 생성은 시키지 않습니다.
  2. 업로드 위젯으로 제품 사진을 올립니다.
  3. 모델, 비율, 해상도를 적어 대표 이미지를 요청합니다.
  4. 착용샷·디테일 컷은 바꿀 것과 유지할 것을 나눠 수정합니다.
  5. 마음에 드는 것만 다운로드로 저장합니다.
예시 프롬프트
먼저 생성하지 말고 Artlist에서 쓸 수 있는 이미지 모델을 확인해 줘. 첨부한 운동화 사진으로 정사각형 2K 대표 이미지를 만들 계획과 예상 크레딧을 알려 줘.
  • 로고·형태·한글 문구가 달라질 수 있으니 확인하세요.
  • 재생성은 크레딧이 추가로 듭니다.

모델 캐릭터 시트 만들기

힉스필드

광고에 인물이 나온다면 전신 모델 이미지를 만들고 캐릭터 시트를 레퍼런스로 삼아 얼굴·의상을 유지합니다. 전신으로 만들어야 하반신이 임의로 표현되지 않습니다.

따라 하기

  1. 이미지를 선택하고 외모·의상·분위기를 구체적으로 적어 전신 사진을 요청합니다.
  2. GPT Image 2.5를 고르고 비율·품질을 정해 생성하기를 누릅니다.
  3. 만든 이미지를 첨부해 같은 인물의 캐릭터 시트를 요청합니다.
  4. 마음에 드는 시트를 저장합니다.
  • 스타터 요금제에서는 Seedance 2.5를 쓸 수 없다고 합니다.
  • 해상도·길이를 올리면 크레딧과 시간이 늘어납니다.

레퍼런스로 광고 영상 생성

Artlist

제품과 배경 이미지를 이미지 레퍼런스로 넣고 짧은 프롬프트로 최대 30초 영상을 만듭니다. 영상 생성은 크레딧이 많이 드니 구도는 이미지로 먼저 확정하세요.

따라 하기

  1. AI 툴킷에서 비디오를 고르고 올 모델스에서 Seedance 2.5를 선택합니다.
  2. 길이를 30초로, 화질을 높게 정하고 소리가 필요하면 오디오를 켭니다.
  3. +를 눌러 이미지 레퍼런스로 제품·배경 이미지를 추가합니다.
  4. 프롬프트를 쓰고 제너레이트를 누릅니다.
  5. 수정은 생성된 영상을 레퍼런스로 첨부하고 바꿀 부분만 적습니다.
예시 프롬프트
첨부한 SUV가 비 오는 서울 도심 야경을 달리는 30초 광고. 앞부분은 차분하게, 마지막에 차량 정면 클로즈업. 제품 디자인은 레퍼런스 그대로 유지.
  • 시작·끝 프레임이 아니라 이미지 레퍼런스로 넣어야 합니다.
  • 엄격한 브랜드 가이드가 필요하면 실제 촬영이 필요할 수 있습니다.

따라 하기

  3. 수정 문장을 입력해 생성합니다.
  4. 원본과 결과를 비교해 확인합니다.
예시 프롬프트

  • AI가 다시 생성하므로 세부가 완전히 같지는 않습니다.
