따라 하기

  • 사용량이 빨리 닳으면 모델을 한 단계 가벼운 것으로 바꾸세요.

계획 모드로 방향 잡기

Claude Code

큰 작업은 계획 모드로 먼저 방향을 잡으면 실수를 줄입니다. 코드가 쓰이기 전인 계획 단계가 방향을 고치기 가장 좋은 시점입니다.

따라 하기

  1. Shift + Tab을 눌러 Plan mode로 전환합니다.
  2. 만들 대시보드와 알고 싶은 점을 구체적으로 요청합니다.
  3. Claude가 내놓은 계획을 검토하고 부족하면 추가·수정을 요청합니다.
  4. 계획이 좋으면 승인하고 파일 수정을 자동 수락할지 매번 물을지 고릅니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저로 볼 수 있는 대시보드 웹사이트를 만들 계획을 먼저 세워 줘. 연령대별 만족도 막대그래프와 주요 의견 요약을 넣어 줘.
  • 모든 단계를 확인하고 싶으면 기본 승인 모드를 유지하세요.
  • 권한 무시는 물어보지 않고 전부 실행하니 작업 폴더 범위를 확인한 뒤에만 켜세요.

만들고 확인하고 고치기

Claude Code

탐색, 계획, 구현, 검증 순서로 일하면 품질이 안정됩니다. 성공 기준을 분명히 적고 우측 내장 브라우저로 결과를 확인합니다.

따라 하기

  1. 계획에 올바른 결과의 성공 기준을 적습니다.
  2. 구현이 끝나면 우측 내장 브라우저에서 결과를 확인합니다.
  3. 필요하면 기본 브라우저에서 열기로 크롬에서 엽니다.
  4. 고칠 점은 프롬프트로 이어서 요청합니다.
  5. 만족하면 내 스타일에 맞는 커밋 메시지를 만들게 합니다.
예시 프롬프트
이 변경의 성공 기준은 모든 그래프가 표시되고 모바일 화면에서도 깨지지 않는 거야. 구현 후 직접 열어 확인한 결과를 알려 줘.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청하세요.

CLAUDE.md로 규칙 남기기

Claude Code

CLAUDE.md는 세션을 시작할 때마다 먼저 읽는 규칙 파일입니다. 작업 중 반복해서 바로잡은 규칙만 추가해 간결하게 유지하세요.

따라 하기

  1. /init 명령으로 CLAUDE.md를 생성합니다.
  2. 스택, 명령어, 코드 스타일 규칙을 확인하고 고칩니다.
  3. 반복해서 바로잡은 규칙은 메모리에 저장하라고 명시적으로 요청합니다.
  4. 200줄 이내로 지도처럼 유지합니다.
예시 프롬프트
방금 바로잡은 규칙, 즉 보고서 숫자는 항상 천 단위 쉼표를 쓴다는 내용을 CLAUDE.md에 저장해 줘.
  • AI가 자동 생성한 설정 파일은 사람이 검수해야 합니다.
  • 상세 내용은 문서나 스킬로 넘기세요.

컨텍스트를 확인하고 정리

Claude Code

컨텍스트는 Claude의 작업 기억이고 읽은 파일과 대화가 모두 공간을 차지합니다. 슬래시 명령으로 상태를 보고 정리하면 긴 작업에서도 답변 품질을 지킬 수 있습니다.

따라 하기

  1. /context로 크기와 가장 많이 차지하는 항목을 확인합니다.
  2. 같은 기능 작업이면 /compact로 요약합니다.
  3. 새 기능을 시작할 때는 /clear로 비웁니다.
  4. 안 쓰는 MCP 서버는 끄고 다음에도 필요한 내용은 CLAUDE.md에 적습니다.
  • 압축하면 이전 대화의 세부 내용이 사라질 수 있습니다.
  • /btw로 곁가지 질문을 하면 본 대화가 길어지지 않습니다.

반복 방법을 스킬로 저장

Claude Code

성공한 작업 방법을 스킬로 저장하면 관련 상황에서 자동으로 적용됩니다. 스킬은 요청이 맞을 때만 로드되어 컨텍스트도 아낍니다.

따라 하기

  1. 잘 된 결과물을 두고 이 방식을 스킬로 만들어 달라고 요청합니다.
  2. 개인용은 홈 디렉터리 .claude/skills, 프로젝트용은 저장소 루트 .claude/skills에 SKILL.md로 둡니다.
  3. 새 스킬이 인식되도록 세션을 재시작합니다.
  4. /를 입력해 스킬이 목록에 보이는지 확인합니다.
예시 프롬프트
방금 만든 대시보드 제작 방식을 '설문 대시보드' 스킬로 만들어 줘. 다음엔 CSV만 주면 같은 구성으로 만들어 줘.
  • 배포처럼 위험한 작업은 슬래시로 직접 호출하는 방식이 안전합니다.

원격 제어는 내 컴퓨터에서 실행 중인 세션에 웹이나 모바일로 접속해 이어가는 기능입니다. 파일과 도구는 내 컴퓨터에서 돌고 대화만 동기화됩니다.

따라 하기

  1. 데스크톱 앱의 Code 모드에서 리모트 컨트롤 설정을 켭니다.
  2. 터미널을 쓴다면 claude remote-control을 실행하고 표시된 URL을 엽니다.
  3. 휴대폰 Claude 앱이나 모바일 브라우저에서 진행 중인 세션을 확인합니다.
  4. 모든 세션에 적용하려면 /config에서 원격 제어를 켭니다.
  • 내 컴퓨터가 켜져 있어야 합니다.
  • 제공 플랜이 순차 확대 중이었으니 내 플랜에서 되는지 확인하세요.
