Claude Code 설치하고 로그인

Claude Code

터미널이 낯설다면 데스크톱 앱이나 VS Code에서 시작하세요. 처음에는 데스크톱 앱으로 시작하고 익숙해지면 CLI로 넘어가는 것을 영상에서 추천합니다.

따라 하기

  1. Claude 데스크톱 앱 상단의 Code 토글(또는 코드 탭)로 전환합니다.
  2. VS Code라면 확장 패널에서 Claude Code를 검색해 Anthropic이 만든 확장을 설치합니다.
  3. Ctrl/Cmd + Shift + P로 명령 팔레트를 열고 Claude Code를 검색해 새 탭을 엽니다.
  4. Claude 계정(Pro, Max, Enterprise) 또는 API 키로 로그인합니다.
  • 실행한 폴더와 그 하위 폴더 전체에 접근 권한이 생기므로 폴더 위치를 확인하세요.
  • 코워크·코드·디자인은 Pro(월 20달러) 이상이 필요합니다.

디자인 시안 먼저 뽑기

Claude Design

코드를 짜기 전에 화면 시안을 여러 개 뽑아 비교하면 결과가 나아집니다. 디자인 시스템 없이 쓰면 'AI스럽다'는 평가가 있어 먼저 만들어 두는 것이 좋습니다.

따라 하기

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 잘 된 점과 아쉬운 점을 댓글로 남기고 새 시안을 더 요청합니다.
  5. 클릭해 볼 수 있는 프로토타입을 만들어 달라고 요청합니다.
예시 프롬프트
현재 앱을 살펴보고 앱에 맞는 온보딩 디자인 시안을 여러 개 만들어 줘.
  • 작은 사이드 프로젝트도 짧은 디자인 탐색을 거치면 결과가 나아집니다.

계획 모드로 방향 잡기

Claude Code

계획 모드에서는 Claude가 파일을 수정하지 않고 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전이 방향을 고치기 가장 좋은 시점입니다.

따라 하기

  1. 프로젝트 루트에서 Claude Code를 엽니다.
  2. Shift+Tab을 눌러 입력창 아래에 plan mode가 표시될 때까지 전환합니다.
  3. 구현하려는 내용을 구체적으로 요청합니다.
  4. Claude가 내놓은 계획을 검토하고 부족하면 수정을 요청합니다.
  5. 계획이 좋으면 승인하고 파일 수정을 자동 수락할지 매번 물을지 고릅니다.
예시 프롬프트
앱 전체에 다크 모드를 넣고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마에 어울리는 대비 색을 쓰는 계획을 먼저 세워 줘.
  • Shift + Tab으로 승인·자동 수락·계획 모드를 오갈 수 있습니다.
  • 모든 단계를 확인하고 싶으면 승인 모드를 유지하세요.

첫 결과물 만들고 고치기

Claude Code

폴더를 지정하고 자료를 첨부해 만들고 싶은 것을 풀어 쓰면 됩니다. 내장 브라우저로 결과를 확인하면서 프롬프트로 고쳐 갑니다.

따라 하기

  1. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정합니다.
  2. 필요한 자료 파일을 첨부합니다.
  3. 만들고 싶은 결과물과 필요한 기능을 풀어 써서 요청합니다.
  4. 우측 내장 브라우저에서 확인하고 기본 브라우저에서 열기로 크롬에서 엽니다.
  5. 수정할 점은 프롬프트로 요청합니다.
예시 프롬프트
내 포트폴리오를 소개하는 한 페이지 웹사이트를 만들어 줘. 상단에 소개, 아래에 프로젝트 3개 카드, 맨 아래에 연락처를 넣어 줘.
  • 오류가 나면 콘솔의 오류 메시지를 복사해 붙여 넣으세요.

말로 요구사항 인터뷰하기

Claude Code

처음 프롬프트를 길게 쓰지 않아도 됩니다. Claude가 사용자에게 질문해 요구사항을 끌어내게 하면 스펙이 정리됩니다.

따라 하기

  1. 프롬프트에서 만들 앱의 관심 영역(예: 대상 사용자)만 주고 결과는 과하게 지정하지 않습니다.
  2. 프롬프트에 ask user question 도구를 쓰라고 명시합니다.
  3. Claude가 띄우는 질문에 차례로 답합니다.
  4. 답변이 끝나면 Claude가 작성하는 스펙을 확인합니다.
예시 프롬프트
고객 문의를 정리하는 간단한 웹 앱을 만들 거야. 구현 전에 ask user question 도구로 나에게 필요한 걸 먼저 질문해 줘.
  • '더 좋게 만들어', '실수 없이 만들어' 같은 프롬프트는 피합니다.

CLAUDE.md로 규칙 남기기

Claude Code

CLAUDE.md는 세션을 시작할 때마다 자동으로 읽는 파일입니다. 반복해서 바로잡은 규칙이나 실수를 여기에 적어 두면 같은 문제가 줄어듭니다.

따라 하기

  1. 프로젝트 루트에서 /init 명령을 실행해 CLAUDE.md를 생성합니다.
  2. 스택, 명령어, 코드 스타일 규칙을 확인하고 고칩니다.
  3. 금지 규칙과 주요 폴더 안내를 추가합니다.
  4. 작업 중 반복해서 바로잡은 규칙은 메모리에 저장하라고 요청합니다.
예시 프롬프트
방금 알려 준 규칙(커밋 메시지는 한국어로 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 매뉴얼이 아니라 지도처럼 씁니다.
  • 자동 생성된 설정 파일은 사람이 검수하세요.

검증하고 커밋하기

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 마지막에 리뷰와 커밋 메시지까지 맡겨 작업을 매듭짓습니다.

따라 하기

  1. 계획에 무엇이 올바른 결과인지 성공 기준을 적습니다.
  2. 웹 UI라면 Claude in Chrome 확장으로 탭에서 직접 테스트하게 합니다.
  3. 직접 확인해 만족하면 서브에이전트 코드 리뷰어로 점검합니다.
  4. 내 스타일에 맞는 커밋 메시지를 만들게 한 뒤 푸시합니다.
예시 프롬프트
커밋하기 전에 서브에이전트 코드 리뷰어로 변경 사항을 점검해 주고, 문제가 없으면 커밋 메시지를 만들어 줘.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청합니다.
  • 컨텍스트가 길어지면 /compact나 /clear로 정리하세요.

링크로 공유하거나 배포하기

Claude 앱

간단한 도구는 아티팩트로 만들어 링크로 공유할 수 있습니다. 웹 페이지는 Codex 플러그인으로 Vercel에 바로 배포하는 방법도 소개됩니다.

따라 하기

  1. 간단한 도구는 새 아티팩트 → 처음부터 시작하기로 만들고 앱을 설명합니다.
  2. 우측 패널에서 앱을 직접 사용해 봅니다.
  3. 공유하려면 게시해 링크로 받습니다.
  4. 웹 페이지 배포가 필요하면 Codex의 플러그인 탭에서 Vercel을 설치하고 배포를 요청합니다.
예시 프롬프트
월별 수입과 지출을 입력하면 합계와 카테고리별 비율을 보여 주는 가계부 앱을 만들어 줘.
  • Artifacts 탭에서 내가 만든 아티팩트와 공유받은 것을 모아 볼 수 있습니다.
