도구 고르고 아이디어 펼치기

Claude 앱

작동하는 작은 도구는 아티팩트, 파일 기반 대시보드나 앱은 코드, 사업 소개 페이지는 AI 빌더가 맞습니다. 구상은 화이트보드로 펼칠 수 있습니다.

따라 하기

  1. 만들 결과물을 한 줄로 적습니다.
  2. 계산기·퀴즈 같은 작은 도구면 아티팩트로 갑니다.
  3. 설문 데이터 대시보드 같은 건 코드 탭으로 갑니다.
  4. 사업 소개·랜딩 페이지는 AI 빌더로 갑니다.
  5. 구상이 막히면 화이트보드에 흐름을 펼칩니다.
  • 코워크·코드·디자인은 영상 기준 유료 플랜이 필요했으나 이후 일부 무료로 확대되었다고 하니 내 플랜을 확인하세요.

데스크톱 앱으로 사이트 만들기

Claude Code

폴더를 지정하고 파일을 첨부해 요청하면 개발 지식 없이도 웹사이트를 만듭니다. 어떻게 만들지는 AI에게 맡기고 무엇을 만들지에 집중합니다.

따라 하기

  1. 데스크톱 앱에서 코드 탭으로 들어갑니다.
  2. 폴더 열기로 작업 폴더를 지정하고 워크스페이스를 신뢰합니다.
  3. 자료 파일(예: 설문 CSV)을 첨부합니다.
  4. 결과물과 기능을 풀어 써서 요청합니다.
  5. 내장 브라우저에서 확인하고 수정은 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 큰 작업은 Shift+Tab으로 계획 모드를 켜 계획부터 받으면 방향을 고치기 쉽습니다.

AI 빌더로 홈페이지 만들기

Hostinger AI 빌더

사이트 이름, 색감, 구성을 적으면 몇 분 안에 홈페이지가 생성됩니다. 참고 화면 캡처를 붙이면 분위기가 정확히 전달됩니다.

따라 하기

  1. 입력창에 사이트 이름·색감·제목·구성을 적습니다.
  2. 참고 스크린샷이나 사이트 링크를 함께 넣습니다.
  3. AI가 확인을 물으면 확인을 누릅니다.
  4. 생성된 사이트에서 텍스트는 직접 고치고 큰 변경은 채팅으로 요청합니다.
예시 프롬프트
해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘
  • 수정 요청은 한 번에 하나씩 입력해야 어긋남이 적습니다.
  • 후기·숫자 같은 생성 문구는 사실에 맞게 고칩니다.
