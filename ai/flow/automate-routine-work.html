코워크로 폴더 업무 맡겨 보기

Cowork

자동화 전에 코워크가 어떻게 일하는지 감을 잡습니다. 범위가 분명한 일에서 계획을 확인하고 승인하는 흐름을 익힙니다.

따라 하기

  1. Claude 데스크톱 앱에서 Cowork 탭(또는 협업)을 엽니다.
  2. 프로젝트 또는 폴더에서 작업 폴더 하나를 선택합니다.
  3. 접근 권한 창이 뜨면 허용합니다.
  4. 할 일을 적고 변경 전에 계획을 먼저 보여 달라고 요청합니다.
  5. 계획을 읽고 고칠 부분을 지시한 뒤 승인합니다.
  6. 결과 파일을 폴더에서 확인합니다.
예시 프롬프트
다운로드 폴더의 파일을 종류별로 정리할 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • 처음에는 범위가 분명한 작업부터, 중요한 폴더는 복사본으로 시험하세요.
  • 웹 버전은 로컬 파일 접근이 안 되므로 데스크톱 앱에서 합니다.

너는 마케팅 팀의 업무 보조야. 보고서는 존댓말로 간결하게 쓰고, 날짜는 2026-11-18 형식으로 적어. 파일을 삭제하기 전에는 반드시 나에게 확인해.

메일·캘린더 커넥터 연결

커넥터

커넥터가 있어야 Claude가 내 메일·일정·문서를 읽고 정리할 수 있습니다. 한 번만 연결하면 채팅마다 켜고 끌 수 있습니다.

따라 하기

  1. 대화창 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail, 구글 캘린더, 구글 드라이브, 노션 등을 검색합니다.
  3. 서비스 옆 +를 눌러 계정으로 로그인·인증합니다.
  4. + → 커넥터에서 연결 표시(파란 불)를 확인합니다.
예시 프롬프트
구글 드라이브에서 '11월 견적서' 파일을 찾아서, 내용을 바탕으로 거래처에 보낼 안내 메일 초안을 써 줘.
  • 메일은 자동 발송하게 하지 말고 초안까지만 만들게 하면 안전합니다.

보고서 양식을 스킬로 저장

Claude

스킬은 반복 업무의 형식과 규칙을 저장합니다. 평소 쓰던 좋은 보고서를 올려 스킬로 만들면 매번 같은 포맷으로 초안이 나옵니다.

따라 하기

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 형식을 분석해 스킬로 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력하고 이번 주 자료를 넣습니다.
  5. 빠진 항목이 있으면 스킬에 추가해 갱신합니다.
예시 프롬프트
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 피드백을 줄 때마다 스킬에 남기면 갈수록 품질이 좋아집니다.

자료 모아 보고서 초안 만들기

Cowork

회의록·엑셀·메모가 흩어져 있다면 폴더에 모아 한 번에 정리시킵니다. 이 단계에서 결과를 확인해야 이후 예약이 안전합니다.

따라 하기

  1. 협업을 선택하고 작업 폴더를 고른 뒤 항상 허용을 누릅니다.
  2. 회의록·매출 데이터·메모를 그 폴더에 복사합니다.
  3. 자료를 모두 읽고 정리해 달라고 요청합니다.
  4. 완성된 문서의 숫자와 내용을 직접 확인합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘.
  • 엑셀은 원본을 두고 정리본을 새 파일로 저장하라고 적습니다.

Cowork

먼저 브리핑을 한 번 만들어 보고 마음에 들면 같은 내용을 예약 작업으로 등록합니다. 7월 업데이트 이후 기기가 꺼져 있어도 클라우드에서 실행됩니다.

따라 하기

  1. 어제 오후 6시 이후 메일과 오늘 일정으로 브리핑을 만들어 달라고 요청합니다.
  2. 같은 내용을 아침 7시 50분마다 실행하는 예약 작업으로 등록해 달라고 요청합니다.
  3. Claude가 만든 예약 내용과 주기를 확인하고 승인합니다.
  4. 좌측 예약됨에서 스케줄을 확인합니다.
예시 프롬프트
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고 아침 브리핑을 만들어 줘. 답장이 필요한 메일을 우선순위 순으로 알려 줘.
  • 예약 작업은 유료 플랜에서만 쓸 수 있습니다.

주간 업무 예약 작업 만들기

Cowork

반복할 일을 말로 설명하면 Claude가 프롬프트 초안을 만들고, 주기를 승인하면 정기 실행됩니다. 첫 실행 후 프롬프트가 더 상세히 다듬어집니다.

따라 하기

  1. 반복할 일을 자연어로 설명하거나 /schedule을 입력합니다.
  2. Claude가 만든 프롬프트 초안을 검토합니다.
  3. 주기를 매시간·매일·평일·수동 중에서 고릅니다.
  4. 제안을 수락합니다.
  5. 예약 페이지(예정된 탭)에 추가됐는지 확인합니다.
  6. 한 번 즉시 실행해 결과가 의도대로인지 확인합니다.
예시 프롬프트
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 꺼져 있어서 놓친 작업은 복귀 후 바로 실행되고 지연됐다고 알려 줍니다.
  • 예약 페이지에서 기록 확인, 수정, 즉시 실행이 가능합니다.

Cowork

캘린더·Slack·이메일·회의록을 연결해 미팅 전에는 브리핑 문서를, 후에는 할 일과 후속 메시지를 만듭니다.

따라 하기

  1. 캘린더, Slack, 이메일을 Claude에 연결합니다.
  2. 회의록 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 미팅 준비용 스킬을 만들고 테스트 계정으로 다듬습니다.
  4. 미팅 전 /로 스킬을 고르고 회의 이름과 시간을 알려 줍니다.
  5. 미팅 후 녹취록 처리 스킬로 할 일과 후속 메시지를 만듭니다.
  6. 각 결과를 확인하고 승인한 뒤에만 발송합니다.
예시 프롬프트
Prep me for today's call with Acme Corp at 1PM.
  • 이름을 걸고 보내는 메일이므로 브리핑 근거를 원문에서 확인합니다.

플러그인·n8n으로 더 키우기

Cowork

기본 자동화가 익숙해지면 직무별 플러그인이나 n8n 같은 노코드 도구로 다른 서비스와도 이어 봅니다. n8n은 설정이 더 어려워 고급 과정입니다.

따라 하기

  1. 코워크의 + 버튼에서 플러그인을 선택해 직무에 맞는 것을 설치합니다.
  2. 플러그인 관리에서 제공 명령어를 확인합니다.
  3. 더 복잡한 연결은 n8n 클라우드에서 빌드 위드 AI로 시나리오를 만듭니다.
  4. API 키와 OAuth 인증은 직접 연결하고 테스트 데이터로 실행해 확인합니다.
예시 프롬프트
슬랙 채널에 '긴급'이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일을 보내 줘.
  • n8n AI 빌더는 베타이며 프롬프트 한 번에 1크레딧을 씁니다.
  • 명령어 표기는 플러그인 관리 화면에서 확인하세요.
