  4. 자료를 폴더에 넣거나 첨부합니다.
  • 사용량이 빨리 닳으면 모델을 한 단계 가벼운 것으로 바꾸세요.

레퍼런스·원본 폴더 정리

Claude Code

비슷한 촬영 방식의 완성본을 레퍼런스로 두면 같은 스타일로 편집할 수 있습니다. 영상 종류별 기준 편집본과 편집 방식 매뉴얼도 함께 둡니다.

따라 하기

  1. 레퍼런스 폴더에 완성된 편집본을 넣습니다.
  2. 원본 폴더에 촬영 영상을 넣습니다.
  3. 영상 종류별 편집 방식을 업무 매뉴얼로 적어 둡니다.
  4. 스타터 폴더를 열고 "너는 어떻게 만들어져 있어?"라고 물어 구조를 파악합니다.
예시 프롬프트
너는 어떻게 만들어져 있어? 이 폴더의 구조와 규칙을 설명해 줘.
  • 레퍼런스와 촬영 방식이 비슷해야 결과가 잘 맞습니다.

  • 처음에는 없이 시작해 바로잡는 부분만 추가하면 간결하게 유지됩니다.

첫 편집 시켜 보기

Claude Code

먼저 영상 하나로 시험합니다. 애매한 부분은 물어보라고 해 두면 엉뚱한 결과를 줄일 수 있습니다.

따라 하기

  1. 레퍼런스를 참고해 원본을 똑같이 편집하라고 요청합니다.
  2. 애매하면 물어보라고 덧붙입니다.
  3. 결과 영상을 확인하고 고칠 점을 이어서 요청합니다.

예시 프롬프트
레퍼런스 폴더의 편집본을 참고해서 원본 폴더의 촬영 영상을 똑같은 스타일로 편집해 줘. 애매한 부분은 먼저 물어봐 줘.
  • 영상에서는 34초 편집에 약 40분, 후속 편은 약 15분이 걸렸습니다.

잘 된 방식을 스킬로 저장

Claude Code

스킬은 작업 방법을 한 번 가르쳐 두면 관련 상황에서 적용되게 하는 파일입니다. 잘 된 편집 방식을 저장해 반복 사용합니다.

따라 하기

  1. 성공한 편집 방식을 스킬로 만들어 달라고 요청합니다.
  2. 스킬이 인식되도록 세션을 재시작합니다.
  3. /를 입력해 스킬이 목록에 보이는지 확인합니다.
  4. 스킬을 호출해 새 영상에 적용합니다.
예시 프롬프트
방금 편집한 방식을 '영상 편집' 스킬로 만들어 줘. 새 영상을 주면 같은 순서와 스타일로 편집하게 해 줘.
  • 스킬은 요청이 맞을 때만 로드되어 컨텍스트를 아낍니다.

드라이브 폴더 자동 편집

Claude 데스크톱 앱

구글 드라이브 커넥터와 예약됨 기능을 묶으면 폴더에 새 영상이 올라올 때 정해 둔 스타일로 자동 편집합니다.

따라 하기

  4. 영상 올리는 폴더를 지정하고 한 시간마다 확인하도록 설정합니다.
  5. 새 영상이 올라오면 자동으로 편집하도록 지시합니다.
  • 연결된 계정이 어느 것인지 미리 확인하세요.
