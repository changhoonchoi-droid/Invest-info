디자인은 말로 설명하는 것보다 이미지로 보여 주는 편이 훨씬 정확합니다. 템플릿 마켓에서 마음에 드는 화면을 골라 캡처합니다.

따라 하기

  3. 캡처 이미지를 저장해 둡니다.
  • 요청이 막연하면 이미지를 더 붙이는 편이 말로 길게 설명하는 것보다 낫습니다.

데이터로 대시보드 만들기

Claude Code

데이터가 있다면 데스크톱 앱 코드 탭에서 파일을 첨부해 요청합니다. 어떻게 만들지는 AI에게 맡기고 무엇을 만들지에 집중합니다.

따라 하기

  1. 클로드 데스크톱 앱 코드 탭으로 들어갑니다.
  2. 폴더 열기로 작업 폴더를 지정하고 신뢰를 진행합니다.
  3. CSV 같은 자료 파일을 첨부합니다.
  4. 결과물과 필요한 기능을 풀어 써서 요청합니다.
  5. 내장 브라우저에서 확인하고 기본 브라우저에서 열기로 크롬에서 엽니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코드 탭은 Pro(월 20달러) 이상에서 사용합니다.

오류를 단서와 함께 전달하기

크롬 개발자 도구

오류가 나면 단서를 충분히 줘야 AI가 잘 고칩니다. 오류 메시지, 발생 시점, 기대 동작을 함께 전달합니다.

따라 하기

  1. 문제 화면에서 마우스 오른쪽 버튼을 눌러 검사를 엽니다.
  2. 콘솔 탭의 오류 메시지를 복사하거나 캡처합니다.
  3. 프롬프트에 오류 메시지를 붙여 넣습니다.
  4. 언제 발생하는지(예: 스크롤할 때)를 적습니다.
  5. 기대 동작과 현재 문제를 함께 적고 스크린샷을 첨부합니다.
예시 프롬프트
스크롤할 때 헤더가 깜빡거려. 콘솔 오류 메시지는 아래와 같아. 원래는 헤더가 고정되어 있어야 해. (오류 메시지와 스크린샷 첨부)
  • 언제·어디서·어떻게 발생했는지 단서를 많이 줄수록 해결이 잘 됩니다.
