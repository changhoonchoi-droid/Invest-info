업무를 단계로 나누기

Claude Code

여러 작업을 동시에 맡겨도 내가 병목이 되지 않도록 단계와 확인 지점을 미리 설계합니다. 콘텐츠뿐 아니라 어떤 반복 업무에도 적용됩니다.

따라 하기

  1. 업무를 기획·리서치 → 초안 → 검수 → 패키징 → 업로드 같은 단계로 나눕니다.
  2. 단계마다 입력과 결과물이 무엇인지 적습니다.
  3. 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 정합니다.
  4. 크레딧처럼 크게 나가는 것은 상한을 정합니다.
예시 프롬프트
내 콘텐츠 제작 과정을 기획·초안·검수·패키징·업로드 단계로 나누고, 단계마다 입력과 결과물, 내가 직접 확인할 지점을 표로 정리해 줘.
  • 영상의 크레딧 상한(쇼츠 500, 롱폼 1,500)은 본인 값이므로 내 요금제에 맞게 정하세요.
  • 자동 발행은 충분히 검증한 뒤 켜세요.

단계별 규칙을 스킬로 만들기

Claude Code

단계별 규칙을 스킬로 만들면 시리즈 전체를 같은 품질로 만들 수 있습니다. 피드백을 줄 때마다 규칙으로 남기면 스킬이 점점 좋아집니다.

따라 하기

  1. 먼저 원하는 결과물을 한 번 만들고 마음에 들 때까지 수정합니다.
  2. 만족스러운 방식을 스킬로 만들어 달라고 요청합니다.
  3. 요청에 작업 순서와 검증 기준을 함께 적습니다.
  4. 개인용은 홈 디렉터리의 .claude/skills에, 팀 공유용은 저장소의 .claude/skills에 둡니다.
  5. Claude Code를 껐다 켜서 스킬을 적용하고 자동으로 쓰이는지 확인합니다.
  6. 피드백을 줄 때마다 스킬에 계속 더해 갑니다.
예시 프롬프트
방금 만든 결과물의 작업 순서와 검증 기준을 정리해서, 다음에도 같은 방식으로 만들 수 있는 스킬로 만들어 줘. 프로젝트 스킬 폴더에 저장해 줘.
  • 스킬은 재시작해야 같은 세션에서 인식됩니다.
  • 항상 지킬 규칙은 CLAUDE.md에 적으세요.

만든 AI와 검수 AI 분리

Claude Code

만드는 AI는 자기 결과에 관대해지기 쉽습니다. 검수는 다른 AI가 독립적으로 하게 하고, 참/거짓으로 판정할 수 있는 종료 조건을 겹쳐 겁니다.

따라 하기

  1. 누가 봐도 참/거짓을 판정할 수 있는 종료 조건을 적습니다.
  2. 검증 통과, 최대 반복 횟수, 시간·비용 한도를 겹쳐서 걸어 둡니다.
  3. 진행 상황을 적는 상태 파일을 만들어 AI의 기억 장치로 씁니다.
  4. 만드는 AI와 검사하는 AI를 분리합니다.
  5. 처음에는 단순한 루프 하나로 시작해 돌려 봅니다.
  • 한 실험에서 코드 검사 루프가 가장 빠르고 쌌습니다. 이유가 있을 때만 구조를 늘리세요.

정기 실행으로 돌리기

Cowork

소재 수집처럼 정기적인 단계는 예약 작업으로 맡길 수 있습니다. 처음에는 결과를 직접 확인하다가 신뢰가 쌓이면 범위를 늘립니다.

따라 하기

  1. 반복할 일을 자연어로 설명하거나 /schedule을 입력합니다.
  2. Claude가 만든 프롬프트 초안과 주기를 확인하고 수락합니다.
  3. 예약 페이지에서 작업이 추가됐는지 확인합니다.
  4. 처음 몇 번은 실행 기록을 열어 결과를 점검합니다.
예시 프롬프트
AI 트렌드를 리서치해서 매주 수요일 유튜브 아이디어 5개를 제안해 줘. 예약 작업으로 만들어 줘.
  • 실행마다 새 세션으로 돌기 때문에 필요한 맥락은 프롬프트나 폴더에 두세요.
