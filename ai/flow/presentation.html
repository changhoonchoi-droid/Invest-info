음성 메모로 할 말 쏟아내기

Claude Slides

빈 슬라이드 앞에서 막막할 때는 하고 싶은 말을 음성 메모로 먼저 녹음하는 것이 좋습니다. 서식보다 내용에 집중할 수 있습니다.

따라 하기

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청합니다.
예시 프롬프트
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

딥 리서치로 근거 자료 모으기

Claude

발표에 쓸 시장·경쟁사 자료는 딥 리서치로 모으고 출처 링크를 함께 받습니다. 이후 슬라이드에 넣을 숫자는 원문과 대조합니다.

따라 하기

  1. + 버튼에서 리서치(딥 리서치) 모드를 켭니다.
  2. 조사할 주제와 원하는 결과 형태를 적어 요청합니다.
  3. 나온 결과에서 출처 링크를 직접 열어 확인합니다.
  4. 쓸 내용만 골라 슬라이드용 요약을 요청합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 비교하고, 가격과 장단점을 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 숫자·날짜·인용은 특히 틀리기 쉬우니 원문을 직접 확인하세요.

슬라이드·문서 초안 만들기

Claude Slides

같은 채팅 안에서 보고서, 슬라이드, 디자인을 이어서 만들 수 있습니다. 내용을 먼저 대화로 정리한 뒤 결과물 형식을 지정합니다.

따라 하기

  1. Opus 5.5로 보고서 등 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 설명하거나 /slides, /docs, /designs를 입력합니다.
  3. Claude가 던지는 질문에 답하고 나온 초안을 확인합니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  5. 수정 반복은 Sonnet 5.5로 바꿔 문구 다듬기, 차트 교체, 색상 팔레트 변경을 합니다.
예시 프롬프트
신제품 출시 브리프야: 대상은 30~40대 직장인, 핵심 메시지는 '퇴근 30분 앞당기기'. 이 브리프로 발표 슬라이드 10장과 소셜용 이미지 3종, 현장용 한 장 요약 문서를 만들어 줘.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • 질문 내용은 사용자마다 다르게 나옵니다.

디자인 시스템 만들고 적용

Claude Design

디자인 시스템은 색, 폰트, 여백 같은 브랜드 규칙 모음입니다. 먼저 만들어 두면 이후 슬라이드에 자동 적용되어 AI 티가 줄고, PPTX로 내보낼 수 있습니다. Claude Design은 베타입니다.

따라 하기

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create를 누릅니다.
  2. 회사 이름과 설명을 적고, 기존 자료가 있으면 피그마 파일이나 GitHub 주소를 넣습니다.
  3. 폰트 파일을 업로드하고 Continue to generation을 눌러 생성합니다.
  4. 초기 화면에서 만든 디자인 시스템을 선택하고 Slide deck 프로젝트를 새로 만듭니다.
  5. 슬라이드 장수와 주제를 입력하고 Claude의 질문에 답한 뒤 Continue를 누릅니다.
예시 프롬프트
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • 디자인 시스템 없이 쓰면 결과물이 AI스럽게 나올 수 있다는 평가가 있습니다.
  • Claude Design 사용량은 5월 말 업데이트로 Claude Code 사용량과 통합되었습니다.

PowerPoint에서 직접 다듬기

Claude in PowerPoint

PowerPoint 안에서 Claude를 불러 슬라이드를 추가하거나 선택한 부분만 고칠 수 있습니다. 템플릿을 연 채 요청하면 브랜드 서식을 따릅니다.

따라 하기

  1. PowerPoint에서 템플릿을 연 채 슬라이드 수, 주제, 다룰 항목, 어조를 적어 덱 초안을 요청합니다.
  2. 고칠 슬라이드나 개체를 선택한 뒤 요청해 선택한 부분만 수정합니다.
  3. + 버튼으로 보고서나 데이터 파일을 올려 자료 기반 슬라이드를 만듭니다.
  4. 복잡한 템플릿은 브랜드 지침에 맞는지 직접 확인합니다.
  • 복잡하거나 많이 맞춤화된 템플릿은 결과를 직접 확인하세요.
  • 민감한 데이터는 조직의 데이터 처리 정책을 따르세요.

디자인 규칙서로 톤 고정하기

Claude Code

AI가 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 색, 글꼴, 크기, 장당 글자 수를 수치로 정한 규칙서를 스킬로 저장하면 다음 작업에서도 같은 톤이 나옵니다. 고급 단계이니 익숙해진 뒤 도전하세요.

따라 하기

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준으로 디자인 규칙서를 만듭니다.
  2. 규칙서로 Claude Code나 코덱스에서 PPT 작업을 합니다.
  3. 작업을 마친 뒤 대화와 결과물로 스킬을 만들어 달라고 요청합니다.
  4. 다음 PPT 작업 때 그 스킬을 불러와 대본만 넣습니다.
예시 프롬프트
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 수치로 적습니다.
  • 차트는 이미지가 아니라 데이터 편집이 가능한 형태로 요청합니다.

숫자 확인하고 내보내기·공유

Claude

발표 전에 숫자와 인용을 원문과 대조하고, 내보내기나 공유로 마무리합니다. 팀원마다 접근 권한을 정해 함께 편집할 수도 있습니다.

따라 하기

  1. 슬라이드 속 숫자와 인용을 원문과 직접 대조합니다.
  2. 공유로 팀원을 초대하거나 내보내기로 파일을 저장합니다.
  3. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  4. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  5. PPTX로 받았다면 파일을 열어 폰트와 레이아웃을 확인합니다.
예시 프롬프트
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘
  • Slides는 PDF, 파워포인트, PNG, 구글 슬라이드로 내보낼 수 있습니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
