Claude

완벽한 프롬프트보다 상황과 기준을 충분히 알리는 것이 중요합니다. 음성 받아쓰기로 길게 말하면 시간이 줄고 생각도 정리됩니다.

따라 하기

  1. 음성 받아쓰기로 상황, 목적, 기준을 길게 말합니다.
  2. 관련 파일이나 화면 캡처를 많이 붙입니다.
  3. 결과를 직접 읽고 맞는지 판단합니다.
  4. 부족한 부분은 기준을 더 알려 다시 요청합니다.
예시 프롬프트
지금 상황을 설명할게. 나는 기획팀 대리이고, 다음 주 경쟁사 비교 보고를 준비 중이야. 기준은 한 장으로 요약 가능하고 출처가 있어야 해.
  • 맥락을 많이 주는 것과 결과를 판단하는 능력이 가장 중요합니다.

웹 검색·딥 리서치로 조사

Claude

웹 검색을 켜면 최신 정보와 출처를 받고, 시장 조사나 경쟁사 분석처럼 깊은 조사에는 딥 리서치 모드를 씁니다.

따라 하기

  1. + 버튼에서 웹 탭을 눌러 웹 검색을 켭니다.
  2. 깊은 조사는 + 버튼에서 연구를 눌러 딥 리서치를 켭니다.
  3. 조사할 내용을 프롬프트로 요청합니다.
  4. 답변의 출처 링크를 열어 확인합니다.
예시 프롬프트
국내 사무용 협업 도구 시장의 주요 경쟁사 세 곳을 비교하고, 출처 링크와 함께 표로 정리해 줘.
  • 모델은 검색 도구 없이는 훈련 이후의 사실을 확실히 알지 못합니다.

노트북LM에 자료 모아 질문

NotebookLM

노트북LM은 내가 올린 자료만 근거로 답하고 출처 번호를 달아 줍니다. 프로젝트별 노트북에 파일, 링크, 유튜브 자료를 모아 질문합니다.

따라 하기

  1. 노트북LM에서 새 노트 만들기를 누르고 제목을 프로젝트 이름으로 바꿉니다.
  2. 소스 추가로 파일, 링크, 유튜브, 드라이브 자료를 넣습니다.
  3. 채팅창에 질문하고 답변의 숫자를 눌러 출처를 확인합니다.
  4. 좋은 답변은 메모에 저장을 누릅니다.
  5. 오른쪽 스튜디오에서 마인드맵 등으로 정리합니다.
예시 프롬프트
AI 전문 강사 스타일로 답변해 줘
  • 웹 검색은 약하니 최신 정보는 제미나이로 보완하세요.
  • 채팅 설정은 노트북마다 따로 적용됩니다.

엑셀에서 숫자 분석하기

Claude in Excel

Claude in Excel은 통합 문서 전체를 이해하고 질문 답변, 오류 추적, 피벗 테이블, 차트 작성까지 도와줍니다.

따라 하기

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. 응답의 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
  5. 피벗 테이블을 요청하고 그 표로 차트를 만듭니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.
  • 오류는 Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • 리서치 프리뷰 베타입니다.

Claude

질문에 원하는 답을 흘리면 AI가 그쪽으로 맞춰 주기 쉽습니다. 결론을 숨기고 찬성·반대 논거를 모두 요청하세요.

따라 하기

  1. 원하는 결론을 드러내지 않고 질문합니다.

  3. 한쪽으로 치우친 답은 반박하고 균형을 요청합니다.
  4. 같은 질문을 다른 각도에서 다시 물어봅니다.
예시 프롬프트
이 결정에 대한 가장 강력한 찬성 논거와 반대 논거는 무엇인가요? 어느 쪽도 편들지 말고 근거와 함께 알려 주세요.
  • 일반 대화에도 똑같이 유용합니다.

출처와 숫자 검증하기

Claude

보고서에 들어갈 숫자·날짜·인용은 반드시 원문에서 확인합니다. 신뢰는 스위치가 아니라 다이얼처럼 질문의 중요도에 따라 조절하세요.

따라 하기

  1. 주장마다 근거 출처를 요청합니다.
  2. 제시된 링크를 직접 열어 내용이 있는지 확인합니다.
  3. 의심스러운 부분은 얼마나 확신하는지 묻습니다.
  4. 새 대화나 다른 AI로 교차 검증합니다.
예시 프롬프트
방금 답에 쓴 수치와 인용마다 출처를 알려 줘. 확신이 낮은 부분은 따로 표시하고, 모르는 것은 모른다고 말해 줘.
  • AI가 없는 출처를 그럴듯하게 만들 수 있습니다.
  • 상사에게 보일 통계·법률·금전 문제는 반드시 확인하세요.

Word에서 보고서 다듬기

Claude for Word

Claude for Word는 모든 수정을 추적 변경으로 남겨 직접 수락하거나 거절할 수 있습니다. 사실 확인, 고쳐 쓰기, 분량 줄이기를 맡깁니다.

따라 하기

  1. Word 오른쪽의 Claude 패널을 엽니다.
  2. Turn on Track Changes and keep it on for everything you do in this document.라고 요청합니다.
  3. 본문의 수치와 주장을 근거 문서와 대조하게 합니다.
  4. 고쳐 쓸 문단을 선택하고 요청한 뒤 카드별로 확인합니다.
  5. 서식 정리 때는 Don't change anything else.를 덧붙입니다.
예시 프롬프트
We need to get this under 1,000 words, but don't cut any more than you need to.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.
