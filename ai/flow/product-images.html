이미지 서비스 연결하기

Claude 커넥터

Artlist를 연결하면 채팅 안에서 이미지를 만들고 고칠 수 있습니다. 기획은 AI 채팅이, 생성은 Artlist 크레딧이 맡습니다.

따라 하기

  1. Artlist 사이트에서 MCP 메뉴로 들어가 Claude를 선택하고 MCP URL을 복사합니다.
  2. Claude에서 이름을 눌러 설정으로 들어갑니다.
  3. 맨 아래 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  4. 이름에 Artlist를 쓰고 URL을 붙여 넣은 뒤 계속을 누릅니다.
  5. 채팅창의 + → 커넥터에서 Artlist가 파란색(사용 중)인지 확인합니다.
  • 연결은 처음 한 번만 하면 되고 회색이면 사용 안 함 상태입니다.
  • ChatGPT에서는 설정에서 개발자 모드를 켠 뒤 커넥터를 만들어 연결합니다.

대표 이미지 만들기

Claude + Artlist

생성 전에 체크만 시키면 크레딧을 아낄 수 있습니다. 모델, 비율, 해상도를 구체적으로 적어 대표 이미지를 만들고 착용샷·디테일 컷으로 넓힙니다.

따라 하기

  1. Artlist 커넥터로 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 요청합니다.
  2. 생성 없이 체크만 해 달라고 하며 사진을 첨부하고 업로드 위젯으로 올립니다.
  3. 모델, 비율(정사각형), 해상도(2K) 등을 적어 대표 이미지를 요청합니다.
  4. 착용샷·디테일·배너 등을 추가로 요청합니다.
  5. 유지할 것과 바꿀 것을 나누어 수정합니다.
예시 프롬프트
첨부한 운동화 사진으로 흰 배경의 정사각형 2K 대표 이미지를 만들어 줘. 신발 형태와 로고는 그대로 유지해 줘.
  • 재생성하면 크레딧이 추가로 소진됩니다.
  • 제품 이미지를 먼저 확정한 뒤 영상으로 만들면 일관성이 유지됩니다.

배경 바꾸고 로고 다듬기

Gemini

같은 대화에서 이어 요청하면 필요한 부분만 고칠 수 있습니다. 로고는 제미나이가 알려 주는 의뢰 양식에 맞춰 엠블럼을 만든 뒤 미리캔버스에서 마무리합니다.

따라 하기

  1. 수정할 사진을 업로드합니다.
  2. 없앨 대상을 지정하고 '다른 부분은 바꾸지 말고 빈 곳은 자연스럽게 채워 줘'라고 요청합니다.
  3. 배경 교체는 바꿀 장소를 말하고 '빛과 조명도 자연스럽게'라고 덧붙입니다.
  4. 로고는 의뢰 양식(주제·상징물·스타일·색상·분위기)을 물어 그에 맞춰 요청합니다.
  5. 엠블럼을 다운로드해 미리캔버스에서 텍스트를 넣고 JPG, 고해상도로 저장합니다.
예시 프롬프트
이 사진에서 오른쪽 사람만 지워 줘. 다른 부분은 바꾸지 말고 빈 곳은 자연스럽게 채워 줘.
  • 화면 캡처 대신 다운로드해야 화질이 깨지지 않습니다.
  • 결과는 매번 달라지므로 마음에 들지 않으면 같은 요청을 다시 시도하세요.
  • 미리캔버스의 왕관 표시 폰트는 유료입니다.

광고 시안과 상세페이지 만들기

Genspark Design

광고 레퍼런스와 제품 사진을 넣고 광고 키 비주얼을 만든 뒤, 그 시안을 기준으로 디자인 시스템을 정리해 상세페이지와 랜딩페이지로 이어 갑니다.

따라 하기

  1. Genspark 디자인에서 +를 눌러 광고 레퍼런스와 제품 사진을 첨부하고 광고 키 비주얼을 요청합니다.
  2. 되묻는 질문에 답합니다. 잘 모르는 질문은 비워 두면 AI가 제안합니다.
  3. 조정이나 편집으로 톤·글자를 수정합니다.
  4. 광고 시안을 기준으로 디자인 시스템을 정리하게 한 뒤 상세페이지와 랜딩페이지를 요청합니다.
  5. 결과를 다운로드로 저장합니다.
예시 프롬프트
첨부한 광고 레퍼런스의 분위기를 따라 이 제품의 광고 키 비주얼을 만들어 줘. 제품 형태와 로고는 원본 그대로 유지해 줘.
  • 빌드하기로 실제 웹사이트까지 만들 수 있고, 공유로 편집자를 초대할 수 있습니다.

사진 여러 장을 영상으로

Artlist Kling 4.0

시작·중간·끝 프레임에 사진을 최대 10장까지 넣어 하나의 영상으로 만듭니다. 따로 편집 프로그램에서 이어 붙이는 과정이 사라집니다.

따라 하기

  1. Artlist에서 AI 비디오로 이동합니다.
  2. 모델 선택의 올 모델에서 Kling 4.0을 선택하고 유즈 모델을 누릅니다.
  3. 스타트 프레임의 업로드 이미지로 첫 장면 사진을 넣습니다.
  4. 미들 프레임을 눌러 장면 사진을 순서대로 넣고 마지막 사진은 엔드 프레임으로 넣습니다.
  5. 사진 순서에 맞춰 장면 흐름을 적고 비율과 길이(최대 30초)를 정해 제너레이트를 누릅니다.
  • 프롬프트는 GPT나 Claude에 사진 순서를 보여 주고 문안을 제안받아도 됩니다.
  • 장면이 너무 많으면 파트를 나눠 생성하세요.
  • 30초 영상이 약 1분 만에 만들어졌고 배경 음악과 목소리까지 함께 생성됩니다.

영상의 제품만 바꾸기

Newtake

같은 영상에서 제품이나 모델만 바꾸고 싶을 때 구간을 지정해 교체합니다. 구간이 짧을수록 크레딧이 덜 듭니다.

따라 하기

  1. Newtake 캔버스에서 이미지 노드로 모델과 제품 이미지를 만듭니다.
  2. 참조 이미지를 선택해 비디오 생성으로 광고 영상을 만듭니다.
  3. 영상을 선택하고 구간 리메이크를 눌러 바꿀 구간을 지정합니다.
  4. 바꿀 제품 이미지를 끌어다 연결하고 선글라스를 안경으로 바꿔 줘처럼 입력합니다.
  5. 원본과 결과를 비교해 확인합니다.
예시 프롬프트
선글라스를 안경으로 바꿔 줘.
  • 프롬프트에 어떤 이미지의 인물인지 구체적으로 써야 엉뚱한 인물이 섞이지 않습니다.
  • 모든 세부가 완전히 같지는 않습니다.

로고·형태·한글 문구 검수

Claude

AI 이미지는 로고, 제품 형태, 한글 문구가 달라질 수 있습니다. 업로드 전에 원본 사진과 나란히 비교해 달라진 곳만 원본대로 고칩니다.

따라 하기

  1. 원본 사진과 결과 이미지를 나란히 놓고 로고·형태를 확인합니다.
  2. 한글 문구의 오탈자와 변형을 확인합니다.
  3. 유지할 것과 바꿀 것을 나누어 다시 요청합니다.
  4. 재생성은 크레딧이 추가로 소진되므로 필요한 컷만 합니다.
예시 프롬프트
방금 만든 이미지를 첨부한 원본 사진과 비교해 로고·신발 형태·한글 문구가 달라진 곳이 있는지 점검해 줘. 달라진 곳만 원본대로 고쳐 줘.
  • 얼굴·로고는 원본 그대로 유지하라고 프롬프트에 못 박으세요.
