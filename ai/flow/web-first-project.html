Claude Code 설치하고 로그인

Claude Code

터미널이 낯설다면 데스크톱 앱이나 VS Code에서 시작합니다. 처음에는 데스크톱 앱으로 시작하고 익숙해지면 터미널로 넘어가는 것이 추천되었습니다.

따라 하기

  1. Claude Desktop 상단의 Code 토글(또는 코드 탭)로 전환합니다.
  2. VS Code라면 확장 패널에서 Anthropic이 만든 Claude Code 확장을 설치합니다.
  3. 터미널을 쓴다면 안내된 설치 명령을 실행하고 작업할 프로젝트 폴더에서 Claude Code를 실행합니다.
  4. Claude 계정(Pro, Max, Enterprise) 또는 API 키로 로그인합니다.
  • 실행한 폴더와 그 하위 폴더 전체에 접근 권한이 생기므로 폴더 위치를 확인하세요.
  • 웹(claude.ai/code)은 GitHub 저장소만 지원합니다.

디자인 시안 먼저 잡기

Claude Design

코드를 쓰기 전에 Claude Design으로 화면 시안을 빠르게 만들어 방향을 정합니다. 시안이 정해지면 Claude Code로 넘겨 실제 웹 서비스로 구현합니다.

따라 하기

  1. 웹에서 Claude Design에 접속합니다(유료 구독 필요).
  2. 만들고 싶은 화면을 일상 언어로 설명해 시안을 만듭니다.
  3. 부분별로 수정을 요청하고 댓글로 피드백합니다.
  4. 마음에 들면 Claude Code로 넘겨 구현을 지시합니다.
예시 프롬프트
우리 팀 설문 결과를 보여 주는 대시보드 화면을 만들어 줘. 상단에 응답자 수, 아래에 항목별 평균 차트가 있으면 좋겠어.
  • 디자인 시스템 없이 쓰면 결과물이 'AI스럽게' 나오기 쉽습니다.
  • 사용량 한도는 5월 말 업데이트로 Claude Code와 통합되었다는 안내가 있습니다.

계획 모드로 방향 잡기

Claude Code

계획 모드에서는 Claude가 파일을 수정하지 않고 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전에 방향을 고칠 수 있어 첫 작업에 알맞습니다.

따라 하기

  1. Shift+Tab을 눌러 입력창 아래에 plan mode가 표시될 때까지 전환합니다.
  2. 만들려는 내용과 알고 싶은 점을 구체적으로 요청합니다.
  3. Claude가 내놓은 계획을 검토하고 부족하면 추가·수정을 요청합니다.
  4. 좋으면 승인하고 파일 수정을 자동 수락할지 매번 물을지 고릅니다.
예시 프롬프트
앱 전체에 다크 모드를 넣고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마에 어울리는 대비 색을 쓰는 계획을 먼저 세워 줘.
  • 기본 모드에서는 파일 수정·명령 실행 전에 매번 허락을 묻습니다. 모든 단계를 확인하고 싶으면 이 모드를 유지하세요.
  • 권한을 건너뛰면 실수를 미리 잡기 어려우니 신중히 사용하세요.

CLAUDE.md로 규칙 정하기

Claude Code

CLAUDE.md는 프로젝트 루트에 두는 파일로 Claude가 세션을 시작할 때마다 읽습니다. 규칙을 적어 두면 같은 실수를 반복하지 않습니다.

따라 하기

  1. 프로젝트 폴더에서 /init을 실행해 CLAUDE.md를 생성합니다.
  2. 스택, 실행·테스트 명령어, 코드 스타일 규칙을 확인하고 고칩니다.
  3. 건드리면 안 되는 폴더 같은 금지 규칙을 추가합니다.
  4. 작업 중 반복해서 바로잡은 규칙은 저장하라고 명시적으로 요청합니다.
예시 프롬프트
방금 알려 준 규칙(커밋 메시지는 한국어로 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 매뉴얼이 아니라 지도처럼 씁니다.
  • AI가 자동 생성한 설정 파일은 사람이 검수하세요.
  • 어길 수 없는 규칙은 Hooks로 강제합니다.

첫 결과물 요청하고 확인

Claude Code 데스크톱 앱

폴더를 지정하고 자료 파일을 첨부해 원하는 결과물을 풀어 써서 요청합니다. 내장 브라우저에서 결과를 보고 수정할 점을 프롬프트로 이어 갑니다.

따라 하기

  1. 코드 탭의 로컬 옆 버튼에서 폴더 열기로 작업 폴더를 지정하고 워크스페이스 신뢰를 진행합니다.
  2. 설문 결과 CSV 같은 자료 파일을 첨부합니다.
  3. 만들고 싶은 결과물과 필요한 기능을 풀어 써서 요청합니다.
  4. 우측 내장 브라우저에서 확인하고, 필요하면 기본 브라우저에서 열기로 크롬에서 엽니다.
  5. 수정할 점은 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코드 탭은 Pro 플랜(월 20달러) 이상에서 사용할 수 있습니다.
  • 프롬프트를 너무 짧게 쓰면 Claude가 코드베이스를 더 뒤져 컨텍스트를 더 씁니다.

스스로 검증하게 하고 정리

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 작업이 길어지면 컨텍스트가 차므로 요약하거나 비워 가며 진행합니다.

따라 하기

  1. 계획에 무엇이 올바른 결과인지 성공 기준을 적습니다.
  2. 웹 UI라면 Claude in Chrome 확장을 설치해 Claude가 탭에서 직접 테스트하게 합니다.
  3. /context로 컨텍스트 사용량을 확인하고, 같은 기능이면 /compact, 새 기능이면 /clear를 씁니다.
  4. 만족하면 서브에이전트 코드 리뷰어로 점검하고 커밋 메시지를 만들게 합니다.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청합니다.
  • 압축하면 이전 대화의 세부 내용이 사라질 수 있습니다.

외출 중에도 세션 이어가기

Claude Code

원격 제어는 내 컴퓨터에서 도는 세션을 웹·모바일로 이어 가는 기능이고, 클라우드 세션은 GitHub 저장소를 클라우드에서 작업합니다. 상황에 맞게 고릅니다.

따라 하기

  1. 원격 제어는 터미널에서 claude remote-control을 실행해 표시된 URL이나 QR 코드로 접속합니다.
  2. 이미 실행 중인 세션은 /remote-control을 입력합니다.
  3. 클라우드 세션은 데스크톱 앱에서 Local 대신 Cloud를 고르고 저장소를 지정해 맡깁니다.
  4. 끝나면 변경 내용을 검토하고 Create PR로 풀 리퀘스트를 엽니다.
  • 원격 제어는 컴퓨터가 켜져 있어야 하고, 클라우드 세션은 커밋·푸시한 내용만 쓸 수 있습니다.
  • 영상 기준 제공 플랜이 달라 내 플랜에서 되는지 확인하세요.

공개 전 점검하고 올리기

Claude Code

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

웹사이트를 다른 사람에게 보이려면 먼저 비밀번호·개인정보가 코드에 들어 있지 않은지 확인합니다. 공개할 곳(호스팅)은 용도에 맞게 정하고, 방법은 Claude에게 단계별로 물어 따라 합니다.

따라 하기

  1. 사이트에 개인정보나 사내 기밀 자료가 들어 있지 않은지 Claude에게 점검을 요청합니다.
  2. 비밀번호·API 키가 코드 파일에 적혀 있지 않은지 확인합니다.
  3. 공개할 곳을 정하고 그곳의 배포 방법을 Claude에게 단계별로 물어봅니다.
  4. 공개 후 다른 기기에서 열어 화면을 확인합니다.
예시 프롬프트
이 사이트를 공개하기 전에 비밀번호, API 키, 개인정보가 코드에 들어 있는지 점검해 줘. 문제가 있으면 위치와 고치는 방법을 알려 줘.
  • 회사 자료가 들어간 사이트는 공개 전에 사내 규정을 확인하세요.

각 유튜브 채널의 공개 영상과 자막을 AI(Claude)가 요약·정리했습니다. 자세한 내용과 최신 화면은 원본 영상을 확인하세요. 영상의 저작권은 각 채널에 있습니다.
