AI 빌더로 홈페이지 만들기

Readdy

Readdy, 호스팅어 같은 AI 빌더는 업종과 분위기를 설명하면 여러 섹션의 반응형 홈페이지를 만듭니다. 수정은 부분을 찍어 말로 요청합니다.

따라 하기

  1. 입력창에 업종, 사업 이름, 대상, 분위기, 넣을 섹션을 적습니다.
  2. AI가 제작을 마칠 때까지 2~5분 기다립니다.
  3. PC·모바일 화면을 모두 확인합니다.
  4. 편집 선택으로 고칠 부분을 클릭해 요청합니다.
  5. 수정 요청은 한 번에 하나씩 입력합니다.
예시 프롬프트
우리 동네 필라테스 스튜디오 홈페이지를 만들어 줘. 대상은 30~40대 직장인 여성, 분위기는 차분한 베이지 톤, 섹션은 소개·수업 안내·가격·예약 문의로 구성해 줘.
  • 생성된 임의 문구와 숫자·후기는 실제 사실에 맞게 고치세요.
  • Readdy는 요청 한 번마다 크레딧이 차감됩니다.

디자인 시안 먼저 만들기

Claude Design

Claude Design은 일상 언어로 설명하면 앱 화면 시안이나 클릭해 볼 수 있는 프로토타입을 만들어 줍니다. 마음에 들면 Claude Code로 구현을 넘길 수 있습니다.

따라 하기

  1. 메인 화면에서 Prototype 새 프로젝트를 만들고 디자인 시스템을 선택합니다.
  2. 만들고 싶은 화면을 입력하고 질문에 답한 뒤 Continue를 누릅니다.
  3. Comment로 영역을 지정해 Send to Claude로 수정을 요청합니다.
  4. 클릭해 볼 수 있는 프로토타입을 요청합니다.
  5. Share에서 Handoff to Claude Code 명령어를 복사해 둡니다.
예시 프롬프트
현재 앱을 살펴보고 앱에 맞는 온보딩 디자인 시안을 여러 개 만들어 줘
  • Pro·Max·Team·Enterprise 구독이 필요합니다.

계획부터 세워 구현 맡기기

Claude Code

Claude 데스크톱의 코드 모드에서 폴더를 지정하고 자료를 넣어 결과물을 만듭니다. 계획 모드로 먼저 계획을 받고 방향을 고친 뒤 승인합니다.

따라 하기

  1. 데스크톱 앱에서 코드 탭을 선택합니다.
  2. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정합니다.
  3. Shift+Tab으로 plan mode를 켜고 만들 내용을 구체적으로 요청합니다.
  4. 계획을 검토하고 수정한 뒤 승인합니다.
  5. 우측 내장 브라우저에서 결과를 확인하고 수정을 이어서 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 먼저 계획부터 세워 줘.
  • 사용량이 빨리 닳으면 모델을 한 단계 가벼운 것으로 바꾸세요.

CLAUDE.md로 규칙 고정하기

Claude Code

CLAUDE.md는 Claude Code가 세션을 시작할 때마다 읽는 규칙서입니다. 스택, 명령어, 금지 규칙을 적어 두면 같은 설명을 반복하지 않습니다.

따라 하기

  1. 프로젝트 폴더에서 /init으로 CLAUDE.md를 생성합니다.
  2. 스택과 규칙을 확인하고 필요한 내용을 고칩니다.
  3. 건드리면 안 되는 폴더 같은 금지 규칙을 적습니다.
  4. 반복해서 바로잡은 규칙은 저장해 달라고 요청합니다.
예시 프롬프트
반복해서 알려 준 규칙이니까 앞으로도 지키도록 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 목차처럼 쓰세요.
  • 자동 생성된 파일은 사람이 검수하세요.
