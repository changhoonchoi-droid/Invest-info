Claude Design

화면을 만들기 전에 시안을 먼저 보면 결과가 나아집니다. 마음에 드는 방향을 고르고 댓글로 고칩니다.

따라 하기

  1. Claude에서 방향 세 가지를 캔버스에 나란히 보여 달라고 요청합니다.
  2. 시안마다 팔레트, 폰트, 로고를 만들도록 지시합니다.
  3. 마음에 드는 시안을 고르고 댓글 기능으로 요소별로 수정합니다.
  4. 앱 화면이라면 클릭해 볼 수 있는 프로토타입을 요청합니다.
예시 프롬프트
우리 카페 신메뉴의 브랜드 방향 세 가지를 캔버스에 나란히 보여 줘. 시안마다 팔레트, 폰트, 로고, 인스타 샘플 한 장씩 만들어 줘.
  • Tweaks로 여러 변형을 비교해 고를 수 있습니다.
  • Pro 이상 구독이 필요합니다.

따라 하기

  1. 프레이머 마켓플레이스에서 마음에 드는 템플릿을 고르고 프리뷰를 엽니다.
  2. 스크롤 캡처 도구로 사이트 전체를 캡처합니다.
  3. 구글 AI 스튜디오 입력창에 이미지를 붙여 넣습니다.
  4. 비슷한 느낌으로 만들어 달라고 요청하고 빌드로 결과를 확인합니다.
예시 프롬프트

계획 모드로 계획 세우기

Claude Code

계획 모드에서는 Claude가 파일을 수정하지 않고 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전에 방향을 고칠 수 있습니다.

따라 하기

  1. Claude Code를 작업 폴더에서 엽니다.
  2. Shift+Tab을 눌러 plan mode가 표시될 때까지 전환합니다.
  3. 만들려는 내용을 구체적으로 요청합니다.
  4. 나온 계획을 검토하고 부족하면 수정을 요청합니다.
  5. 계획이 좋으면 승인합니다.
예시 프롬프트
앱 전체에 다크 모드를 넣고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마에 어울리는 대비 색을 쓰는 계획을 먼저 세워 줘.
  • 프롬프트는 가능한 한 구체적으로 씁니다.

데스크톱 앱에서 첫 화면 만들기

Claude Code

폴더를 지정하고 자료를 첨부해 요청하면 개발 지식 없이도 웹사이트를 만들 수 있습니다. 어떻게 만들지는 AI에게 맡기세요.

따라 하기

  1. 클로드 데스크톱 앱의 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정합니다.
  3. 워크스페이스 신뢰를 진행합니다.
  4. 자료 파일을 첨부하고 만들 결과물과 기능을 풀어 써서 요청합니다.
  5. 우측 내장 브라우저에서 결과를 확인합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코드 탭은 Pro 이상에서 쓸 수 있습니다.
  • 기본 브라우저에서 열기로 크롬에서도 볼 수 있습니다.

에러를 잘 전달해 고치기

Claude Code

문제가 생겼을 때 단서를 충분히 주면 해결이 훨씬 잘 됩니다. 브라우저의 오류 메시지를 복사해 상황과 함께 전달합니다.

따라 하기

  1. 문제 화면에서 마우스 오른쪽 버튼을 눌러 검사를 엽니다.
  2. 콘솔 탭의 오류 메시지를 복사하거나 캡처합니다.
  3. 프롬프트에 붙여 넣고 언제 발생하는지 적습니다.
  4. 원래 기대하는 동작과 현재 문제를 함께 적습니다.
  5. 가능하면 스크린샷도 첨부합니다.
  • 언제·어디서·어떻게 발생했는지 많이 줄수록 해결이 잘 됩니다.

따라 하기

  4. 내 스타일에 맞는 커밋 메시지를 만들게 해 저장합니다.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청하세요.

배포하고 주소 받기

Codex

Vercel 플러그인을 쓰면 요청 한 번으로 페이지를 배포하고 주소까지 받을 수 있습니다. 포트폴리오 같은 페이지를 공개할 때 씁니다.

따라 하기

  1. Codex 좌측 상단 플러그인 탭에서 Vercel을 설치합니다.
  2. 새 채팅에서 새 프로젝트 추가, 처음부터 시작을 누릅니다.
  3. 페이지를 만들고 Vercel 플러그인으로 배포한 뒤 URL을 알려 달라고 요청합니다.
  4. 프리뷰와 배포 URL을 눌러 확인합니다.
  5. 수정이 필요하면 같은 대화에서 추가로 요청합니다.
예시 프롬프트
포트폴리오 랜딩 페이지를 만들고 Vercel 플러그인으로 배포한 뒤 URL을 알려 줘.
  • 공개하기 전에 회사 기밀이나 개인정보가 들어가 있지 않은지 확인하세요.
