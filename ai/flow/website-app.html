아티팩트로 작은 도구 만들기

Claude

아티팩트는 채팅 옆에 바로 작동하는 계산기·퀴즈·간단한 앱을 만들어 줍니다. 코딩 없이 만들기 감각을 익히기에 가장 쉽습니다.

따라 하기

  1. Claude 채팅창에 만들고 싶은 도구를 한 줄로 요청합니다.
  2. 채팅 옆에 나타난 아티팩트를 직접 사용해 봅니다.
  3. 고칠 부분을 채팅으로 수정 요청합니다.
  4. 공유하려면 게시해 링크로 받습니다.
예시 프롬프트
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 인포그래픽에도 쓸 수 있습니다.

디자인 시안 먼저 탐색하기

Claude 디자인

코드를 짜기 전에 짧게 디자인 시안을 탐색하면 결과가 좋아집니다. 시안 → 댓글 피드백 → 수정 → 클릭형 프로토타입 순서로 진행합니다. Pro 이상 구독이 필요합니다.

따라 하기

  1. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  2. 원하는 화면의 시안을 여러 개 만들어 달라고 요청합니다.
  3. 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  4. 마음에 들지 않는 세부는 에디터에서 직접 고칩니다.
  5. 클릭해 볼 수 있는 프로토타입을 만들어 달라고 요청합니다.
예시 프롬프트
현재 앱을 살펴보고 앱에 맞는 온보딩 디자인 시안을 여러 개 만들어 줘
  • Tweaks로 화면의 여러 변형을 비교해 고를 수 있습니다.

데스크톱 앱에서 Claude Code 준비하기

Claude Code

개발 지식이 없어도 Claude 데스크톱 앱의 Claude Code 모드로 폴더를 열고 결과물을 만들게 할 수 있습니다. 어떻게 만들지는 AI에 맡기고 무엇을 만들지에 집중합니다.

따라 하기

  1. Claude 데스크톱 앱에서 Claude Code 모드(상단의 Code 토글)를 선택합니다.
  2. 로컬 옆 버튼에서 폴더 열기를 눌러 작업할 폴더를 선택합니다.
  3. 폴더(워크스페이스) 신뢰를 허용합니다.
  4. 필요한 파일(예: CSV)을 첨부하고 만들 결과물을 풀어서 요청합니다.
  5. 우측 내장 브라우저에서 결과를 확인하고 필요하면 기본 브라우저에서 열기로 크롬에서 엽니다.
예시 프롬프트
첨부한 설문 결과 CSV로, 팀원 누구나 브라우저로 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 연령대별 만족도 막대그래프와 주요 의견 요약을 넣어 줘.
  • 사용량이 빨리 닳으면 모델을 한 단계 가벼운 것으로 바꿉니다.

계획 모드로 안전하게 시키기

Claude Code

큰 작업은 계획 모드로 먼저 방향을 잡으면 실수를 줄입니다. 코드가 쓰이기 전인 계획 단계가 방향을 고치기 가장 좋은 시점입니다.

따라 하기

  1. Shift + Tab을 눌러 Plan mode로 전환합니다.
  2. 만들려는 내용과 알고 싶은 점을 구체적으로 요청합니다.
  3. Claude가 내놓은 계획을 검토하고 부족하면 추가·수정을 요청합니다.
  4. 계획이 좋으면 승인하고 파일 수정을 자동 수락할지 매번 물을지 고릅니다.
예시 프롬프트
앱 전체에 다크 모드를 추가하고 싶어. 헤더에 토글 스위치를 만들고, 기존 라이트 테마와 어울리는 대비 색을 쓰도록 계획을 먼저 세워 줘.
  • 모든 단계를 직접 확인하고 싶으면 기본 승인 모드를 유지하세요.
  • 권한 무시는 작업 폴더 범위를 확인한 뒤에만 켭니다.

AI 빌더로 홈페이지 만들기

Readdy AI

Readdy AI, 호스팅어 AI 빌더, 구글 AI 스튜디오는 사이트 설명이나 스크린샷만으로 홈페이지를 만들어 줍니다. 시안을 빠르게 만들고 말로 고쳐 갑니다.

따라 하기

  1. Readdy AI에 로그인하고 계정 메뉴의 Language에서 한국어를 선택합니다.
  2. 입력창에 사이트 종류, 대상, 분위기, 넣을 섹션을 적어 전송합니다.
  3. 완성된 사이트를 PC·모바일 화면으로 확인합니다.
  4. 마음에 드는 사이트를 캡처해 해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘라고 요청할 수도 있습니다.
예시 프롬프트
치과 병원 홈페이지를 만들어 줘. 대상은 30~50대 직장인, 분위기는 깔끔하고 따뜻하게, 섹션은 소개·진료 안내·예약 문의·오시는 길로 구성해 줘.
  • 디자인은 말보다 이미지가 정확합니다.
  • Readdy는 요청 한 번마다 25 크레딧이 차감되고 공개 게시에는 유료 결제가 필요합니다.

결과를 직접 확인하고 검증하기

Claude Code

성공 기준을 분명히 적고 Claude가 직접 테스트하게 하면 품질이 안정됩니다. 웹 화면은 Claude in Chrome으로 탭에서 확인하게 할 수 있습니다.

따라 하기

  1. 계획에 무엇이 올바른 결과인지 성공 기준을 분명히 적습니다.
  2. 웹 UI라면 Claude in Chrome 확장을 설치해 Claude가 탭에서 직접 테스트하게 합니다.
  3. 직접 확인해 만족하면 서브에이전트 코드 리뷰어로 점검합니다.
  4. 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청합니다.
예시 프롬프트
이 변경의 성공 기준은 기존 테스트가 모두 통과하고 로그인 화면에 오류가 없는 거야. 먼저 계획을 세우고, 구현 후 테스트까지 돌려서 결과를 알려 줘.
  • 같은 실수가 나오면 다시 시키지 말고 CLAUDE.md나 스킬에 적어 두세요.
