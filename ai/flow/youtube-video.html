채널용 프로젝트 만들기

Claude 앱

영상마다 시청자와 말투를 다시 설명하면 대본 톤이 들쭉날쭉해집니다. 채널 전용 프로젝트에 지침과 참고 자료를 넣어 두면 모든 대본이 같은 톤으로 나옵니다.

따라 하기

  1. Claude에서 채널 이름으로 프로젝트를 새로 만듭니다.
  2. 커스텀 지침 칸에 대상 시청자, 말투, 분량, 형식을 적습니다.
  3. 지침 저장을 눌러 저장합니다.
  4. 채널 소개, 잘된 지난 대본 같은 참고 자료를 업로드합니다.
  5. 프로젝트 안에서 새 대화를 열어 영상 주제를 의논합니다.
예시 프롬프트
대상: 40대 직장인 유튜브 시청자. 톤: 쉽고 친근한 존댓말, 전문 용어는 한 줄 풀이를 붙일 것. 형식: 소제목 3~5개, 각 소제목 아래 핵심 요약 한 줄 먼저. 업로드한 자료에 없는 수치는 지어내지 말 것.
  • 쇼츠용·롱폼용처럼 형식별로 프로젝트를 나눠도 좋습니다.

대본을 컷 표로 쓰기

Claude 앱

영상 모델과 편집 단계는 컷 단위로 움직이므로 대본도 처음부터 컷 표로 씁니다. 컷 번호를 파일 이름과 맞추면 이후 음성·영상 파일 관리가 쉬워집니다.

따라 하기

  1. 작업 폴더를 만들고 단계가 끝날 때마다 결과 파일을 남기기로 정합니다.
  2. 주제와 핵심 내용을 알려 주고 대본을 표 하나로 써 달라고 요청합니다.
  3. 칸은 컷 번호, 화면 설명, 내레이션, 길이로 정합니다.
  4. 한 클립은 대사 세 줄, 10초 이하로 묶게 합니다.
  5. 확인이 필요한 수치는 따로 표시하게 합니다.
예시 프롬프트
'직장인 연말정산 꼭 챙길 3가지'를 주제로 60초 쇼츠 대본을 써 줘. 한 줄이 한 컷인 표로, 칸은 컷 번호·화면 설명·내레이션·길이(초)로 해 줘. 컷 하나는 10초를 넘지 않게 하고, 확인이 필요한 수치는 따로 표시해 줘.
  • 16초까지 묶었을 때는 대사 타이밍이 줄마다 최대 1.5초 흔들렸습니다.
  • 인물이 나오면 인물 묘사 문장을 정해 두고 모든 영상 프롬프트에 그대로 붙입니다.

ElevenLabs

따라 하기

  1. Claude에게 한글·영어 테스트 대사를 짧게 만들어 달라고 요청합니다.

  3. Eleven v4로 생성해 들어 봅니다.
  4. 같은 대사를 Multilingual v2로 생성해 억양·감정·발음을 비교합니다.
  5. 내 목소리가 필요하면 Create Voice → Instant Voice에서 30~40초를 일정한 톤으로 녹음해 복제합니다.
예시 프롬프트
ElevenLabs 음성 모델을 비교하려고 해. 내 채널 톤(차분하고 친근한 경제 설명)에 맞는 15초 분량 테스트 대사를 한글과 영어로 하나씩 써 줘. 숫자와 외래어를 섞어 줘.

감정 태그로 내레이션 만들기

ElevenLabs

ElevenLabs에는 감정 설정값이 거의 없어서 대사 안에 태그와 문장부호를 넣어 말투를 조절합니다. 컷 번호와 같은 파일 이름으로 저장하면 편집이 쉬워집니다.

따라 하기

  1. 대사 앞에 대괄호로 연기 지시를 영어로 씁니다 (예: [whispers], [curious]).
  2. 감정 이름보다 말투로 쓰고, 한 줄에 한 개에서 세 개까지만 붙입니다.
  3. [beat]로 한 박자 쉬는 구간을 만듭니다.
  4. 말줄임표와 느낌표로 억양을 보강합니다.
  5. 생성해 들어 보고 태그를 다듬습니다.
  6. 컷마다 대사 파일을 만들고 파일 이름을 컷 번호와 맞춥니다.
예시 프롬프트
[whispers] 이건 우리끼리만 아는 얘긴데요... [beat] [curious] 혹시 벌써 들으셨어요?
  • 대괄호 안의 말은 소리로 읽히지 않고 뒤 대사를 어떻게 말할지만 정합니다.
  • 잘 먹히는 태그를 모르겠으면 Claude에게 감정 표현 프롬프트 설계 방법을 찾아 달라고 해도 됩니다.

사진으로 영상 클립 만들기

Kling 4.0

Artlist의 Kling 4.0은 사진을 최대 10장까지 시작·중간·끝 프레임에 넣어 최대 30초 영상 한 편을 만들어 줍니다. 편집 프로그램 없이 장면 전환이 이어진 클립을 얻을 수 있습니다.

따라 하기

  1. Artlist에서 AI 비디오로 이동합니다.
  2. 모델 선택에서 올 모델을 열고 Kling 4.0을 고른 뒤 유즈 모델을 누릅니다.
  3. 스타트 프레임의 업로드 이미지로 첫 장면 사진을 넣습니다.
  4. 미들 프레임에 중간 장면 사진을 순서대로 넣고, 마지막 사진은 엔드 프레임에 넣습니다.
  5. 사진 순서에 맞춘 장면 흐름 프롬프트를 입력합니다.
  6. 비율(쇼츠는 세로)과 길이(최대 30초)를 정하고 제너레이트를 누릅니다.
예시 프롬프트
이 사진들을 이 순서로 넣어 Kling 4.0으로 30초 영상을 만들려고 해. 이 순서로 영상이 자연스럽게 나올지 검토하고, 장면 흐름을 담은 영상 프롬프트를 써 줘.
  • 장면이 너무 많으면 파트를 나눠 생성하고, 강조할 장면은 앞뒤에 둡니다.
  • 직접 찍었거나 사용 허락을 받은 사진만 넣으세요.
  • 인물이 대사하는 장면이 필요하면 Higgsfield의 Seedance 2.5에 시작 스틸·캐릭터 시트·대사 오디오를 넣는 방법이 있습니다(크레딧 소모가 큼).

  3. 대본 표 형식, 컷 길이 규칙, 감정 태그 규칙, 사실 확인 단계를 포함하게 합니다.
  4. 생성된 SKILL.md의 설명(description)에 언제 쓰는 스킬인지 분명히 적혀 있는지 확인합니다.
  5. Claude Code를 다시 실행하고 /를 입력해 스킬이 목록에 보이는지 확인합니다.
  6. 다음 편 주제만 주고 스킬로 대본 표를 만들어 봅니다.

Claude Code

영상 자동화는 생성 크레딧처럼 한 번에 크게 나가는 비용이 있습니다. 비용이 드는 단계와 공개 직전에는 사람이 확인하도록 정하고, 상한을 걸어 폭주를 막습니다.

따라 하기

  1. 영상 생성처럼 크레딧이 드는 단계는 실행 전에 내 확인을 받도록 정합니다.
  2. 제출 전에 비용 견적 기능으로 크레딧을 확인합니다.
  3. 한 편당 크레딧 상한을 내 요금제에 맞게 정합니다.
  4. 업로드·공개는 자동으로 하지 않고 내가 직접 합니다.
  5. 만드는 AI와 검사하는 AI를 나눠, 다른 AI가 대본과 결과를 검증하게 합니다.
  6. 조회·반응 데이터를 보고 스킬과 규칙을 고칩니다.
  • 숏드라마 1화 전체에 2,450크레딧이 들었고, 견적 옵션을 잘못 넣어 128크레딧이 실제로 나간 사례도 있습니다.
  • 영상 속 크레딧 상한(쇼츠 500, 롱폼 1,500)은 제작자 본인의 값이므로 내 요금제에 맞게 정합니다.
