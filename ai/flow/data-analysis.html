지저분한 엑셀 정리하기

Cowork

여러 엑셀을 합치고 날짜 형식·빈칸·중복 행을 맞추는 일을 코워크에 맡깁니다. 원본은 건드리지 않게 하는 것이 핵심입니다.

따라 하기

  1. 데스크톱 앱에서 협업을 선택하고 작업 폴더를 항상 허용으로 지정합니다.
  2. 정리할 엑셀 파일을 폴더에 넣습니다.
  3. 날짜 형식·빈칸·중복 행 규칙을 적어 요청합니다.
  4. '원본은 그대로 두고 정리본은 새 파일로 저장'하라고 요청합니다.
  5. 결과 파일의 숫자를 확인합니다.
예시 프롬프트
폴더 안의 엑셀 파일들을 날짜 열 형식을 2026-11-07로 통일하고 빈칸과 중복 행을 정리해 줘. 원본은 그대로 두고 정리본은 새 파일로 저장해 줘.
  • 파일명에 날짜를 넣어 정리해 달라고 함께 요청하면 편합니다.

Excel에서 질문하고 근거 확인

Claude in Excel

Claude in Excel은 통합 문서 전체를 이해하고 셀 인용과 함께 답합니다. 오류 추적과 수식 설명에 특히 유용합니다.

따라 하기

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽습니다.
  5. 응답의 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
예시 프롬프트
Why is there an error in May?
  • 수식이 낯설면 부분별 설명을 요청하세요.
  • 민감한 데이터는 조직의 데이터 처리 정책에 맞는지 확인하세요.
  • Pro 이상 리서치 프리뷰 베타입니다.

  4. 출처 링크를 열어 내용을 확인합니다.
  • 최신 정보는 검색을 켜고 묻습니다.

대시보드 웹페이지 만들기

Claude Code

정리한 데이터를 첨부해 요청하면 누구나 브라우저에서 볼 수 있는 대시보드를 만들 수 있습니다.

따라 하기

  1. 데스크톱 앱 코드 탭에서 폴더 열기로 작업 폴더를 지정합니다.
  2. 워크스페이스 신뢰를 진행합니다.
  3. 정리한 CSV를 첨부합니다.
  4. 보여 줄 차트와 기능을 풀어 써서 요청합니다.
  5. 우측 내장 브라우저에서 확인하고 수정할 점을 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코드 탭은 Pro 이상에서 쓸 수 있습니다.

아티팩트로 팀과 함께 보기

Claude 앱

아티팩트는 링크로 공유하거나 팀원과 함께 고칠 수 있습니다. 댓글이 달리면 Claude에게 업데이트를 요청합니다.

따라 하기

  1. Artifacts 탭에서 새 아티팩트를 눌러 만들 것을 설명합니다.
  2. 우측 패널에서 결과를 직접 사용해 봅니다.
  3. 조직의 팀원을 추가하고 보기, 댓글, 수정 중 접근 수준을 고릅니다.
  4. 입력과 체크만 필요한 사람은 contributor로 지정합니다.
  5. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  • 공유된 아티팩트에서 "이번 주 팀이 한 일은?" 같은 요약을 요청할 수 있습니다.
  • 스타일 수정을 요청해도 내용과 상태는 유지됩니다.
