Excel에서 질문하고 검증하기

Claude in Excel

Excel 사이드바의 Claude는 통합 문서 전체를 이해해 질문 답변, 오류 추적, 피벗 테이블까지 도와줍니다. 인용 상자로 근거 셀을 열어 검증합니다.

따라 하기

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽습니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
예시 프롬프트
Why is there an error in May?
  • 수식이 낯설면 부분별로 설명해 달라고 요청합니다.
  • Pro, Max, Team, Enterprise 플랜에서 베타로 제공됩니다.
  • 외부 공유 결과물과 민감 데이터는 조직 정책을 따릅니다.

Claude in Excel

따라 하기

  1. 피벗 테이블이 필요한 기준(지역·제품 등)을 적어 요청합니다.
  2. 피벗 테이블로 차트를 만들게 합니다.
  3. 차트 종류와 제목을 요청으로 바꿉니다.
  4. 숫자가 맞는지 근거 셀로 이동해 다시 확인합니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.
  • 오류는 원인 셀까지 추적해 달라고 물으면 됩니다.

대시보드 웹사이트 만들기

Claude Code

폴더를 지정하고 CSV 같은 자료를 첨부해 요청하면 개발 지식 없이도 대시보드를 만들 수 있습니다. 어떻게 만들지는 AI에게 맡기고 무엇을 만들지에 집중하세요.

따라 하기

  1. Claude 데스크톱 앱에서 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정합니다.
  3. 폴더 선택 후 워크스페이스 신뢰를 진행합니다.
  4. CSV 같은 자료 파일을 첨부합니다.
  5. 만들고 싶은 결과물과 기능을 풀어 써서 요청합니다.
  6. 우측 내장 브라우저에서 결과를 확인하고 수정할 점은 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코워크·코드·디자인은 프로 플랜(월 20달러) 이상에서 사용할 수 있습니다.

오류가 나면 단서 전달하기

Claude Code

결과물에 문제가 생기면 단서를 충분히 줄수록 해결이 잘 됩니다. 개발 지식이 없어도 오류 메시지를 복사해 전달하면 됩니다.

따라 하기

  1. 문제 화면에서 마우스 오른쪽 버튼을 눌러 검사를 엽니다.
  2. 콘솔 탭의 오류 메시지를 복사하거나 캡처합니다.
  3. 프롬프트 창에 붙여 넣고 언제 발생하는지 적습니다.
  4. 원래 기대하는 동작과 현재 문제를 함께 적습니다.
  5. 가능하면 발생 화면 스크린샷도 첨부합니다.
  • 구체적 질문, 이미지 첨부, 공식 문서 제공도 성공률을 높입니다.

아티팩트 트래커 팀과 공유

Claude 앱

만든 문서나 트래커를 조직 팀원에게 공유하고 권한을 나눠 함께 씁니다. 체크리스트나 업무 현황판을 팀이 같이 갱신할 때 유용합니다.

따라 하기

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 우선순위별 체크박스가 있는 트래커를 요청합니다.
  4. 팀원을 추가하고 팀원별로 접근 수준을 고릅니다.
  5. 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시 프롬프트
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
