여러 시트 합치고 정리하기

Cowork

분석 전에 지점별·월별로 흩어진 엑셀을 하나로 합치고 형식을 통일해야 합니다. 정리 규칙을 구체적으로 주고, 원본은 건드리지 않게 합니다.

따라 하기

  1. 작업용 새 폴더에 합칠 엑셀 파일을 복사해 넣습니다.
  2. Claude 데스크톱 앱에서 폴더 추가로 그 폴더를 열고 항상 허용을 누릅니다.
  3. 날짜 형식·빈칸·중복 행 같은 정리 규칙을 적어 합치기를 요청합니다.
  4. 원본은 그대로 두고 결과는 날짜를 넣은 새 파일로 저장하게 합니다.
  5. 결과 파일의 행 수와 합계를 원본과 비교해 확인합니다.
예시 프롬프트
이 폴더의 지점별 매출 엑셀 5개를 하나로 합쳐 줘. 날짜는 YYYY-MM-DD로 통일하고, 빈칸은 '미입력'으로 표시하고, 완전히 같은 행은 하나만 남겨 줘. 원본은 그대로 두고 결과 파일명에 날짜를 넣어 줘.
  • 고객 정보 같은 민감한 열은 빼고 먼저 시험해 보세요.

Excel 사이드바에 질문하기

Claude in Excel

Claude in Excel은 통합 문서 전체를 이해하고 질문에 답하는 사이드바입니다. 무엇을 알고 싶은지 구체적으로 묻고 계산 과정을 함께 봅니다.

따라 하기

  1. Excel에서 합친 통합 문서를 엽니다.
  2. Windows는 Control + Alt + C, Mac은 Control + Option + C로 Claude 사이드바를 엽니다.
  3. 알고 싶은 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽습니다.
  5. 낯선 수식은 어떻게 작동하는지 물어봅니다.
예시 프롬프트
이 통합 문서에서 지난 분기 대비 매출이 가장 많이 줄어든 지역과 제품 3개를 찾아 주고, 계산 과정을 보여 줘.
  • Pro, Max, Team, Enterprise 플랜에서 쓸 수 있습니다.

Claude in Excel

보고에 쓸 수치는 피벗 테이블로 묶고 차트로 보여 주면 한눈에 들어옵니다. 피벗 → 차트 → 차트 다듬기 순서로 요청합니다.

따라 하기

  1. 지역·제품별 매출 피벗 테이블을 요청합니다.
  2. Now, create a chart from this pivot table showing revenue by region.처럼 차트를 요청합니다.
  3. Change the chart to be a stacked bar chart and add a title.처럼 차트 종류와 제목을 바꿉니다.
  4. 요청하지 않은 요소가 더해졌는지 확인하고 필요 없으면 빼 달라고 합니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.

근거 셀과 숫자 검산하기

Claude in Excel

분석 결과를 보고에 쓰기 전에 숫자가 어느 셀에서 왔는지 확인합니다. 오류가 있는 칸은 원인을 묻고, 합계는 직접 검산합니다.

따라 하기

  1. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 확인합니다.
  2. 오류가 보이면 Why is there an error in May?처럼 원인을 묻습니다.
  3. 핵심 합계 몇 개는 직접 SUM으로 검산합니다.
  4. 모든 숫자가 원본으로 추적되는지 확인해 달라고 요청합니다.
예시 프롬프트
이 시트의 요약 표에 나온 숫자마다 어떤 셀에서 계산됐는지 알려 주고, 원본 데이터와 다른 숫자가 있으면 표시해 줘.
  • 외부에 공유할 결과물과 민감한 데이터는 조직의 기준과 정책에 맞는지 확인합니다.

분석 결과를 슬라이드로 옮기기

Claude in PowerPoint

Excel과 PowerPoint를 함께 열면 한 세션에서 분석한 표와 차트를 덱에 바로 넣을 수 있습니다. 결과는 편집 가능한 PowerPoint 도형·차트로 들어갑니다.

따라 하기

  1. 분석한 Excel 파일과 회사 템플릿 PowerPoint 파일을 함께 엽니다.
  2. 같은 대화에서 차트와 핵심 발견을 덱에 넣어 달라고 요청합니다.
  3. 고칠 슬라이드를 선택해 그 부분만 수정을 요청합니다.
  4. 글머리표가 많은 슬라이드는 블록형 시각 레이아웃으로 바꿔 달라고 합니다.
  5. 브랜드 지침에 맞는지 직접 확인합니다.
예시 프롬프트
방금 만든 지역별 매출 차트와 핵심 발견 3가지를 열려 있는 PowerPoint 덱의 5번 슬라이드 뒤에 2장으로 넣어 줘. 각 장 제목은 결론 한 문장으로 써 줘.
  • Claude에 설정해 둔 Google Drive·Notion 커넥터가 애드인에서도 그대로 쓰입니다.

분석 흐름을 스킬로 저장하기

Claude in Excel

매달 같은 분석을 반복한다면 정리·피벗·차트·슬라이드 흐름을 스킬로 저장해 다시 실행합니다.

따라 하기

  1. 이번 분석을 마친 대화에서 지금까지의 흐름을 스킬로 저장해 달라고 요청합니다.
  2. 스킬에 입력 파일 형식, 정리 규칙, 만들 표·차트를 적게 합니다.
  3. 다음 달 데이터로 /를 입력해 스킬을 실행합니다.
  4. 결과를 지난달과 비교하고 아쉬운 점을 스킬에 반영합니다.
예시 프롬프트
오늘 한 매출 분석 흐름(지역·제품별 피벗, 누적 막대 차트, 전분기 대비 감소 상위 3개, 슬라이드 2장)을 '월간 매출 분석' 스킬로 저장해 줘.
  • 스킬은 일반 텍스트 파일이라 팀과 공유하면 누구나 같은 분석을 돌릴 수 있습니다.

BigQuery로 회사 데이터 묻기

Claude Code

엑셀을 넘어 회사 데이터베이스를 보고 싶다면 데이터 팀이 BigQuery MCP로 Claude Code에 연결해 줄 수 있습니다. SQL을 몰라도 말로 지표를 조회하고 그래프를 받습니다.

따라 하기

  1. 데이터 팀에 BigQuery MCP로 필요한 테이블을 Claude Code에 연결해 달라고 요청합니다.
  2. Claude Code에서 보고 싶은 지표와 기간을 말합니다.
  3. 조회할 데이터 테이블 이름을 알려 줍니다.
  4. 파일 수정 권한 요청이 나오면 내용을 보고 허용합니다.
  5. 만들어진 그래프를 확인하고 '요금제별로 나눠 그려 줘'처럼 이어서 요청합니다.
예시 프롬프트
지난 3개월 동안 신규 가입자 수를 주별 그래프로 그려 줘. 그다음 같은 그래프를 요금제별로 나눠서 다시 그려 줘.
  • 7일 이동평균처럼 요청하지 않은 요소가 더해질 수 있으니 결과를 꼭 확인하세요.
  • SQL을 쓰는 것보다 결과를 해석하는 일이 더 중요해집니다.
