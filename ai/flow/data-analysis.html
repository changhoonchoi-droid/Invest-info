흩어진 파일 정리하기

Cowork

분석 전에 여러 파일에 흩어진 데이터를 하나로 모읍니다. 폴더를 열어 주고 계획을 먼저 보게 한 뒤, 원본은 그대로 두고 정리본을 새 파일로 만들게 합니다.

따라 하기

  1. Claude 데스크톱 앱의 코워크에서 작업할 폴더를 엽니다.
  2. 합칠 파일과 정리 규칙을 적고 파일을 바꾸기 전에 계획을 보여 달라고 요청합니다.
  3. 원본 보존과 파일명 규칙(날짜 포함)을 함께 적습니다.
  4. 결과 파일을 열어 빠진 데이터가 없는지 확인합니다.
예시 프롬프트
이 폴더의 엑셀 세 개를 하나로 합쳐 줘. 파일을 바꾸기 전에 계획을 먼저 보여 주고, 원본은 그대로 두고 정리본은 새 파일로 저장해 줘. 파일명에는 날짜를 넣어 줘.
  • 웹 버전은 내 컴퓨터 파일에 접근할 수 없으니 데스크톱 앱에서 하세요.
  • 원본 보존은 반드시 프롬프트에 적어 둡니다.

회의록에서 실행 항목 뽑기

ChatGPT Work

회의록처럼 글로 된 자료에서 필요한 항목만 뽑아 시트로 만듭니다. ChatGPT Work는 파일과 앱을 다뤄 결과물까지 만들어 주는 모드로, 데스크탑 앱에서 씁니다.

따라 하기

  1. ChatGPT 데스크탑 앱을 설치하고 메인 화면에서 Work 모드를 선택합니다.
  2. 회의록 파일을 첨부합니다.
  3. 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 달라고 요청합니다.
  4. 복잡한 작업이면 + 버튼에서 계획 모드를 켜고 질문에 답합니다.
예시 프롬프트
첨부한 회의록에서 실행 항목만 뽑아 담당자·할 일·마감 세 개의 열로 된 스프레드시트로 만들어 줘.
  • 파일·앱을 다루는 기능은 데스크탑 전용입니다.
  • 추론 수준은 미디엄에서 시작하고 결과가 부족하면 올리세요.

엑셀에서 분석·피벗 만들기

Claude in Excel

엑셀 안에서 통합 문서 전체를 이해하는 Claude에게 질문하며 오류 추적, 수식 설명, 피벗 테이블, 차트까지 맡깁니다. 인용 상자로 근거 셀을 확인할 수 있어 검증이 쉽습니다.

따라 하기

  1. Excel에서 통합 문서를 열고 Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  2. 목표를 구체적으로 적어 질문하고 Claude가 보여 주는 계산 과정을 읽습니다.
  3. 응답의 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
  4. 지역·제품 등 기준을 적어 피벗 테이블을 요청하고, 이어서 차트를 요청합니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.
  • Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • Pro, Max, Team, Enterprise 플랜에서 베타로 제공됩니다.

숫자와 해석 검증하기

Claude 앱

AI가 낸 숫자와 해석을 그대로 믿지 않고 위험도에 맞춰 확인합니다. 숫자·날짜·인용은 원문 데이터와 직접 대조하고, 의심스러우면 새 대화나 다른 AI로 교차 검증합니다.

따라 하기

  1. 숫자·통계가 들어간 답변을 따로 표시합니다.
  2. 각 숫자의 근거와 확신도를 묻습니다.
  3. 새 대화에서 같은 질문을 던져 결과가 같은지 확인합니다.
  4. 최종 숫자는 원본 데이터와 직접 대조합니다.
예시 프롬프트
방금 분석에서 숫자, 날짜, 인용이 들어간 부분을 모두 뽑아 주고, 각각 얼마나 확신하는지와 확인할 수 있는 출처를 알려 줘.
  • 상사에게 보일 통계·금전 문제는 반드시 검증합니다.
  • 민감하거나 규제 대상인 데이터는 조직의 데이터 처리 정책을 따르세요.

아티팩트로 작은 도구 만들기

Claude 아티팩트

코딩 없이 채팅 옆에 바로 쓸 수 있는 작은 도구를 만듭니다. 간단한 계산기, 점수 측정기, 인포그래픽이 필요할 때 좋고, 흐름 정리에는 화이트보드도 쓸 수 있습니다.

따라 하기

  1. Claude 채팅창에 만들고 싶은 도구를 한 줄로 요청합니다.
  2. 우측 패널에 나타난 결과물을 직접 눌러 써 봅니다.
  3. 고치고 싶은 점을 채팅으로 다시 요청합니다.
  4. 공유하려면 게시해 링크로 받습니다.
예시 프롬프트
내 1일 칼로리 계산기 만들어 줘
  • 시트(Sheets)는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵습니다.
  • 예전 방식: 아티팩트의 대시보드는 지금 데이터(Data)라는 이름으로 바뀌었습니다.

대시보드 웹사이트 만들기

Claude Code

여러 사람이 브라우저에서 볼 대시보드가 필요하면 Claude Code 데스크톱 앱에서 데이터 파일을 첨부해 요청합니다. 어떻게 만들지는 AI에게 맡기면 됩니다.

따라 하기

  1. 코드 탭에서 폴더 열기로 작업 폴더를 지정합니다.
  2. 분석한 CSV 파일을 첨부합니다.
  3. 보여 줄 차트와 필요한 기능을 풀어 써서 요청합니다.
  4. 내장 브라우저에서 확인하고 수정할 점을 프롬프트로 요청합니다.
예시 프롬프트
첨부한 설문 결과 CSV로 팀원 누구나 브라우저에서 볼 수 있는 대시보드 웹사이트를 만들어 줘. 응답자 분포와 항목별 평균을 차트로 보여 줘.
  • 코드 탭은 Pro 이상 플랜이 필요합니다.
  • 생각 정리는 채팅, 파일 정리는 코워크, 웹사이트 제작은 코드, 발표 자료는 디자인으로 고릅니다.

보고서·슬라이드로 정리

Claude 앱

분석 내용을 담은 같은 대화에서 보고서(Docs)와 슬라이드(Slides)를 만듭니다. 이전 대화 내용을 바탕으로 만들어져 다시 설명할 필요가 줄어듭니다.

따라 하기

  1. 분석 결과를 대화로 먼저 정리합니다.
  2. /docs 또는 /slides를 입력하거나 원하는 결과물을 설명합니다.
  3. Claude가 묻는 질문에 답하고 초안을 확인합니다.
  4. 고칠 부분을 드래그해 댓글로 지시를 남깁니다.
예시 프롬프트
위 분석 결과를 임원 보고용 문서 한 장과 5장짜리 슬라이드로 만들어 줘. 숫자마다 해석을 한 줄씩 붙여 줘.
  • Slides, Docs, Design은 유료 요금제에서 베타로 제공됩니다.

팀과 공유하고 추적하기

Claude 아티팩트

완성한 문서·대시보드를 팀원과 함께 보고 편집합니다. 접근 권한을 나누고, 체크리스트형 트래커를 만들어 같이 쓸 수도 있습니다.

따라 하기

  1. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.

  3. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  4. 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시 프롬프트
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘
  • Artifacts 탭에서 내가 만든 것과 공유받은 것을 모아 볼 수 있습니다.
