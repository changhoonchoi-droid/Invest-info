자동화할 보고 업무 고르기

Cowork

모든 반복 업무를 자동화할 필요는 없습니다. 가장 부담이 큰 보고 하나를 골라 지금도 필요한지 점검하고, 남길 절차 가운데 Claude가 도울 부분을 찾습니다.

따라 하기

  1. 팀에서 가장 번잡하거나 모두가 꺼리는 보고 업무 하나를 고릅니다.
  2. 그 보고가 원래 어떤 목적으로 생겼는지 적어 봅니다.
  3. 지금도 그 목적에 도움이 되는지 스스로 묻습니다.
  4. 필요 없으면 없애고, 필요하지만 손이 많이 가면 Claude가 도울 부분을 찾습니다.
  5. 한 번에 한 단계씩 바꾸고 결과를 확인합니다.
  • 50명이 참석하지만 다들 노트북만 보던 주간 리뷰를 '왜 하는가'라는 질문 하나로 취소한 사례가 있습니다.
  • 절차는 스스로 사라지지 않고 계속 쌓이므로 의식적으로 정리해야 합니다.

데이터 출처 연결하기

Cowork

주간 보고에 쓰는 숫자와 대화가 있는 곳을 Cowork에 연결합니다. 연결해 둔 커넥터는 뒤에 만들 예약 작업에서도 그대로 쓰입니다.

따라 하기

  1. 보고에 쓰는 데이터가 어디 있는지(공유 드라이브, 데이터 파일, Slack 채널, 회의록) 적습니다.
  2. claude.com/connectors에서 연결할 수 있는 커넥터를 확인합니다.
  3. Cowork에 필요한 커넥터를 연결하고, 파일을 읽고 저장할 작업 폴더를 지정합니다.
  4. 후속 조치를 관리하는 Asana 같은 도구가 있으면 함께 연결합니다.

한 번 직접 시켜 보기

Cowork

예약을 걸기 전에 Cowork에서 이번 주 보고를 한 번 직접 시켜 결과가 마음에 드는지 봅니다. 여기서 원하는 순서와 결과물 모양이 정해집니다.

따라 하기

  1. Cowork에서 이번 주 보고 준비를 한 번 직접 시킵니다.
  2. 먼저 지표 표와 헤드라인만 있는 초안을 받아 봅니다.
  3. 데이터가 맞지 않으면 추측하지 말고 묻도록 지시합니다.
  4. 결과 형식과 순서가 마음에 들 때까지 고칩니다.
예시 프롬프트
지난주 지표 리뷰 문서, 이번 주 Slack 채널 대화, 공유 폴더의 주간 데이터 파일을 확인해서 주간 지표 리포트 초안을 만들어 줘. 지표 표와 헤드라인만 먼저 보여 주고, 데이터가 서로 맞지 않으면 추측하지 말고 나에게 물어봐 줘.

준비·검증·액션 스킬 만들기

Cowork

잘된 절차를 리뷰 준비, 교정(숫자 출처 검증), 액션 아이템 관리 스킬로 나눠 저장합니다. 검증을 스킬에 넣어 두면 매주 같은 기준으로 숫자를 점검합니다.

따라 하기

  1. 방금 한 과정을 리뷰 준비 스킬로 저장해 달라고 요청합니다.
  2. 초안의 모든 숫자가 확인된 출처로 이어지는지 점검하는 교정 스킬을 만듭니다.
  3. 후속 조치를 정리해 Asana 작업으로 남기는 액션 아이템 스킬을 만듭니다.
  4. 각 스킬을 /로 불러 실행해 보고 다듬습니다.
예시 프롬프트
방금 만든 주간 리포트 과정을 세 개의 스킬로 나눠 저장해 줘. 1) 리뷰 준비 2) 초안 속 모든 숫자가 원본 데이터 출처로 이어지는지 확인하는 교정 3) 액션 아이템 정리.
  • 스킬은 일반 텍스트 파일이라 언제든 열어 동작을 확인하고 고칠 수 있습니다.

일요일 저녁 예약 걸기

Cowork

매주 같은 때 하는 준비는 예약 작업으로 넘깁니다. 일요일 저녁에 돌려 두면 월요일 아침에 준비된 자료와 제안된 집중 영역을 받습니다.

따라 하기

  1. 이 작업을 매주 실행하고 싶다고 Claude에 요청합니다.
  2. Claude가 만든 예약 프롬프트 초안을 읽고 고칩니다.
  3. 주기를 매주 일요일 저녁으로 확인하고 수락합니다.
  4. 왼쪽 사이드바의 scheduled 페이지에서 작업을 확인합니다.
  5. 한 번 바로 실행해 결과를 봅니다.
예시 프롬프트
매주 일요일 저녁 8시에 지난 리뷰 문서, 이번 주 회의록, Slack 채널, 데이터 파일을 확인해서 월요일 지표 리뷰 준비 자료를 만들어 줘. 리뷰 준비 스킬과 교정 스킬을 차례로 쓰고, 이번 주 집중할 영역을 세 가지 제안해 줘.
  • 예약 작업은 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있을 때만 실행됩니다. 놓친 작업은 복귀 후 바로 실행되고 지연됐다고 알려 줍니다.
  • PC가 꺼져 있어도 돌아야 하면 클라우드에서 도는 Claude Code 루틴(/schedule)을 검토합니다.

월요일 초안 검토하기

Cowork

숫자 수집과 검증은 Claude가 했어도, 이번 주 이야기의 초점과 판단은 사람 몫입니다. 제안된 집중 영역을 보고 방향을 정해 줍니다.

따라 하기

  1. 월요일 아침 Cowork를 열어 준비 결과와 제안된 집중 영역을 확인합니다.
  2. 분기 리뷰 문서를 넣고 이번 주 초점을 지시합니다.
  3. Claude가 데이터 불일치를 알리면 처리 기준을 정해 줍니다.
  4. 지표 표와 헤드라인만 있는 초안을 먼저 확인합니다.
예시 프롬프트
이번 주는 신규 가입 감소에 초점을 맞춰 줘. 분기 목표 대비 차이를 헤드라인에 넣고, 지표 표와 헤드라인만 먼저 보여 줘.
  • 데이터가 맞지 않으면 Claude가 추측하지 않고 묻도록 되어 있으니, 그때 기준을 정해 주세요.

배운 점 스킬에 반영하기

Cowork

매주 내가 고친 내용을 스킬에 다시 넣어야 같은 지적을 반복하지 않습니다. 스킬을 팀과 공유하면 누구나 같은 방식으로 같은 결과를 냅니다.

따라 하기

  1. 이번 주 내가 고친 점과 새로 정한 기준을 정리합니다.
  2. 이번 주 배운 점을 스킬에 반영해 달라고 요청합니다.
  3. 피드백할 때마다 규칙으로 남겨 같은 지적을 반복하지 않게 합니다.
  4. 결과가 믿을 만해지면 내가 확인하는 지점을 조금씩 줄여 갑니다.
  5. 완성된 스킬을 팀원과 공유합니다.
예시 프롬프트
이번 주 내가 고친 내용(헤드라인은 분기 목표 대비로 쓰기, 환불 건은 매출에서 빼기)을 리뷰 준비 스킬과 교정 스킬에 반영해 줘.
  • 모델이 좋아지면 검증 수준도 달라질 수 있으니 주기적으로 다시 점검합니다.
