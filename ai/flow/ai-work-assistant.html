내 정보 설정 먼저 점검하기

Claude 앱

비서에게는 메일과 일정처럼 민감한 정보가 들어갑니다. 연결하기 전에 내 정보가 어디에 저장되고 학습에 쓰이는지 확인해 두면 직접 통제할 수 있습니다.

따라 하기

  1. 계정 또는 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 저장된 메모리 중 틀리거나 필요 없는 내용을 고치거나 지웁니다.
  3. 업무 정보를 다룰 계획이라면 학습 사용을 거부하는 옵트아웃 설정을 켜 둡니다.
  4. 개인 계정을 업무에 쓴다면 회사가 Claude를 조직 단위로 도입했는지 먼저 확인합니다.
  5. 기밀·규제 데이터를 다뤄야 한다면 비즈니스나 엔터프라이즈 플랜에서 데이터 처리 조건을 확인합니다.
예시 프롬프트
[고객명]님께 보내는 납기 지연 안내 메일을 정중하게 다듬어 줘. 납기는 [날짜]로 바뀌었어.
  • 제품에 따라 메모리가 기본으로 켜져 있을 수 있으니 처음 쓸 때 꼭 확인하세요.
  • 조직이 Claude를 도입한 경우 모델 학습은 기본적으로 꺼져 있습니다.
  • 실명이 필요 없는 작업은 예시처럼 이름을 자리표시자로 바꿔 입력합니다.

메일·캘린더·Slack 연결하기

Cowork

따라 하기

  • 9월 업데이트로 채팅과 Cowork가 하나의 Claude로 합쳐져 모드를 따로 고르지 않아도 됩니다.
  • 커넥터 목록은 claude.com/connectors 에서 볼 수 있습니다.

회의 준비 문서 맡기기

Cowork

회의 전에 흩어진 맥락을 모으는 일을 맡깁니다. Claude가 캘린더에서 회의를 찾고 관련 대화와 지난 회의록을 읽어 안건 문서를 만듭니다.

따라 하기

  1. 회의 상대와 시간을 알려 주며 회의 준비를 요청합니다.
  2. 캘린더 검색, 참석자 조사, Slack 스레드 확인, 이전 회의록 검토, 안건 작성을 요청하고 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  3. Claude가 세운 계획을 확인하고 작업이 진행되게 둡니다.
  4. 빠뜨린 출처가 있으면 작업 도중에 추가로 요청합니다(예: 이메일도 확인).
  5. 완성된 안건 문서를 작업 폴더에서 열어 검토하고, 빠진 내용은 추가를 요청하거나 직접 고칩니다.
예시 프롬프트
캘린더에서 내일 오후 2시 협력사 미팅을 찾고, 관련 Slack 대화와 이메일, 지난 회의록을 읽어서 회의 준비 문서를 만들어 줘. 참석자, 지난 논의 내용, 이번에 확인할 질문을 정리하고 기존 회의록 형식을 따라 줘.
  • 작업 도중 지시를 더해도 처음부터 다시 만들지 않고 방향만 바꿔 이어갑니다.
  • 최종 문서의 책임은 사용자에게 있으니 회의 전에 꼭 읽어 봅니다.

미팅 후속 처리 스킬 만들기

Cowork

미팅이 끝난 뒤의 정리는 매번 비슷합니다. 녹취록 처리 방식을 스킬로 만들어 두면 / 한 번으로 내 할 일, 팀 공유, 고객 후속 메시지 초안이 나옵니다.

따라 하기

  1. Cowork 세션에서 미팅 후 정리하고 싶은 내용을 설명해 스킬 파일 초안을 만듭니다.
  2. Claude가 파일을 읽고 저장할 폴더를 지정합니다.
  3. 지난 미팅 녹취록으로 스킬을 시험 실행해 결과를 보고 다듬습니다.
  4. 다음 미팅 후에는 /를 입력해 통화 녹취록 처리 스킬을 고릅니다.
  5. Claude가 만든 개인 할 일, 내부 Slack 메시지, 고객 후속 메시지를 하나씩 확인하고 승인한 뒤 보냅니다.
예시 프롬프트
방금 끝난 고객 미팅 녹취록을 정리해 줘. 1) 내가 할 일 목록 2) 팀 Slack에 올릴 요약 3) 고객에게 보낼 후속 메일 초안으로 나눠 주고, 보내기 전에 하나씩 확인받아 줘. 이 방식을 '미팅 후속' 스킬로 저장해 줘.
  • 피드백을 줄 때마다 그 내용을 스킬에 다시 반영하면 결과가 점점 좋아집니다.
  • 미팅 전 고객사 브리핑도 같은 방식으로 스킬을 만들어 둘 수 있습니다.
  • 이름을 걸고 보내는 답장이라면 브리핑이 가리키는 원문을 직접 확인합니다.

브라우저 조회 업무 맡기기

어사이드(Aside)

커넥터가 없는 사내 사이트 조회나 메일함 확인은 AI 브라우저에게 맡길 수 있습니다. 이미 결제 중인 Claude를 연결하면 어사이드에는 따로 돈을 내지 않아도 된다고 소개됩니다.

따라 하기

  1. Claude 데스크톱 앱을 설치하고 로그인합니다.
  2. 어사이드(Aside) 브라우저를 설치하고 이미 결제 중인 Claude(또는 GPT)를 연결합니다.
  3. 크롬의 로그인 정보를 어사이드로 가져와 로그인이 필요한 사이트도 쓸 수 있게 합니다.
  4. 할 일을 말로 설명해 맡기고, AI가 화면에서 클릭·입력하는 과정을 지켜봅니다.
  5. 결과를 확인하고 필요하면 이어서 다음 지시를 내립니다.
예시 프롬프트
받은 메일함에서 오늘 온 메일을 확인해서 답장이 필요한 것만 골라 정리해 줘.
  • 로그인 정보를 넘기는 만큼 회사 보안 규정에 맞는지 먼저 확인하세요.
  • 메일 확인, 사내 물류 사이트의 반품 확인 같은 조회 업무부터 시작하면 좋습니다.
  • Claude 앱 안에서 브라우저 작업을 맡기려면 Claude in Chrome을 따로 설정해야 합니다.

아침 업무 정리 예약하기

Cowork

비서의 기본기는 출근 전에 오늘 할 일을 정리해 두는 것입니다. 한 번 직접 시켜 결과를 확인한 뒤 평일 아침에 자동으로 돌게 예약합니다.

따라 하기

  1. 오늘 받은 메일과 일정으로 할 일 정리를 한 번 직접 시켜 보고 결과가 마음에 드는지 확인합니다.
  2. 이 작업을 평일 아침마다 실행하고 싶다고 말합니다.
  3. Claude가 만든 예약 작업 프롬프트 초안을 읽고 필요한 부분을 고칩니다.
  4. 실행 주기를 확인하고 승인해 등록합니다.
  5. 왼쪽 사이드바의 예약(scheduled) 페이지에서 작업을 확인하고 한 번 바로 실행해 봅니다.
예시 프롬프트
매일 아침 Gmail과 캘린더를 확인해서 오늘 회의, 답장이 필요한 메일, 마감이 다가온 일을 한 장으로 정리해 주는 작업을 평일마다 오전 8시에 실행하도록 예약해 줘.
  • 6월 영상 기준으로는 실행 시각에 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 합니다. 9월 통합 이후 달라졌는지는 첫 회차에서 확인하세요.
  • 데이터가 맞지 않으면 Claude가 추측하지 않고 질문하므로, 결과의 숫자는 출처를 함께 확인합니다.

사람이 확인할 지점 정하기

Claude 앱

비서에게 권한을 넉넉히 줄수록 편해지지만, 외부 발송이나 삭제처럼 되돌리기 어려운 일은 실수 한 번이 큽니다. 어디서 내 확인을 받을지 미리 정해 지시와 스킬에 적어 둡니다.

따라 하기

  1. 비서에게 맡긴 일을 읽기·정리처럼 되돌릴 수 있는 일과 외부 발송·삭제처럼 되돌리기 어려운 일로 나눕니다.
  2. 읽기·정리는 넉넉히 맡기고, 되돌리기 어려운 일은 실행 전에 내 확인을 받도록 지시와 스킬에 적습니다.
  3. 메일·Slack 답장은 초안까지만 만들게 하고 하나씩 검토한 뒤 승인해 보냅니다.
  4. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  5. Claude가 스스로 결과를 확인할 수 있게 기준을 알려 주어 중간 확인을 줄입니다.
예시 프롬프트
앞으로 메일과 Slack 메시지는 초안만 만들고 바로 보내지 마. 파일 삭제와 외부 공유도 실행 전에 반드시 나에게 확인받아 줘.
  • Cowork·Claude Tag·Duet 모두 사용자를 대신해 보내거나 바꾸기 전에 확인을 받는 구조이니 승인 단계를 건너뛰지 마세요.
  • 폭주하는 작업에 대비해 멈출 장치를 두라는 조언도 있습니다.
