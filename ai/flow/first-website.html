Claude 데스크톱 앱

폴더를 지정하고 자료 파일을 첨부해 요청하면 웹사이트를 만들 수 있습니다. 어떻게 만들지는 AI에게 맡기고 무엇을 만들지에 집중하세요. 코드 기능은 Pro(월 20달러) 이상에서 쓸 수 있습니다.

따라 하기

  1. 클로드 데스크톱 앱에서 코드 탭으로 들어갑니다.
  2. 로컬 옆 버튼으로 폴더 열기를 눌러 작업 폴더를 지정합니다.
  3. 폴더 선택 후 워크스페이스 신뢰를 진행합니다.
  4. 설문 결과 CSV 같은 자료 파일을 첨부합니다.
  • Claude Code는 실행한 폴더와 그 하위 폴더에 접근하므로 폴더 위치를 확인하세요.
  • 처음에는 데스크톱 앱으로 시작하고 익숙해지면 터미널로 넘어가는 것을 추천합니다.

인터뷰로 요구사항 정리하기

Claude Code

결과를 과하게 지정하는 대신 Claude가 질문해 요구사항을 끌어내게 합니다. 대상 사용자 같은 핵심만 주고 나머지는 질문에 답하며 정합니다.

따라 하기

  1. 만들 대상과 대상 사용자 정도만 프롬프트에 적습니다.
  2. ask user question 도구를 쓰라고 프롬프트에 명시합니다.
  3. Claude가 띄우는 질문에 차례로 답합니다.
  4. 답변이 끝나면 Claude가 작성하는 스펙을 확인합니다.
예시 프롬프트
팀원 누구나 브라우저에서 볼 수 있는 설문 결과 대시보드 웹사이트를 만들고 싶어. 주요 사용자는 우리 팀원들이야. ask user question 도구를 써서 필요한 것을 나에게 질문한 뒤 스펙을 작성해 줘.
  • '더 좋게 만들어', '실수 없이 만들어' 같은 프롬프트는 피합니다.

계획 모드로 계획 먼저 세우기

Claude Code

계획 모드에서는 Claude가 파일을 수정하지 않고 읽기만 하며 계획을 세웁니다. 코드가 쓰이기 전에 방향을 고칠 수 있어 가장 효율적입니다.

따라 하기

  1. Shift+Tab을 눌러 입력창 아래에 plan mode가 표시될 때까지 전환합니다.
  2. 구현하려는 내용을 구체적으로 요청합니다.
  3. Claude가 내놓은 계획을 검토합니다.
  4. 부족하면 추가나 수정을 요청합니다.
  5. 계획이 좋으면 승인하고 파일 수정을 자동 수락할지 매번 물을지 고릅니다.
예시 프롬프트
첨부한 설문 결과 CSV로 대시보드 웹사이트를 만들 계획을 먼저 세워 줘. 응답자 분포와 항목별 평균을 차트로 보여 주는 구성으로 해 줘.
  • 모든 단계를 직접 확인하고 싶으면 기본(승인) 모드를 유지합니다.
  • 권한을 건너뛰면 실수를 미리 잡기 어려우니 신중히 사용합니다.

Claude Code

따라 하기

  1. 우측 내장 브라우저에서 결과를 확인합니다.
  2. 필요하면 기본 브라우저에서 열기로 크롬에서 엽니다.
  3. 수정할 점을 프롬프트로 요청합니다.
  4. 파일 변경 권한 요청이 나오면 내용을 검토하고 허용합니다.
예시 프롬프트
차트 색을 더 구분하기 쉽게 바꾸고, 맨 위에 전체 응답자 수를 크게 보여 줘.
  • 생각 정리는 채팅, 파일 정리는 코워크, 웹사이트·앱 제작은 코드, 발표 자료는 디자인으로 고릅니다.

따라 하기

예시 프롬프트

CLAUDE.md에 프로젝트 규칙 저장

Claude Code

CLAUDE.md는 Claude Code가 세션을 시작할 때마다 자동으로 읽는 파일입니다. 스타일과 금지 규칙을 적어 두면 같은 지적을 반복하지 않아도 됩니다.

따라 하기

  1. 프로젝트 폴더에서 /init을 실행해 CLAUDE.md를 생성합니다.
  2. 스택, 명령어, 스타일 규칙을 확인하고 필요한 내용을 고칩니다.
  3. 건드리면 안 되는 폴더 같은 금지 규칙을 추가합니다.
  4. 작업 중 반복해서 바로잡은 규칙은 메모리에 저장하라고 요청합니다.
예시 프롬프트
방금 알려 준 규칙(차트 색은 팀 브랜드 색을 쓴다)을 CLAUDE.md에 저장해 줘.
  • 200줄 이내로 매뉴얼이 아니라 지도처럼 씁니다.
  • AI가 자동 생성한 설정 파일은 사람이 검수합니다.

검증하고 마무리하기

Claude Code

성공 기준과 검증 수단을 주면 Claude가 스스로 결과를 확인합니다. 마지막에 리뷰와 커밋 메시지까지 맡기면 작업이 매듭지어집니다.

따라 하기

  1. 계획에 무엇이 올바른 결과인지 성공 기준을 분명히 적습니다.
  2. 웹 UI라면 Claude in Chrome 확장을 설치해 Claude가 탭에서 직접 테스트하게 합니다.
  3. 직접 확인해 만족하면 서브에이전트 코드 리뷰어로 코드를 점검합니다.
  4. Claude에게 커밋 메시지를 만들게 한 뒤 저장합니다.
예시 프롬프트
차트가 모든 항목을 보여 주는지 브라우저에서 직접 확인하고, 문제가 있으면 고친 뒤 다시 확인해 줘.
  • 같은 문제가 반복되면 해결책을 CLAUDE.md에 저장하도록 요청합니다.
