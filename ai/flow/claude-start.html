학습·메모리 설정 점검하기

Claude

대화가 어디에 저장되고 학습에 쓰이는지는 제품·플랜마다 다릅니다. 회사 일에 쓰기 전에 설정을 직접 확인하고, 민감한 정보는 넣지 않는 습관을 들입니다.

따라 하기

  1. 계정이나 개인정보 설정에서 데이터·개인정보 메뉴를 엽니다.
  2. 내 대화가 모델 학습에 쓰이는지 확인하고 원하지 않으면 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 항목을 함께 확인합니다.
  4. 저장된 메모리를 열어 틀린 것은 고치고 필요 없는 것은 지웁니다.
  5. 실명은 자리표시자로 바꿔 입력하고, 기밀 데이터는 비즈니스·엔터프라이즈 플랜을 씁니다.
예시 프롬프트
이 메일 문구를 정중하게 다듬어 줘. 고객 이름은 [고객A], 회사명은 [회사B]로 바꿔 두었어.
  • 메뉴 이름은 버전에 따라 다를 수 있습니다.
  • 정책은 제공사마다 다르니 쓰는 도구의 처리방침을 직접 확인하세요.

따라 하기

  1. Claude 데스크톱 앱을 설치합니다.
  2. 내 프로젝트가 있는 폴더 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청합니다.

구체적으로 질문하기

Claude

막연히 묻지 않고 상황, 대상, 결과 형식을 말하면 한 번에 쓸 만한 답이 나옵니다. 역할·결과·이유·예시·제한을 담는 POWER 5원칙이 도움이 됩니다.

따라 하기

  1. 내 상황과 대상을 먼저 적습니다.
  2. 표로 정리해 줘처럼 원하는 결과 형식을 말합니다.
  3. 역할, 이유, 예시, 제한 사항 중 두세 가지를 더합니다.
  4. 답을 받은 뒤 이어서 질문해 내용을 고치거나 보탭니다.
  5. 답이 짧으면 지금보다 두 배로 답변해 줘처럼 분량을 조정합니다.
예시 프롬프트
너는 10년 경력의 HR 담당자야. 신입 사원 환영 행사 기획안을 표로 만들어 줘. 팀 분위기를 풀어 주려는 목적이고 예산은 100만 원 이내, 2시간 분량이야.
  • 다섯 가지를 모두 쓸 필요는 없고 두세 가지면 충분합니다.
  • 예시를 구체적으로 줄수록 결과가 가까워집니다.

웹 검색·딥 리서치 켜기

Claude

검색 도구가 없으면 모델은 훈련 시점 이후의 사실을 확실히 알지 못합니다. 웹 검색으로 출처 링크를 받고, 깊은 조사는 딥 리서치를 씁니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 답에 달린 출처 링크를 열어 확인합니다.
  4. 깊은 조사는 /딥리서치를 입력하거나 + → 리서치를 누릅니다.
  5. 조사 주제와 원하는 결과 형태를 적어 요청합니다.
예시 프롬프트
/딥리서치 국내 중견기업 대상 AI 업무 자동화 도구 시장 현황과 주요 경쟁사 3곳을 비교해 줘. 출처 링크를 함께 정리해 줘.
  • 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.

AI 답변 검증하기

Claude

AI는 그럴듯하지만 사실이 아닌 내용을 만들 수 있습니다. 틀렸을 때의 위험에 따라 확인 강도를 정하고 출처를 직접 열어 봅니다.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 스스로 묻고 확인 강도를 정합니다.
  2. 모르면 모른다고 말해 달라고 미리 허용합니다.
  3. 주장마다 근거 출처를 요청하고 직접 열어 확인합니다.
  4. 의심스러우면 얼마나 확신하는지, 틀릴 부분이 있는지 묻습니다.
  5. 새 대화나 다른 AI로 교차 검증합니다.
예시 프롬프트
이 결정에 대한 가장 강력한 찬성 논거와 반대 논거를 각각 알려 줘. 모르는 부분은 모른다고 말해도 괜찮아.
  • 숫자·날짜·인용·최근 사건은 특히 다시 확인합니다.
  • 깔끔한 결과물이 정확성의 증거는 아닙니다.
