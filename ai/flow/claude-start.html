가입하고 첫 질문하기

Claude

설치나 공부보다 먼저 말을 걸어 보는 것이 입문의 핵심입니다. 완벽한 질문을 만들려 하지 말고 답을 보고 고쳐 달라고 이어 가면 됩니다.

따라 하기

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 누릅니다.
  3. 로그인 후 질문창에 하고 싶은 일을 입력합니다.
  4. 타이핑이 번거로우면 질문창의 마이크를 눌러 말로 질문합니다.
  5. 마음에 들지 않는 부분은 고쳐 달라고 이어서 요청합니다.
예시 프롬프트
내일 팀 회의에서 쓸 신제품 출시 일정 공지 메일 초안을 정중한 말투로 써 줘.
  • 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.
  • 무료로 시작해 한도에 막힐 때 유료로 올리면 됩니다.

학습·메모리 설정 점검하기

Claude 설정

업무 내용을 입력하기 전에 대화가 학습에 쓰이는지, 메모리에 무엇이 저장되는지 확인합니다. 정책은 제공사와 플랜마다 다르므로 설정 화면에서 직접 봐야 합니다.

따라 하기

  1. 계정 또는 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 관련 토글을 확인합니다.
  2. 데이터 컨트롤 부근에서 모델 개선(학습) 사용 항목을 찾아 끕니다.
  3. 저장된 메모리를 열어 잘못되었거나 불필요한 내용을 고치거나 지웁니다.
  4. 필요 없으면 메모리 기능 자체를 끕니다.
  5. 실명이 필요 없는 작업은 이름을 자리표시자로 바꿔 입력합니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 문서로 확인합니다.
  • 메뉴 이름과 위치는 바뀔 수 있으니 설정 안에서 데이터 컨트롤 부근을 찾아보세요.
  • 메모리는 모델이 아니라 계정에 저장된 정보입니다.
  • 개인정보와 기밀 정보는 설정과 상관없이 입력하지 않는 것이 안전합니다.

데스크톱·모바일 앱 설치하기

Claude 앱

코워크 같은 파일 작업 기능은 데스크톱 앱에서만 쓸 수 있어 미리 설치해 두면 좋습니다. 휴대폰 앱의 음성 모드는 이동 중 질문에 편합니다.

따라 하기

  1. Claude 사이트 아래쪽의 데스크톱 앱 다운로드를 눌러 설치합니다(무료 사용자도 가능).
  2. 설치한 앱에서 같은 계정으로 로그인합니다.
  3. 휴대폰 앱 스토어에서 Claude 앱을 설치하고 로그인합니다.
  4. 업무용과 개인 계정을 쓴다면 로그아웃 없이 두 계정을 추가해 전환합니다.
  5. 음성 모드로 말하듯 질문해 봅니다.
  • 모바일 앱은 총 33개 언어를 지원합니다.
  • 웹·데스크톱에서는 대화 검색이 가능하며 Mac은 Command K입니다.

Claude에게 나를 알려 주기

Claude

AI를 잘 쓰는 핵심은 나에 대한 맥락을 주는 것입니다. 첫날 몇 가지 질문과 인터뷰만으로 이후 답이 훨씬 나아집니다.

따라 하기

  1. 나에 대해 아는 것을 한 문단으로 설명해 봐라고 물어 Claude가 나를 얼마나 아는지 확인합니다.
  2. 데스크톱 앱을 쓴다면 폴더 접근을 허락합니다.
  3. 컴퓨터 보고 나에 대해 파악해 줘라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  4. 나에 대해서 궁금한 거 100개까지 물어봐 봐라고 요청해 인터뷰를 받습니다.
  5. 이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?라고 묻습니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 봐. 한 번에 다섯 개씩 물어봐 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 하루 30분씩 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 메모리는 설정에서 채팅 검색·참조와 메모리 생성을 켜야 작동합니다.

맥락을 충분히 주고 요청하기

Claude

완벽한 프롬프트보다 상황과 기준을 충분히 알려 주는 것이 결과를 좌우합니다. 음성 입력과 자료 첨부를 쓰면 시간도 줄고 생각도 정리됩니다.

따라 하기

  1. 타이핑 대신 음성 받아쓰기로 상황, 목적, 기준을 길게 말합니다.
  2. 관련 파일이나 화면 캡처 같은 자료를 많이 붙입니다.
  3. AI가 낸 결과를 직접 읽고 맞는지 판단합니다.
  4. 부족한 부분은 기준을 더 알려 주어 다시 요청합니다.
예시 프롬프트
지금 상황을 설명할게. 나는 중소기업 영업팀 대리이고, 다음 주 고객사 제안 발표를 준비 중이야. 첨부한 자료를 보고 발표 흐름을 제안해 줘. 기준은 10분 안에 끝나고 비전문가도 이해할 수 있어야 해.
  • 중요한 것은 맥락을 많이 주는 것과 결과를 판단하는 능력입니다.
  • Typeless 같은 음성 입력 도구는 군더더기를 지워 정리된 문장으로 입력해 줍니다.

웹 검색·딥 리서치로 조사하기

Claude

모델은 훈련 이후의 사실을 검색 없이는 확실히 알지 못합니다. 웹 검색을 켜면 최신 정보와 출처 링크를 받고, 딥 리서치는 시장 조사처럼 깊은 조사에 씁니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 검색을 활성화합니다.
  3. 질문하면 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 리서치(예전 표기 연구)를 눌러 딥 리서치를 켭니다.
  5. 조사 주제와 원하는 결과물 형식을 적어 요청합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 가격·기능·장단점 기준으로 비교해 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • AI가 웹 검색을 했다고 단정하지 말고 직접 물어보세요.

답변 검증하며 쓰기

Claude

AI는 그럴듯하지만 사실이 아닌 내용(환각)을 만들거나 듣고 싶은 말에 동의(아첨)할 수 있습니다. 틀렸을 때의 위험에 따라 확인 강도를 정하세요.

따라 하기

  1. 틀렸을 때 어떤 일이 생기는지 스스로 묻고 확인 강도를 정합니다.
  2. 미리 모르면 모른다고 말해 달라고 허용합니다.
  3. AI에게 근거가 되는 출처를 요청합니다.
  4. 제시된 출처를 직접 열어 실제로 그 내용이 있는지 확인합니다.
  5. 새 대화를 열어 답의 오류를 찾아 달라고 하거나 다른 AI로 교차 검증합니다.
예시 프롬프트
방금 답변에서 구체적인 통계와 날짜마다 출처를 알려 줘. 확신이 낮은 부분은 따로 표시해 줘.
  • 숫자·날짜·인용은 특히 다시 확인합니다.
  • 깔끔한 문단이나 자신 있는 말투는 정확성의 증거가 아닙니다.
  • 원하는 답을 흘리지 말고 중립적으로 질문하세요.

일에 맞는 도구 고르기

Claude 앱

Claude에는 목적이 다른 도구가 여럿 있습니다. 기준만 알면 어떤 일에 무엇을 쓸지 헤매지 않고, 다음 목표 가이드로 자연스럽게 넘어갈 수 있습니다.

따라 하기

  1. 생각 정리와 질문·분석은 채팅에서 합니다.
  2. 파일 정리와 엑셀·워드 보고서 작성은 코워크를 씁니다.
  3. 웹사이트나 앱 제작은 코드를 씁니다.
  4. 발표 자료는 디자인에서 슬라이드로 만듭니다.
  5. 하나의 자료를 채팅 분석, 코워크 보고서, 디자인 슬라이드 순으로 이어서 써 봅니다.
  • 코워크·코드·디자인은 유료 플랜이 필요할 수 있으니 내 플랜에서 되는지 확인하세요.
  • 코워크는 코드와 같은 엔진을 쓰는 사무용 버전입니다.
