Claude 가입하고 첫 질문하기

Claude

먼저 무료 플랜으로 시작해 내 업무에 충분한지 확인합니다. 완벽한 질문을 만들기보다 말하듯 입력하고, 아쉬우면 이어서 고쳐 달라고 하는 것이 요령입니다.

따라 하기

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기로 가입합니다.
  3. 질문창의 모델 선택에서 일상 작업용으로 Sonnet을 고릅니다.
  4. 궁금한 것을 친구에게 말하듯 입력하고 전송합니다.
  5. 답이 아쉬우면 "이 부분을 이렇게 고쳐 줘"라고 이어서 요청합니다.
  6. 타이핑이 번거로우면 질문창의 마이크로 말로 질문합니다.
예시 프롬프트
내가 하는 일과 오늘 해야 할 일을 설명할 테니, 우선순위를 정하는 걸 도와줘. 필요하면 먼저 나에게 질문해 줘.
  • 무료로 쓰다가 사용 한도에 자주 막힐 때 유료로 넘어가면 됩니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시킵니다.

대화 데이터 설정 점검하기

Claude

입력한 정보는 대화, 메모리, 제공사 시스템, 모델 학습 중 어디로 갈 수 있습니다. 업무 내용을 넣기 전에 설정을 한 번 점검해 두면 안심하고 쓸 수 있습니다.

따라 하기

  1. 계정이나 개인정보 설정을 엽니다.
  2. 메모리, 대화 기록, 연결된 앱, 학습 토글을 하나씩 확인합니다.
  3. 저장된 메모리가 있으면 수정·삭제하고, 필요 없으면 메모리를 끕니다.
  4. 모델 학습에 쓰이지 않도록 학습 관련 항목을 끕니다.
  5. 실명 같은 불필요한 정보는 자리표시자로 바꿔 입력합니다.
  • 메뉴 위치는 영상에서 정확히 짚지 않았으니 설정의 데이터 컨트롤 부근을 찾아보세요.
  • 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜과 데이터 처리 조건을 확인합니다.

AI에게 나를 알려 주기

Claude

AI에게 나에 대한 정보를 주면 답이 내 상황에 훨씬 맞게 나옵니다. AI가 나에게 질문하게 하면 무엇을 알려 줘야 할지 몰라도 시작할 수 있습니다.

따라 하기

  1. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 현재 얼마나 아는지 확인합니다.
  2. "너는 뭘 할 수 있니?"라고 물어 가능한 일을 파악합니다.
  3. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰에 답합니다.
  4. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
  5. 추천받은 일 중 작은 것 하나를 실제로 시켜 봅니다.
예시 프롬프트
나에 대해서 궁금한 거 100개까지 물어봐 봐. 한 번에 하나씩 물어보고, 내 답을 바탕으로 마지막에 나를 도와줄 수 있는 일을 정리해 줘.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 마이크로 길게 말하면 맥락을 더 쉽게 줄 수 있습니다.

웹 검색·딥 리서치로 조사하기

Claude

모델은 검색 없이는 최신 사실을 확실히 알지 못합니다. 웹 검색을 켜면 출처 링크가 달리고, 깊은 조사는 딥 리서치 모드를 씁니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 필요할 때 검색하고 출처 링크가 달리는지 확인합니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치를 켭니다.
  5. 조사할 주제와 원하는 결과 형태(표 등)를 적어 요청합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 경쟁사 3곳을 조사해서, 가격·핵심 기능·장단점을 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석에 유용합니다.

프로젝트로 업무 공간 나누기

Claude

프로젝트는 작업별로 맥락을 모아 두는 공간입니다. 지침과 문서를 한 번 넣어 두면 그 안의 대화마다 같은 설명을 반복하지 않아도 됩니다.

따라 하기

  1. 화면 왼쪽 프로젝트 옆 +를 눌러 프로젝트를 만듭니다.
  2. 업무 용도별로 프로젝트를 나눕니다.
  3. 커스텀 지침에 대상, 톤 등 원하는 응답 방식을 적고 지침 저장을 누릅니다.
  4. 관련 문서를 파일로 업로드합니다.
  5. 프로젝트 안에서 대화를 시작하고 이어 갑니다.
예시 프롬프트
이 프로젝트는 신입 사원 교육 자료를 만드는 작업이야. 대상은 입사 1년 차 직장인이고, 톤은 친절하고 쉬운 존댓말로 해 줘. 업로드한 문서를 근거로 답하고, 근거가 없으면 모른다고 말해 줘.
  • 새 채팅을 열면 기억 일부가 사라지니, 이전 대화에서 가져올 내용을 찾아 달라고 요청하세요.
  • 프로젝트는 맥락, 스킬은 작업 방식, 커넥터는 외부 도구를 맡는다고 구분하면 쉽습니다.

구글 드라이브·Gmail 연결하기

Claude

커넥터를 연결하면 드라이브 파일을 찾아 요약하고 메일 초안까지 채팅 안에서 만들 수 있습니다. 한 번 연결해 두면 이후 자동화의 기반이 됩니다.

따라 하기

  1. 대화창 아래의 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가를 누르고 커넥터 둘러보기를 선택합니다.
  3. Gmail, 구글 캘린더, 구글 드라이브 등 서비스를 검색합니다.
  4. 서비스 옆 +를 눌러 내 계정으로 로그인하고 인증합니다.
  5. 채팅에서 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청합니다.
예시 프롬프트
구글 드라이브에서 '11월 영업 보고' 파일을 찾아 내용을 요약하고, 팀장님께 보낼 이메일 초안을 써 줘.
  • 메일은 발송하지 말고 초안으로 남기게 하면 안전합니다.

따라 하기

  4. 제시된 출처를 직접 열어 실제 내용이 있는지 확인합니다.
  5. 의심스러운 답은 새 대화나 다른 AI로 교차 검증합니다.
예시 프롬프트
이 답변의 각 주장마다 근거 출처를 찾아 줘. 확실하지 않은 부분은 모른다고 말해도 괜찮아. 그리고 틀릴 가능성이 있는 부분을 짚어 줘.
  • 브레인스토밍은 느슨하게, 숫자·날짜·출처·법률·금전 문제는 반드시 확인합니다.
  • AI가 없는 출처를 만들어 낼 수도 있습니다.
