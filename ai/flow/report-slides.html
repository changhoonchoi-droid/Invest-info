딥 리서치로 근거 모으기

Claude

발표 내용의 신뢰는 근거에서 나옵니다. 딥 리서치로 조사 보고서를 먼저 만들고, 출처를 확인해 쓸 내용만 추립니다.

따라 하기

  1. 입력창에 /딥리서치를 입력합니다.
  2. 조사 목적과 청중, 범위를 적어 요청합니다.
  3. 결과의 출처 링크를 열어 핵심 숫자를 확인합니다.
  4. 쓸 내용만 남기도록 요약을 요청합니다.
예시 프롬프트
/딥리서치 국내 중소기업의 협업 툴 도입 현황을 조사해 줘. 임원 보고용이라 핵심 수치와 출처가 필요해.
  • 근거가 없는 내용은 확인 필요로 표시해 달라고 요청할 수 있습니다.

NotebookLM

회사 문서나 PDF만 근거로 답이 필요하면 노트북LM이나 어도비 PDF 스페이스를 씁니다. 출처 번호로 근거를 바로 확인할 수 있습니다.

따라 하기

  1. 노트북LM에서 새 노트 만들기를 누릅니다.
  2. 소스 추가로 파일·링크·텍스트를 넣습니다.
  3. 질문하고 답변의 숫자를 눌러 출처를 확인합니다.
  4. 좋은 답변은 메모에 저장을 누릅니다.
예시 프롬프트
올려 둔 자료 세 개를 비교해서 공통점과 차이점을 표로 정리하고, 각 항목에 출처를 달아 줘.
  • 웹 검색은 약하므로 최신 정보는 따로 보완합니다.
  • 어도비 PDF 스페이스는 유료 구독이 필요합니다.

음성·대화로 슬라이드 초안

Claude Slides

빈 슬라이드 앞에서 막막하면 하고 싶은 말을 녹음해 넘기세요. 서식보다 내용에 집중할 수 있고, 기존 대화도 재료가 됩니다.

따라 하기

  1. 휴대폰 음성 메모로 발표 내용을 두서없이 녹음합니다.
  2. 텍스트 변환본을 복사해 Claude에 보냅니다.
  3. 슬라이드 제작을 요청하거나 /slides를 입력합니다.
  4. 작은 수정은 직접, 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  5. 정리된 대화가 있다면 같은 채팅에서 바로 슬라이드를 요청합니다.
예시 프롬프트
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다.
  • Slides·Design·Docs는 베타 단계입니다.

디자인 시스템으로 톤 맞추기

Claude Design

디자인 시스템 없이 만들면 결과가 AI스러워지기 쉽습니다. 색·폰트·레이아웃 규칙을 먼저 만들어 두면 이후 자료가 같은 톤으로 나옵니다.

따라 하기

  1. claude.ai/design의 디자인 시스템 탭에서 Create new design system을 누릅니다.
  2. 원하는 기업의 DESIGN.md 코드를 복사해 입력창에 붙여 넣습니다.
  3. 쓸 폰트 파일을 업로드하고 일괄 적용하라고 적습니다.
  4. Continue to generation으로 생성합니다.
  5. 새 프로젝트를 만들 때 이 디자인 시스템을 선택합니다.
예시 프롬프트
업로드한 폰트로 일괄 적용하고, 그래프 컴포넌트를 포함해 줘
  • 회사 자료가 있으면 깃허브 주소나 피그마 파일로도 만들 수 있습니다.
  • Claude Design은 무료 플랜에서 쓸 수 없습니다.

Claude Design

디자인 시스템을 적용해 PPT를 만들고, 질문에 답하며 주제·대상을 확정합니다. 업데이트로 PPTX 변환 품질이 좋아졌습니다.

따라 하기

  1. 초기 화면에서 만들어 둔 디자인 시스템을 설정합니다.

  4. 결과를 확인하고 Claude Design 안에서 수정합니다.
  5. 발표 메모가 필요하면 Use speaker notes를 체크합니다.
예시 프롬프트

따라 하기

  4. 변경을 수락하기 전에 결과를 확인합니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.
  • 변경을 수락하면 되돌릴 수 없습니다.

수치·내용 직접 검산하기

Claude

이 단계는 흐름을 잇기 위해 덧붙인 일반 안내입니다. 모니터링 영상에서 직접 다룬 내용은 아닙니다.

발표 자료의 숫자와 인용은 내 이름으로 나갑니다. 마무리 전에 근거 확인이 필요합니다.

따라 하기

  1. 슬라이드의 숫자와 인용을 목록으로 뽑아 달라고 요청합니다.
  2. 각 항목을 원문 출처와 직접 대조합니다.
  3. 확신이 낮은 부분은 따로 표시해 달라고 합니다.
  4. 틀린 부분은 고쳐 달라고 요청합니다.
예시 프롬프트
슬라이드의 모든 숫자와 인용을 목록으로 뽑고, 각각 근거 출처와 확신 정도를 표로 정리해 줘.
  • 숫자·날짜·인용은 특히 다시 확인합니다.

Claude Code

따라 하기

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수 기준으로 규칙서를 만듭니다.

  3. 다음 PPT 때 스킬을 불러와 사용합니다.
예시 프롬프트
