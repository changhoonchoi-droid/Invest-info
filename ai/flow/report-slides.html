자료 모으고 조사하기

Claude

보고서의 재료가 되는 정보를 먼저 모읍니다. 출처가 달린 조사 결과를 받으면 나중에 근거 확인이 쉽습니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼에서 웹 탭을 켭니다.
  2. 깊은 조사가 필요하면 리서치 모드를 켭니다.
  3. 조사 주제와 원하는 결과 형태(표, 요약 등)를 적어 요청합니다.
  4. 출처 링크를 눌러 핵심 숫자를 확인합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 조사해서 가격, 강점, 약점을 표로 정리하고 출처 링크를 달아 줘.
  • 숫자는 원문과 대조하세요.

음성 메모로 생각 쏟아내기

Claude

빈 슬라이드 앞에서 막막할 때는 하고 싶은 말을 먼저 녹음합니다. 서식보다 내용에 집중할 수 있습니다.

따라 하기

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 구조(목차)를 먼저 만들어 달라고 요청합니다.
예시 프롬프트
내가 말한 내용을 바탕으로 발표 구조를 먼저 만들어 줘. 구조가 확정되면 슬라이드로 만들어 달라고 할게.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.

문서 초안 만들기

Claude

앞서 나눈 대화 내용이 그대로 재료가 되어 문서(Docs)가 만들어집니다. 고칠 곳은 드래그해 댓글로 지시합니다.

따라 하기

  1. Opus 5.5로 보고서 내용을 먼저 대화로 정리합니다. 자료나 사진이 있으면 첨부합니다.
  2. 원하는 결과물을 설명하거나 /docs를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 답해 초안을 받습니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  5. Sonnet 5.5로 바꿔 문구 다듬기 같은 수정을 반복합니다.
예시 프롬프트
첨부한 신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프 문서를 만들어 줘
  • Docs는 모든 유료 요금제에서 쓸 수 있습니다.

슬라이드 만들기

Claude

문서 내용을 슬라이드로 이어서 만듭니다. Claude Slides를 쓰거나, 제미나이·젠스파크 같은 도구로도 만들 수 있습니다.

따라 하기

  1. 같은 대화에서 /slides를 입력하거나 슬라이드를 만들어 달라고 요청합니다.
  2. 대상, 톤, 슬라이드 총 장수를 함께 적습니다.
  3. 작은 수정은 직접 고치고, 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  4. PPT 파일이 필요하면 내보내기로 저장합니다.
예시 프롬프트
신제품 출시 브리프야. 대상은 영업팀이고 핵심 메시지는 '설치 10분'이야. 발표용 슬라이드 10장과 현장에서 나눠 줄 한 장짜리 요약 문서를 만들어 줘.
  • 제미나이로 만들 때는 캔버스를 선택하고 구글 슬라이드를 거쳐 PPT로 저장하는 방법도 있습니다.
  • 한 번에 전부 만들기보다 1~2장씩 나눠 만드세요.

디자인 규칙으로 톤 맞추기

Claude 디자인

AI가 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 색 역할, 글씨 크기, 장당 글자 수 같은 규칙을 수치로 정해 두면 매번 같은 톤이 나옵니다.

따라 하기

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create를 누릅니다.
  2. 회사 이름과 설명을 적고 기존 자료가 있으면 깃허브 주소나 피그마 파일을 넣습니다.
  3. 쓸 폰트 파일을 업로드하고 Continue to generation을 눌러 기다립니다.
  4. 새 프로젝트를 만들 때 방금 만든 디자인 시스템을 선택합니다.
  5. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트 옵션으로 다운로드합니다.
  • '깔끔하게' 같은 추상적 표현 대신 색 역할, 글씨 크기, 장당 글자 수를 수치로 적습니다.
  • Pro 이상 구독이 필요하고 무료 플랜은 쓸 수 없습니다.

PowerPoint 안에서 마무리하기

Claude

Claude를 Word·PowerPoint 패널로 열면 문서를 읽고 직접 편집합니다. 모든 수정은 검토 카드나 추적 변경으로 나타나 수락·거절할 수 있습니다.

따라 하기

  1. Word는 오른쪽 Claude 패널, PowerPoint는 Claude 애드인을 엽니다.
  2. Word에서는 Turn on Track Changes and keep it on for everything you do in this document.라고 요청합니다.
  3. 고칠 슬라이드나 텍스트 상자를 선택한 뒤 요청하면 선택한 부분만 수정됩니다.
  4. 수정 카드를 확인해 수락하고, 수치와 근거는 원문과 대조합니다.
  • Pro, Max, Team, Enterprise 유료 플랜에서 쓸 수 있습니다.
  • 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 줍니다.

팀과 함께 고치고 공유하기

Claude

만든 문서와 슬라이드를 팀원과 공유해 함께 고칩니다. 팀원마다 보기·댓글·수정 권한을 정하고, 댓글이 달리면 Claude에게 수정을 시킵니다.

따라 하기

  1. 문서가 준비되면 조직의 팀원을 추가합니다.
  2. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  3. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  4. 우측 상단 공유로 초대하거나 내보내기로 파일을 저장합니다.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
