근거 자료 조사하기

Claude 앱

발표의 뼈대가 될 근거를 먼저 모읍니다. 웹 검색으로 출처가 달린 조사를 하거나, PDF 스페이스에 보고서를 넣고 요약하면 숫자의 원문 근거를 바로 확인할 수 있습니다.

따라 하기

  1. + 버튼에서 웹 탭을 켜거나 연구로 딥 리서치 모드를 켭니다.
  2. 발표 목적, 청중, 비교 기준을 적어 조사를 요청합니다.
  3. 보고서 PDF가 있다면 어도비 PDF 스페이스에 파일·웹링크를 넣고 AI 어시스턴트에 요약을 요청합니다.
  4. 요약 속 숫자를 눌러 원문 근거를 확인합니다.
  5. 근거가 없는 내용은 확인 필요로 표시해 달라고 요청합니다.
예시 프롬프트
임원 보고용이야. 이 보고서에서 가장 크게 달라진 수치 5개를 근거와 함께 요약하고, 근거가 없는 내용은 확인 필요로 표시해 줘.
  • PDF 스페이스는 유료 구독이 필요하고, 문서 기반이라 거짓 정보가 들어갈 위험이 줄어듭니다.
  • AI는 틀린 내용을 자신 있게 말할 수 있으니 출처를 확인하세요.

음성으로 하고 싶은 말 쏟기

휴대폰 음성 메모

빈 슬라이드 앞에서 막막하다면 서식보다 내용에 집중해 말부터 녹음합니다. 엉망인 메모도 괜찮고, 그 글을 Claude에게 넘겨 구조를 잡게 합니다.

따라 하기

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보내 핵심 메시지와 목차를 정리해 달라고 요청합니다.
예시 프롬프트
아래 내 말을 그대로 살려서 발표 흐름으로 정리해 줘. 청중은 팀장급이고 10분 안에 끝나야 해.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.

문서·슬라이드 초안 만들기

Claude 앱

내용 정리는 대화로 하고, 결과물은 같은 대화에서 문서·슬라이드·디자인으로 바로 만듭니다. 방향을 잡는 단계에는 상위 모델, 반복 수정에는 빠른 모델을 씁니다.

따라 하기

  1. 먼저 보고서 내용을 대화로 정리합니다(영상에서는 Opus 5.5 권장).
  2. 원하는 결과물을 설명하거나 /slides, /docs, /designs를 입력합니다.
  3. Docs가 열리면 Claude가 묻는 질문에 모두 답합니다.
  4. 초안이 나오면 직접 고치거나, 고칠 부분을 드래그해 댓글로 지시를 남깁니다.
  5. 문구 다듬기·차트 교체 같은 반복 수정은 Sonnet 5.5로 바꿔 진행합니다.
예시 프롬프트
아래 신제품 출시 브리프를 바탕으로 10장짜리 발표 슬라이드와 한 장 요약 문서를 만들어 줘.
  • 질문 내용은 사용자마다 다르게 나옵니다.
  • Slides는 우측 상단 재생 버튼으로 바로 발표할 수 있습니다.

엑셀로 표·차트 근거 만들기

Claude in Excel

숫자 근거가 필요하면 엑셀 사이드바의 Claude에게 분석과 피벗 테이블, 차트를 맡깁니다. 인용 상자로 근거 셀을 확인할 수 있어 검증이 쉽습니다.

따라 하기

  1. Excel에서 통합 문서를 열고 Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  2. 목표를 구체적으로 적어 질문합니다.
  3. 응답의 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
  4. 지역·제품 등 기준을 적어 피벗 테이블을, 이어서 차트를 요청합니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.
  • Pro, Max, Team, Enterprise 플랜에서 베타로 제공됩니다.
  • 민감한 데이터는 조직의 데이터 처리 정책을 따르세요.

디자인 시스템으로 톤 맞추기

Claude Design

디자인 시스템(색, 폰트, 글씨 크기, 여백 규칙)을 먼저 만들면 모든 슬라이드가 같은 톤으로 나옵니다. 'AI스러운' 들쭉날쭉함을 줄이고 PPTX로 내보낼 수 있습니다.

따라 하기

  1. 클로드 디자인의 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. 원하는 기업의 DESIGN.md 코드를 복사해 입력창에 붙여 넣고 폰트 파일을 올립니다.
  3. Continue to generation으로 생성한 뒤, 초기 화면에서 이 디자인 시스템을 선택하고 슬라이드를 요청합니다.
  4. Claude의 주제·대상 질문에 답하고 Continue를 누릅니다.
  5. Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 받습니다.
예시 프롬프트
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • '세련되게' 같은 표현 대신 색 3가지, 글씨 크기, 장당 글자 수처럼 수치로 적습니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • Claude Design은 유료 구독이 필요합니다.

Word·PPT 안에서 마무리

Claude for Word·PowerPoint

파일을 열어 둔 채 패널에서 Claude에게 수정을 맡기면 모든 변경이 검토 카드와 추적 변경으로 나타납니다. 하나씩 수락·거절하며 팀 기준에 맞게 다듬습니다.

따라 하기

  1. Word 오른쪽의 Claude 패널을 열고 추적 변경을 켜 달라고 요청합니다.
  2. 고칠 문단을 선택해 고객 눈높이로 바꾸는 등 요청하고 카드별로 확인합니다.
  3. 분량 줄이기는 지킬 부분(인용문, 날짜)을 함께 알려 줍니다.
  4. PowerPoint에서는 고칠 슬라이드나 텍스트 상자를 선택하고 요청해 그 부분만 수정합니다.
  5. + 버튼으로 보고서나 데이터 파일을 올려 슬라이드의 근거로 씁니다.
예시 프롬프트
We need to get this under 1,000 words, but don't cut any more than you need to. Keep the quotes and dates.
  • 서식은 원하는 최종 상태를 말하고 Don't change anything else.를 덧붙이면 다른 곳이 안 바뀝니다.
  • 변경 수락은 되돌릴 수 없어 Claude가 먼저 확인을 요청합니다.

숫자와 출처 최종 확인

Claude 앱

상사에게 보일 자료는 숫자, 날짜, 인용을 따로 뽑아 다시 확인합니다. 새 대화에서 같은 질문을 던지거나 원문과 대조해 오류를 걸러 냅니다.

따라 하기

  1. 숫자·통계·인용·날짜가 들어간 부분을 모두 뽑아 달라고 요청합니다.
  2. 각각의 확신도와 확인할 수 있는 출처를 묻습니다.
  3. 새 대화를 열어 오류를 찾아 달라고 하거나 다른 AI로 교차 검증합니다.
  4. 최종 숫자는 원문과 직접 대조합니다.
예시 프롬프트
방금 답변에서 숫자, 날짜, 인용이 들어간 부분을 모두 뽑아 주고, 각각 얼마나 확신하는지와 확인할 수 있는 출처를 알려 줘.
  • 횟수가 줄수록 확인을 건너뛰기 쉬우니 중요한 업무는 늘 검증하세요.

팀과 공유해 함께 고치기

Claude 아티팩트

완성한 문서·슬라이드를 팀원과 함께 편집합니다. 접근 권한을 나누고 댓글을 남기면 Claude가 업데이트를 반영합니다. 파일이 필요하면 내보내기로 전달합니다.

따라 하기

  1. 우측 상단 공유로 조직의 팀원을 추가합니다.
  2. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  3. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  4. 입력·체크만 필요한 사람은 contributor로 지정합니다.
  5. 내보내기로 Word, PDF, 파워포인트 등 필요한 형식으로 저장해 전달합니다.
예시 프롬프트
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 내보내기 형식: Docs는 Word, PDF, 마크다운 등이고 Slides는 PDF, 파워포인트, PNG 등입니다.
