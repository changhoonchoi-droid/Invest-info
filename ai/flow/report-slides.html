흩어진 자료를 한 번에 읽히기

Cowork

자료가 폴더에 흩어져 있다면 코워크가 한 번에 읽고 정리합니다. 주간 현황이나 설문 취합처럼 반복되는 문서 업무에 맞습니다.

따라 하기

  1. 데스크톱 앱에서 새로 생성을 누르고 협업을 선택합니다.
  2. 프로젝트 또는 폴더에서 작업 폴더를 고르고 항상 허용을 누릅니다.
  3. 회의록·메모·엑셀을 그 폴더에 복사해 넣습니다.
  4. 읽고 원하는 보고서 형식을 구체적으로 요청합니다.
  5. 완성된 결과의 숫자와 내용을 확인합니다.
예시 프롬프트
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘.
  • 원본은 그대로 두고 정리본은 새 파일로 저장하라고 요청하세요.

음성 메모로 재료 만들기

휴대폰 음성 메모

빈 슬라이드 앞에서 막막하면 하고 싶은 말을 먼저 녹음합니다. 서식보다 내용에 집중할 수 있고 메모가 두서없어도 괜찮습니다.

따라 하기

  1. 휴대폰 음성 메모 앱으로 발표 내용을 두서없이 말해 녹음합니다.
  2. 녹음의 텍스트 변환본을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  • 나와 Claude만 보는 자료이니 엉망이어도 괜찮습니다.

문서·슬라이드 초안 만들기

Claude 앱

대화로 정리한 내용을 그대로 이어받아 문서와 슬라이드를 만듭니다. 자료를 다시 옮겨 붙일 필요가 없습니다.

따라 하기

  1. 보고서에 들어갈 내용을 먼저 대화로 정리합니다.
  2. 참고 자료가 있으면 첨부합니다.
  3. 원하는 결과물을 설명합니다. /slides, /docs, /designs를 입력해도 됩니다.
  4. Claude가 던지는 질문에 모두 답합니다.
  5. 초안이 나오면 텍스트 편집기처럼 직접 고칩니다.
예시 프롬프트
첨부한 신메뉴 사진을 바탕으로 사장님께 보고할 런칭 브리프를 문서로 만들어 줘.
  • 방향을 잡는 단계는 Opus 5.5를 권장합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.

댓글로 부분 수정하기

Claude 앱

전체를 다시 만들지 않고 고칠 부분만 지정하면 빠르고 정확합니다. 반복 수정은 가벼운 모델로 바꿔 효율을 높입니다.

따라 하기

  1. 고칠 부분을 드래그합니다.
  2. 댓글을 눌러 지시를 입력합니다.
  3. 문구 다듬기, 차트 교체, 색상 변경 같은 반복 수정은 Sonnet 5.5로 바꿔 합니다.
  4. 결과를 확인하고 필요하면 다시 댓글을 남깁니다.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.

디자인 규칙 정해 톤 맞추기

Claude Design

AI로 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 디자인 시스템이나 수치로 적은 규칙서를 만들어 두면 'AI 티'가 줄고 톤이 일정해집니다.

따라 하기

  1. claude.ai/design의 디자인 시스템 탭에서 새 디자인 시스템을 만듭니다.
  2. 참고할 기업의 DESIGN.md를 붙여 넣거나 색·글꼴·글씨 크기를 수치로 적습니다.
  3. 폰트 파일을 업로드해 일괄 적용합니다.
  4. 만든 디자인 시스템으로 슬라이드를 요청합니다.
  5. Share → Export에서 파워포인트로 내보내 폰트와 레이아웃을 확인합니다.
예시 프롬프트
최신 AI 트렌드 리서치 주제로 PT 만들어 줘.
  • '깔끔하게' 같은 추상적 표현은 규칙이 아닙니다. 수치로 적으세요.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • Pro 이상 구독이 필요합니다.

숫자와 출처 검증하기

Claude 채팅

AI가 만든 통계와 인용은 틀릴 수 있습니다. 공개 전에 사람이 원문과 대조해 검수해야 합니다.

따라 하기

  1. 통계, 인용, 날짜, 숫자에 표시를 해 둡니다.
  2. Claude에게 각 항목의 출처와 확신 정도를 물어봅니다.
  3. 출처를 직접 열어 실제로 그 내용이 있는지 확인합니다.
  4. 새 대화를 열어 같은 내용을 다시 물어 비교합니다.
예시 프롬프트
방금 답변에 들어 있는 통계와 인용마다 출처를 알려 주고, 각각 얼마나 확신하는지 말해 줘. 확실하지 않은 것은 모른다고 말해 줘.
  • 다른 AI로 교차 검증하는 방법도 있습니다.

내보내고 팀에 공유하기

Claude 앱

완성한 결과는 팀원을 초대해 함께 보거나 원하는 형식의 파일로 내보내 전달합니다.

따라 하기

  1. 우측 상단 공유로 팀원을 초대합니다.
  2. 내보내기로 파일을 저장합니다.
  3. Docs는 Word·PDF·마크다운 등, Slides는 PDF·파워포인트·PNG 등을 고릅니다.
  4. 받는 사람이 잘 열리는지 확인합니다.
  • Docs 내보내기는 Word, PDF, 마크다운, 노션, 구글 문서를 지원합니다.
  • Slides는 PDF, 파워포인트, PNG, 구글 슬라이드를 지원합니다.
