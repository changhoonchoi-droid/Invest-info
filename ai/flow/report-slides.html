자료 조사하고 정리하기

Claude 앱

발표의 품질은 자료에서 갈립니다. 웹 검색·리서치로 근거를 모으고, 올린 자료만 근거로 답하는 도구도 함께 씁니다.

따라 하기

  1. + → 웹으로 검색을 켭니다.
  2. 깊은 조사는 리서치 모드를 씁니다.
  3. 자료가 많으면 NotebookLM에 소스 추가로 넣고 질문합니다.
  4. 답의 출처 숫자를 눌러 원문을 확인합니다.
  5. 핵심 메시지 3가지를 정리합니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장을 조사해 줘. 주요 제품 5개의 가격, 장단점, 도입 사례를 표로 정리하고 출처를 달아 줘.
  • NotebookLM은 웹 검색이 약해 최신 정보는 따로 보완합니다.

음성 메모로 말 먼저 쏟아내기

Claude Slides

빈 슬라이드가 막막하면 하고 싶은 말을 먼저 녹음합니다. 서식보다 내용에 집중할 수 있습니다.

따라 하기

  1. 휴대폰 음성 메모로 내용을 두서없이 말해 녹음합니다.
  2. 텍스트 변환본을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청합니다.
예시 프롬프트
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 나와 Claude만 보는 자료입니다.

문서·슬라이드 초안 만들기

Claude Docs

같은 채팅 안에서 보고서와 발표 자료를 이어서 만듭니다. 내용은 큰 모델로 정리하고 수정 반복은 작은 모델로 돌립니다.

따라 하기

  1. Opus 5.5로 보고서 내용을 대화로 정리합니다.
  2. /slides, /docs, /designs로 원하는 결과물을 만듭니다.
  3. Docs가 던지는 질문에 답하고 초안을 직접 수정합니다.
  4. 고칠 부분을 드래그해 댓글로 지시합니다.
  5. 수정 반복은 Sonnet 5.5로 바꿔 진행합니다.
예시 프롬프트
신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프를 만들어 줘
  • Docs 댓글에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • 화면 구성은 버전에 따라 영상과 다를 수 있습니다.

파일 안에서 바로 작업하기

Claude for Office

이미 쓰는 Office 파일을 떠나지 않고 분석·교정·덱 제작을 합니다. 변경 전에 확인을 구해 결과를 점검하며 쓸 수 있습니다.

따라 하기

  1. Excel에서 사이드바를 열고 목표를 구체적으로 질문합니다.
  2. 응답의 인용 상자로 근거 셀을 확인합니다.
  3. Word에서는 변경 내용 추적을 켜 두고 교정을 요청합니다.
  4. PowerPoint에서는 템플릿을 연 채 슬라이드 수·주제·어조를 적어 덱을 요청합니다.
  5. 고칠 슬라이드를 선택한 뒤 요청해 선택한 부분만 수정합니다.
예시 프롬프트
Create a pivot table showing total revenue by region and product.
  • Word 변경을 수락하면 되돌릴 수 없어 먼저 확인을 요청합니다.
  • 민감한 데이터는 조직 정책을 따릅니다.

디자인 시스템 만들기

Claude Design

디자인 시스템을 먼저 만들면 이후 슬라이드에 자동 적용되어 AI 티가 줄어듭니다. 폰트 불일치가 레이아웃 무너짐의 주원인입니다.

따라 하기

  1. claude.ai/design에서 디자인 시스템 탭의 Create를 누릅니다.
  2. 회사 이름·설명을 적고 기존 자료나 피그마 파일을 넣습니다.
  3. 폰트 파일을 업로드하고 Continue to generation을 누릅니다.
  4. Slide deck 프로젝트를 만들어 장수와 주제를 입력합니다.
  5. Share → Export에서 파워포인트를 고르고 커스텀 폰트로 내려받습니다.
예시 프롬프트
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • 스크린샷 베이스 PPTX는 모양은 같지만 편집이 안 됩니다.
  • Claude Design은 베타입니다.

규칙을 스킬로 저장하기

Claude Code

색·글꼴·장당 글자 수를 수치로 정한 규칙서를 스킬로 저장하면 다음 작업에서도 같은 톤을 유지합니다. 추상적 표현 대신 수치로 적습니다.

따라 하기

  1. 색 역할·글꼴·크기·장당 글자 수 기준으로 규칙서를 만듭니다.
  2. 샘플 PPT를 만들어 만족할 때까지 고칩니다.
  3. "지금까지 작업한 내용으로 스킬로 만들어 줘"라고 요청합니다.
  4. 세션을 재시작해 스킬을 적용합니다.
  5. 다음 작업에서 스킬을 호출해 대본만 넣습니다.
예시 프롬프트
방금 만든 샘플 PPT 방식을 스킬로 만들어 줘. 새 작업 폴더를 만들고 HTML, PPTX, 키노트를 생성한 뒤 HTML 기준으로 결과를 검증하는 단계까지 넣어 줘.
  • '깔끔하게' 같은 말은 규칙이 아닙니다.
  • 차트는 데이터 편집이 가능한 형태로 요청합니다.
