자료 조사하기

Claude

보고서의 뼈대가 될 시장·경쟁사 정보를 출처와 함께 모읍니다. 이 단계의 출처가 나중에 사실 확인의 기준이 됩니다.

따라 하기

  1. 프롬프트 입력창의 + 버튼을 누르고 웹 탭을 활성화합니다.
  2. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치를 켭니다.
  3. 조사 주제와 원하는 결과 형태를 적어 요청합니다.
  4. 출처 링크가 달린 결과를 읽고 쓸 만한 것만 추립니다.
예시 프롬프트
국내 중소기업용 협업 툴 시장의 주요 경쟁사 3곳을 조사해서, 가격·핵심 기능·장단점을 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 최신 정보는 검색을 켜고 묻습니다.

말로 생각 쏟아내기

Claude

빈 화면 앞에서 막막할 때는 하고 싶은 말을 음성으로 모두 녹음해 넘기는 것이 빠릅니다. 서식보다 내용에 집중할 수 있습니다.

따라 하기

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보내 정리를 요청합니다.
  4. 대상, 발표 시간 같은 기준을 덧붙여 말합니다.
예시 프롬프트
지금 상황을 설명할게. 나는 중소기업 영업팀 대리이고, 다음 주 고객사 제안 발표를 준비 중이야. 첨부한 자료를 보고 발표 흐름을 제안해 줘. 기준은 10분 안에 끝나고 비전문가도 이해할 수 있어야 해.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.

보고서 초안 쓰기

Claude Docs

보고서 내용을 먼저 대화로 정리한 뒤 같은 대화에서 문서를 만듭니다. Claude가 던지는 질문에 답하면 초안의 품질이 올라갑니다.

따라 하기

  1. 보고서 내용을 먼저 대화로 정리합니다(방향을 잡을 때는 Opus 5.5).
  2. 만들 결과물을 설명하거나 /docs를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 모두 답합니다.
  4. 초안이 나오면 직접 고치거나 고칠 부분을 드래그해 댓글로 지시합니다.
예시 프롬프트
첨부한 자료를 바탕으로 사장님께 보고할 런칭 브리프를 만들어 줘
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.

슬라이드로 이어 만들기

Claude Slides

문서를 만든 대화 안에서 슬라이드를 요청하면 앞의 내용이 그대로 바탕이 됩니다. 시장 조사 수치는 차트로 넣어 달라고 하면 보기 좋습니다.

따라 하기

  1. 같은 대화에서 /slides로 슬라이드를 요청합니다.
  2. 시장 조사는 차트로 넣어 달라고 지시합니다.
  3. 빠른 수정 반복은 Sonnet 5.5로 바꿔 진행합니다.
  4. 고칠 장은 댓글로 지시해 그 부분만 수정합니다.
예시 프롬프트
위 보고서를 바탕으로 10장짜리 발표 슬라이드를 만들어 줘. 시장 규모는 차트로 넣어 줘.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.

디자인 시스템으로 톤 맞추기

Claude Design

AI가 만든 PPT가 들쭉날쭉한 것은 기준이 없기 때문입니다. 색·글꼴 같은 규칙서를 한 번 만들어 두면 일정한 톤이 유지됩니다.

따라 하기

  1. claude.ai/design의 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. 원하는 기업의 DESIGN.md를 복사해 입력창에 붙여 넣습니다.
  3. 사용할 폰트 파일을 업로드하고 Continue to generation으로 생성합니다.
  4. 초기 화면에서 만든 디자인 시스템을 선택하고 PPT를 요청합니다.
  5. Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 내려받습니다.
  6. 작업 후 "지금까지 작업한 내용으로 스킬로 만들어 줘"라고 요청해 재사용합니다.
예시 프롬프트
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • '깔끔하게' 같은 말 대신 색 3가지, 본문 크기, 장당 글자 수처럼 수치로 적습니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.

댓글로 고치고 팀과 공유하기

Claude

만든 문서와 슬라이드를 팀원과 같이 보고 댓글로 의견을 모읍니다. 댓글이 달리면 Claude에게 업데이트를 요청해 반영합니다.

따라 하기

  1. 문서가 준비되면 조직의 팀원을 추가합니다.
  2. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  3. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  4. 공유로 팀원을 초대하거나 내보내기로 Word·PDF·PPT 등으로 저장합니다.
예시 프롬프트
팀원들이 단 댓글을 모두 반영해서 문서를 업데이트해 줘. 바뀐 부분은 요약해서 알려 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • Slides는 PDF·파워포인트·PNG·구글 슬라이드로 내보낼 수 있습니다.

사실 확인하고 발표 준비하기

Claude

AI가 쓴 숫자와 인용은 발표 전에 원문과 비교해야 합니다. 예상 질문과 답변까지 정리해 두면 발표 부담이 줄어듭니다.

따라 하기

  1. 수치와 인용마다 근거 출처를 달라고 요청합니다.
  2. 출처를 직접 열어 원문과 비교합니다.
  3. 근거가 없는 내용은 확인 필요로 표시해 달라고 합니다.
  4. 예상 질문과 답변을 정리해 달라고 요청합니다.
예시 프롬프트
이 자료로 경영진 대상 발표를 준비하려 해. 핵심 변화 3가지와 수치를 요약하고, 근거가 없는 내용은 확인 필요로 표시해 줘. 예상 질문 5개와 답변도 정리해 줘.
  • Adobe Acrobat의 PDF 스페이스(유료)는 요약 속 숫자를 눌러 원문 근거를 바로 볼 수 있습니다.
