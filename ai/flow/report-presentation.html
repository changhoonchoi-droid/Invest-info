흩어진 자료 한 폴더에 모으기

Cowork

보고서의 재료가 여러 파일에 흩어져 있으면 먼저 한 폴더에 모아 Claude가 합치고 정리하게 합니다. 원본은 그대로 두고 결과만 새 파일로 받아 안전하게 시작합니다.

따라 하기

  1. 작업용 새 폴더를 만들고 매출 데이터·회의록·메모 파일을 복사해 넣습니다.
  2. Claude 데스크톱 앱 입력창 하단 프로젝트 또는 폴더에서 폴더 추가로 그 폴더를 엽니다.
  3. 폴더 접근 권한 창에서 항상 허용을 고릅니다.
  4. 만들 결과물을 구체적으로 적고, 파일을 바꾸기 전에 계획부터 보여 달라고 합니다.
  5. 원본은 그대로 두고 결과는 날짜를 넣은 새 파일로 저장해 달라고 덧붙입니다.
  6. 결과 파일을 열어 빠진 자료가 없는지 확인합니다.
예시 프롬프트
이 폴더의 주간 매출 엑셀과 회의록 3개를 합쳐서 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 정리한 워드 보고서를 만들어 줘. 먼저 계획을 보여 주고, 원본은 그대로 두고 결과 파일명에는 날짜를 넣어 줘.
  • 고객 정보 같은 민감한 데이터는 빼고 먼저 하나만 시험해 보세요.
  • 9월 업데이트로 채팅과 Cowork가 합쳐져 모드를 따로 고를 필요가 없습니다.
  • 내 폴더 작업은 웹이 아니라 데스크톱 앱에서 합니다.

보고 내용을 대화로 정리하기

Claude 앱

결과물을 만들기 전에 보고 대상과 핵심 메시지를 대화로 정리해 두면 문서와 슬라이드가 같은 방향으로 나옵니다. 방향을 잡는 이 단계에는 큰 모델을 씁니다.

따라 하기

  1. 모델을 Opus 5.5로 고릅니다.
  2. 내가 누구이고 누구에게 보고하는지, 좋은 결과의 모습(분량·형식)을 적습니다.
  3. 앞 단계의 결과 파일을 첨부하고 핵심 메시지 3개와 근거 숫자를 뽑아 달라고 합니다.
  4. 더 필요한 정보가 있으면 Claude가 먼저 질문하게 합니다.
  5. 말로 하는 게 편하면 휴대폰 음성 메모로 하고 싶은 말을 녹음해 변환본을 붙여 넣습니다.
예시 프롬프트
나는 영업팀 과장이고, 금요일 본부장 보고에 쓸 3분기 실적 자료를 준비하고 있어. 첨부한 보고서에서 본부장이 꼭 알아야 할 핵심 메시지 3개와 근거 숫자를 뽑아 줘. 더 필요한 정보가 있으면 먼저 나에게 질문해 줘.
  • 음성 메모가 두서없어도 괜찮습니다. 나와 Claude만 보는 자료입니다.

Docs로 보고서 초안 만들기

Claude Docs

정리한 대화에서 바로 문서 초안을 만들면 내용을 다시 설명할 필요가 없습니다. 초안은 직접 고치거나 댓글로 Claude에게 고칠 부분을 지시합니다.

따라 하기

  1. 같은 대화에서 /docs를 입력하거나 만들 문서를 말로 설명합니다.
  2. Docs가 열리면 Claude가 묻는 질문에 모두 답합니다.
  3. 초안이 나오면 텍스트 편집기처럼 직접 고칩니다.
  4. 고칠 부분을 드래그하고 댓글을 눌러 지시를 적습니다.
  5. 오른쪽 위 공유로 팀원을 초대해 함께 다듬습니다.
예시 프롬프트
지금까지 정리한 내용으로 본부장 보고용 2쪽짜리 보고서를 만들어 줘. 첫 문단에 결론, 그다음 근거 숫자 표, 마지막에 다음 분기 할 일 3개를 넣어 줘.
  • Claude가 묻는 질문은 사용자마다 다르게 나옵니다.
  • 댓글에서 Claude를 멘션해 수정을 요청할 수도 있습니다.

Slides로 발표 자료 만들기

Claude Slides

보고서를 만든 같은 대화에서 발표 슬라이드를 요청하면 같은 내용과 숫자로 일관된 자료가 나옵니다. 숫자는 차트로, 발표할 말은 스피커 노트로 함께 받습니다.

따라 하기

  1. 같은 대화에서 /slides를 입력하고 구성·장수·디자인을 적습니다.
  2. 숫자 자료는 차트로 넣고 스피커 노트도 써 달라고 지시합니다.
  3. Claude가 주제·대상·디자인을 물으면 답합니다.
  4. 오른쪽 아래 캔버스 버튼으로 전체 슬라이드를 한눈에 봅니다.
  5. 오른쪽 위 재생 버튼으로 발표 모드를 실행해 흐름을 점검합니다.
예시 프롬프트
/slides 지금까지 정리한 실적 보고 내용으로 10장짜리 발표 자료를 만들어 줘. 장당 메시지는 하나, 분기별 매출은 막대 차트로, 각 장에 1분 분량 스피커 노트를 넣어 줘.
  • 회사 PowerPoint 템플릿을 꼭 써야 하면 PowerPoint 안의 Claude 애드인으로 템플릿에 맞춰 만들 수 있습니다.
  • 작업이 클라우드에서 돌아가 노트북을 닫아도 계속되고 휴대폰으로 진행 상황을 볼 수 있습니다.

숫자와 출처 검증하기

Claude 앱

상사에게 보일 숫자는 반드시 원본과 맞아야 합니다. Claude에게 근거와 확신 정도를 표시하게 한 뒤 직접 원본을 열어 대조합니다.

따라 하기

  1. 틀리면 곤란한 숫자·날짜·인용 문장을 먼저 표시합니다.
  2. 숫자마다 근거가 된 원본 파일과 위치를 알려 달라고 합니다.
  3. 문장마다 확신 정도를 높음·중간·낮음으로 표시하게 합니다.
  4. 근거를 찾지 못한 내용은 '확인 필요'로 표시하게 합니다.
  5. 제시된 근거를 직접 열어 실제로 그 내용이 있는지 확인합니다.
  6. 중요한 자료는 새 대화나 다른 AI에게 다시 검증시킵니다.
예시 프롬프트
이 발표 자료에서 숫자·날짜·인용이 들어간 문장마다 원본 파일의 어느 부분이 근거인지 알려 주고, 확신 정도를 높음·중간·낮음으로 표시해 줘. 근거를 찾지 못한 내용은 '확인 필요'로 표시해 줘.
  • 자동 검사, 눈 검사, 숫자 검산을 함께 쓰면 놓치는 것이 줄어듭니다.
  • 깔끔한 결과물은 정확하다는 증거가 아닙니다.

댓글로 고치고 디자인 맞추기

Claude Slides

초안이 나온 뒤의 문구·차트·색 수정은 빠른 모델로 여러 번 반복하는 편이 효율적입니다. 작은 것은 직접, 큰 것은 댓글로 맡깁니다.

따라 하기

  1. 초안이 나오면 모델을 Sonnet 5.5로 바꿉니다.
  2. 작은 수정은 슬라이드에서 직접 고칩니다.
  3. 큰 수정은 고칠 부분을 선택하고 댓글로 Claude에게 보냅니다.
  4. 문구 다듬기·차트 종류·색상 팔레트 바꾸기를 차례로 요청합니다.
  5. 회사 브랜드가 있다면 디자인 시스템을 적용해 색·글꼴을 통일합니다.
예시 프롬프트
3번 슬라이드는 글머리표 대신 4개 블록 레이아웃으로 바꾸고, 전체 색은 남색·회색·흰색 세 가지로만 맞춰 줘.
  • 방향 잡기는 Opus 5.5, 빠른 수정은 Sonnet 5.5가 권장됩니다.
  • '깔끔하게' 같은 말보다 색 개수·글씨 크기처럼 숫자로 지시하면 결과가 안정적입니다.

PPTX로 내보내 확인하기

Claude Slides

회사에서 공유하려면 PPTX·Word·PDF 같은 파일이 필요합니다. 레이아웃이 깨지는 주된 원인은 폰트 불일치라서 폰트 옵션을 골라 내보낸 뒤 직접 열어 확인합니다.

따라 하기

  1. 오른쪽 위 내보내기를 누릅니다.
  2. 파워포인트를 고르고 폰트 옵션은 커스텀 폰트를 선택합니다.
  3. 받은 PPTX를 파워포인트에서 열어 폰트와 레이아웃이 깨지지 않았는지 봅니다.
  4. 보고서 문서는 내보내기에서 Word·PDF 중 필요한 형식으로 저장합니다.
  5. 발표에서 나올 예상 질문과 답변을 정리해 달라고 요청합니다.
예시 프롬프트
이 발표를 본부장 앞에서 할 때 나올 만한 예상 질문 5개와 답변을 정리해 줘. 답변의 근거가 되는 슬라이드 번호도 적어 줘.
  • 유니버셜 폰트는 어디서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양은 같지만 편집할 수 없습니다.

디자인 규칙을 스킬로 남기기

Claude 앱

AI가 만든 자료가 매번 다르게 나오는 것은 기준이 없기 때문입니다. 이번 작업의 구성과 디자인 규칙을 숫자로 정리해 스킬로 저장하면 다음 분기에도 같은 품질을 얻습니다.

따라 하기

  1. 색 3가지, 본문·제목 글씨 크기, 장당 글자 수처럼 규칙을 숫자로 적습니다.
  2. '깔끔하게' 같은 표현은 수치로 고쳐 씁니다.
  3. 작업을 마친 대화에서 지금까지의 구성과 규칙을 스킬로 만들어 달라고 요청합니다.
  4. 다음 보고서 때 /를 입력해 저장한 스킬을 고릅니다.
  5. 같은 요청을 스킬 저장 전후로 실행해 결과를 비교합니다.
예시 프롬프트
지금까지 만든 실적 보고 자료의 구성과 디자인 규칙(색 3가지, 본문 26~30px, 제목 68px, 장당 약 200자, 장당 주제 1개)을 스킬로 만들어 줘. 다음 분기 보고서도 같은 형식으로 만들 수 있게 해 줘.
  • 한글 글꼴은 자간을 0으로 두면 AI 티가 줄어듭니다.
  • 스킬은 일반 텍스트 파일이라 팀과 공유하면 누구나 같은 결과를 냅니다.
