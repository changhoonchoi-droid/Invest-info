할 말과 맥락 정리하기

Claude 앱

빈 문서 앞에서 막막하다면 서식보다 내용부터 정리합니다. 보고 대상과 목적, 가진 자료를 알려 주고 Claude가 질문하게 하면 빠진 맥락이 채워집니다.

따라 하기

  1. 내 직무, 보고 대상, 보고 목적을 먼저 알려 줍니다.
  2. 원하는 결과물의 분량과 형식(보고서 몇 장, 슬라이드 몇 장)을 적습니다.
  3. 실적 엑셀·회의 메모 같은 자료를 첨부합니다.
  4. 글로 쓰기 어려우면 휴대폰 음성 메모로 하고 싶은 말을 두서없이 녹음해 받아 적은 글을 붙여 넣습니다.
  5. Claude가 필요한 정보를 먼저 질문하게 하고 하나씩 답합니다.
예시 프롬프트
나는 영업기획팀 대리고, 다음 주 본부장 보고용으로 3분기 실적과 4분기 계획을 정리하고 있어. 결과물은 A4 2장 보고서와 10장 이내 발표 자료야. 첨부한 실적 엑셀과 회의 메모를 보고, 더 좋은 결과를 위해 필요한 정보를 먼저 나에게 질문해 줘.
  • 음성 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • 방향을 잡는 이 단계는 Opus 5.5로 하는 것이 공식 권장 방식입니다.

근거 자료 조사하기

Claude 앱

보고서의 설득력은 근거에서 나옵니다. 시장 규모나 경쟁사 동향처럼 최신 정보가 필요하면 웹 검색이나 딥 리서치로 출처가 달린 자료를 모읍니다.

따라 하기

  1. 입력창의 + 버튼에서 웹을 눌러 웹 검색을 켭니다.
  2. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치를 켭니다.
  3. 조사 범위, 기간, 믿을 만한 출처의 조건을 적어 요청합니다.
  4. 수치마다 출처 링크와 발표 시점을 달고, 확실하지 않으면 '확인 필요'로 표시하게 합니다.
  5. 핵심 출처는 직접 열어 내용이 맞는지 확인합니다.
예시 프롬프트
국내 B2B SaaS 시장 규모와 성장률을 조사해 줘. 최근 2년 안의 공신력 있는 자료만 쓰고, 수치마다 출처 링크와 발표 시점을 달아 줘. 확실하지 않으면 '확인 필요'라고 표시해 줘.
  • 보고서·기사 파일이 많다면 Adobe Acrobat의 PDF 스페이스(최대 100개)에 모아 요약하고, 요약 속 숫자를 눌러 원문 근거를 확인할 수 있습니다(유료).

대화에서 보고서 초안 만들기

Claude Docs

지금까지 나눈 대화를 바탕으로 Claude가 문서를 바로 만들어 줍니다. 초안은 직접 고치거나 드래그 후 댓글로 수정을 지시해 다듬습니다.

따라 하기

  1. 같은 대화에서 /docs를 입력하고 만들 보고서를 설명합니다.
  2. Claude가 던지는 질문에 모두 답합니다.
  3. 초안이 나오면 텍스트 편집기처럼 직접 고칩니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 '이 내용을 더 자세하게 작성해 줘'처럼 지시합니다.
  5. 문구 다듬기 같은 잔손질은 Sonnet 5.5로 바꿔 반복합니다.
  6. 내보내기에서 Word로 저장합니다.
예시 프롬프트
/docs 지금까지 정리한 3분기 실적과 4분기 계획으로 본부장 보고용 2장짜리 보고서를 만들어 줘. 맨 앞에 결론 3줄을 두고, 근거 수치에는 출처를 달아 줘.
  • Docs는 Word·PDF·마크다운·노션·구글 문서로 내보낼 수 있습니다.
  • Docs·Slides·Design은 모든 유료 요금제에서 쓸 수 있습니다.

Word에서 문장 다듬기

Claude for Word

Word 오른쪽 Claude 패널은 고쳐 쓰기, 분량 줄이기, 오탈자 교정을 변경 내용 추적으로 남겨 줍니다. 수정을 하나씩 수락·거절할 수 있어 최종 문서를 내가 통제합니다.

따라 하기

  1. Word에서 보고서를 열고 오른쪽 Claude 패널을 엽니다.
  2. 모든 수정에 변경 내용 추적을 켜 달라고 요청하고 확인창에서 Allow once를 누릅니다.
  3. 고쳐 쓸 문단을 선택하고 읽는 사람에 맞게 다시 써 달라고 요청합니다.
  4. 분량을 줄일 때는 목표 분량과 지킬 부분(인용문, 날짜)을 함께 알려 줍니다.
  5. 패널에 /를 입력해 copy edit 스킬로 오탈자를 교정합니다.
  6. 수정 카드를 하나씩 확인하고 수락합니다.
예시 프롬프트
이 문서에서 하는 모든 수정은 변경 내용 추적을 켠 상태로 해 줘. 결론 문단은 본부장님이 30초 안에 읽을 수 있게 고쳐 쓰고, 날짜와 수치는 바꾸지 마.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • Pro·Max·Team·Enterprise 플랜에 포함되며 Microsoft AppSource에서 설치합니다.

슬라이드로 바꾸기

Claude Slides

보고서를 만든 같은 대화에서 슬라이드를 요청하면 내용이 일관되게 이어집니다. 스피커 노트와 발표 모드까지 확인한 뒤 PowerPoint에서 편집할 수 있는 PPTX로 내보냅니다.

따라 하기

  1. 보고서를 만든 대화에서 /slides를 입력하고 구성·장수·디자인을 적습니다.
  2. 시장·실적 수치는 차트로 넣어 달라고 지시합니다.
  3. Claude가 묻는 주제·대상·디자인 질문에 답합니다.
  4. 스피커 노트를 확인하고 필요하면 고칩니다.
  5. 우측 하단 캔버스 버튼으로 전체 슬라이드를 한눈에 보고 고칩니다.
  6. 우측 상단 재생 버튼으로 발표 모드를 실행해 봅니다.
  7. 내보내기에서 파워포인트를 고르고 폰트 옵션은 커스텀 폰트를 선택해 내려받습니다.
예시 프롬프트
/slides 위 보고서를 바탕으로 본부장 보고용 10장 발표 자료를 만들어 줘. 장당 메시지는 하나만, 실적 수치는 차트로 넣고 스피커 노트도 써 줘.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치이므로 폰트 파일을 업로드해 두면 좋습니다.
  • 회사 색·글꼴을 디자인 시스템으로 만들어 두면 이후 슬라이드에 자동 적용됩니다.
  • 스크린샷 베이스 PPTX는 모양은 같지만 편집할 수 없습니다.

회사 템플릿에 맞추기

Claude in PowerPoint

Claude in PowerPoint는 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 회사 템플릿에 맞춰 덱을 고칩니다. 결과가 PowerPoint 기본 도형·차트라 하나씩 직접 편집할 수 있습니다.

따라 하기

  1. 회사 템플릿이 적용된 파일을 PowerPoint에서 열고 Claude 애드인을 엽니다.
  2. 필요하면 + 버튼으로 보고서·데이터 파일을 올립니다.
  3. 고칠 슬라이드나 텍스트 상자를 선택하고 그 부분만 수정을 요청합니다.
  4. 글머리표가 많은 슬라이드는 블록형 시각 레이아웃으로 바꿔 달라고 하며 블록마다 넣을 항목을 지정합니다.
  5. '4번과 5번을 하나로 합쳐 줘'처럼 구조를 정리합니다.
  6. 글꼴·색상·간격과 출처 표기가 템플릿과 맞는지 확인합니다.
예시 프롬프트
이 템플릿에 맞춰 4분기 계획 보고 덱을 정리해 줘. 4번과 5번 슬라이드는 하나로 합치고, 글머리표가 많은 7번은 4개 블록 레이아웃으로 바꿔 줘. 필요하면 질문해 줘.
  • Claude에 설정한 Google Drive·Notion·Confluence 커넥터가 애드인에도 그대로 적용됩니다.
  • 복잡하게 맞춤화된 템플릿은 브랜드 지침과 맞는지 직접 확인하세요.

숫자·출처 마지막 검산하기

Claude 앱

보고 직전에는 규칙 위반, 어색한 화면, 틀린 숫자를 따로따로 확인합니다. 특히 모든 수치가 원본 데이터·출처와 맞는지 검산해야 보고 자리에서 곤란해지지 않습니다.

따라 하기

  1. 완성본을 Claude에 올리고 자동 검사로 글자 수·글꼴 같은 규칙 위반을 찾게 합니다.
  2. 눈 검사로 슬라이드를 직접 넘겨 보며 어색한 곳을 고칩니다.
  3. 숫자 검산으로 모든 숫자가 원본 엑셀·출처와 맞는지 확인하게 합니다.
  4. 출처를 찾지 못한 내용은 '확인 불가'로 표시하게 하고 직접 확인합니다.
  5. 고친 내용은 다음 작업을 위해 메모해 둡니다.
예시 프롬프트
아래 보고서와 발표 자료에 나온 통계와 인용을 하나씩 검토해 줘. 첨부한 원본 엑셀과 숫자가 다르면 표시하고, 주장마다 근거 출처를 붙이고, 출처를 찾지 못한 내용은 '확인 불가'로 표시해 줘. 모르면 모른다고 해도 괜찮아.
  • 상사에게 보일 슬라이드의 통계는 반드시 검증합니다.
  • 근거가 없는 내용을 '확인 필요'로 표시하라고 미리 요청해 두면 검산이 쉬워집니다.

디자인 규칙을 스킬로 저장하기

Claude Code

AI로 만든 PPT가 매번 들쭉날쭉한 것은 기준이 없기 때문입니다. 색·글꼴·글씨 크기를 수치로 적은 규칙서와 이번 작업 과정을 스킬로 저장하면 다음 보고서는 대본만 넣어 같은 품질로 만듭니다.

따라 하기

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준을 수치로 적은 규칙서를 만듭니다.
  2. 한글 글꼴은 자간 0, 수정 가능한 PPTX, 데이터 편집이 되는 차트를 규칙에 넣습니다.
  3. 규칙서로 PPT 작업을 한 번 해 보고 자동·눈·숫자 검사로 확인합니다.
  4. 작업을 마치면 대화 내용과 결과물로 스킬을 만들어 달라고 요청합니다.
  5. 'PPT 만드는 방법을 총정리한 업무 매뉴얼을 만들어 줘'로 매뉴얼도 함께 남깁니다.
  6. 다음 PPT 작업 때 그 스킬을 불러와 대본만 넣어 생성합니다.
예시 프롬프트
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • '깔끔하게'는 규칙이 아닙니다. 예: 색 3가지, 본문 26~30px, 제목 68px, 장당 약 200자처럼 수치로 적습니다.
  • HTML과 PPTX는 생성 방식이 달라 디자인이 틀어질 수 있으니 계속 비교해 맞춥니다.
