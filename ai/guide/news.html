발표·소식

이 페이지는 Claude를 중심으로 한 신기능 발표, 모델 출시, 회사 소식, 연구·안전 이야기를 업무에 연결해 보는 곳입니다. 먼저 새 모델과 업무용 기능을 어디서 쓰는지 확인하고, 그다음 데이터 보관·환각·편향 같은 안전 이야기를 읽은 뒤, 마지막으로 팀 단위 도입 사례로 넘어가 보세요. 발표는 요금제·지역별로 순차 제공되는 경우가 많으니 본인 계정에서 보이는지 먼저 확인하는 것이 좋습니다.

1. Claude 모델 고르고 바꿔 쓰기

Claude는 모델 계열이 여러 개라 작업에 맞게 골라 쓰면 결과와 사용량이 달라집니다. 새 모델이 나오면 무엇이 달라졌는지 확인하고 내 업무에 맞는지 시험해 볼 때 쓰는 가이드입니다.

  1. Claude 대화 화면에서 모델 전환 메뉴를 엽니다.
  2. 유료 플랜이라면 목록에서 새로 출시된 Fable 5.2가 보이는지 확인합니다.
  3. 방향을 잡는 단계에서는 Opus 5.5를, 빠른 수정 단계에서는 Sonnet 5.5를 고릅니다.
  4. 같은 요청을 두 모델에 보내 결과와 걸린 시간을 비교합니다.
  5. 업무에 잘 맞는 모델을 정해 두고, 새 모델이 나올 때마다 같은 요청으로 다시 비교합니다.
예시
아래 보고서 초안을 임원 보고용 한 장 요약으로 줄여 줘. 핵심 결론 3개와 다음 할 일을 포함해 줘.
  • Fable 5.2는 지식 노동 과제 완료율이 높다고 소개됐지만, 작업량이 큰 작업은 사용량도 많이 쓸 수 있으니 첫 시도는 작은 일로 해 보세요.
  • 벤치마크와 실제 체감은 다를 수 있으니 직접 써 보고 고르는 것이 좋습니다.
  • 일부 고객 팀은 새 모델을 받으면 자동화 평가(evals)부터 돌려 봅니다. 자주 하는 업무 요청을 몇 개 정해 두면 비교가 쉽습니다.

2. Claude 모바일 앱 새 기능 쓰기

Claude 모바일 앱이 계정 전환, 분할 화면, 음성 모드 등에서 업데이트됐습니다. 이동 중이나 태블릿에서 Claude를 쓰는 직장인이 설정해 두면 편한 기능입니다.

  1. iOS 또는 Android에서 Claude 앱을 최신 버전으로 업데이트합니다.
  2. 업무용 계정과 개인 계정을 로그아웃 없이 함께 로그인해 두고 필요할 때 전환합니다.
  3. iPad나 iPhone Duo에서는 Claude가 만든 아티팩트를 대화 옆 열에 열어 두 창을 나란히 씁니다.
  4. iPhone에서는 음성 모드를 켜고 Apple CarPlay에서도 써 봅니다.
  5. iPhone에서 사진을 골라 첨부하면 업로드 중에도 채팅에 바로 표시되는지 확인합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공 예정입니다. 웹과 데스크톱에는 이미 있고 Mac에서는 Command K로 쓸 수 있습니다.
  • Chromebook·폴더블의 Android 앱은 크기 조절 사이드바, 마우스 우클릭, Claude Desktop과 같은 단축키를 지원합니다.
  • 인터페이스 언어는 24개가 추가되어 총 33개 언어입니다.

3. Claude로 슬라이드·디자인·문서 만들기

Claude Slides, Claude Design, Claude Docs는 대화를 벗어나지 않고 발표 자료, 이미지 세트, 한 장짜리 문서를 만드는 베타 기능입니다. 출시·보고용 자료를 한 번에 정리해야 할 때 씁니다.

  1. Claude 대화에서 만들고 싶은 결과물의 배경과 목적을 하나의 브리프로 적습니다.
  2. 브리프를 바탕으로 슬라이드, 소셜 이미지, 한 장짜리 문서를 요청합니다.
  3. 결과물에서 고치고 싶은 부분에 코멘트를 답니다.
  4. 코멘트를 Claude에게 보내 그 부분만 수정하게 합니다.
  5. Claude Design을 쓸 때는 먼저 회사 디자인 시스템(색상·폰트·컴포넌트)을 만들어 두고 이후 프로젝트에 적용합니다.
예시
신제품 출시 브리프야: 대상은 30~40대 직장인, 핵심 메시지는 '퇴근 30분 앞당기기'. 이 브리프로 발표 슬라이드 10장과 소셜용 이미지 3종, 현장용 한 장 요약 문서를 만들어 줘.
  • 디자인 시스템 없이 쓰면 결과물이 'AI스럽게' 나올 수 있다는 평가가 있습니다.
  • Claude Design은 4월 17일 공개된 리서치 프리뷰로 웹에서만 쓸 수 있고 Pro·Max·Team·Enterprise 구독이 필요합니다.
  • 사용량 한도가 채팅·Claude Code와 별도로 관리되며 빡빡하다는 평가가 있습니다.

4. Claude Whiteboards·Sheets·Data 써보기

Claude에 팀이 함께 쓰는 화이트보드, 수식이 담긴 시트, 인증된 쿼리와 실시간 공유가 되는 Data(옛 dashboards)가 추가됐습니다. 아이디어 구상이나 간단한 표·대시보드 작업에 쓸 수 있습니다.

  1. 유료 플랜 계정으로 Claude에 로그인합니다.
  2. 아이디어 정리나 워크플로·행사 계획에는 Whiteboards를 열어 구상을 시각적으로 펼쳐 달라고 요청합니다.
  3. 간단한 계산표에는 Sheets에서 수식이 들어간 시트를 만들게 하고, 편집된 부분의 표시를 확인합니다.
  4. 데이터 현황 공유에는 Data로 대시보드를 만들어 팀과 공유합니다.
  5. 연동 앱은 인터랙티브 커넥터로 Claude 안에서 바로 엽니다.
예시
다음 달 사내 워크숍 준비 과정을 화이트보드로 정리해 줘. 준비 단계, 담당자, 마감일을 칸으로 나눠 줘.
  • Data·Whiteboards·Sheets는 모든 유료 플랜에서 쓸 수 있고 Whiteboards와 Sheets는 베타입니다.
  • Sheets에는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵다는 평가가 있습니다.
  • Data는 베타를 벗어났지만 인증 쿼리와 실시간 공유는 아직 베타입니다.
  • 모든 작업은 각자 가진 권한 안에서 이뤄집니다.

5. Claude Meetings로 회의 노트 맡기기

Claude Meetings는 통화에 참가자로 들어와 노트를 쓰고, 요청하면 문서나 화이트보드를 만들어 주는 기능입니다. 회의록 정리에 시간을 쓰는 팀에게 맞습니다.

  1. Team 또는 Enterprise 요금제인지 확인합니다.
  2. 통화를 시작하고 Claude Meetings를 참가자로 들어오게 합니다.
  3. 회의 중 필요할 때 문서나 화이트보드 작성을 요청합니다.
  4. 회의가 끝나면 Claude가 쓴 노트를 확인하고 빠진 내용을 보완합니다.
예시
지금까지 논의한 내용을 바탕으로 결정 사항과 담당자별 할 일을 문서로 만들어 줘.
  • Team·Enterprise 요금제에서 베타로 제공됩니다.
  • Claude의 작업은 각자 가진 권한 안에서 이뤄집니다.

6. Slack에서 Claude Tag로 일 맡기기

Claude Tag는 Slack 채널에서 Claude를 태그해 일을 맡기는 기능입니다. 채널 맥락을 파악해 작업하고, 끝나거나 입력이 필요하면 알려 줍니다. 팀 단위로 반복 업무를 넘기고 싶을 때 씁니다.

  1. Team 또는 Enterprise 요금제인지 확인합니다.
  2. Slack 스레드에서 Claude를 태그하고 목표를 적습니다.
  3. 여러 사람이 같은 스레드에서 함께 지시를 추가합니다.
  4. 작업이 끝났거나 입력을 요청하는 알림이 오면 확인합니다.
  5. 채널별로 접근 범위를 나누고 Claude 계정의 자격 증명 사용 기록을 점검합니다.
  • Slack에서 베타로 제공되며 Microsoft Teams 등으로 확대할 계획입니다.
  • 비공개 채널이나 DM에서 배운 내용은 그 안에만 남습니다.
  • Anthropic 제품 PR의 약 65%를 Tag가 작성한다고 소개됩니다.
  • 작업이 아니라 목표를 맡기는 방식으로 쓰는 팀이 늘고 있습니다.

7. AI 답을 이해하며 쓰는 업무 습관

AI 답을 복사해 전달만 하면 누구나 할 수 있는 일이 됩니다. 리서치는 AI에게 맡기되, 이해와 판단은 내가 확보하는 방법을 정리한 가이드입니다.

  1. 자료 조사와 검증은 AI에게 많이 돌리게 합니다.
  2. 제안서는 빈 문서에서 AI와 한 줄씩 쓰며 모르는 부분을 질문합니다.
  3. 일이 들어오면 '이걸 안 하면 어떤 문제가 생길까?'를 먼저 묻습니다.
  4. AI가 모르는 내 도메인 영역에서 가치를 더하고, AI로 스스로 검증합니다.
  5. 만들고 버릴 것을 판단하는 기준을 정해 둡니다.
예시
내가 이해했는지 점검하게 이 제안서 초안의 핵심 논리를 3문장으로 설명하고, 내가 물어봐야 할 질문 5개를 알려 줘.
  • 사람이 AI 사이에서 복붙만 하는 상태를 '미트 프록시'라고 부릅니다.
  • AI로 효율이 높아져도 새 일이 채워져 더 바빠질 수 있으니 하지 않을 일을 정하는 것이 중요합니다.

8. AI 조언에 휘둘리지 않고 결정하기

Anthropic 연구에서 분석가들은 에이전트가 기운 쪽을 86% 따랐고, 자신이 결정했다고 착각하기 쉬웠습니다. AI에게 계획이나 판단을 맡길 때 영향을 줄이는 세 가지 방법을 따라 해 봅니다.

  1. AI에게 조언을 구하기 전에 내 우선순위를 먼저 적고, AI가 내 우선순위를 먼저 묻게 합니다.
  2. 논쟁이 되는 결정은 말로만 정하지 말고 프로토타입으로 만들어 비교합니다.
  3. AI에게 '어떤 조건이면 조언을 바꾸겠는가'를 묻습니다.
  4. 최종 추천에 AI의 논거를 썼다면 출처로 밝혀 둡니다.
예시
추천하기 전에 내 우선순위부터 질문해 줘. 그리고 네 추천이 어떤 조건에서 바뀌는지도 알려 줘.
  • 연구는 에이전트의 기울기를 일부러 강화했고, 한 분야·한 과제·한 모델만 다뤘다는 한계가 있습니다.
  • 사전에 선호가 있던 분석가도 에이전트가 반대하면 60%가 선호를 바꿨습니다.

9. AI 환각 줄이며 검증하기

환각은 AI가 없는 내용을 사실처럼 말하는 현상입니다. 환각이 생기기 쉬운 상황을 알고 확인하는 습관을 들이면 업무 자료의 실수를 줄일 수 있습니다.

  1. 구체적 사실, 통계, 인용, 정확한 날짜·이름·숫자는 환각 가능성이 높다고 생각하고 점검합니다.
  2. 답에 출처를 요청합니다.
  3. AI에게 답의 확신도를 묻습니다.
  4. 새 대화를 열어 같은 내용을 검증하게 합니다.
  5. 중요한 숫자와 인용은 원문을 직접 확인합니다.
예시

10. Claude 데이터 보관 방식 이해하기

Claude Fable 5부터 안전 모니터링을 위해 최근 30일의 프롬프트와 출력이 저장됩니다. 회사에서 쓰기 전에 보관 범위와 기업용 옵션을 알아 두는 가이드입니다.

  1. Claude Fable 5 이후 모델은 최근 30일의 프롬프트와 출력이 안전 모니터링용으로 저장된다는 점을 확인합니다.
  2. 엔터프라이즈 데이터는 명시적 허가 없이 학습에 쓰이지 않는다는 점을 확인합니다.
  3. 사람의 검토는 자동 시스템이 유해 가능성을 표시한 드문 경우에만 승인된 소수 검토자가 한다는 점을 알아 둡니다.
  4. 조직이 데이터를 자체 클라우드에 두어야 한다면 Enterprise Frontier Safeguards(EFS)를 검토합니다.
  5. EFS가 제공되기 전까지는 대상 조직이 Fable 5와 5.1에서 데이터 보관 없음(ZDR)을 받는지 확인합니다.
  • EFS는 올가을 이후 단계적으로 제공됩니다.
  • EFS의 검토는 기계로만 이뤄지고 결과는 정해진 탐지 항목으로 제한됩니다.
  • 보안 정책 판단은 공식 문서와 담당자 확인이 필요합니다.
