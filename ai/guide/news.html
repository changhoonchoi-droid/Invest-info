1. 작업에 맞는 Claude 모델 고르기

Claude는 여러 모델 계열이 있어 작업 성격에 따라 골라 쓰면 결과와 사용량이 달라집니다. 새 모델이 나왔을 때 무엇을 바꿔 써 볼지 판단하는 기본 기준을 정리합니다.

  1. Claude 대화 화면에서 모델 전환 메뉴를 엽니다.
  2. 유료 플랜이면 목록에서 Fable 5.2가 보이는지 확인합니다.
  3. 방향을 잡는 단계에는 Opus 5.5를 선택해 아이디어와 구조를 먼저 만듭니다.
  4. 방향이 정해지면 Sonnet 5.5로 바꿔 빠른 수정과 다듬기를 합니다.
  5. 슬라이드·게임·시뮬레이션처럼 한 번에 완성도 높은 결과가 필요하면 Fable 5.2로 같은 요청을 해 비교합니다.
  6. 결과와 사용량을 비교해 내 업무에 맞는 조합을 정합니다.
  • Fable 5.2로 슬라이드 덱 한 개를 약 30분 작업했을 때 ultra 플랜 사용량의 약 1.5%를 썼다는 사례가 있습니다.
  • 벤치마크보다 내 업무로 직접 써 보고 고르라는 조언이 반복됩니다.
  • 새 모델이 나오면 평소 쓰던 작업 하나를 그대로 맡겨 비교해 보는 방식이 좋습니다.

2. 채팅 하나로 문서·슬라이드·디자인 만들기

9월 업데이트 이후 채팅과 Cowork가 하나의 Claude로 합쳐져, 어느 대화에서든 문서·슬라이드·디자인을 만들 수 있습니다. 원하는 결과를 말하면 Claude가 방법을 찾고, 작업은 클라우드에서 계속됩니다.

  1. Claude에서 새 대화를 열고 만들고 싶은 결과물(발표 자료, 한 장 요약 문서, 소셜 이미지 등)을 설명합니다.
  2. 출시 브리프처럼 목적·대상·핵심 메시지를 한 번에 적어 줍니다.
  3. Claude가 만든 슬라이드, 디자인, 문서 결과를 확인합니다.
  4. 고치고 싶은 부분에 코멘트를 달아 Claude에게 보냅니다.
  5. 작업이 오래 걸리면 노트북을 닫아도 되고, 휴대폰으로 진행 상황을 확인합니다.
예시
신제품 출시 브리프입니다. 대상은 중소기업 마케터, 핵심 메시지는 '보고서 작성 시간을 절반으로'입니다. 이 내용으로 발표용 슬라이드, 소셜 이미지 세트, 현장용 한 장 요약 문서를 만들어 주세요.
  • Claude Slides, Claude Design, Claude Docs는 베타로 제공됩니다.
  • 기존 Cowork 작업은 그대로 유지됩니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집합니다.

3. Claude 디자인으로 디자인 시스템 만들고 앱·PPT 제작하기

Claude 디자인은 회사 색상·폰트·컴포넌트를 담은 디자인 시스템을 먼저 만들어 두고, 그 위에서 앱 프로토타입이나 피치덱을 만드는 도구입니다. 시스템 없이 쓰면 결과가 'AI스러워지기' 쉬워서 순서가 중요합니다.

  1. 웹에서 Claude 디자인에 접속합니다. 웹에서만 쓸 수 있고 Pro·Max·Team·Enterprise 구독이 필요합니다.
  2. 먼저 회사 디자인 시스템을 생성합니다.
  3. 만든 디자인 시스템이 이후 프로젝트에 적용되도록 선택합니다.
  4. 만들 앱 프로토타입이나 PPT 내용을 일상 언어로 설명합니다.
  5. 결과를 확인하고 부분별로 수정을 요청합니다.
  6. 실제 웹 서비스가 필요하면 결과를 Claude Code로 넘겨 구현합니다.
  • 디자인 시스템 없이 쓰면 결과물이 'AI스럽다'는 평가가 있습니다.
  • 사용량 한도가 채팅·Claude Code와 별도로 관리되며, 영상 제작자는 Max 플랜에서 62%를 소진했습니다.
  • 무료 플랜에서는 쓸 수 없고, 리서치 프리뷰 단계입니다.

4. 시트·화이트보드·데이터 아티팩트 써 보기

Claude Artifacts에 시트(Sheets)와 화이트보드(Whiteboard)가 추가되고 대시보드는 데이터(Data)로 이름이 바뀌었습니다. 아이디어를 시각적으로 펼치거나 간단한 표를 만들 때 유용합니다.

  1. 유료 플랜 계정으로 Claude에 접속합니다.
  2. 아이디어 구상이나 행사 계획처럼 펼쳐 놓고 싶은 주제를 요청에 적습니다.
  3. 화이트보드로 만들어 달라고 지정해 워크플로나 계획을 시각적으로 배치합니다.
  4. 간단한 표 작업은 시트로 만들어 달라고 요청합니다.
  5. 대시보드 기능을 찾을 때는 이름이 바뀐 데이터를 확인합니다.
  • 시트에는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵다는 평가입니다.
  • 화이트보드는 아이디어 구상과 워크플로·행사 계획에 유용하다고 소개됩니다.
  • 세 기능 모두 유료 플랜에서 쓸 수 있습니다.

5. Slack에서 Claude Tag로 팀 업무 맡기기

Claude Tag는 Slack 스레드에서 Claude를 태그해 팀과 함께 일하게 하는 기능입니다. 채널 맥락을 파악해 작업하고 끝나거나 입력이 필요할 때 알려 줍니다.

  1. Team 또는 Enterprise 요금제에서 Claude Tag가 켜져 있는지 확인합니다(베타).
  2. Slack 채널의 스레드에서 Claude를 태그하고 요청을 적습니다.
  3. Claude가 채널의 맥락을 파악해 작업하는 것을 지켜봅니다.
  4. 같은 스레드에서 다른 팀원도 함께 지시를 추가합니다.
  5. 작업이 끝나거나 입력이 필요하다는 알림이 오면 확인하고 답합니다.
  6. 채널별로 반복되는 지시는 메모리로 쌓이는지 확인합니다.
  • Claude는 자기 계정과 권한을 가지며 채널별 접근 범위가 나뉘고, 모든 자격 증명 사용이 기록됩니다.
  • 비공개 채널이나 DM에서 배운 내용은 그 안에만 남습니다.
  • 데이터 질문 답변, PR 작성, 버그 수정, 사내 문의 응대 등에 쓰입니다.
  • Microsoft Teams 등으로 확대할 계획이 있다고 밝혔습니다.

6. Claude 모바일 앱 새 기능 활용하기

10월 모바일 앱 업데이트로 계정 전환, 태블릿 화면 분할, 음성 모드, 언어 지원이 개선되었습니다. 출퇴근과 이동 중에 Claude를 쓰는 분께 도움이 됩니다.

  1. iOS 또는 Android의 Claude 앱을 최신 버전으로 업데이트합니다.
  2. 업무용과 개인 계정을 로그아웃 없이 동시에 로그인해 전환합니다.
  3. iPad나 iPhone Duo에서는 아티팩트가 대화 옆 열에 열리는지 확인하고 두 창을 나란히 씁니다.
  4. 음성 모드를 켜 보고, iPhone이면 Apple CarPlay에서도 써 봅니다.
  5. 앱 언어를 바꿔 33개 언어 중 원하는 언어로 설정합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공 예정이며 웹과 데스크톱에는 이미 있습니다(Mac은 Command K).
  • iPhone에서 사진을 고르면 업로드 중에도 바로 채팅에 표시됩니다.
  • Chromebook·폴더블의 Android 앱은 크기 조절 사이드바와 마우스 우클릭을 지원합니다.

7. Claude 개인 금융·Duet 신기능 살펴보기

Claude에 개인 금융 기능과 Duet 앱이 새로 소개되었습니다. 둘 다 현재 미국 구독자 대상 제한 공개라, 한국 사용자는 어떤 기능인지 미리 이해해 두는 용도로 보면 됩니다.

  1. 개인 금융은 현재 미국의 Pro·Max·Ultra 플랜에 베타로 순차 제공되는지 확인합니다.
  2. 이용 가능하면 연결할 계좌를 직접 골라 연결합니다.
  3. 지출, 청구서, 잔액에 대해 Claude에게 쉬운 설명을 요청합니다.
  4. 연결을 끊고 싶을 때는 언제든 연결을 해제합니다.
  5. Duet은 미국 Pro·Max 구독자 대상 대기자 명단으로 열려 있으니 대상이면 등록 여부를 확인합니다.
  • 개인 금융에서 Claude의 계좌 접근은 읽기 전용입니다.
  • Duet은 연구 프리뷰이며, 사용자를 대신해 행동하기 전에 먼저 확인을 받습니다.
  • 두 영상 모두 자막 내용이 적어 제목과 설명을 바탕으로 정리한 것이라 세부 사용법은 공식 안내를 확인하세요.

8. Claude 데이터 보관 방식 확인하기

Claude Fable 5부터 안전 모니터링을 위해 최근 30일의 프롬프트와 출력이 저장됩니다. 회사에서 쓰기 전에 어떤 데이터가 어떻게 다뤄지는지 알아 두는 가이드입니다.

  1. 내가 쓰는 모델이 Fable 5 이후 계열인지 확인합니다.
  2. 최근 30일의 프롬프트와 출력이 안전 모니터링용으로 저장된다는 점을 숙지합니다.
  3. 엔터프라이즈 데이터는 명시적 허가 없이 학습에 쓰이지 않는다는 점을 확인합니다.
  4. 조직이 모니터링 데이터를 자체 클라우드에 두어야 한다면 Enterprise Frontier Safeguards(EFS)를 검토합니다.
  5. EFS가 제공되기 전에는 대상 조직이 Fable 5와 5.1에서 데이터 보관 없음(ZDR)을 받는지 담당자에게 확인합니다.
  • 자동 시스템이 분석하며 기본적으로 Anthropic 직원은 읽을 수 없습니다.
  • 사람의 검토는 유해 가능성이 표시된 드문 경우에만 승인된 소수 검토자가 하고, 접근 기록은 변조 불가 로그에 남습니다.
  • EFS는 올가을 이후 단계적으로 제공됩니다.

9. AI 답변의 환각 줄이고 검증하기

AI는 자료가 적은 주제에서 없는 내용을 사실처럼 말할 수 있습니다. 업무에 쓰기 전에 출처를 묻고 다시 검증하는 습관을 익히는 가이드입니다.

  1. 통계, 인용, 날짜, 이름, 숫자처럼 구체적 사실이 나오면 주의 표시를 해 둡니다.
  2. Claude에게 출처를 요청합니다.
  3. 답변에 대한 확신도를 물어봅니다.
  4. 새 대화를 열어 같은 내용을 다시 물어 답이 일치하는지 검증합니다.
  5. 중요한 수치는 원문 자료로 직접 확인한 뒤 씁니다.
예시
방금 답변에서 구체적인 통계와 날짜마다 출처를 알려 주세요. 확신이 낮은 부분은 따로 표시해 주세요.
  • Claude의 환각은 1년 전보다 크게 줄었지만 해결된 문제는 아닙니다.

10. AI 답을 이해하며 쓰고 휘둘리지 않기

AI 답을 복사해 전달만 하면 누구나 할 수 있는 일이 됩니다. AI에게 일을 많이 맡기되 내가 이해하고 판단하는 방식으로 쓰는 법을 정리합니다. Anthropic 연구도 AI의 기울기에 사람이 쉽게 따라간다고 보고합니다.

  1. 리서치와 검증처럼 시간이 드는 일은 AI에게 많이 돌리게 합니다.
  2. 제안서 같은 핵심 문서는 빈 문서에서 AI와 한 줄씩 쓰며 질문합니다.
  3. 계획을 세울 때 AI에게 내 우선순위를 먼저 묻게 합니다.
  4. 결정이 어려우면 프로토타입을 만들어 비교한 뒤 정합니다.
  5. AI에게 '어떤 조건이면 조언을 바꾸겠는지'를 물어봅니다.
  6. 최종 결정에 쓴 논거의 출처가 AI인지 내 판단인지 스스로 점검합니다.
예시
이 결정에 대해 조언하기 전에 내 우선순위부터 질문해 주세요. 그리고 어떤 조건이면 당신의 조언이 바뀌는지도 알려 주세요.
  • Anthropic 연구에서 분석가는 에이전트가 기운 쪽을 86% 따랐고, 논거를 쓴 사람 77% 중 출처로 밝힌 사람은 15%였습니다.
  • 이 연구는 한 분야·한 과제·한 모델만 다룬 한계가 있습니다.
  • 일이 새로 들어오면 '안 하면 어떤 문제가 생길까'를 먼저 물으라는 제안도 있습니다.
