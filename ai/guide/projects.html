프로젝트·메모리·지식

이 분야에서는 AI가 내 업무 맥락을 기억하게 만드는 방법을 다룹니다. 먼저 AI가 무엇을 기억하고 내 정보가 어디로 가는지 이해한 뒤, 프로젝트로 작업별 맥락을 쌓고, 지침과 파일을 넣고, 메모리를 관리하는 순서로 보면 좋습니다. 마지막에 새 채팅에서 이전 내용을 이어 가는 요령까지 익히면 같은 설명을 반복하지 않고 일할 수 있습니다.

입문

1. AI가 기억하는 범위 이해하기

AI에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있습니다. 모델 자체는 대화 안에서만 맥락을 갖고 새 대화는 빈 상태로 시작합니다. 프로젝트와 메모리를 쓰기 전에 이 구조를 알아 두면 무엇을 넣어도 되는지 판단할 수 있습니다.

  1. 새 대화를 열면 모델은 이전 내용을 모르는 빈 상태로 시작한다는 점을 먼저 확인합니다.
  2. 메모리는 모델이 아니라 계정에 저장된 정보를 모델이 참고하는 방식임을 이해합니다.
  3. 사용하는 AI 제품의 메모리 기본값이 켜짐인지 꺼짐인지 설정 화면에서 확인합니다.
  4. 저장된 메모리가 있으면 내용을 열어 보고 필요 없는 항목은 편집하거나 삭제합니다.
  5. 모델 학습에 내 대화를 쓰는지 제공사의 설정과 안내에서 확인하고, 옵트아웃이 있으면 원하는 대로 정합니다.
  6. 다루는 정보의 민감도에 맞는 제품과 플랜을 고릅니다.
  • 학습에 쓰이기 전에 개인정보는 대체로 제거되며, 내 대화가 그대로 저장되어 다른 사용자에게 보이지는 않습니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 학습 사용 정책은 제공사마다 다르므로 쓰는 제품마다 따로 확인하세요.

2. 프로젝트로 작업별 공간 만들기

프로젝트는 강의, 브랜드 협업, 책 쓰기처럼 작업별로 대화와 맥락을 모아 두는 폴더 같은 기능입니다. 용도별로 나누면 같은 설명을 매번 반복하지 않아도 됩니다.

  1. 왼쪽 사이드바에서 프로젝트를 찾아 + 또는 새 프로젝트를 누릅니다.
  2. 프로젝트 이름을 작업 단위로 정합니다 (예: 유튜브 대본 쓰기).
  3. 프로젝트 안에서 새 채팅을 열어 대화를 시작합니다.
  4. 작업이 다르면 별도 프로젝트를 만들어 나눕니다.
  • 유튜브용·강의용·리서치용처럼 용도별로 나누면 같은 프롬프트를 반복하지 않아도 됩니다.
  • ChatGPT의 프로젝트는 영상 기준(2025년 6월)으로 유료 버전에서 쓸 수 있다고 설명했으니 현재 플랜 조건은 직접 확인하세요.

3. 프로젝트 지침으로 응답 방식 고정하기

프로젝트 지침에 역할, 대상, 톤, 형식을 적어 두면 새 채팅에서 주제만 입력해도 같은 형식으로 답이 나옵니다. 보고서나 이메일처럼 반복되는 업무에 알맞습니다.

  1. 프로젝트를 만들고 지침 입력 화면을 엽니다. Claude는 커스텀 지침, ChatGPT는 지침 추가입니다.
  2. AI의 역할과 대상 독자, 톤 등 원하는 응답 방식을 적습니다.
  3. 구간별 분량과 원하는 결과 예시를 함께 적습니다.
  4. Claude에서는 지침 저장을 눌러 저장합니다.
  5. 프로젝트 안에서 새 채팅을 열고 주제만 입력해 결과를 확인합니다.
  6. 결과가 기대와 다르면 지침을 고쳐 다시 시험합니다.
예시
당신은 직장인 업무 이메일 작성 도우미입니다. 내가 상황만 알려 주면 제목 1줄, 본문 5문장 이내, 마무리 인사 순서로 정중한 어조의 이메일을 써 주세요. 예시: [여기에 평소 쓰던 좋은 이메일 하나 붙여넣기]
  • 지침은 인트로·본문·결론처럼 구간별로 나눠 쓰면 더 정확합니다.
  • 예시를 함께 주면 결과가 좋아집니다.
  • 처음 세팅에는 시간을 들여 AI와 맞춰 가는 것이 좋습니다. 영상에서는 주말 하루 이틀 정도를 권합니다.

4. 프로젝트에 참고 파일 올리기

관련 문서를 프로젝트에 파일로 올려 두면 그 프로젝트의 대화가 자료를 바탕으로 이어집니다. 회사 양식이나 기준 문서가 있는 업무에 씁니다.

  1. 파일을 올릴 프로젝트를 엽니다.
  2. Claude는 관련 문서를 파일로 업로드하고, ChatGPT는 파일 추가를 누릅니다.
  3. 프로젝트 안에서 새 채팅을 열어 올린 자료를 바탕으로 질문합니다.
  4. 답변이 자료와 맞는지 직접 읽고 검증합니다.
  • 영상 제작자는 ChatGPT에서 파일 추가의 효과가 크지 않았다고 합니다. 지침이 더 중요할 수 있으니 직접 비교해 보세요.
  • 파일과 캡처 같은 자료는 많이 줄수록 좋지만 결과 검증은 내 몫입니다.

5. 메모리 확인하고 관리하기

메모리는 대화 중 AI가 계정에 저장해 두고 다음 대화에서 참고하는 정보입니다. 내용을 열어 보고 지우거나 추가해 내가 통제할 수 있습니다.

  1. 사용하는 AI 제품의 설정에서 메모리 항목을 찾습니다.
  2. 메모리 기능이 켜져 있는지 확인합니다.
  3. ChatGPT는 관리에서 저장된 메모리 목록을 엽니다.
  4. 틀리거나 오래된 항목, 넣고 싶지 않은 항목은 삭제합니다.
  5. 꼭 기억시킬 내용은 직접 추가합니다.
  • Claude의 메모리 기능은 2026년 3월 무료 사용자까지 확대되었습니다.
  • 제품에 따라 메모리 기본값이 켜짐일 수 있으니 처음 쓸 때 확인하세요.
  • 민감한 업무 내용은 메모리에 남기지 않도록 주의하세요.

6. 새 채팅에서 이전 대화 이어 가기

채팅창이 바뀌면 기억 일부가 사라질 수 있습니다. 같은 프로젝트 안에서 새 채팅을 열고 이전 내용을 가져오라고 요청하면 맥락을 이어 갈 수 있습니다.

  1. 이어 갈 작업의 프로젝트 안에서 새 채팅을 엽니다.
  2. 기존 대화에서 필요한 내용을 찾아 달라고 요청합니다.
  3. 가져온 내용이 맞는지 확인합니다.
  4. 꼭 기억할 내용은 AI에게 기록해 두라고 요청합니다.
예시
이 프로젝트의 이전 대화에서 지난주에 정한 보고서 구성과 톤 기준을 찾아 요약해 주세요. 그 기준대로 이번 보고서 초안을 이어서 써 주세요.
  • 채팅창이 바뀌면 기억 일부가 사라집니다.
  • 중요한 결정은 지침이나 메모리에 따로 남겨 두면 안전합니다.

7. 맥락을 충분히 주고 음성으로 입력하기

AI를 잘 쓰는 핵심은 완벽한 프롬프트보다 상황과 기준을 충분히 알려 주는 것입니다. 타이핑 대신 음성 입력으로 길게 말하면 시간이 줄고 생각도 정리됩니다.

  1. 작업의 배경, 목적, 원하는 기준을 떠올립니다.
  2. 음성 받아쓰기로 상황을 길게 말해 입력합니다.
  3. 관련 파일이나 캡처를 함께 붙입니다.
  4. AI의 답을 직접 읽고 맞는지 판단합니다.
  • 영상에서는 음성 받아쓰기가 ChatGPT에서 가장 정확하다고 합니다.
  • 중요한 두 가지는 맥락을 많이 주는 것과 결과를 판단하는 능력입니다.
