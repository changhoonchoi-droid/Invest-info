프로젝트·메모리·지식

이 분야에서는 AI가 내 정보를 어디에 저장하고 무엇을 기억하는지 알고, 메모리와 데이터 사용 설정을 내 업무에 맞게 관리하는 법을 다룹니다. 먼저 AI가 맥락을 기억하는 방식을 이해하고, 메모리 설정과 학습 사용 여부를 점검한 뒤, 정보의 민감도에 맞는 제품을 고르는 순서로 보면 좋습니다.

입문

1. AI가 내 정보를 기억하는 방식 알기

AI에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있습니다. 이 구조를 알면 어떤 정보를 어디까지 입력해도 되는지 스스로 판단할 수 있습니다. AI를 업무에 쓰기 전에 꼭 알아 두면 좋습니다.

  1. AI에 입력한 정보가 갈 수 있는 곳이 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳이라는 점을 기억합니다.
  2. 모델 자체는 지금 열린 대화 안에서만 맥락을 기억한다는 점을 확인합니다.
  3. 새 대화를 열면 모델이 빈 상태에서 시작하므로, 필요한 배경 정보는 다시 알려 주거나 메모리 기능을 활용합니다.
  4. 메모리는 모델이 아니라 내 계정에 저장된 정보를 모델이 참고하는 방식이라는 점을 구분해 둡니다.
  5. 입력하려는 정보가 네 곳 중 어디까지 갈 수 있는지 생각한 뒤 입력 여부를 정합니다.
  • 새 대화에서 AI가 이전 내용을 모른다면 오류가 아니라 원래 그렇게 동작하는 것입니다.
  • 대화 내용이 모델에 그대로 저장되어 다른 사용자에게 보이지는 않습니다.

2. 메모리 설정 점검하고 관리하기

메모리는 내 계정에 저장된 정보를 AI가 다음 대화에서도 참고하게 하는 기능입니다. 제품에 따라 처음부터 켜져 있을 수 있으므로, 무엇이 저장되어 있는지 확인하고 필요하면 고치거나 지우거나 끕니다.

  1. 사용하는 AI 제품의 설정 화면에서 메모리 관련 항목을 찾습니다.
  2. 메모리 기능이 지금 켜져 있는지 꺼져 있는지 확인합니다. 제품에 따라 처음부터 켜져 있을 수 있습니다.
  3. 저장된 메모리 내용을 읽어 보고 잘못되었거나 오래된 정보가 있는지 확인합니다.
  4. 필요 없는 정보나 민감한 정보는 편집하거나 삭제합니다.
  5. 메모리를 쓰고 싶지 않다면 기능을 끕니다.
  6. 이 점검을 정기적으로 반복하는 습관을 들입니다.
  • 메모리는 대부분 편집, 삭제, 끄기가 가능하지만 메뉴 위치는 제품마다 다르니 각 제품의 설정 화면에서 확인하세요.
  • 메모리는 모델이 아니라 계정에 저장되므로, 계정 설정에서 관리한다고 생각하면 됩니다.

3. 모델 학습 사용 여부 확인하기

내가 입력한 대화가 향후 AI 모델 학습에 쓰일지는 제공사마다 다릅니다. 업무 정보를 다루기 전에 학습 사용 정책과 옵트아웃 가능 여부를 확인해 두면 안심하고 쓸 수 있습니다.

  1. 사용하는 AI 제공사가 대화를 모델 학습에 쓰는지 정책을 확인합니다.
  2. 학습 사용을 거부하는 옵트아웃 기능이 있는지 설정 화면에서 찾습니다.
  3. 업무 정보를 입력할 계획이라면 옵트아웃 설정을 켜 둡니다.
  4. 설정을 바꾼 뒤 제대로 적용되었는지 다시 확인합니다.
  • 옵트아웃을 지원하는 제공사가 많지만 기본값은 제품마다 다르니 직접 확인하세요.
  • 학습에 쓰이기 전에는 개인정보가 대체로 제거됩니다.

4. 정보 민감도에 맞게 AI 제품 고르기

다루는 정보가 얼마나 민감한지에 따라 개인용과 조직용 등 알맞은 AI 제품을 골라 써야 합니다. 회사 업무 정보를 자주 다룬다면 조직 단위로 도입한 제품을 쓰는 것이 통제하기 쉽습니다.

  1. 업무에서 AI에 입력할 정보를 민감도에 따라 나눠 봅니다.
  2. 민감도가 높은 정보는 학습 사용과 메모리 설정을 더 엄격하게 관리할 수 있는 제품에서만 다루기로 정합니다.
  3. 회사가 Claude를 조직 단위로 도입했는지 확인합니다. 조직이 도입한 경우 모델 학습은 기본적으로 꺼져 있습니다.
  4. 개인 계정을 업무에 쓴다면 메모리와 학습 사용 설정을 먼저 점검합니다.
  5. 정한 기준을 팀원과 공유해 같은 방식으로 쓰도록 합니다.
  • 설정 점검과 민감도에 맞는 제품 선택을 습관으로 만들면 내 정보에 대한 통제력을 지킬 수 있습니다.
  • 조직용이라도 회사의 보안 규정을 함께 확인하세요.
