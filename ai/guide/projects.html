프로젝트·메모리·지식

「프로젝트·메모리·지식」 분야에서는 작업별로 AI의 기억 공간을 나누고, 자료와 지침을 올려 두어 같은 설명을 반복하지 않게 만드는 방법을 다룹니다. 먼저 AI가 내 정보를 어디에 두는지 이해한 뒤, 프로젝트를 만들어 지침과 파일을 넣고, 새 대화에서 맥락을 이어 가는 순서로 보시면 좋습니다.

Projects, 메모리, 파일·지식 업로드, 스타일, 대화 관리 · 영상 3개 기반 · 2026-11-09 갱신

최근 바뀐 점

  • 2026년 8월 Claude 공식 영상에서 AI에 입력한 정보가 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있다고 정리했습니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있다고 안내했습니다.
  • 2026년 7월 영상에서 프로젝트 안의 새 채팅에서 기존 대화 내용을 가져오라고 요청하는 활용법이 소개되었습니다.
AI가 내 정보를 어떻게 다루는지 알기프로젝트 만들고 지침·파일 넣기새 채팅에서 이전 대화 이어 가기맥락을 많이 주어 답변 품질 높이기메모리 기능 이해하고 활용하기
입문

1. AI가 내 정보를 어떻게 다루는지 알기

AI에 입력한 정보가 어디에 저장되고 어디에 쓰일 수 있는지 이해하는 단계입니다. 메모리나 프로젝트를 쓰기 전에 먼저 알아 두면 민감한 업무 내용을 안전하게 다룰 수 있습니다.

  1. AI에 입력한 정보가 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있다는 점을 확인합니다.
  2. 모델 자체는 대화 안에서만 맥락을 갖고, 새 대화는 빈 상태로 시작한다는 점을 기억합니다.
  3. 메모리는 모델이 아니라 계정에 저장된 정보를 참고하는 방식이라는 점을 구분합니다.
  4. 사용하는 제품의 설정에서 메모리가 켜져 있는지 확인합니다. 제품에 따라 기본값이 켜짐일 수 있습니다.
  5. 저장된 메모리가 있다면 편집·삭제하거나 끌 수 있는지 확인하고 필요하면 정리합니다.
  6. 모델 학습에 대화가 쓰이는지 제공사 설정을 확인하고, 옵트아웃이 지원되면 필요에 따라 선택합니다.
  7. 정보의 민감도에 맞는 제품과 요금제를 골라 사용합니다.
  • 학습에 쓰이기 전에 개인정보는 대체로 제거되며, 대화가 모델에 그대로 저장되어 다른 사용자에게 보이지는 않습니다.
  • 학습 사용 정책은 제공사마다 다르므로 쓰는 서비스별로 따로 확인하세요.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.

2. 프로젝트 만들고 지침·파일 넣기

프로젝트는 작업별로 맥락을 모아 두는 공간입니다. 지침과 관련 문서를 한 번 넣어 두면 그 안의 대화마다 같은 프롬프트를 반복하지 않아도 됩니다.

  1. 프로젝트를 새로 만듭니다. 화면 왼쪽 프로젝트 옆 +를 누르는 방법이 영상에서 소개되었습니다.
  2. 강의, 브랜드 협업, 책 쓰기, 유튜브용, 리서치용처럼 용도별로 프로젝트를 나눕니다.
  3. 커스텀 지침에 대상 시청자, 톤 등 원하는 응답 방식을 적습니다.
  4. 지침 저장을 누릅니다.
  5. 관련 문서를 파일로 업로드합니다.
  6. 프로젝트 안에서 대화를 시작하고 이어 갑니다.
예시
이 프로젝트는 신입 사원 교육 자료를 만드는 작업이야. 대상은 입사 1년 차 직장인이고, 톤은 친절하고 쉬운 존댓말로 해 줘. 업로드한 문서를 근거로 답하고, 근거가 없으면 모른다고 말해 줘.
  • 용도별로 프로젝트를 나누면 같은 프롬프트를 반복하지 않아도 됩니다.
  • 프로젝트는 맥락을 관리하고, 스킬은 작업 방식을, 커넥터는 외부 도구를 맡는다고 구분하면 이해하기 쉽습니다.

3. 새 채팅에서 이전 대화 이어 가기

프로젝트 안에서 새 채팅을 열 때 이전 대화의 내용을 가져와 작업을 이어 가는 방법입니다. 채팅창이 바뀌면 기억 일부가 사라지므로 알아 두면 유용합니다.

  1. 작업하던 프로젝트를 엽니다.
  2. 프로젝트 안에서 새 채팅을 엽니다.
  3. 새 채팅에서 기존 대화에서 가져올 내용을 찾아 달라고 요청합니다.
  4. 가져온 내용이 맞는지 직접 읽고 확인합니다.
  5. 꼭 기억할 내용은 AI에게 기록해 두라고 요청합니다.
예시
이 프로젝트의 이전 대화에서 지난주에 정한 목차와 문체 규칙을 찾아서 정리해 줘. 그다음 이 내용을 앞으로 계속 기억하도록 기록해 둬.
  • 채팅창이 바뀌면 기억 일부가 사라집니다.
  • AI의 답은 그대로 믿지 말고 직접 읽고 검증하세요.
  • 세팅에는 주말 하루 이틀 정도 시간을 들여 AI와 맞춰 가는 것이 좋습니다.

4. 맥락을 많이 주어 답변 품질 높이기

완벽한 프롬프트보다 상황과 기준을 충분히 알려 주는 것이 중요하다는 활용법입니다. 음성 입력과 자료 첨부를 활용하면 시간이 줄고 생각도 정리됩니다.

  1. 타이핑 대신 음성 받아쓰기로 상황, 목적, 기준을 길게 말합니다.
  2. 관련 파일이나 화면 캡처 같은 자료를 많이 붙입니다.
  3. AI가 낸 결과를 직접 읽고 맞는지 판단합니다.
  4. 부족한 부분은 기준을 더 알려 주어 다시 요청합니다.
예시
지금 상황을 설명할게. 나는 중소기업 영업팀 대리이고, 다음 주 고객사 제안 발표를 준비 중이야. 첨부한 자료를 보고 발표 흐름을 제안해 줘. 기준은 10분 안에 끝나고 비전문가도 이해할 수 있어야 해.
  • 중요한 두 가지는 맥락을 많이 주는 것과 결과를 판단하는 능력입니다.
  • 영상에서는 음성 받아쓰기가 ChatGPT에서 가장 정확하다고 소개했습니다.

5. 메모리 기능 이해하고 활용하기

메모리는 계정에 저장된 정보를 모델이 대화에서 참고하게 하는 기능입니다. 내 업무 방식과 선호를 반복해서 설명하지 않아도 되도록 돕습니다.

  1. 메모리가 모델 자체가 아니라 계정에 저장된 정보라는 점을 이해합니다.
  2. 사용하는 제품에서 메모리 기능이 켜져 있는지 확인합니다.
  3. 기억시킬 내용이 있으면 AI에게 기록해 두라고 요청합니다.
  4. 저장된 내용을 확인하고 틀리거나 불필요한 것은 편집·삭제합니다.
  5. 원하지 않으면 메모리를 끕니다.
예시
앞으로 보고서를 쓸 때는 결론을 먼저 쓰고, 문장은 짧게 써 줘. 이 선호를 기억해 줘.
  • Claude의 메모리 기능은 2026년 3월 무료 사용자까지 확대되었습니다.
  • 제품에 따라 기본값이 켜짐일 수 있으니 직접 확인하세요.
  • 민감한 정보는 메모리에 남기지 않는 것이 안전합니다.
