프로젝트·메모리·지식

이 분야에서는 Claude가 대화 맥락을 기억하는 방식을 이해하고, 프로젝트에 지침과 문서를 넣어 같은 설명을 반복하지 않으며, 메모리와 개인정보 설정을 직접 관리하는 법을 다룹니다. 먼저 '새 대화는 빈 상태로 시작한다'는 원리를 익힌 뒤 프로젝트 만들기, 메모리 관리, 개인정보 점검 순서로 보면 좋습니다.

1. AI가 맥락을 기억하는 원리 알기

Claude 같은 AI 모델은 지금 진행 중인 대화 안에서만 앞의 내용을 기억하고, 새 대화를 열면 빈 상태로 시작합니다. 이 원리를 알면 어떤 정보를 대화에 다시 줘야 하는지, 언제 프로젝트나 메모리를 써야 하는지 판단할 수 있습니다.

  1. 이어지는 작업은 같은 대화 안에서 계속 진행합니다.
  2. 새 대화를 열 때는 앞 대화의 내용을 AI가 모른다고 보고, 필요한 배경을 다시 알려 줍니다.
  3. 매번 반복해서 알려 주는 정보(대상 독자, 말투, 참고 문서)가 있는지 적어 봅니다.
  4. 반복되는 정보는 프로젝트의 커스텀 지침이나 업로드 파일로 옮겨 둡니다.
  5. 나에 대한 정보를 대화 사이에 이어 가고 싶다면 메모리 기능을 켜 둡니다.
  • 메모리는 모델 자체가 아니라 계정에 저장된 정보를 모델이 참고하는 방식입니다.
  • 대화가 모델 안에 그대로 저장되어 다른 사용자에게 보이는 것은 아닙니다.

2. 프로젝트 만들고 지침 저장하기

프로젝트는 커스텀 지침과 관련 문서를 한곳에 묶어 두고, 그 안의 대화마다 같은 맥락을 적용하는 공간입니다. 유튜브 대본, 강의 자료, 리서치처럼 반복되는 업무에 쓰면 매번 같은 설명을 프롬프트에 붙이지 않아도 됩니다.

  1. Claude에서 프로젝트를 새로 만듭니다.
  2. 커스텀 지침 칸에 대상 독자, 말투, 분량 등 원하는 응답 방식을 적습니다.
  3. 지침 저장을 눌러 지침을 저장합니다.
  4. 업무에 참고할 관련 문서를 파일로 업로드합니다.
  5. 프로젝트 안에서 새 대화를 열어 작업을 요청합니다.
  6. 결과가 기대와 다르면 지침을 고쳐 다시 저장합니다.
예시
대상: 40대 직장인 유튜브 시청자. 톤: 쉽고 친근한 존댓말, 전문 용어는 한 줄 풀이를 붙일 것. 형식: 소제목 3~5개, 각 소제목 아래 핵심 요약 한 줄 먼저. 업로드한 자료에 없는 수치는 지어내지 말 것.
  • 유튜브용·강의용·리서치용처럼 용도별로 프로젝트를 나누면 같은 프롬프트를 반복하지 않아도 됩니다.
  • 프로젝트는 '맥락'을 관리하는 곳입니다. 작업 방식은 스킬, 외부 도구 연결은 커넥터가 맡는다고 구분해 두면 정리가 쉽습니다.

3. 메모리 확인하고 관리하기

메모리는 내 계정에 저장된 정보(선호, 하는 일 등)를 Claude가 새 대화에서도 참고하게 해 주는 기능입니다. 편하지만 무엇이 저장되는지 직접 확인하고 필요하면 고치거나 지우는 습관이 중요합니다.

  1. 지금 쓰는 플랜에서 메모리 기능이 켜져 있는지 설정에서 확인합니다.
  2. 저장된 메모리 내용을 열어 어떤 정보가 기록되어 있는지 읽어 봅니다.
  3. 틀리거나 오래된 내용은 편집합니다.
  4. 남기고 싶지 않은 정보는 삭제합니다.
  5. 민감한 업무를 할 때는 메모리를 끄는 것도 고려합니다.
  • 메모리 기능은 2026년 3월부터 무료 사용자까지 확대되었습니다.
  • 제품에 따라 메모리 기본값이 '켜짐'일 수 있으니 처음 한 번은 꼭 확인합니다.
  • 대부분의 메모리는 편집·삭제·끄기가 가능합니다.

4. 내 정보 흐름 점검하고 설정하기

AI에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있습니다. 회사 자료나 개인정보를 다루기 전에 각 경로의 설정을 점검하면 내 정보에 대한 통제력을 지킬 수 있습니다.

  1. 입력하려는 정보가 대화·메모리·제공사 시스템·모델 학습 중 어디로 갈 수 있는지 떠올려 봅니다.
  2. 메모리에 저장된 내용을 확인하고 필요 없는 것은 지웁니다.
  3. 쓰고 있는 서비스가 대화를 모델 학습에 쓰는지 개인정보 설정에서 확인합니다.
  4. 원하지 않으면 학습 사용을 끄는(옵트아웃) 설정을 적용합니다.
  5. 정보의 민감도에 맞춰 개인 계정과 회사 도입 계정 중 어떤 제품을 쓸지 정합니다.
  6. 설정은 한 번으로 끝내지 말고 주기적으로 다시 점검합니다.
  • 학습 사용 정책은 제공사마다 다르며, 옵트아웃을 지원하는 곳이 많습니다.
  • 조직이 Claude를 도입한 경우 모델 학습은 기본적으로 꺼져 있습니다.
  • 학습에 쓰이기 전에 개인정보는 대체로 제거됩니다.
