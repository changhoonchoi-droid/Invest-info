업무 자동화·에이전트

이 분야에서는 메일 브리핑·보고서 작성·폴더 정리처럼 매일 반복되는 업무를 AI에게 맡기고, 예약 작업으로 정해진 시각에 저절로 돌아가게 만들 수 있습니다. 먼저 Cowork로 폴더 업무를 맡겨 보고, 커넥터와 예약 작업, 스킬로 나만의 규칙을 굳힌 뒤, 마지막으로 팀 채널·노코드 자동화·루틴 같은 응용 단계로 넘어가면 편합니다. 어떤 도구를 쓰든 결과는 사람이 확인하고, 발송처럼 되돌리기 어려운 일은 초안 단계에서 멈추게 하는 것이 안전합니다.

최근 바뀐 점

  • Claude에서 문서·슬라이드·디자인 같은 아티팩트를 팀원과 함께 편집하고, 보기·댓글·수정 권한을 나눠 줄 수 있게 되었습니다.
  • Claude 예약 작업은 클로드 서버에서 돌아 컴퓨터를 꺼도 실행된다고 소개되었습니다(유료 플랜).
  • Claude Code로 영상 편집을 자동화할 때 템플릿·업무 매뉴얼(SOP)을 스킬로 저장하고, 루틴으로 드라이브 폴더를 1~2시간마다 확인시키는 방식이 소개되었습니다.
  • Claude Code로 인스타 카드뉴스를 만드는 흐름에서, 매일 아침 7시에 레퍼런스를 모아 기준을 넘긴 게시물만 자동 제작하는 방식이 공개되었습니다.

1. Cowork로 폴더 정리 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 정리하거나 문서를 만들어 주는 기능입니다. 다운로드 폴더 정리처럼 범위가 분명한 일부터 맡겨 보기에 좋습니다.

  1. Claude 데스크톱 앱을 열고 Cowork 탭(또는 협업)을 누릅니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더 하나를 선택합니다.
  3. 접근 권한 창이 뜨면 허용합니다(항상 허용 또는 허용).
  4. 필요하면 커넥터를 연결해 Google Drive·Notion·Slack 등에서 맥락을 가져오게 합니다.
  5. 할 일을 적고 변경 전에 계획을 먼저 보여 달라고 요청합니다.
  6. 제안된 계획을 읽고 고칠 부분(예: 남길 파일은 검토 폴더로)을 지시합니다.
  7. 승인하면 Claude가 실제로 실행합니다. 진행 상황을 지켜보고 결과 파일을 폴더에서 확인합니다.
예시
Organize my downloads folder. Scan the contents and propose a plan. 변경하기 전에 계획을 먼저 보여 줘.
  • 처음에는 범위가 분명한 작업부터 시작하고 결과를 항상 검토합니다.
  • 작업 중에는 데스크톱 앱을 열어 두어야 합니다.
  • 웹 버전은 로컬 파일 접근과 컴퓨터 조작이 안 되므로 폴더 작업은 데스크톱 앱에서 합니다.

2. Cowork로 자료를 모아 보고서 만들기

폴더에 흩어진 회의록·엑셀·메모를 Claude가 모두 읽고 한 페이지 보고서로 정리해 주는 방법입니다. 주간 현황 보고처럼 매번 비슷한 문서에 쓰면 시간이 크게 줄어듭니다.

  1. 새로 생성을 누르고 입력창 하단에서 협업을 선택합니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 고르고 항상 허용을 누릅니다.
  3. 매출 데이터, 슬랙 메모, 주간 회의록 등 자료를 그 폴더에 복사해 넣습니다.
  4. 폴더 안 자료를 모두 읽고 정리해 달라고 요청합니다.
  5. 계획과 실행 진행 상황을 지켜봅니다.
  6. 완성된 워드 보고서를 열어 숫자와 내용을 직접 확인합니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘.
  • 엑셀을 정리할 때는 원본은 그대로 두고 정리본을 새 파일로 저장하라고 프롬프트에 꼭 적습니다.
  • 날짜 형식·빈칸·중복 행 같은 정리 규칙을 구체적으로 적을수록 결과가 좋아집니다.

3. 코워크 글로벌 지침 정하기

나를 소개하고 작업 스타일을 한 번 적어 두면 모든 Cowork 세션에 적용되어 매번 같은 설명을 하지 않아도 됩니다. 자동화를 시작하기 전에 해 두면 이후 결과 품질이 안정됩니다.

  1. 좌측 상단에서 Claude 설정을 엽니다.
  2. 협업 탭으로 이동합니다.
  3. 지침 항목의 편집 버튼을 누릅니다.
  4. 내가 어떤 사람인지, 작업 스타일, 선호하는 도구 환경을 적습니다.
  5. 저장을 누릅니다.
  • Settings의 Cowork 탭에서 역할 설명이나 파일 형식(예: Word 문서) 같은 전역 지침을 설정할 수 있다고 소개되었습니다.
  • 예전 방식: 설정 메뉴 이름이 영상마다 협업 또는 Cowork로 다르게 나오니 내 화면의 이름을 따릅니다.

4. 커넥터로 메일 브리핑 예약하기

Gmail이나 Microsoft 365를 Claude에 연결하면 어제 이후 메일과 일정을 요약한 아침 브리핑을 받을 수 있습니다. 한 번 만들어 두면 매일 정해진 시각에 자동으로 돌아갑니다.

  1. 클로드 데스크톱에서 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail 또는 Microsoft 365를 선택해 클로드에 연결하고 계정을 고릅니다.
  3. + → 커넥터에서 연결 표시(파란 불)를 확인합니다.
  4. 어제 오후 6시 이후 메일과 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  5. 같은 내용을 아침 7시 50분마다 실행하는 예약 작업으로 등록해 달라고 요청합니다.
  6. 좌측 예약됨에서 스케줄을 확인합니다.
예시
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고 아침 브리핑을 만들어 줘. 답장이 필요한 메일을 우선순위 순으로 알려 줘.
  • 예약 작업은 유료 플랜에서만 쓸 수 있습니다.
  • 예전 방식: 예약 작업은 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 돌았는데, 최근 영상에서는 클로드 서버에서 돌아 컴퓨터를 꺼도 실행된다고 설명합니다(7월 업데이트).
  • 메일을 자동 발송하게 하지 말고 초안까지만 만들게 하면 안전합니다.

5. Cowork 예약 작업 만들기

반복할 일을 말로 설명하면 Claude가 프롬프트 초안을 만들고, 주기를 확인해 승인하면 정기 실행됩니다. 매주 리포트나 폴더 점검처럼 규칙적인 업무에 쓰기 좋습니다.

  1. 반복할 일을 자연어로 설명합니다(예: 매시간 공유 폴더에 추가·수정된 문서를 확인해 요약).
  2. 또는 입력창에 /schedule을 입력하고 작업 이름, 설명, 프롬프트, 빈도를 정합니다.
  3. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  4. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  5. 내용이 맞으면 제안을 수락합니다.
  6. 왼쪽 사이드바의 예약 페이지(예정된 탭)에 작업이 추가된 것을 확인합니다.
  7. 한 번 즉시 실행해 결과가 의도대로 나오는지 확인합니다.
예시
AI 트렌드를 리서치해서 매주 수요일에 유튜브 아이디어 5개를 제안해 줘.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있고, 실행마다 새 세션으로 최신 파일 기준으로 돌아갑니다.
  • 꺼져 있어서 놓친 작업은 복귀 후 바로 실행되고 지연됐다고 알려 줍니다.
  • 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행이 가능합니다.
  • 첫 실행 후 Claude가 프롬프트를 더 상세히 다시 써서 정확도가 올라간다고 합니다.

6. 스킬로 보고서 양식 고정하기

스킬은 반복 업무의 형식과 규칙을 저장해 두는 기능입니다. 보고서·메일·브리핑을 매번 같은 포맷과 말투로 받고 싶을 때 씁니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 형식을 분석해 스킬로 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 선택하고 주제를 적어 요청합니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
  6. 스타일·브랜드 컬러·섹션 구성처럼 바꾸고 싶은 규칙은 스킬에 추가로 적어 갱신합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • AI 티가 나는 문장은 별도 스킬로 다듬되, 중요한 보고서는 직접 읽고 고칩니다.
  • 피드백을 줄 때마다 내용을 스킬에 남기면 갈수록 품질이 좋아집니다.
  • 스킬은 팀과 공유하면 누구나 같은 결과를 낼 수 있습니다.

7. 플러그인으로 직무별 업무 시작하기

플러그인은 스킬·커넥터·슬래시 명령을 묶은 직무별 패키지입니다. 세일즈·제품 관리·마케팅처럼 내 직무에 맞는 명령을 바로 쓰고 싶을 때 설치합니다.

  1. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  2. 플러그인 추가에서 원하는 플러그인(세일즈, 제품 관리, 마케팅 등)을 설치합니다.
  3. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  4. 입력창에 슬래시 명령을 입력합니다.
  5. 필요한 정보(회사명, 목적 등)를 적고 시작합니다.
  • Anthropic이 제공하는 공식 플러그인 11종은 오픈 소스라 회사에 맞게 고쳐 쓸 수 있다고 소개됩니다.
  • 영상에서 명령어 이름은 자막이 불분명하므로 정확한 표기는 플러그인 관리 화면에서 확인합니다.

8. 미팅 준비와 후속 처리 자동화하기

캘린더·Slack·이메일·회의록을 연결해 미팅 전 브리핑 문서를 만들고, 미팅 후에는 녹취록으로 할 일과 후속 메시지까지 정리하는 흐름입니다. 몇 시간 걸리던 조사가 몇 분으로 줄어듭니다.

  1. 캘린더, Slack, 이메일을 Claude에 연결합니다.
  2. 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 미팅 준비용 스킬을 만들어 두고, 처음에는 테스트용 계정으로 실행해 다듬습니다.
  4. 미팅 전 /를 입력해 스킬을 고르고 회의 이름과 시간을 알려 줍니다.
  5. Claude가 만든 안건·브리핑 문서를 폴더에서 열어 검토합니다.
  6. 미팅 후 같은 세션에서 녹취록 처리 스킬을 골라 할 일, 내부 메시지, 고객 후속 메시지를 만들게 합니다.
  7. 각 결과를 확인하고 승인한 뒤에만 발송합니다.
예시
Prep me for today's call with Acme Corp at 1PM.
  • 이름을 걸고 보내는 메일이므로 브리핑의 근거를 원문에서 직접 확인합니다.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 스킬은 일반 텍스트 파일이라 언제든 열어 동작을 확인할 수 있습니다.

9. 주간 리포트를 스킬과 예약으로 돌리기

일요일 저녁 예약 작업이 지난 리뷰와 데이터를 모아 두고, 월요일 아침에 확인만 하면 되도록 주간 지표 리뷰를 자동화합니다. 숫자 수집·검증은 Claude에, 서사와 초점은 사람에게 맡기는 구조입니다.

  1. 리뷰 준비, 교정, 액션 아이템 관리용 스킬을 각각 만듭니다.
  2. 일요일 저녁에 실행되는 예약 작업을 설정합니다.
  3. 월요일 아침 Cowork를 열어 준비 결과와 제안된 집중 영역을 확인합니다.
  4. 이번 주 초점을 지시하고, 데이터 불일치를 알리면 처리 방식을 알려 줍니다.
  5. 먼저 지표 표와 헤드라인만 있는 초안을 확인합니다.
  6. 문제가 없으면 최종 문서와 메시지를 만들게 하고, 같은 데이터로 리더십용 슬라이드를 요청합니다.
  7. 이번 주 배운 점을 스킬에 반영하도록 요청합니다.
  • 교정 스킬은 초안의 모든 숫자가 검증된 데이터 출처로 추적되는지 확인하게 합니다.

10. Slack 채널에서 Claude Tag 쓰기

Claude Tag는 팀 Slack 채널에 Claude를 추가해 대화 맥락을 보며 일하게 하는 기능입니다. 여러 사람이 한 스레드에서 함께 지시할 수 있고, 채널별 지침을 기억합니다. Team·Enterprise 계정에서 쓸 수 있습니다.

  1. Claude를 쓸 채널 하나에 Claude를 추가합니다.
  2. 필요한 도구(캘린더, 드라이브 등)를 연결합니다.
  3. 채널에서 Claude를 태그해 작업을 요청합니다.
  4. 진행 상황을 채널에서 확인하고, 기다리지 말고 다른 일을 합니다.
  5. 완료 또는 결정 요청 알림이 오면 확인하고 답합니다.
  6. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
예시
@Claude 최근 3일 스레드와 Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • 처음에는 한 채널에서만 시작해 보세요.
  • 채널별 접근 권한이 나뉘어 있고, DM과 비공개 채널의 내용은 그 안에만 남습니다.
  • Claude가 사용자를 대신해 응답하거나 도구에 접근할 때는 매번 권한을 묻습니다.
  • 너무 자주 또는 드물게 끼어들면 개입 빈도를 조정해 달라고 말합니다.

11. Claude Code 루틴으로 자동 실행하기

루틴은 프롬프트, 저장소, 커넥터, 트리거를 정해 두면 Anthropic 관리형 인프라에서 Claude Code 세션이 자동으로 도는 기능입니다. 노트북을 닫아도 실행되며 일정이나 GitHub 이벤트로 시작할 수 있습니다.

  1. 루틴의 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나)을 먼저 정합니다.
  2. 터미널에서 Claude Code를 실행합니다.
  3. /schedule을 입력하고 원하는 작업을 적습니다.
  4. Claude가 묻는 질문(실행 시각, 알림 여부 등)에 답합니다.
  5. 필요한 저장소를 컨텍스트로 연결합니다.
  6. 만들어진 루틴을 웹의 Claude Code에서 확인하고 실행 결과 세션을 열어 봅니다.
예시
/schedule 매주 main에 병합된 변경을 문서 저장소와 비교해서, 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 처음에는 결과를 직접 확인하고, 신뢰가 쌓이면 더 많은 권한을 맡깁니다.
  • 트리거는 시간 기반과 이벤트 기반(GitHub 이벤트, 웹훅)이 있습니다.
  • Projects는 베타이며 Pro·Max 요금제에 순차 제공됩니다.

12. n8n으로 노코드 자동화 만들기

n8n은 작업 블록(노드)을 연결해 자동화 시나리오를 만드는 도구입니다. AI 워크플로우 빌더를 쓰면 한국어로 요청해 슬랙·노션·메일·구글 시트를 잇는 흐름을 만들 수 있습니다.

  1. n8n 클라우드에 가입하고 새 워크플로우를 만듭니다.
  2. 빌드 위드 AI(또는 우측 n8n AI)를 눌러 빌드를 선택합니다.
  3. 자동화할 내용을 트리거 시점과 처리 방식까지 구체적으로 적습니다.
  4. 만들어진 각 노드를 클릭해 설정을 확인합니다.
  5. 수정 요청을 입력창에 적어 흐름을 고칩니다.
  6. API 키와 OAuth 인증 정보를 직접 연결합니다.
  7. 테스트 데이터로 실행해 동작을 확인한 뒤 실제로 사용합니다.
예시
슬랙 채널에 '긴급'이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일을 보내 줘.
  • AI 빌더는 베타이며 n8n 클라우드에서만 쓸 수 있고, 프롬프트 한 번에 1크레딧을 씁니다.
  • API 키와 OAuth 인증은 보안상 AI가 설정해 주지 않으니 직접 해야 합니다.
  • 기본 흐름 → 테스트 → 기능 추가 → 예외 처리 순으로 단계적으로 만들고, 요구 사항은 한 번에 모아 요청하면 크레딧을 아낍니다.
  • 오류가 나면 /clear로 컨텍스트를 초기화한 뒤 다시 시도합니다.

13. 레퍼런스 기반 콘텐츠 제작 자동화하기

Claude Code로 매일 아침 레퍼런스를 모으고 기준을 넘긴 것만 골라 카드뉴스나 영상 제작으로 이어 가는 에이전트 설계입니다. 에이전트 설계에서 사람이 개입할 지점과 상한을 정하는 방법을 함께 익힐 수 있습니다.

  1. 유튜브·X·레딧·인스타그램 등 수집 대상 계정을 정합니다.
  2. 매일 아침 7시에 좋아요·조회수 등을 모으도록 예약합니다.
  3. 조회수·댓글 수가 정한 기준을 넘은 게시물만 골라냅니다.
  4. 기준을 넘은 게시물을 카드뉴스로 자동 제작합니다.
  5. 결과를 저장하고 노션에 기획·자료·원본 링크와 함께 올립니다.
  6. 되돌리기 어려운 지점과 크레딧처럼 크게 나가는 비용에는 상한과 내 확인 단계를 둡니다.
  7. 피드백을 줄 때마다 스킬이나 규칙으로 남깁니다.
  • 업로드는 자동화하지 않았는데, 인기 음악은 앱에서만 넣을 수 있기 때문이라고 합니다.
  • 남의 영상을 쓸 때는 단순 번역 대신 AI가 던지는 질문에 내 의견으로 답하는 인터뷰 단계를 넣어 차별점을 만듭니다.
  • 만든 AI와 검사하는 AI를 분리하면 자기 결과에 관대해지는 문제를 줄일 수 있습니다.
  • 크레딧 상한 숫자(쇼츠 500, 롱폼 1,500)는 영상 제작자의 값이므로 내 요금제에 맞게 정합니다.
