1. Cowork로 폴더 업무 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·워드 결과물을 만들어 주는 기능입니다. 흩어진 파일을 합치거나 보고서로 정리하는 일에 처음 써 보기 좋습니다.

  1. Claude 데스크톱 앱을 열고 코워크 버튼을 누릅니다.
  2. 하단의 프로젝트 또는 폴더 버튼에서 폴더 추가를 눌러 작업할 폴더를 엽니다.
  3. 폴더 접근 권한 창에서 항상 허용을 선택합니다.
  4. 할 일을 구체적으로 적어 요청하고, 파일을 바꾸기 전에 계획을 먼저 보여 달라고 덧붙입니다.
  5. 파일명에 날짜를 넣는 등 정리 규칙과 원본 보존 여부를 함께 적습니다.
  6. 계획·실행·검증이 진행되는 것을 지켜보고, 지정한 폴더에 생긴 결과 파일을 열어 확인합니다.
예시
이 폴더의 엑셀 세 개를 하나로 합쳐 줘. 파일을 바꾸기 전에 계획을 먼저 보여 주고, 원본은 그대로 두고 정리본은 새 파일로 저장해 줘. 파일명에는 날짜를 넣어 줘.
  • 코워크는 프로 플랜(월 20달러) 이상에서 쓸 수 있습니다.
  • 웹 버전은 내 컴퓨터의 파일에 접근하거나 컴퓨터를 직접 조작할 수 없으므로, 폴더 작업은 데스크톱 앱에서 하세요.
  • 원본 보존은 반드시 프롬프트에 적어 둡니다.
  • 예전 방식: 2월 영상에서는 폴더에서 작업 → 다른 폴더 선택으로 폴더를 열었고, 8월 초 영상에서는 협업 버튼으로 표기됐습니다. 화면에 보이는 이름을 따라가세요.

2. 글로벌 지침과 플러그인 설정하기

글로벌 지침은 나의 역할과 작업 스타일을 한 번 적어 두면 모든 코워크 세션에 적용되는 설정입니다. 플러그인은 스킬·커넥터·슬래시 명령을 직무별로 묶은 패키지로, 세일즈·제품 관리·마케팅 등이 있습니다.

  1. Settings를 열고 Cowork 탭으로 이동합니다.
  2. 전역 지침에 내가 어떤 일을 하는 사람인지, 작업 스타일, 선호하는 도구 환경, 원하는 파일 형식(예: Word 문서)을 적습니다.
  3. 지침을 저장합니다.
  4. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  5. 플러그인 추가에서 내 직무에 맞는 플러그인을 설치합니다.
  6. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  7. 입력창에 슬래시 명령을 입력하고 회사명·목적 같은 필요한 정보를 적어 시작합니다.
  • 전역 지침을 적어 두면 매번 같은 설명을 반복하지 않아도 됩니다.
  • 슬래시 명령 이름은 영상 자막이 불분명했으므로 플러그인 관리 화면에서 정확한 표기를 확인하세요.
  • 예전 방식: 3월 영상에서는 설정의 협업 탭에서 지침을 편집했습니다.

3. 스킬로 반복 보고서 형식 고정하기

스킬은 반복 업무의 양식과 규칙을 저장해 두는 기능입니다. 보고서 스타일, 섹션 구성, 강조 방식을 스킬로 굳히면 매번 같은 포맷의 결과가 나옵니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 보고서 형식을 분석해 회사 보고서 만드는 스킬을 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 스킬을 고르고 주제를 적어 요청합니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 보고서 스타일을 설명할 때 브랜드 컬러, 강조 방식, 폰트, 한 줄 정의, 섹션 구성을 함께 알려 주면 좋습니다.
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • AI 티가 나는 문장은 별도 스킬로 다듬되 본인 스타일에 맞게 고쳐 쓰고, 중요한 보고서는 직접 읽고 고치세요.

4. ChatGPT Work로 회의록 정리하기

ChatGPT Work는 답변만 주는 것이 아니라 파일과 앱을 다뤄 결과물까지 만들어 주는 업무 실행 모드입니다. 회의록에서 실행 항목만 뽑아 시트로 만드는 일에 바로 쓸 수 있습니다.

  1. ChatGPT 데스크탑 앱(macOS·Windows)을 설치합니다.
  2. 메인 화면에서 Work 모드를 선택합니다.
  3. 회의록 파일을 첨부합니다.
  4. 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 달라고 요청합니다.
  5. 복잡한 작업이면 입력창의 + 버튼을 눌러 계획 모드를 켜고 같은 요청을 합니다.
  6. Work가 던지는 질문에 답한 뒤, 작성된 계획대로 나온 결과물을 확인합니다.
예시
첨부한 회의록에서 실행 항목만 뽑아 담당자·할 일·마감 세 개의 열로 된 스프레드시트로 만들어 줘.
  • 파일·앱을 다루는 기능은 데스크탑 전용입니다.
  • 단순 작업은 기본 모드, 복잡한 작업은 계획 모드를 씁니다. 모호한 부분을 먼저 물어봐 줘서 결과가 구체적입니다.
  • 추론 수준은 미디엄에서 시작하고, 결과가 부족하면 올리세요. 높일수록 비용이 늘어납니다.

5. Cowork 예약 작업 만들기

예약 작업은 반복되는 일을 정해진 주기로 자동 실행하는 기능입니다. 매시간 새 문서를 확인해 요약하는 일처럼 정기적으로 하는 업무를 맡기기에 좋습니다.

  1. 반복할 일을 자연어로 설명합니다.
  2. Claude가 만들어 준 예약 작업 프롬프트 초안을 검토합니다.
  3. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  4. 내용이 맞으면 제안을 수락합니다.
  5. 왼쪽 사이드바의 예약 페이지에 작업이 추가된 것을 확인합니다.
  6. 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행을 할 수 있으니 처음 한 번은 직접 실행해 결과를 봅니다.
예시
매시간 공유 드라이브 폴더에 추가되거나 수정된 문서를 확인해서, 변경한 사람을 기록하고 요약한 뒤 클라이언트별로 묶어 문서로 저장해 줘.
  • 실행마다 새 Cowork 세션으로 돌아 최신 파일과 도구 상태를 기준으로 하며, 설정해 둔 커넥터도 쓸 수 있습니다.
  • 7월 업데이트 이후에는 코워크가 웹·모바일로 확장되어, 예약 작업이 기기가 꺼져 있어도 클라우드에서 실행된다고 소개되었습니다. 단 로컬 파일을 다루는 작업은 데스크톱 앱이 필요합니다.
  • 예전 방식: 6월 영상에서는 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 예약 작업이 실행되었습니다.
  • 슬래시 명령 /schedule로도 만들 수 있습니다.

6. 제미나이 스파크로 메일 브리핑 예약하기

제미나이 스파크는 구글 클라우드에서 상시 일하는 개인 에이전트로, Gmail·캘린더·독스·시트·드라이브를 별도 연결 없이 다룹니다. 메일 우선순위 정리와 주간 자동 실행에 쓰기 좋습니다.

  1. 제미나이를 실행하고 좌측 상단 스파크 베타 탭을 누릅니다.
  2. 좌측 하단 프로필에서 설정을 열고, 연결된 앱에서 구글 워크스페이스가 켜져 있는지 확인합니다.
  3. 이번 주 캘린더와 Gmail에서 답장 안 한 메일을 확인해 우선순위 브리핑 문서를 만들어 달라고 요청합니다.
  4. 정기 실행을 하려면 프롬프트에 실행 시점(예: 매주 월요일 오전 8시)을 적습니다.
  5. 지난 7일간 뉴스레터·업무 보고 메일을 구글 시트에 정리하고, 핵심 요약 5개를 이메일 초안으로 쓰되 발송하지 말고 초안으로 남기도록 지시합니다.
  6. 좌측 일정 탭에서 등록된 일정을 확인합니다.
예시
매주 월요일 오전 8시에, 지난 7일간 Gmail의 뉴스레터와 업무 보고 메일을 구글 시트에 정리해 줘. 핵심 요약 5개는 이메일 초안으로 작성하되 발송하지 말고 초안으로 남겨 줘.
  • 구글 AI 프로 이상 구독이 필요합니다.
  • 발송하지 말고 초안으로 남기게 하면 안전합니다.
  • 내가 보낸 메일을 분석해 문체를 스킬로 저장하면 이후 초안이 내 말투로 나옵니다.
  • 데스크탑 앱은 현재 macOS만 지원합니다.

7. 커넥터로 회의 준비 문서 만들기

캘린더·Slack·이메일 같은 커넥터를 연결하면 Cowork가 흩어진 정보를 모아 회의 안건 문서를 만들어 줍니다. 기존 문서 형식을 템플릿으로 따르게 할 수도 있습니다.

  1. 캘린더, Slack, 이메일을 Claude에 연결합니다.
  2. 이전 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 회의 이름과 시간을 알려 줍니다.
  4. 캘린더 검색, 참석자 조사, Slack 스레드 확인, 이전 회의록 검토, 안건 작성을 요청하고 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  5. Claude가 세운 계획을 확인하고 작업이 진행되게 둡니다.
  6. 빠뜨린 출처가 있으면 작업 중에 추가로 요청합니다.
  7. 완성된 안건 문서를 작업 폴더에서 열어 검토하고, 빠진 내용은 추가 요청하거나 직접 고칩니다.
예시
Prep me for today's call with Acme Corp at 1PM. 캘린더, Slack, 이메일, 이전 회의록을 확인해서 안건 문서를 만들어 줘. 기존 문서 형식을 템플릿으로 따라 줘.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 자주 하는 준비는 스킬로 만들어 /로 불러 쓰면 됩니다. 처음에는 테스트용 계정으로 돌려 보고 다듬으세요.

8. 스킬과 예약으로 주간 리포트 자동화

준비·교정·액션 아이템 관리를 스킬로 나누고 예약 작업과 묶으면 주간 지표 리뷰를 매주 같은 방식으로 만들 수 있습니다. 숫자 수집과 검증은 Claude에게, 서사와 초점은 사람이 정하는 방식입니다.

  1. 리뷰 준비, 교정, 액션 아이템 관리용 스킬을 각각 만듭니다.

  4. 이번 주 초점을 지시합니다.
  5. Claude가 데이터 불일치를 알리면 처리 방식을 알려 줍니다.

9. Slack 채널에서 Claude Tag 쓰기

Claude Tag는 Slack 같은 팀 채널에 Claude를 추가해 대화를 따라가며 일하게 하는 기능입니다. 채팅 창을 오가며 맥락을 붙여 넣지 않고 채널에서 바로 작업을 시킬 수 있습니다.

  1. Claude를 사용할 채널 하나에 추가합니다.
  2. 필요한 도구를 Claude Tag에 연결합니다.
  3. 작업이 필요한 스레드에서 Claude를 태그해 요청합니다.
  4. Claude가 진행하는 상황을 채널에서 확인하고, 그동안 다른 일을 합니다.
  5. 완료 또는 결정 요청 알림이 오면 확인하고 답합니다.
  6. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
예시
@Claude 최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • Team·Enterprise 요금제에서 베타로 제공됩니다. 처음에는 한 채널에서만 시작하세요.
  • 채널별로 접근 범위가 나뉘고, DM과 비공개 채널의 내용은 그 안에만 남습니다. 모든 변경과 요청자가 기록됩니다.
  • 매번 태그하기 번거로우면 항상 응답하도록, 너무 자주 끼어들면 개입 빈도를 줄이도록 말로 조정합니다.
  • 누구든 채널에서 Claude를 태그해 기억 내용을 읽고 수정할 수 있습니다.

10. n8n으로 FAQ 챗봇 자동화 만들기

n8n은 작업 블록(노드)을 연결해 자동화 시나리오(워크플로우)를 만드는 도구입니다. 구글 시트의 질문·답변을 읽어 응답하는 FAQ 챗봇을 만들며 기본 구조를 익힐 수 있습니다.

  1. n8n 클라우드에 가입하고 대시보드에서 Create Workflow로 새 워크플로우를 만듭니다.
  2. Add first step에서 트리거로 On chat message를 선택합니다.
  3. + 버튼을 눌러 AI 노드 중 AI Agent를 추가합니다.
  4. Chat Model에서 OpenAI 챗 모델을 고릅니다.
  5. AI Agent의 Add Option에서 시스템 메시지를 추가해 FAQ 응답 에이전트 역할을 입력합니다.
  6. Memory에서 Simple Memory를 선택하고 기억할 대화 수를 5개로 설정합니다.
  7. 구글 시트에 Question·Answer 열로 FAQ 데이터를 만들고, Tool로 구글 시트를 추가해 해당 문서와 Sheet1을 선택합니다.
  8. 화면 하단 채팅창에서 시트에 있는 질문을 입력해 답변이 오는지 테스트합니다.
  • 구글 시트 연결은 Create New Credential에서 Sign in with Google로 진행합니다.
  • AI 에이전트는 기본적으로 이전 대화를 기억하지 못하므로 메모리 노드가 필요합니다.
  • n8n 클라우드에서는 빌드 위드 AI로 한국어 요청만으로 노드를 만들 수 있지만(베타, 프롬프트당 1크레딧), API 키와 OAuth 인증은 직접 연결해야 합니다.
  • 도커 설치 방식은 개발에 익숙하지 않으면 추천하지 않습니다.

11. Claude Code 루틴으로 정기 작업 맡기기

루틴은 프롬프트, 연결할 저장소, 커넥터, 트리거만 정하면 Anthropic 관리형 인프라에서 Claude Code 세션을 자동 실행하는 기능입니다. 노트북을 닫아도 돌아가며 일정이나 GitHub 이벤트로 시작할 수 있습니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문(실행 시각, 완료 후 알림 여부 등)에 답합니다.
  4. 작업에 필요한 저장소를 컨텍스트로 연결합니다.
  5. 만들어진 루틴을 웹의 Claude Code에서 확인하고 실행 결과 세션을 열어 봅니다.
예시
/schedule 매주 main에 병합된 변경을 문서 저장소와 비교해서, 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘
  • 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 처음에는 결과를 직접 확인하고, 신뢰가 쌓이면 권한을 늘리세요.
  • 활용 예: 루틴이 1~2시간마다 구글 드라이브 폴더를 확인하게 하면 영상을 올리는 것만으로 편집 작업이 시작됩니다.
  • Projects 안에서도 매일 도는 루틴을 설정할 수 있으며, 베타로 Pro·Max에 순차 제공됩니다.

12. 개입 지점을 설계해 병목 없애기

여러 단계의 업무를 AI에 맡길 때 내가 매번 확인하느라 병목이 되지 않도록 규칙, 한도, 확인 지점을 미리 정하는 설계법입니다. 콘텐츠 제작 사례를 바탕으로 하지만 어떤 반복 업무 파이프라인에도 응용할 수 있습니다.

  1. 업무를 단계로 나눕니다. 예: 기획·리서치, 대본, 음성, 모션, 검수, 패키징, 업로드.
  2. 단계별 기준을 업무 매뉴얼(SOP)로 마크다운·노션·문서에 정리하고, 잘 된 작업은 스킬로 저장합니다.
  3. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  4. 에이전트에 가능한 한 많은 권한을 줍니다.
  5. 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  6. 캐릭터 생성처럼 되돌리기 어려운 지점은 다음 단계 전에 내 확인을 받도록 정합니다.
  7. Claude가 만든 결과는 Codex가, Codex가 만든 결과는 Claude가 독립적으로 검증하게 합니다.
  8. 결과의 반응 데이터를 보고 다음 작업을 개선합니다.
  • 영상의 상한 숫자(쇼츠 500, 롱폼 1,500 크레딧)는 제작자 본인의 값이므로 내 요금제에 맞게 정하세요.
  • 영상 편집 사례에서 34초 영상에 약 40분이 걸렸고, 템플릿과 맞지 않는 포맷은 품질이 떨어질 수 있습니다.
  • 검수 없이 올리지 말고 직접 아는 범위에서 확인한 뒤 게시하세요.
