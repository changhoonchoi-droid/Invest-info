1. Cowork로 폴더 업무 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·워드 같은 결과물을 만들어 주는 도구입니다. 영수증 정리, 흩어진 자료의 보고서화처럼 파일 위주의 반복 업무에 씁니다.

  1. Claude 데스크톱 앱을 열고 Cowork(또는 협업) 버튼을 누릅니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 고릅니다.
  3. 폴더 접근 권한 창에서 항상 허용을 선택합니다.
  4. 자료(회의록, 엑셀, 메모 등)를 그 폴더에 복사해 넣습니다.
  5. 원하는 결과물과 포함할 항목을 구체적으로 적어 요청합니다.
  6. Claude가 제안한 계획을 확인하고 진행시킵니다.
  7. 완성된 파일을 지정한 폴더에서 열어 내용을 검토합니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘.
  • 원본 파일은 그대로 두고 정리본을 새 파일로 저장하라고 프롬프트에 적어 두세요.
  • 파일명에 날짜를 넣어 달라고 함께 요청하면 정리가 쉽습니다.
  • 웹 버전은 로컬 파일 접근이 안 되므로 파일 작업은 데스크톱 앱에서 하세요.
  • Settings의 Cowork 탭에서 역할 설명이나 파일 형식 같은 전역 지침을 정해 두면 매번 설명하지 않아도 됩니다.

2. 반복 보고서를 스킬로 고정하기

스킬은 '어떤 단계와 규칙으로 일할지'를 저장한 작업 지시서입니다. 보고서 양식, 문체 같은 기준을 스킬로 저장하면 요청할 때마다 같은 형식의 결과가 나옵니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 형식을 분석해 보고서 만드는 스킬을 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 스킬을 고릅니다.
  5. 주제를 적어 보고서를 요청합니다.
  6. 결과를 직접 읽고 고칩니다. 부족한 규칙은 스킬에 다시 반영합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
  • 스타일, 색, 섹션 구성 같은 규칙을 스킬이나 메모리에 넣으면 매번 같은 포맷이 나옵니다.
  • AI 티가 나는 문장은 별도 교정 스킬로 다듬되, 중요한 문서는 직접 읽고 고칩니다.

3. Cowork 예약 작업으로 자동 실행하기

예약 작업은 매일·매주 같은 일을 정해진 시각에 Claude가 알아서 실행하게 합니다. 아침 메일 정리, 주간 지표 리포트 같은 정기 업무에 적합합니다.

  1. 반복할 일을 자연어로 설명합니다. 예: 매시간 공유 폴더의 변경 문서를 확인해 요약.
  2. 또는 입력창에 /schedule을 입력해 시작합니다.
  3. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  4. 주기(매시간·매일·평일·수동)를 확인하고 필요하면 바꿉니다.
  5. 내용이 맞으면 제안을 수락합니다.
  6. 왼쪽 사이드바의 예약 페이지에서 작업이 추가됐는지 확인합니다.
  7. 처음 몇 번은 실행 기록을 열어 결과를 점검합니다.
예시
AI 트렌드를 리서치해서 매주 수요일 유튜브 아이디어 5개를 제안해 줘. 예약 작업으로 만들어 줘.
  • 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행됐습니다. 7월 업데이트 이후에는 클라우드에서 기기가 꺼져 있어도 실행된다고 소개됩니다.
  • 꺼져 있어서 놓친 작업은 복귀 후 바로 실행되고 지연됐다고 알려 줍니다.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있습니다.
  • 실행마다 새 세션으로 돌기 때문에 필요한 맥락은 프롬프트나 폴더에 두세요.

4. 플러그인·커넥터로 업무 도구 잇기

커넥터는 Google Drive, Slack, 이메일 같은 외부 서비스를 Claude에 붙이고, 플러그인은 스킬·커넥터·슬래시 명령을 직무별로 묶은 패키지입니다. 회의 준비나 영업 브리핑처럼 여러 곳에 흩어진 정보를 모을 때 씁니다.

  1. Cowork 설정에서 필요한 커넥터(캘린더, Slack, 이메일 등)를 연결합니다.
  2. 작업 폴더를 지정해 Claude가 파일을 읽고 저장할 수 있게 합니다.
  3. + 버튼에서 플러그인을 선택해 직무에 맞는 플러그인을 설치합니다.
  4. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  5. 입력창에서 슬래시 명령이나 스킬을 호출하고 회의·고객 정보를 적습니다.
  6. Claude가 만든 브리핑 문서를 폴더에서 열어 근거를 확인합니다.
  7. 발송이 필요한 결과는 내용을 승인한 뒤 보냅니다.
예시
Prep me for today's call with Acme Corp at 1PM. 캘린더, Slack, 이메일, 이전 회의록을 확인해서 안건 문서를 만들고, 기존 문서 형식을 템플릿으로 따라 줘.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 처음에는 테스트 계정으로 스킬을 돌려 보고 다듬은 뒤 실제 업무에 씁니다.
  • 근거를 원문에서 직접 확인하세요. 내 이름으로 보내는 답장은 특히 그렇습니다.
  • 플러그인 명령어 이름은 영상에서 불분명했으니 플러그인 관리 화면에서 정확한 표기를 확인하세요.

5. PDF·메일 요약과 발표 준비 맡기기

긴 PDF 요약, 근거 확인, 이메일 초안, 발표 예상 질문 준비는 AI가 가장 빨리 시간을 줄여 주는 업무입니다. 근거 번호로 원문 위치를 확인할 수 있는 도구를 쓰면 안심하고 맡길 수 있습니다.

  1. 애크로뱃에서 PDF를 열고 AI 어시스턴트에게 질문하기를 누릅니다.
  2. 이 문서의 중요 정보 요약을 누르거나 직접 질문합니다.
  3. 답변의 근거 숫자를 눌러 해당 페이지와 구간을 확인합니다.
  4. 여러 자료는 PDF 스페이스에 넣어 두고 팀회의 예상 질문과 답변을 요청합니다.
  5. 필요하면 이메일 초안을 요청하고 더 친근하게처럼 말투를 바꿉니다.
  6. 중요한 조항과 숫자는 직접 확인한 뒤 사용합니다.
예시
이 자료를 바탕으로 팀회의에서 나올 만한 질문 세 개와 답변을 정리해 줘. 근거가 없는 내용은 '확인 필요'라고 표시해 줘.
  • 이미지·표가 많은 문서는 먼저 OCR을 돌리면 정확도가 올라갑니다.
  • 근거 번호가 정확한 문장이 아니라 근처를 가리킬 수 있습니다.
  • 무료 버전은 AI 요청 횟수 제한이 있고, 최종 판단은 사람이 합니다.

6. ChatGPT Work·스파크로 메일·회의 정리

ChatGPT Work와 제미나이 스파크는 파일과 메일·캘린더를 직접 다루며 결과물까지 만들어 주는 업무 에이전트입니다. 회의록을 실행 항목 시트로 바꾸거나 메일 우선순위 브리핑을 받을 때 씁니다.

  1. ChatGPT 데스크탑 앱에서 Work 모드를 선택합니다.
  2. 회의록 파일을 첨부하고 담당자·할 일·마감 세 열의 스프레드시트를 요청합니다.
  3. 복잡한 작업은 입력창의 +에서 계획 모드를 켜고 Work의 질문에 답합니다.
  4. 제미나이는 스파크 베타 탭에서 설정의 연결된 앱에 구글 워크스페이스가 켜져 있는지 확인합니다.
  5. 캘린더와 Gmail 기준 우선순위 브리핑 문서를 요청합니다.
  6. 반복할 일은 '매주 월요일 오전 8시'처럼 시점을 적고 좌측 일정 탭에서 확인합니다.
  7. 메일은 발송하지 말고 초안으로 남기도록 지시합니다.
예시
이번 주 캘린더와 Gmail에서 답장 안 한 메일을 확인해 우선순위 브리핑 문서를 만들어 줘. 메일은 발송하지 말고 초안으로만 남겨 줘.
  • 스파크는 구글 AI 프로 이상 구독이 필요합니다.
  • 단순 작업은 기본 모드, 복잡한 작업은 계획 모드를 쓰세요.
  • 추론 수준은 미디엄에서 시작하고 결과가 부족할 때 올립니다.
  • Work의 파일·앱 기능은 데스크탑 전용입니다.

7. n8n으로 노코드 자동화 만들기

n8n은 노드(작업 블록)를 연결해 자동화 시나리오를 만드는 도구입니다. AI 워크플로우 빌더에 한국어로 요청하면 노드 배치까지 대신해 주므로, 슬랙·노션·구글 시트 연동 업무를 코딩 없이 만들 수 있습니다.

  1. n8n 클라우드에 가입하고 새 워크플로우를 만듭니다.
  2. 빌드 위드 AI(또는 n8n AI)를 눌러 빌드를 선택합니다.
  3. 트리거 시점과 처리 방식까지 구체적으로 적어 요청합니다.
  4. 만들어진 각 노드를 눌러 설정을 확인합니다.
  5. 수정 요청을 입력창에 적어 고칩니다.
  6. API 키와 OAuth 인증은 직접 연결합니다.
  7. 테스트 데이터로 실행해 확인한 뒤 실제로 씁니다.
예시
슬랙 채널에 '긴급'이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일을 보내는 워크플로우를 만들어 줘.
  • 프롬프트 한 번에 1크레딧을 쓰므로 여러 요구를 한 번에 요청하면 아낄 수 있습니다.
  • 기본 흐름 → 테스트 → 기능 추가 → 예외 처리 순으로 단계적으로 만듭니다.
  • AI 빌더는 베타이며 n8n 클라우드에서만 쓸 수 있습니다.
  • 오류가 나면 /clear로 초기화 후 다시 시도하세요.
  • FAQ 챗봇은 On chat message 트리거에 AI Agent, Simple Memory, 구글 시트 Tool을 붙이면 됩니다.

8. 화면 녹화로 반복 작업 스킬 만들기

Codex의 Record & Replay는 평소 하던 작업을 화면으로 보여 주면 재사용 가능한 스킬로 만들어 줍니다. 사이트 정보를 시트와 노션에 옮기는 식의 단순 반복 업무에 코드 없이 쓸 수 있습니다.

  1. Codex 앱 좌측의 플러그인에서 컴퓨터 유즈 플러그인을 먼저 설치합니다.
  2. 레코드 앤 리플레이 플러그인을 설치합니다.
  3. 설정에서 사용해 보기 버튼으로 기능을 켭니다.
  4. 새 프로젝트 추가 → 처음부터 시작을 골라 이름을 정하고 녹화를 시작합니다.
  5. 구글 시트·노션 정리 등 평소 하던 작업을 그대로 수행합니다.
  6. 정지 버튼으로 녹화를 마치면 스킬이 자동 생성됩니다.
  7. 채팅에서 사용해 보기로 불러와 조건을 덧붙여 실행합니다.
예시
제목 외에 유용한 정보도 시트에 기록하고 노션 DB에도 보기 좋게 정리해 줘. RSS 링크가 있으면 최대한 활용해 줘.
  • 현재 macOS에서만 사용할 수 있습니다.
  • 구글 계정은 미리 로그인해 두고 로그인 화면은 녹화에 넣지 마세요.
  • 만들어진 스킬은 텍스트로 요구사항을 덧붙여 개선합니다.

9. Claude Tag로 팀 채널에서 일 시키기

Claude Tag는 Slack 같은 팀 채널에 Claude를 추가해 대화 맥락을 보며 일하게 하는 기능입니다. 맥락을 복사해 붙일 필요 없이 채널에서 바로 요청하고, 여러 사람이 이어서 지시할 수 있습니다.

  1. 처음 쓸 채널 하나에 Claude를 추가합니다.
  2. 필요한 도구를 Claude Tag에 연결합니다.
  3. 채널에서 Claude를 태그해 작업을 요청합니다.
  4. 진행 상황을 채널에서 보다가 완료·결정 요청 알림이 오면 확인합니다.
  5. 반복할 지침은 Remember for this channel: ... 형태로 저장시킵니다.
  6. 개입 빈도가 너무 잦거나 드물면 조정해 달라고 말합니다.
예시
@Claude 최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • Team·Enterprise 요금제에서 베타로 제공됩니다.
  • 채널별로 접근 범위가 나뉘며 DM과 비공개 채널의 내용은 그 안에만 남습니다.
  • Claude가 사용자를 대신해 응답하거나 개별 도구에 접근할 때는 매번 권한을 묻습니다.
  • 처음에는 한 채널에서만 시작하세요.

10. Claude Code 루틴으로 먼저 일하게 하기

루틴은 프롬프트, 저장소, 커넥터, 트리거를 정하면 Anthropic 관리형 인프라에서 Claude Code 세션을 자동 실행하는 기능입니다. 노트북을 닫아도 돌아가며 일정이나 GitHub 이벤트로 시작할 수 있습니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 실행 주기와 알림 방식에 답합니다.
  4. 필요한 저장소를 컨텍스트로 연결합니다.
  5. 웹의 Claude Code에서 루틴을 확인하고 실행 결과 세션을 열어 봅니다.
예시
/schedule 매주 main에 병합된 변경을 문서 저장소와 비교해서 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나)을 먼저 정하세요.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 권한을 늘리세요.
  • 트리거는 시간 기반과 이벤트 기반(GitHub 이벤트, 웹훅)이 있습니다.

11. 24시간 도는 Claude Code 서버 만들기

노트북은 꺼지면 멈추고 Claude 클라우드는 내 PC 파일에 접근하지 못합니다. 전용 VPS 서버에 Claude Code를 설치하면 두 장점을 합쳐 24시간 작업을 돌릴 수 있습니다.

  1. Hostinger VPS에서 Claude Code 템플릿으로 서버를 만듭니다.
  2. 웹 콘솔에서 Claude 계정으로 로그인합니다.
  3. 별도 사용자를 만들어 권한 무시 모드로 실행합니다.
  4. SSH 키로 내 PC의 데스크톱 앱과 서버를 연결합니다.
  5. 모바일 Claude 앱의 코드 메뉴에서 서버 세션을 사용합니다.
  • 영상은 Hostinger 제휴 홍보를 포함합니다. 같은 구성이 다른 VPS에서도 가능한지는 영상에서 다루지 않았습니다.
  • 소개된 KVM2는 연 20~30만 원대이며 고사양은 KVM8(RAM 16GB 이상 권장)입니다.
  • 권한 무시 모드는 위험하므로 별도 사용자와 서버에 민감한 파일을 두지 마세요.

12. 에이전트 파이프라인과 개입 지점 설계

여러 작업을 동시에 맡겨도 내가 병목이 되지 않도록 단계(기획→실행→검수→배포)와 확인 지점을 미리 설계하는 방법입니다. 콘텐츠 제작뿐 아니라 어떤 반복 업무에도 적용됩니다.

  1. 업무를 기획·리서치 → 초안 → 검수 → 패키징 → 업로드 같은 단계로 나눕니다.
  2. 단계별 규칙을 스킬로 만들어 둡니다.
  3. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  4. 에이전트에 가능한 한 많은 권한을 줍니다.
  5. 크레딧처럼 크게 나가는 것은 상한을 정합니다.
  6. 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 정합니다.
  7. 검수는 만든 AI와 다른 AI가 독립적으로 하게 합니다.
  • 영상의 크레딧 상한(쇼츠 500, 롱폼 1,500)은 알렉스 본인 값이므로 내 요금제에 맞게 정하세요.
  • 종료 조건은 검증 통과·최대 반복 횟수·시간/비용 한도처럼 참/거짓을 판정할 수 있게 겹쳐 겁니다.
  • 자동 발행은 영상 시점에 아직 계획 단계였습니다. 충분히 검증한 뒤 켜세요.
