1. 코워크에 폴더 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·워드 같은 결과물을 만들어 주는 도구입니다. 흩어진 자료를 보고서로 정리하거나 엑셀을 합치는 일에 쓰면 좋습니다. 모든 코워크 활용의 출발점입니다.

  1. Claude 데스크톱 앱을 설치하고 로그인합니다. 코워크는 유료(Pro 이상) 플랜이 필요합니다.
  2. 클로드 채팅 화면에서 코워크 버튼을 누릅니다.
  3. 하단의 프로젝트 또는 폴더 버튼에서 폴더 추가를 눌러 작업할 폴더를 엽니다.
  4. 폴더 접근 권한 창에서 항상 허용을 선택합니다.
  5. 매출 데이터, 회의록, 메모 같은 자료를 그 폴더에 복사해 넣습니다.
  6. 아래 예시처럼 원하는 결과물과 형식을 구체적으로 적어 요청합니다.
  7. Claude가 계획·실행·검증을 거치는 진행 상황을 지켜봅니다.
  8. 완성된 파일을 지정한 폴더에서 열어 내용을 확인합니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘. 원본은 그대로 두고 결과는 새 파일로 저장해 줘.
  • 원본 보존을 프롬프트에 꼭 적어 두세요. 엑셀 정리처럼 파일을 바꾸는 일은 정리본을 새 파일로 저장하게 하는 것이 안전합니다.
  • 변경 전에 계획을 먼저 보여 달라고 요청하고, 처음에는 정리처럼 범위가 분명한 작업부터 시작하세요.
  • 웹 버전은 내 컴퓨터의 파일 접근과 컴퓨터 직접 조작이 안 되므로, 그런 작업은 데스크톱 앱에서 하세요.
  • 예전 방식: 상단 탭 코워크에서 폴더에서 작업 → 다른 폴더 선택으로 열었고, 영상에 따라 메뉴 이름이 협업으로 나오기도 합니다.

2. 코워크 지침 정해 반복 설명 줄이기

글로벌 지침은 나의 역할과 작업 스타일을 한 번 적어 두면 모든 코워크 세션에 적용되는 설정입니다. 매번 같은 말을 반복하지 않아도 되어 결과 형식이 일정해집니다.

  1. 좌측 상단에서 Claude 설정을 엽니다.
  2. 협업 탭으로 이동합니다.
  3. 지침 항목의 편집 버튼을 누릅니다.
  4. 내가 어떤 사람인지, 작업 스타일, 선호하는 도구 환경을 적습니다.
  5. 자주 쓰는 결과 파일 형식(예: Word 문서)도 함께 적습니다.
  6. 저장을 누릅니다.
  7. 새 코워크 작업을 시작해 지침이 반영되는지 확인합니다.
예시
저는 마케팅팀에서 일하는 직장인입니다. 보고서는 Word 문서로 만들고, 핵심 요약을 맨 위에 써 주세요. 문장은 존댓말로 간결하게 써 주세요.
  • 한 번 저장하면 모든 코워크 세션에 적용됩니다.
  • 전역 지침 외에 폴더별 지침도 쓸 수 있다고 소개됩니다. 업무마다 다른 규칙이 필요하면 나눠 두세요.
  • 비밀번호나 고객 개인정보는 지침에 적지 마세요.

3. 커넥터로 회의 준비 문서 만들기

캘린더·Slack·이메일 같은 서비스를 Claude에 연결하면, 흩어진 정보를 모아 회의 안건 문서를 만들어 줍니다. 고객 미팅이나 주간 회의 전에 조사하는 시간을 줄이고 싶을 때 씁니다.

  1. 캘린더, Slack, 이메일을 Claude에 연결합니다.
  2. 이전 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 준비할 회의와 시간을 알려 줍니다.
  4. 캘린더 검색, 참석자 조사, Slack 스레드 확인, 이전 회의록 검토, 안건 작성을 요청하고 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  5. Claude가 세운 계획을 확인하고 작업이 진행되게 둡니다.
  6. 빠뜨린 출처가 있으면 작업 중에 추가로 요청합니다(예: 이메일 확인).
  7. 완성된 안건 문서를 작업 폴더에서 열어 검토하고, 빠진 내용은 추가를 요청하거나 직접 고칩니다.
예시
Prep me for today's call with Acme Corp at 1PM.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 최종 문서의 책임과 수정은 사용자에게 있으니 근거를 직접 확인하세요.
  • 메시지 발송처럼 밖으로 나가는 작업은 내용을 확인하고 승인한 뒤 보내게 하세요.
  • 브라우저 작업까지 시키려면 Claude in Chrome을 따로 설정해야 합니다.

4. 플러그인·스킬로 업무 방식 저장하기

플러그인은 스킬·커넥터·슬래시 명령을 직무별로 묶은 패키지이고, 스킬은 우리 팀의 업무 방식을 적어 둔 지시서입니다. 한 번 만들어 두면 같은 지시로 같은 품질의 결과가 나오므로 반복 업무에 알맞습니다.

  1. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  2. 플러그인 추가에서 직무에 맞는 플러그인(세일즈, 제품 관리, 마케팅 등)을 설치합니다.
  3. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  4. 입력창에 /를 입력하고 쓸 명령이나 스킬을 고른 뒤 회사명·목적 같은 필요한 정보를 적습니다.
  5. 우리 팀만의 업무라면, 미팅 전에 알고 싶은 내용을 설명해 스킬 파일 초안을 만들게 합니다.
  6. 필요한 커넥터를 연결하고 작업 폴더를 지정한 뒤, 테스트용 자료로 스킬을 실행해 결과를 보고 다듬습니다.
  7. 실행 후 배운 점을 스킬에 반영해 달라고 요청해 다음 회차에 쓰이게 합니다.
예시
이번 주 실행하면서 배운 점을 정리해서 이 스킬에 반영해 줘.
  • 스킬은 일반 텍스트 파일이라 언제든 열어서 동작을 확인할 수 있습니다.
  • 처음에는 테스트 계정이나 샘플 자료로 돌려 보고, 다듬은 뒤 실제 자료에 쓰세요.
  • 플러그인 명령어 이름은 영상에서 불분명했으므로 플러그인 관리 화면에서 정확한 표기를 확인하세요.
  • 스킬은 팀과 공유하면 누구나 같은 방식으로 결과를 낼 수 있습니다.

5. 예약 작업으로 반복 업무 자동 실행하기

예약 작업은 정해진 주기에 Claude가 같은 일을 알아서 실행하게 하는 기능입니다. 매일 아침 메일 정리, 매주 지표 리포트, 매시간 문서 변경 확인처럼 반복되는 일에 씁니다.

  1. 반복할 일을 자연어로 설명합니다(예: 매시간 공유 드라이브 폴더의 추가·수정 문서를 확인하고 요약).
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  4. 내용이 맞으면 제안을 수락합니다.
  5. 사이드바의 예약 페이지(영상에 따라 예정된 탭)에서 작업이 추가된 것을 확인합니다.
  6. 첫 실행 결과를 확인하고, 필요하면 지시문이나 주기를 고칩니다.
예시
매시간 공유 드라이브 폴더에 추가되거나 수정된 문서를 확인해서 변경한 사람을 기록하고, 내용을 요약해 클라이언트별로 묶어 문서로 저장해 줘.
  • 2026년 7월 7일 업데이트 이후에는 기기가 꺼져 있어도 클라우드에서 예약 작업이 실행됩니다. 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 했고, 놓친 작업은 다시 켤 때 실행되었습니다.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있고, 실행마다 새 세션으로 최신 파일 기준으로 돌아갑니다.
  • 웹 버전은 내 컴퓨터의 파일에 접근하지 못하므로, 로컬 파일을 쓰는 작업은 데스크톱 앱에서 만드세요.
  • 처음에는 결과를 직접 확인하고, 믿을 만해지면 더 많은 일을 맡기세요.

6. Slack 채널에서 Claude Tag에게 일 시키기

Claude Tag는 Slack 같은 팀 워크스페이스의 채널에 Claude를 추가해, 팀 대화를 따라가며 일하게 하는 기능입니다. 채팅 창을 오가거나 맥락을 복사해 붙이지 않고 채널에서 바로 복합 작업을 맡길 수 있습니다.

  1. Claude를 쓸 채널 하나에 Claude를 추가합니다.
  2. 필요한 도구(Google Drive, Asana 등)를 Claude Tag에 연결합니다.
  3. 채널에서 Claude를 태그해 작업을 요청합니다.
  4. Claude가 단계별로 진행하는 상황을 채널에서 확인합니다.
  5. 기다리지 말고 다른 일을 하다가, 완료 또는 결정 요청 알림이 오면 확인하고 답합니다.
  6. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
  7. 너무 자주 또는 드물게 끼어들면 개입 빈도를 조정해 달라고 말합니다.
예시
최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.

7. ChatGPT Work로 회의록 실행 항목 뽑기

ChatGPT Work는 답을 주는 데 그치지 않고 파일·스프레드시트 같은 결과물을 만들어 주는 업무 실행 모드입니다. 회의록에서 담당자·할 일·마감만 뽑아 표로 만드는 일에 바로 쓸 수 있습니다.

  1. ChatGPT 데스크탑 앱을 설치하고 메인 화면에서 Work 모드를 선택합니다.
  2. 회의록 파일을 첨부합니다.
  3. 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 달라고 요청합니다.
  4. 더 복잡한 작업이면 입력창의 + 버튼을 눌러 계획 모드를 켭니다.
  5. Work가 던지는 질문에 답합니다.
  6. 작성된 계획대로 나온 결과물(팀 공용 문서, 실행 항목 시트)을 확인합니다.
예시
첨부한 회의록에서 실행 항목만 뽑아 담당자, 할 일, 마감 세 열의 스프레드시트로 만들어 줘.
  • 파일·앱을 다루는 기능은 데스크탑 전용입니다.
  • 단순 작업은 기본 모드, 복잡한 작업은 플랜 모드를 쓰세요. 모호한 부분을 먼저 물어봐 더 구체적인 결과가 나옵니다.
  • 채팅에서 가볍게 아이디어를 다듬고 Work에서 마무리하는 방식도 편합니다.

8. 제미나이 스파크로 주간 업무 자동화하기

제미나이 스파크는 구글 클라우드에서 상시 일하는 개인 AI 에이전트로, Gmail·캘린더·독스·시트·드라이브를 별도 연결 없이 다룹니다. 브라우저를 닫고 폰을 잠가도 백그라운드에서 일이 이어지므로 주간 정리 같은 반복 업무에 맞습니다.

  1. 제미나이를 실행하고 좌측 상단 스파크 베타 탭을 누릅니다.
  2. 좌측 하단 프로필에서 설정을 열어 연결된 앱의 구글 워크스페이스가 켜져 있는지 확인합니다.

  4. 자동 실행하려면 프롬프트에 실행 시점을 적습니다(예: 매주 월요일 오전 8시).
  5. 지난 7일간 Gmail의 뉴스레터·업무 보고 메일을 구글 시트에 정리하도록 지시합니다.
  6. 핵심 요약 5개를 이메일 초안으로 쓰되 발송하지 말고 초안으로 남기도록 요청합니다.
  7. 좌측 일정 탭에서 등록된 일정을 확인합니다.
예시
이번 주 캘린더와 Gmail에서 답장 안 한 메일을 확인해서 우선순위 브리핑 문서를 만들어 줘.
  • 구글 AI 프로 이상 구독이 필요하며 한국어를 공식 지원합니다.

9. Codex 자동화로 매일 아침 브리핑 받기

OpenAI Codex의 자동화 기능은 정해진 시각에 일정 정리나 알림 같은 일을 대신 실행합니다. 캘린더 일정을 Slack으로 받아 보는 아침 브리핑처럼 간단한 반복 업무에 적합합니다.

10. n8n AI 빌더로 노코드 자동화 만들기

n8n은 작업 블록(노드)을 연결해 자동화 시나리오를 만드는 도구이고, AI 빌더는 한국어로 요청하면 노드 선택과 연결을 대신해 줍니다. 슬랙 알림을 노션에 저장하거나 매출 리포트를 메일로 보내는 식의 연동 자동화에 쓰입니다.

  1. n8n 클라우드에 접속해 새 워크플로우를 만듭니다.
  2. 가운데의 빌드 위드 AI 또는 우측의 n8n AI를 클릭하고 빌드를 선택합니다.
  3. 자동화할 내용을 트리거 시점과 처리 방식까지 구체적으로 적어 엔터를 누릅니다.
  4. 만들어진 각 노드(트리거, 필터, 노션, 이메일 등)를 클릭해 설정을 확인합니다.
  5. 입력창에 수정 요청을 적습니다. 예: 이메일 본문에 슬랙 메시지 링크를 추가해 줘.
  6. API 키와 OAuth 인증 정보는 직접 연결합니다.
  7. 테스트 데이터로 실행해 동작을 확인한 뒤 실제로 사용합니다.
예시
슬랙 채널에 긴급이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일을 보내 줘.
  • 프롬프트 한 번에 1크레딧을 쓰므로 요구 사항을 한 번에 모아 요청하면 아낄 수 있습니다.
  • 베타 기능이며 n8n 클라우드에서만 쓸 수 있고, 인증 설정은 보안상 AI가 대신해 주지 않습니다.
  • 기본 흐름 → 테스트 → 기능 추가 → 예외 처리 순으로 단계적으로 만드세요. 오류가 나면 /clear로 컨텍스트를 초기화하고 다시 시도하라고 권합니다.
  • 직접 조립하는 방식도 있습니다. 트리거 On chat message에 AI Agent와 Simple Memory, 구글 시트 툴을 엮으면 FAQ 챗봇이 됩니다.

11. 종료 조건 정해 에이전트 루프 설계하기

루프 설계는 내가 시키지 않아도 AI가 일을 이어가도록 반복 구조를 짜는 일입니다. 반복 업무를 맡길수록 언제 끝낼지, 어디서 사람이 확인할지를 미리 정해 두는 것이 가장 중요합니다.

  1. 자동으로 돌릴 반복 업무 하나를 고르고, 무엇이 완료인지 누가 봐도 참/거짓으로 판정할 수 있게 적습니다.
  2. 진행 상황을 적어 두는 상태 파일을 만들어 AI의 기억 장치로 쓰게 합니다.
  3. 종료 조건을 겹쳐 겁니다: 검증 통과, 최대 반복 횟수, 시간·비용 한도, 진전 없음 중단.
  4. 만드는 AI와 검사하는 AI를 분리합니다(예: Claude가 쓰면 Codex가, Codex가 쓰면 Claude가 검증).
  5. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  6. 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  7. 캐릭터 생성처럼 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 정합니다.
  • 영상의 크레딧 상한(쇼츠 500, 롱폼 1,500)은 발표자 본인의 값이므로 내 요금제에 맞게 정하세요.
  • 폭주하는 프로세스에 대비해 비용·횟수 한도 같은 서킷 브레이커가 필요합니다.
  • 모델은 작업의 길이와 복잡도에 맞춰 고르세요. 단순 파일 생성에 고성능 모델은 필요하지 않습니다.
  • AI가 만든 결과물도 공개 전에 사람이 원문과 대조해 검수해야 합니다.
