업무 자동화·에이전트

이 분야에서는 AI에게 파일 정리·보고서 작성 같은 일을 통째로 맡기고, 정해진 시각에 저절로 돌게 예약하고, Slack 같은 팀 채널에서 함께 일하게 할 수 있습니다. 처음이라면 코워크로 폴더 작업을 맡기는 법과 글로벌 지침부터 익히세요. 그다음 예약 작업, 커넥터, 스킬로 반복 업무를 표준화하고, 마지막에 사람이 확인할 지점과 멈출 조건을 설계하는 순서로 보면 좋습니다.

Cowork, 예약 작업, 반복 업무 자동화, 에이전트 설계, 실무 워크플로 · 영상 78개 기반 · 2026-11-03 갱신

최근 바뀐 점

  • Claude Code Projects가 베타로 나왔습니다. 하나의 지속 대화가 클라우드의 별도 브랜치에서 도는 스레드들을 조율하고, 매일 도는 루틴까지 한 프로젝트 안에서 설정할 수 있습니다(Pro·Max에 순차 제공).
  • Claude Duet이 연구 프리뷰로 공개되었습니다. 주의가 필요한 일을 먼저 알려 주고 폰을 내려놓아도 계속 일하며, 사용자를 대신해 행동하기 전에는 확인을 받습니다(미국 Pro·Max 구독자 대상 대기자 명단).
  • 클로드 데스크톱에서 Docs·Designs·Slides를 한 채팅 안에서 이어 만들 수 있습니다. 드래그한 부분에 댓글을 달아 수정을 시키는 방식이 소개되었습니다.
  • 콘텐츠 자동화 사례에서 두 가지 방식이 소개되었습니다. 하나는 Claude가 만든 것은 Codex가, Codex가 만든 것은 Claude가 검증하는 교차 검토이고, 다른 하나는 사람의 확인 지점을 최소화하는 Human on the loop 설계입니다.

1. 코워크로 폴더 속 파일 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 스스로 계획을 세워 파일을 읽고 엑셀·워드 같은 결과물을 만들어 주는 기능입니다. 흩어진 자료로 보고서를 만들거나, 여러 엑셀을 합치거나, 지저분한 데이터를 정리할 때 씁니다.

  1. Claude 데스크톱 앱을 설치해 엽니다.
  2. 채팅 화면에서 코워크 버튼을 누릅니다.
  3. 입력창 아래 프로젝트 또는 폴더에서 폴더 추가를 눌러 작업할 폴더를 엽니다.
  4. 폴더 접근 권한 창에서 항상 허용을 선택합니다.
  5. 회의록·엑셀·메모 등 작업할 자료를 그 폴더에 넣습니다.
  6. 만들 결과물과 파일 이름 규칙을 적어 요청하고, 바꾸기 전에 계획을 먼저 보여 달라고 덧붙입니다.
  7. 제안된 계획을 확인하고 고칠 점을 말한 뒤 승인합니다.
  8. 진행 상황을 지켜보고, 완성된 결과 파일을 폴더에서 열어 내용과 수식을 확인합니다.
예시
설문 응답 엑셀 세 개를 하나로 합치고, 채널별 만족도 비교 시트와 불만 키워드 탑 10, 이를 바탕으로 한 워드 보고서를 만들어 줘. 파일명에는 날짜를 넣어 줘. 파일을 바꾸기 전에 계획을 먼저 보여 줘.
  • 코워크는 프로 플랜(월 20달러) 이상에서 쓸 수 있습니다. 웹 버전은 로컬 파일에 접근할 수 없으니 폴더 작업은 데스크톱 앱에서 하세요.
  • 엑셀을 정리할 때는 '원본은 그대로 두고 정리본은 새 파일로 저장해 줘'를 반드시 프롬프트에 적습니다.
  • 7월 업데이트 이후 화면에서는 새로 생성을 누른 뒤 입력창 아래 협업을 고르는 형태로 보이기도 합니다.
  • 예전 방식: 상단 코워크 탭에서 폴더에서 작업 → 다른 폴더 선택 → 열기 순서로 폴더를 열었습니다.

2. 코워크 글로벌 지침 설정하기

글로벌 지침은 내가 누구인지, 어떤 방식으로 일하는지를 한 번 적어 두면 모든 코워크 세션에 적용되는 설정입니다. 매번 같은 설명을 반복하지 않으려고 씁니다.

  1. 좌측 상단에서 Claude 설정을 엽니다.
  2. 협업 탭으로 이동합니다(영문 화면에서는 Settings의 Cowork 탭).
  3. 지침 항목의 편집 버튼을 누릅니다.
  4. 내 역할, 작업 스타일, 선호하는 도구와 파일 형식을 적습니다.
  5. 저장을 누릅니다.
예시
나는 영업 지원 업무를 하는 직장인입니다. 결과물은 Word 문서로 만들어 주고, 핵심 요약을 맨 앞에 둬 주세요.
  • 전역 지침과 별도로 폴더별 인스트럭션도 둘 수 있어 프로젝트마다 다른 규칙을 줄 수 있습니다.

3. ChatGPT Work로 회의록 정리하기

ChatGPT Work는 답 대신 결과물을 만들어 주는 OpenAI의 업무 실행 에이전트입니다. 회의록에서 실행 항목 시트를 만들거나, 웹에서 자료를 모아 스프레드시트로 정리할 때 씁니다.

  1. ChatGPT 데스크탑 앱을 설치합니다. 파일·앱을 다루는 기능은 데스크탑 전용입니다.
  2. 메인 화면 상단에서 Work를 선택합니다.
  3. 모델은 GPT-6 아스트라, 추론 수준은 미디엄으로 둡니다.
  4. 회의록 파일을 첨부합니다.
  5. 실행 항목을 담당자·할 일·마감 세 열의 스프레드시트로 만들어 달라고 요청합니다.
  6. 작업이 복잡하면 입력창의 + 버튼을 누르고 계획 모드를 켠 뒤 요청합니다.
  7. Work가 던지는 질문에 답하고, 완성된 결과물을 확인합니다.
예시
회의록에서 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 줘.
  • 추론 수준은 미디엄에서 시작해 결과가 부족할 때 올립니다. 높일수록 비용이 늘어납니다.
  • 채팅에서 아이디어를 다듬은 뒤 Work의 컨텍스트 첨부로 이전 채팅을 불러와 기획안으로 마무리할 수 있습니다.
  • 웹 조사를 맡길 때는 필수 조건·선호 조건·검색 원칙·결과 형식을 적어 주면 결과를 구글 스프레드시트로 정리하게 할 수 있습니다.
  • 예약 작업으로 연결된 앱을 오가는 여러 단계 업무도 통째로 예약할 수 있습니다.

4. 코워크 예약 작업 만들기

예약 작업은 반복할 일을 한 번 설명해 두면 매시간·매일·평일 같은 주기로 Claude가 알아서 실행하는 기능입니다. 아침 메일 정리나 주간 지표 리뷰 준비처럼 정기적으로 하는 일을 맡길 때 씁니다.

  1. 먼저 맡길 작업을 일반 요청으로 한 번 실행해 결과가 마음에 드는지 확인합니다.
  2. 왼쪽 사이드바의 예약 페이지에서 새 작업을 만들거나 입력창에 /schedule을 입력합니다.
  3. 반복할 일을 자연어로 설명합니다.
  4. Claude가 만든 예약 작업 프롬프트 초안을 검토하고 고칩니다.
  5. 주기를 매시간·매일·평일·수동 중에서 고릅니다.
  6. 내용이 맞으면 제안을 수락합니다.
  7. 예약 페이지에서 작업이 추가됐는지 확인하고, 필요하면 바로 한 번 실행해 봅니다.
예시
매시간 공유 드라이브 폴더에서 추가되거나 수정된 문서를 확인해 변경한 사람을 기록하고, 내용을 요약해 클라이언트별로 묶은 문서로 저장해 줘.
  • 2026년 7월 7일 업데이트 이후 예약 작업은 클라우드에서 돌아 기기가 꺼져 있어도 실행됩니다. 다만 웹·클라우드 쪽은 로컬 파일에 접근하지 못하니, 내 PC 폴더를 다루는 작업이면 실행 조건을 확인하세요.
  • 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행됐으며, 놓친 작업은 다시 켰을 때 실행되고 지연됐다고 알려 줬습니다.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있습니다. 실행마다 새 세션으로 돌아 최신 파일 상태를 기준으로 합니다.
  • 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행을 할 수 있습니다.

5. 제미나이 스파크로 메일 브리핑 자동화하기

제미나이 스파크는 구글 클라우드에서 상시 일하는 개인 AI 에이전트로, Gmail·캘린더·독스·시트·드라이브를 별도 연결 없이 다룹니다. 메일 우선순위 브리핑이나 매주 정해진 시각의 메일 정리를 맡길 때 씁니다.

  1. 제미나이를 실행하고 좌측 상단 스파크 베타 탭을 누릅니다.
  2. 좌측 하단 프로필에서 설정을 엽니다.
  3. 연결된 앱에서 구글 워크스페이스가 켜져 있는지 확인합니다.
  4. 프롬프트에 실행 시점(예: 매주 월요일 오전 8시)과 할 일을 함께 적어 요청합니다.
  5. 메일은 보내지 말고 초안으로만 남기라고 덧붙입니다.
  6. 좌측 일정 탭에서 등록된 일정을 확인합니다.
  7. 보낸 이메일을 분석해 내 문체를 스킬로 저장해 달라고 요청하고, 인사말 한 줄·본론 먼저 같은 규칙을 덧붙입니다.
예시
매주 월요일 오전 8시에 지난 7일간 Gmail의 뉴스레터·업무 보고 메일을 구글 시트에 정리하고, 핵심 요약 5개를 이메일 초안으로 작성해 줘. 발송하지 말고 초안으로만 남겨 줘.
  • 구글 AI 프로 이상 구독이 필요합니다. 웹·모바일에서 쓸 수 있고 데스크탑 앱은 현재 macOS만 지원합니다.
  • 브라우저를 닫거나 폰을 잠가도 백그라운드에서 작업이 계속됩니다.
  • Codex에서도 플러그인 탭에서 Slack·구글 캘린더를 먼저 연결한 뒤 자동화 탭의 채팅으로 만들기로 매일 아침 브리핑을 걸 수 있습니다. 플러그인을 먼저 연결하지 않으면 동작하지 않습니다.

6. 커넥터로 회의 준비 브리핑 만들기

캘린더·Slack·이메일 같은 서비스를 커넥터로 연결하면 Claude가 흩어진 정보를 직접 찾아 회의 준비 문서를 만듭니다. 고객 미팅 전 조사와 미팅 후 후속 메시지 작성을 몇 분으로 줄일 때 씁니다.

  1. 설정에서 캘린더, Slack, 이메일 등 필요한 서비스를 커넥터로 연결합니다.
  2. 이전 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 회의 이름과 시간을 알려 주고, 캘린더 검색·참석자 조사·Slack 스레드 확인·이전 회의록 검토·안건 작성을 요청합니다.
  4. 기존 안건 문서의 형식을 템플릿으로 따르라고 지시합니다.
  5. Claude가 세운 계획을 확인하고 진행시킵니다.
  6. 빠뜨린 출처가 있으면 작업 중에 추가로 요청합니다(예: 이메일도 확인해 줘).
  7. 완성된 안건 문서를 작업 폴더에서 열어 검토하고, 빠진 내용은 추가를 요청하거나 직접 고칩니다.
  8. 미팅 후 같은 세션에서 통화 녹취록으로 개인 할 일, 내부 Slack 메시지, 고객 후속 메시지를 만들게 하고 하나씩 확인·승인한 뒤 발송합니다.
예시
오늘 오후 1시 Acme Corp 통화를 준비해 줘. 캘린더에서 일정을 찾고, 참석자를 조사하고, 관련 Slack 스레드와 이전 회의록을 검토해서 기존 안건 문서 형식대로 안건을 만들어 줘.
  • 작업 도중 지시를 추가해도 처음부터 다시 만들지 않고 방향을 바꿔 이어갑니다.
  • 내 이름으로 나가는 답장이므로 브리핑이 가리키는 원문을 직접 열어 근거를 확인합니다.
  • 최종 문서의 책임과 수정은 사용자에게 있습니다.

7. 플러그인·스킬로 반복 업무 표준화하기

스킬은 업무 방식을 적어 둔 매뉴얼이고, 플러그인은 스킬·커넥터·슬래시 명령을 묶은 직무별 패키지입니다. 같은 지시로 매번 같은 품질의 결과를 내고 팀과 방식을 나눌 때 씁니다.

  1. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  2. 플러그인 추가에서 세일즈·제품 관리·마케팅 등 필요한 플러그인을 설치합니다.
  3. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  4. 입력창에 /를 입력해 명령(예: /call-prep)을 고르고 회사명·목적 같은 필요한 정보를 적어 실행합니다.
  5. 나만의 스킬이 필요하면 세션에서 원하는 결과를 설명해 스킬 파일 초안을 만들게 합니다.
  6. 테스트용 자료로 스킬을 실행해 결과를 보고 다듬습니다.
  7. 실행할 때마다 배운 점을 스킬에 반영해 달라고 요청합니다.
  8. 완성된 스킬을 팀과 공유해 누구나 같은 결과를 내게 합니다.
  • 명령어 표기는 영상 자막이 불분명할 수 있으니 플러그인 관리 화면에서 정확한 이름을 확인하세요.
  • 스킬은 일반 텍스트 파일이라 언제든 열어서 어떻게 동작하는지 확인할 수 있습니다.
  • Anthropic 공식 플러그인 11종은 오픈 소스이며 회사에 맞게 고치거나 직접 만들 수 있습니다.
  • 팀 스킬은 첫 스킬을 내놓기 전에 소유자·검토자·폐기 기준·테스트 방식을 정해 두어야 개인 맞춤 스킬이 엉뚱하게 퍼지는 문제를 막습니다.

8. 화면 녹화로 자동화 스킬 만들기

Codex의 Record & Replay는 평소 하던 작업을 화면으로 보여 주면 재사용할 수 있는 스킬로 만들어 주는 기능입니다. 코드나 단계별 프롬프트 없이 웹 자료를 시트·노션에 옮기는 반복 작업을 자동화할 때 씁니다.

  1. Codex 앱을 실행하고 좌측의 플러그인을 누릅니다.
  2. 컴퓨터 유즈 플러그인을 먼저 설치합니다.
  3. 다시 플러그인에서 레코드 앤 리플레이 플러그인을 설치합니다.
  4. 설정에서 사용해 보기 버튼을 눌러 기능을 켭니다.
  5. 새 프로젝트 추가 → 처음부터 시작을 고르고 이름을 정해 녹화를 시작합니다.
  6. 구글 시트 작성, 사이트 정보 입력, 노션 정리 등 평소 작업을 그대로 수행합니다.
  7. 정지 버튼을 눌러 녹화를 마치면 Codex가 스킬을 만듭니다.
  8. 만들어진 스킬에 바랄 점을 채팅으로 덧붙여 개선합니다.
  9. 플러그인의 스킬 목록에서 채팅에서 사용해 보기로 불러와 조건을 적고 실행합니다.
예시
제목 외에 유용한 정보도 시트에 기록하고, 노션 DB에도 보기 좋게 정리해 줘. RSS 링크가 있으면 최대한 활용해 줘.
  • 현재 macOS에서만 쓸 수 있고 컴퓨터 유즈가 켜져 있어야 합니다.
  • 쓸 계정은 미리 로그인해 두고 로그인 화면은 녹화에 넣지 않는 것이 안전합니다.
  • Claude에서는 Claude in Chrome의 클로드 가르치기로 녹화하며 음성으로 설명하면 숏컷이 만들어지고, 일정 버튼으로 매일·주간 반복을 걸 수 있습니다.
  • 브라우저 자동화는 느리고 악성 웹사이트의 숨은 지시(프롬프트 인젝션)에 조작될 수 있으며, 캡차·로그인은 직접 처리해야 합니다.

9. 규칙서와 3가지 검사로 품질 맞추기

AI 결과물이 들쭉날쭉한 것은 기준이 없기 때문입니다. 디자인 규칙서를 만들어 스킬로 저장하고 세 가지 검사를 거치면 PPT·보고서를 항상 같은 톤과 정확도로 받을 수 있습니다.

  1. 결과물 기준을 규칙서로 적습니다. 예: 색 3가지(검정·흰색·파랑), 본문 26~30px, 제목 68px, 도식 제목 34~36px, 장당 약 200자.
  2. 한글 글꼴은 자간을 0으로 두라고 규칙서에 넣습니다.
  3. 규칙서를 스킬로 저장해 매번 같은 기준으로 만들게 합니다.
  4. 만든 뒤 자동 검사로 규칙 위반을 찾게 합니다.
  5. 눈 검사로 화면을 직접 보며 어색한 곳을 고칩니다.
  6. 숫자 검산으로 모든 숫자가 원본 데이터 출처와 맞는지 확인하게 합니다.
  7. 고친 내용을 규칙서·스킬에 다시 반영합니다.
  • 색상표는 Open Color, 아이콘은 Lucide, 도식은 Mermaid 같은 오픈소스를 쓰면 품질이 올라갑니다.
  • 초보자는 Adobe Acrobat의 PDF 스페이스에 자료(최대 100개 파일)를 넣어 PPT 초안을 만들고 PPTX로 내려받을 수 있습니다. 요약 속 숫자를 누르면 원문 근거가 표시됩니다.
  • 클로드 Slides·Designs에서는 폰트·컬러·자간 같은 브랜드 규칙을 디자인 시스템으로 묶어 쓸 수 있습니다.
  • 근거가 없는 내용은 '확인 필요'로 표시해 달라고 요청해 두면 검산이 쉬워집니다.

10. Slack 채널에서 Claude Tag 쓰기

Claude Tag는 Slack 채널에 Claude를 추가해 팀 대화를 따라가며 일하게 하는 기능입니다. 채팅 창을 오가거나 맥락을 복사할 필요 없이 채널에서 바로 정보 정리·문서 초안·도구 내 수정을 맡길 때 씁니다.

  1. Claude를 쓸 Slack 채널 하나에 Claude를 추가합니다.
  2. Google Drive, Asana 같은 필요한 도구를 연결합니다.
  3. 채널이나 스레드에서 Claude를 태그해 작업을 요청합니다.
  4. 진행 상황은 채널에서 확인하고, 기다리지 말고 다른 일을 하다가 완료·결정 요청 알림이 오면 답합니다.
  5. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
  6. 매번 태그하기 번거로우면 항상 응답하도록 지시하고, 개입이 너무 잦거나 드물면 빈도를 조정해 달라고 말합니다.
예시
최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • Team·Enterprise 요금제에서 베타로 제공됩니다. 처음에는 한 채널에서만 시작해 보세요.
  • Claude는 자체 계정으로 일하며 모든 변경과 요청자를 기록합니다. 대신 응답하거나 개별 도구에 접근할 때는 매번 권한을 묻습니다.
  • DM과 비공개 채널에서 배운 내용은 그 안에만 남습니다. 프로젝트 상태를 추적하려면 공개 채널이 좋습니다.
  • 스타일 가이드나 체크리스트 문서를 알려 주면 참고하며, 문서가 바뀌면 기본적으로 최신 내용을 따릅니다.

11. Claude Code 루틴으로 작업 예약하기

루틴은 프롬프트·저장소·커넥터·트리거만 정하면 Anthropic 관리형 인프라에서 Claude Code 세션을 자동 실행하는 기능입니다. 노트북을 닫아도 돌아가므로 매주 문서 갱신 같은 정기 작업이나 GitHub 이벤트에 반응하는 작업에 씁니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문에 답합니다(예: 매주 몇 시에 실행할지, 끝나면 Slack으로 알릴지).
  4. 작업에 필요한 저장소를 컨텍스트로 연결합니다.
  5. 만들어진 루틴을 웹의 Claude Code에서 확인합니다.
  6. 실행 결과 세션을 열어 보고, 필요하면 그 세션에서 이어서 지시합니다.
예시
/schedule 매주 main에 병합된 변경을 문서 저장소와 비교해서, 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 루틴을 만들기 전에 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 트리거는 일정 기반과 GitHub 이벤트·웹훅 같은 이벤트 기반이 있습니다.
  • Claude Code Projects(베타, Pro·Max 순차 제공)에서는 한 프로젝트 안에서 매일 도는 루틴을 설정하고, 클라우드 브랜치에서 도는 스레드로 병렬 작업을 맡길 수 있습니다.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 더 많은 권한을 맡깁니다.

12. 확인 지점과 종료 조건 설계하기

여러 자동화를 동시에 돌리면 사람이 일일이 확인하느라 병목이 됩니다. 어디서 사람이 확인할지, 언제 멈출지를 미리 정해 두면 AI가 혼자 오래 일해도 안전하게 결과를 받을 수 있습니다(Human on the loop).

  1. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  2. 에이전트에게 맡길 일에는 가능한 한 넉넉한 권한을 줍니다.
  3. 메일 발송·캐릭터 생성처럼 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 정합니다.
  4. 크레딧처럼 한 번에 크게 나가는 비용에는 상한을 정합니다.
  5. 종료 조건을 검증 통과·최대 반복 횟수·시간/비용 한도·진전 없으면 중단으로 겹쳐 겁니다.
  6. 진행 상황을 적는 상태 파일을 두어 다음 실행이 이어받게 합니다.
  7. 만드는 AI와 검사하는 AI를 분리합니다(예: Claude가 쓴 것은 Codex가, Codex가 쓴 것은 Claude가 검증).
  8. 결과 반응 데이터를 보고 규칙과 스킬을 고칩니다.
  • 영상 속 크레딧 상한(쇼츠 500, 롱폼 1,500)은 제작자 본인의 값이므로 내 요금제에 맞게 정합니다.
  • 종료 조건은 누가 봐도 참/거짓을 판정할 수 있어야 합니다. 자기 결과를 검사하게 하면 관대해지기 쉽습니다.
  • 폭주하는 프로세스에 대비해 서킷 브레이커(자동 차단 장치)를 둡니다.
  • 반복 업무는 루프·루틴으로, 단계를 미리 알 수 없는 일은 동적 워크플로로 나눠 맡깁니다.
