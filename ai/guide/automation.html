1. Cowork로 폴더 업무 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세우고 파일을 읽어 엑셀·워드 같은 결과물을 만들어 주는 도구입니다. 파일 정리, 자료 취합, 보고서 초안처럼 범위가 분명한 일을 한 번에 위임할 때 씁니다.

  1. Claude 데스크톱 앱을 열고 Cowork(또는 협업) 탭을 누릅니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 골라 접근을 허용합니다(항상 허용).
  3. 필요하면 커넥터를 연결해 Google Drive·Notion·Slack 같은 서비스에서 맥락을 가져오게 합니다.
  4. 작업을 말로 설명하고 변경 전에 계획을 먼저 보여 달라고 요청합니다.
  5. Claude가 제안한 계획을 읽고, 고치고 싶은 부분은 수정을 지시합니다.
  6. 승인하면 오른쪽 위에서 진행 상황을 확인합니다.
  7. 완성된 파일을 지정한 폴더에서 열어 내용을 직접 검토합니다.
예시
Organize my downloads folder. Scan the contents and propose a plan.
  • 처음에는 정리처럼 범위가 분명한 작업부터 시작하고 결과를 항상 검토하세요.
  • 원본을 건드리지 않으려면 '원본은 그대로 두고 정리본은 새 파일로 저장'이라고 프롬프트에 적으세요.
  • Settings의 Cowork 탭에서 내 역할이나 선호 파일 형식 같은 전역 지침을 정해 두면 매번 설명하지 않아도 됩니다.
  • 웹·모바일 버전은 로컬 파일 접근과 컴퓨터 조작이 안 되므로 그런 작업은 데스크톱 앱에서 하세요.

2. 보고서 포맷을 스킬로 고정하기

스킬은 반복 업무의 양식과 규칙을 저장해 두고 필요할 때 불러 쓰는 기능입니다. 매번 같은 형식의 보고서가 나오게 하고 싶을 때 씁니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 스킬을 선택하고 주제를 적어 요청합니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 스타일·강조·폰트·섹션 구성 같은 디자인 규칙도 함께 설명해 두면 포맷이 더 일정해집니다.
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • AI 티가 나는 문장은 별도 교정 스킬로 다듬되 본인 스타일에 맞게 고쳐 쓰고, 중요한 문서는 직접 읽고 고치세요.

3. Cowork 예약 작업으로 반복 업무 돌리기

예약 작업은 정한 주기에 Claude가 업무를 자동으로 실행하는 기능입니다. 아침 메일 정리, 주간 지표 리포트, 폴더 변경 요약처럼 매번 같은 방식으로 하는 일에 씁니다.

  1. 반복할 일을 자연어로 설명하거나 입력창에 /schedule을 입력합니다.
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 주기를 매시간·매일·평일·수동 중에서 확인하고 필요하면 바꿉니다.
  4. 내용이 맞으면 제안을 수락합니다.
  5. 사이드바의 예약 페이지에 작업이 추가된 것을 확인합니다.
  6. 지난 실행 기록을 확인하고 필요하면 지시문·주기를 고치거나 바로 실행해 봅니다.
예시
매시간 공유 드라이브 폴더에서 추가·수정된 문서를 확인하고, 변경한 사람을 기록하고, 요약해서 클라이언트별로 묶어 문서로 저장해 줘.
  • 이미 설정한 커넥터는 예약 작업에서도 쓸 수 있고, 실행마다 새 세션으로 최신 파일 기준으로 돕니다.
  • 2026년 7월 업데이트 이후 클라우드에서 돌아 기기가 꺼져 있어도 실행된다고 소개되었습니다. 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행되며, 놓친 작업은 복귀 후 바로 실행됩니다.
  • 처음 몇 번은 결과를 직접 확인하고, 신뢰가 쌓이면 맡기는 범위를 넓히세요.

4. Cowork로 회의 준비·후속 처리하기

캘린더, Slack, 이메일, 지난 회의록을 모아 회의 전 브리핑을 만들고, 회의 후에는 할 일과 후속 메시지까지 정리하는 흐름입니다. 영업·법무·마케팅처럼 흩어진 정보를 모아야 하는 업무에 맞습니다.

  1. 캘린더, Slack, 이메일을 Claude에 연결합니다.
  2. 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 회의와 시간을 알려 주고, 참석자 조사·Slack 스레드 확인·이전 회의록 검토·안건 작성을 요청합니다.
  4. 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  5. Claude가 세운 계획을 확인하고, 빠뜨린 출처가 있으면 작업 중에 추가로 요청합니다.
  6. 완성된 안건 문서를 작업 폴더에서 열어 검토합니다.
  7. 회의 후 통화 녹취록 처리 같은 스킬을 /로 불러 할 일, 내부 메시지, 고객 후속 메시지를 만들고 승인 후 발송합니다.
예시
Prep me for today's call with Acme Corp at 1PM.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 이름을 걸고 보내는 답장이나 메시지는 근거를 원문에서 확인하고 승인한 뒤 보내세요.
  • 스킬은 일반 텍스트 파일이라 열어서 동작을 확인하고 고칠 수 있으며, 처음에는 테스트 계정으로 돌려 보세요.

5. 플러그인으로 직무별 업무 시작하기

플러그인은 스킬·커넥터·슬래시 명령을 직무별로 묶은 패키지입니다. 세일즈, 제품 관리, 마케팅처럼 직무에 맞는 명령을 바로 쓰고 싶을 때 설치합니다.

  1. 좌측 상단에서 Claude 설정을 열고 협업 탭의 지침 편집에서 내 역할과 작업 스타일을 적어 저장합니다.
  2. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  3. 플러그인 추가에서 원하는 플러그인을 설치합니다.
  4. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  5. 입력창에 슬래시 명령을 입력하고 회사명·목적 같은 필요한 정보를 적어 시작합니다.
  • 글로벌 지침은 모든 코워크 세션에 적용되어 매번 자기소개를 하지 않아도 됩니다.
  • 명령어 이름은 영상 자막이 불분명하므로 플러그인 관리 화면에서 정확한 표기를 확인하세요.
  • 플러그인은 회사 플레이북에 맞게 수정할 수 있습니다.

6. 구글·ChatGPT 에이전트로 메일 브리핑 받기

Claude 말고도 제미나이 스파크와 ChatGPT Work 같은 에이전트에 메일 정리, 회의록 정리, 주간 자동 실행을 맡길 수 있습니다. 이미 구글 워크스페이스나 ChatGPT를 쓰는 직장인이 같은 방식을 따라 할 때 유용합니다.

  1. 제미나이에서 좌측 상단 스파크 베타 탭을 열고, 설정의 연결된 앱에서 구글 워크스페이스가 켜져 있는지 확인합니다.
  2. 이번 주 캘린더와 Gmail에서 답장 안 한 메일을 확인해 우선순위 브리핑 문서를 만들어 달라고 요청합니다.
  3. 주기 작업은 프롬프트에 실행 시점(예: 매주 월요일 오전 8시)을 적어 요청합니다.
  4. 메일 요약은 발송하지 말고 이메일 초안으로 남기도록 지시합니다.
  5. 좌측 일정 탭에서 등록된 일정을 확인합니다.
  6. ChatGPT를 쓴다면 데스크탑 앱에서 Work 모드를 선택하고 회의록 파일을 첨부해 담당자·할 일·마감 열의 시트를 요청합니다.
예시
지난 7일간 Gmail의 뉴스레터·업무 보고 메일을 구글 시트에 정리하고, 핵심 요약 5개를 이메일 초안으로 작성하되 발송하지 말고 초안으로 남겨 줘.
  • 발송하지 말고 초안으로 남기게 하면 안전합니다.
  • 스파크는 구글 AI 프로 이상 구독이 필요합니다.
  • 복잡한 작업은 ChatGPT Work의 계획 모드(입력창 + 버튼)를 켜면 모호한 부분을 먼저 물어봐 더 구체적인 결과가 나옵니다.

7. Slack 채널에서 Claude Tag에게 일 시키기

Claude Tag는 Slack 같은 팀 채널에 Claude를 추가해 대화를 따라가며 일하게 하는 기능입니다. 정보 정리, 문서 초안, 도구 수정을 채널에서 바로 맡기고 싶을 때 씁니다.

  1. Claude를 사용할 채널 하나에 추가합니다.
  2. 필요한 도구를 Claude Tag에 연결합니다.
  3. 작업이 필요한 스레드에서 Claude를 태그해 요청합니다.
  4. Claude가 진행하는 상황을 채널에서 확인하고 다른 일을 합니다.
  5. 완료 또는 입력 요청 알림이 오면 확인하고 답합니다.
  6. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
예시
최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 작성해 줘.
  • 처음에는 한 채널에서만 시작해 보세요.
  • Team과 Enterprise 요금제에서 베타로 제공되며, DM과 비공개 채널의 내용은 그 안에만 남습니다.
  • 너무 자주 또는 드물게 개입하면 개입 빈도를 조정해 달라고 말하면 됩니다.
  • Claude가 사용자를 대신해 응답하거나 개별 도구에 접근할 때는 매번 권한을 묻습니다.

8. Claude Code 루틴으로 자동 실행하기

루틴은 프롬프트, 저장소, 커넥터, 트리거를 정하면 관리형 인프라에서 원격 Claude Code 세션이 자동 실행되는 기능입니다. 노트북을 닫아도 돌아가며 개발 문서 갱신 같은 정기 작업에 맞습니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문(실행 시각, 알림 여부 등)에 답합니다.
  4. 소스 코드 저장소와 문서 저장소를 컨텍스트로 연결합니다.
  5. 만들어진 루틴을 웹의 Claude Code에서 확인하고 실행 결과 세션을 열어 봅니다.
예시
/schedule 매주 main에 병합된 변경을 문서 저장소와 비교해서 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 트리거는 일정 기반과 GitHub 이벤트·웹훅 같은 이벤트 기반이 있습니다.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 더 많은 권한을 맡기세요.
  • Claude Code Projects(베타, Pro·Max)를 쓰면 한 프로젝트 안에서 매일 도는 루틴과 병렬 스레드를 함께 관리할 수 있습니다.

9. Codex 자동화와 Record & Replay 쓰기

OpenAI Codex에서는 매일 아침 브리핑 같은 자동화를 채팅으로 만들 수 있고, 화면 녹화로 반복 작업을 스킬로 만드는 Record & Replay도 있습니다. 코드를 모르는 상태에서 반복 작업을 자동화하고 싶을 때 씁니다.

  1. 플러그인 탭에서 Slack과 구글 캘린더를 미리 연결합니다.
  2. 좌측 상단 자동화 탭을 열고 우측 상단 채팅으로 만들기를 누릅니다.
  3. 자동화용 새 프로젝트를 만들어 둡니다.
  4. Codex의 질문에 맞춰 캘린더 일정을 Slack으로 브리핑하고 매일 오전 9시에 실행하도록 답합니다.
  5. 자동화가 액티브 상태로 생성된 것을 확인합니다.
  6. 화면 녹화 방식은 컴퓨터 유즈와 레코드 앤 리플레이 플러그인을 차례로 설치하고, 설정의 사용해 보기로 켠 뒤 평소 작업을 수행하고 정지 버튼을 눌러 스킬을 만듭니다.
예시
구글 캘린더 일정을 가져와서 Slack으로 브리핑해 줘. 매일 오전 9시에 실행해 줘.
  • 플러그인 연결을 먼저 해 두지 않으면 자동화가 동작하지 않습니다.
  • Record & Replay는 현재 macOS에서만 사용할 수 있습니다.
  • 녹화 전에 구글 계정은 미리 로그인해 두고 로그인 화면은 녹화에 넣지 않는 것이 안전합니다.

10. 제미나이 Gems로 반복 업무 저장하기

Gems는 역할과 지침을 미리 저장해 두는 나만의 AI 비서입니다. 이메일, 대본, 보고서처럼 반복되는 글쓰기를 주제만 넣고 맡기고 싶을 때 쓰며 무료 계정으로도 만들 수 있습니다.

  1. 제미나이 왼쪽의 Gems에서 새 잼을 누릅니다.
  2. 이름에 구분하기 쉬운 이름(예: 월간 회의록 작성)을 적습니다.
  3. 요청 사항에 역할, 할 일, 배경 정보, 결과 형식을 적습니다.
  4. 작성이 어려우면 제미나이에게 요청 사항을 만들어 달라고 하고, 내 기존 글 파일을 첨부해 분석시킵니다.
  5. 나온 요청 사항을 읽고 고친 뒤 붙여 넣습니다.
  6. 저장하고 오른쪽 미리보기에서 주제를 입력해 테스트합니다.
예시
주제만 주면 대본을 써 주는 Gem의 요청 사항을 만들어 줘. 첨부한 내 기존 대본의 말투와 구성을 분석해서 반영해 줘.
  • 요청 사항이 부실하면 결과가 잘 안 나옵니다.
  • 설명란은 비워도 되고, 참고 파일이 있으면 지식에 추가합니다.

11. n8n으로 노코드 자동화 만들기

n8n은 노드(작업 블록)를 연결해 자동화 시나리오를 만드는 도구입니다. Slack·구글 시트·메일 같은 서비스를 이어 정형화된 반복 업무를 돌릴 때 쓰며, AI 워크플로우 빌더로 한국어 요청만으로 초안을 만들 수도 있습니다.

  1. n8n 클라우드에 가입하고 Create Workflow로 새 워크플로우를 만듭니다.
  2. Add first step에서 트리거(예: On chat message)를 선택합니다.
  3. + 버튼으로 AI Agent 노드를 추가하고 Chat Model과 시스템 메시지를 설정합니다.
  4. Simple Memory를 추가해 이전 대화를 기억하게 합니다.
  5. 구글 시트를 Tool로 추가하고 Sign in with Google로 연결합니다.
  6. 또는 빌드 위드 AI를 눌러 자동화할 내용을 구체적으로 적고, 만들어진 각 노드의 설정을 확인합니다.
  7. API 키와 OAuth 인증은 직접 연결한 뒤, 테스트 데이터로 실행해 동작을 확인합니다.
예시
슬랙 채널에 '긴급'이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일을 발송해 줘.
  • AI 빌더는 베타 기능이고 프롬프트 한 번에 1크레딧이 들며 n8n 클라우드에서만 쓸 수 있습니다.
  • 기본 흐름 → 테스트 → 기능 추가 → 예외 처리 순으로 단계적으로 만들고, 요구 사항은 한 번에 묶어 요청하면 크레딧을 아낍니다.
  • 정형화된 반복 작업은 n8n, 판단이 필요한 챗봇형 작업은 OpenAI Agent Builder가 낫다고 합니다.
  • 도커로 직접 설치하는 방식은 개발에 익숙하지 않으면 추천하지 않습니다.

12. 내 업무 파이프라인과 개입 지점 설계하기

반복 콘텐츠 제작이나 보고서 작업을 기획부터 검수·업로드까지 하나의 파이프라인으로 묶고, 사람이 병목이 되지 않도록 확인 지점을 설계하는 방법입니다. 에이전트에게 많은 일을 맡기되 되돌리기 어려운 지점만 직접 확인하고 싶을 때 씁니다.

  1. 업무를 기획·리서치, 대본(초안), 제작, 검수, 패키징, 업로드 같은 단계로 나눕니다.
  2. 단계마다 반복되는 규칙(컷 편집, 말투, 형식)을 스킬로 만들어 둡니다.
  3. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  4. 에이전트에 가능한 한 많은 권한을 주되, 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  5. 캐릭터 생성처럼 되돌리기 어려운 지점은 다음 단계로 가기 전에 내 확인을 받도록 정합니다.
  6. 한 AI가 만든 결과를 다른 AI가 독립적으로 검증하게 하는 검수 단계를 넣습니다.
  • 상한 숫자(예: 쇼츠 500, 롱폼 1,500 크레딧)는 영상 제작자 본인의 값이므로 내 요금제에 맞게 정하세요.
  • 남의 자료를 가공할 때는 AI가 던지는 질문에 내 의견을 답하는 인터뷰 단계를 넣어야 차별점이 생깁니다.
  • 가장 번잡한 업무 하나를 골라 '지금도 필요한가, AI로 줄일 수 있는가'를 먼저 점검하는 것이 좋습니다.
  • 종료 조건은 누가 봐도 참/거짓을 판정할 수 있게 정하고, 만드는 AI와 검사하는 AI를 분리하면 자기 결과에 관대해지는 문제를 줄일 수 있습니다.
