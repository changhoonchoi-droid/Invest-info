업무 자동화·에이전트

업무 자동화·에이전트 분야에서는 메일 브리핑, 보고서 작성, 파일 정리, 회의 준비 같은 반복 업무를 AI에게 맡기고 정해 둔 시각에 자동으로 실행하게 만들 수 있습니다. 먼저 Cowork로 폴더 업무를 맡기는 법을 익히고, 스킬로 형식을 고정한 뒤, 커넥터와 예약 작업으로 자동 실행까지 이어 가는 순서를 권합니다. 익숙해지면 노코드 자동화 도구나 팀 채널 에이전트, 루틴으로 범위를 넓혀 보세요.

  • Claude Code Projects(베타)는 작업마다 클라우드의 별도 브랜치에서 스레드를 병렬로 돌려, 노트북을 닫아도 일이 이어지고 휴대폰으로 확인할 수 있습니다.

1. Cowork로 폴더 업무 맡기기

Cowork는 폴더를 열어 주면 AI가 계획을 세워 파일을 읽고 엑셀·워드 같은 결과물을 만들어 주는 기능입니다. 영수증 정리, 자료 모아 보고서 만들기, 지저분한 엑셀 정리처럼 파일 중심 업무에 씁니다. 예약 작업의 바탕이 되는 기본기이므로 가장 먼저 익힙니다.

  1. Claude 데스크톱 앱을 열고 Cowork(또는 협업) 탭을 누릅니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 골라 접근을 허용합니다(항상 허용).
  3. 정리할 자료(회의록, 엑셀, 메모 등)를 그 폴더에 넣습니다.
  4. 원하는 결과물과 규칙을 한 번에 적어 요청하고, 변경 전에 계획을 보여 달라고 합니다.
  5. 제안된 계획을 확인하고 필요하면 수정을 지시한 뒤 승인합니다.
  6. 진행 상황을 지켜보고, 완성된 파일을 지정한 폴더에서 열어 내용을 검토합니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘. 원본 파일은 그대로 두고 결과는 새 파일로 저장해 줘.
  • 처음에는 폴더 정리처럼 범위가 분명한 작업부터 시작하고 결과를 항상 검토합니다.
  • 원본 보존은 프롬프트에 반드시 적어 둡니다.
  • 웹 버전은 로컬 파일 접근과 컴퓨터 조작이 안 되므로 파일 작업은 데스크톱 앱에서 합니다.
  • Settings의 Cowork 탭에서 역할 설명 같은 전역 지침을 정해 두면 매번 설명하지 않아도 됩니다.

2. 스킬로 보고서 형식 고정하기

스킬은 반복 업무의 양식과 작업 규칙을 저장해 두는 기능입니다. 한 번 만들어 두면 같은 형식과 품질로 보고서를 계속 받을 수 있어 매번 긴 지시를 쓰지 않아도 됩니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 그 형식을 분석해 보고서용 스킬을 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 다음부터 /와 스킬 이름을 입력해 스킬을 고르고 주제를 적어 요청합니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
  6. 결과가 어긋나면 어떤 점이 달랐는지 말해 스킬을 고치게 합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 브랜드 컬러, 폰트, 섹션 구성까지 설명해 스킬이나 메모리로 저장하면 매번 같은 포맷이 나옵니다.
  • AI 티가 나는 문장은 전용 스킬로 다듬되, 중요한 문서는 직접 읽고 고칩니다.

3. 커넥터로 메일 브리핑 예약하기

Gmail 같은 서비스를 Claude에 연결하고 브리핑을 예약 작업으로 등록하면 매일 아침 메일과 일정을 정리해 받을 수 있습니다. 출근 직후 확인할 일을 빠르게 파악하고 싶을 때 씁니다.

  1. 클로드 데스크톱에서 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail 또는 Microsoft 365를 선택해 클로드에 연결하고 계정을 고릅니다.
  3. + → 커넥터에서 연결 표시(파란 불)를 확인합니다.
  4. 어제 오후 6시 이후 메일과 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  5. 같은 내용을 아침 7시 50분마다 실행하는 예약 작업으로 등록해 달라고 요청합니다.
  6. 좌측 예약됨에서 스케줄을 확인합니다.
예시
어제 오후 6시 이후에 온 메일과 오늘 캘린더 일정을 보고, 답장이 필요한 순서대로 브리핑을 만들어 줘. 이 작업을 매일 아침 7시 50분에 실행하도록 예약해 줘.
  • 예약 작업은 유료 플랜에서만 쓸 수 있습니다.
  • 서버 실행 여부는 앱 버전에 따라 다르니, 처음에는 예약됨에서 실행 기록을 확인합니다. 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행되었습니다(최근 영상 기준으로는 클라우드에서 돌아 컴퓨터를 꺼도 실행됩니다).
  • 자동으로 발송하지 말고 초안으로 남기게 하면 안전합니다.

4. Cowork 예약 작업 만들기

반복하는 일을 자연어로 설명해 두면 정해진 주기에 Claude가 자동으로 실행합니다. 주간 리포트, 폴더 모니터링, 정기 리서치처럼 매번 같은 절차로 하는 업무에 씁니다.

  1. 반복할 일을 자연어로 설명합니다(예: 매시간 공유 폴더의 추가·수정 문서 확인 후 요약).
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  4. 내용이 맞으면 제안을 수락합니다.
  5. 왼쪽 사이드바의 예약 페이지에 작업이 추가된 것을 확인합니다.
  6. 설정 후 한 번 직접 실행해 제대로 되는지 확인합니다.
예시
매주 수요일 아침에 AI 트렌드를 리서치해서 유튜브 아이디어 5개를 제안해 줘.
  • 실행마다 새 세션으로 돌아 최신 파일과 도구 상태를 기준으로 합니다.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있습니다.
  • 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행이 가능합니다.
  • 예전 방식: 컴퓨터를 꺼 두면 놓친 작업이 복귀 후 실행되었으나, 7월 업데이트 이후 클라우드 실행이 가능해졌다고 소개됩니다.

5. 플러그인으로 직무별 업무 맡기기

플러그인은 스킬, 커넥터, 슬래시 명령을 직무별로 묶은 패키지입니다. 영업, 제품 관리, 마케팅처럼 정해진 흐름의 업무를 명령 한 줄로 시작하고 싶을 때 씁니다.

  1. 설정의 협업 탭에서 지침 항목의 편집을 눌러 내 역할과 작업 스타일을 적고 저장합니다.
  2. 코워크 메인 화면에서 + → 플러그인을 선택합니다.
  3. 플러그인 추가에서 필요한 플러그인(세일즈, 제품 관리, 마케팅 등)을 설치합니다.
  4. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  5. 입력창에 슬래시 명령을 입력하고 회사명·목적 같은 필요한 정보를 적어 시작합니다.
  • 영상에서 명령어 이름은 자막이 불분명하니 정확한 표기는 플러그인 관리 화면에서 확인하세요.
  • 플러그인은 오픈 프로토콜이라 회사 플레이북에 맞게 고쳐 쓸 수 있습니다.

6. 미팅 전후 업무를 스킬로 처리하기

캘린더·Slack·이메일 등 흩어진 정보를 스킬 하나로 모아 회의 준비 문서를 만들고, 미팅 뒤에는 녹취록으로 후속 메시지까지 만드는 흐름입니다. 몇 시간 걸리던 준비를 몇 분으로 줄이고 싶을 때 씁니다.

  1. 캘린더, Slack, 이메일 등 필요한 도구를 Claude에 연결합니다.
  2. 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 미팅 전에 알고 싶은 내용을 설명해 스킬 파일 초안을 만듭니다.
  4. 테스트용 계정으로 스킬을 돌려 결과를 보고 다듬습니다.
  5. 미팅 전 /를 입력해 스킬을 고르고 회의 상대와 시간을 알려 브리핑을 받습니다.
  6. 미팅 후 녹취록 처리 스킬로 할 일, 내부 메시지, 고객 후속 메시지를 만들게 합니다.
  7. 각 결과를 확인하고 승인한 뒤 발송합니다.
예시
Prep me for today's call with Acme Corp at 1PM.
  • 발송 전에 항상 승인 단계를 거쳐 내용을 확인합니다.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 이름을 걸고 보내는 답장이므로 브리핑의 근거를 원문에서 직접 확인합니다.

7. ChatGPT Work·Gemini 스파크로 자동화하기

Claude 외에도 ChatGPT Work와 제미나이 스파크가 예약 작업과 문서·시트 작업을 지원합니다. 이미 쓰는 구독이나 구글 업무 환경에 맞춰 골라 쓰면 됩니다.

  1. ChatGPT는 데스크탑 앱에서 Work 모드를, 제미나이는 좌측 상단 스파크 베타 탭을 엽니다.
  2. 제미나이는 설정의 연결된 앱에서 구글 워크스페이스가 켜져 있는지 확인합니다.
  3. 회의록 등 자료를 첨부하고 담당자·할 일·마감 열의 스프레드시트처럼 결과 형태를 정해 요청합니다.
  4. 복잡한 작업은 + → 계획 모드를 켜고 Work가 던지는 질문에 답합니다.
  5. 실행 시점(예: 매주 월요일 오전 8시)을 프롬프트에 적어 예약합니다.
  6. 제미나이는 좌측 일정 탭에서 등록된 일정을 확인합니다.
예시
지난 7일간 Gmail의 뉴스레터·업무 보고 메일을 구글 시트에 정리하고, 핵심 요약 5개를 이메일 초안으로 작성하되 발송하지 말고 초안으로 남겨 줘. 매주 월요일 오전 8시에 실행해 줘.
  • 제미나이 스파크는 구글 AI 프로 이상 구독이 필요하고, 데스크탑 앱은 영상 기준 macOS만 지원합니다.
  • 추론 수준은 미디엄에서 시작해 결과가 부족하면 올립니다.
  • 발송은 하지 말고 초안으로 남기게 하면 안전합니다.

8. n8n으로 노코드 자동화 만들기

n8n은 노드(작업 블록)를 연결해 자동화 시나리오를 만드는 도구입니다. 슬랙·노션·구글 시트·메일을 엮은 반복 업무나 FAQ 챗봇을 만들 때 씁니다. 빌더에 한국어로 요청하면 노드 구성을 AI가 대신해 줍니다.

  1. n8n 클라우드에 가입하고 대시보드에서 Create Workflow로 새 워크플로우를 만듭니다.
  2. 가운데의 빌드 위드 AI 또는 우측의 n8n AI에서 빌드를 선택하고 자동화할 내용을 구체적으로 적습니다.
  3. 만들어진 각 노드(트리거, 필터, 앱 액션)를 눌러 설정을 확인합니다.
  4. 수정이 필요하면 입력창에 요청을 추가합니다.
  5. API 키와 OAuth 인증 정보는 직접 연결합니다.
  6. 테스트 데이터로 실행해 동작을 확인한 뒤 실제로 사용합니다.
예시
슬랙 채널에 긴급이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일 발송해 줘
  • 프롬프트 한 번에 1크레딧을 쓰므로 여러 요구를 한 번에 요청하면 아낄 수 있습니다.
  • 기본 흐름 → 테스트 → 기능 추가 → 예외 처리 순으로 단계적으로 만듭니다.
  • AI 빌더는 베타이며 n8n 클라우드에서만 쓸 수 있습니다.
  • 오류가 나면 /clear로 초기화한 뒤 다시 시도합니다.

9. Slack에서 Claude Tag로 일 맡기기

Claude Tag는 팀 채널에 Claude를 추가해 대화 맥락을 보며 일하게 하는 기능입니다. 채널에서 바로 요청하고 결과를 받으며, 채널별 지침을 기억해 반복 업무에 쓸 수 있습니다. Team·Enterprise 계정에서 베타로 제공됩니다.

  1. Claude를 사용할 Slack 채널 하나에 추가합니다.
  2. 필요한 도구(Google Drive, Asana 등)를 Claude Tag에 연결합니다.
  3. 채널에서 Claude를 태그해 작업을 요청합니다.
  4. 진행 상황을 채널에서 확인하고, 완료나 결정 요청 알림이 오면 답합니다.
  5. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
  6. 너무 자주 또는 드물게 개입하면 개입 빈도를 조정해 달라고 말합니다.
예시
최근 3일 스레드와 Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • 처음에는 한 채널에서만 시작해 보세요.
  • 채널별 접근 권한이 나뉘어 있고, DM과 비공개 채널의 내용은 그 안에만 남습니다.
  • Claude가 사용자를 대신해 응답하거나 개별 도구에 접근할 때는 매번 권한을 묻습니다.
  • 프로젝트 상태를 추적하려면 공개 채널이 좋습니다.

10. Claude Code 루틴으로 자동 실행하기

루틴은 프롬프트, 저장소, 커넥터, 트리거를 정하면 Anthropic 관리형 인프라에서 Claude Code 세션을 자동 실행하는 기능입니다. 노트북을 닫아도 돌아가며 일정 기반이나 GitHub 이벤트 기반으로 시작할 수 있습니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문(실행 시각, 알림 방식 등)에 답합니다.
  4. 필요한 저장소를 컨텍스트로 연결합니다.
  5. 만들어진 루틴을 웹의 Claude Code에서 확인하고 실행 결과 세션을 열어 봅니다.
예시
매주 main에 병합된 변경을 문서 저장소와 비교해서 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 권한을 더 맡기세요.
  • Claude Code Projects(베타)를 쓰면 여러 스레드를 병렬로 돌릴 수 있습니다.

11. 콘텐츠 제작 파이프라인 자동화하기

기획·리서치부터 대본, 음성, 편집, 업로드까지 이어지는 반복 제작 과정을 스킬과 파이프라인으로 묶는 방법입니다. 영상이나 카드뉴스를 꾸준히 만드는 1인 제작자에게 맞습니다.

  1. 기획·리서치, 대본, 음성, 모션, 검수, 패키징, 업로드 단계로 파이프라인을 나눕니다.
  2. 유튜브·X·인스타 등 레퍼런스 계정을 수집 대상으로 정하고 매일 아침 일정에 모읍니다.
  3. 조회수·댓글 수가 기준을 넘은 게시물만 골라 카드뉴스나 롱폼으로 만듭니다.
  4. 남의 영상은 번역만 하지 않고, Claude가 던지는 질문에 내 소감을 답하는 인터뷰로 내 해석을 더합니다.
  5. Claude가 만든 것은 Codex가, Codex가 만든 것은 Claude가 독립적으로 검증하게 합니다.
  6. 피드백을 줄 때마다 스킬이나 규칙으로 남기고, 크레딧처럼 크게 나가는 것은 상한을 정합니다.
  7. 되돌리기 어려운 지점(캐릭터 생성 등)은 내 확인을 받도록 정합니다.
예시
이 영상으로 롱폼을 만들어 보자. 영상을 본 사람이 궁금해할 질문을 뽑아서 나를 인터뷰해 줘. 내 답변을 바탕으로 롱폼 대본을 만들어 줘.
  • 상한 숫자(쇼츠 500, 롱폼 1,500)는 영상 제작자 본인의 값이므로 내 요금제에 맞게 정해야 합니다.
  • 업로드까지 완전 자동화하지 않는 경우도 있습니다. 인기 음악은 앱에서만 넣을 수 있기 때문입니다.
  • 검수 없이 올리지 말고, 아는 지식 범위에서만 올립니다.
