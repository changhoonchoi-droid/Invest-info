업무 자동화·에이전트

이 분야에서는 Claude Cowork·예약 작업·루틴 같은 도구로 메일 브리핑, 보고서 작성, 폴더 정리, 영상·콘텐츠 제작 같은 반복 업무를 자동화하고, 더 나아가 에이전트를 설계하는 방법까지 다룹니다. 먼저 폴더로 일을 맡기는 Cowork 기초를 익히고, 커넥터와 예약 작업, 스킬로 반복 업무를 굳힌 뒤, 마지막으로 사람의 개입 지점을 설계하는 에이전트 설계로 넘어가면 좋습니다. 같은 일을 하는 ChatGPT Work, 제미나이 스파크, n8n 같은 대안도 뒤쪽에 정리했습니다.

  • Claude Data, Whiteboards, Sheets와 인터랙티브 커넥터가 업무용 기능으로 추가되었습니다(11/18).

입문

1. 코워크로 폴더 업무 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세우고 파일을 읽어 엑셀·워드 같은 결과물을 만드는 기능입니다. 영수증 정리, 흩어진 자료로 보고서 만들기, 엑셀 정리처럼 범위가 분명한 일에 먼저 쓰기 좋습니다. 유료 플랜의 데스크톱 앱에서 쓰며 웹 버전은 내 PC 파일에 접근하지 못합니다.

  1. Claude 데스크톱 앱을 열고 협업(영문 Cowork) 탭을 누릅니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 고르고 접근 권한 창에서 항상 허용을 누릅니다.
  3. 정리할 자료(회의록, 엑셀, 메모 등)를 그 폴더에 넣습니다.
  4. 원하는 결과물과 형식을 구체적으로 적어 요청합니다.
  5. Claude가 제안하는 계획을 확인하고 진행시킵니다.
  6. 오른쪽 진행 상황을 지켜보다가 완성된 파일을 폴더에서 열어 내용을 검토합니다.
  7. Settings의 Cowork 탭에서 내 역할과 선호하는 파일 형식 같은 전역 지침을 적어 두면 매번 설명하지 않아도 됩니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순서로 써 줘.
  • 처음에는 폴더 정리처럼 범위가 분명한 작업부터 시작하고 결과는 항상 검토하세요.
  • 엑셀을 정리할 때는 "원본은 그대로 두고 정리본은 새 파일로 저장해 줘"라고 반드시 적습니다.
  • 작업 중에는 데스크톱 앱을 열어 두어야 합니다.
  • 코워크는 2026년 7월 웹·모바일로 확장되었지만, 로컬 파일 접근이나 컴퓨터 조작은 데스크톱 앱에서만 됩니다.

2. 커넥터로 메일 브리핑 받기

커넥터는 Gmail·Microsoft 365·캘린더·Slack 같은 외부 서비스를 Claude에 연결하는 기능입니다. 연결하면 어제 온 메일과 오늘 일정을 모아 아침 브리핑을 만들 수 있습니다. 다음 가이드의 예약 작업과 묶으면 매일 아침 자동으로 받아 볼 수 있습니다.

  1. 클로드 데스크톱에서 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail 또는 Microsoft 365를 선택해 클로드에 연결하고 계정을 고릅니다.
  3. + → 커넥터에서 연결 표시(파란 불)가 켜졌는지 확인합니다.
  4. 어제 오후 6시 이후 메일과 오늘 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  5. 결과의 출처를 눌러 실제 메일과 일정을 확인합니다.
예시
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 확인해서, 답장이 필요한 메일을 우선순위 순으로 정리한 아침 브리핑을 만들어 줘.
  • 연결된 도구의 자료는 각 사용자의 권한 범위 안에서만 가져옵니다.
  • 답장은 바로 보내지 말고 초안으로 받아 직접 확인한 뒤 보내세요.

3. 예약 작업으로 반복 업무 자동 실행하기

예약 작업은 정해 둔 시간마다 Claude가 같은 업무를 자동으로 실행하는 기능입니다. 아침 메일 브리핑, 주간 지표 리뷰, 폴더 변경 요약처럼 매번 하는 일에 알맞습니다. 유료 플랜에서 쓸 수 있습니다.

  1. 반복할 일을 자연어로 설명합니다(예: 매일 아침 7시 50분에 메일과 일정 브리핑).
  2. 또는 입력창에 /schedule을 입력하고 작업을 적습니다.
  3. Claude가 만든 예약 작업 프롬프트 초안을 읽고 필요하면 고칩니다.
  4. 주기를 매시간·매일·평일·수동 중에서 확인하거나 바꿉니다.
  5. 내용이 맞으면 제안을 수락해 등록합니다.
  6. 왼쪽 예약됨(또는 예정된) 페이지에서 등록된 스케줄과 지난 실행 기록을 확인합니다.
  7. 처음 몇 번은 결과를 직접 확인하고 지시문을 다듬습니다.
예시
평일 아침 7시 50분마다 실행해 줘. 어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고, 답장이 필요한 메일과 오늘의 핵심 일정을 정리한 브리핑을 만들어 줘.
  • 실행 환경에 대한 설명이 영상마다 다릅니다. 최근 영상(11/15, 7/1)은 클라우드에서 돌아 컴퓨터가 꺼져 있어도 실행된다고 하고, 예전 방식: 6월 영상은 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행된다고 했습니다. 내 환경에서 한 번 확인하세요.
  • 실행마다 새 세션으로 돌아 최신 파일과 도구 상태를 기준으로 합니다.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있습니다.
  • 메일 발송 같은 외부 행동은 '초안으로 남겨 줘'라고 지시하면 안전합니다.

4. 스킬로 반복 업무 방식 고정하기

스킬은 보고서 양식, 문체, 업무 절차처럼 반복되는 작업 방식을 저장해 두는 기능입니다. 한 번 만들면 /로 불러 매번 같은 품질과 포맷의 결과를 받을 수 있습니다. 미팅 준비, 주간 리뷰, 교정 같은 업무에 널리 쓰입니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부하거나 원하는 스타일(색, 강조, 섹션 구성)을 설명합니다.
  2. 그 형식을 분석해 스킬로 만들어 달라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 선택하고 주제를 적습니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
  6. 결과가 마음에 안 들면 피드백을 스킬에 반영해 달라고 요청해 다듬습니다.
  7. 팀과 공유해 누구나 같은 결과를 내게 합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 스킬은 일반 텍스트 파일이라 언제든 열어 동작을 확인하고 고칠 수 있습니다.
  • 처음에는 테스트용 자료로 돌려 보고 다듬은 뒤 실제 업무에 쓰세요.
  • AI 티가 나는 문장은 교정용 스킬을 따로 두되, 중요한 문서는 직접 읽고 고칩니다.
  • 그날 배운 점을 스킬에 반영하게 하면 매주 조금씩 좋아집니다.

5. 플러그인으로 직무별 업무 시작하기

코워크 플러그인은 스킬, 커넥터, 슬래시 명령을 묶은 직무별 패키지입니다. 세일즈, 제품 관리, 마케팅, 법무 같은 직무의 업무 방식을 한 번에 설치해 쓸 수 있습니다. 직접 만들거나 회사에 맞게 수정할 수도 있습니다.

  1. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  2. 플러그인 추가에서 내 직무에 맞는 플러그인을 설치합니다.
  3. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  4. 입력창에 슬래시 명령을 입력하고 회사명, 목적 같은 필요한 정보를 적어 시작합니다.
  5. 나온 결과를 검토하고 회사 방식에 맞게 플러그인 내용을 수정합니다.
  • Anthropic 공식 플러그인은 11종이며 오픈 소스입니다.
  • 명령어 이름은 영상 자막이 불분명하므로 플러그인 관리 화면에서 정확한 표기를 확인하세요.
  • 미팅 전 계정 브리핑, 통화 후 후속 처리처럼 스킬을 연결해 쓰면 몇 시간 걸리던 조사가 몇 분으로 줄어든다고 소개됩니다.

6. 팀 채널에서 Claude Tag로 일 맡기기

Claude Tag는 Slack 같은 팀 채널에 Claude를 추가해, 대화 맥락을 보며 요청을 처리하게 하는 기능입니다. 복사·붙여넣기 없이 채널에서 바로 태그해 일을 시키고, 채널별 지침을 기억시킬 수 있습니다. Team·Enterprise 요금제에서 베타로 제공됩니다.

  1. Claude를 사용할 Slack 채널 하나에 추가합니다.
  2. 필요한 도구(Google Drive, Asana 등)를 연결합니다.
  3. 작업이 필요한 스레드에서 Claude를 태그해 요청합니다.
  4. Claude가 진행하는 상황을 채널에서 보거나, 다른 일을 하다 완료·결정 요청 알림을 받으면 확인합니다.
  5. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
  6. 너무 자주 또는 드물게 개입하면 개입 빈도를 조정해 달라고 말합니다.
예시
@Claude 최근 3일 스레드와 Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • 처음에는 한 채널에서만 시작하세요.
  • 채널별 접근 권한이 나뉘어 다른 채널의 시스템은 볼 수 없고, DM·비공개 채널 내용은 그 안에만 남습니다.
  • Claude가 사용자를 대신해 응답하거나 개별 도구에 접근할 때는 매번 권한을 묻습니다.
  • 프로젝트 상태를 추적하려면 공개 채널이 좋습니다.

8. 클로드 코드 루틴으로 먼저 일하게 하기

루틴은 프롬프트, 저장소, 커넥터, 트리거를 정해 두면 Anthropic 관리형 인프라에서 Claude Code 세션을 자동 실행하는 기능입니다. 노트북을 닫아도 돌고, 일정이나 GitHub 이벤트·웹훅으로 시작할 수 있습니다. 개발 환경이 있는 사람에게 맞는 단계입니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문(실행 시각, 알림 여부)에 답합니다.
  4. 필요한 저장소를 컨텍스트로 연결합니다.
  5. 만들어진 루틴을 웹의 Claude Code에서 확인하고 실행 결과 세션을 열어 봅니다.
예시
매주 main에 병합된 변경을 문서 저장소와 비교해서, 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 권한을 늘립니다.
  • 반복 업무는 루프·루틴으로, 단계를 미리 알 수 없는 일은 동적 워크플로로 나누는 것이 좋다고 소개됩니다.

9. 영상 편집·콘텐츠 제작 자동화하기

Claude Code와 스킬을 이용해 레퍼런스 영상의 스타일대로 편집하거나, 라이브 한 편에서 롱폼과 쇼츠를 뽑아 내는 자동화입니다. 기준이 되는 템플릿과 업무 매뉴얼(SOP)을 스킬로 저장하는 것이 핵심입니다. 제작 시간을 크게 줄일 수 있지만 개발 도구 설치가 필요합니다.

  1. 스타터 팩 폴더를 압축 해제하고 클로드에서 그 폴더를 선택합니다.
  2. 너는 어떻게 만들어져 있어?라고 물어 폴더 구조와 CLAUDE.md 규칙을 파악합니다.
  3. install.md에 따라 설치를 시키고, 하이퍼프레임즈·리모션 설치도 이어서 요청합니다.
  4. 새 세션을 열어 설치된 스킬이 보이게 합니다.
  5. 레퍼런스 폴더에 완성 편집본, 원본 폴더에 촬영 영상을 넣습니다.
  6. 레퍼런스를 참고해 원본을 똑같이 편집하되 애매하면 물어보라고 시킵니다.
  7. 영상 종류별 템플릿과 편집 매뉴얼(SOP)을 스킬로 저장해 반복 사용합니다.
  8. 구글 드라이브와 루틴을 연결해 1~2시간마다 폴더를 확인하게 하면 업로드만으로 편집이 시작됩니다.
예시
레퍼런스 폴더의 편집본을 참고해서 원본 폴더의 촬영 영상을 똑같은 스타일로 편집해 줘. 애매한 부분은 먼저 물어봐.
  • 레퍼런스와 촬영 방식이 비슷해야 결과가 잘 맞습니다.
  • 시간이 걸리므로 자기 전에 걸어 두면 편합니다(직접 40분 걸린 작업이 약 15분에 나왔다고 합니다).
  • 예전 방식: 2편(11/13)에서는 캡컷·프리미어 프로 같은 편집 툴과 구글 드라이브를 통해 SOP대로 편집했고 34초 영상에 약 40분이 걸렸습니다.
  • 남의 영상을 가공할 때는 번역·자막만 달지 말고 Claude의 질문에 답하는 인터뷰로 내 해석을 더하세요.

10. 사람은 위에서, 에이전트 설계하기

에이전트를 병목 없이 돌리려면 사람이 자동화 안에서 버튼을 누르는 대신 위에서 보고받고 필요할 때만 개입하는 Human on the loop 설계가 필요합니다. 목표, 트리거, 액션, 거버넌스(하지 말아야 할 일)를 정하고, 점수로 스스로 테스트하게 만드는 평가를 더합니다. 콘텐츠 자동화 같은 실무 파이프라인에도 같은 원리가 쓰입니다.

  1. 에이전트가 이룰 목표(골)를 한 문장으로 정합니다.
  2. 언제 시작할지 트리거를 정합니다.
  3. 에이전트가 할 수 있는 액션과 권한을 정하고, 하지 말아야 할 일(거버넌스)을 규칙으로 적습니다.
  4. 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  5. 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 정합니다.
  6. 내 경험과 암묵지를 점수 기준(루브릭)으로 바꿔 에이전트가 스스로 테스트하게 합니다.
  7. Claude가 쓴 것은 다른 모델이, 다른 모델이 쓴 것은 Claude가 독립적으로 검증하게 합니다.
  8. 피드백을 줄 때마다 스킬이나 규칙으로 남겨 점수를 조금씩 끌어올립니다.
  • 상한 숫자(쇼츠 500, 롱폼 1,500 크레딧)는 영상 제작자 본인의 값이므로 내 요금제에 맞게 정하세요.
  • 루프를 설계할 때는 종료 조건이 가장 중요합니다. 검증 통과, 최대 반복 횟수, 시간·비용 한도, 진전 없음 중단을 겹쳐 겁니다.
  • 만드는 AI와 검사하는 AI를 분리하면 자기 결과에 관대해지는 문제를 줄입니다.
  • AI가 95%를 해도 남은 5%의 취향·방향 판단은 사람의 몫이므로 확인 지점을 최소화하세요.

11. Managed Agents로 기억하는 에이전트 만들기

Claude Managed Agents는 샌드박스, 도구, 자격 증명 관리 같은 에이전트 인프라를 대신 맡는 개발자용 플랫폼입니다. 메모리 저장소로 세션이 끝나도 기억하게 하고, 드리밍으로 잘못 굳은 기억을 정리하며, outcome으로 기준을 줘 반복 개선하게 합니다. API를 다룰 수 있는 개발자를 위한 단계입니다.

  1. 에이전트(도구·페르소나), 환경(샌드박스), 세션(진행 중인 대화)의 세 자원을 구분해 이해합니다.
  2. 에이전트를 정의하고 실행 환경을 구성합니다.
  3. 세션을 시작하고 이벤트 스트림으로 진행을 관찰합니다.
  4. 도구별 권한을 자동 실행 또는 사용자 승인으로 나눕니다.
  5. 여러 세션에 걸쳐 기억할 내용은 메모리 저장소를 세션에 붙입니다.
  6. 결과의 기준(루브릭)을 outcome으로 주고 기준에 닿을 때까지 반복하게 합니다.
  7. 드리밍을 일정에 따라 돌려 세션 기록을 바탕으로 중복·오래된 기억을 정리합니다.
  • Outcomes·멀티 에이전트·드리밍은 연구 프리뷰 또는 베타 단계라 제공 범위를 먼저 확인하세요.
  • 메모리는 버전 관리와 변경 기록을 지원하고, 콘솔에서 직접 열어 고칠 수 있습니다.
  • 비용 절감 수단이 아직 적다는 의견이 있으므로, 강한 모델이 조정하고 작은 모델이 나눠 맡는 구성으로 관리합니다.
  • 하네스는 모델이 좋아질수록 얇아지는 추세라 주기적으로 다시 점검해야 합니다.

13. n8n으로 노코드 자동화 만들기

n8n은 노드(작업 블록)를 연결해 자동화 시나리오를 만드는 도구입니다. 슬랙·노션·구글 시트·메일 같은 서비스를 엮어 알림, 리포트 발송, FAQ 챗봇을 만들 수 있습니다. 한국어 요청으로 워크플로를 만들어 주는 AI 빌더도 있습니다.

  1. n8n 클라우드에 가입하고 대시보드에서 Create Workflow로 새 워크플로를 만듭니다.
  2. 가운데의 빌드 위드 AI 또는 우측의 n8n AI를 눌러 빌드를 선택합니다.
  3. 자동화할 내용을 트리거 시점과 처리 방식까지 구체적으로 적어 보냅니다.
  4. 만들어진 각 노드를 눌러 설정을 확인합니다.
  5. 수정이 필요하면 입력창에 요청을 적습니다.
  6. API 키와 OAuth 인증 정보는 직접 연결합니다.
  7. 테스트 데이터로 실행해 동작을 확인한 뒤 실제로 사용합니다.
