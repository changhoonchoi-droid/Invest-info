1. Cowork로 폴더 업무 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만들어 주는 기능입니다. 정리·집계·보고서처럼 범위가 분명한 문서 업무에 쓰기 좋습니다.

  1. Claude 데스크톱 앱을 열고 Cowork 탭을 누릅니다.
  2. Claude가 작업할 폴더를 선택하고 접근 권한 창에서 항상 허용을 고릅니다.
  3. 필요하면 커넥터를 연결해 Google Drive·Notion·Slack 등에서 맥락을 가져오게 합니다.
  4. 작업을 설명하고, 변경 전에 계획을 먼저 보여 달라고 요청합니다.
  5. 제안된 계획을 확인하고 고칠 부분을 말한 뒤 승인합니다.
  6. 오른쪽의 진행 상황을 보고, 완료되면 폴더에 생긴 결과 파일을 열어 내용을 확인합니다.
예시
Organize my downloads folder. Scan the contents and propose a plan.
  • 처음에는 정리처럼 범위가 분명한 작업부터 시작하고 결과를 항상 검토합니다.
  • 작업 중에는 데스크톱 앱을 열어 두어야 하며, 웹 버전은 로컬 파일 접근과 컴퓨터 조작이 안 됩니다.
  • 원본을 보존해야 하면 '정리본은 새 파일로 저장'이라고 프롬프트에 적습니다.
  • 코워크·코드·디자인은 프로 플랜(월 20달러) 이상에서 쓸 수 있습니다.

2. 흩어진 자료를 보고서로 만들기

회의록·엑셀·메모가 폴더에 흩어져 있을 때 Cowork에게 한 번에 읽고 정리하게 하는 방법입니다. 주간 현황 보고서나 설문 취합 보고서처럼 반복되는 문서 업무에 맞습니다.

  1. 데스크톱 앱에서 새로 생성을 누르고 입력창 하단에서 협업을 선택합니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 고르고 항상 허용을 누릅니다.
  3. 매출 데이터, 메모, 회의록 등 자료를 그 폴더에 복사해 넣습니다.
  4. 폴더 안의 자료를 모두 읽고 어떤 형식의 보고서를 원하는지 구체적으로 요청합니다.
  5. 계획과 실행 진행 상황을 지켜봅니다.
  6. 완성된 엑셀·워드 결과물을 열어 숫자와 내용을 확인합니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘.
  • 엑셀 여러 개를 합칠 때는 '파일명에 날짜를 넣어 정리해 달라'고 함께 요청하면 편합니다.
  • 지저분한 엑셀은 날짜 형식·빈칸·중복 행 규칙을 적고 '원본은 그대로 두고 정리본은 새 파일로 저장'하라고 요청합니다.

3. 코워크 글로벌 지침 설정하기

글로벌 지침은 모든 Cowork 세션에 공통으로 적용되는 나에 대한 설명과 작업 스타일입니다. 매번 같은 말을 반복하지 않아도 되어 결과물의 일관성이 높아집니다.

  1. 좌측 상단에서 Claude 설정을 엽니다.
  2. 협업 탭으로 이동합니다.
  3. 지침 항목의 편집 버튼을 누릅니다.
  4. 내가 어떤 사람인지, 작업 스타일, 선호하는 도구 환경을 적습니다.
  5. 저장을 누릅니다.
  • 역할 설명이나 파일 형식(예: Word 문서) 같은 기본값을 적어 두면 좋습니다.
  • 프로젝트마다 다른 규칙은 폴더별 인스트럭션으로 나눠 둡니다.
  • 예전 방식: Settings의 Cowork 탭에서 전역 지침을 설정했다는 설명도 있습니다. 화면 이름이 다르면 설정에서 협업·Cowork 항목을 찾아보세요.

4. 플러그인과 스킬로 업무 방식 저장하기

플러그인은 스킬·커넥터·슬래시 명령을 묶은 직무별 패키지이고, 스킬은 반복 업무의 절차를 저장한 것입니다. 한 번 만들어 두면 같은 지시로 같은 품질의 결과를 얻고 팀과 공유할 수 있습니다.

  1. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  2. 플러그인 추가에서 세일즈, 제품 관리, 마케팅 등 필요한 플러그인을 설치합니다.
  3. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  4. 입력창에 /를 입력해 스킬이나 슬래시 명령을 고르고 필요한 정보를 적어 실행합니다.
  5. 내 업무용 스킬은 알고 싶은 내용을 설명해 스킬 파일 초안을 만들게 하고, 테스트 계정으로 돌려 보며 다듬습니다.
  6. 실행 후 배운 점을 스킬에 반영하도록 요청해 다음에 개선되게 합니다.
예시
미팅 전에 알고 싶은 정보(최근 90일 통화, 매출 추이, 열린 기회, 이해관계자)를 모아 계정 브리핑 문서로 정리하는 스킬을 만들어 줘.
  • 스킬은 일반 텍스트 파일이라 언제든 열어 동작을 확인할 수 있습니다.
  • 명령어 이름은 영상에서 불분명했으니 플러그인 관리 화면에서 정확한 표기를 확인하세요.
  • 발송 같은 외부 행동은 승인 단계를 거치게 해 내용을 확인한 뒤 보냅니다.
  • 스킬을 많은 사람이 쓰려면 소유자·검토자·폐기 기준을 먼저 정해야 합니다.

5. Cowork 예약 작업 만들기

예약 작업은 정해진 주기마다 Cowork가 자동으로 일을 실행하게 하는 기능입니다. 매일 아침 브리핑, 주간 지표 리뷰, 폴더 변경 확인처럼 반복 업무에 쓰기 좋습니다.

  1. 반복할 일을 자연어로 설명하거나 입력창에 /schedule을 입력합니다.
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 작업 이름, 설명, 프롬프트, 빈도를 확인하고 필요하면 주기를 바꿉니다.
  4. 내용이 맞으면 제안을 수락합니다.
  5. 왼쪽 사이드바의 예약 페이지에 작업이 추가되었는지 확인합니다.
  6. 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행을 할 수 있습니다.
예시
AI 트렌드를 리서치해서 매주 수요일에 유튜브 아이디어 5개를 제안해 줘.
  • 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있을 때만 실행되었습니다. 2026년 7월 7일 업데이트 이후에는 클라우드에서 기기가 꺼져 있어도 실행된다고 소개되었습니다.
  • 웹 버전은 로컬 파일 접근이 안 되므로 로컬 파일이 필요한 작업은 데스크톱 앱에서 하세요.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있고, 실행마다 새 세션으로 최신 파일 상태를 기준으로 합니다.
  • 외부로 보내는 작업은 발송하지 말고 초안으로 남기게 하면 안전합니다.

6. Cowork로 회의 준비 문서 만들기

캘린더·Slack·이메일·이전 회의록을 연결해 오늘 회의의 안건 문서를 자동으로 만드는 방법입니다. 흩어진 정보를 찾는 시간을 줄여 줍니다.

  1. 캘린더, Slack, 이메일을 Claude에 연결합니다.
  2. 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 회의와 시간을 알려 주고 준비를 요청합니다.
  4. 캘린더 검색, 참석자 조사, Slack 스레드 확인, 이전 회의록 검토, 안건 작성을 시키고 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  5. Claude가 세운 계획을 확인하고 작업이 진행되게 둡니다.
  6. 빠뜨린 출처가 있으면 작업 중에 추가로 요청합니다.
  7. 완성된 안건 문서를 작업 폴더에서 열어 검토하고 고칩니다.
예시
Prep me for today's call with Acme Corp at 1PM.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 최종 문서의 책임과 수정은 사용자에게 있으니 근거를 직접 확인합니다.

7. Slack 채널에서 Claude Tag에게 일 시키기

Claude Tag는 팀 채널에 Claude를 추가해 대화 맥락을 따라가며 일하게 하는 기능입니다. 채팅창을 오가거나 맥락을 복사할 필요 없이 채널에서 바로 요청할 수 있습니다. Team·Enterprise 요금제에서 베타로 제공됩니다.

  1. Claude를 사용할 Slack 채널 하나에 추가합니다.
  2. 필요한 도구를 Claude Tag에 연결합니다.
  3. 작업이 필요한 스레드에서 Claude를 태그해 요청합니다.
  4. Claude가 단계별로 진행하는 상황을 채널에서 확인하고, 그동안 다른 일을 합니다.
  5. 완료 또는 입력 요청 알림이 오면 확인하고 답합니다.
  6. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
예시
@Claude 최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • 처음에는 한 채널에서만 시작해 보세요.
  • 매번 태그하기 번거로우면 항상 응답하도록 지시하고, 너무 자주 개입하면 빈도를 조정해 달라고 말합니다.
  • 프로젝트 상태를 추적하려면 공개 채널이 좋습니다. DM과 비공개 채널에서 배운 내용은 그 안에만 남습니다.

8. ChatGPT Work로 회의록·조사 자동화

ChatGPT Work는 OpenAI의 업무 실행 에이전트로, 답이 아니라 결과물을 만들어 줍니다. 파일·앱을 다루는 기능은 데스크탑 앱에서 쓸 수 있습니다. 회의록 정리, 웹 자료 수집처럼 반복 업무에 적합합니다.

  1. ChatGPT 데스크탑 앱을 설치하고 메인 화면에서 Work 모드를 선택합니다.
  2. 회의록 파일을 첨부합니다.
  3. 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 달라고 요청합니다.
  4. 복잡한 작업은 입력창의 + 버튼에서 계획 모드를 켜고 Work가 던지는 질문에 답합니다.
  5. 웹 데이터 수집은 모델을 GPT-6 아스트라, 추론 수준을 미디엄으로 두고 필수 조건·선호 조건·결과 형식을 적어 요청합니다.
  6. 결과를 구글 스프레드시트에 정리해 달라고 이어서 요청합니다.
예시
첨부한 회의록에서 실행 항목만 뽑아 담당자, 할 일, 마감 세 열의 스프레드시트로 만들어 줘.
  • 단순 작업은 기본 모드, 복잡한 작업은 플랜 모드를 씁니다. 모호한 부분을 먼저 물어봐서 결과가 구체적입니다.
  • 추론 수준은 미디엄에서 시작해 결과가 부족하면 올리세요. 높일수록 비용이 늘어납니다.
  • 채팅에서 가볍게 다듬은 대화는 컨텍스트 첨부로 Work에 이어 갈 수 있습니다.

9. 제미나이 스파크로 메일 브리핑 자동화

제미나이 스파크는 구글 클라우드에서 상시 일하는 개인 AI 에이전트로 Gmail·캘린더·독스·시트·드라이브를 다룹니다. 태스크(무엇을), 스케줄(언제), 스킬(업무 매뉴얼)로 구성되며 구글 AI 프로 이상 구독이 필요합니다.

  1. 제미나이를 실행하고 좌측 상단 스파크 베타 탭을 누릅니다.
  2. 좌측 하단 프로필에서 설정을 열어 연결된 앱의 구글 워크스페이스가 켜져 있는지 확인합니다.
  3. 이번 주 캘린더와 Gmail에서 답장 안 한 메일을 확인해 우선순위 브리핑 문서를 만들어 달라고 요청합니다.
  4. 주기 실행은 프롬프트에 시점을 적습니다. 예: 매주 월요일 오전 8시.
  5. 핵심 요약 5개를 이메일 초안으로 쓰되 발송하지 말고 초안으로 남기게 합니다.
  6. 좌측 일정 탭에서 등록된 일정을 확인합니다.
예시
매주 월요일 오전 8시에 지난 7일간 Gmail의 뉴스레터와 업무 보고 메일을 구글 시트에 정리하고, 핵심 요약 5개를 이메일 초안으로 작성해 줘. 발송은 하지 말고 초안으로만 남겨 줘.
  • 발송하지 말고 초안으로 남기게 하면 안전합니다.
  • 내 문체는 보낸 이메일을 분석해 스킬로 저장하게 하고, 인사말 한 줄·본론 먼저 같은 규칙을 덧붙입니다.
  • 브라우저를 닫고 폰을 잠가도 백그라운드에서 작업이 이어집니다.

10. Codex 자동화와 Record & Replay

OpenAI Codex는 플러그인과 자동화 기능으로 매일 아침 브리핑 같은 반복 작업을 돌립니다. Record & Replay는 평소 하던 작업을 화면으로 보여 주면 스킬로 만들어 주는 기능입니다.

  1. 플러그인 탭에서 Slack과 구글 캘린더를 미리 연결합니다.
  2. 좌측 상단 자동화 탭을 열고 채팅으로 만들기를 누른 뒤 자동화용 새 프로젝트를 만듭니다.
  3. 캘린더 일정을 가져와 Slack으로 브리핑하고 매일 오전 9시에 실행하도록 Codex의 질문에 답합니다.
  4. 자동화가 액티브 상태로 생성되었는지 확인합니다.
  5. 녹화형 스킬은 컴퓨터 유즈 플러그인과 레코드 앤 리플레이 플러그인을 차례로 설치하고 설정에서 사용해 보기를 켭니다.
  6. 새 프로젝트 추가에서 녹화를 시작해 평소 작업을 수행하고 정지하면 스킬이 자동으로 만들어집니다.
예시
구글 캘린더의 오늘 일정을 가져와서 Slack으로 브리핑해 줘. 매일 오전 9시에 실행해 줘.
  • 플러그인 연결을 먼저 해 두지 않으면 자동화가 동작하지 않습니다.
  • Record & Replay는 현재 macOS에서만 쓸 수 있습니다.
  • 녹화 전에 구글 계정을 미리 로그인해 두고 로그인 화면은 녹화에 넣지 않는 것이 안전합니다.
  • 만든 스킬은 채팅에서 사용해 보기로 불러와 조건을 덧붙여 개선합니다.

11. n8n으로 노코드 자동화 만들기

n8n은 노드(작업 블록)를 연결해 워크플로우를 만드는 자동화 도구입니다. 챗봇, 슬랙·노션·메일 연동 같은 자동화를 코드 없이 만들 수 있습니다.

  1. n8n 클라우드에 가입하고 대시보드에서 Create Workflow로 새 워크플로우를 만듭니다.
  2. Add first step에서 트리거로 On chat message를 선택합니다.
  3. + 버튼으로 AI Agent를 추가하고 Chat Model과 시스템 메시지를 설정합니다.
  4. Memory에서 Simple Memory를 선택해 기억할 대화 수를 설정합니다.
  5. 구글 시트를 Tool로 추가하고 Sign in with Google로 연결해 문서를 선택합니다.
  6. 하단 채팅창에서 테스트합니다.
  7. AI로 빠르게 만들려면 빌드 위드 AI에서 자동화할 내용을 구체적으로 적고, 만들어진 노드를 클릭해 설정을 확인합니다.
  8. API 키와 OAuth 인증은 직접 연결하고 테스트 데이터로 실행해 확인합니다.
예시
슬랙 채널에 긴급이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일 발송
  • AI 빌더는 베타이며 n8n 클라우드에서만 쓸 수 있고 프롬프트 한 번에 1크레딧을 씁니다.
  • 트리거 시점과 데이터 처리 방식까지 구체적으로 적고, 기본 흐름 → 테스트 → 기능 추가 → 예외 처리 순으로 만듭니다.
  • AI 에이전트는 기본적으로 이전 대화를 기억하지 못하므로 메모리 노드가 필요합니다.
  • 정형화된 반복 작업은 n8n, 판단이 필요한 챗봇형 작업은 OpenAI Agent Builder가 맞다는 비교가 있습니다.

12. 개입 지점을 설계해 자동화 병목 줄이기

에이전트를 많이 돌려도 내가 병목이 되지 않도록 권한, 상한, 확인 지점, 종료 조건을 미리 정하는 방법입니다. 자동화를 넓힐 때 가장 중요한 설계 단계입니다.

  1. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  2. 에이전트에 가능한 한 많은 권한을 줍니다.
  3. 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  4. 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 정합니다.
  5. 무엇이 완료인지 누가 봐도 참/거짓을 판정할 수 있는 종료 조건을 만듭니다.
  6. 만드는 AI와 검사하는 AI를 분리해 독립적으로 검증하게 합니다.
  • 종료 조건은 검증 통과, 최대 반복 횟수, 시간·비용 한도, 진전 없음 중단을 겹쳐 겁니다.
  • 상한 숫자(쇼츠 500, 롱폼 1,500 등)는 영상 제작자 본인의 값이므로 내 요금제에 맞게 정하세요.
  • 팀에서 가장 번잡한 회의나 절차를 하나 골라 지금도 필요한지, Claude로 줄일 수 있는지 점검해 보세요.
  • AI가 만든 결과물도 공개 전에 사람이 원문과 대조해 검수해야 합니다.
