1. Claude 채팅으로 반복 보고서 스킬 만들기

스킬은 반복 업무의 양식과 작업 방식을 저장해 두는 기능입니다. 매번 같은 설명을 쓰지 않고 /로 불러 쓰면 항상 같은 포맷의 결과가 나옵니다. 주간 보고서처럼 형식이 정해진 문서에 알맞습니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 스킬을 선택하고 주제를 적어 요청합니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 브랜드 컬러·폰트·섹션 구성까지 설명해 저장하면 매번 같은 포맷이 나옵니다.
  • AI 티가 나는 문장은 직접 읽고 고치고, 중요한 보고서는 꼭 검토하세요.

2. Cowork로 폴더 속 파일 정리·보고서 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세우고 파일을 읽어 엑셀·워드 같은 결과물을 만들어 주는 도구입니다. 흩어진 자료를 보고서로 묶거나 지저분한 엑셀을 정리할 때 씁니다. Claude 데스크톱 앱에서 쓰며 Pro 이상 요금제가 필요합니다.

  1. Claude 데스크톱을 열고 Cowork(협업) 탭을 누릅니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 고르고 접근 권한 창에서 항상 허용을 누릅니다.
  3. 정리할 자료(회의록, 매출 엑셀, 메모 등)를 그 폴더에 넣습니다.
  4. 원하는 결과를 구체적으로 적어 요청하고, 변경 전에 계획을 보여 달라고 합니다.
  5. Claude가 제안한 계획을 확인하고 필요하면 수정을 지시한 뒤 승인합니다.
  6. 진행 상황을 지켜보고 폴더에 저장된 결과 파일을 열어 확인합니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘.
  • 엑셀 정리는 원본은 그대로 두고 정리본은 새 파일로 저장이라고 꼭 적으세요.
  • 처음에는 폴더 정리처럼 범위가 분명한 작업부터 시작합니다.
  • 웹 버전은 로컬 파일 접근이 안 되므로 파일 작업은 데스크톱 앱에서 합니다.
  • Settings의 Cowork 탭에서 역할 설명 같은 전역 지침을 정해 둘 수 있습니다.

3. 커넥터로 메일 브리핑 예약 작업 만들기

Gmail·캘린더 같은 서비스를 커넥터로 연결하고 예약 작업으로 등록하면 매일 아침 메일·일정 브리핑이 자동으로 만들어집니다. 출근 전에 오늘 할 일을 훑고 싶을 때 알맞습니다. 예약 작업은 유료 플랜에서 쓸 수 있습니다.

  1. 클로드 데스크톱에서 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail 또는 Microsoft 365를 선택해 클로드에 연결하고 계정을 고릅니다.
  3. + → 커넥터에서 연결 표시(파란 불)를 확인합니다.
  4. 어제 오후 6시 이후 메일과 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  5. 결과가 마음에 들면 같은 내용을 아침 7시 50분마다 실행하는 예약 작업으로 등록해 달라고 요청합니다.
  6. 좌측 예약됨에서 스케줄을 확인합니다.
예시
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고 우선순위 브리핑을 만들어 줘. 같은 내용을 매일 아침 7시 50분에 실행하는 예약 작업으로 등록해 줘.
  • 영상에서는 예약 작업이 클로드 서버에서 돌아 컴퓨터를 꺼도 실행된다고 했습니다.
  • 예전 방식: 6월 영상에서는 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행됐으나, 7월 업데이트 이후 기기가 꺼져 있어도 클라우드에서 실행됩니다.
  • 메일은 자동 발송보다 초안으로 남기게 하는 편이 안전합니다.

4. Cowork 예약 작업으로 정기 업무 돌리기

반복할 일을 자연어로 설명하면 Claude가 예약 작업 프롬프트 초안을 만들고, 주기를 확인해 승인하면 등록됩니다. 매시간 폴더 변경 확인, 주간 지표 리뷰 준비 같은 정기 업무에 씁니다.

  1. 반복할 일을 자연어로 설명합니다(예: 매시간 공유 폴더의 추가·수정 문서를 확인해 요약).
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  4. 내용이 맞으면 제안을 수락합니다.
  5. 왼쪽 사이드바의 예약 페이지에 작업이 추가된 것을 확인합니다.
  6. 예약 페이지에서 지난 실행 기록을 보거나 지시문·주기를 고치고 즉시 실행해 봅니다.
예시
매주 평일 오후 4시에 공유 폴더에서 새로 추가·수정된 문서를 확인하고, 변경한 사람과 요약을 클라이언트별로 묶어 문서로 저장해 줘.
  • 처음에는 한 번 직접 실행해 결과가 맞는지 확인한 뒤 맡기세요.
  • 숫자가 들어가는 리포트는 출처가 검증된 데이터인지 확인하는 교정 스킬을 따로 두면 좋습니다.
  • 이 방식은 실행마다 새 세션으로 돌아 최신 파일 기준으로 작동합니다.
  • 예전 방식(6월 기준): 컴퓨터와 데스크톱 앱이 켜져 있어야 실행됐습니다.

5. 플러그인·글로벌 지침으로 Cowork 맞춤화하기

플러그인은 스킬·커넥터·슬래시 명령을 묶은 직무별 패키지입니다. 글로벌 지침에 내 역할과 작업 스타일을 적어 두면 매번 설명하지 않아도 됩니다. 영업·마케팅·법무처럼 직무가 뚜렷할 때 유용합니다.

  1. 좌측 상단에서 Claude 설정을 열고 협업 탭으로 이동합니다.
  2. 지침 항목의 편집을 눌러 내가 어떤 사람인지, 작업 스타일, 선호 도구를 적고 저장합니다.
  3. 코워크 메인 화면에서 + → 플러그인을 선택합니다.
  4. 플러그인 추가에서 세일즈·제품 관리·마케팅 등 맞는 플러그인을 설치합니다.
  5. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  6. 입력창에 슬래시 명령을 입력하고 필요한 정보를 적어 실행합니다.
  • 영상에서 명령어 이름은 자막이 불분명하므로 정확한 표기는 플러그인 관리 화면에서 확인하세요.
  • 스킬은 일반 텍스트 파일이라 열어서 회사 방식에 맞게 고칠 수 있습니다.
  • 미팅 전 브리핑이나 통화 후 후속 정리처럼 매번 반복되는 일을 스킬로 만들면 효과가 큽니다.
  • 발송이 필요한 결과는 승인 단계를 거쳐 보내세요.

6. Gemini 스파크로 메일·일정 자동화하기

제미나이 스파크는 구글 클라우드에서 상시 일하는 개인 에이전트로, Gmail·캘린더·독스·시트·드라이브를 별도 연결 없이 다룹니다. 태스크(무엇을), 스케줄(언제), 스킬(매뉴얼)로 구성됩니다. 구글 AI 프로 이상 구독이 필요합니다.

  1. 제미나이를 실행하고 좌측 상단 스파크 베타 탭을 누릅니다.
  2. 좌측 하단 프로필에서 설정을 열어 연결된 앱의 구글 워크스페이스가 켜져 있는지 확인합니다.
  3. 이번 주 캘린더와 Gmail에서 답장 안 한 메일로 우선순위 브리핑 문서를 만들어 달라고 요청합니다.
  4. 주간 반복은 프롬프트에 실행 시점(예: 매주 월요일 오전 8시)을 적어 스케줄로 만듭니다.
  5. 좌측 일정 탭에서 등록된 일정을 확인합니다.
  6. 보낸 메일을 분석해 내 문체를 스킬로 저장해 달라고 요청하고 다시 같은 요청을 해 비교합니다.
예시
매주 월요일 오전 8시에 지난 7일간 Gmail의 뉴스레터·업무 보고 메일을 구글 시트에 정리하고, 핵심 요약 5개를 이메일 초안으로 작성해 줘. 발송은 하지 말고 초안으로 남겨 줘.
  • 발송하지 말고 초안으로 남기게 하면 안전합니다.
  • 스킬은 여러 태스크에 공통 적용되는 지침을 저장해 두는 기능입니다.
  • 데스크톱 앱은 영상 시점에 macOS만 지원합니다.

7. ChatGPT Work·Codex로 업무 맡기기

ChatGPT Work는 파일과 앱을 다뤄 결과물을 만들어 주는 업무 실행 에이전트이고, Codex 자동화는 정해진 시각에 작업을 돌립니다. 회의록에서 실행 항목 뽑기나 매일 아침 브리핑에 알맞습니다. 파일·앱 기능은 데스크탑 앱 기준입니다.

  1. ChatGPT 데스크탑 앱을 설치하고 메인 화면에서 Work 모드를 선택합니다.
  2. 회의록 파일을 첨부하고 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 달라고 요청합니다.
  3. 복잡한 작업은 입력창의 + 버튼에서 계획 모드를 켜고 Work가 던지는 질문에 답합니다.
  4. 정기 실행은 Codex에서 플러그인 탭에 Slack과 구글 캘린더를 먼저 연결합니다.
  5. 자동화 탭의 채팅으로 만들기로 매일 오전 9시 브리핑 자동화를 요청합니다.
  6. 자동화가 액티브 상태로 생성됐는지 확인합니다.
예시
회의록에서 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 줘.
  • 추론 수준은 미디엄에서 시작해 결과가 부족하면 올립니다.
  • 플러그인 연결을 먼저 해 두지 않으면 자동화가 동작하지 않습니다.
  • 모호한 부분은 계획 모드에서 Work가 먼저 물어봐 줍니다.

8. n8n으로 노코드 자동화 워크플로우 만들기

n8n은 작업 블록(노드)을 연결해 자동화 시나리오를 만드는 도구입니다. AI 워크플로우 빌더에 한국어로 요청하면 노드 구성까지 만들어 줍니다. 정해진 순서로 반복되는 업무에 알맞고, 판단이 필요한 챗봇형은 에이전트 도구가 낫습니다.

  1. n8n 클라우드에 가입하고 Create Workflow로 새 워크플로우를 만듭니다.
  2. 빌드 위드 AI를 눌러 빌드를 선택합니다.
  3. 자동화할 내용을 트리거 시점과 처리 방식까지 구체적으로 적어 요청합니다.
  4. 만들어진 노드를 하나씩 눌러 설정을 확인합니다.
  5. API 키와 OAuth 인증 정보는 직접 연결합니다.
  6. 테스트 데이터로 실행해 동작을 확인한 뒤 실제로 씁니다.
  7. FAQ 챗봇은 On chat message 트리거에 AI Agent, Simple Memory, 구글 시트 Tool을 이어 만듭니다.

  • AI 빌더는 베타이며 n8n 클라우드에서만 쓸 수 있습니다.
  • 에이전트가 이전 대화를 기억하게 하려면 메모리 노드가 필요합니다.

9. Slack 채널에서 Claude Tag로 일 시키기

Claude Tag는 Slack 같은 팀 채널에 Claude를 추가해 대화를 따라가며 일하게 하는 기능입니다. 맥락을 복사해 붙일 필요 없이 채널에서 바로 요청하고, 채널별 지침을 기억시킬 수 있습니다. Team·Enterprise 요금제 베타입니다.

  1. Claude를 사용할 채널 하나에 추가합니다.
  2. 필요한 도구를 Claude Tag에 연결합니다.
  3. 작업이 필요한 스레드에서 Claude를 태그해 요청합니다.
  4. 진행 상황을 채널에서 확인하고, 완료나 결정 요청 알림이 오면 확인합니다.
  5. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
  6. 너무 자주 또는 드물게 개입하면 개입 빈도를 조정해 달라고 말합니다.
예시
@Claude 최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • 처음에는 한 채널에서만 시작해 보세요.
  • 스타일 가이드 문서를 알려 주면 참고하며 문서가 바뀌면 최신 내용을 따릅니다.
  • DM과 비공개 채널의 정보는 그 안에만 남고, 다른 사람 대신 응답하거나 도구에 접근할 때는 권한을 묻습니다.

11. 예약 루틴으로 먼저 일하는 에이전트 만들기

Claude Code 루틴은 프롬프트, 저장소, 커넥터, 트리거만 정하면 관리형 인프라에서 원격 세션을 자동 실행합니다. 노트북을 닫아도 돌아가며, 일정이나 이벤트로 시작합니다. 주간 문서 갱신 같은 개발 관련 반복 업무에 알맞습니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문(실행 요일·시간, 알림 여부)에 답합니다.
  4. 필요한 저장소를 컨텍스트로 연결합니다.
  5. 만들어진 루틴을 웹의 Claude Code에서 확인하고 실행 결과 세션을 열어 봅니다.
예시
/schedule 매주 main에 병합된 변경을 문서 저장소와 비교해서 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 권한을 늘리세요.
  • Claude Code Projects(베타, Pro·Max)를 쓰면 여러 스레드를 병렬로 돌릴 수 있습니다.

12. 콘텐츠 제작 파이프라인 자동화하기

영상·카드뉴스 같은 콘텐츠를 기획부터 업로드까지 단계별 스킬로 묶어 자동화하는 방법입니다. 같은 형식의 결과물을 꾸준히 내야 할 때 씁니다. 사람은 해석과 검수에 집중하고, 반복 작업은 에이전트에 맡깁니다.

  1. 영상 종류별 기준 편집본(템플릿)과 편집 방식을 적은 업무 매뉴얼(SOP)을 만듭니다.
  2. 스타터 폴더를 클로드에서 열고 너는 어떻게 만들어져 있어?라고 물어 구조와 CLAUDE.md 규칙을 파악합니다.
  3. 레퍼런스 폴더에 완성본, 원본 폴더에 촬영 영상을 넣습니다.
  4. 레퍼런스를 참고해 원본을 똑같이 편집하되 애매하면 물어보라고 시킵니다.
  5. 기획·리서치 → 대본 → 음성 → 모션 → 검수 → 패키징 순으로 단계를 나누고, Claude가 쓴 것은 다른 도구가 검증하게 합니다.
  6. 크레딧 상한 같은 규칙과 되돌리기 어려운 지점의 확인 절차를 미리 정합니다.
  7. 잘 된 작업은 스킬로 저장해 반복 사용합니다.
예시
레퍼런스 폴더의 편집본을 참고해서 원본 폴더의 촬영 영상을 똑같은 스타일로 편집해 줘. 애매한 부분은 먼저 물어봐 줘.
  • 레퍼런스와 촬영 방식이 비슷해야 결과가 잘 맞습니다.
  • 시간이 걸리므로 자기 전에 걸어 두면 편합니다(영상에서는 34초 편집에 약 40분, 후속 편은 약 15분).
  • 크레딧 상한 숫자는 영상 속 제작자의 값이므로 내 요금제에 맞게 정하세요.
  • 남의 영상을 가공할 때는 인터뷰로 내 해석을 더해야 차별점이 생깁니다.

13. 에이전트 설계: 종료 조건과 확인 지점 정하기

에이전트를 스스로 돌아가게 하려면 무엇이 완료인지, 어디서 사람이 확인할지 미리 설계해야 합니다. 반복 업무를 맡길수록 이 설계가 결과 품질을 좌우합니다. 위의 자동화 가이드를 익힌 뒤 보는 응용 편입니다.

  1. 자동화할 업무의 완료 기준을 누가 봐도 참·거짓을 가릴 수 있게 적습니다.
  2. 검증 통과, 최대 반복 횟수, 시간·비용 한도, 진전 없음 중단을 겹쳐 종료 조건으로 둡니다.
  3. 진행 상황을 적는 상태 파일을 두어 다음 실행이 이어받게 합니다.
  4. 만드는 AI와 검사하는 AI를 분리합니다.
  5. 피드백을 줄 때마다 스킬이나 규칙으로 남깁니다.
  6. 되돌리기 어려운 지점(발송, 큰 비용 지출)은 사람 확인을 거치게 정합니다.
  • 가장 소모적인 회의나 절차 하나를 골라 지금도 필요한지 점검하는 것부터 시작해도 좋습니다.
  • 모델이 바뀌면 설계도 달라질 수 있으니 주기적으로 다시 점검하세요.
  • 복잡한 계획에는 큰 모델, 단순 작업에는 가벼운 모델을 쓰는 것이 효율적이라고 소개됩니다.
