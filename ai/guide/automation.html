1. Cowork로 폴더 작업 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세우고 파일을 읽어 엑셀·워드 같은 결과물까지 만들어 주는 기능입니다. 영수증 정리, 자료 취합, 파일 분류처럼 여러 단계가 필요한 사무 작업에 씁니다.

  1. Claude 데스크톱 앱을 설치하고 열어 코워크(협업) 모드를 선택합니다.
  2. 프로젝트 또는 폴더에서 폴더 추가를 눌러 작업할 폴더를 엽니다.
  3. 폴더 접근 권한 창이 뜨면 항상 허용을 선택합니다.
  4. 필요하면 커넥터를 연결해 Google Drive·Notion·Slack의 맥락을 가져오게 합니다.
  5. 작업을 말로 설명하고, 변경하기 전에 계획부터 보여 달라고 요청합니다.
  6. 제안된 계획을 확인하고 고칠 부분을 말한 뒤 승인합니다.
  7. 진행 상황을 지켜보고, 완성된 파일을 폴더에서 열어 내용을 확인합니다.
예시
Organize my downloads folder. Scan the contents and propose a plan.
  • 처음에는 정리처럼 범위가 분명한 작업부터 시작하고 결과를 항상 검토합니다.
  • 원본은 그대로 두고 정리본을 새 파일로 저장해 달라고 프롬프트에 적어 둡니다.
  • 웹 버전은 로컬 파일 접근과 컴퓨터 조작이 안 되므로 폴더 작업은 데스크톱 앱에서 합니다.
  • 예전 방식: 코워크가 맥 전용이던 시기에는 맥에서만 쓸 수 있었지만, 지금은 윈도우 데스크톱 앱도 지원합니다.

2. 글로벌 지침으로 내 업무 방식 알려 주기

코워크 설정의 지침에 나와 내 작업 스타일을 적어 두면 모든 세션에 적용됩니다. 매번 같은 설명을 반복하지 않아도 되어 결과물의 톤과 형식이 일정해집니다.

  1. Claude 설정을 엽니다.
  2. 협업 탭으로 이동합니다.
  3. 지침 항목의 편집 버튼을 누릅니다.
  4. 내가 어떤 일을 하는 사람인지, 선호하는 작업 스타일과 도구를 적습니다.
  5. 저장을 누릅니다.
  • Settings의 Cowork 탭에서 역할 설명이나 결과 파일 형식(예: Word 문서) 같은 전역 지침도 설정할 수 있습니다.
  • 화면 이름은 앱 버전에 따라 조금 다를 수 있으니 설정 화면에서 확인하세요.

3. 메일 브리핑을 예약 작업으로 받기

Gmail·캘린더를 연결하고 브리핑 요청을 예약 작업으로 등록하면 매일 아침 정해진 시각에 요약이 만들어집니다. 출근 직후 메일과 일정을 훑는 시간을 줄이고 싶을 때 씁니다.

  1. 클로드 데스크톱에서 + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기를 엽니다.
  2. Gmail 또는 Microsoft 365를 선택해 클로드에 연결하고 계정을 고릅니다.
  3. + → 커넥터에서 연결 표시(파란 불)를 확인합니다.
  4. 어제 오후 6시 이후 메일과 캘린더 일정으로 브리핑을 만들어 달라고 요청합니다.
  5. 같은 내용을 아침 7시 50분마다 실행하는 예약 작업으로 등록해 달라고 요청합니다.
  6. 좌측 예약됨에서 스케줄을 확인합니다.
예시
어제 오후 6시 이후 받은 메일과 오늘 캘린더 일정을 보고 우선순위 브리핑을 만들어 줘. 이 작업을 매일 아침 7시 50분에 실행되도록 예약해 줘.
  • 최근 영상 기준으로 예약 작업은 클로드 서버에서 돌아 컴퓨터를 꺼도 실행되며, 유료 플랜에서만 쓸 수 있습니다.
  • 예전 방식: 예약 작업은 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행됐습니다(꺼져 있어 놓친 작업은 복귀 후 실행).
  • 처음 몇 번은 결과를 직접 확인하고, 이상 없을 때 신뢰하세요.

4. Cowork 예약 작업 직접 만들기

반복할 일을 자연어로 설명하면 Claude가 프롬프트 초안을 만들고, 주기를 정해 승인하면 등록됩니다. 주간 리포트, 폴더 변경 확인처럼 정기적으로 하는 일에 알맞습니다.

  1. 반복할 일을 자연어로 설명합니다(예: 매시간 공유 폴더의 추가·수정 문서를 확인해 요약).
  2. 또는 입력창에 /schedule을 입력하고 작업 이름·설명·프롬프트·빈도를 정합니다.
  3. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  4. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  5. 내용이 맞으면 제안을 수락합니다.
  6. 왼쪽 사이드바의 예약 페이지에 작업이 추가됐는지 확인합니다.
  7. 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행을 할 수 있습니다.
예시
매주 수요일 AI 트렌드를 리서치해서 유튜브 아이디어 5개를 제안해 줘.
  • 예약 작업은 실행마다 새 세션으로 돌아 최신 파일과 도구 상태를 기준으로 합니다.
  • 설정해 둔 커넥터는 예약 작업에서도 쓸 수 있습니다.
  • 첫 실행 후 Claude가 프롬프트를 더 상세히 다시 써 정확도가 올라갑니다.

5. 반복 보고서를 스킬로 고정하기

스킬은 반복하는 업무의 형식과 규칙을 저장해 두는 기능입니다. 보고서 양식을 한 번 가르쳐 두면 이후 주제만 말해도 같은 포맷으로 나옵니다.

  1. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  2. 이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘라고 요청합니다.
  3. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  4. 사용할 때는 /와 스킬 이름을 입력해 스킬을 선택하고 주제를 적어 요청합니다.
  5. 저장된 스킬은 + 메뉴의 스킬에서 확인합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • 브랜드 컬러·폰트·섹션 구성 같은 디자인 규칙도 스킬이나 메모리에 넣어 두면 매번 같은 포맷이 나옵니다.
  • AI 티가 나는 문장은 별도 교정 스킬로 다듬되, 중요한 문서는 직접 읽고 고칩니다.
  • 스킬은 일반 텍스트 파일이라 열어서 동작을 확인하고 수정할 수 있습니다.

6. Cowork 스킬로 미팅 준비·후속 처리하기

흩어진 메일·Slack·CRM·녹취록을 스킬 하나로 모아 미팅 전 브리핑을 만들고, 미팅 후에는 후속 메시지까지 정리합니다. 몇 시간 걸리던 조사를 몇 분으로 줄이는 데 씁니다.

  1. Cowork 세션에서 미팅 전에 알고 싶은 내용을 설명해 스킬 파일 초안을 만듭니다.
  2. 설정에서 이메일·Slack·캘린더 등 필요한 도구를 연결합니다.
  3. Claude가 파일을 읽고 저장할 수 있는 폴더를 지정합니다.
  4. 테스트용 계정이나 건으로 스킬을 실행해 결과를 보고 다듬습니다.
  5. 미팅 전 /를 입력하고 브리핑 스킬을 골라 고객사 이름을 입력합니다.
  6. 미팅 후 같은 세션에서 /로 녹취록 처리 스킬을 골라 할 일·내부 공유·고객 후속 메시지를 만들게 합니다.
  7. 각 결과를 확인하고 승인한 뒤 발송합니다.
예시
Prep me for today's call with Acme Corp at 1PM.
  • 처음에는 테스트 건으로 돌려 보고 다듬은 뒤 실제 업무에 씁니다.
  • 발송 전에는 항상 승인 단계를 거치고 근거를 원문에서 직접 확인합니다.

7. 주간 지표 리뷰 자동 준비하기

일요일 저녁 예약 작업이 자료를 모아 두고, 월요일에 사람이 서사와 초점만 정하는 방식입니다. 숫자 수집·검증은 Claude에게, 판단은 사람에게 나누는 주간 보고에 맞습니다.

  1. 리뷰 준비, 교정, 액션 아이템 관리용 스킬을 각각 만듭니다.
  2. 일요일 저녁에 실행되는 예약 작업을 설정합니다.
  3. 월요일 아침 Cowork를 열어 준비 결과와 제안된 집중 영역을 확인합니다.
  4. 분기 리뷰 문서를 넣고 이번 주 초점을 지시합니다.
  5. Claude가 데이터 불일치를 알리면 처리 방식을 알려 줍니다.
  6. 먼저 지표 표와 헤드라인만 있는 초안을 확인합니다.
  7. ship it이라고 말해 최종 문서와 Slack 메시지를 만들게 합니다.
  8. 이번 주 배운 점을 스킬에 반영하도록 요청합니다.
  • 교정 스킬은 초안의 모든 숫자가 검증된 출처로 추적되는지 확인하게 합니다.
  • 후속 조치는 작업 관리 도구에 남겨 누락을 막고, 스킬은 팀과 공유해 같은 결과를 냅니다.

8. Gem·스파크로 일정·메일 자동 처리하기

제미나이에서는 Gems로 역할과 지침을 저장하고, 스파크로 태스크·스케줄·스킬을 묶어 상시 일하는 비서를 둘 수 있습니다. 구글 워크스페이스(Gmail·캘린더·드라이브)를 주로 쓰는 직장인에게 맞습니다.

  1. 제미나이 왼쪽의 Gems에서 새 잼을 눌러 이름과 요청 사항(역할·할 일·배경·결과 형식)을 적고 저장합니다.
  2. 스파크를 쓰려면 제미나이 좌측 상단 스파크 베타 탭을 엽니다.
  3. 프로필 설정의 연결된 앱에서 구글 워크스페이스가 켜져 있는지 확인합니다.
  4. 이번 주 캘린더와 Gmail에서 답장 안 한 메일로 우선순위 브리핑 문서를 만들어 달라고 요청합니다.
  5. 프롬프트에 실행 시점(매주 월요일 오전 8시)을 적어 스케줄로 등록하고, 요약은 발송하지 말고 이메일 초안으로 남기게 합니다.
  6. 좌측 일정 탭에서 등록된 일정을 확인합니다.
예시
이번 주 캘린더와 Gmail에서 답장 안 한 메일을 확인해서 우선순위 브리핑 문서를 만들어 줘. 발송하지 말고 초안으로만 남겨 줘.
  • 스파크는 구글 AI 프로 이상 구독이 필요하고, 데스크톱 앱은 현재 macOS만 지원합니다.
  • 내 기존 글을 예시 파일로 주면 말투까지 분석해 Gem 지침을 만들어 줍니다.
  • 발송은 하지 말고 초안으로 남기게 하면 안전합니다.
  • Gem은 무료 계정으로도 만들 수 있습니다.

9. Slack 채널에서 Claude Tag로 일 시키기

Claude Tag는 팀 채널에 Claude를 추가해 대화 맥락을 보며 정보 정리·문서 초안·도구 수정까지 맡기는 기능입니다. 팀이 함께 쓰는 업무와 반복 요청을 채널 안에서 처리할 때 씁니다.

  1. Claude를 사용할 Slack 채널 하나에 추가합니다.
  2. 필요한 도구를 Claude Tag에 연결합니다.
  3. 작업이 필요한 스레드에서 Claude를 태그해 요청합니다.
  4. Claude가 단계별로 진행하는 상황을 채널에서 확인합니다.
  5. 완료 또는 결정 요청 알림이 오면 확인하고 답합니다.
  6. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
  7. 너무 자주 또는 드물게 개입하면 개입 빈도를 조정해 달라고 말합니다.
예시
최근 3일 스레드와 Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • Team·Enterprise 요금제에서 쓸 수 있고, 처음에는 한 채널에서만 시작해 보세요.
  • 채널별 접근 권한이 나뉘고 DM·비공개 채널 내용은 그 안에만 남습니다.
  • Claude가 사용자를 대신해 응답하거나 개별 도구에 접근할 때는 매번 권한을 묻습니다.
  • 프로젝트 상태를 추적하려면 공개 채널이 좋습니다.

10. n8n으로 노코드 자동화 워크플로우 만들기

n8n은 작업 블록(노드)을 연결해 자동화 시나리오를 만드는 도구입니다. 슬랙·구글 시트·노션 같은 서비스를 엮어 알림, 리포트 발송, FAQ 챗봇을 만들 수 있습니다.

  1. n8n 클라우드에 가입하고 대시보드에서 Create Workflow로 새 워크플로우를 만듭니다.
  2. 가운데의 빌드 위드 AI 또는 n8n AI를 눌러 빌드를 선택합니다.
  3. 자동화할 내용을 트리거 시점과 처리 방식까지 구체적으로 적습니다.
  4. 만들어진 각 노드를 클릭해 설정을 확인하고, 수정할 내용은 입력창에 다시 요청합니다.
  5. API 키와 OAuth 인증 정보는 직접 연결합니다.
  6. 테스트 데이터로 실행해 동작을 확인한 뒤 실제로 사용합니다.
예시
슬랙 채널에 긴급이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일 발송해 줘
  • AI 빌더는 베타이며 프롬프트 한 번에 1크레딧을 쓰고 n8n 클라우드에서만 됩니다. 여러 요구를 한 번에 요청하면 크레딧을 아낍니다.
  • 기본 흐름 → 테스트 → 기능 추가 → 예외 처리 순으로 단계적으로 만듭니다.
  • 정형화된 반복 작업은 n8n, 판단이 필요한 챗봇형 작업은 OpenAI Agent Builder가 낫다는 비교가 있습니다.
  • 도커 설치(기본 포트 5678)는 개발에 익숙하지 않으면 권하지 않으며, 클라우드가 더 쉽습니다.

11. 코딩 에이전트 루틴·자동화 만들기

Claude Code 루틴이나 Codex 자동화는 정해진 시각이나 이벤트에 맞춰 에이전트 세션을 저절로 실행합니다. 주간 문서 갱신, 아침 브리핑처럼 사람이 시키지 않아도 돌아가야 하는 작업에 씁니다.

  1. 터미널에서 Claude Code를 실행하고 /schedule을 입력해 원하는 작업을 적습니다.
  2. Claude가 묻는 실행 시각, 알림 방식 같은 질문에 답합니다.
  3. 작업에 필요한 저장소와 커넥터를 컨텍스트로 연결합니다.
  4. 만들어진 루틴을 웹의 Claude Code에서 확인하고 실행 결과 세션을 열어 봅니다.
  5. Codex를 쓴다면 플러그인 탭에서 Slack·구글 캘린더를 먼저 연결합니다.
  6. Codex 좌측 자동화 탭의 채팅으로 만들기에서 내용과 실행 시각(예: 매일 오전 9시)을 답하고, 액티브 상태를 확인합니다.
예시
매주 main에 병합된 변경을 문서 저장소와 비교해서 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 루틴을 만들 때는 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 처음에는 결과를 직접 확인하고, 신뢰가 쌓이면 더 많은 권한을 맡기세요.
  • Codex는 플러그인 연결을 먼저 해 두지 않으면 자동화가 동작하지 않습니다.

12. 내 사용 흐름을 녹화해 스킬로 만들기

Codex의 Record & Replay는 평소 하던 화면 작업을 녹화하면 Codex가 학습해 재사용 가능한 스킬로 만들어 줍니다. 코드나 긴 프롬프트 없이 시트·노션 정리 같은 반복 작업을 자동화하고 싶을 때 씁니다.

  1. Codex 앱을 실행하고 좌측의 플러그인을 누릅니다.
  2. 컴퓨터 유즈 플러그인을 먼저 설치합니다.
  3. 레코드 앤 리플레이 플러그인을 설치합니다.
  4. 설정에서 사용해 보기 버튼을 눌러 기능을 켭니다.
  5. 새 프로젝트 추가 → 처음부터 시작을 고르고 이름을 정해 녹화를 시작합니다.
  6. 구글 시트 작성, 노션 정리 등 평소 하던 작업을 그대로 수행합니다.
  7. 정지 버튼을 눌러 녹화를 마치면 Codex가 스킬을 자동으로 만듭니다.
  8. 채팅에서 사용해 보기로 스킬을 불러와 조건을 덧붙여 실행합니다.
예시
RSS 링크가 있으면 최대한 활용하고, 사이트별로 최소 10개 이상 시트에 기록해 줘.
  • 현재 macOS에서만 사용할 수 있습니다.
  • 사용할 구글 계정은 미리 로그인해 두고 로그인 화면은 녹화에 넣지 않는 것이 안전합니다.
  • 스킬 이름은 녹화 내용에 따라 달라집니다.

13. 에이전트에 맡길 때 확인·상한 정하기

에이전트에 일을 맡길수록 어디서 사람이 확인하고 어디까지 알아서 하게 할지 미리 정하는 설계가 중요합니다. 자동화가 늘어도 내가 병목이 되지 않고 사고도 막고 싶을 때 쓰는 원칙입니다.

  1. 피드백을 줄 때마다 그 내용을 스킬이나 규칙으로 남깁니다.
  2. 에이전트에 가능한 한 많은 권한을 줍니다.
  3. 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  4. 되돌리기 어려운 지점(발송·결제·게시)은 실행 전에 내 확인을 받도록 정합니다.
  5. Claude가 쓴 결과는 다른 AI가, 다른 AI가 쓴 결과는 Claude가 독립적으로 검증하게 합니다.
  6. 가장 번거로운 업무 절차 하나를 골라 지금도 필요한지, AI로 줄일 수 있는지 점검합니다.
  • 영상 속 상한 숫자(쇼츠 500, 롱폼 1,500 크레딧)는 제작자 본인 값이므로 내 요금제에 맞게 정해야 합니다.
  • 작업을 끝내는 조건(검증 통과, 최대 반복 횟수, 시간·비용 한도)을 겹쳐 걸면 안전합니다.
  • 발송은 초안으로만 남기고 승인 후 보내게 하는 방식이 기본입니다.
