업무 자동화·에이전트

Cowork와 예약 작업, 다른 AI 도구의 자동화 기능으로 메일·회의록·보고서 같은 반복 업무를 맡기는 방법을 모았습니다. 먼저 Claude 기본 사용법과 Cowork로 폴더 업무를 맡기는 법부터 익히고, 스킬로 형식을 고정한 뒤 예약 작업·채널 연동·노코드 자동화 순으로 보시길 권합니다. 마지막에는 에이전트 설계와 루틴처럼 더 넓은 자동화를 다룹니다.

Cowork, 예약 작업, 반복 업무 자동화, 에이전트 설계, 실무 워크플로 · 영상 100개 기반 · 2026-11-10 갱신

최근 바뀐 점

  • Claude Duet이 연구 프리뷰로 공개되어, 확인이 필요한 일을 먼저 알려 주고 폰을 내려놓은 뒤에도 계속 일합니다(현재 미국 Pro·Max 대기자 명단).
  • Claude에서 만든 문서·슬라이드·대시보드 같은 아티팩트를 팀원과 함께 편집하고, 권한과 댓글로 협업할 수 있게 되었습니다.
  • Claude Code Projects(베타)로 작업별 클라우드 스레드를 병렬로 돌리고 노트북을 닫아도 일을 이어 갈 수 있습니다.
  • Claude Tag가 Slack 채널에서 팀 대화를 따라가며 일하는 방식으로 소개되었고, 팀·엔터프라이즈 계정에서 쓸 수 있습니다.

1. Claude 시작하고 스킬로 보고서 양식 고정하기

Claude 채팅에 가입해 쓰는 기본 흐름과, 반복하는 보고서 양식을 스킬로 저장해 매번 같은 형식을 얻는 방법입니다. 같은 서식의 문서를 자주 만드는 직장인에게 맞습니다.

  1. 구글 계정으로 Claude에 가입합니다. 일상 작업에는 Sonnet까지 무료로 쓸 수 있습니다.
  2. 평소 쓰는 보고서 양식 파일을 채팅에 첨부합니다.
  3. 이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘라고 요청합니다.
  4. 결과에서 스킬 저장을 눌러 내 스킬로 저장합니다.
  5. 다음부터 입력창에 /와 스킬 이름을 입력해 스킬을 고르고 주제를 적어 요청합니다.
  6. + 메뉴의 스킬에서 저장된 스킬을 확인합니다.
예시
이 보고서 형식을 분석해서 회사 보고서 만드는 스킬 제작해 줘. 답변은 한국어로 해 줘
  • 원본이 워드 파일이면 결과도 워드 파일로 만들어집니다.
  • AI 티가 나는 문장은 별도 스킬로 다듬되 본인 스타일에 맞게 고치고, 중요한 보고서는 직접 읽고 수정하세요.
  • 타이핑이 길어지면 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.

2. Cowork로 폴더 속 업무 맡기기

Cowork는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·워드 같은 결과물을 만들어 주는 기능입니다. 흩어진 자료로 보고서를 만들거나 파일을 정리할 때 씁니다.

  1. Claude 데스크톱 앱을 열고 Cowork(또는 협업)을 선택합니다.
  2. 프로젝트 또는 폴더에서 작업할 폴더를 고르고 접근 권한 창에서 항상 허용을 선택합니다.
  3. 자료(회의록, 엑셀, 메모 등)를 그 폴더에 넣습니다.
  4. 원하는 결과물을 구체적으로 적어 요청하고, Claude가 제안하는 계획을 확인한 뒤 승인합니다.
  5. 진행 상황을 지켜본 뒤 폴더에 저장된 결과 파일을 열어 확인합니다.
예시
폴더 안의 회의록·엑셀·메모를 모두 읽고 이번 주 팀 현황을 한 페이지 워드 보고서로 정리해 줘. 핵심 요약, 진행 상황, 다음 주 할 일, 리스크 순으로 써 줘.
  • 처음에는 정리처럼 범위가 분명한 작업부터 시작하고 결과를 항상 검토하세요.
  • 원본은 그대로 두고 정리본은 새 파일로 저장해 달라고 프롬프트에 적어 두세요.
  • 웹 버전은 로컬 파일 접근이 안 되므로 폴더 작업은 데스크톱 앱에서 하세요.
  • Settings의 Cowork 탭에서 역할 설명 같은 전역 지침을 설정하면 매번 설명하지 않아도 됩니다.

3. Cowork 예약 작업으로 반복 업무 돌리기

정해진 주기마다 Cowork가 같은 일을 자동으로 하도록 등록하는 기능입니다. 아침 메일 정리나 주간 지표 리뷰처럼 정기적으로 하는 일에 씁니다.

  1. 반복할 일을 자연어로 설명합니다. 입력창에 /schedule을 입력해도 됩니다.
  2. Claude가 만든 예약 작업 프롬프트 초안을 검토합니다.
  3. 필요하면 주기를 매시간·매일·평일·수동 중에서 바꿉니다.
  4. 내용이 맞으면 제안을 수락합니다.
  5. 왼쪽 사이드바의 예약 페이지에서 작업이 추가되었는지 확인합니다.
  6. 첫 실행 결과를 열어 보고 지시문이나 주기를 고칩니다.
예시
매시간 공유 드라이브 폴더의 추가·수정된 문서를 확인해서 변경자를 기록하고, 요약한 뒤 클라이언트별로 묶어 문서로 저장해 줘.
  • 7월 업데이트 이후 클라우드에서 실행되어 기기가 꺼져 있어도 돌아간다는 설명이 있습니다. 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행되었고, 놓친 작업은 복귀 후 실행되었습니다.
  • 커넥터를 설정해 두면 예약 작업에서도 쓸 수 있습니다.
  • 예약 페이지에서 지난 실행 기록 확인, 지시문·주기 수정, 즉시 실행이 가능합니다.

4. Cowork로 회의 준비와 후속 처리하기

캘린더·Slack·이메일·회의록을 연결해 회의 전 브리핑을 만들고, 회의 후 할 일과 후속 메시지까지 정리하는 흐름입니다. 영업, 법무, 마케팅처럼 회의 준비가 잦은 직무에 맞습니다.

  1. 캘린더, Slack, 이메일 같은 필요한 커넥터를 Claude에 연결합니다.
  2. 회의록이 있는 폴더를 Claude가 볼 수 있게 지정합니다.
  3. 회의와 시간을 알려 주고 준비 문서를 요청하며, 기존 문서 형식을 템플릿으로 따르라고 지시합니다.
  4. Claude가 세운 계획을 확인하고 작업이 진행되게 둡니다.
  5. 빠진 출처가 있으면 작업 중에 추가로 요청합니다.
  6. 완성된 문서의 근거를 원문에서 직접 확인하고 고칩니다.
  7. 회의 후 같은 세션에서 녹취록을 처리해 할 일과 후속 메시지를 만들게 하고, 승인한 뒤 발송합니다.
예시
Prep me for today's call with Acme Corp at 1PM.
  • 작업 도중 지시를 추가해도 처음부터 다시 하지 않고 방향을 바꿔 이어갑니다.
  • 이름을 걸고 보내는 답장은 근거를 꼭 검증하고, 발송 전 승인 단계를 거치세요.
  • 반복되는 준비 절차는 스킬로 저장해 /로 불러 쓰면 편하고, 처음에는 테스트 계정으로 돌려 보세요.

5. 플러그인으로 직무별 자동화 쓰기

플러그인은 스킬·커넥터·슬래시 명령을 직무별로 묶은 패키지입니다. 세일즈, 제품 관리, 마케팅처럼 정해진 업무 방식을 빠르게 가져다 쓰고 싶을 때 씁니다.

  1. Claude 설정의 협업 탭에서 지침의 편집을 눌러 내 역할과 작업 스타일을 적고 저장합니다.
  2. 코워크 메인 화면에서 + 버튼을 누르고 플러그인을 선택합니다.
  3. 플러그인 추가에서 원하는 플러그인을 설치합니다.
  4. 플러그인 관리에서 제공되는 명령어와 스킬을 확인합니다.
  5. 입력창에 슬래시 명령을 입력하고 회사명, 목적 같은 필요한 정보를 적어 시작합니다.
  • 공식 플러그인 11종이 오픈 소스로 공개되어 있어 회사에 맞게 수정할 수 있습니다.
  • 영상에서 명령어 표기가 불분명했으니 정확한 이름은 플러그인 관리 화면에서 확인하세요.

6. Gems와 스파크로 제미나이 자동화하기

제미나이의 Gems는 역할과 지침을 저장해 두는 나만의 비서이고, 스파크는 메일·캘린더 등을 다루며 일정에 맞춰 일하는 에이전트입니다. 구글 서비스를 업무에 쓰는 분에게 맞습니다.

  1. 제미나이 왼쪽 Gems에서 새 잼을 누르고 이름을 적습니다.
  2. 요청 사항에 역할, 할 일, 배경 정보, 결과 형식을 적습니다. 어려우면 제미나이에게 만들어 달라고 하고 내 기존 글 파일을 첨부해 분석시킵니다.
  3. 나온 요청 사항을 읽고 고쳐 붙여 넣은 뒤 저장하고 미리보기에서 테스트합니다.
  4. 스파크를 쓰려면 제미나이의 스파크 베타 탭을 열고 설정의 연결된 앱에서 구글 워크스페이스가 켜져 있는지 확인합니다.
  5. 프롬프트에 실행 시점(예: 매주 월요일 오전 8시)과 할 일을 적어 요청합니다.
  6. 좌측 일정 탭에서 등록된 일정을 확인합니다.
예시
이번 주 캘린더와 Gmail에서 답장 안 한 메일을 확인해 우선순위 브리핑 문서를 만들어 줘.
  • Gems는 무료 계정으로도 만들 수 있지만, 스파크는 구글 AI 프로 이상 구독이 필요합니다.
  • 메일은 발송하지 말고 초안으로 남기게 하면 안전합니다.
  • 요청 사항이 부실하면 결과가 잘 안 나옵니다.

7. ChatGPT Work와 Codex로 업무 자동화하기

OpenAI의 ChatGPT Work는 회의록 정리, 웹 자료 수집, 예약 작업을 맡기는 업무 에이전트이고, Codex는 자동화와 화면 녹화 기반 스킬 만들기를 지원합니다. ChatGPT를 주로 쓰는 분을 위한 대안입니다.

  1. ChatGPT 데스크탑 앱을 설치하고 Work 모드를 선택합니다.
  2. 회의록 파일을 첨부하고 실행 항목만 담당자·할 일·마감 세 열의 스프레드시트로 만들어 달라고 요청합니다.
  3. 복잡한 작업은 입력창의 + 버튼에서 계획 모드를 켜고, Work가 던지는 질문에 답합니다.
  4. Codex에서 매일 브리핑을 만들려면 플러그인 탭에서 Slack과 구글 캘린더를 먼저 연결합니다.
  5. 좌측 상단 자동화 탭의 채팅으로 만들기를 누르고, 질문에 맞춰 할 일과 실행 시각(예: 매일 오전 9시)을 답합니다.
  6. 자동화가 액티브 상태로 생성되었는지 확인합니다.
예시
회의록에서 실행 항목만 뽑아 담당자·할 일·마감 세 열의 스프레드시트로 만들어 줘.
  • 단순 작업은 기본 모드, 복잡한 작업은 계획 모드를 쓰면 모호한 부분을 먼저 물어봐 줍니다.
  • 추론 수준은 미디엄에서 시작해 결과가 부족하면 올립니다.
  • 플러그인 연결을 먼저 하지 않으면 자동화가 동작하지 않습니다.

8. Slack 채널에 Claude Tag 붙여 쓰기

Claude Tag는 Slack 같은 팀 채널에 Claude를 추가해 대화를 따라가며 일하게 하는 기능입니다. 채팅창을 오가지 않고 팀이 함께 업무를 맡기고 싶을 때 씁니다.

  1. Claude를 사용할 채널 하나에 추가합니다.
  2. 필요한 도구를 연결합니다.
  3. 채널에서 Claude를 태그해 작업을 요청합니다.
  4. 단계별 진행을 채널에서 확인하고, 완료나 결정 요청 알림이 오면 답합니다.
  5. 반복할 지침은 Remember for this channel: ... 형태로 말해 저장시킵니다.
  6. 너무 자주 또는 드물게 개입하면 개입 빈도를 조정해 달라고 말합니다.
예시
최근 3일 스레드, Google Drive 회의록, Asana 열린 작업을 확인해서 이번 주 미결 액션 아이템 목록을 만들어 줘.
  • Team과 Enterprise 계정에서 베타로 제공됩니다.
  • 처음에는 한 채널에서만 시작하세요.
  • DM과 비공개 채널에서 배운 내용은 그 안에만 남고, 모든 변경과 요청자가 기록됩니다.
  • 프로젝트 상태를 추적하려면 공개 채널이 좋습니다.

9. n8n으로 노코드 자동화 만들기

n8n은 작업 블록(노드)을 연결해 자동화 시나리오를 만드는 도구이며, AI 빌더에 한국어로 요청하면 노드까지 만들어 줍니다. 슬랙·노션·구글 시트·메일을 엮은 정형 반복 업무에 적합합니다.

  1. n8n 클라우드에 가입하고 Create Workflow로 새 워크플로우를 만듭니다.
  2. 가운데의 빌드 위드 AI 또는 n8n AI를 눌러 빌드를 선택합니다.
  3. 자동화할 내용을 트리거 시점과 처리 방식까지 구체적으로 적어 엔터를 누릅니다.
  4. 만들어진 각 노드를 눌러 설정을 확인합니다.
  5. 수정이 필요하면 입력창에 수정 요청을 적습니다.
  6. API 키와 OAuth 인증 정보는 직접 연결합니다.
  7. 테스트 데이터로 실행해 동작을 확인한 뒤 사용합니다.
예시
슬랙 채널에 긴급이 들어간 메시지가 오면 노션에 저장하고 담당자에게 이메일을 발송해 줘.
  • AI 빌더는 베타이며 n8n 클라우드에서만 쓸 수 있고, 프롬프트 한 번에 1크레딧을 씁니다.
  • 기본 흐름, 테스트, 기능 추가, 예외 처리 순으로 단계적으로 만드세요.
  • 오류가 나면 /clear로 컨텍스트를 초기화한 뒤 다시 시도합니다.
  • 정형 반복 작업은 n8n, 판단이 필요한 챗봇형 작업은 OpenAI Agent Builder를 권합니다.

10. Claude Code 루틴으로 자동 실행하기

루틴은 프롬프트, 저장소, 커넥터, 트리거를 정해 두면 Anthropic 관리형 환경에서 Claude Code 세션을 자동 실행하는 기능입니다. 노트북을 닫아도 돌아가며 일정이나 GitHub 이벤트로 시작할 수 있습니다.

  1. 터미널에서 Claude Code를 실행합니다.
  2. /schedule을 입력하고 원하는 작업을 적습니다.
  3. Claude가 묻는 질문(실행 요일·시각, 알림 여부 등)에 답합니다.
  4. 필요한 저장소를 컨텍스트로 연결합니다.
  5. 웹의 Claude Code에서 만들어진 루틴과 실행 결과 세션을 확인합니다.
예시
매주 main에 병합된 변경을 문서 저장소와 비교해서, 바뀐 부분이 있으면 문서 수정 PR을 만들어 줘.
  • 트리거(언제), 컨텍스트(무엇을 알아야 하나), 조종(어떻게 바로잡나) 세 가지를 먼저 정하세요.
  • 처음에는 결과를 직접 확인하고 신뢰가 쌓이면 권한을 더 맡기세요.
  • 여러 세션과 저장소에 걸친 큰 목표는 베타인 Claude Code Projects로 스레드를 병렬로 돌릴 수 있습니다.

11. 에이전트 자동화의 종료 조건과 개입 설계하기

AI가 시키지 않아도 돌아가는 자동화를 만들 때 언제 끝낼지, 사람이 어디서 확인할지 미리 정하는 설계 방법입니다. 자동화를 넓힐 때 생기는 병목과 사고를 줄이려는 분께 맞습니다.

  1. 자동화할 업무에서 무엇이 완료인지 누가 봐도 참/거짓을 판정할 수 있게 적습니다.
  2. 검증 통과, 최대 반복 횟수, 시간·비용 한도, 진전 없음 중단을 겹쳐 종료 조건으로 정합니다.
  3. 진행 상황을 적는 상태 파일을 두어 기억 장치로 씁니다.
  4. 크레딧처럼 한 번에 크게 나가는 것은 상한을 정합니다.
  5. 되돌리기 어려운 지점은 실행 전에 내 확인을 받도록 정합니다.
  6. 피드백을 줄 때마다 스킬이나 규칙으로 남겨 개선합니다.
  7. 만드는 AI와 검사하는 AI를 분리해 검증하게 합니다.
  • 상한 숫자는 영상 속 제작자 본인의 값이니 내 요금제에 맞게 정하세요.
  • Claude가 쓰면 Codex가, Codex가 쓰면 Claude가 검증하는 독립 검토 방식이 소개되었습니다.
  • 폭주하는 프로세스에 대비해 서킷 브레이커 같은 안전장치가 필요합니다.
  • 팀에서 가장 번잡한 업무 하나를 골라 지금도 필요한지 점검하는 것부터 시작해 보세요.
