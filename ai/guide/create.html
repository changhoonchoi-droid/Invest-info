문서·슬라이드·디자인 만들기

이 분야에서는 Claude 대화창에서 문서·슬라이드·디자인을 바로 만들고, Word·Excel·PowerPoint 안에서 Claude로 작업하고, Acrobat·젠스파크 같은 다른 도구로 PPT를 만들 수 있습니다. 먼저 1~3번 가이드로 Claude 대화창에서 결과물을 만드는 기본을 익히세요. 그다음 Office 프로그램 연동(5~7번)과 다른 도구(8~9번), 마지막으로 디자인 시스템과 시안 제작(10~12번) 순서로 보면 됩니다.

최근 바뀐 점

  • Claude 채팅과 Cowork가 하나로 합쳐져, 어느 대화에서든 문서·슬라이드·디자인을 만들 수 있습니다(10월 영상 기준).
  • 아티팩트를 팀원과 함께 편집할 수 있습니다. 보기·댓글·수정 권한을 정하고, 트래커에서는 contributor 역할로 입력과 체크만 허용할 수 있습니다.
  • Claude Design으로 영상 내레이션에 맞는 16:9 애니메이션을 만들어 편집 프로그램의 B-roll로 쓰는 작업 흐름이 소개되었습니다.
  • Adobe Acrobat의 PDF 스페이스에서 자료를 분석한 뒤 프레젠테이션 만들기로 문서 기반 슬라이드를 만들 수 있습니다.

1. Claude Docs로 문서 만들고 댓글로 고치기

Claude 대화창에서 자료를 첨부해 문서를 만들고, 고칠 부분에 댓글을 달아 Claude에게 수정시키는 방법입니다. 보고서나 브리프 초안을 빠르게 만들 때 씁니다.

  1. Claude 데스크탑에서 사진 등 참고 자료를 첨부합니다.
  2. 만들 문서를 설명하는 프롬프트를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 모두 답합니다.
  4. 나온 초안을 텍스트 편집기처럼 직접 수정합니다.
  5. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  6. 작업이 끝나면 완료 버튼을 눌러 결과를 확인합니다.
  7. 우측 상단 공유로 팀원을 초대하거나 내보내기로 Word·PDF·구글 문서 등으로 저장합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님께 보고할 런칭 브리프를 만들어 줘.
  • 질문 내용은 사용자마다 다르게 나옵니다.
  • 형식을 알고 있으면 대화창에 /docs, /slides, /designs를 입력해 바로 시작할 수 있습니다.
  • Docs 댓글에서 Claude를 멘션해 수정을 요청할 수도 있습니다.
  • Docs·Slides·Design은 모든 유료 요금제에서 쓸 수 있다고 소개됩니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성으로 녹음해 그대로 발표 자료로 바꾸는 방법입니다. 서식 대신 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청하는 프롬프트를 입력합니다.
  5. 결과에서 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

3. 아티팩트로 앱 만들고 링크로 공유하기

코딩을 몰라도 말로 설명하면 Claude가 우측 패널에 작동하는 앱을 만들어 주는 기능입니다. 가계부처럼 간단한 도구를 만들어 링크로 나눌 때 씁니다.

  1. 새 아티팩트를 누릅니다.
  2. 처음부터 시작하기를 선택합니다.
  3. 만들 앱을 설명합니다.
  4. 우측 패널에서 만들어진 앱을 직접 사용해 봅니다.
  5. 공유하려면 게시해 링크로 받습니다.
예시
월별 수입과 지출을 입력하면 합계와 카테고리별 비율을 보여 주는 가계부 앱을 만들어 줘.
  • Artifacts 탭에서는 템플릿으로 시작하고 내가 만든 아티팩트와 공유받은 아티팩트를 모아 볼 수 있습니다.

4. 아티팩트를 팀과 함께 편집하고 트래커 만들기

만든 문서나 트래커를 조직 팀원에게 공유하고 권한을 나눠 함께 쓰는 방법입니다. 체크리스트나 업무 현황판을 팀이 같이 갱신할 때 유용합니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 우선순위별 체크박스가 있는 트래커를 요청합니다.
  4. 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 달라고 합니다.
  5. 팀원을 추가하고 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  6. 입력·체크만 필요한 사람은 contributor로 지정합니다.
  7. 댓글이 달리면 Claude에게 내용이나 스타일 수정을 요청합니다.
예시
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.

5. Excel에서 Claude로 분석하고 차트 만들기

Excel 사이드바의 Claude가 통합 문서 전체를 이해해 질문 답변, 오류 추적, 피벗 테이블, 차트 작성까지 도와줍니다. Pro, Max, Team, Enterprise 플랜에서 베타로 제공됩니다.

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C를 눌러 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽습니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
  6. 피벗 테이블이 필요하면 지역·제품 같은 기준을 적어 요청합니다.
  7. 피벗 테이블로 차트를 만들게 하고 종류와 제목을 요청으로 바꿉니다.
예시
Create a pivot table showing total revenue by region and product.
  • 오류는 Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • 수식이 낯설면 부분별로 설명해 달라고 요청합니다.
  • 외부에 공유할 결과물과 민감한 데이터는 조직의 기준과 정책을 따릅니다.

6. Word에서 Claude로 초안 다듬기

Word 오른쪽 Claude 패널이 문서를 읽고 댓글 요약, 사실 확인, 서식 정리, 분량 줄이기까지 맡습니다. 모든 수정은 추적 변경으로 남아 직접 수락하거나 거절합니다.

  1. Word 오른쪽의 Claude 패널을 열고 댓글을 검토자별로 정리해 달라고 요청합니다.
  2. 변경 내용 추적을 켜고 유지하라고 요청하고, 확인창에서 Allow once를 누릅니다.
  3. Box 등의 자료와 대조해 사실 확인을 요청하고, 맞지 않는 내용은 고치게 합니다.
  4. 서식은 원하는 최종 상태를 말해 정리하고 Don't change anything else.를 덧붙입니다.
  5. 고쳐 쓸 문단을 선택하고 독자 관점으로 다시 쓰게 한 뒤 카드별로 확인합니다.
  6. 분량 목표를 말하되 지킬 부분(인용문, 날짜)을 함께 알려 줍니다.
  7. 패널에 /를 입력해 교정용 스킬을 골라 오탈자와 문법을 한 번에 교정합니다.
예시
We need to get this under 1,000 words, but don't cut any more than you need to. Keep the quotes and dates as they are.
  • Word 웹, Windows, Mac에서 쓸 수 있고 Microsoft AppSource에서 설치합니다.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남습니다.
  • 카드가 지나치게 잘라 내면 이유를 말하고 다시 제안하게 합니다.

7. PowerPoint에서 Claude로 덱 만들고 고치기

PowerPoint 안의 Claude가 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 브랜드에 맞게 슬라이드를 만들고 고칩니다. 결과물은 직접 편집 가능한 기본 도형과 차트입니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 엽니다.
  2. Claude에게 슬라이드 수, 주제, 다룰 항목, 어조를 적어 요청합니다.
  3. Claude가 변경 전에 허락을 구하면 검토하고 허용합니다.
  4. 참고 자료가 있으면 + 버튼으로 파일을 올려 맥락을 더합니다.
  5. 수정할 슬라이드나 개체를 선택하고 그 부분만 고쳐 달라고 요청합니다.
  6. 슬라이드 합치기나 순서 바꾸기를 요청하고, 삭제 확인 질문에 답합니다.
  7. 글머리표 슬라이드는 블록형 시각 레이아웃으로 바꿔 달라고 요청합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 데이터 중심의 애널리스트 어조로 만들어 줘. 필요하면 질문해 줘.
  • 요청 끝에 "필요하면 질문하라"를 덧붙이면 Claude가 먼저 기존 내용을 읽고 되묻습니다.
  • 선택한 부분만 수정하므로 나머지 내용은 그대로인지 확인합니다.
  • Google Drive·Notion 같은 커넥터 자료도 쓸 수 있습니다.
  • 복잡한 템플릿은 브랜드 지침에 맞는지 직접 확인합니다.

8. Acrobat PDF 스페이스로 문서 기반 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 보고서와 기사를 넣고 AI로 요약한 뒤 발표 슬라이드까지 만드는 방법입니다. 원문 기반이라 엉뚱한 내용이 들어갈 위험이 줄지만 유료 구독이 필요합니다.

  1. 어도비 사이트에 로그인해 PDF 스페이스에서 새 스페이스를 만듭니다.
  2. 장치, 웹링크, 텍스트 붙여 넣기로 보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  3. AI 어시스턴트에 발표 목적과 청중을 적어 요약을 요청합니다.
  4. 요약 속 숫자를 눌러 원문에서 표시된 근거 부분을 확인합니다.
  5. 프레젠테이션 만들기를 누릅니다.
  6. 청중·목적·어조·길이·템플릿을 고르고 생성합니다.
  7. 편집 화면에서 글자와 디자인을 수정한 뒤 다운로드로 저장합니다.
예시
임원 보고용 발표입니다. 이 자료에서 가장 크게 바뀐 점 3가지와 관련 수치를 정리해 줘. 근거가 없는 내용은 확인 필요로 표시해 줘.
  • 스페이스에는 최대 100개 파일까지 넣을 수 있습니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 생성된 내용과 수치는 원문과 비교해 확인합니다.
  • 예상 질문과 답변을 정리해 달라고 하면 발표 준비에도 쓸 수 있습니다.

9. 젠스파크로 수정 가능한 PPT 만들기

젠스파크 AI 슬라이드에서 텍스트와 차트를 파워포인트에서 고칠 수 있는 형태로 PPT를 내려받는 방법입니다. 첫 프롬프트를 잘 쓰는 것이 핵심입니다.

  1. 젠스파크에서 AI 슬라이드로 들어갑니다.
  2. 주제·목적·대상·분량·필수 조건이 담긴 프롬프트를 입력합니다.
  3. 프로페셔널을 선택하고 스탠더드 또는 울트라를 고릅니다.
  4. 가이드 모드를 켜고 전송합니다.
  5. 가이드의 질문에 답하고 전략·구성·디자인 단계를 승인합니다.
  6. 샘플 두 장을 확인한 뒤 나머지 전체 제작을 승인합니다.
  7. 보기 및 내보내기에서 내보내기→PPT로 받습니다.
예시
주제: 신제품 출시 보고 / 목적: 임원 승인 / 대상: 임원진 / 분량: 8장. 파워포인트에서 수정할 예정이니 텍스트는 텍스트 박스로, 차트는 수정 가능하게 만들어 줘.
  • 크리에이티브는 통 이미지로 나와 수정이 안 되므로 프로페셔널을 권합니다.
  • 처음엔 한두 장만 만들어 스타일을 확정한 뒤 확장하면 크레딧이 절약됩니다.
  • 작은 수정은 크레딧이 들기 때문에 파워포인트에서 직접 합니다.
  • 기존 PPT는 올려서 16:9, 슬라이드당 핵심 메시지 하나 같은 조건으로 디자인만 다시 만들 수 있습니다.

10. 제품 사진으로 판매용 이미지 만들기

Claude에 Artlist를 커넥터로 연결해 제품 사진 한 장으로 대표 이미지, 착용샷, 배너, SNS용 이미지를 만드는 방법입니다. 상세페이지 시안을 만들 때 씁니다.

  1. Artlist 도구로 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 요청합니다.
  2. 생성 없이 체크만 해 달라고 하며 사진을 첨부합니다.
  3. Claude가 띄우는 업로드 위젯으로 사진을 올립니다.
  4. 모델, 비율, 해상도를 구체적으로 적어 대표 이미지를 요청합니다.
  5. 착용샷·디테일·배너를 추가로 요청합니다.
  6. 유지할 것과 바꿀 것을 나누어 수정을 요청합니다.
  7. 결과를 다운로드로 저장합니다.
예시
바지를 청바지로 바꿔 줘. 신발 형태와 로고는 그대로 유지해 줘.
  • 생성 전에는 체크만 시키면 Artlist 크레딧을 아낄 수 있고, 재생성하면 크레딧이 추가로 소진됩니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 반드시 확인합니다.
  • 빠른 수정에는 Haiku 5.5가 속도와 사용량 면에서 유리하다고 소개됩니다.

11. Claude 디자인 시스템 만들고 PPTX로 내보내기

색·글꼴·컴포넌트를 미리 정해 두는 디자인 시스템을 만들면 AI 티가 덜 나고 일관된 PPT가 나옵니다. 만든 슬라이드는 PPTX로 내보내 파워포인트나 키노트에서 열 수 있습니다.

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. getdesign 사이트에서 원하는 기업의 DESIGN.md를 열어 코드를 복사해 입력창에 붙여 넣습니다.
  3. 업로드한 폰트로 일괄 적용하고 그래프 컴포넌트를 포함하라고 함께 적습니다.
  4. 폰트 파일을 드래그해 업로드한 뒤 Continue to generation으로 생성합니다.
  5. 초기 화면에서 만든 디자인 시스템을 선택하고 슬라이드 주제를 요청합니다.
  6. Claude의 질문에 답하고 Continue를 눌러 결과를 확인합니다.
  7. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 다운로드합니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘.
  • 2026년 5월 말 업데이트로 HTML→PPTX 변환 품질이 좋아지고 사용량이 Claude Code와 통합되었다고 소개됩니다.
  • 유니버셜 폰트는 어느 컴퓨터에서나 열리지만 폰트가 바뀔 수 있습니다.
  • 스크린샷 베이스 PPTX는 모양이 같지만 편집이 불가능합니다.
  • 예전 방식: 4월 공개 당시에는 깃허브 주소나 피그마 파일로 디자인 시스템을 만들었습니다(Link code on GitHub).
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.

12. Claude 디자인으로 시안에서 구현까지 가기

코드를 짜기 전에 Claude 디자인으로 화면 시안을 여러 개 뽑고, 댓글로 고친 뒤 클릭형 프로토타입을 거쳐 구현까지 이어 가는 방법입니다. 앱이나 웹 화면을 새로 설계할 때 씁니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 세부 사항은 에디터에서 직접 고치거나 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입을 만들어 달라고 요청합니다.
  7. 만족하면 Claude에게 구현을 지시하거나, Share의 Handoff to Claude Code 명령어를 Claude Code에 붙여 넣습니다.
예시
현재 앱을 살펴보고 앱에 맞는 온보딩 디자인 시안을 여러 개 만들어 줘.
  • 작은 사이드 프로젝트의 일부 화면에도 짧은 디자인 탐색을 거치면 결과가 나아집니다.
  • Claude가 작업하는 동안 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • 디자인 시스템 없이 쓰면 결과가 'AI스럽다'는 평가가 있어 먼저 만들어 두는 것이 좋습니다.
  • Tweaks로 화면의 여러 변형을 비교해 고를 수 있다고 소개됩니다.
