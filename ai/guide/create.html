문서·슬라이드·디자인 만들기

Claude의 Artifacts·Docs·Slides·Design으로 문서, 슬라이드, 디자인, 대시보드를 대화만으로 만들 수 있고, 제미나이·젠스파크·어도비 Acrobat 같은 도구로도 같은 작업을 할 수 있습니다. 먼저 Claude에서 문서와 슬라이드를 만들어 보며 감을 잡고, 디자인 시스템과 협업·공유로 넓힌 뒤, 제미나이·젠스파크·Acrobat 같은 다른 도구와 이미지·홈페이지 제작으로 이어 가는 순서를 권합니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 89개 기반 · 2026-11-20 갱신

최근 바뀐 점

  • Claude Artifacts에 시트(Sheets)와 화이트보드(Whiteboard)가 추가되고 대시보드는 데이터(Data)로 이름이 바뀌었으며, 모든 유료 플랜에서 쓸 수 있습니다.
  • Artifacts를 팀원과 공유해 함께 편집하고, 보기·댓글·수정 권한을 나누며 트래커에서는 기여자(contributor) 역할을 줄 수 있습니다.
  • Claude Fable 5.2가 유료 플랜에 출시되어 모델 전환 메뉴에서 고를 수 있고, 슬라이드 덱 같은 결과물 품질이 이전 모델보다 나아졌다고 소개됩니다.
  • Claude Design에 영상 속 말과 타이밍을 맞춘 16:9 애니메이션을 만들어 편집 프로그램에 B-roll로 얹는 활용법이 소개되었습니다.
  • Hostinger AI 빌더로 2~3분 만에 여러 페이지짜리 홈페이지를 만들고, 채팅이나 직접 편집으로 고칠 수 있습니다.

1. Claude 아티팩트로 계산기·앱 만들기

아티팩트는 채팅 옆 화면에 바로 작동하는 계산기, 퀴즈, 간단한 앱을 만들어 주는 기능입니다. 코딩을 몰라도 말로 설명하면 되며, 반복해서 쓰는 도구나 업무용 계산기를 만들 때 좋습니다.

  1. Claude 채팅창에 만들고 싶은 도구를 한 줄로 요청합니다.
  2. 엔터를 치면 채팅 옆에 작동하는 결과가 아티팩트로 나타납니다.
  3. 우측 패널에서 만들어진 앱을 직접 사용해 봅니다.
  4. 고치고 싶은 점을 채팅으로 이어서 요청합니다.
  5. 공유하려면 게시해 링크로 받습니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.
  • 월별 가계부 앱처럼 목적을 구체적으로 적을수록 원하는 결과에 가깝습니다.

2. Claude 화이트보드로 아이디어 펼치기

Claude Artifacts의 화이트보드는 아이디어 구상, 워크플로, 행사 계획을 시각적으로 펼쳐 보는 기능입니다. 모든 유료 플랜에서 쓸 수 있습니다. 시트는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵다는 평가가 있습니다.

  1. Artifacts로 이동합니다.
  2. Whiteboard를 클릭합니다.
  3. Ask Claude를 눌러 만들고 싶은 내용을 설명합니다.
  4. 배치된 화이트보드를 확인합니다.
  5. 스타일 변경, 차트 추가, 예산 같은 내용 수정을 요청합니다.
  • 사업 아이디어 공유, 워크플로·행사 흐름 정리 같은 구상 단계에 잘 맞습니다.
  • 표 작업은 시트(Sheets)가 있지만 피벗 테이블·매크로가 없으니 복잡한 계산은 구글 시트나 Excel을 쓰는 편이 낫습니다.

3. Claude로 문서·슬라이드·디자인 만들기

Claude 대화에서 문서(Docs), 슬라이드(Slides), 디자인(Designs)을 이어서 만드는 방법입니다. 같은 채팅 안에서 보고서, 이미지, 발표 자료까지 연결되고, 직접 고치거나 댓글로 수정을 시킬 수 있습니다.

  1. Opus 5.5로 보고서 등 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 설명하거나, 형식을 안다면 /slides, /docs, /designs를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 답하고 나온 초안을 직접 수정합니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  5. 수정 반복은 Sonnet 5.5로 바꿔 문구 다듬기, 차트 교체, 색상 팔레트 변경을 합니다.
  6. 작업이 끝나면 공유로 팀원을 초대하거나 내보내기로 파일을 저장합니다.
예시
신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프를 만들어 줘
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Docs 내보내기는 Word, PDF, 마크다운, 노션, 구글 문서를, Slides는 PDF, 파워포인트, PNG, 구글 슬라이드를 지원합니다.
  • Docs 댓글에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • 질문 내용은 사용자마다 다르게 나옵니다.

4. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성 메모로 먼저 녹음해 Claude에게 슬라이드로 만들게 하는 방법입니다. 서식보다 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청합니다.
  5. 작은 수정은 직접 고치고, 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

5. Claude 디자인 시스템 만들고 PPT 내보내기

디자인 시스템은 색, 폰트, 여백, 컴포넌트 같은 브랜드 규칙 모음입니다. 먼저 만들어 두면 이후 슬라이드와 프로토타입에 자동 적용되어 'AI 티'가 줄고, PPTX로 내보내 파워포인트나 키노트에서 열 수 있습니다.

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create를 누릅니다.
  2. 회사 이름과 설명을 적고, 기존 자료가 있으면 Link code on GitHub에 주소를 넣거나 피그마 파일을 넣습니다.
  3. getdesign 같은 사이트의 DESIGN.md를 복사해 붙여 넣는 방법도 있습니다.
  4. 폰트 파일을 드래그해 업로드하고 Continue to generation을 눌러 생성합니다.
  5. 초기 화면에서 만든 디자인 시스템을 선택하고 Slide deck 프로젝트를 새로 만듭니다.
  6. 슬라이드 장수와 주제를 프롬프트로 입력하고 Claude의 질문에 답한 뒤 Continue를 누릅니다.
  7. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 다운로드합니다.
  8. 받은 PPTX를 열어 폰트와 레이아웃을 확인합니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • 유니버셜 폰트는 어느 컴퓨터에서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양은 같지만 편집이 안 됩니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • 예전 방식: 클로드 디자인 사용량이 별도로 관리되어 한도가 빡빡했지만, 5월 말 업데이트로 Claude Code 사용량과 통합되었고 HTML→PPTX 변환 품질도 좋아졌습니다.
  • Claude Design은 베타 버전입니다.

6. Claude 디자인으로 시안에서 구현까지

코드를 짜기 전에 Claude Design으로 여러 시안을 보고, 댓글로 고친 뒤 클릭형 프로토타입을 거쳐 구현까지 이어 가는 방법입니다. 앱 화면이나 온보딩 같은 UI를 만들 때 유용합니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 본 뒤 만족하면 Claude에게 구현을 지시합니다.
예시
우리 앱에 맞는 온보딩 디자인 시안을 여러 개 만들어 줘
  • 작은 사이드 프로젝트의 일부 화면에도 짧은 디자인 탐색을 거치면 결과가 나아집니다.
  • Claude가 작업하는 동안 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • 프로토타입 프로젝트에서는 Share의 Handoff to Claude Code 명령어를 복사해 Claude Code에 붙여 넣어 구현으로 넘길 수도 있습니다.

7. 아티팩트를 팀과 공유해 함께 편집하기

Claude에서 만든 문서, 슬라이드, 디자인, 대시보드를 팀원과 함께 편집하는 방법입니다. 팀원마다 접근 권한을 정하고, 트래커에서는 입력과 체크만 허용하는 역할도 줄 수 있습니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  6. 트래커는 체크 표시가 저장되어 모두에게 같은 목록이 보이게 요청하고, 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • Artifacts 탭에서 템플릿으로 시작하고 내가 만든·공유받은 아티팩트를 모아 볼 수 있습니다.

8. Excel·Word·PowerPoint에서 Claude 쓰기

Claude를 Excel, Word, PowerPoint 안에서 바로 불러 쓰는 방법입니다. 스프레드시트 분석, 문서 교정, 발표 자료 제작과 수정을 파일을 떠나지 않고 할 수 있고, 변경 전에 허락을 구해 결과를 확인하며 쓸 수 있습니다.

  1. Excel에서는 통합 문서를 열고 Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  2. 목표를 구체적으로 적어 질문하고, 응답의 인용 상자를 눌러 근거 셀을 확인합니다.
  3. 피벗 테이블이 필요하면 지역·제품 같은 기준을 적어 요청하고, 이어서 차트 종류와 제목 수정을 요청합니다.
  4. Word에서는 오른쪽 Claude 패널에 Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고 확인창에서 Allow once를 누릅니다.
  5. 서식·분량은 원하는 최종 상태를 말하고, 지킬 부분과 Don't change anything else.를 덧붙입니다.
  6. PowerPoint에서는 템플릿을 연 채 슬라이드 수, 주제, 다룰 항목, 어조를 적어 덱 초안을 요청합니다.
  7. 고칠 슬라이드나 개체를 선택한 뒤 요청하면 선택한 부분만 수정됩니다.
  8. + 버튼으로 보고서나 데이터 파일을 올려 자료 기반 슬라이드를 만듭니다.

Create a pivot table showing total revenue by region and product.

9. 제미나이 캔버스·독스·슬라이드로 문서 만들기

제미나이 캔버스에서 문서를 만들고 구간별로 고친 뒤, 구글 독스나 구글 슬라이드로 내보내 PPT까지 만드는 흐름입니다. 구글 계정 환경에서 작업하는 직장인에게 맞습니다.

  1. 제미나이에서 요청을 입력하고 도구에서 캔버스를 선택해 제출합니다.
  2. 수정할 문단을 드래그해 바꿀 내용을 요청합니다.
  3. 길이 변경과 어조 변경에서 5단계 중 원하는 단계를 고릅니다.
  4. 마지막에 수정 제안으로 문서 전체를 검토합니다.
  5. 슬라이드가 필요하면 모델을 사고 또는 프로로 바꾸고 청중, 총 장수, 톤을 적어 요청합니다.
  6. 슬라이드로 내보내기 → 슬라이드 열기를 누르고 구글 슬라이드에서 파일 → 다운로드 → pptx로 저장합니다.
예시
이 내용 앞뒤 맥락에 맞게 바꿔 주고 필요하면 앞뒤도 같이 바꿔 줘
  • 캔버스를 누르지 않으면 만들어지지 않습니다.
  • 한 번에 다 만들기보다 1~2장씩 나눠 만들고, 수정 전에 슬라이드로 내보내 백업합니다.
  • 색상은 이름 대신 정확한 컬러 코드로 지정하고, 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리합니다.
  • 예전 방식: 캔버스에서 바로 PPT 슬라이드를 만들었는데 최근 오류가 나면 구글 슬라이드를 열어 오른쪽 위 제미나이로 한 장씩 만들고 파일 → 다운로드로 내보냅니다.
  • 캔버스 문서는 만들기로 웹페이지, 인포그래픽, 퀴즈, 플래시카드, 오디오 오버뷰로도 바꿀 수 있습니다.

10. 수정 가능한 PPT를 만드는 AI 슬라이드 도구

젠스파크와 Adobe Acrobat처럼 PPT 제작에 특화된 도구로 발표 자료를 만드는 방법입니다. 자료를 근거로 만들 때는 Acrobat PDF 스페이스, 프롬프트 한 번으로 시작할 때는 젠스파크가 맞습니다.

  1. 젠스파크에서 AI 슬라이드로 들어가 주제·목적·대상·분량·필수 조건이 담긴 프롬프트를 입력합니다.
  2. 프로페셔널을 선택하고 가이드 모드를 켜서 전송합니다.
  3. 질문에 답하고 전략·구성·디자인 단계를 승인한 뒤, 샘플 두 장을 확인하고 전체 제작을 승인합니다.
  4. 보기 및 내보내기에서 내보내기→PPT로 받습니다.
  5. 자료 기반으로 만들려면 Adobe Acrobat에서 PDF 스페이스 만들기를 선택하고 보고서·기사 링크 등을 추가합니다.
  6. 프레젠테이션 만들기를 누르고 청중, 목적, 어조를 선택해 슬라이드를 생성합니다.
  7. 편집 화면에서 내용과 디자인을 고치고 다운로드로 저장합니다.
예시
파워포인트에서 수정할 예정이니 모든 텍스트를 수정 가능한 텍스트 박스로, 차트도 수정 가능하게 만들어 줘
  • 젠스파크의 크리에이티브는 통 이미지로 나와 수정이 안 되므로 프로페셔널을 권합니다.
  • 처음엔 한두 장만 만들어 스타일을 확정한 뒤 확장하면 크레딧이 절약되고, 작은 수정은 파워포인트에서 직접 합니다.
  • Acrobat은 요약 속 숫자를 누르면 원문 근거가 표시되지만, 수치는 원문과 비교해 확인합니다. 유료 구독이 필요합니다.
  • 기존 PPT는 젠스파크에 올려 16:9, 슬라이드당 핵심 메시지 하나 조건으로 디자인만 다시 만들 수 있습니다.

11. 디자인 규칙서로 항상 같은 톤의 PPT 만들기

AI가 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 색, 글꼴, 크기, 장당 글자 수를 수치로 정한 디자인 규칙서를 만들고 스킬로 저장해 두면 다음 작업에서도 같은 톤을 유지할 수 있습니다.

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준으로 디자인 규칙서를 만듭니다.
  2. 규칙서로 Claude Code나 코덱스에서 PPT 작업을 합니다.
  3. 작업을 마친 뒤 지금까지의 대화와 결과물로 스킬을 만들어 달라고 요청합니다.
  4. 다음 PPT 작업 때 그 스킬을 불러와 대본만 넣습니다.
  5. 업무 매뉴얼도 함께 남겨 달라고 요청합니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 수치로 명확히 적습니다.
  • 영상이 제안한 예시 기준은 색 3가지(검정·흰색·파랑), 본문 26~30px, 제목 68px, 장당 약 200자입니다.
  • 차트는 이미지가 아니라 데이터 편집이 가능한 형태로 요청하고, HTML과 PPTX의 디자인을 계속 비교해 맞춥니다.
  • 검사는 자동 검사, 눈 검사, 숫자 검산 세 가지를 거칩니다.

12. AI로 이미지·로고·제품 사진 만들기

제미나이(나노바나나)와 Artlist 같은 도구로 이미지를 만들고 고치는 방법입니다. 원본의 얼굴·포즈를 유지한 채 필요한 부분만 바꾸거나, 제품 사진으로 광고·상세페이지용 이미지를 만들 수 있습니다.

  1. 수정할 사진이나 참고 이미지를 업로드합니다.
  2. 바꿀 것과 유지할 것을 나누어 구체적으로 요청합니다.
  3. 결과에서 얼굴·포즈·로고가 유지됐는지 확인하고, 아니면 같은 요청을 다시 보냅니다.
  4. 로고는 마음에 드는 참고 로고 이미지와 함께 주제·상징물·스타일·색상·분위기를 적어 요청합니다.
  5. 엠블럼만 이미지로 저장해 미리캔버스의 업로드로 넣고 텍스트를 추가해 마무리합니다.
  6. 제품 판매용 이미지는 Claude에 Artlist를 커넥터로 연결해 사진을 올리고 비율·해상도를 적어 요청합니다.
  7. 결과를 다운로드로 저장합니다.
예시
다른 부분은 바꾸지 말고 배경을 깔끔한 스튜디오로 바꿔 줘. 빛과 조명도 자연스럽게
  • 결과는 매번 달라서 마음에 들지 않으면 같은 요청을 다시 시도합니다.
  • 화면 캡처 대신 다운로드해야 화질이 깨지지 않습니다. 미리캔버스의 왕관 표시 폰트는 유료입니다.
  • Artlist에서는 생성 없이 체크만 시키면 크레딧을 아끼고, 재생성하면 크레딧이 추가로 소진됩니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 반드시 확인합니다.
  • 예전 방식: 나노바나나를 LM Arena에서 무료·무가입으로 써 보는 방법이 소개되었지만, 이후 제미나이에 정식 탑재되어 제미나이에서 바로 쓰는 것이 편합니다.

13. AI 빌더로 홈페이지·랜딩 페이지 만들기

Hostinger, Readdy AI, Google AI Studio처럼 원하는 사이트를 말로 설명하면 홈페이지를 만들어 주는 도구를 쓰는 방법입니다. 사업 소개나 상품 랜딩 페이지를 빠르게 시안으로 만들 때 좋습니다.

  1. 첫 화면 입력창에 사이트 이름, 색감, 제목, 구성을 적어 보냅니다.
  2. 스크린샷이나 참고 사이트 링크가 있으면 함께 넣어 분위기를 전달합니다.
  3. AI가 확인을 물으면 내용을 읽고 확인을 누릅니다(Hostinger).
  4. 2~3분 뒤 생성된 사이트를 확인합니다.
  5. 텍스트나 요소는 직접 눌러 고치고, 큰 변경은 채팅으로 요청합니다.
  6. Readdy는 편집 선택으로 고칠 부분을 고른 뒤 일상 언어로 요청합니다.
  7. 마음에 들면 출시나 퍼블리시로 공개합니다.
예시
해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘
  • 이름과 분위기를 구체적으로 적을수록 카피와 디자인이 맞춰지고, 생성된 임의 내용은 내 것으로 바꿔 줍니다.
  • 디자인은 말보다 이미지가 정확해서 참고할 화면 캡처를 붙여 넣으면 좋고, 위치 설명이 어려우면 어노테이트 기능으로 화면에 직접 표시합니다.
  • 수정 요청은 한 번에 하나씩 입력해야 어긋남이 적고, 숫자·후기 같은 생성 문구는 사실에 맞게 고칩니다.
  • 공개 게시와 도메인 연결에는 유료 결제가 필요하고, 요금은 기간과 플랜에 따라 달라지니 결제 전에 확인합니다.
