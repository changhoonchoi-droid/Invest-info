1. Claude 아티팩트로 앱·위젯 만들기

아티팩트는 채팅 옆에 바로 작동하는 계산기, 퀴즈, 가계부 같은 결과물을 만들어 주는 기능입니다. 코딩을 몰라도 말로 설명하면 만들어지며, 링크로 공유할 수 있습니다. 가장 먼저 해 볼 기본 기능입니다.

  1. 클로드 채팅창에 만들고 싶은 것을 한 줄로 요청합니다.
  2. 또는 Artifacts 탭에서 새 아티팩트를 누르고 처음부터 시작하기를 선택합니다.
  3. 만들 앱을 설명합니다 (예: 월별 가계부 앱).
  4. 엔터를 치면 채팅 옆 우측 패널에 작동하는 결과물이 나타납니다.
  5. 패널에서 직접 사용해 보고 고칠 점을 채팅으로 요청합니다.
  6. 공유하려면 게시해 링크를 받습니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.
  • 코딩을 몰라도 말로 설명하면 앱을 만들 수 있습니다.

2. Claude Docs·Slides·Design 한 채팅에서 만들기

Claude 한 대화 안에서 문서, 슬라이드, 디자인을 이어서 만드는 기능입니다. 대화 내용을 바탕으로 결과물이 만들어지고, 고칠 부분에 댓글을 달면 Claude가 그 부분만 수정합니다. 보고서에서 발표 자료까지 한 흐름으로 작업할 때 씁니다.

  1. 보고서 내용을 먼저 대화로 정리합니다 (방향을 잡을 때는 Opus 5.5).
  2. 만들 결과물을 설명하거나, 형식을 안다면 /docs, /slides, /designs를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 모두 답합니다.
  4. 초안이 나오면 직접 고치거나, 고칠 부분을 드래그해 댓글로 지시를 남깁니다.
  5. 같은 대화에서 슬라이드를 요청하고, 시장 조사는 차트로 넣어 달라고 지시합니다.
  6. 빠른 수정 반복은 Sonnet 5.5로 바꿔 진행합니다.
  7. 공유로 팀원을 초대하거나 내보내기로 Word·PDF·PPT 등으로 저장합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님께 보고할 런칭 브리프를 만들어 줘
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Docs 내보내기는 Word·PDF·마크다운·노션·구글 문서, Slides는 PDF·파워포인트·PNG·구글 슬라이드를 지원합니다.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.

3. 아티팩트를 팀과 공유해 함께 편집하기

Claude에서 만든 문서·슬라이드·대시보드·트래커를 팀원과 같이 보고 댓글을 달고 수정할 수 있습니다. 누가 활동 중인지도 실시간으로 보입니다. 팀 협업이 필요할 때 씁니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  6. 트래커는 체크박스가 있는 목록을 요청하고, 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시
위 문서를 바탕으로 우선순위별 체크박스가 있는 트래커를 만들어 줘. 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.

4. Claude 디자인으로 시안·SNS 이미지 만들기

Claude 디자인은 브랜드 시안, SNS 이미지, 앱 화면을 말로 설명해 만드는 도구입니다. 코드를 짜기 전에 짧게 시안을 탐색하면 결과가 좋아집니다. 시안에 댓글로 피드백하고 클릭형 프로토타입을 거쳐 구현까지 이어 갈 수 있습니다.

  1. 브랜드 방향 세 가지를 캔버스에 나란히 보여 달라고 요청합니다.
  2. 시안마다 팔레트, 폰트, 로고, 인스타 샘플 한 장씩 만들도록 지시합니다.
  3. 마음에 드는 시안을 고르고 댓글 기능으로 요소별로 수정합니다.
  4. 세부 사항은 에디터에서 직접 고칩니다.
  5. 선택한 시안으로 1:1, 4:5, 9:16, 16:9 규격의 이미지를 요청합니다.
  6. 앱 화면이라면 클릭해 볼 수 있는 프로토타입을 요청하고, 만족하면 구현을 지시합니다.
예시
신메뉴 런칭용 브랜드 방향 3가지를 캔버스에 나란히 보여 줘. 시안마다 팔레트, 폰트, 로고, 인스타 샘플 한 장씩 만들어 줘.
  • 디자인은 결과를 보고 직접 손봐 주는 것이 좋습니다.
  • Claude가 작업하는 동안 다른 일을 하다 돌아와 확인해도 됩니다.
  • 디자인 시스템을 먼저 만들어 두면 브랜드에 맞는 결과가 나옵니다.

5. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성으로 녹음해 Claude에게 넘겨 발표 자료로 만드는 방법입니다. 서식보다 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청합니다.
  5. 작은 수정은 직접 고치고, 큰 수정은 댓글로 Claude에게 보냅니다.
  6. 완성되면 팀에 공유하거나 내보내기해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

6. 제미나이 캔버스로 문서·PPT 만들기

제미나이 캔버스는 답변 옆 작업창에서 문서와 슬라이드를 함께 편집하는 기능입니다. 원하는 구간만 드래그해 고치고, 구글 독스·슬라이드로 내보내 PPT로 저장할 수 있습니다. Claude 외 도구로 문서·PPT를 만들고 싶을 때 씁니다.

  1. 채팅창에서 도구를 눌러 캔버스를 선택합니다.
  2. PPT를 만들 때는 모델을 사고 또는 프로로 바꿉니다.
  3. +에서 파일 업로드로 자료를 첨부하거나 내용을 입력하고, 대상과 톤을 적어 요청합니다.
  4. 문서는 고칠 문단을 드래그해 요청하고, 길이·어조는 5단계 중 고릅니다.
  5. 마지막에 수정 제안으로 문서 전체의 어색한 곳을 검토합니다.
  6. 슬라이드는 슬라이드로 내보내기 → 슬라이드 열기 후 구글 슬라이드에서 파일 → 다운로드 → pptx를 선택합니다.
예시
첨부한 자료로 임원 보고용 PPT 슬라이드를 만들어 줘. 색상은 #1F3A5F를 메인으로 하고, 모든 슬라이드 좌상단에 제목을 넣어 줘.
  • 캔버스를 누르지 않으면 만들어지지 않습니다.
  • 한 번에 다 만들지 말고 1~2장씩 나눠 만들고, 수정 전에 미리 슬라이드로 내보내 백업합니다.
  • 색상은 이름 대신 정확한 컬러 코드로 지정합니다.
  • 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리하는 분업을 권합니다.
  • 예전 방식: 캔버스 대신 구글 슬라이드를 열어 오른쪽 위 제미나이로 한 장씩 만드는 방법(캔버스 PPT 생성 오류 시 대안).

7. Acrobat PDF 스페이스로 자료 기반 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 보고서와 기사 링크를 넣고, 요약부터 프레젠테이션 초안까지 만드는 방법입니다. 요약 속 숫자를 누르면 원문의 근거가 표시되어 확인이 쉽습니다. 유료 구독이 필요합니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 자료를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적과 청중을 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 근거 부분을 확인합니다.
  6. 프레젠테이션을 선택하고 대상자·톤·길이·템플릿을 골라 프레젠테이션 생성을 누릅니다.
  7. 편집 화면에서 글자와 디자인을 수정한 뒤 다운로드로 저장합니다.
예시
이 자료로 경영진 대상 발표를 준비하려 해. 핵심 변화 3가지와 수치를 요약하고, 근거가 없는 내용은 확인 필요로 표시해 줘.
  • 문서 기반이라 원문이 잘 반영되어 거짓 정보가 들어갈 위험이 줄지만, 수치는 원문과 비교해 확인합니다.
  • 파일은 최대 100개까지 넣을 수 있고, 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 예상 질문과 답변을 정리해 발표 준비까지 할 수 있습니다.

8. 젠스파크로 수정 가능한 PPT 만들기

젠스파크 AI 슬라이드로 PPT를 만들되, 파워포인트에서 글자와 차트를 직접 고칠 수 있게 받는 방법입니다. 첫 프롬프트를 꼼꼼히 쓰는 것이 핵심입니다. 기존 PPT의 디자인만 바꾸는 데도 쓸 수 있습니다.

  1. 젠스파크에서 AI 슬라이드로 들어갑니다.
  2. 주제·목적·대상·분량·필수 조건이 담긴 프롬프트를 입력합니다.
  3. 프로페셔널을 선택하고 스탠더드 또는 울트라를 고릅니다.
  4. 가이드 모드를 켜고 전송합니다.
  5. 가이드의 질문에 답하고 전략·구성·디자인 단계를 승인합니다.
  6. 샘플 두 장을 확인한 뒤 나머지 전체 제작을 승인합니다.
  7. 보기 및 내보내기에서 내보내기→PPT로 받습니다.
예시
주제: 2027년 마케팅 계획 / 목적: 팀 내부 공유 / 대상: 팀원 / 분량: 10장. 파워포인트에서 수정할 예정이니 모든 텍스트는 텍스트 박스로, 차트는 수정 가능한 형태로 만들어 줘.
  • 크리에이티브는 통 이미지로 나와 수정이 안 되므로 프로페셔널을 권합니다.
  • 처음엔 한두 장만 만들어 스타일을 확정한 뒤 확장하면 크레딧이 절약됩니다.
  • 작은 수정은 크레딧이 드니 파워포인트에서 직접 합니다.
  • 기존 PPT는 파일을 올리고 16:9 비율, 슬라이드당 핵심 메시지 하나, 모든 텍스트를 수정 가능한 텍스트 박스로 하라고 요청하면 디자인만 바꿉니다.

9. 디자인 시스템으로 일정한 톤의 PPT 만들기

AI가 만든 PPT가 들쭉날쭉한 것은 기준이 없기 때문입니다. 색·글꼴·글씨 크기 같은 디자인 규칙서(디자인 시스템)를 만들어 두면 매번 같은 톤으로 만들 수 있습니다. 클로드 디자인이나 Claude Code로 진행하고, 스킬로 저장해 재사용합니다.

  1. claude.ai/design의 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. getdesign 같은 사이트에서 원하는 기업의 DESIGN.md를 복사해 입력창에 붙여 넣습니다.
  3. 사용할 폰트 파일을 업로드하고 그래프 컴포넌트를 포함하라고 함께 적습니다.
  4. Continue to generation으로 디자인 시스템을 생성합니다.
  5. 초기 화면에서 만든 디자인 시스템을 선택하고 PPT를 요청합니다.
  6. Claude의 질문에 답하고 Continue를 누른 뒤 결과를 확인합니다.
  7. Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 내려받습니다.
  8. 작업 후 '지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘'라고 요청해 스킬로 저장합니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 색 3가지, 본문 크기, 장당 글자 수처럼 수치로 적습니다.
  • 유니버셜 폰트는 어느 컴퓨터에서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양이 같지만 편집이 불가능합니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • HTML과 PPTX는 생성 방식이 달라 디자인이 틀어질 수 있으니 비교해 맞춥니다.
  • 예전 방식: 2026년 5월 말 업데이트 전에는 HTML→PPTX 변환 품질이 낮아 폰트 깨짐이 잦았고, 사용량도 별도로 관리되었습니다.

10. Word·PowerPoint·Excel에서 Claude 쓰기

Claude를 Microsoft Word, PowerPoint, Excel 안에 붙여 문서·슬라이드·스프레드시트를 직접 다듬는 방법입니다. 선택한 부분만 고치고, 모든 수정은 검토 카드나 추적 변경으로 남아 직접 수락하거나 거절합니다. 유료 플랜(Pro, Max, Team, Enterprise)에서 쓸 수 있습니다.

  1. Word는 오른쪽의 Claude 패널을 열고, Excel은 Mac Control + Option + C, Windows Control + Alt + C로 사이드바를 엽니다.
  2. Word에서는 Turn on Track Changes and keep it on for everything you do in this document.로 추적 변경을 먼저 켭니다.
  3. 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기를 순서대로 요청하고 수정 카드를 확인해 적용합니다.
  4. PowerPoint에서는 + 버튼으로 참고 파일을 올려 슬라이드를 만들거나, 수정할 슬라이드·개체를 선택한 뒤 요청해 그 부분만 고칩니다.
  5. Excel에서는 목표를 구체적으로 질문하고, 응답의 인용 상자를 눌러 근거 셀을 검증합니다.
  6. 피벗 테이블과 차트는 Create a pivot table showing total revenue by region and product.처럼 요청한 뒤 차트 종류와 제목을 요청으로 바꿉니다.
예시
Create a pivot table showing total revenue by region and product.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 고칠 때 지킬 부분(인용문, 날짜)을 함께 알려 주고 Don't change anything else.를 덧붙이면 안전합니다.
  • PowerPoint 결과물은 기본 도형과 차트라 개별 편집이 됩니다. 복잡한 템플릿은 브랜드 지침과 맞는지 직접 확인합니다.
  • 민감하거나 규제 대상인 데이터는 조직의 데이터 처리 정책을 따릅니다.

11. 제품 사진으로 광고·상세페이지 이미지 만들기

상품 사진 한 장으로 대표 이미지, 착용샷, 배너, SNS 광고, 상세페이지 시안까지 만드는 방법입니다. Claude에 Artlist를 연결하거나 Genspark Design을 쓰는 두 가지 길이 있습니다. 쇼핑몰·SNS 운영자에게 유용합니다.

  1. Claude에 Artlist 커넥터를 연결하고, 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 요청합니다 (생성 없이 체크만).
  2. Claude가 띄우는 업로드 위젯으로 제품 사진을 올립니다.
  3. 모델, 비율(정사각형), 해상도(2K)를 구체적으로 적어 대표 이미지를 요청합니다.
  4. 착용샷·디테일 컷·배너를 추가로 요청합니다.
  5. 바지를 청바지로 바꿔 줘처럼 유지할 것과 바꿀 것을 나누어 수정합니다.
  6. Genspark를 쓴다면 디자인에서 +로 광고 레퍼런스와 제품 사진을 첨부하고 광고 키 비주얼을 요청합니다.
  7. 광고 시안을 기준으로 디자인 시스템과 상세페이지, 랜딩페이지를 이어서 요청합니다.
  8. 결과를 다운로드로 저장합니다.
예시
첨부한 운동화 사진으로 정사각형 2K 대표 이미지를 만들어 줘. 신발 형태와 로고는 그대로 유지해 줘.
  • 생성 전에 체크만 시키면 크레딧을 아낄 수 있고, 재생성하면 크레딧이 추가로 소진됩니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 반드시 확인합니다.
  • Genspark는 질문을 비워 두면 AI가 제안해 진행하며, 공유로 편집자를 초대할 수 있습니다.
  • 빠른 수정 작업에는 Haiku 5.5가 속도와 사용량 면에서 유리합니다.

12. Claude 디자인으로 영상용 애니메이션 만들기

내레이션 자막(SRT)을 Claude 디자인에 넣어 말과 맞는 16:9 애니메이션을 만들고 영상의 B-roll로 쓰는 방법입니다. 영상을 자주 만드는 사람에게 유용합니다.

  1. 카메라와 화면을 녹화하고 MP3를 추출해 ChatGPT에 올립니다.
  2. SRT 트랜스크립트를 만들어 달라고 요청해 타임스탬프가 있는 자막을 받습니다.
  3. claude.ai/design을 열고 SRT 파일과 애니메이션 프롬프트를 붙여 넣습니다.
  4. 로고와 인터페이스 스크린샷을 첨부하고 모델 설정을 높게(extra 또는 max) 둡니다.
  5. 엔터를 눌러 생성을 기다리고, 멈춘 듯하면 계속하라고 입력합니다.
  6. 완성된 영상을 내레이션과 함께 보며 수정 사항을 요청합니다.
  7. 편집 프로그램에 B-roll 층으로 넣어 필요한 부분만 골라 씁니다.
  • 기본값은 글자가 많게 나오므로 16:9 그래픽, 움직임 위주, 글자 최소로 요청합니다.
  • 생성에는 영상 길이에 따라 30분~2시간이 걸립니다.
  • 진행이 멈췄는데 알려 주지 않는 경우가 있어 계속하라고 지시해야 합니다.
  • 높은 사고 수준 설정이 중간 수준보다 결과가 훨씬 좋았다고 합니다.

13. 스크린샷으로 랜딩 페이지·UI 디자인 만들기

마음에 드는 사이트의 스크린샷이나 컴포넌트 코드를 AI에 주면 비슷한 느낌의 웹페이지를 만들어 줍니다. 디자인은 말보다 이미지가 훨씬 정확합니다. 구글 AI 스튜디오와 스티치를 사용합니다.

  1. 프레이머 리소스의 마켓플레이스에서 마음에 드는 템플릿을 고르고 프리뷰로 실제 화면을 띄웁니다.
  2. 스크롤 캡처 도구로 웹사이트 전체를 캡처해 복사합니다.
  3. 구글 AI 스튜디오 프롬프트 입력창에 이미지를 붙여 넣고 비슷한 느낌의 랜딩 페이지를 요청합니다.
  4. 빌드를 눌러 결과를 원본과 비교합니다.
  5. 고칠 곳은 어노테이트 앱으로 화면에 직접 표시하고 애드 텍스트로 요청을 적은 뒤 애드투 챗, 샌드 프롬프트를 누릅니다.
  6. 앱 화면이라면 스티치에서 프롬프트를 입력하고 Generate로 만든 뒤, 화면을 선택해 Instant Prototype으로 클릭 가능한 프로토타입을 만듭니다.
예시
해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘
  • 위치를 글로 설명하기 어려울 때는 어노테이트가 효과적입니다.
  • 컴포넌트 사이트의 코드를 --- 구분선으로 나눠 함께 붙여 넣으면 디자인 품질이 올라갑니다.
  • 스티치는 구글 계정만 있으면 무료이고, HTML과 Tailwind CSS를 생성하므로 네이티브 앱 코드는 추가 변환이 필요합니다.
