문서·슬라이드·디자인 만들기

Claude의 Docs·Slides·Design·Artifacts부터 Gemini 캔버스, 젠스파크, 어도비 Acrobat, 이미지·영상 생성 도구까지 써서 문서·슬라이드·디자인·웹페이지를 만드는 방법을 모았습니다. 먼저 Claude 대화에서 문서와 슬라이드를 만들고 고치는 기초를 익힌 뒤, 디자인 시스템으로 같은 톤을 유지하는 법과 Gemini·젠스파크·PPT 연동, 엑셀·워드 작업 순서로 보면 좋습니다. 마지막에는 이미지·로고·홈페이지·영상 제작 같은 응용 가이드를 확인하세요.

  • Claude Artifacts에 시트(Sheets)와 화이트보드(Whiteboard)가 추가되고 대시보드는 데이터(Data)로 이름이 바뀌었으며, 모든 유료 플랜에서 쓸 수 있습니다(11/13).
  • Artifacts를 팀원과 공유해 함께 편집하고, 댓글 작성자·기여자(contributor) 등 권한을 나눌 수 있습니다(11/04).

  • Claude Design에 자막(SRT)과 프롬프트를 넣어 영상용 16:9 애니메이션을 만드는 작업 흐름이 공개되었습니다(11/04).

1. Claude 대화에서 문서·슬라이드 만들기

Claude 대화에서 Docs, Slides, Designs를 바로 만들 수 있습니다. 기존 대화 내용이 그대로 재료가 되어, 보고서 정리 후 발표 자료까지 한 채팅에서 이어 갈 수 있습니다. 모든 유료 요금제에서 쓸 수 있습니다.

  1. Opus 5.5로 보고서 등 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 설명해 Claude가 형식을 고르게 하거나, 형식을 안다면 /slides, /docs, /designs를 입력합니다.
  3. Sonnet 5.5로 바꿔 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 반복합니다.
  4. 직접 슬라이드를 고치거나, 특정 문단을 선택해 바꿀 내용을 말하면 그 부분만 수정됩니다.
  5. 완성되면 공유로 팀원을 초대하거나 내보내기에서 PDF·파워포인트 등 원하는 형식으로 저장합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • Docs에서는 문단을 드래그해 댓글로 지시하면 그 부분만 고쳐 줍니다. 코멘트에서 Claude를 멘션해 수정을 요청할 수도 있습니다.
  • Docs 내보내기는 Word, PDF, 마크다운, 노션, 구글 문서를, Slides 내보내기는 PDF, 파워포인트, PNG, 구글 슬라이드를 지원합니다.
  • Design은 베타 단계입니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성 메모로 녹음해 Claude에게 넘기면 발표 자료가 됩니다. 서식보다 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 아래 예시 프롬프트로 슬라이드 제작을 요청합니다.
  5. 작은 수정은 직접 고치고, 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

3. Artifacts로 앱·계산기 만들기

Artifacts는 채팅 옆에 바로 작동하는 앱, 계산기, 퀴즈 같은 결과물을 만들어 주는 기능입니다. 코딩을 몰라도 말로 설명하면 되고, 링크로 공유할 수 있습니다.

  1. 새 아티팩트를 누릅니다.
  2. 처음부터 시작하기를 선택합니다.
  3. 만들 앱을 설명합니다. 예: 월별 가계부 앱.
  4. 우측 패널에서 만들어진 앱을 직접 사용해 봅니다.
  5. 고칠 부분은 채팅으로 요청하고, 공유하려면 게시해 링크로 받습니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.

4. 화이트보드로 아이디어 펼치기

Artifacts의 화이트보드는 사업 아이디어, 워크플로, 행사 계획 같은 구상 단계를 시각적으로 펼쳐 보는 기능입니다. 시트(Sheets)와 데이터(Data)도 함께 추가되어 모든 유료 플랜에서 쓸 수 있습니다.

  1. Artifacts로 이동합니다.
  2. Whiteboard를 클릭합니다.
  3. Ask Claude를 눌러 만들고 싶은 내용을 설명합니다.
  4. 배치된 화이트보드를 확인하고 스타일 변경, 차트 추가, 예산 같은 내용 수정을 요청합니다.
  • 시트에는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵다는 평가가 있습니다. 구상 정리용으로 화이트보드가 더 잘 맞습니다.
  • 대시보드는 Data로 이름이 바뀌었습니다.

5. 아티팩트를 팀과 함께 편집하기

Claude에서 만든 문서·슬라이드·디자인·트래커를 팀원과 공유해 실시간으로 함께 편집합니다. 팀원마다 보기·댓글·수정 권한을 나누고, 댓글이 달리면 Claude에게 수정을 시킬 수 있습니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 트래커라면 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 달라고 요청합니다.
  6. 입력·체크만 필요한 사람은 contributor로 지정합니다.
  7. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
예시
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.

6. 디자인 시스템으로 같은 톤 유지하기

색, 폰트, 여백, 레이아웃을 규칙으로 정리한 디자인 시스템을 먼저 만들어 두면 이후 PPT·앱 시안이 항상 같은 톤으로 나옵니다. Claude Design에서 만들 수 있고, 사용량은 Claude Code 사용량과 통합되어 구독 플랜 안에서 쓸 수 있습니다.

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. getdesign 사이트에서 원하는 기업의 DESIGN.md를 열어 코드를 복사합니다.
  3. 클로드 디자인 입력창에 붙여 넣습니다.
  4. 업로드한 폰트로 일괄 적용하고 그래프 컴포넌트를 포함하라고 함께 적습니다.
  5. 폰트 파일(예: 프리텐다드)을 모두 드래그해 업로드합니다.
  6. 상단의 Continue to generation으로 디자인 시스템을 생성합니다.
  7. 이후 새 프로젝트를 만들 때 이 디자인 시스템을 선택합니다.
예시
업로드한 폰트로 일괄 적용하고, 그래프 컴포넌트를 포함해 줘
  • 디자인 시스템 없이 쓰면 결과물이 AI스러워지기 쉽습니다.
  • 회사 자료가 있으면 Link code on GitHub에 깃허브 주소나 피그마 파일을 넣어 만들 수도 있습니다.
  • 예전 방식: 디자인 MD를 Claude Code에 붙여 PPT용으로 변환하는 방식도 쓰였습니다.

7. Claude Design으로 PPT 만들고 PPTX로 내보내기

디자인 시스템을 적용해 PPT를 만들고 수정 가능한 PPTX 파일로 내보냅니다. 업데이트로 HTML에서 PPTX 변환 품질이 좋아져 폰트 깨짐과 레이아웃 붕괴가 줄었습니다.

  1. 초기 화면으로 돌아가 디자인 시스템을 만들어 둔 것으로 설정합니다.
  2. 최신 AI 트렌드 리서치 주제로 PT 만들어 줘처럼 요청합니다.
  3. Claude가 던지는 주제·대상·디자인 질문에 답하고 Continue를 누릅니다.
  4. 결과를 확인하고 수정이 필요하면 클로드 디자인 안에서 편집합니다.
  5. 우측 상단 Share → Export에서 파워포인트를 고릅니다.
  6. 옵션 중 커스텀 폰트를 선택하고 다운로드합니다.
  7. 받은 PPTX를 파워포인트나 키노트에서 열어 폰트와 레이아웃을 확인합니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • 유니버셜 폰트는 어느 컴퓨터에서나 열리지만 폰트가 바뀔 수 있습니다.
  • 스크린샷 베이스 PPTX는 모양이 같지만 편집이 불가능합니다.
  • 발표 메모가 필요하면 슬라이드 프로젝트에서 Use speaker notes를 체크합니다.
  • 프레젠트 버튼으로 바로 발표할 수도 있습니다.

8. Claude Design으로 시안에서 구현까지

코드를 짜기 전에 짧게 디자인 시안을 탐색하면 결과가 나아집니다. 시안 요청, 댓글 피드백, 직접 수정, 클릭형 프로토타입을 거쳐 Claude Code 구현으로 넘기는 흐름입니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 만족하면 Claude에게 구현(build)을 지시합니다. Share의 Handoff to Claude Code 명령어를 복사해 Claude Code에 붙여 넣는 방법도 있습니다.
예시
현재 앱을 살펴보고 우리 앱에 맞는 온보딩 디자인 시안을 여러 개 만들어 줘
  • 우측 하단 Tweaks로 화면의 여러 변형을 비교해 고를 수 있습니다.
  • Claude가 작업하는 동안 다른 일을 하다 돌아와 결과를 확인해도 됩니다.

9. Word·PowerPoint·Excel에서 Claude 쓰기

Claude for Word, PowerPoint, Excel은 각 프로그램 안의 패널에서 문서를 읽고 직접 편집까지 해 줍니다. 모든 수정은 검토 카드와 추적 변경으로 나타나 직접 수락하거나 거절할 수 있습니다. Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.

10. 젠스파크로 수정 가능한 PPT 만들기

젠스파크 AI 슬라이드는 프롬프트 하나로 조사·기획·제작을 자동으로 진행합니다. 첫 프롬프트에 파워포인트에서 수정할 예정이라는 조건을 넣으면 텍스트와 차트가 수정되는 PPT로 내보낼 수 있습니다.

  1. 젠스파크에서 AI 슬라이드로 들어갑니다.
  2. 주제·목적·대상·분량·필수 조건이 담긴 프롬프트를 입력합니다.
  3. 프로페셔널을 선택하고 스탠더드 또는 울트라를 고릅니다.
  4. 가이드 모드를 켜고 전송합니다.
  5. 가이드의 질문에 답하고 전략·구성·디자인 단계를 승인합니다.
  6. 샘플 두 장을 확인한 뒤 나머지 전체 제작을 승인합니다.
  7. 보기 및 내보내기에서 내보내기→PPT로 받습니다.
예시
주제: 신입 사원 온보딩 안내 / 목적: 첫 주 일정 설명 / 대상: 신입 사원 / 분량: 8장. 파워포인트에서 수정할 예정이니 모든 텍스트는 텍스트 박스로, 차트는 수정 가능한 형태로 만들어 줘.
  • 크리에이티브는 통 이미지로 나와 수정이 안 되므로 프로페셔널을 권합니다.
  • 처음엔 한두 장만 만들어 스타일을 확정한 뒤 확장하면 크레딧이 절약됩니다.
  • 작은 수정은 크레딧이 들기 때문에 파워포인트에서 직접 합니다.
  • 기존 PPT는 올린 뒤 16:9, 슬라이드당 핵심 메시지 하나, 수정 가능한 텍스트 박스 조건으로 다시 만들게 할 수 있습니다.
  • 딥리서치로 근거 있는 보고서를 먼저 만든 뒤 슬라이드로 변환하는 방법도 있습니다.

11. 제미나이 캔버스로 문서·PPT 만들기

제미나이 캔버스는 답변 옆에 작업창이 생겨 문서를 함께 편집하는 기능입니다. 구간별 수정, 구글 독스·슬라이드 내보내기, PPT 저장까지 이어집니다.

  1. 채팅창에서 도구를 눌러 캔버스를 선택하고, 모델을 사고 또는 프로로 바꿉니다.
  2. +에서 파일 업로드로 자료를 첨부하거나 내용을 입력합니다.
  3. 대상과 톤, 슬라이드 총 장수를 적어 PPT 슬라이드 형식으로 요청합니다.
  4. 고칠 문단을 드래그해 이 부분을 바꿔 줘처럼 요청하고, 길이·어조는 5단계 중에서 고릅니다.
  5. 마지막에 수정 제안으로 문서 전체의 어색한 곳을 검토합니다.
  6. 슬라이드로 내보내기를 누르고 완료되면 슬라이드 열기를 누릅니다.
  7. 구글 슬라이드에서 파일 → 다운로드 → pptx를 선택합니다.
예시

  • 색상은 이름 대신 정확한 컬러 코드로 지정합니다.
  • 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리하는 분업을 권합니다. PPT에서는 홈 → 바꾸기 → 글꼴 바꾸기로 폰트를 한 번에 바꿉니다.

12. PDF 자료로 근거 있는 PPT 만들기

  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 자료를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적과 청중, 원하는 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기의 프레젠테이션을 선택하고 대상자·톤·길이·템플릿을 고른 뒤 프레젠테이션 생성을 누릅니다.
  7. 편집 화면에서 글자와 디자인을 수정하고 다운로드로 저장합니다.
  • 생성된 내용과 수치는 원문과 비교해 확인합니다.
  • 근거가 없는 내용은 확인 필요로 표시해 달라고 요청할 수 있습니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.

  3. 작업을 마친 뒤 아래 예시처럼 스킬로 만들어 달라고 요청합니다.
  4. 다음 PPT 작업 때 그 스킬을 불러와 사용합니다.
  5. PPT 만드는 방법을 총정리한 업무 매뉴얼도 함께 남깁니다.
