문서·슬라이드·디자인 만들기

이 분야에서는 Claude 대화창, Word·Excel·PowerPoint 애드인, Adobe Acrobat 같은 도구로 보고서·발표 자료·표·차트·디자인 시안을 만들고 다듬을 수 있습니다. 처음이라면 Claude 대화에서 슬라이드·문서를 바로 만드는 법부터 보세요. 그다음 평소 쓰는 Office 프로그램 안에서 Claude를 쓰는 법을 익히고, 마지막으로 디자인 규칙을 스킬로 저장해 같은 품질을 반복하는 단계로 넘어가면 됩니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 21개 기반 · 2026-10-31 갱신

최근 바뀐 점

  • Claude 9월 업데이트로 채팅과 Cowork가 하나로 합쳐졌고, 어떤 대화에서든 /slides, /docs, /designs로 슬라이드·문서·디자인을 바로 만들 수 있습니다.
  • 작업이 클라우드에서 실행되어 노트북을 닫아도 계속되고, 휴대폰으로 진행 상황을 확인할 수 있습니다.
  • Adobe Acrobat의 PDF 스페이스에 보고서·기사 링크를 최대 100개까지 넣어 근거를 확인하며 PPT 초안을 만들고 PPTX로 내려받을 수 있습니다.
  • AI로 만든 PPT의 톤이 들쭉날쭉하지 않도록 색·글씨 크기·장당 글자 수를 수치로 정한 디자인 규칙서를 스킬로 저장해 재사용하는 방법이 소개되었습니다.

1. Claude 대화에서 슬라이드·문서 만들기

Claude와 나눈 대화 내용을 바탕으로 슬라이드, 문서, 디자인을 대화창을 벗어나지 않고 바로 만드는 기능입니다. 보고서 내용을 정리한 뒤 발표 자료나 한 장짜리 요약 문서가 필요할 때 씁니다.

  1. Opus 5.5를 고르고 보고서나 출시 브리프 등 만들 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 설명해 Claude가 형식을 고르게 하거나, 형식을 안다면 /slides, /docs, /designs 중 하나를 입력합니다.
  3. 결과물이 나오면 Sonnet 5.5로 바꿉니다.
  4. 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 요청합니다.
  5. 작은 부분은 직접 고치고, 특정 문단이나 부분을 선택해 바꿀 내용을 말하면 그 부분만 수정됩니다.
  6. 결과물의 원하는 곳에 코멘트를 달아 Claude에게 보내 고치게 합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • 방향을 잡는 단계는 Opus 5.5, 빠르게 고치는 단계는 Sonnet 5.5로 나눠 쓰기를 권합니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집하고, 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • 출시 브리프 하나로 발표 자료, 소셜 이미지 세트, 한 장짜리 문서를 함께 만들 수 있습니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 말로 쏟아낸 생각을 Claude가 발표 자료로 바꿔 주는 방법입니다. 서식보다 내용에 집중하고 싶을 때 좋습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본을 복사합니다.
  3. 변환본을 Claude에 붙여 넣어 보냅니다.
  4. 슬라이드로 만들어 달라는 프롬프트를 함께 보냅니다.
  5. 결과에서 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있으면 폰트·템플릿을 따로 찾지 않아도 됩니다.

3. Acrobat PDF 스페이스로 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 보고서·기사 링크 같은 자료를 모아 두고, 그 내용을 근거로 발표 자료 초안을 만드는 기능입니다. 원문 기반이라 엉뚱한 내용이 들어갈 위험이 적어 초보자에게 알맞습니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 기획서·보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적과 청중, 원하는 수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기의 프레젠테이션을 선택하거나 채팅창에 프레젠테이션 생성을 요청합니다.
  7. 대상자·톤·길이·템플릿을 고르고 프레젠테이션 생성을 누릅니다.
  8. 편집 화면에서 글자·배경·아이콘을 수정한 뒤 다운로드로 저장합니다.
  • 파일, 이미지, 웹 링크, 텍스트를 확장자와 관계없이 최대 100개까지 넣을 수 있습니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 생성된 내용과 수치는 원문과 비교해 확인하고, 근거가 없는 내용은 '확인 필요'로 표시해 달라고 요청할 수 있습니다.
  • 유료 구독이 필요합니다.

4. Excel에서 Claude에게 질문하기

Claude in Excel은 통합 문서 전체를 읽고 질문 답변, 오류 추적, 수식 설명을 셀 단위 근거와 함께 알려 주는 사이드바 에이전트입니다. 예산 목표 달성 여부를 확인하거나 낯선 수식을 이해할 때 씁니다.

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C를 눌러 Claude 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽고 확인합니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
예시
I'm trying to keep my travel and meal budget to under 40% of my total costs. Did I hit that target?
  • 오류는 Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • 수식이 낯설면 How does the letter grade formula work?처럼 물어 부분별 설명을 받습니다.
  • Pro, Max, Team, Enterprise 플랜의 베타 기능이며, 수정 전에 허락을 구하고 변경 내용을 설명합니다.
  • 민감하거나 규제 대상인 데이터는 조직의 데이터 처리 정책을 따르세요.

5. Excel 피벗 테이블·차트 만들기

판매 데이터 같은 표를 Claude에게 말로 요청해 피벗 테이블과 차트로 바꾸는 방법입니다. 집계 보고서나 대시보드용 그래프를 빠르게 만들 때 씁니다.

  1. 판매 거래 데이터가 있는 통합 문서에서 Claude 사이드바를 엽니다.
  2. Create a pivot table showing total revenue by region and product.라고 요청합니다.
  3. 지역이 행, 제품이 열로 구성된 피벗 테이블을 확인합니다.
  4. Now, create a chart from this pivot table showing revenue by region.이라고 요청합니다.
  5. Change the chart to be a stacked bar chart and add a title.처럼 차트를 수정시킵니다.
예시
Create a pivot table showing total revenue by region and product.
  • 차트의 종류, 축, 제목, 색상을 모두 요청으로 바꿀 수 있습니다.
  • 데이터 정리, 수식으로 연결된 예측 모델, DCF 모델도 맡길 수 있습니다.
  • 외부에 공유할 결과물은 조직의 기준에 맞는지 반드시 검증합니다.

6. PowerPoint에서 덱 한 번에 만들기

Claude in PowerPoint는 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 회사 템플릿에 맞춰 덱 전체 초안을 만드는 에이전트입니다. 참고 파일을 올려 여러 문서를 한 발표 자료로 묶을 때도 씁니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 엽니다.
  2. Claude 애드인을 엽니다.
  3. 필요하면 + 버튼을 눌러 리서치 보고서, 데이터 내보내기 파일, 내부 분석 자료를 올립니다.
  4. 슬라이드 수, 주제, 다룰 항목, 어조를 적어 덱을 요청합니다.
  5. Claude가 변경 전에 허락을 구하면 매번 검토하거나 편집을 허용합니다.
  6. 생성된 덱의 구조와 출처 설명을 확인합니다.
  7. 겹치는 슬라이드는 '4번과 5번을 하나로 합쳐 줘'처럼 남길 내용과 함께 요청하고, 지워도 되는지 묻는 Claude에게 답합니다.
  8. '규제 슬라이드를 시장 규모 바로 뒤로 옮겨 줘'처럼 순서 변경을 요청합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 만들어 줘. 데이터 중심의 애널리스트 어조로 써 줘.
  • Claude AI에 설정해 둔 Google Drive·Notion·Confluence 같은 커넥터가 애드인에도 그대로 적용되어 외부 자료를 읽고 쓸 수 있습니다.
  • 복잡하거나 많이 맞춤화된 템플릿은 브랜드 지침에 맞는지 꼭 직접 확인하세요.
  • 공유받은 덱을 열고 슬라이드별 논지 요약이나 '7번 슬라이드에 인용된 데이터 출처는?' 같은 질문으로 회의 준비를 할 수도 있습니다.
  • 합치고 옮긴 뒤 흐름이 논리적으로 쌓이는지 확인하세요.

7. PowerPoint 슬라이드 부분 수정하기

완성된 덱에서 선택한 슬라이드·개체만 고치거나, 글머리표 슬라이드를 블록형 레이아웃·매트릭스·차트로 바꾸는 방법입니다. 결과는 이미지가 아닌 PowerPoint 기본 도형과 차트라 직접 편집할 수 있습니다.

  1. 수정할 슬라이드, 텍스트 상자 또는 제목을 선택합니다.
  2. '이 섹션을 한 줄로 요약해 줘'처럼 선택한 부분에 대한 수정을 요청합니다.
  3. 선택하지 않은 나머지 내용이 그대로인지 확인합니다.
  4. 글머리표가 많은 슬라이드를 선택하고 '4개 블록의 시각 레이아웃으로 바꿔 줘'라고 요청합니다.
  5. 블록마다 넣을 항목(이름, 핵심 수치, 한 문장 설명)을 지정합니다.
  6. 생성된 블록을 필요에 따라 이동·크기 조정·색 변경합니다.
  7. 새 슬라이드가 필요하면 요청 끝에 '필요하면 질문해 줘'를 덧붙이고, Claude가 묻는 질문에 답합니다.
  8. 새 슬라이드가 덱의 글꼴·색상·간격과 맞는지 확인합니다.
예시
이 슬라이드를 4개 블록의 시각 레이아웃으로 바꿔 줘. 블록마다 기업 이름, 핵심 수치, 한 문장 설명을 넣어 줘.
  • 표는 x축 매출 규모, y축 성장률의 2x2 매트릭스로, 막대 차트는 두 지표가 함께 보이는 묶음 가로 막대 차트로 바꿀 수 있습니다.
  • 질문 문장을 덧붙이면 Claude가 바로 만들지 않고 기존 내용을 읽고 빠진 점부터 파악합니다.
  • Claude는 추가한 데이터의 출처도 알려 줍니다.

8. Word에서 Claude로 초안 다듬기

Claude for Word는 Word 오른쪽 패널에서 문서를 읽고 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기, 분량 줄이기, 교정까지 맡습니다. 모든 수정이 추적 변경으로 남아 직접 수락·거절할 수 있습니다.

  1. Word 오른쪽의 Claude 패널을 열고 문서의 댓글을 검토자별로 정리해 달라고 요청합니다.
  2. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고 확인창에서 Allow once를 누릅니다.
  3. Box 같은 연결된 자료와 대조해 문서 속 수치·주장을 확인하게 하고, 맞지 않는 내용은 고치게 합니다.
  4. 수정 카드를 확인해 적용하면 추적 변경으로 문서에 반영됩니다.
  5. 서식은 원하는 최종 상태를 말하고 Don't change anything else.를 덧붙여 정리합니다.
  6. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인합니다.
  7. 분량을 줄일 때는 목표 단어 수와 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬을 골라 교정한 뒤 변경 사항을 모두 수락하게 합니다.
예시
Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?
  • Word 웹, Windows, Mac에서 쓸 수 있고 Microsoft AppSource에서 설치하며 Pro, Max, Team, Enterprise 플랜에 포함됩니다.
  • 변경을 수락하면 되돌릴 수 없어 Claude가 먼저 확인을 요청합니다. leave the comment threads open이라고 하면 댓글 스레드가 남습니다.
  • 카드가 지나치게 잘라 내면 이유를 말하고 다시 제안하게 하면 됩니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.

9. 디자인 규칙서를 스킬로 저장하기

AI로 만든 PPT가 매번 다른 톤으로 나오는 문제를, 수치로 정한 디자인 규칙서와 스킬 저장으로 해결하는 방법입니다. 같은 품질의 자료를 반복해서 만들어야 할 때 씁니다.

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준으로 디자인 규칙서를 만듭니다.
  2. 규칙서를 주고 Claude Code나 코덱스에서 PPT 작업을 합니다.
  3. 결과물을 자동 검사, 눈 검사, 숫자 검산 세 가지로 확인합니다.
  4. 작업을 마친 뒤 대화 내용과 결과물로 스킬을 만들어 달라고 요청합니다.
  5. 'PPT 만드는 방법을 총정리한 업무 매뉴얼을 만들어 줘'로 매뉴얼도 함께 남깁니다.
  6. 다음 PPT 작업 때 그 스킬을 불러와 사용합니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘.
  • '깔끔하게', '세련되게' 같은 표현은 규칙이 아닙니다. 예: 색 3가지(검정·흰색·파랑), 본문 26~30px, 제목 68px, 도식 제목 34~36px, 장당 약 200자처럼 수치로 적습니다.
  • 한글 글꼴은 자간을 0으로 두면 AI 티가 줄어듭니다.
  • Open Color(색상표), Lucide(아이콘), Mermaid(도식) 같은 오픈소스를 쓰면 품질이 올라갑니다.
  • 나만의 규칙은 핀터레스트나 구글의 PPT 예시를 기준으로 명세서를 만들어 얻을 수 있습니다.

10. Claude 디자인으로 시안부터 구현하기

코드를 짜기 전에 Claude 디자인으로 여러 화면 시안을 탐색하고, 피드백과 클릭형 프로토타입을 거쳐 구현까지 이어 가는 방법입니다. 앱이나 웹 화면을 만들 때 결과물 품질을 높이고 싶을 때 씁니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 본 뒤 만족하면 Claude에게 구현(build)을 지시합니다.
  • 작은 사이드 프로젝트의 일부 화면에도 짧은 디자인 탐색을 거치면 결과가 나아집니다.
  • Claude가 작업하는 동안 기다리지 않고 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • Claude Design은 일상 언어 설명만으로 제작 수준의 결과물을 만들도록 설계되었고, 문서보다 프로토타입을 우선합니다.
