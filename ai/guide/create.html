문서·슬라이드·디자인 만들기

문서·슬라이드·이미지·웹페이지를 AI에게 말로 시켜 만드는 방법을 모았습니다. 먼저 Claude 채팅에서 아티팩트·문서·슬라이드를 만들어 보고, 그다음 PPT 품질 높이기와 디자인 시스템으로 일관된 결과를 내는 단계로 넘어가세요. 이미지·제품 사진·홈페이지 제작은 그 뒤에 이어서 보면 순서가 자연스럽습니다.

  • Claude 아티팩트를 팀원과 공유해 함께 편집하고, 사람마다 보기·댓글·수정 권한을 나눌 수 있습니다(11/4).
  • Claude Design에 영상 자막(SRT)을 넣어 말과 맞는 16:9 애니메이션을 만들고 편집 프로그램에 B-roll로 얹는 활용법이 소개되었습니다(11/4).
  • 호스팅어 AI 빌더, 힉스필드 MCP 연결 등 Claude나 AI 빌더로 홈페이지·쇼핑 브랜드 자료를 한 번에 만드는 사례가 나왔습니다(11/16~17).

1. Claude 아티팩트로 계산기·앱 만들기

아티팩트는 Claude 채팅 옆 화면에 바로 작동하는 계산기·퀴즈·앱·인포그래픽을 만들어 주는 기능입니다. 코딩을 몰라도 말로 설명하면 되므로, 간단한 업무 도구가 필요할 때 가장 먼저 해 보기 좋습니다.

  1. Claude 채팅창에 만들고 싶은 도구를 한 줄로 요청합니다.
  2. 엔터를 치면 채팅 옆에 작동하는 결과가 아티팩트로 나타납니다.
  3. 우측 패널에서 만들어진 앱을 직접 사용해 봅니다.
  4. 고치고 싶은 점을 채팅으로 이어서 요청합니다.
  5. 다른 사람과 쓰려면 게시해 링크로 받습니다.
  6. 화면 그대로 자료에 넣고 싶으면 결과 화면을 캡처해 씁니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.
  • 코딩을 몰라도 말로 설명하면 앱을 만들 수 있습니다.

2. Claude 화이트보드로 구상 정리하기

Claude Artifacts의 화이트보드는 아이디어, 워크플로, 행사 계획을 한 화면에 시각적으로 펼쳐 주는 기능입니다. 구상 단계에서 생각을 정리하거나 팀에 공유할 때 알맞습니다. 모든 유료 플랜에서 쓸 수 있습니다.

  1. Artifacts로 이동합니다.
  2. Whiteboard를 클릭합니다.
  3. Ask Claude를 눌러 만들고 싶은 내용을 설명합니다.
  4. 배치된 화이트보드를 확인합니다.
  5. 스타일 변경, 차트 추가, 예산 같은 내용 수정을 요청합니다.
  • 사업 아이디어 공유, 워크플로·행사 흐름 정리 같은 구상 단계에 잘 맞습니다.
  • 같은 업데이트의 시트(Sheets)는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵습니다. 간단한 표 정리용으로 보세요.

3. Claude로 문서·슬라이드 한 채팅에서 만들기

Claude에서는 한 대화 안에서 문서(Docs), 디자인(Designs), 슬라이드(Slides)를 이어서 만들 수 있습니다. 앞에서 정리한 내용이 그대로 다음 결과물의 재료가 되므로, 보고서 하나로 발표 자료까지 빠르게 만들 때 씁니다.

  1. Opus 5.5로 보고서 등 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 설명해 Claude가 형식을 고르게 하거나, /slides, /docs, /designs를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 답하고 초안을 받습니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  5. Sonnet 5.5로 바꿔 문구 다듬기, 차트 교체, 색상 변경 같은 수정을 반복합니다.
  6. 우측 하단 캔버스 버튼으로 슬라이드 전체를 한눈에 보고, 우측 상단 재생 버튼으로 발표 모드를 실행합니다.
  7. 내보내기에서 Word, PDF, 파워포인트, 구글 슬라이드 등 원하는 형식을 고릅니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프를 만들어 줘. 필요한 건 질문해 줘.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • 방향을 찾을 때는 Opus 5.5, 빠른 수정은 Sonnet 5.5로 나눠 쓰기를 권합니다.
  • 슬라이드는 스피커 노트를 확인하고 필요하면 고칩니다.
  • 질문 내용은 사용자마다 다르게 나옵니다.

4. 음성 메모로 발표 자료 초안 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성 메모로 쏟아낸 뒤 Claude에게 슬라이드로 바꾸게 하는 방법입니다. 서식 걱정 없이 내용에만 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본을 복사합니다.
  3. 변환본을 Claude에 보내고 슬라이드 제작을 요청합니다.
  4. 작은 수정은 직접 고칩니다.
  5. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  6. 완성되면 팀에 공유하거나 내보내서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

5. 아티팩트를 팀과 공유해 함께 편집하기

Claude에서 만든 문서·슬라이드·디자인·대시보드를 팀원과 함께 보고 고칠 수 있습니다. 사람마다 권한을 정하고, 댓글이 달리면 Claude에게 수정을 시킵니다. 팀 체크리스트나 트래커를 같이 쓸 때 유용합니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  6. 트래커라면 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시
이 문서를 바탕으로 우선순위별 체크박스가 있는 트래커를 만들어 줘. 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.

6. Word·Excel·PowerPoint 안에서 Claude 쓰기

Claude를 Word, Excel, PowerPoint 패널에 붙여, 열어 둔 파일 안에서 바로 요약·수정·분석을 시키는 방법입니다. 모든 수정이 검토 카드나 추적 변경으로 나타나 직접 수락·거절할 수 있어 업무 문서에 안전하게 쓸 수 있습니다.

  1. Pro, Max, Team, Enterprise 플랜에서 Microsoft AppSource를 통해 Claude를 설치합니다.
  2. Word는 오른쪽 Claude 패널에서 댓글 요약을 먼저 요청해 검토자별 요구를 정리합니다.
  3. 문서 수정 전 Track Changes를 켜 달라고 요청하고, 확인창에서 Allow once를 누릅니다.
  4. Excel은 Mac Control + Option + C, Windows Control + Alt + C로 사이드바를 열어 질문합니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
  6. PowerPoint는 템플릿을 연 상태에서 주제, 다룰 항목, 어조를 적어 덱 초안을 요청합니다.
  7. 수정할 슬라이드나 개체를 선택하고 요청하면 선택한 부분만 고쳐집니다.
예시
Turn on Track Changes and keep it on for everything you do in this document.
  • 변경을 수락하면 되돌릴 수 없어 Claude가 먼저 확인을 요청합니다.
  • 표를 2x2 매트릭스로, 글머리표를 블록형 레이아웃으로 바꾸는 요청도 됩니다. 결과는 직접 편집 가능한 기본 도형과 차트입니다.
  • 복잡한 템플릿은 브랜드 지침과 맞는지 직접 확인하세요.
  • 민감하거나 규제 대상인 데이터는 조직의 데이터 정책을 따릅니다.

7. 디자인 시스템으로 같은 톤의 PPT 만들기

AI가 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 색·글꼴·크기 같은 규칙을 먼저 정해 디자인 시스템으로 두면 매번 같은 톤의 슬라이드가 나옵니다. 보고서를 자주 만드는 직장인에게 맞습니다.

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create를 누릅니다.
  2. 회사 이름과 설명을 적고, 기존 자료가 있으면 깃허브 주소나 피그마 파일을 넣습니다. 또는 DESIGN.md 코드를 복사해 붙여 넣습니다.
  3. 쓸 폰트 파일을 업로드합니다.
  4. Continue to generation을 눌러 디자인 시스템을 생성합니다.
  5. 초기 화면으로 돌아가 방금 만든 디자인 시스템을 선택하고 PPT를 요청합니다.
  6. Claude가 묻는 주제·대상·디자인 질문에 답하고 Continue를 누릅니다.
  7. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 내려받습니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • 규칙은 '깔끔하게' 같은 말 대신 색 3가지, 본문 26~30px처럼 수치로 적어야 합니다.
  • 유니버셜 폰트는 어디서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스는 편집이 안 됩니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • 디자인 시스템 없이 쓰면 결과가 'AI스럽고' 사용량 한도도 빡빡할 수 있습니다.
  • 예전 방식: 4~5월에는 클로드 디자인 사용량이 따로 관리됐지만, 5월 말 업데이트로 Claude Code 사용량과 통합되었습니다.

8. Claude Design으로 시안·프로토타입 만들기

Claude Design은 일상 언어로 설명하면 앱 화면 시안이나 클릭해 볼 수 있는 프로토타입을 만들어 줍니다. 코드를 짜기 전에 짧게 디자인을 탐색하고 싶을 때 쓰며, 마음에 들면 Claude Code로 구현까지 넘길 수 있습니다.

  1. 메인 화면에서 Prototype의 새 프로젝트를 만들고 디자인 시스템을 선택합니다.
  2. 레이아웃만 잡으려면 와이어프레임, 정교한 결과물은 하이델리티를 고릅니다.
  3. 채팅창에 만들고 싶은 화면을 입력하고, 묻는 질문에 답한 뒤 Continue를 누릅니다.
  4. 결과가 나오면 Comment로 영역을 지정해 Send to Claude를 누르거나 Edit으로 직접 고칩니다.
  5. 클릭해 볼 수 있는 프로토타입을 만들어 달라고 요청합니다.
  6. 만족하면 Share에서 Handoff to Claude Code 명령어를 복사해 Claude Code에 붙여 넣어 구현합니다.
예시

9. 제미나이 캔버스·독스로 문서·PPT 만들기

제미나이 캔버스는 답변 옆 작업창에서 문서를 구간별로 고치고, 웹페이지·퀴즈·인포그래픽으로 바꾸며, 구글 슬라이드를 거쳐 PPT로 내보내는 기능입니다. Claude 외에 구글 도구를 이미 쓰는 직장인에게 알맞습니다.

  1. 제미나이 채팅창에서 도구를 눌러 캔버스를 선택하고 요청을 입력합니다.
  2. 수정할 문단을 드래그해 바꿀 내용을 요청하고, 길이·어조는 5단계 중에서 고릅니다.
  3. 마지막에 수정 제안으로 문서 전체의 어색한 곳을 검토합니다.
  4. PPT가 목적이면 모델을 사고 또는 프로로 바꾸고 대상과 톤, 슬라이드 총 장수를 적어 요청합니다.
  5. 슬라이드로 내보내기를 누르고 슬라이드 열기를 누릅니다.
  6. 구글 슬라이드에서 파일 → 다운로드 → pptx를 선택합니다.
  7. PPT에서 홈 → 바꾸기 → 글꼴 바꾸기로 폰트를 일괄 변경합니다.
예시
청중은 신입 사원, 총 10장, 차분한 파란색 톤으로 PPT 슬라이드를 만들어 줘. 모든 슬라이드 좌상단에 제목을 넣어 줘.
  • 처음에는 1~2장씩 나눠 만들고, 중간중간 슬라이드로 내보내 백업하면 안정적입니다.
  • 색상은 이름 대신 정확한 컬러 코드로 지정합니다.
  • 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리하는 분업을 권합니다.
  • 예전 방식: 캔버스에서 PPT 생성이 막히는 오류(4월)가 있을 때는 구글 슬라이드에서 오른쪽 위 제미나이로 한 장씩 만들고 파일 → 다운로드로 내보냈습니다.

10. 젠스파크·Acrobat으로 PPT 만들기

Claude나 제미나이 외에도 젠스파크 AI 슬라이드나 Adobe Acrobat PDF 스페이스처럼 PPT 제작에 특화된 도구가 있습니다. 근거 있는 자료를 바탕으로 발표 자료를 만들거나, 수정 가능한 PPT로 내보내야 할 때 씁니다.

  1. 젠스파크는 AI 슬라이드로 들어가 주제·목적·대상·분량·필수 조건이 담긴 프롬프트를 입력합니다.
  2. 프로페셔널을 고르고 가이드 모드를 켜서 전송한 뒤, 질문에 답하고 단계를 승인합니다.
  3. 샘플 두 장을 확인한 뒤 전체 제작을 승인하고 보기 및 내보내기에서 PPT로 받습니다.
  4. Acrobat은 PDF 스페이스를 만들어 보고서·기사 링크 등 자료를 추가합니다.
  5. AI 어시스턴트에 목적과 청중을 적어 요약을 요청하고, 요약 속 숫자를 눌러 원문 근거를 확인합니다.
  6. 프레젠테이션을 선택해 대상자·톤·길이·템플릿을 고르고 생성한 뒤 편집·다운로드합니다.
예시
파워포인트에서 수정할 예정이니 모든 텍스트는 수정 가능한 텍스트 박스로, 차트도 수정 가능한 형태로 만들어 줘.
  • 젠스파크의 크리에이티브는 통 이미지로 나와 수정이 안 되므로 프로페셔널을 권합니다.
  • 처음엔 한두 장만 만들어 스타일을 확정한 뒤 늘리면 크레딧이 절약되고, 작은 수정은 PPT에서 직접 합니다.
  • Acrobat은 문서 기반이라 원문이 잘 반영되지만 유료 구독이 필요합니다. 생성된 수치는 원문과 꼭 비교합니다.
  • 이 영상들은 일부 광고가 포함되어 있습니다.

11. 나노바나나로 이미지 편집·로고 만들기

제미나이의 나노바나나는 얼굴·포즈·배경을 유지한 채 필요한 부분만 고치는 이미지 생성·편집 기능입니다. 사진 속 물체 제거, 배경 교체, 로고 시안 제작처럼 디자이너 없이 자료 이미지를 만들 때 씁니다.

  1. 제미나이에서 이미지 기능을 선택하고 수정할 사진을 업로드합니다.
  2. 없앨 대상이나 바꿀 장소를 지정하고 나머지는 바꾸지 말라고 요청합니다.
  3. 결과에서 얼굴·포즈가 유지됐는지 확인하고, 아니면 같은 요청을 다시 보냅니다.
  4. 로고는 마음에 드는 참고 로고 이미지를 함께 올리고 주제·상징물·스타일·색상·분위기를 구체적으로 적습니다.
  5. 마음에 드는 엠블럼만 이미지로 받아 다운로드합니다.
  6. 미리캔버스에서 새 디자인 만들기로 크기를 정하고 엠블럼을 업로드한 뒤 텍스트를 배치해 다운로드합니다.
예시
사진에서 오른쪽 사람을 없애 줘. 다른 부분은 바꾸지 말고 빈 곳은 자연스럽게 채워 줘.
  • 결과는 매번 달라서 마음에 들지 않으면 같은 요청을 다시 시도합니다.
  • 프롬프트 쓰기가 어렵다면 ChatGPT나 제미나이에게 프롬프트를 대신 써 달라고 부탁합니다.
  • 화면 캡처 대신 다운로드해야 화질이 깨지지 않습니다.
  • 미리캔버스의 왕관 표시 폰트는 유료입니다.

12. 제품 사진으로 판매용 이미지·영상 만들기

Claude에 Artlist나 힉스필드 같은 이미지·영상 서비스를 커넥터(MCP)로 연결하면, 제품 사진 한 장으로 대표 이미지·착용샷·배너·쇼츠·상세페이지 시안까지 대화창 하나에서 만들 수 있습니다. 소규모 판매자나 마케터에게 알맞습니다.

  1. Claude에 Artlist 또는 힉스필드를 커넥터로 연결합니다.
  2. 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 하며, 생성 없이 체크만 시킵니다.
  3. Claude가 띄우는 업로드 위젯으로 제품 사진을 올립니다.
  4. 모델, 비율, 해상도를 구체적으로 적어 대표 이미지를 요청합니다.
  5. 착용샷·디테일 컷·배너를 추가로 요청하고, 바꿀 것과 유지할 것을 나누어 수정합니다.
  6. 쇼츠는 제품 이미지를 먼저 고정한 뒤 그 이미지로 클립을 만들게 하고, 이어 붙여 자막을 넣어 달라고 요청합니다.
  7. 예상 크레딧을 확인하고 확정한 항목만 진행한 뒤 다운로드로 저장합니다.
예시
먼저 생성하지 말고 Artlist에서 쓸 수 있는 이미지 모델을 확인해 줘. 첨부한 운동화 사진으로 정사각형 2K 대표 이미지를 만들 계획과 예상 크레딧을 알려 줘.
  • 생성 전에 체크만 시키면 크레딧을 아낄 수 있고, 재생성은 크레딧이 추가로 듭니다.
  • 제품·모델 이미지를 먼저 고정하면 영상 일관성에 도움이 됩니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 확인이 필요합니다.
  • 영상 예시에서 사진 3장과 쇼츠 3편, 랜딩 페이지에 총 79크레딧(약 4,900원)이 들었습니다.
