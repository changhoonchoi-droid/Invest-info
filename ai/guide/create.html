문서·슬라이드·디자인 만들기

이 분야에서는 대화 내용, 음성 메모, 보고서, PDF를 바탕으로 AI에게 슬라이드, 문서, 디자인 시안을 만들게 하고, 원하는 부분만 골라 고칠 수 있습니다. 먼저 Claude 대화에서 슬라이드와 문서를 바로 만들고 코멘트로 고치는 기초를 익히세요. 그다음 Acrobat, Word, Excel·PowerPoint 같은 업무 도구와 함께 쓰는 방법으로 넘어가고, 마지막으로 디자인 시안을 프로토타입과 구현까지 잇는 방법을 보면 좋습니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 12개 기반 · 2026-10-22 갱신

최근 바뀐 점

  • Claude의 채팅과 Cowork가 하나로 합쳐졌습니다. 작업이 클라우드에서 실행되므로 노트북을 닫아도 계속되고 휴대폰으로 진행 상황을 확인할 수 있습니다.
  • 이제 어떤 대화에서든 /slides, /docs, /designs로 슬라이드, 문서, 디자인을 바로 만들 수 있고, 모든 유료 요금제에서 쓸 수 있습니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집하고, 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • Adobe Acrobat의 PDF 스페이스에 파일과 웹 링크를 최대 100개까지 넣고, 이를 바탕으로 프레젠테이션 초안을 만들어 PPTX로 내려받을 수 있습니다.
대화에서 슬라이드·문서 바로 만들기음성 메모로 발표 자료 만들기코멘트로 원하는 부분만 고치기Acrobat PDF 스페이스로 PPT 만들기Word에서 Claude로 초안 다듬기Excel·PowerPoint를 한 대화로 잇기디자인 시안에서 구현까지 이어 가기
입문

1. 대화에서 슬라이드·문서 바로 만들기

Claude와 나눈 대화 내용을 바탕으로 슬라이드, 문서, 디자인을 대화창을 벗어나지 않고 만드는 기능입니다. 보고서나 출시 브리프처럼 내용을 먼저 정리해 두었다면 바로 발표 자료나 한 장짜리 요약 문서로 바꿀 때 씁니다.

  1. Opus 5.5 모델을 선택하고 보고서 등 만들 내용을 대화로 먼저 정리합니다.
  2. 원하는 결과물을 말로 설명해 Claude가 형식을 고르게 합니다.
  3. 형식을 이미 정했다면 /slides, /docs, /designs 중 하나를 입력해 바로 만듭니다.
  4. 모델을 Sonnet 5.5로 바꿉니다.
  5. 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 반복해서 요청합니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)로 전달합니다.
예시
/slides 위에서 정리한 출시 브리프로 사내 발표용 슬라이드를 만들어 줘
  • 방향을 잡는 단계에서는 Opus 5.5를, 빠르게 고치는 단계에서는 Sonnet 5.5를 쓰는 것이 권장됩니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • 출시 브리프 하나로 발표 자료, 소셜 이미지 세트, 현장용 한 장 요약 문서를 함께 만들 수 있습니다.
  • 예전 방식: 2026년 9월 공개 당시에는 Claude Slides·Design·Docs가 베타였고 채팅과 Cowork 모드를 따로 골라야 했지만, 지금은 하나의 Claude로 합쳐졌습니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성으로 녹음하고 그 받아쓰기를 Claude에 보내 슬라이드로 만드는 방법입니다. 폰트와 템플릿 같은 서식보다 내용에 집중하고 싶을 때 좋습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude 대화창에 붙여 넣어 보냅니다.
  4. 슬라이드로 만들어 달라는 프롬프트를 함께 보냅니다.
  5. 결과에서 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)로 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있으면 폰트나 템플릿을 따로 찾지 않아도 됩니다.
  • 한국어로 쓰려면 '내가 말한 내용을 그대로 살려서 Claude 슬라이드로 발표 자료를 만들어 줘'처럼 요청해도 됩니다.

3. 코멘트로 원하는 부분만 고치기

Claude가 만든 슬라이드, 문서, 디자인에서 특정 부분을 선택하거나 코멘트를 달아 그 부분만 고치게 하는 방법입니다. 전체를 다시 만들지 않고 일부만 다듬고 싶을 때 씁니다.

  1. Claude로 만든 슬라이드나 문서를 엽니다.
  2. 오타나 짧은 문구 같은 작은 수정은 결과물에서 직접 고칩니다.
  3. 바꾸고 싶은 문단이나 요소를 선택하고 바꿀 내용을 말하면 그 부분만 수정됩니다.
  4. 큰 수정은 해당 부분에 코멘트를 달아 Claude에게 보냅니다.
  5. Claude Docs에서 팀원과 함께 편집할 때는 코멘트에서 Claude를 멘션해 수정을 요청합니다.
  6. 수정 결과를 확인하고 필요하면 코멘트를 다시 남겨 반복합니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집할 수 있습니다.
  • 코멘트는 결과물의 어느 부분에든 달 수 있습니다.

4. Acrobat PDF 스페이스로 PPT 만들기

Adobe Acrobat의 AI 기반 PDF 스페이스에 보고서, 기사 링크 등을 모아 핵심 내용을 요약하고 발표 PPT 초안까지 만드는 방법입니다. 요약에서 원문 근거를 바로 확인할 수 있어서 자료 분석과 발표 준비를 함께 할 때 좋습니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적, 청중, 원하는 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기에서 프레젠테이션을 선택하거나 채팅창에 프레젠테이션을 만들어 달라고 요청합니다.
  7. 대상자, 톤, 길이, 템플릿을 고르고 프레젠테이션 생성을 누릅니다.
  8. Adobe Express 편집 화면에서 글자, 배경, 아이콘을 수정한 뒤 다운로드로 저장합니다.
예시
임원 보고용 발표를 준비하고 있어. 넣은 보고서와 기사에서 올해 가장 중요한 변화 3가지와 핵심 수치 5개를 정리해 줘. 근거가 없는 내용은 '확인 필요'로 표시해 줘.
  • PDF 스페이스에는 확장자와 관계없이 최대 100개 파일을 넣을 수 있습니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 생성된 내용과 수치는 반드시 원문과 비교해 확인합니다.
  • 예상 질문과 답변도 정리해 달라고 하면 발표 준비까지 할 수 있습니다.

5. Word에서 Claude로 초안 다듬기

Claude for Word는 Microsoft Word 오른쪽 패널에서 문서를 읽고 댓글 요약, 사실 확인, 서식 정리, 고쳐 쓰기, 분량 줄이기, 교정까지 직접 해 줍니다. 모든 수정이 추적 변경으로 남아서 검토가 필요한 공지문이나 보고서를 마무리할 때 좋습니다.

  1. Word 오른쪽의 Claude 패널을 열고 문서에 달린 댓글을 검토자별로 정리해 달라고 요청합니다.
  2. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고 확인창에서 Allow once를 누릅니다.
  3. Box에 있는 근거 문서와 대조해 성능·수치 표현을 확인하게 하고, 맞지 않는 내용을 고치게 합니다.
  4. 수정 카드를 확인하고 적용하면 추적 변경으로 문서에 반영됩니다.
  5. 원하는 최종 서식을 말하고 Don't change anything else.를 덧붙여 서식을 정리합니다.
  6. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인합니다.
  7. 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬로 오탈자와 문법을 교정하고, 마지막에 변경 사항을 모두 수락하게 합니다.
예시
Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?
  • Word 웹·Windows·Mac에서 쓸 수 있습니다. Claude for Microsoft 365의 일부로 Microsoft AppSource에서 설치하며 Pro, Max, Team, Enterprise 플랜에 포함됩니다.
  • 수락한 변경은 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다. 수락할 때 leave the comment threads open이라고 하면 댓글 스레드가 남습니다.
  • 카드가 너무 많이 잘라 내면 이유를 말하고 다시 제안하게 합니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.

6. Excel·PowerPoint를 한 대화로 잇기

Claude for Excel과 PowerPoint는 열려 있는 두 파일을 하나의 연속된 세션에서 다룹니다. Excel의 실제 셀 값으로 분석표를 만들고 그 결과를 슬라이드에 바로 반영하므로, 데이터를 다시 설명하거나 탭을 오갈 필요가 없습니다.

  1. 작업할 Excel 파일과 PowerPoint 파일을 둘 다 엽니다.
  2. Claude에게 한 번의 프롬프트로 분석과 슬라이드 작업을 함께 요청합니다. 예: 데이터 가져오기 → Excel 표 만들기 → 요약을 슬라이드에 넣기.
  3. Excel에 만들어진 표와 계산 결과를 확인합니다.
  4. PowerPoint에서 갱신된 슬라이드와 요약문을 확인하고 필요한 부분을 다시 요청합니다.
  5. 자주 반복하는 흐름이면 Skills로 저장해 다음부터는 한 번의 클릭으로 다시 실행합니다.
  • 유료 플랜 사용자는 모두 Mac과 Windows에서 쓸 수 있습니다.
  • Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry로도 제공됩니다.
  • 영상 예시에서는 비교 기업 재무 자료로 트레이딩 컴프스 표를 만들고, 밸류에이션 요약을 피치덱에 넣고, 요약문까지 한 번에 작성했습니다.

7. 디자인 시안에서 구현까지 이어 가기

코드를 바로 짜기 전에 Claude에게 화면 디자인 시안을 여러 개 만들게 하고, 피드백과 클릭형 프로토타입을 거쳐 구현까지 이어 가는 방법입니다. 앱 온보딩 화면처럼 작은 화면이라도 디자인을 먼저 짧게 탐색하면 결과가 좋아집니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 디자인 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 직접 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 보고 만족하면 Claude에게 구현(build)을 지시합니다.
  • Claude가 작업하는 동안 기다리지 않고 다른 일을 하다가 돌아와 결과를 확인해도 됩니다.
  • Claude Design은 문서보다 프로토타입을 먼저 만드는 방식을 바탕으로 만들어졌습니다. 말로 설명하기보다 시안을 보며 고치는 편이 빠릅니다.
