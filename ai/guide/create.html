문서·슬라이드·디자인 만들기

Claude와 Gemini, 전용 AI 도구로 문서·슬라이드·이미지·웹페이지를 만드는 방법을 모았습니다. 먼저 Claude에서 문서·슬라이드·디자인을 한 채팅으로 만드는 기본기를 익히고, 그다음 PPT 품질을 높이는 방법과 Gemini·Excel·Word 활용으로 넘어가세요. 마지막으로 이미지·로고·홈페이지·영상 애니메이션 같은 응용 작업을 해 보시면 됩니다.

최근 바뀐 점

  • Claude Artifacts에 시트(Sheets)와 화이트보드(Whiteboard)가 추가되고, 대시보드는 데이터(Data)로 이름이 바뀌었습니다(모든 유료 플랜).
  • Claude Fable 5.2가 유료 플랜에 출시되어 모델 전환 메뉴에서 선택할 수 있고, 슬라이드 덱·인터랙티브 자료 같은 결과물 품질이 올랐다고 소개됩니다.
  • Claude 아티팩트(문서·슬라이드·디자인·대시보드)를 팀원과 함께 편집하고 접근 권한을 나눌 수 있게 되었습니다.
  • Claude Design에서 자막(SRT)과 프롬프트를 넣어 영상용 16:9 애니메이션을 만드는 활용법이 공개되었습니다.
  • Claude에 힉스필드 MCP를 연결해 한 대화창에서 제품 이미지·쇼츠·랜딩 페이지까지 만드는 흐름이 소개되었습니다(세 작업 약 4,900원).

1. Claude로 문서·슬라이드·디자인 만들기

Claude 한 대화 안에서 문서(Docs), 디자인(Designs), 슬라이드(Slides)를 이어서 만드는 방법입니다. 보고서 초안부터 SNS 이미지, 발표 자료까지 앞선 대화 내용을 바탕으로 만들 수 있어 업무 자료를 한 번에 정리할 때 좋습니다.

  1. Claude 데스크탑에서 사진 등 참고 자료를 첨부하고 만들 문서를 설명하는 프롬프트를 입력합니다.
  2. 원하는 결과물을 설명해 Claude가 형식을 고르게 하거나, 형식을 알면 /docs, /slides, /designs를 입력합니다.
  3. Claude가 던지는 질문에 모두 답하고 초안이 나오면 텍스트 편집기처럼 직접 고칩니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력해 그 부분만 수정시킵니다.
  5. 같은 채팅에서 브랜드 방향 세 가지를 캔버스에 나란히 보여 달라고 요청하고, 마음에 드는 시안을 고릅니다.
  6. 선택한 시안으로 1:1, 4:5, 9:16, 16:9 규격의 이미지를 요청합니다.
  7. 앞선 문서·이미지가 있는 같은 대화에서 발표 자료를 요청하고, 우측 하단 캔버스 버튼으로 전체 슬라이드를 한눈에 보며 고칩니다.
  8. 내보내기에서 PDF, 파워포인트, PNG, 구글 슬라이드 등을 골라 저장하거나 공유로 팀원을 초대합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프 문서를 만들어 줘. 필요한 정보는 먼저 질문해 줘.
  • Docs 내보내기는 Word, PDF, 마크다운, 노션, 구글 문서를, Slides 내보내기는 PDF, 파워포인트, PNG, 구글 슬라이드를 지원합니다.
  • 내용을 잡는 단계는 Opus 5.5, 문구 다듬기·차트 교체 같은 빠른 수정은 Sonnet 5.5로 나눠 쓰라고 권합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있고 일부는 베타입니다.
  • 질문 내용은 사용자마다 다르게 나옵니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성으로 녹음해 Claude 슬라이드로 바꾸는 방법입니다. 서식 대신 내용에만 집중할 수 있어 아이디어 발표나 보고 준비에 좋습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청하는 프롬프트를 입력합니다.
  5. 결과에서 작은 수정은 직접 고치고, 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

3. 아티팩트로 계산기·앱·화이트보드 만들기

Claude 채팅 옆 작업창(아티팩트)에 계산기, 간단한 앱, 화이트보드를 말로 설명해 만드는 방법입니다. 코딩 없이 업무용 도구나 구상 자료를 빠르게 만들 때 씁니다.

  1. 클로드 채팅창에 내 1일 칼로리 계산기 만들어 줘처럼 만들 도구를 한 줄로 요청합니다.
  2. 엔터를 치면 채팅 옆에 작동하는 도구가 아티팩트로 나타나므로 직접 사용해 봅니다.
  3. 앱이 필요하면 Artifacts에서 새 아티팩트 → 처음부터 시작하기를 선택하고 만들 앱을 설명합니다.
  4. 화이트보드가 필요하면 Artifacts로 이동해 Whiteboard를 클릭하고 Ask Claude를 눌러 만들 내용을 설명합니다.
  5. 배치된 결과를 확인하고 스타일 변경, 차트 추가, 내용 수정을 요청합니다.
  6. 공유하려면 게시해 링크로 받습니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.
  • 화이트보드는 사업 아이디어 공유, 워크플로·행사 흐름 정리 같은 구상 단계에 잘 맞습니다.
  • 시트(Sheets)에는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵다는 평가입니다.

4. 아티팩트 팀과 공유해 함께 편집하기

Claude에서 만든 문서·슬라이드·디자인·대시보드를 팀원과 함께 보고 댓글 달고 고치는 방법입니다. 팀원마다 권한을 나눌 수 있어 체크리스트나 트래커를 공동으로 관리할 때 유용합니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 트래커가 필요하면 우선순위별 체크박스가 있는 트래커를 요청하고, 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 달라고 합니다.
  6. 입력·체크만 필요한 사람은 contributor로 지정합니다.
  7. 댓글이 달리면 Claude에게 내용이나 스타일 수정을 요청합니다.
예시
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 공유된 아티팩트에서 "이번 주 팀이 한 일은?" 같은 요약을 요청할 수도 있습니다.

5. 디자인 시스템으로 AI 티 안 나는 PPT 만들기

색·폰트·여백을 규칙으로 정해 두고 Claude 디자인으로 일관된 PPT를 만들어 PPTX로 내보내는 방법입니다. 같은 톤의 발표 자료를 반복해서 만들어야 할 때 씁니다.

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. getdesign 사이트에서 원하는 기업의 DESIGN.md를 열어 코드를 복사합니다.
  3. 클로드 디자인 입력창에 붙여 넣고, 업로드한 폰트로 일괄 적용하고 그래프 컴포넌트를 포함하라고 적습니다.
  4. 사용할 폰트 파일(영상에서는 프리텐다드)을 드래그해 업로드합니다.
  5. Continue to generation 버튼으로 디자인 시스템을 생성합니다.
  6. 초기 화면으로 돌아가 방금 만든 디자인 시스템을 설정하고 만들 PPT 주제를 요청합니다.
  7. Claude가 묻는 주제·대상·디자인 질문에 답하고 Continue를 누릅니다.
  8. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 다운로드한 뒤, 열어서 폰트와 레이아웃을 확인합니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • 내보내기 옵션 중 유니버셜 폰트는 어디서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양이 같지만 편집이 불가능합니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • 디자인 시스템 없이 쓰면 결과물이 'AI스럽게' 나오고 사용량 한도가 빡빡할 수 있습니다.
  • 예전 방식: 디자인 시스템 문서(디자인 MD)를 Claude Code에 붙여 넣어 PPTX를 만들었으나, 최근에는 Claude 디자인 안에서 바로 만들고 내보냅니다.

6. PPT 디자인 규칙서를 스킬로 저장하기

색·글꼴·글씨 크기 같은 기준을 수치로 정리한 규칙서를 만들고, 스킬로 저장해 매번 같은 톤으로 PPT를 만드는 방법입니다. 결과가 들쭉날쭉한 이유는 기준이 없기 때문이라는 관점입니다.

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준으로 디자인 규칙서를 만듭니다.
  2. 규칙서로 Claude Code나 코덱스에서 PPT 작업을 합니다.
  3. 작업을 마친 뒤 지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘라고 요청합니다.
  4. 다음 PPT 작업 때 그 스킬을 불러와 사용합니다.
  5. PPT 만드는 방법을 총정리한 업무 매뉴얼을 만들어 줘로 매뉴얼도 함께 남깁니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 수치로 명확히 적습니다.
  • 영상이 제안한 기준은 색 3가지(검정·흰색·파랑), 본문 26~30px, 제목 68px, 장당 약 200자입니다.
  • 한글 글꼴은 자간을 0으로 두면 AI 티가 줄어듭니다.
  • 검사는 자동 검사, 눈 검사, 숫자 검산 세 가지를 거칩니다.

7. PowerPoint 안에서 Claude로 슬라이드 만들기

PowerPoint에 Claude 애드인을 열어 슬라이드를 만들고 다듬는 방법입니다. 슬라이드 마스터·글꼴·색상을 읽어 브랜드에 맞춰 주므로, 기존 템플릿으로 보고서 자료를 만들 때 좋습니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 엽니다.
  2. Claude 채팅에 슬라이드 수, 주제, 다룰 항목, 어조를 적어 요청합니다. 끝에 "필요하면 질문하라"는 취지의 문장을 덧붙입니다.
  3. 참고 자료가 있으면 + 버튼으로 보고서·데이터 파일을 올립니다.
  4. Claude가 변경 전에 허락을 구하면 검토하고 허용합니다.
  5. 수정할 슬라이드나 텍스트 상자를 선택하고 그 부분만 고쳐 달라고 요청합니다.
  6. 글머리표가 많은 슬라이드는 선택한 뒤 블록형 시각 레이아웃으로 바꿔 달라고 요청합니다.
  7. 겹치는 슬라이드는 번호를 지정해 합치게 하고, 순서 변경도 요청합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 만들어 줘. 데이터 중심의 애널리스트 어조로, 필요하면 질문해 줘.
  • 선택한 슬라이드·개체만 수정하고 나머지는 건드리지 않습니다.
  • 결과는 이미지가 아닌 기본 도형과 차트라 직접 편집이 됩니다.
  • Google Drive·Notion·Confluence 같은 커넥터로 외부 자료를 가져와 슬라이드를 만들 수 있습니다.
  • 복잡하게 맞춤화된 템플릿은 브랜드 지침과 맞는지 직접 확인해야 합니다.

8. Excel과 Word에서 Claude 활용하기

  1. Excel에서 통합 문서를 열고 Mac은 Control + Option + C, Windows는 Control + Alt + C로 사이드바를 엽니다.
  2. 목표를 구체적으로 적어 질문하고, 응답의 인용 상자를 눌러 근거 셀을 확인합니다.
  3. 피벗 테이블과 차트는 지역·제품 등 기준을 적어 요청한 뒤, 차트 종류와 제목도 요청으로 바꿉니다.
  4. Word에서는 오른쪽 Claude 패널을 열고 댓글 요약을 요청합니다.
  5. 추적 변경을 켜게 하고, 확인창에서 Allow once를 누릅니다.
  6. 문단을 선택해 고쳐 쓰기·분량 줄이기를 요청하고 수정 카드를 하나씩 확인합니다.
  7. 패널에서 /를 입력해 스킬 목록의 교정 스킬로 오탈자와 문법을 교정하고 마지막에 변경을 수락합니다.

Create a pivot table showing total revenue by region and product.

9. Gemini 캔버스로 PPT 만들어 내보내기

Gemini 캔버스로 문서와 슬라이드를 만들고 구글 슬라이드를 거쳐 PPT로 저장하는 방법입니다. Gemini와 구글 독스·슬라이드를 쓰는 환경에서 슬라이드를 빠르게 만들 때 맞습니다.

  1. 채팅창에서 도구를 눌러 캔버스를 선택하고 모델을 사고 또는 프로로 바꿉니다.
  2. +에서 파일 업로드로 자료를 첨부하거나 내용을 입력합니다.
  3. 대상, 톤, 슬라이드 총 장수를 적어 PPT 슬라이드 형식으로 요청합니다.
  4. 한 번에 다 만들기보다 1~2장씩 나눠 요청해 스타일을 확정한 뒤 확장합니다.
  5. 수정 요청 전에 슬라이드로 내보내기를 눌러 백업하고 슬라이드 열기를 누릅니다.
  6. 구글 슬라이드에서 이미지 수정으로 이미지를 바꿉니다.
  7. 파일 → 다운로드 → pptx로 저장하고, PPT에서 폰트와 정렬을 마무리합니다.
예시
첨부한 자료로 경영진 보고용 PPT 슬라이드를 총 8장으로 만들어 줘. 색상은 #1F3A5F를 메인으로 하고 모든 슬라이드 좌상단에 제목을 넣어 줘.
  • 색상은 이름 대신 정확한 컬러 코드로 지정하면 원하는 색이 나옵니다.
  • 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리하는 분업을 권합니다.
  • PPT 전체 폰트는 홈 → 바꾸기 → 글꼴 바꾸기로 한 번에 바꿀 수 있습니다.
  • 예전 방식: 캔버스에서 PPT 생성이 막히는 오류(4월)가 있을 때는 구글 슬라이드 오른쪽 위 제미나이로 슬라이드를 한 장씩 만드는 우회 방법을 썼습니다.

10. 젠스파크로 수정 가능한 PPT 만들기

  1. 젠스파크에서 AI 슬라이드로 들어갑니다.

  3. 프로페셔널을 선택하고 스탠더드 또는 울트라를 고릅니다.
  4. 가이드 모드를 켜고 전송합니다.
  5. 가이드의 질문에 답하고 전략·구성·디자인 단계를 승인합니다.
  6. 샘플 두 장을 확인한 뒤 나머지 전체 제작을 승인합니다.

예시

  • 다운로드 형식은 JPG, PNG, PPTX, PDF이며 최대 100개 파일까지 넣을 수 있습니다.
  • 생성된 내용과 수치는 원문과 비교해 확인하고, 근거가 없는 내용은 확인 필요로 표시해 달라고 요청할 수 있습니다.

13. 제품 사진으로 판매용 이미지 만들기

상품 사진 한 장으로 대표 이미지, 착용샷, 디테일 컷, 배너 등을 만들고 상세페이지나 광고 시안까지 이어 가는 방법입니다. Claude에 이미지 서비스를 연결하는 방법과 Genspark Design을 쓰는 방법이 있습니다.

  1. Claude에 Artlist를 커넥터로 연결하고, 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 요청합니다.
  2. 생성 없이 체크만 해 달라고 하며 사진을 첨부하고, 업로드 위젯으로 사진을 올립니다.
  3. 모델, 비율(정사각형), 해상도(2K) 등을 구체적으로 적어 대표 이미지를 요청합니다.
  4. 착용샷·디테일·배너 등을 추가로 요청하고, 유지할 것과 바꿀 것을 나누어 수정합니다.
  5. Genspark를 쓴다면 디자인에서 +를 눌러 광고 레퍼런스와 제품 사진을 첨부하고 광고 키 비주얼을 요청합니다.
  6. 되묻는 질문에 답하고 조정이나 편집으로 톤·글자를 수정합니다.
  7. 광고 시안을 기준으로 디자인 시스템을 정리하게 한 뒤 상세페이지와 랜딩페이지를 요청합니다.
  8. 결과를 다운로드로 저장합니다.
예시
첨부한 운동화 사진으로 흰 배경의 정사각형 2K 대표 이미지를 만들어 줘. 신발 형태와 로고는 그대로 유지해 줘.
  • 생성 전에는 체크만 시키면 크레딧을 아낄 수 있고, 재생성하면 크레딧이 추가로 소진됩니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 반드시 확인합니다.
  • 잘 모르는 질문은 비워 두면 AI가 제안해 진행합니다.
  • Genspark의 빌드하기로 실제 웹사이트까지 만들 수 있고, 공유로 편집자를 초대할 수 있습니다.

14. 제미나이로 이미지 편집·로고 만들기

제미나이(나노바나나)로 사진 속 물체 제거, 배경 교체, 로고 제작을 하는 방법입니다. 같은 대화에서 이어서 요청하면 얼굴과 포즈를 유지한 채 필요한 부분만 고칠 수 있습니다.

  1. 수정할 사진을 업로드합니다.
  2. 없앨 대상을 지정하고 '다른 부분은 바꾸지 말고 빈 곳은 자연스럽게 채워 줘'라고 요청합니다.
  3. 배경 교체는 바꿀 장소를 말하고 '빛과 조명도 자연스럽게'라고 덧붙입니다.
  4. 로고는 제미나이에게 로고 의뢰 양식(주제·상징물·스타일·색상·분위기)을 물어 그에 맞춰 요청합니다.
  5. 마음에 드는 참고 로고 이미지를 함께 올리고 엠블럼만 이미지로 요청해 다운로드 버튼으로 저장합니다.
  6. 미리캔버스에서 새 디자인 만들기로 크기를 정하고 업로드로 엠블럼을 넣은 뒤 텍스트를 추가합니다.
  7. 용도에 맞는 크기로 바꾸고 JPG, 고해상도로 다운로드합니다.
예시
이 사진에서 오른쪽 사람만 지워 줘. 다른 부분은 바꾸지 말고 빈 곳은 자연스럽게 채워 줘.
  • 결과는 매번 달라지므로 마음에 들지 않으면 같은 요청을 다시 시도합니다.
  • 화면 캡처 대신 다운로드해야 화질이 깨지지 않습니다.
  • 미리캔버스의 왕관 표시 폰트는 유료이므로 없는 것을 고릅니다.
  • 프롬프트 쓰기가 어렵다면 ChatGPT나 제미나이에게 대신 써 달라고 부탁합니다.

15. 스크린샷으로 랜딩 페이지 만들기

마음에 드는 웹사이트 화면을 캡처해 AI에 붙여 넣으면 비슷한 느낌의 랜딩 페이지를 만들어 주는 방법입니다. 디자인은 말보다 이미지가 정확하게 전달됩니다.

  1. 프레이머 리소스의 마켓플레이스에서 마음에 드는 템플릿을 골라 프리뷰를 누릅니다.
  2. 스크롤 캡처 도구로 웹사이트 전체를 캡처해 복사합니다.
  3. 구글 AI 스튜디오 프롬프트 입력창에 이미지를 붙여 넣습니다.
  4. 참고 이미지로 비슷한 느낌의 랜딩 페이지를 만들어 달라고 요청합니다.
  5. 빌드를 눌러 결과를 확인하고 원본과 비교합니다.
  6. 고칠 위치는 미리보기에서 어노테이트 앱을 켜 화면에 직접 표시합니다.
  7. 애드 텍스트로 요청을 적고 애드투 챗, 샌드 프롬프트를 눌러 수정 결과를 확인합니다.
예시
해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘
  • 위치를 글로 설명하기 어려울 때 어노테이트가 효과적입니다.
  • 기능 추가는 해당 사이트에 다크 모드 기능을 추가해 줘처럼 이어서 요청합니다.
  • 완성된 컴포넌트 코드를 레퍼런스로 함께 붙여 넣으면 디자인 품질이 올라갑니다.
  • 영상 자막이 불분명해 일부 버튼 이름은 화면에서 확인이 필요합니다.

16. Readdy AI로 홈페이지 만들기

업종과 요청을 입력하면 몇 분 만에 반응형 홈페이지를 만들어 주는 Readdy AI 사용법입니다. 참고 사이트 링크로 복제하듯 만들거나 편집 선택으로 부분 수정도 할 수 있습니다.

  1. Readdy AI에 접속해 구글 계정으로 로그인하고, 계정 메뉴의 언어에서 한국어를 선택합니다.
  2. 처음부터 시작을 선택하고 업종, 비즈니스 이름, 대상, 원하는 분위기와 섹션을 입력합니다.
  3. 보내기를 눌러 AI가 계획·개발을 마칠 때까지 기다립니다.
  4. 완성된 PC·모바일 화면을 확인합니다.
  5. 편집 선택을 눌러 바꾸고 싶은 부분을 클릭한 뒤 일상 언어로 변경을 입력합니다.
  6. 섹션 전체를 바꾸려면 상위 선택을 눌러 파란 박스가 전체를 감싸게 합니다.
  7. 공개하려면 도메인 메뉴에서 도메인을 연결합니다.
  • 수정 요청은 한 번에 하나씩 입력해야 어긋남이 적습니다.
  • 참고 사이트 주소나 명함, 템플릿으로 시작할 수도 있고, 말로 설명하기 어려우면 캡처를 첨부합니다.
  • 요청 한 번마다 25 크레딧이 차감되며 공개 게시에는 유료 결제가 필요합니다.
  • 숫자·후기 같은 생성 문구는 실제 사실에 맞게 고쳐야 합니다.
  • 예전 방식: 가입 시 매달 250 크레딧이 무료였다고 소개됐으나 최근 영상에서는 유료 플랜 기준 크레딧을 안내합니다.

17. Claude 디자인으로 앱 화면 시안 만들기

코드를 짜기 전에 Claude 디자인으로 화면 시안을 탐색하고 클릭형 프로토타입을 거쳐 구현까지 가는 방법입니다. 앱이나 서비스 화면을 기획하는 직장인에게 맞습니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 본 뒤 만족하면 Claude에게 구현(build)을 지시합니다.
예시
현재 앱을 살펴보고 우리 앱에 맞는 온보딩 화면 시안을 여러 개 만들어 줘.
  • 작은 사이드 프로젝트의 일부 화면에도 짧은 디자인 탐색을 거치면 결과가 나아집니다.
  • Claude가 작업하는 동안 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • 화면 안에서 Share의 Handoff to Claude Code 명령어를 복사해 Claude Code에 붙여 넣는 방법도 있습니다.
  • 구글 스티치(무료)는 텍스트나 이미지로 앱 UI를 만들고 Instant Prototype으로 클릭 프로토타입을 만드는 대안입니다.

18. 자막으로 영상용 애니메이션 만들기

녹화한 영상의 자막(SRT)과 프롬프트를 Claude Design에 넣어 말과 맞는 16:9 애니메이션을 만드는 방법입니다. 만든 결과는 편집 프로그램에 B-roll 층으로 얹어 씁니다.

  1. 카메라와 화면을 녹화하고 녹화본에서 MP3를 추출해 ChatGPT에 올립니다.
  2. SRT 트랜스크립트를 만들어 달라고 요청해 타임스탬프가 있는 자막을 받습니다.
  3. claude.ai/design을 열고 SRT 파일과 애니메이션 프롬프트를 붙여 넣습니다.
  4. 로고와 인터페이스 스크린샷을 첨부하고 모델 설정을 높게(extra 또는 max) 둡니다.
  5. 엔터를 눌러 생성을 기다리고, 멈춘 듯하면 계속하라고 입력합니다.
  6. 완성된 영상을 내레이션과 함께 보며 수정 사항을 요청합니다.
  7. 편집 프로그램에 B-roll 층으로 넣어 필요한 부분만 골라 씁니다.
예시
첨부한 SRT 자막의 타이밍에 맞춰 16:9 그래픽 애니메이션을 만들어 줘. 움직임은 많이, 글자는 최소로 해 줘.
  • 기본값은 글자가 많게 나오므로 움직임 위주, 글자 최소로 요청합니다.
  • 생성에는 영상 길이에 따라 약 30분~2시간이 걸립니다.
  • 높은 사고 수준 설정이 중간 수준보다 결과가 훨씬 좋았다고 합니다.
  • 진행이 멈췄는데 알려 주지 않는 경우가 있어 계속하라고 지시해야 합니다.
