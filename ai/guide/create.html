문서·슬라이드·디자인 만들기

Claude의 Docs·Slides·Design과 PowerPoint·Excel·Word 연동, 그리고 Adobe Acrobat·Genspark·Google 도구까지 활용해 문서, 엑셀, 슬라이드, 이미지, 디자인을 만드는 방법을 모았습니다. 먼저 Claude 채팅에서 문서·슬라이드를 만들어 보고, 디자인 시스템으로 톤을 통일한 뒤, 오피스 프로그램 연동과 팀 협업, 이미지·영상 제작 순으로 보시면 좋습니다.

입문

1. 대화에서 문서·슬라이드 바로 만들기

Claude 대화 안에서 보고서 내용을 정리한 뒤 문서(Docs), 슬라이드(Slides), 디자인(Designs)으로 바로 이어서 만드는 기능입니다. 기존 대화 내용이 그대로 바탕이 되므로 처음부터 다시 설명할 필요가 없습니다.

  1. Opus 5.5로 보고서에 들어갈 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 말로 설명해 Claude가 형식을 고르게 합니다.
  3. 형식을 이미 안다면 /slides, /docs, /designs 중 하나를 입력합니다.
  4. Sonnet 5.5로 바꿔 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 반복합니다.
  5. 직접 고치거나 특정 문단을 선택해 바꿀 내용을 말하면 그 부분만 수정됩니다.
예시
위에서 정리한 내용을 바탕으로 팀 회의용 슬라이드 8장을 만들어 줘. 시장 조사는 차트로 넣어 줘.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • 방향을 잡을 때는 Opus 5.5, 빠른 수정은 Sonnet 5.5로 나눠 쓰기를 권합니다.

2. Docs로 문서 만들고 댓글로 고치기

첨부한 사진·자료로 문서 초안을 만들고, 고칠 부분을 드래그해 댓글로 지시하면 Claude가 그 부분만 수정합니다. 텍스트 편집기처럼 직접 고칠 수도 있어 보고서나 브리프 작성에 좋습니다.

  1. 클로드 데스크탑에서 사진 등 자료를 첨부합니다.
  2. 만들 문서를 설명하는 프롬프트를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 모두 답합니다.
  4. 초안이 나오면 텍스트 편집기처럼 직접 수정합니다.
  5. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  6. 작업이 끝나면 완료 버튼을 눌러 결과를 확인합니다.
  7. 우측 상단 공유로 팀원을 초대하거나 내보내기로 파일을 저장합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프를 만들어 줘.
  • 질문 내용은 사용자마다 다르게 나옵니다.
  • Docs 내보내기 형식은 Word, PDF, 마크다운, 노션, 구글 문서입니다.
  • Claude도 댓글을 달고 해결하는 방식으로 협업합니다.

3. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 먼저 말로 내용을 모두 녹음하고 받아 적은 글을 Claude에게 넘겨 발표 자료로 만드는 방법입니다. 서식보다 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청하는 프롬프트를 입력합니다.
  5. 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

4. Claude 디자인 시스템 만들어 톤 통일하기

회사나 브랜드의 색·폰트·컴포넌트 규칙을 디자인 시스템으로 먼저 만들어 두면 이후 앱·PPT·시안에 자동 적용됩니다. 디자인 시스템 없이 쓰면 결과물이 AI스럽게 나오기 쉽습니다.

  1. 주소창에 claude.ai/design을 입력해 접속합니다.
  2. 디자인 시스템 탭에서 Create를 누릅니다.
  3. 회사 이름과 설명을 적습니다.
  4. 기존 자료가 있으면 Link code on GitHub에 깃허브 주소를 넣거나 피그마 파일을 넣습니다. getdesign 사이트의 DESIGN.md를 복사해 붙여 넣는 방법도 있습니다.
  5. 폰트를 쓰려면 폰트 파일을 드래그해 업로드합니다.
  6. Continue to generation을 누르고 Generate로 약 5분간 기다립니다.
  7. 폰트 계층, 간격, 컴포넌트, 브랜드 아이콘, UI 키트 데모 문서가 나오면 확인합니다.
예시
업로드한 폰트로 일괄 적용하고 그래프 컴포넌트를 포함해 줘.
  • 앱·PPT를 만들기 전에 디자인 시스템부터 만드는 것이 결과 품질을 좌우합니다.
  • Claude Design은 베타이며, 사용량은 Claude Code 사용량과 통합되어 구독 플랜 안에서 쓸 수 있습니다(예전 방식: 별도 한도로 관리되어 한도가 빡빡했음).
  • Pro 이상 유료 플랜이 필요하고 무료 플랜은 쓸 수 없습니다.

5. Claude 디자인으로 PPT 만들고 PPTX로 내보내기

만들어 둔 디자인 시스템을 적용해 슬라이드 덱을 만들고 PowerPoint 파일로 내려받는 방법입니다. 내보내기 옵션을 맞추면 폰트 깨짐과 레이아웃 붕괴를 줄일 수 있습니다.

  1. 초기 화면에서 Slide deck 프로젝트를 새로 만듭니다.
  2. 이름을 짓고 앞서 만든 디자인 시스템을 선택합니다.
  3. 발표자 메모를 넣으려면 Use speaker notes를 체크합니다.
  4. Create를 누르고 슬라이드 장수와 주제를 프롬프트로 입력합니다.
  5. Claude가 묻는 주제·대상·디자인 질문에 답하고 Continue를 누릅니다.
  6. 결과를 확인하고 수정이 필요하면 Claude 디자인 안에서 편집합니다.
  7. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 다운로드합니다.
  8. 받은 PPTX를 파워포인트나 키노트에서 열어 폰트와 레이아웃을 확인합니다.
예시
최신 AI 트렌드 리서치 주제로 12장짜리 PT 만들어 줘.
  • 유니버셜 폰트는 어느 컴퓨터에서나 열리지만 폰트가 바뀔 수 있습니다.
  • 스크린샷 베이스 PPTX는 모양이 같지만 편집이 불가능합니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • 발표자 메모를 켜면 슬라이드의 글이 줄고 설명은 메모로 들어갑니다.

6. 디자인 규칙서를 스킬로 저장해 PPT 자동화

AI로 PPT를 만들 때 결과가 들쭉날쭉한 것은 기준이 없기 때문입니다. 수치로 된 디자인 규칙서를 만들고 스킬로 저장해 두면 다음부터 같은 톤의 PPT를 반복해서 만들 수 있습니다.

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준으로 디자인 규칙서를 만듭니다.
  2. 규칙서로 Claude Code나 코덱스에서 PPT 작업을 합니다.
  3. 작업을 마친 뒤 스킬 생성을 요청합니다.
  4. 다음 PPT 작업 때 그 스킬을 불러와 사용합니다.
  5. 업무 매뉴얼도 함께 만들어 남깁니다.
  6. 자동 검사, 눈 검사, 숫자 검산 세 가지로 결과를 확인합니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘.
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 수치로 명확히 적습니다.
  • 영상이 제안한 예시 기준: 색 3가지(검정·흰색·파랑), 본문 26~30px, 제목 68px, 장당 약 200자.
  • 한글 글꼴은 자간을 0으로 두면 AI 티가 줄어듭니다.
  • HTML과 PPTX는 생성 방식이 달라 디자인이 틀어질 수 있으니 계속 비교해 맞춥니다.

7. PowerPoint 안에서 Claude로 덱 만들고 고치기

PowerPoint에 Claude 애드인을 열면 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 브랜드에 맞게 슬라이드를 만들고 고칩니다. 선택한 슬라이드·개체만 수정하고, 결과는 직접 편집 가능한 기본 도형과 차트입니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 엽니다.
  2. Claude 애드인을 열고 슬라이드 수, 주제, 다룰 항목, 어조를 적어 요청합니다.
  3. 필요하면 + 버튼으로 보고서나 데이터 파일을 올려 맥락을 더합니다.
  4. Claude가 변경 전에 허락을 구하면 검토하고 허용합니다.
  5. 고칠 슬라이드나 개체를 선택하고 그 부분만 수정을 요청합니다.
  6. 글머리표 슬라이드는 블록형 레이아웃으로, 표는 2x2 매트릭스로 바꿔 달라고 요청합니다.
  7. 슬라이드를 합치거나 순서를 옮길 때는 지울 슬라이드를 묻는 확인에 답합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 데이터 중심의 애널리스트 어조로 만들어 줘. 필요하면 질문해 줘.
  • 요청 끝에 "필요하면 질문하라"를 덧붙이면 Claude가 먼저 기존 내용을 읽고 되묻습니다.
  • Google Drive·Notion·Confluence 같은 커넥터를 설정해 두면 애드인에서도 외부 자료를 쓸 수 있습니다.
  • 복잡하거나 많이 맞춤화된 템플릿은 브랜드 지침에 맞는지 직접 확인합니다.
  • 민감하거나 규제 대상인 내용은 조직의 데이터 취급 정책을 따릅니다.

8. Excel에서 Claude로 분석·피벗·차트 만들기

Claude in Excel은 통합 문서 전체를 이해하고 질문 답변, 오류 추적, 수식 설명을 셀 단위 인용과 함께 제공합니다. 피벗 테이블과 차트 작성까지 맡길 수 있습니다.

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C를 눌러 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽고 확인합니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
  6. 피벗 테이블을 요청하고, 이어서 그 표로 차트를 만들게 합니다.
  7. 차트 종류, 제목 등을 요청으로 수정합니다.
예시
Create a pivot table showing total revenue by region and product.

9. Word에서 Claude로 초안 다듬기

Claude for Word는 Word 패널 안에서 댓글 요약, 변경 추적, 사실 확인, 서식 정리, 분량 줄이기까지 맡습니다. 모든 수정이 검토 카드와 추적 변경으로 나타나 직접 수락하거나 거절할 수 있습니다.

  1. Word 오른쪽의 Claude 패널을 열고 문서의 열린 댓글을 검토자별로 요약해 달라고 요청합니다.
  2. 변경 내용 추적을 켜고 모든 작업에 유지하도록 요청한 뒤, 확인창에서 Allow once를 누릅니다.
  3. Box 같은 외부 문서와 대조해 사실 확인을 요청하고, 맞지 않는 내용은 고치게 합니다.
  4. 수정 카드를 확인해 적용하면 추적 변경으로 문서에 반영됩니다.
  5. 서식은 원하는 최종 상태를 말하고 Don't change anything else.를 덧붙입니다.
  6. 고쳐 쓸 문단을 선택해 고객용 문장으로 바꾸게 하고 카드별로 확인합니다.
  7. 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 교정 스킬을 골라 오탈자와 문법을 교정합니다.
예시
We need to get this under 1,000 words, but don't cut any more than you need to. Keep the quotes and dates.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남습니다.
  • 카드가 지나치게 잘라 내면 이유를 말하고 다시 제안하게 합니다.
  • Word 웹, Windows, Mac에서 쓰며 Pro, Max, Team, Enterprise 플랜에 포함됩니다.

10. 아티팩트로 앱 만들고 팀과 함께 편집하기

코딩 없이 말로 설명해 가계부 같은 간단한 앱을 만들고, 문서·트래커 같은 아티팩트를 팀원과 공유해 함께 편집합니다. 팀원마다 보기·댓글·수정 권한을 정할 수 있습니다.

  1. 새 아티팩트를 누르고 처음부터 시작하기를 선택합니다. 템플릿으로 시작할 수도 있습니다.
  2. 만들 앱이나 문서를 설명합니다.
  3. 우측 패널에서 만들어진 결과를 직접 사용해 봅니다.
  4. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  5. 팀원을 추가하고 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  6. 입력·체크만 필요한 사람은 contributor로 지정합니다.
  7. 댓글이 달리면 Claude에게 업데이트를 요청합니다.

  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 링크를 공유해 별도 웹페이지에서 보게 할 수도 있습니다.

12. 제품 사진으로 광고·상세페이지 이미지 만들기

상품 사진 한 장으로 대표 이미지, 착용샷, 배너, SNS용 이미지를 만들고 상세페이지 시안까지 이어 가는 방법입니다. Claude에 Artlist를 연결하거나 Genspark Design을 쓸 수 있습니다.

  1. Claude에 Artlist 커넥터를 연결하고, 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 요청합니다.
  2. 생성 없이 체크만 해 달라고 하며 사진을 첨부하고, 업로드 위젯으로 올립니다.
  3. 모델, 비율, 해상도를 구체적으로 적어 대표 이미지를 요청합니다.
  4. 착용샷·디테일·배너를 추가로 요청합니다.
  5. 바지를 청바지로 바꿔 줘처럼 유지할 것과 바꿀 것을 나누어 수정합니다.
  6. Genspark을 쓴다면 디자인에서 +로 광고 레퍼런스와 제품 사진을 첨부하고 키 비주얼을 요청합니다.
  7. 광고 시안으로 디자인 시스템을 정리한 뒤 상세페이지와 랜딩페이지를 이어서 요청합니다.
  8. 결과를 다운로드로 저장합니다.
예시
첨부한 운동화 사진으로 정사각형 2K 대표 이미지를 만들어 줘. 신발의 형태와 로고는 그대로 유지해 줘.
  • 생성 전에는 체크만 시키면 Artlist 크레딧을 아낄 수 있고, 재생성하면 크레딧이 추가로 소진됩니다.
