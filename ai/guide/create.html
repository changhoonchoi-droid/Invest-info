문서·슬라이드·디자인 만들기

이 분야에서는 Claude 대화창, Claude 디자인, Word·Excel·PowerPoint 애드인, Adobe Acrobat 같은 도구로 보고서·발표 자료·브랜드 이미지·간단한 앱까지 말로 만들 수 있습니다. 처음이라면 대화에서 문서·슬라이드를 바로 만드는 입문 가이드부터 보세요. 그다음 평소 쓰는 오피스 프로그램 안에서 Claude를 쓰는 법을 익히고, 디자인 시스템·스킬로 매번 같은 품질을 내는 응용 가이드로 넘어가면 됩니다.

최근 바뀐 점

  • 이제 어떤 Claude 대화에서든 /slides, /docs, /designs로 문서·슬라이드·디자인을 바로 만들고, 같은 채팅 안에서 브리프→브랜드 시안→발표 자료로 이어서 작업할 수 있습니다.
  • 채팅과 Cowork가 하나의 Claude로 합쳐져 모드를 고를 필요가 없고, 작업이 클라우드에서 돌아 노트북을 닫아도 계속되며 휴대폰으로 진행 상황을 볼 수 있습니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집하고, 드래그한 부분에 댓글을 달거나 Claude를 멘션해 수정을 맡길 수 있습니다.

1. 대화에서 문서·슬라이드 바로 만들기

Claude 대화창 안에서 Docs(문서), Slides(발표 자료), Designs(디자인)를 바로 만들고, 직접 클릭하거나 댓글로 고치는 기본 기능입니다. 보고서·브리프·발표 자료 초안이 필요할 때 대화로 내용을 정리한 뒤 그대로 결과물로 바꿉니다.

  1. Opus 5.5로 만들 내용을 먼저 대화로 정리합니다. 사진이나 자료가 있으면 함께 첨부합니다.
  2. 원하는 결과물을 설명해 Claude가 형식을 고르게 하거나, 형식을 안다면 /slides, /docs, /designs 중 하나를 입력합니다.
  3. Claude가 던지는 질문에 모두 답합니다.
  4. 초안이 나오면 텍스트 편집기처럼 직접 고칩니다.
  5. 고칠 부분을 드래그한 뒤 댓글을 눌러 '이 내용을 더 자세하게 작성해 줘'처럼 지시합니다.
  6. Sonnet 5.5로 바꿔 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 반복합니다.
  7. 우측 상단 공유로 팀원을 초대하거나 내보내기로 파일을 저장합니다.
예시
/docs 첨부한 신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프를 만들어 줘
  • Docs·Slides·Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Docs는 Word·PDF·마크다운·노션·구글 문서로, Slides는 PDF·파워포인트·PNG·구글 슬라이드로 내보낼 수 있습니다.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • Claude가 묻는 질문은 사용자마다 다르게 나옵니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 휴대폰에 녹음한 뒤 받아 적은 글을 Claude에 넘겨 슬라이드로 만드는 방법입니다. 서식 작업 대신 내용에 집중하고 싶을 때 씁니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본을 복사합니다.
  3. 변환본을 Claude에 붙여 넣어 보냅니다.
  4. 슬라이드로 만들어 달라는 프롬프트를 함께 입력합니다.
  5. 결과에서 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기로 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있으면 폰트·템플릿을 따로 찾지 않아도 됩니다.

3. 아티팩트로 간단한 앱 만들기

아티팩트는 Claude가 만든 결과물을 오른쪽 패널에 띄워 바로 써 볼 수 있게 하는 기능입니다. 코딩을 몰라도 가계부 같은 작은 업무용 앱을 말로 설명해 만들고 링크로 공유할 수 있습니다.

  1. 새 아티팩트를 누릅니다.
  2. 처음부터 시작하기를 선택합니다.
  3. 만들 앱을 설명합니다.
  4. 우측 패널에서 만들어진 앱을 직접 사용해 봅니다.
  5. 공유하려면 게시해 링크를 받습니다.
예시
월별 가계부 앱을 만들어 줘
  • 코딩을 몰라도 말로 설명하면 앱을 만들 수 있습니다.

4. Acrobat PDF 스페이스로 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 기획서·보고서·기사 링크를 모아 넣으면 AI가 내용을 정리하고 발표 자료 초안까지 만들어 줍니다. 원문을 기반으로 만들기 때문에 근거를 확인하며 문서 기반 PPT를 만들 때 좋습니다.

  1. 어도비 사이트에 로그인하고 Adobe Acrobat에서 PDF 스페이스 만들기를 선택합니다.
  2. 장치, 웹링크, 텍스트 붙여 넣기로 보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  3. AI가 파일 내용을 분석해 스페이스에 정리할 때까지 기다립니다.
  4. AI 어시스턴트에 발표 목적과 청중, 원하는 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 표시된 근거 부분을 확인합니다.
  6. 프레젠테이션 만들기를 누릅니다.
  7. 청중·목적·어조(길이·템플릿)를 선택하고 슬라이드를 생성합니다.
  8. 오른쪽 상단 연필 모양으로 내용, 배치, 폰트를 편집합니다.
  9. 다운로드로 PPTX·PDF·PNG·JPG 중 원하는 형식으로 저장합니다.
  • PDF 스페이스에는 파일·이미지·웹 링크·텍스트를 최대 100개까지 넣을 수 있습니다.
  • 생성된 내용과 수치는 원문과 비교해 확인하고, 근거가 없는 내용은 '확인 필요'로 표시해 달라고 요청할 수 있습니다.
  • 유료 구독이 필요합니다.

5. Excel에서 Claude로 분석·차트 만들기

Claude in Excel은 통합 문서 전체를 읽고 질문에 답하거나 오류를 추적하고, 피벗 테이블·차트까지 만들어 주는 사이드바 에이전트입니다. 셀 단위 근거를 함께 보여 줘서 숫자를 확인하며 쓸 수 있습니다.

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C를 눌러 Claude 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽고, 응답의 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
  5. Create a pivot table showing total revenue by region and product.처럼 피벗 테이블을 요청합니다.
  6. Now, create a chart from this pivot table showing revenue by region.으로 차트를 만듭니다.
  7. Change the chart to be a stacked bar chart and add a title.처럼 차트 종류·제목을 고칩니다.
예시
I'm trying to keep my travel and meal budget to under 40% of my total costs. Did I hit that target?
  • 오류는 Why is there an error in May?, 수식은 How does the letter grade formula work?처럼 물으면 원인 셀과 부분별 설명을 받을 수 있습니다.
  • Excel과 PowerPoint 파일을 함께 열면 한 대화에서 표를 만들고 슬라이드까지 갱신하며, 이 흐름을 Skills로 저장해 다시 실행할 수 있습니다.
  • Pro·Max·Team·Enterprise 플랜용 베타이며, 민감한 데이터는 조직의 데이터 처리 정책을 따르세요.

6. PowerPoint에서 Claude로 덱 만들기

Claude in PowerPoint는 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 회사 템플릿에 맞춰 덱을 만들고 고치는 애드인입니다. 처음부터 덱을 만들거나, 선택한 슬라이드만 고치고, 합치기·순서 바꾸기로 흐름을 다듬을 때 씁니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 열고 Claude 애드인을 엽니다.
  2. 필요하면 + 버튼으로 리서치 보고서·데이터 파일·내부 분석 자료를 올립니다.
  3. 슬라이드 수, 주제, 다룰 항목, 어조를 적고 끝에 '필요하면 질문해 줘'를 덧붙여 요청합니다.
  4. Claude의 질문에 답하고, 변경 전 허락을 구하면 매번 검토하거나 편집을 허용합니다.
  5. 고칠 슬라이드나 텍스트 상자를 선택하고 '이 섹션을 한 줄로 요약해 줘'처럼 그 부분만 수정을 요청합니다.
  6. 글머리표가 많은 슬라이드를 선택하고 '4개 블록의 시각 레이아웃으로 바꿔 줘'라고 하며 블록마다 넣을 항목을 지정합니다.
  7. '4번과 5번을 하나로 합쳐 줘', '규제 슬라이드를 시장 규모 바로 뒤로 옮겨 줘'처럼 구조를 정리합니다.
  8. 생성된 덱의 출처 설명과 글꼴·색상·간격이 맞는지 확인합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 데이터 중심의 애널리스트 어조로 만들어 줘. 필요하면 질문해 줘.
  • 결과는 이미지가 아니라 PowerPoint 기본 도형·차트라서 하나씩 직접 편집할 수 있습니다.
  • Claude에 설정한 Google Drive·Notion·Confluence 커넥터가 애드인에도 그대로 적용됩니다.
  • 공유받은 덱은 '덱 전체의 논지를 슬라이드별로 요약해 줘', '7번 슬라이드에 인용된 데이터 출처는?'처럼 물어 회의 준비에 쓸 수 있습니다.
  • 복잡하게 맞춤화된 템플릿은 브랜드 지침과 맞는지 직접 확인하세요.

7. Word에서 Claude로 초안 다듬기

Claude for Word는 Word 오른쪽 패널에서 문서를 읽고 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기, 분량 줄이기까지 맡습니다. 모든 수정이 검토 카드와 변경 내용 추적으로 남아 하나씩 수락하거나 거절할 수 있습니다.

  1. Word 오른쪽의 Claude 패널을 열고 문서에 달린 댓글을 검토자별로 정리해 달라고 요청합니다.
  2. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고 확인창에서 Allow once를 누릅니다.
  3. Box 등에 있는 근거 문서와 수치를 대조하게 하고, 맞지 않는 내용은 고치게 합니다.
  4. 수정 카드를 확인해 적용하면 추적 변경으로 문서에 반영됩니다.
  5. 서식은 원하는 최종 상태를 말하고 Don't change anything else.를 덧붙여 정리합니다.
  6. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인합니다.
  7. 분량은 We need to get this under 1,000 words, but don't cut any more than you need to.처럼 요청하고 지킬 부분(인용문, 날짜)을 함께 알려 줍니다.
  8. 패널에 /를 입력해 copy edit 스킬로 오탈자를 교정한 뒤 변경 사항을 모두 수락하게 합니다.
예시
Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남아 팀이 변경 내용을 볼 수 있습니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.
  • Word 웹·Windows·Mac에서 쓸 수 있고, Microsoft AppSource에서 설치하며 Pro·Max·Team·Enterprise 플랜에 포함됩니다.

8. 디자인 시스템 만들기

디자인 시스템은 색·글꼴·자간·여백·카드·버튼 같은 브랜드 규칙 모음입니다. 한 번 만들어 두면 이후 슬라이드·디자인·앱 시안에 같은 규칙이 자동으로 적용되어 'AI 티' 나는 결과물을 줄여 줍니다.

  1. 클로드 디자인(claude.ai/design)에 접속해 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. getdesign 사이트에서 원하는 기업의 DESIGN.md를 열고 코드를 복사합니다.
  3. 클로드 디자인 입력창에 붙여 넣습니다.
  4. 업로드한 폰트로 일괄 적용하고 그래프 컴포넌트를 포함하라고 함께 적습니다.
  5. 프리텐다드 같은 폰트 파일을 내려받아 모든 파일을 드래그해 업로드합니다.
  6. 상단의 Continue to generation 버튼으로 디자인 시스템을 생성합니다.
  7. 생성된 폰트 계층, 간격, 컴포넌트를 확인합니다.
  • 예전 방식: 회사 이름과 설명을 적고 Link code on GitHub에 깃허브 주소나 피그마 파일을 넣은 뒤 Generate로 약 5분 기다려 만들었습니다. 회사 자료가 있다면 지금도 참고할 만합니다.
  • 슬라이드·앱을 만들기 전에 디자인 시스템부터 만드는 것이 결과 품질을 좌우합니다.
  • 예전 방식: 클로드 디자인 사용량은 채팅·Claude Code와 따로 관리되어 빡빡했지만, 2026년 5월 말 업데이트로 Claude Code 사용량과 통합되었습니다.

9. 슬라이드 만들고 PPTX로 내보내기

앞서 만든 문서·이미지나 디자인 시스템을 바탕으로 Claude에서 발표 슬라이드를 만들고, 파워포인트에서 편집할 수 있는 PPTX로 내보내는 방법입니다. 스피커 노트와 발표 모드까지 한 번에 준비할 수 있습니다.

  1. 앞선 문서·이미지가 있는 같은 대화에서(또는 디자인 시스템을 설정한 상태에서) 발표 자료를 요청합니다.
  2. 구성, 규칙, 디자인을 적고 시장 조사 내용은 차트로 넣어 달라고 지시합니다.
  3. Claude가 묻는 주제·대상·디자인 질문에 답합니다.
  4. 결과에서 스피커 노트를 확인하고 필요하면 편집합니다.
  5. 우측 하단 캔버스 버튼으로 전체 슬라이드를 한눈에 보고 고칩니다.
  6. 우측 상단 재생 버튼으로 발표 모드를 실행해 봅니다.
  7. 내보내기에서 파워포인트를 고르고, 폰트 옵션은 커스텀 폰트를 선택해 내려받습니다.
  8. 받은 PPTX를 파워포인트나 키노트에서 열어 폰트와 레이아웃을 확인합니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • 예전 방식: 클로드 디자인에서 Slide deck 프로젝트를 새로 만들고 디자인 시스템을 고른 뒤 Use speaker notes를 체크하고, Share → Export로 내보냈습니다.
  • 유니버셜 폰트는 어느 컴퓨터에서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양은 같지만 편집할 수 없습니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치이므로 폰트 파일을 업로드해 두는 것이 좋습니다.
  • 디자인 시스템을 활용하면 브랜드에 맞는 슬라이드가 나옵니다.

10. 브랜드 시안·SNS 이미지 만들기

같은 채팅에서 브랜드 방향 여러 개를 캔버스에 나란히 받아 고르고, 고른 시안으로 SNS 규격별 이미지까지 만드는 방법입니다. 신제품·신메뉴 출시처럼 브리프 하나로 홍보물 세트를 만들 때 씁니다.

  1. 브리프를 만든 같은 채팅에서 브랜드 방향 세 가지를 캔버스에 나란히 보여 달라고 요청합니다.
  2. 시안마다 팔레트, 폰트, 로고, 인스타 샘플 한 장씩 만들도록 지시합니다.
  3. 마음에 드는 시안을 고르고 댓글 기능으로 요소별로 수정합니다.
  4. 선택한 시안으로 1:1, 4:5, 9:16, 16:9 규격의 이미지를 요청합니다.
예시
브랜드 방향 세 가지를 캔버스에 나란히 보여 줘. 시안마다 팔레트, 폰트, 로고, 인스타 샘플 한 장씩 만들어 줘.
  • 디자인은 결과를 보고 직접 손봐 주는 것이 좋습니다.
  • 하나의 출시 브리프에서 발표 자료, 소셜 이미지 세트, 현장용 한 장 요약 문서까지 대화를 벗어나지 않고 만들 수 있습니다.

11. 디자인 규칙서를 스킬로 저장하기

AI로 만든 PPT가 매번 들쭉날쭉한 것은 기준이 없기 때문입니다. 색·글꼴·글씨 크기를 수치로 적은 규칙서로 작업한 뒤 그 과정을 스킬로 저장하면, 다음부터 대본만 넣어도 같은 톤의 PPT가 나옵니다.

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준을 수치로 적은 디자인 규칙서를 만듭니다.
  2. 회사 디자인을 기준으로 삼으려면 디자인 MD 모음 사이트에서 디자인 MD를 복사해 Claude Code에 붙여 넣고 PPT용 디자인 시스템으로 바꿔 달라고 요청합니다.
  3. 이때 수정 가능한 PPTX, 데이터 편집이 되는 차트, HTML과의 디자인 비교 검증, 애매하면 질문하기, 폰트 지정을 함께 요청하고 폰트 파일을 첨부합니다.
  4. 규칙서로 Claude Code나 코덱스에서 PPT 작업을 합니다.
  5. 결과물을 자동 검사, 눈 검사, 숫자 검산 세 가지로 확인합니다.
  6. 작업을 마친 뒤 대화 내용과 결과물로 스킬을 만들어 달라고 요청합니다.
  7. 'PPT 만드는 방법을 총정리한 업무 매뉴얼을 만들어 줘'로 매뉴얼도 함께 남깁니다.
  8. 다음 PPT 작업 때 그 스킬을 불러와 대본만 넣어 생성합니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • '깔끔하게', '세련되게'는 규칙이 아닙니다. 예: 색 3가지(검정·흰색·파랑), 본문 26~30px, 제목 68px, 도식 제목 34~36px, 장당 약 200자처럼 수치로 적습니다.
  • 한글 글꼴은 자간을 0으로 두면 AI 티가 줄어듭니다.
  • 색상표는 Open Color, 아이콘은 Lucide, 도식은 Mermaid 같은 오픈소스를 쓰면 품질이 올라갑니다.
  • HTML과 PPTX·키노트는 생성 방식이 달라 디자인이 틀어질 수 있으니 계속 비교해 맞춥니다.

12. 디자인 시안에서 앱 구현까지 하기

코드를 짜기 전에 Claude 디자인으로 화면 시안을 여러 개 받아 보고, 클릭형 프로토타입으로 써 본 뒤 Claude에게 구현까지 맡기는 흐름입니다. 사내 도구나 사이드 프로젝트의 화면을 더 잘 만들고 싶을 때 씁니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 본 뒤 만족하면 Claude에게 구현(build)을 지시합니다.
  • 예전 방식: claude.ai/design에서 Prototype 프로젝트를 만들고, 완성 후 Share의 Handoff to Claude Code 명령어를 복사해 Claude Code에 붙여 넣어 구현했습니다.
  • 예전 화면에서는 우측 하단 Tweaks로 화면의 여러 변형을 비교해 고를 수 있었습니다.
  • Claude가 작업하는 동안 기다리지 않고 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • 작은 화면 하나라도 짧은 디자인 탐색을 거치면 결과가 나아집니다.
