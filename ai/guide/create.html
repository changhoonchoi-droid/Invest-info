문서·슬라이드·디자인 만들기

이 분야에서는 Claude 대화 안에서 문서·슬라이드·디자인·앱을 만들고, Word·Excel·PowerPoint·Acrobat 같은 도구에서 AI로 작업하며, 이미지와 영상 자료까지 만들 수 있습니다. 먼저 1~3번으로 대화에서 결과물을 만들고 공유하는 법을 익히세요. 이어서 4~7번에서 Office·Acrobat 안의 AI를 쓰고, 8~12번에서 디자인 시스템과 자동화로 일정한 품질을 유지하는 순서로 보시면 좋습니다.

1. 대화에서 문서·슬라이드 바로 만들기

Claude 대화 안에서 보고서, 슬라이드, 디자인 같은 결과물을 바로 만드는 기능입니다. 대화로 정리한 내용을 그대로 이어받아 만들기 때문에, 자료를 다시 옮겨 붙일 필요가 없습니다. 처음 시작하는 분께 가장 먼저 권하는 방법입니다.

  1. Claude에서 보고서에 들어갈 내용을 먼저 대화로 정리합니다 (방향을 잡는 단계는 Opus 5.5 모델을 권장합니다).
  2. 사진 등 참고 자료가 있으면 대화창에 첨부합니다.
  3. 원하는 결과물을 설명하는 프롬프트를 입력합니다. 형식을 알면 /slides, /docs, /designs를 입력해도 됩니다.
  4. Claude가 던지는 질문에 모두 답합니다. 질문 내용은 사용자마다 다르게 나옵니다.
  5. 초안이 나오면 텍스트 편집기처럼 직접 고칩니다.
  6. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  7. 문구 다듬기, 차트 교체, 색상 변경 같은 반복 수정은 Sonnet 5.5로 바꿔서 합니다.
  8. 우측 상단 공유로 팀원을 초대하거나 내보내기로 파일을 저장합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님께 보고할 런칭 브리프를 문서로 만들어 줘.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Docs 내보내기는 Word, PDF, 마크다운, 노션, 구글 문서를 지원하고, Slides는 PDF, 파워포인트, PNG, 구글 슬라이드를 지원합니다.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • 예전 방식: 8월 영상에서는 채팅·코워크·코드·디자인을 용도별로 따로 골라 썼지만, 9월 업데이트 이후 채팅과 Cowork가 하나로 합쳐져 한 대화에서 이어서 작업합니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성으로 녹음하고 그 글을 Claude에게 보내 슬라이드로 만드는 방법입니다. 서식보다 내용에 집중할 수 있습니다. 메모가 두서없어도 괜찮습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청하는 프롬프트를 입력합니다.
  5. 결과에서 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

3. 아티팩트로 앱 만들고 팀과 함께 편집하기

아티팩트는 Claude가 대화 중에 만들어 주는 문서, 슬라이드, 디자인, 대시보드, 간단한 앱입니다. 코딩을 몰라도 말로 설명하면 만들 수 있고, 링크로 공유하거나 팀원과 함께 고칠 수 있습니다. 체크리스트나 트래커처럼 여럿이 같이 쓰는 도구에 잘 맞습니다.

  1. Artifacts 탭에서 새 아티팩트를 누르고 처음부터 시작하기를 선택하거나 템플릿으로 시작합니다.
  2. 만들 것을 설명합니다 (예: 월별 가계부 앱, 우선순위별 체크박스 트래커).
  3. 우측 패널에서 만들어진 결과를 직접 사용해 봅니다.
  4. 공유할 때 쓰는 체크 표시가 모두에게 같은 목록으로 저장되게 해 달라고 요청합니다.
  5. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  6. 조직의 팀원을 추가하고 보기, 댓글, 수정 중 접근 수준을 고릅니다.
  7. 입력과 체크만 필요한 사람은 contributor로 지정합니다.
  8. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
예시
이 문서를 바탕으로 우선순위별 체크박스가 있는 트래커를 만들어 줘. 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.
  • 공유된 아티팩트에서 "이번 주 팀이 한 일은?" 같은 요약을 요청할 수 있습니다.

4. Word에서 Claude로 초안 다듬기

Microsoft Word 패널 안에서 Claude가 문서를 읽고 댓글 정리, 사실 확인, 서식 정리, 분량 줄이기까지 맡아 줍니다. 모든 수정은 검토 카드와 추적 변경으로 나타나 직접 수락하거나 거절합니다. 팀 검토를 거치는 공지문이나 보고서에 편리합니다.

  1. Word 오른쪽의 Claude 패널을 열고 문서에 달린 댓글을 검토자별로 요약해 달라고 요청합니다.
  2. 추적 변경을 켜고 유지해 달라고 요청한 뒤, 확인창에서 Allow once를 누릅니다.
  3. Box 같은 외부 문서와 대조해 사실 확인을 요청하고, 맞지 않는 내용은 고치게 합니다.
  4. 수정 카드를 확인해 적용하면 추적 변경으로 문서에 반영됩니다.
  5. 서식은 원하는 최종 상태를 말해 정리합니다 (번호 잇기, 표를 글머리표로 바꾸기 등).
  6. 고쳐 쓸 문단을 선택하고 독자 관점으로 다시 쓰라고 요청한 뒤 카드별로 확인합니다.
  7. 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬을 골라 오탈자와 문법을 한 번에 교정합니다.
예시
Rewrite these in customer language. Lead with what the reader gets. Don't change anything else.
  • Word 웹, Windows, Mac에서 쓸 수 있으며 Microsoft AppSource에서 설치합니다. Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남아 팀이 변경 내용을 볼 수 있습니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.

5. Excel에서 Claude로 분석·피벗 만들기

Claude in Excel은 통합 문서 전체를 이해하고 질문 답변, 오류 추적, 수식 설명을 셀 단위 인용과 함께 해 주는 도구입니다. 피벗 테이블과 차트 작성도 요청 한 줄로 맡길 수 있습니다. 수정 전에 허락을 구하고 변경 내용을 설명해 줍니다.

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C를 눌러 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽고 확인합니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
  6. 피벗 테이블이 필요하면 지역·제품 등 기준을 적어 요청합니다.
  7. 만들어진 피벗 테이블로 차트를 요청하고, 종류와 제목을 요청으로 바꿉니다.
예시
Create a pivot table showing total revenue by region and product.
  • 오류는 Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • 수식이 낯설면 어떻게 동작하는지 물어 부분별 설명을 받습니다.
  • Pro, Max, Team, Enterprise 대상 리서치 프리뷰 베타입니다.
  • 외부에 공유할 결과물과 민감한 데이터는 조직의 기준과 데이터 처리 정책에 맞는지 확인합니다.

6. PowerPoint에서 Claude로 덱 만들고 고치기

PowerPoint 안의 Claude는 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 브랜드에 맞게 슬라이드를 만들고 고칩니다. 선택한 슬라이드나 개체만 수정하고, 결과는 직접 편집 가능한 기본 도형과 차트입니다. 이미 있는 템플릿으로 빠르게 초안을 만들 때 유용합니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 엽니다.
  2. Claude 애드인을 열고 슬라이드 수, 주제, 다룰 항목, 어조를 적어 요청합니다.
  3. 참고 자료는 + 버튼으로 올립니다 (보고서, 데이터 파일, 내부 분석 자료).
  4. Claude가 변경 전에 허락을 구하면 검토하고 허용합니다.
  5. 고칠 슬라이드나 텍스트 상자를 선택하고 "이 섹션을 한 줄로 요약해 줘"처럼 요청합니다.
  6. 글머리표가 많은 슬라이드는 "4개 블록의 시각 레이아웃으로 바꿔 줘"처럼 요청합니다.
  7. 겹치는 슬라이드는 "4번과 5번을 하나로 합쳐 줘"처럼 요청하고 순서 변경도 같은 방식으로 합니다.
  8. 생성된 슬라이드가 덱의 글꼴·색상·간격과 맞는지 확인합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 만들어 줘. 데이터 중심의 애널리스트 어조로 써 주고, 필요하면 질문해.
  • 요청 끝에 "필요하면 질문하라"를 덧붙이면 Claude가 먼저 기존 내용을 읽고 빠진 점을 물어봅니다.
  • Claude AI에 설정해 둔 커넥터(Google Drive, Notion, Confluence)는 애드인에서도 그대로 쓸 수 있습니다.
  • 기존 덱을 열고 슬라이드별 논지 요약이나 "7번 슬라이드의 데이터 출처는?" 같은 질문도 할 수 있습니다.
  • 복잡하거나 많이 맞춤화된 템플릿은 브랜드 지침에 맞는지 직접 확인하세요.

7. Acrobat PDF 스페이스로 자료 기반 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 보고서·기사 링크 같은 자료를 모아 두고, AI가 요약한 뒤 그 내용으로 발표용 PPT를 만드는 방법입니다. 문서 기반이라 원문이 잘 반영되어 엉뚱한 정보가 들어갈 위험이 줄어듭니다. 유료 구독이 필요합니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 자료를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI가 파일 내용을 분석해 정리할 때까지 기다립니다.
  5. AI 어시스턴트에 발표 목적과 청중을 적어 요약을 요청하고, 요약 속 숫자를 눌러 원문의 근거를 확인합니다.
  6. 왼쪽 만들기의 프레젠테이션을 선택하고 대상자·톤·길이·템플릿을 고른 뒤 프레젠테이션 생성을 누릅니다.
  7. 편집 화면에서 글자와 디자인을 수정한 뒤 다운로드로 저장합니다.
  • PDF 스페이스에는 최대 100개 파일을 넣을 수 있고, 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 생성된 내용과 수치는 원문과 비교해 확인합니다.
  • 근거가 없는 내용은 확인 필요로 표시해 달라고 요청할 수 있습니다.
  • 발표 준비용으로 예상 질문과 답변을 정리해 달라고 할 수도 있습니다.

8. Claude 디자인으로 시안 만들고 코드로 넘기기

화면이나 브랜드를 만들기 전에 Claude 디자인에서 여러 시안을 먼저 보고, 댓글로 고친 뒤 클릭형 프로토타입을 거쳐 구현으로 넘기는 방법입니다. 코드를 짜기 전에 디자인을 짧게 탐색하면 결과가 나아집니다. SNS용 이미지도 같은 흐름으로 만듭니다.

  1. Claude에서 브랜드 방향 세 가지를 캔버스에 나란히 보여 달라고 요청합니다.
  2. 시안마다 팔레트, 폰트, 로고, 인스타 샘플 한 장씩 만들도록 지시합니다.
  3. 마음에 드는 시안을 고르고 댓글 기능으로 요소별로 수정합니다. 세부 사항은 에디터에서 직접 고칠 수도 있습니다.
  4. 선택한 시안으로 1:1, 4:5, 9:16, 16:9 규격의 이미지를 요청합니다.
  5. 앱 화면이라면 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  6. 프로토타입을 써 본 뒤 만족하면 Claude에게 구현(build)을 지시합니다.
  7. 코드 연결이 필요하면 Share에서 Handoff to Claude Code 명령어를 복사해 Claude Code에 붙여 넣고 실행합니다.
예시
우리 카페 신메뉴의 브랜드 방향 세 가지를 캔버스에 나란히 보여 줘. 시안마다 팔레트, 폰트, 로고, 인스타 샘플 한 장씩 만들어 줘.
  • 디자인은 결과를 보고 직접 손봐 주는 것이 좋습니다.
  • Tweaks로 화면의 여러 변형을 비교해 고를 수 있습니다.
  • 작업이 오래 걸리면 다른 일을 하다 돌아와 결과를 확인해도 됩니다.

9. 디자인 시스템 만들고 PPTX로 내보내기

디자인 시스템은 색, 폰트, 간격, 컴포넌트 같은 브랜드 규칙 모음입니다. 먼저 만들어 두면 이후 슬라이드와 화면이 일관된 디자인으로 나오고, 'AI 티'가 줄어듭니다. 만든 슬라이드는 PPTX로 내보내 PowerPoint나 Keynote에서 열 수 있습니다.

  1. Claude 디자인(claude.ai/design)에 접속해 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. getdesign 사이트에서 참고할 기업의 DESIGN.md를 열어 코드를 복사하고 입력창에 붙여 넣습니다.
  3. 업로드한 폰트로 일괄 적용하고 그래프 컴포넌트를 포함하라고 적고, 폰트 파일(영상에서는 프리텐다드)을 드래그해 업로드합니다.
  4. 상단의 Continue to generation으로 디자인 시스템을 생성합니다.
  5. 초기 화면으로 돌아가 방금 만든 디자인 시스템으로 설정하고 슬라이드를 요청합니다.
  6. Claude가 던지는 주제·대상·디자인 질문에 답하고 Continue를 누릅니다.
  7. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트 옵션으로 다운로드합니다.
  8. 받은 PPTX를 PowerPoint나 Keynote에서 열어 폰트와 레이아웃을 확인합니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘.
  • 유니버셜 폰트는 어느 컴퓨터에서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양이 같지만 편집이 불가능합니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • Pro·Max·Team·Enterprise 구독이 필요합니다.
  • 예전 방식: 4~5월에는 회사 이름과 설명을 적고 GitHub 주소나 피그마 파일을 넣어 디자인 시스템을 생성했고, 5월 말 업데이트 이후 HTML→PPTX 변환 품질이 좋아지고 사용량이 Claude Code와 통합되었습니다.

10. PPT 규칙서를 스킬로 저장해 같은 톤 유지하기

AI로 만든 PPT가 매번 들쭉날쭉한 이유는 기준이 없기 때문입니다. 수치로 적은 디자인 규칙서를 만들고, 작업 과정을 스킬로 저장해 두면 다음부터 같은 톤으로 만들 수 있습니다. 반복해서 PPT를 만드는 분께 맞습니다.

  1. 색 역할, 글꼴, 글씨 크기, 장당 글자 수, 장당 주제 1개 기준으로 디자인 규칙서를 만듭니다.
  2. 규칙서로 Claude Code나 코덱스에서 PPT 작업을 합니다.
  3. 작업을 마친 뒤 지금까지의 대화와 결과물로 스킬을 만들어 달라고 요청합니다.
  4. 다음 PPT 작업 때 그 스킬을 불러와 사용합니다.
  5. PPT 만드는 방법을 총정리한 업무 매뉴얼도 만들어 달라고 해 함께 남깁니다.
  6. 결과는 자동 검사, 눈 검사, 숫자 검산 세 가지로 점검합니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘.
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 수치로 명확히 적습니다.
  • 영상이 제안한 기준 예: 색 3가지(검정·흰색·파랑), 본문 26~30px, 제목 68px, 장당 약 200자. 한글 글꼴은 자간을 0으로 두면 AI 티가 줄어듭니다.
  • 나만의 규칙은 핀터레스트나 구글의 PPT 예시를 기준으로 명세서를 만들어 얻을 수 있습니다.
  • HTML과 PPTX·키노트는 생성 방식이 달라 디자인이 틀어질 수 있으니 계속 비교해 맞춥니다.

11. 스크린샷으로 랜딩 페이지 만들기

디자인은 말로 설명하는 것보다 이미지로 보여 주는 것이 훨씬 정확합니다. 마음에 드는 템플릿 사이트를 캡처해 구글 AI 스튜디오에 붙여 넣으면 비슷한 느낌의 랜딩 페이지가 만들어집니다. 간단한 소개·상세 페이지에 적합합니다.

  1. 프레이머에 접속해 리소스의 마켓플레이스에서 마음에 드는 템플릿을 고릅니다.
  2. 프리뷰를 눌러 실제 사이트 화면을 띄웁니다.
  3. 스크롤 캡처 도구로 웹사이트 전체를 캡처해 복사합니다.
  4. 구글 AI 스튜디오 프롬프트 입력창에 이미지를 붙여 넣습니다.
  5. 참고 이미지와 비슷한 느낌으로 만들어 달라고 요청합니다.
  6. 빌드를 눌러 결과를 확인하고 원본과 비교합니다.
  7. 고치고 싶은 곳은 어노테이트 앱을 켜 화면에 직접 표시하고, 애드 텍스트로 요청을 적은 뒤 애드투 챗과 샌드 프롬프트로 보냅니다.
예시
해당 이미지를 참고해서 비슷한 느낌의 랜딩 페이지 만들어 줘
  • 전체 페이지 캡처는 macOS에서 셔터 앱의 스크롤링 캡처를 추천했습니다.
  • 위치를 글로 설명하기 어려울 때 어노테이트가 효과적입니다.
  • 기능 추가는 "해당 사이트에 다크 모드 기능을 추가해 줘"처럼 이어서 요청합니다.
  • 영상 자막이 불분명해 버튼 이름은 화면에서 한 번 확인하세요.

12. Claude 디자인으로 영상용 애니메이션 만들기

녹화한 말에 맞는 16:9 애니메이션을 Claude 디자인으로 만들어 영상 편집의 B-roll 층으로 쓰는 작업 흐름입니다. 말의 타임스탬프가 있는 자막(SRT)을 넣는 것이 핵심입니다. 영상을 자주 만드는 분께 맞는 고급 활용입니다.

  1. 카메라와 화면을 녹화하고, 편집자와 공유할 파일은 Dropbox 폴더에 올립니다.
  2. 녹화본에서 MP3를 추출해 ChatGPT에 올립니다.
  3. SRT 트랜스크립트를 만들어 달라고 요청해 타임스탬프가 있는 자막을 받습니다.
  4. claude.ai/design을 열고 SRT 파일과 애니메이션 프롬프트를 붙여 넣습니다.
  5. 로고와 인터페이스 스크린샷을 첨부하고 모델 설정을 높게(extra 또는 max) 둡니다.
  6. 엔터를 눌러 생성을 기다리고, 멈춘 듯하면 계속하라고 입력합니다.
  7. 완성된 영상을 내레이션과 함께 보며 수정 사항을 요청합니다.
  8. 편집 프로그램에 B-roll 층으로 넣어 필요한 부분만 골라 씁니다.
  • 기본값은 글자가 많게 나오므로 프롬프트에서 16:9 그래픽, 움직임 위주, 글자 최소로 요청합니다.
  • 생성에는 영상 길이에 따라 약 30분~2시간이 걸립니다.
  • 진행이 멈췄는데 알려 주지 않는 경우가 있어 계속하라고 지시해야 합니다.
  • 높은 사고 수준 설정이 중간 수준보다 결과가 훨씬 좋았다고 합니다.
