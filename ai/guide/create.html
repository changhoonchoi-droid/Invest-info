문서·슬라이드·디자인 만들기

이 분야에서는 대화로 정리한 내용을 바로 슬라이드·문서·디자인으로 만들고, Word·Excel·PowerPoint 안에서 Claude에게 편집을 맡기고, 보고서 여러 개를 발표 자료로 바꿀 수 있습니다. 먼저 대화에서 결과물을 만들고 코멘트로 고치는 기초 가이드를 익히세요. 그다음 Office 앱 연동, 디자인 시안에서 구현까지 가는 응용 가이드로 넘어가면 됩니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 14개 기반 · 2026-10-25 갱신

최근 바뀐 점

  • 9월 업데이트로 채팅과 Cowork가 하나의 Claude로 합쳐졌습니다. 이제 어떤 대화에서든 문서·슬라이드·디자인을 만들 수 있고, 작업은 클라우드에서 돌아 노트북을 닫아도 계속됩니다.
  • Claude 공식 채널은 방향을 잡는 단계에는 Opus 5.5, 문구 다듬기 같은 빠른 수정에는 Sonnet 5.5를 쓰라고 권합니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집하고, 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • Adobe Acrobat의 PDF 스페이스에 자료를 최대 100개 넣으면 AI가 내용을 요약하고 프레젠테이션 초안을 만들어 줍니다. 결과는 PPTX로 내려받을 수 있습니다.

1. 대화에서 슬라이드·문서 바로 만들기

Claude와 나눈 대화 내용을 바탕으로 대화창을 벗어나지 않고 슬라이드, 문서, 디자인을 만드는 기능입니다. 보고서나 출시 브리프 하나로 발표 자료, 소셜 이미지 세트, 한 장짜리 요약 문서를 함께 만들 때 씁니다.

  1. 모델을 Opus 5.5로 두고 보고서나 브리프 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 말로 설명해 Claude가 형식을 고르게 합니다.
  3. 형식을 정해 두었다면 /slides, /docs, /designs 중 하나를 입력해 바로 요청합니다.
  4. 결과물이 나오면 모델을 Sonnet 5.5로 바꿉니다.
  5. 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 한 번에 하나씩 요청합니다.
예시
/slides 지금까지 정리한 보고서 내용으로 팀 공유용 발표 슬라이드를 만들어 줘
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • 기존 대화 내용을 바탕으로 만들어지므로 내용을 충분히 정리한 뒤 요청할수록 결과가 좋아집니다.
  • 자주 묻는 질문을 모아 고객에게 건넬 한 장짜리 안내문을 만드는 식으로도 쓸 수 있습니다.
  • Slides·Design·Docs는 2026년 9월 베타로 공개된 기능이라 화면이 바뀔 수 있습니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때 하고 싶은 말을 먼저 음성으로 녹음하고, 받아 적은 글을 Claude가 발표 자료로 바꾸게 하는 방법입니다. 서식보다 내용에 집중하고 싶을 때 좋습니다.

  1. 휴대폰 음성 메모 앱을 켭니다.
  2. 발표하고 싶은 내용을 순서 신경 쓰지 말고 모두 말해 녹음합니다.
  3. 녹음을 텍스트로 바꾼 변환본(transcript)을 복사합니다.
  4. 변환본을 Claude 대화창에 붙여 넣습니다.
  5. Claude의 슬라이드로 발표 자료를 만들어 달라고 요청합니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있으면 폰트나 템플릿을 따로 찾지 않아도 됩니다.
  • 산책하면서 녹음하는 식으로 생각을 정리하는 시간과 자료 만드는 시간을 나눌 수 있습니다.

3. 코멘트로 결과물 부분만 고치기

Claude가 만든 슬라이드·문서·디자인의 특정 부분에 코멘트를 달거나 그 부분을 선택해 요청하면 그곳만 수정됩니다. 전체를 다시 만들지 않고 세부를 다듬을 때 씁니다.

  1. Claude가 만든 결과물을 엽니다.
  2. 오탈자처럼 작은 수정은 슬라이드나 문서에서 직접 고칩니다.
  3. 바꾸고 싶은 문단을 선택하고 바꿀 내용을 말하면 그 부분만 수정됩니다.
  4. 구성 변경처럼 큰 수정은 해당 부분에 코멘트로 남겨 Claude에게 보냅니다.
  5. Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청합니다.
  6. 고쳐진 부분을 확인하고 필요하면 같은 방법으로 반복합니다.
  • 결과물의 어느 부분에든 코멘트를 달 수 있습니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집할 수 있어 팀 검토에 편합니다.
  • 잘 된 점과 아쉬운 점을 함께 적어 주면 방향을 잡기 쉽습니다.

4. Acrobat PDF 스페이스로 PPT 만들기

Adobe Acrobat의 AI 기반 PDF 스페이스에 보고서·기사 링크 같은 자료를 모아 핵심을 요약하고 프레젠테이션 초안을 만드는 기능입니다. 요약 속 숫자를 누르면 원문 근거가 표시되어 여러 자료를 근거와 함께 발표 자료로 정리할 때 좋습니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적과 청중, 원하는 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기에서 프레젠테이션을 선택하거나 채팅창에 프레젠테이션 생성을 요청합니다.
  7. 대상자·톤·길이·템플릿을 고르고 프레젠테이션 생성을 누릅니다.
  8. 편집 화면에서 글자와 디자인을 수정한 뒤 다운로드로 저장합니다.
  • PDF 스페이스에는 확장자와 관계없이 최대 100개 파일을 넣을 수 있고, 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 생성된 내용과 수치는 반드시 원문과 비교해 확인합니다.
  • 근거가 없는 내용은 '확인 필요'로 표시해 달라고 요청할 수 있습니다.
  • 예상 질문과 답변을 정리해 달라고 하면 발표 준비까지 할 수 있습니다.

5. Word에서 Claude로 초안 다듬기

Claude for Word는 Microsoft Word 오른쪽 패널에서 문서를 읽고 실제 편집까지 맡는 기능입니다. 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기, 분량 줄이기, 교정을 추적 변경으로 남기며 진행하므로 초안을 완성 문서로 만들 때 씁니다.

  1. Word 오른쪽의 Claude 패널을 열고 문서의 댓글을 검토자별로 요약해 달라고 요청합니다.
  2. 변경 내용 추적을 켜 달라고 요청하고, 확인창에서 Allow once를 누릅니다.
  3. Box에 있는 기준 문서와 대조해 수치·주장을 확인하게 하고, 맞지 않는 부분은 고치게 합니다.
  4. 수정 카드를 확인해 적용하면 추적 변경으로 문서에 반영됩니다.
  5. 번호 매기기나 표를 원하는 최종 모습으로 말해 서식을 정리하고 Don't change anything else.를 덧붙입니다.
  6. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인합니다.
  7. 분량을 줄일 때는 목표 단어 수와 꼭 지킬 부분(인용문, 날짜)을 함께 알려 주고, 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬로 오탈자와 문법을 교정하고, 마지막에 변경 사항을 모두 수락하게 합니다.
예시
Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?
  • Word 웹, Windows, Mac에서 쓸 수 있고, Microsoft AppSource에서 Claude for Microsoft 365로 설치합니다(Pro, Max, Team, Enterprise 플랜 포함).
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다. 수락할 때 leave the comment threads open이라고 하면 댓글 스레드가 남습니다.
  • 카드가 지나치게 잘라 내면 이유를 말하고 다시 제안하게 하면 됩니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.

6. Excel·PowerPoint를 한 대화로 잇기

Claude for Excel과 PowerPoint가 열려 있는 두 파일을 하나의 연속된 세션에서 다루는 기능입니다. 엑셀의 셀 값을 읽어 분석표를 만들고 그 결과를 슬라이드에 반영하므로, 탭을 오가거나 데이터를 다시 설명하지 않고 숫자와 발표 자료를 함께 갱신할 때 씁니다.

  1. 작업할 Excel 파일과 PowerPoint 파일을 함께 엽니다.
  2. Claude에게 한 번의 프롬프트로 필요한 자료 정리, Excel 표 작성, 슬라이드 반영, 요약문 작성을 이어서 요청합니다.
  3. Excel에 만들어진 표와 PowerPoint에 들어간 요약을 확인합니다.
  4. 자주 반복하는 흐름이면 Skills로 저장해 두고 다음에는 한 번의 클릭으로 다시 실행합니다.
  • 유료 플랜 사용자는 Mac·Windows에서 쓸 수 있습니다.
  • 예시에서는 비교 기업 재무 자료를 가져와 트레이딩 컴프스 표를 만들고, 밸류에이션 요약을 피치덱에 넣었습니다.
  • Claude가 만든 수치는 원자료와 대조해 확인한 뒤 공유합니다.

7. Claude 디자인으로 시안부터 구현까지

Claude 디자인은 원하는 것을 일상 언어로 설명하면 디자인 시안을 만들어 주는 기능입니다. 앱 화면처럼 코드로 바로 들어가기 전에 시안을 짧게 탐색하고, 클릭형 프로토타입으로 확인한 뒤 구현까지 이어 갈 때 씁니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 원하는 화면의 시안을 여러 개 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 보고 만족하면 Claude에게 구현(build)을 지시합니다.
  • 작은 사이드 프로젝트의 화면 하나라도 짧게 디자인을 탐색하고 나면 결과가 나아집니다.
  • Claude가 작업하는 동안 기다리지 말고 다른 일을 하다가 돌아와 결과를 확인해도 됩니다.
  • Claude Design은 문서보다 프로토타입을 먼저 만드는 방식으로 만들어진 도구입니다.
