문서·슬라이드·디자인 만들기

이 분야에서는 Claude와 제미나이에 말로 요청해 문서, 엑셀, 슬라이드, 디자인, 광고 이미지, 영상용 애니메이션까지 만들 수 있습니다. 먼저 아티팩트와 Docs·Slides로 한 채팅에서 결과물을 만들어 보고, 팀 공유와 Office 프로그램(Word·Excel·PowerPoint) 연동으로 넓혀 가세요. 디자인 시스템과 영상 애니메이션은 마지막에 보는 것을 권합니다.

최근 바뀐 점

  • Claude 채팅에서 만든 아티팩트를 팀원과 함께 편집하고, 사람마다 보기·댓글·수정 권한을 나눌 수 있습니다(11월 4일).
  • Claude 디자인에 영상 자막(SRT)을 넣으면 말과 맞는 16:9 애니메이션을 만드는 활용법이 소개되었습니다(11월 4일).
  • Claude 데스크탑에서 Docs·Designs·Slides를 한 채팅 안에서 이어서 쓸 수 있고, 모든 유료 요금제에서 사용할 수 있습니다(10월).
  • Adobe Acrobat의 PDF 스페이스에서 자료를 분석한 뒤 근거를 확인하며 프레젠테이션을 만들 수 있습니다(10월).

1. 아티팩트로 계산기·앱 만들기

아티팩트는 Claude 채팅 옆에 바로 작동하는 계산기, 퀴즈, 가계부 같은 작은 앱이나 문서를 띄워 주는 기능입니다. 코딩을 몰라도 말로 설명하면 만들어지므로, 업무용 계산기나 간단한 도구가 필요할 때 시작하기 좋습니다.

  1. Claude 채팅창에 만들고 싶은 도구를 한 줄로 요청합니다.
  2. 엔터를 치면 채팅 옆 패널에 작동하는 아티팩트가 나타납니다.
  3. 패널에서 만들어진 앱을 직접 사용해 봅니다.
  4. 고치고 싶은 점을 채팅으로 말해 수정합니다.
  5. 결과 화면을 캡처하거나, 공유하려면 게시해 링크로 받습니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.
  • 예전 방식: 새 아티팩트를 누르고 처음부터 시작하기를 선택한 뒤 설명했습니다. 지금은 채팅창에 바로 요청해도 됩니다.
  • Artifacts 탭에서 템플릿으로 시작하거나 내가 만든·공유받은 아티팩트를 모아 볼 수 있습니다.

2. 한 채팅에서 문서·디자인·슬라이드 만들기

Claude에서 Docs(문서), Designs(디자인), Slides(슬라이드)를 한 대화 안에서 이어서 만드는 방법입니다. 보고서, 브랜드 시안, 발표 자료를 같은 자료를 바탕으로 만들 때 씁니다.

  1. Claude 데스크탑에서 사진 등 자료를 첨부합니다.
  2. 만들 문서를 설명하는 프롬프트를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 답합니다.
  4. 초안이 나오면 직접 고치거나, 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 적습니다.
  5. 같은 채팅에서 브랜드 방향 세 가지를 캔버스에 나란히 보여 달라고 요청합니다.
  6. 마음에 드는 시안으로 1:1, 4:5, 9:16, 16:9 규격 이미지를 요청합니다.
  7. 같은 대화에서 발표 자료를 요청하고, 시장 조사는 차트로 넣어 달라고 지시합니다.
  8. 우측 상단 공유로 팀원을 초대하거나 내보내기로 PDF, 파워포인트 등 파일로 저장합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님께 보고할 런칭 브리프 문서를 만들어 줘
  • 결과물의 종류를 알면 /slides, /docs, /designs를 입력해 바로 시작할 수 있습니다.
  • 방향을 잡을 때는 Opus 5.5, 문구·차트·색상 같은 빠른 수정은 Sonnet 5.5로 바꿔 쓰기를 권합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.

3. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 먼저 녹음한 뒤 Claude에게 슬라이드로 바꿔 달라고 하는 방법입니다. 서식보다 내용에 집중하고 싶을 때 좋습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청하는 프롬프트를 붙입니다.
  5. 작은 수정은 직접 고치고, 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

4. 아티팩트를 팀과 공유해 함께 편집하기

Claude에서 만든 문서, 슬라이드, 디자인, 대시보드 같은 아티팩트를 팀원과 함께 보고 고치는 기능입니다. 누가 활동 중인지와 댓글·변경이 실시간으로 보입니다. 주간 업무 트래커나 공동 문서에 쓰기 좋습니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 댓글이 달리면 Claude에게 내용이나 스타일 업데이트를 요청합니다.
  6. 트래커라면 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시
위 문서를 바탕으로 우선순위별 체크박스가 있는 트래커를 만들어 줘. 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • "지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘"처럼 스타일을 고쳐도 실제 내용과 상태는 그대로 유지됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.
  • 공유된 아티팩트에서 "이번 주 팀이 한 일은?" 같은 요약을 요청할 수 있습니다.

5. 제미나이 캔버스로 문서·PPT 만들기

제미나이 캔버스는 답변 옆에 작업창이 생겨 문서나 슬라이드를 함께 고치는 기능입니다. 원하는 부분만 드래그해 수정하고, 구글 슬라이드를 거쳐 PPT 파일로 받을 수 있습니다.

  1. 제미나이 채팅창에서 도구를 눌러 캔버스를 선택합니다.
  2. 모델을 사고 또는 프로로 바꿉니다.
  3. +에서 파일 업로드로 자료를 첨부하거나 내용을 입력합니다.
  4. 대상과 톤을 적고 PPT 슬라이드 형식으로 만들어 달라고 요청합니다.
  5. 문서는 수정할 문단을 드래그해 요청하고, 길이·어조는 5단계 중에서 고릅니다.
  6. 슬라이드는 슬라이드로 내보내기를 누르고 완료되면 슬라이드 열기를 누릅니다.
  7. 구글 슬라이드에서 파일 → 다운로드 → pptx를 선택합니다.
예시
첨부한 자료로 임원 보고용 PPT 슬라이드를 만들어 줘. 처음에는 1번 표지와 2번 슬라이드만 만들고, 모든 슬라이드 좌상단에 제목을 넣어 줘.
  • 한 번에 다 만들기보다 1~2장씩 나눠 만들고, 수정 전에 슬라이드로 내보내 백업하면 안정적입니다.
  • 색상은 이름 대신 정확한 컬러 코드로 지정합니다.
  • 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리하는 분업을 권합니다.
  • 캔버스에서 "텍스트 기반 AI라서 도와드릴 수 없다"는 오류가 나면, 구글 슬라이드를 열어 오른쪽 위 제미나이로 한 장씩 만든 뒤 삽입하는 방법이 있습니다.
  • 크리에이티브 같은 통이미지 방식은 글자 수정이 안 될 수 있으니 수정이 필요하면 프로페셔널을 고릅니다.

6. Excel에서 Claude로 분석·피벗 만들기

Claude in Excel은 스프레드시트 안에서 통합 문서 전체를 이해하고 질문 답변, 오류 추적, 수식 설명, 피벗 테이블과 차트 작성까지 도와줍니다. 숫자 검증이 필요한 업무에 유용합니다.

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C를 눌러 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽고 확인합니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
  6. 피벗 테이블을 요청하고, 이어서 그 표로 차트를 만들게 합니다.
  7. Change the chart to be a stacked bar chart and add a title.처럼 차트를 수정시킵니다.
예시
Create a pivot table showing total revenue by region and product.
  • 오류는 Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • 수식이 낯설면 How does the letter grade formula work?처럼 물어 부분별 설명을 받습니다.
  • Pro, Max, Team, Enterprise 플랜의 리서치 프리뷰 베타입니다.
  • 외부에 공유할 결과물은 조직의 기준과 데이터 정책에 맞는지 검증합니다.

7. Word에서 Claude로 초안 다듬기

Claude for Word는 Word 패널 안에서 문서를 읽고 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기, 분량 줄이기를 맡습니다. 모든 수정이 추적 변경으로 남아 직접 수락하거나 거절할 수 있습니다.

  1. Word 오른쪽의 Claude 패널을 열고 댓글을 검토자별로 요약해 달라고 요청합니다.
  2. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고, 확인창에서 Allow once를 누릅니다.
  3. Box 문서가 있으면 본문의 수치와 주장을 그 문서와 대조하게 하고, 맞지 않는 내용은 고치게 합니다.
  4. 수정 카드를 확인해 적용하면 추적 변경으로 문서에 반영됩니다.
  5. 서식은 원하는 최종 상태를 말해 정리하고 Don't change anything else.를 덧붙입니다.
  6. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인합니다.
  7. 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬을 골라 오탈자와 문법을 교정합니다.
예시
We need to get this under 1,000 words, but don't cut any more than you need to.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남아 팀이 변경 내용을 볼 수 있습니다.
  • 카드가 지나치게 잘라 내면 이유를 말하고 다시 제안하게 합니다.
  • Word 웹, Windows, Mac에서 쓸 수 있고 Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.

8. PowerPoint에서 Claude로 덱 만들고 고치기

Claude in PowerPoint는 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 브랜드에 맞게 슬라이드를 만들고 고치는 도구입니다. 처음 초안부터 슬라이드 합치기, 선택한 부분만 수정하기까지 한 곳에서 할 수 있습니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 엽니다.
  2. Claude 애드인을 열고 슬라이드 수, 주제, 다룰 항목, 어조를 적어 요청합니다.
  3. + 버튼으로 보고서나 데이터 파일을 올려 맥락을 더합니다.
  4. Claude가 변경 전에 허락을 구하면 검토하거나 편집을 허용합니다.
  5. 수정할 슬라이드나 텍스트 상자를 선택하고 그 부분만 바꿔 달라고 요청합니다.
  6. 글머리표가 많은 슬라이드는 블록형 시각 레이아웃으로 바꿔 달라고 요청합니다.
  7. 겹치는 슬라이드는 번호를 말해 합치고, 순서 변경도 요청합니다.
  8. 생성된 슬라이드가 덱의 글꼴·색상·간격과 맞는지 확인합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 만들어 줘. 데이터 중심의 애널리스트 어조로 써 줘. 필요하면 질문해 줘.
  • 요청 끝에 "필요하면 질문하라"를 덧붙이면 Claude가 먼저 되묻고 만듭니다.
  • 선택한 개체만 수정하므로 나머지는 건드리지 않습니다.
  • 결과는 기본 도형과 차트라 직접 편집할 수 있습니다.
  • Google Drive·Notion·Confluence 같은 커넥터는 애드인에도 그대로 적용됩니다.
  • 복잡한 템플릿은 브랜드 지침과 맞는지 직접 확인합니다.

9. PDF 자료로 근거 있는 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 보고서와 기사를 넣고 AI로 요약한 뒤 프레젠테이션 초안까지 만드는 방법입니다. 요약 속 숫자를 누르면 원문 근거가 표시되어, 사실 확인이 중요한 발표에 알맞습니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 자료를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적과 청중, 원하는 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기의 프레젠테이션을 선택합니다.
  7. 대상자·톤·길이·템플릿을 고르고 프레젠테이션 생성을 누릅니다.
  8. 편집 화면에서 글자와 디자인을 수정한 뒤 다운로드로 저장합니다.
  • 문서 기반이라 원문 내용이 잘 반영되어 거짓 정보가 들어갈 위험이 줄어듭니다.
  • 근거가 없는 내용은 확인 필요로 표시해 달라고 요청할 수 있습니다.
  • 생성된 수치는 원문과 비교해 확인합니다.
  • 유료 구독이 필요하다고 안내되며, 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.

10. 제품 사진으로 광고·상세페이지 이미지 만들기

제품 사진 한 장으로 대표 이미지, 착용샷, 배너, SNS 광고 이미지를 만들고 상세페이지 시안까지 이어 가는 방법입니다. Claude에 Artlist를 커넥터로 연결하거나 Genspark Design을 쓰는 두 가지 방법이 소개되었습니다.

  1. Claude에 Artlist 커넥터를 연결하고, 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 요청합니다.
  2. 생성 없이 체크만 해 달라고 하며 사진을 첨부하고, 업로드 위젯으로 사진을 올립니다.
  3. 모델, 비율(정사각형), 해상도(2K) 등을 구체적으로 적어 대표 이미지를 요청합니다.
  4. 착용샷·디테일·배너를 추가로 요청합니다.
  5. 유지할 것과 바꿀 것을 나누어 수정하고 다운로드로 저장합니다.
  6. Genspark을 쓴다면 디자인에서 +로 광고 레퍼런스와 제품 사진을 첨부하고 광고 키 비주얼을 요청합니다.
  7. 만든 시안을 기준으로 디자인 시스템을 정리하게 한 뒤 상세페이지와 랜딩페이지를 이어서 요청합니다.
예시
첨부한 운동화 사진으로 흰 배경의 정사각형 대표 이미지를 2K 해상도로 만들어 줘. 로고와 신발 형태는 그대로 유지해 줘.
  • 생성 전에는 체크만 시키면 Artlist 크레딧을 아낄 수 있고, 재생성하면 크레딧이 추가로 듭니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 반드시 확인합니다.
  • Genspark에서 잘 모르는 질문은 비워 두면 AI가 제안해 진행합니다.
  • 공유 버튼으로 이메일을 편집자로 초대해 함께 수정할 수 있습니다.

11. 디자인 시스템으로 일관된 PPT 만들기

AI가 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 색, 글꼴, 글씨 크기 같은 규칙을 먼저 정해 두면 매번 같은 톤의 PPT를 만들 수 있습니다. Claude 디자인의 디자인 시스템이나 스킬로 저장해 재사용합니다.

  1. claude.ai/design에 접속해 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. 회사의 디자인 규칙(DESIGN.md 코드나 깃허브 주소)을 붙여 넣고 쓸 폰트 파일을 업로드합니다.
  3. Continue to generation으로 디자인 시스템을 생성합니다.
  4. 초기 화면에서 방금 만든 디자인 시스템을 선택하고 PPT 주제를 요청합니다.
  5. Claude가 묻는 질문에 답하고 Continue를 누릅니다.
  6. Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 다운로드합니다.
  7. 받은 PPTX를 열어 폰트와 레이아웃을 확인합니다.
  8. 작업을 마친 뒤 작업 내용을 스킬로 만들어 달라고 요청해 다음에도 불러 씁니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 색 역할, 글씨 크기, 장당 글자 수를 수치로 적습니다.
  • 유니버셜 폰트는 어디서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양이 같지만 편집이 안 됩니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • 예전 방식: 5월 영상에서는 Create 후 회사 이름·설명을 적고 Generate를 눌렀고, PPT는 Slide deck 프로젝트로 만들었습니다.
  • Claude 디자인은 베타이며 Pro 이상 구독이 필요합니다.

12. Claude 디자인으로 영상용 애니메이션 만들기

영상의 말과 맞는 16:9 모션 그래픽을 Claude 디자인으로 만들어 편집 프로그램의 B-roll로 얹는 작업 흐름입니다. 영상 제작자가 정기적으로 영상에 애니메이션을 넣을 때 시간을 줄여 줍니다.

  1. 카메라와 화면을 녹화하고 녹화본에서 MP3를 추출합니다.
  2. MP3를 ChatGPT에 올려 SRT 트랜스크립트를 만들어 달라고 요청해 타임스탬프가 있는 자막을 받습니다.
  3. claude.ai/design을 열고 SRT 파일과 애니메이션 프롬프트를 붙여 넣습니다.
  4. 로고와 인터페이스 스크린샷을 첨부하고 모델 설정을 높게(extra 또는 max) 둡니다.
  5. 엔터를 눌러 생성을 기다리고, 멈춘 듯하면 계속하라고 입력합니다.
  6. 완성된 영상을 내레이션과 함께 보며 수정 사항을 요청합니다.
  7. 편집 프로그램에 B-roll 층으로 넣어 필요한 부분만 골라 씁니다.
예시
첨부한 SRT 자막의 내용에 맞춰 16:9 그래픽 애니메이션을 만들어 줘. 움직임은 많게, 글자는 최소로 해 줘.
  • 기본값은 글자가 많게 나오므로 움직임 위주, 글자 최소로 요청합니다.
  • 생성에는 영상 길이에 따라 30분~2시간이 걸립니다.
  • 진행이 멈췄는데 알려 주지 않는 경우가 있어 계속하라고 지시해야 합니다.
  • 높은 사고 수준 설정이 중간 수준보다 결과가 훨씬 좋았다고 합니다.
