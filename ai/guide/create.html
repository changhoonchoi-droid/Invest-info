문서·슬라이드·디자인 만들기

이 분야에서는 Claude 대화 안에서 슬라이드·문서·디자인을 바로 만들고, Word·Excel·PowerPoint 안에서 Claude로 초안을 다듬거나 표와 발표 자료를 이어 만들 수 있습니다. Adobe Acrobat의 PDF 스페이스처럼 자료를 모아 발표 자료로 바꾸는 도구도 함께 다룹니다. 처음이라면 '대화에서 슬라이드·문서 만들기'와 '코멘트로 고치기'부터 보고, 이어서 Office 연동과 Claude 디자인 순서로 넘어가면 됩니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 15개 기반 · 2026-10-27 갱신

최근 바뀐 점

  • 10월 7일 업데이트로 채팅과 Cowork가 하나의 Claude로 합쳐져 모드를 고를 필요가 없고, 작업이 클라우드에서 돌아 노트북을 닫아도 계속되며 휴대폰으로 진행 상황을 볼 수 있습니다.
  • 이제 어떤 대화에서든 /slides, /docs, /designs로 지금까지 나눈 대화 내용을 바탕으로 결과물을 만들 수 있고, 모든 유료 요금제에서 쓸 수 있습니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집하고, 코멘트에서 Claude를 멘션해 수정을 맡길 수 있습니다.
  • Adobe Acrobat의 PDF 스페이스에 파일·웹 링크·텍스트를 최대 100개까지 넣고 프레젠테이션 초안을 만들어 PPTX로 내려받을 수 있습니다.

1. 대화에서 슬라이드·문서 바로 만들기

Claude와 나눈 대화 내용을 바탕으로 발표 슬라이드, 문서, 디자인을 대화를 벗어나지 않고 만드는 기능입니다. 보고서 내용을 정리한 뒤 바로 발표 자료나 문서로 바꾸고 싶을 때 씁니다.

  1. Opus 5.5를 고르고, 보고서 등 만들 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 말로 설명해 Claude가 형식을 고르게 합니다.
  3. 형식을 이미 정했다면 /slides(슬라이드), /docs(문서), /designs(디자인) 중 하나를 입력합니다.
  4. 결과물이 나오면 모델을 Sonnet 5.5로 바꿉니다.
  5. 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경처럼 필요한 수정을 하나씩 요청해 반복합니다.
  • 방향을 잡을 때는 Opus 5.5, 빠른 수정을 반복할 때는 Sonnet 5.5를 쓰라고 권합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • 예전 방식: 9월 베타 공개 당시에는 채팅과 Cowork 중 모드를 골라야 했지만, 10월 업데이트로 하나의 Claude로 합쳐졌고 기존 Cowork 작업도 그대로 남아 있습니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 휴대폰 음성 메모로 하고 싶은 말을 녹음하고 그 받아쓰기 글을 Claude에게 보내 슬라이드로 만드는 방법입니다. 서식보다 내용에 시간을 쓰고 싶을 때 좋습니다.

  1. 휴대폰 음성 메모 앱을 켜고, 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude 대화창에 붙여 넣어 보냅니다.
  4. 아래 예시처럼 내 말을 그대로 살려 슬라이드로 만들어 달라고 요청합니다.
  5. 결과에서 오타나 짧은 문구 같은 작은 수정은 직접 고칩니다.
  6. 구성 변경처럼 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있으면 폰트나 템플릿을 따로 찾지 않아도 됩니다.

3. 코멘트로 결과물 일부만 고치기

만들어진 슬라이드·문서·디자인의 특정 부분에 코멘트를 달거나 문단을 선택해, 그 부분만 Claude가 고치게 하는 방법입니다. 전체를 다시 만들지 않고 원하는 곳만 손볼 때 씁니다.

  1. Claude로 만든 슬라이드·문서·디자인을 엽니다.
  2. 간단한 부분은 화면에서 직접 고칩니다.
  3. 바꾸고 싶은 문단을 선택하고 무엇을 어떻게 바꿀지 말하면 그 부분만 수정됩니다.
  4. 결과물의 원하는 위치에 코멘트를 달아 수정 내용을 적고 Claude에게 보냅니다.
  5. Claude Docs에서 팀원과 함께 편집 중이라면 코멘트에서 Claude를 멘션해 수정을 요청합니다.
  • 작은 수정은 직접, 큰 수정은 코멘트로 맡기면 빠릅니다.
  • Claude Docs는 팀원과 Claude가 같은 문서를 동시에 편집할 수 있습니다.

4. 브리프 하나로 여러 결과물 만들기

출시 브리프나 자주 묻는 질문 모음 같은 자료 하나로 발표 자료, 소셜 이미지 세트, 한 장짜리 안내문을 한 대화 안에서 만드는 방법입니다. 같은 내용을 여러 형태로 내보내야 할 때 씁니다.

  1. 출시 브리프, 기존 메모, 고객 질문 모음 등 기준이 될 자료를 Claude 대화에 붙여 넣거나 올립니다.
  2. /slides로 발표 자료를 먼저 만들어 달라고 요청합니다.
  3. 같은 대화에서 /designs로 소셜 이미지 세트를 요청합니다.
  4. 이어서 /docs로 현장용 한 장 요약 문서나 고객 안내문을 요청합니다.
  5. 각 결과물에서 고칠 부분에 코멘트를 달아 Claude에게 보냅니다.
  6. 수치와 사실관계는 원래 자료와 대조해 직접 확인한 뒤 공유합니다.
  • 자주 받는 고객 질문을 모아 두면 Claude가 고객에게 건넬 한 장짜리 안내문(팩트 시트)으로 정리해 줍니다.
  • 여러 자료에서 주제를 찾는 일은 AI가 잘하지만, 최종 판단과 검토는 사람이 맡아야 합니다.

5. Acrobat PDF 스페이스로 PPT 만들기

Adobe Acrobat의 AI 기반 PDF 스페이스에 보고서·기사 링크를 넣고 핵심을 요약한 뒤 프레젠테이션 초안까지 만드는 방법입니다. 요약 속 숫자를 누르면 원문 근거를 바로 볼 수 있어, 자료가 많은 발표 준비에 좋습니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적, 청중, 원하는 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기의 프레젠테이션을 선택하거나 채팅창에 프레젠테이션 생성을 요청합니다.
  7. 대상자·톤·길이·템플릿을 고르고 프레젠테이션 생성을 누릅니다.
  8. 편집 화면에서 글자와 디자인을 고친 뒤 다운로드로 저장합니다.
예시
임원 보고용 발표를 준비하고 있어. 이 보고서와 기사들에서 가장 중요한 변화 3가지와 핵심 수치 5개를 정리해 줘. 근거가 없는 내용은 '확인 필요'로 표시해 줘.
  • 파일·이미지·웹 링크·텍스트를 확장자와 관계없이 최대 100개까지 넣을 수 있습니다.
  • 생성된 내용과 수치는 반드시 원문과 비교해 확인합니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF입니다. 회사 PPT로 이어서 고치려면 PPTX를 고르세요.
  • 생성 후 예상 질문과 답변도 요청하면 발표 준비까지 할 수 있습니다.

6. Word에서 Claude로 초안 다듬기

Claude for Word는 Word 오른쪽 패널에서 문서를 읽고 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기, 분량 줄이기, 교정까지 실제로 편집합니다. 모든 수정이 검토 카드와 변경 내용 추적으로 남아, 하나씩 수락하거나 거절할 수 있습니다.

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치하고, Word 오른쪽의 Claude 패널을 엽니다.
  2. Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?처럼 요청해 댓글을 검토자별로 정리합니다.
  3. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고, 확인창에서 Allow once를 누릅니다.
  4. Box에 있는 기준 문서와 대조가 필요하면 문서 이름을 알려 주고 수치·주장을 비교해 틀린 곳을 고치게 합니다.
  5. 서식은 원하는 최종 상태를 말하고 Don't change anything else.를 덧붙여 정리합니다.
  6. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인합니다.
  7. 분량은 지킬 부분(인용문, 날짜)을 함께 알려 주며 줄이게 하고, 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬로 오탈자·문법을 교정하고, 마지막에 변경 사항을 모두 수락하게 합니다.
예시
We need to get this under 1,000 words, but don't cut any more than you need to.
  • Word 웹, Windows, Mac에서 쓸 수 있고 Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남아 팀이 변경 내용을 볼 수 있습니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.

7. Excel·PPT를 한 대화로 잇기

Claude for Excel과 PowerPoint는 열려 있는 두 파일을 하나의 대화에서 다뤄, Excel의 실시간 셀 값을 읽고 분석한 결과를 슬라이드에 바로 반영합니다. 탭을 오가며 데이터를 다시 설명할 필요가 없어 숫자 분석과 보고 자료를 함께 만들 때 좋습니다.

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치합니다.
  2. 작업할 Excel 파일과 PowerPoint 파일을 둘 다 엽니다.
  3. Claude 패널에서 데이터 수집, Excel 표 작성, 슬라이드 반영, 요약문 작성을 한 번의 프롬프트로 요청합니다.
  4. Excel에 만들어진 표와 슬라이드에 들어간 수치가 맞는지 확인합니다.
  5. 자주 하는 작업이면 이 흐름을 Skills로 저장해 다음부터 한 번에 다시 실행합니다.
예시
비교 기업들의 재무 자료를 가져와 Excel에 트레이딩 컴프스 표를 만들고, 밸류에이션 요약을 열려 있는 피치덱에 넣은 뒤 요약문도 써 줘.
  • 유료 플랜 사용자라면 Mac·Windows에서 모두 쓸 수 있습니다.
  • 회사에서 Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry를 쓰고 있다면 그 경로로도 제공됩니다.

8. Claude 디자인으로 시안부터 구현까지

앱이나 웹 화면을 코드로 바로 만들기 전에 Claude 디자인으로 여러 시안을 탐색하고, 댓글 피드백과 클릭형 프로토타입을 거쳐 구현까지 이어 가는 방법입니다. 작은 사이드 프로젝트의 화면 하나라도 이렇게 거치면 결과가 좋아집니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 직접 눌러 보고 만족하면 Claude에게 구현(build)을 지시합니다.
  • Claude가 작업하는 동안 기다리지 말고 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • Claude Design은 문서보다 프로토타입을 먼저 만들어 보는 방식에 맞춰 만들어졌습니다. 말로 설명하기보다 시안을 보고 고르세요.
