문서·슬라이드·디자인 만들기

이 분야에서는 Claude, 제미나이, 어도비, 젠스파크 같은 AI로 문서, 엑셀 분석, 슬라이드, 디자인, 이미지, 간단한 앱까지 말로 요청해 만들 수 있습니다. 먼저 Claude 아티팩트와 대화형 문서·슬라이드로 감을 잡고, 그다음 Excel·Word·PowerPoint 연동과 제미나이·젠스파크·PDF 스페이스 같은 슬라이드 도구를 써 보세요. 마지막으로 디자인 시스템을 만들어 같은 톤의 결과물을 반복해서 뽑는 방법을 익히면 됩니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 74개 기반 · 2026-11-14 갱신

최근 바뀐 점

  • Claude 아티팩트에 시트(Sheets)와 화이트보드(Whiteboard)가 추가되고 대시보드는 데이터(Data)로 이름이 바뀌었으며, 모든 유료 플랜에서 쓸 수 있습니다.
  • 새 모델 Fable 5.2가 유료 플랜 Claude에 나와 모델 전환 메뉴에서 고를 수 있고, 지식 노동 과제 완료율이 Opus 5.5의 21%에서 41%로 올랐다고 소개됩니다.
  • 아티팩트를 팀원과 함께 편집할 수 있고, 트래커에서는 contributor 역할로 입력과 체크만 허용할 수 있습니다.
  • Claude Design에 자막(SRT)과 프롬프트를 넣어 영상용 16:9 애니메이션을 만드는 활용법이 공개되었습니다.
  • Claude에 Artlist를 커넥터로 연결해 채팅 안에서 제품 이미지를 만들고 고치는 방법이 소개되었습니다.

1. 아티팩트로 계산기·작은 앱 만들기

아티팩트는 Claude 채팅 옆에 바로 쓸 수 있는 결과물을 띄워 주는 기능입니다. 코딩을 몰라도 계산기, 퀴즈, 가계부 같은 작은 도구를 말로 설명해 만들 수 있습니다. 업무용 간단 도구나 인포그래픽이 필요할 때 씁니다.

  1. Claude 채팅창에 만들고 싶은 도구를 한 줄로 요청합니다.
  2. 엔터를 치면 작동하는 결과물이 채팅 옆에 아티팩트로 나타납니다.
  3. 우측 패널에서 만들어진 앱을 직접 눌러 써 봅니다.
  4. 고치고 싶은 점을 채팅으로 다시 요청합니다.
  5. 새로 시작하려면 새 아티팩트를 누르고 처음부터 시작하기를 선택한 뒤 만들 앱을 설명합니다.
  6. 공유하려면 게시해 링크로 받습니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.
  • 예전 방식: 아티팩트의 대시보드는 지금 데이터(Data)라는 이름으로 바뀌었습니다.

2. 화이트보드로 아이디어·흐름 펼치기

Claude 아티팩트의 화이트보드는 아이디어를 한 화면에 시각적으로 배치해 주는 기능입니다. 사업 아이디어 공유, 워크플로나 행사 흐름 정리 같은 구상 단계에 잘 맞습니다. 모든 유료 플랜에서 쓸 수 있습니다.

  1. Artifacts로 이동합니다.
  2. Whiteboard를 클릭합니다.
  3. Ask Claude를 눌러 만들고 싶은 내용을 설명합니다.
  4. 배치된 화이트보드를 확인합니다.
  5. 스타일 변경, 차트 추가, 예산 같은 내용 수정을 Claude에게 요청합니다.
  • 같은 시기에 추가된 시트(Sheets)는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵다는 평가가 있으니, 간단한 표 용도로 생각하세요.

3. 대화에서 문서·슬라이드·디자인 만들기

Claude에서는 같은 대화 안에서 문서(Docs), 슬라이드(Slides), 디자인(Designs)을 이어서 만들 수 있습니다. 내용 정리는 대화로 하고, 결과물은 직접 고치거나 댓글로 Claude에게 수정을 맡깁니다. 유료 요금제에서 쓸 수 있습니다.

  1. 먼저 보고서 내용 등을 대화로 정리합니다. 영상에서는 이 단계에 Opus 5.5를 권했습니다.
  2. 원하는 결과물을 설명하거나, 형식을 안다면 /slides, /docs, /designs를 입력합니다.
  3. Docs가 열리면 Claude가 묻는 질문에 모두 답합니다.
  4. 초안이 나오면 직접 고치거나, 고칠 부분을 드래그해 댓글로 지시를 남깁니다.
  5. 문구 다듬기, 차트 교체, 색상 변경 같은 반복 수정은 Sonnet 5.5로 바꿔 진행합니다.
  6. 우측 상단 공유로 팀원을 초대하거나 내보내기로 파일을 저장합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님께 보고할 런칭 브리프를 문서로 만들어 줘
  • 내보내기 형식: Docs는 Word, PDF, 마크다운, 노션, 구글 문서이고 Slides는 PDF, 파워포인트, PNG, 구글 슬라이드입니다.
  • Slides는 우측 하단 캔버스로 전체를 한눈에 보고, 우측 상단 재생 버튼으로 바로 발표할 수 있습니다.
  • Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수도 있습니다.
  • 질문 내용은 사용자마다 다르게 나옵니다.

4. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성으로 먼저 녹음하고 그 글을 Claude에게 넘겨 슬라이드로 만드는 방법입니다. 서식보다 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청하는 프롬프트를 입력합니다.
  5. 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

5. 아티팩트를 팀과 공유해 함께 편집하기

Claude에서 만든 문서, 슬라이드, 디자인, 대시보드를 팀원과 함께 편집할 수 있습니다. 팀원별 접근 권한을 정하고 활동 중인 사람과 댓글을 실시간으로 볼 수 있습니다. 체크리스트형 트래커를 만들어 팀이 같이 쓰기에도 좋습니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  6. 트래커는 문서를 바탕으로 우선순위별 체크박스가 있는 형태로 요청하고, 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 달라고 합니다.
  7. 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시
지연되거나 기한이 지난 작업에 색상 상태 라벨을 추가해 줘
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.
  • Artifacts 탭에서 템플릿으로 시작하고, 내가 만든 것과 공유받은 것을 모아 볼 수 있습니다.

6. Excel에서 Claude로 분석·피벗 만들기

Claude in Excel은 스프레드시트 사이드바에서 통합 문서 전체를 이해하고 질문에 답하는 AI입니다. 오류 추적, 수식 설명, 피벗 테이블과 차트 작성까지 맡길 수 있습니다. Pro, Max, Team, Enterprise 플랜에서 베타 리서치 프리뷰로 제공됩니다.

  1. Excel에서 통합 문서를 엽니다.
  2. Mac은 Control + Option + C, Windows는 Control + Alt + C를 눌러 사이드바를 엽니다.
  3. 목표를 구체적으로 적어 질문합니다.
  4. Claude가 보여 주는 계산 과정을 읽고 확인합니다.
  5. 응답의 인용 상자를 눌러 근거가 된 셀로 이동해 검증합니다.
  6. 피벗 테이블이 필요하면 지역·제품 등 기준을 적어 요청합니다.
  7. 차트는 피벗 테이블을 바탕으로 요청하고, 종류·제목 변경도 말로 시킵니다.
예시
Create a pivot table showing total revenue by region and product.
  • 오류는 Why is there an error in May?처럼 물으면 원인 셀까지 추적해 줍니다.
  • Excel과 PowerPoint를 함께 열어 두면 한 세션에서 이어 쓸 수 있고, 스킬(Skills)로 이 흐름을 저장해 다시 실행할 수 있습니다.
  • 민감하거나 규제 대상인 데이터는 조직의 데이터 처리 정책을 따르세요.

7. Word·PowerPoint 안에서 Claude로 다듬기

Claude for Word와 PowerPoint 애드인은 문서 패널 안에서 초안 작성부터 수정까지 맡아 줍니다. 모든 수정이 검토 카드와 추적 변경으로 나타나 직접 수락하거나 거절합니다. 작성한 문서와 덱을 팀 기준에 맞게 다듬을 때 씁니다.

  1. Word 오른쪽의 Claude 패널을 열고 열린 댓글을 검토자별로 요약해 달라고 요청합니다.
  2. 추적 변경을 켜고 모든 작업에 유지하라고 요청한 뒤, 확인창에서 Allow once를 누릅니다.
  3. 고쳐 쓸 문단을 선택하고 고객 눈높이로 바꾸는 등 요청한 뒤 카드별로 확인합니다.
  4. 분량 줄이기는 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  5. PowerPoint에서는 슬라이드 마스터·색상이 갖춰진 템플릿을 열고 슬라이드 수, 주제, 다룰 항목, 어조를 적어 덱을 요청합니다.
  6. 고칠 슬라이드나 텍스트 상자를 선택하고 요청하면 그 부분만 수정됩니다.
  7. + 버튼으로 보고서나 데이터 파일을 올려 슬라이드의 근거 자료로 씁니다.
예시
We need to get this under 1,000 words, but don't cut any more than you need to. Keep the quotes and dates.
  • 변경 수락은 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남습니다.
  • 서식은 원하는 최종 상태를 말하고 Don't change anything else.를 덧붙이면 다른 곳이 안 바뀝니다.
  • 복잡한 템플릿은 브랜드 지침과 맞는지 직접 확인하세요.

8. 제미나이 캔버스로 PPT 만들어 내보내기

제미나이의 캔버스로 슬라이드를 만들고 구글 슬라이드로 내보내 PPT로 저장하는 방법입니다. 한 번에 전부 만들기보다 1~2장씩 나누어 만들면 퀄리티가 올라갑니다. 무료 버전으로도 가능하지만 품질과 속도에 차이가 있습니다.

  1. 채팅창에서 도구를 눌러 캔버스를 선택합니다.
  2. 모델을 사고 또는 프로로 바꿉니다.
  3. +에서 파일 업로드로 자료를 첨부하거나 내용을 입력합니다.
  4. 대상과 톤, 슬라이드 총 장수를 적어 PPT 슬라이드 형식으로 요청합니다.
  5. 슬라이드로 내보내기를 누르고 완료되면 슬라이드 열기를 누릅니다.
  6. 구글 슬라이드에서 파일 → 다운로드 → pptx를 선택합니다.
예시
첨부한 자료로 신입사원 교육용 슬라이드 10장을 만들어 줘. 모든 슬라이드 좌상단에 제목을 넣고 핵심 내용만 추려서 써 줘.
  • 처음에는 표지와 2번 슬라이드만 요청하고, 마음에 들면 같은 컨셉으로 이어 갑니다.
  • 색상은 이름 대신 정확한 컬러 코드로 지정합니다. 수정 요청 전에는 미리 내보내 백업하세요.
  • 분업을 권합니다: 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리합니다.
  • PPT에서 홈 → 바꾸기 → 글꼴 바꾸기로 폰트를 한 번에 바꿀 수 있습니다.
  • 예전 방식: 캔버스에서 PPT 생성이 막히는 오류가 있을 때는 구글 슬라이드 오른쪽 위 제미나이로 한 장씩 만드는 우회 방법을 썼습니다.

9. PDF 스페이스로 자료 기반 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 보고서와 기사 링크를 넣고 요약한 뒤 프레젠테이션 초안까지 만드는 방법입니다. 요약 속 숫자를 누르면 원문 근거가 표시되어 확인하기 쉽고, 문서 기반이라 거짓 정보가 들어갈 위험이 줄어듭니다. 유료 구독이 필요합니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 자료를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적과 청중, 원하는 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에서 표시된 근거를 확인합니다.
  6. 왼쪽 만들기의 프레젠테이션을 선택하고 대상자·톤·길이·템플릿을 골라 프레젠테이션 생성을 누릅니다.
  7. 편집 화면에서 글자와 디자인을 수정한 뒤 다운로드로 저장합니다.
예시
임원 보고용이야. 이 보고서에서 가장 크게 달라진 수치 5개를 근거와 함께 요약하고, 근거가 없는 내용은 확인 필요로 표시해 줘.
  • 생성된 내용과 수치는 원문과 비교해 확인합니다.
  • 자료는 최대 100개 파일까지 넣을 수 있고, 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 초보자는 PDF 스페이스 만들기 후 프레젠테이션 만들기에서 청중·목적·어조만 고르면 됩니다.

10. 젠스파크로 수정 가능한 PPT 만들기

젠스파크의 AI 슬라이드는 프롬프트 하나로 조사부터 슬라이드 제작까지 해 주는 도구입니다. 첫 프롬프트에 주제·목적·대상·분량·필수 조건을 담고 수정 가능한 형태로 요청하는 것이 핵심입니다. 가입하면 매일 100 크레딧이 주어집니다.

  1. 젠스파크에서 AI 슬라이드로 들어갑니다.
  2. 주제·목적·대상·분량·필수 조건이 담긴 프롬프트를 입력합니다.
  3. 프로페셔널을 선택하고 스탠더드 또는 울트라를 고릅니다.
  4. 가이드 모드를 켜고 전송합니다.
  5. 가이드의 질문에 답하고 전략·구성·디자인 단계를 승인합니다.
  6. 샘플 두 장을 확인한 뒤 나머지 전체 제작을 승인합니다.
  7. 보기 및 내보내기에서 내보내기→PPT로 받습니다.
예시
신입사원 교육용 PPT를 8장으로 만들어 줘. 파워포인트에서 수정할 예정이니 모든 텍스트는 수정 가능한 텍스트 박스로, 차트는 수정 가능한 차트로 만들어 줘.
  • 크리에이티브는 통이미지로 나와 수정이 안 되므로 프로페셔널을 권합니다.
  • 처음엔 한두 장만 만들어 스타일을 확정한 뒤 확장하면 크레딧이 절약됩니다.
  • 작은 수정은 크레딧이 들기 때문에 파워포인트에서 직접 합니다.
  • 근거가 중요하면 딥 리서치로 출처 있는 보고서를 먼저 만든 뒤 슬라이드로 변환해 달라고 요청합니다.
  • 기존 PPT 디자인만 바꾸려면 파일을 올리고 16:9, 슬라이드당 핵심 메시지 하나를 조건으로 적습니다.

11. 제품 사진으로 판매용 이미지 만들기

상품 사진 한 장으로 대표 이미지, 착용샷, 배너, SNS 광고 이미지를 만드는 방법입니다. Claude에 Artlist 커넥터를 연결하거나 Genspark의 디자인에서 광고 시안을 만든 뒤 상세페이지로 이어 갑니다. 쇼핑몰이나 SNS 홍보 소재가 필요할 때 씁니다.

  1. Claude에서는 Artlist 도구로 쓸 수 있는 이미지 모델을 먼저 확인해 달라고 요청합니다.
  2. 생성 없이 체크만 해 달라고 하며 사진을 첨부하고, 업로드 위젯으로 올립니다.
  3. 모델, 비율(정사각형), 해상도(2K) 등을 구체적으로 적어 대표 이미지를 요청합니다.
  4. 착용샷·디테일·배너를 추가로 요청합니다.
  5. 유지할 것과 바꿀 것을 나누어 수정을 요청합니다.
  6. 결과를 다운로드로 저장합니다.
  7. Genspark에서는 디자인에서 +로 광고 레퍼런스와 제품 사진을 첨부하고, 되묻는 질문에 답해 시안을 만듭니다.
  8. 시안을 기준으로 디자인 시스템, 상세페이지, 랜딩페이지를 이어서 요청합니다.
예시
바지를 청바지로 바꿔 줘. 신발 디자인과 로고는 그대로 유지해 줘.
  • 생성 전에는 체크만 시키면 Artlist 크레딧을 아낄 수 있고, 재생성하면 크레딧이 추가로 소진됩니다.
  • AI 이미지는 로고·형태·한글 문구가 달라질 수 있으니 반드시 확인합니다.
  • Genspark에서 잘 모르는 질문은 비워 두면 AI가 제안해 진행합니다.
  • 공유 버튼으로 이메일을 편집자로 초대해 함께 수정할 수 있습니다.

12. 디자인 시스템으로 같은 톤의 PPT 만들기

디자인 시스템은 색, 폰트, 글씨 크기, 여백 같은 브랜드 규칙 모음입니다. 먼저 Claude Design에 만들어 두면 이후 슬라이드와 프로토타입이 같은 톤으로 나오고 PPTX로 내보낼 수 있습니다. 결과가 AI스럽게 들쭉날쭉한 문제를 줄일 때 씁니다.

  1. 클로드 디자인에 접속해 디자인 시스템 탭에서 Create new design system의 Create를 누릅니다.
  2. getdesign 사이트에서 원하는 기업의 DESIGN.md를 열어 코드를 복사해 입력창에 붙여 넣습니다.
  3. 업로드한 폰트로 일괄 적용하고 그래프 컴포넌트를 포함하라고 적은 뒤 폰트 파일을 올립니다.
  4. Continue to generation으로 디자인 시스템을 생성합니다.
  5. 초기 화면에서 디자인 시스템을 방금 만든 것으로 설정하고 슬라이드를 요청합니다.
  6. Claude가 던지는 주제·대상·디자인 질문에 답하고 Continue를 누릅니다.
  7. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트를 선택해 다운로드합니다.
  8. 받은 PPTX를 열어 폰트와 레이아웃을 확인합니다.
  9. 같은 작업이 끝나면 '지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘'라고 요청해 다음에 불러 씁니다.
예시
최신 AI 트렌드 리서치 주제로 PT 만들어 줘
  • '깔끔하게', '세련되게' 같은 표현은 규칙이 아닙니다. 색 3가지, 본문·제목 글씨 크기, 장당 글자 수처럼 수치로 적습니다.
  • 유니버셜 폰트는 어디서나 열리지만 폰트가 바뀔 수 있고, 스크린샷 베이스 PPTX는 모양은 같지만 편집이 안 됩니다.
  • 레이아웃이 무너지는 주된 원인은 폰트 불일치입니다.
  • 예전 방식: Claude Design 사용량이 별도로 관리되어 한도가 빡빡했으나, 5월 말 업데이트로 Claude Code 사용량과 통합되었습니다.
  • 시안에서 구현까지 가려면 Artifacts 탭에서 시안을 만들고, 댓글로 피드백한 뒤 클릭형 프로토타입을 거쳐 구현을 지시합니다.
