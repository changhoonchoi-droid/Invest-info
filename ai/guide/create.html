문서·슬라이드·디자인 만들기

Claude의 문서·슬라이드·디자인 기능부터 PPT 자동화, 이미지·로고 제작, 홈페이지 만들기까지 한 분야에서 다룹니다. 먼저 Claude의 Artifacts·Docs·Slides·Design처럼 채팅 안에서 바로 쓰는 기능으로 익숙해진 뒤, 디자인 시스템으로 톤을 맞추는 방법과 엑셀·워드·PowerPoint·제미나이·젠스파크 같은 다른 도구, 이미지·홈페이지·광고 소재 제작으로 넓혀 가세요. 결과물은 사실과 숫자를 원문과 대조해 확인하는 습관을 함께 들이면 좋습니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 91개 기반 · 2026-11-27 갱신

최근 바뀐 점

  • Claude Artifacts에 시트(Sheets)와 화이트보드(Whiteboard)가 추가되고 대시보드는 데이터(Data)로 이름이 바뀌었으며, 모든 유료 플랜에서 쓸 수 있습니다.
  • Artifacts를 팀원과 공유해 보기·댓글·수정 권한을 나누어 함께 편집할 수 있게 되었고, 트래커에서는 contributor 역할로 입력과 체크만 허용할 수 있습니다.
  • Fable 5.2가 유료 플랜 Claude에 출시되어 모델 전환 메뉴에서 선택할 수 있으며, 슬라이드 덱 같은 결과물 품질이 올랐다고 소개됩니다.
  • Claude Design에서 영상 자막(SRT)을 넣어 말과 맞는 16:9 애니메이션을 만들고 편집 프로그램에 B-roll로 얹는 활용법이 소개되었습니다.

1. Claude 아티팩트로 계산기·앱 만들기

아티팩트는 채팅 옆 패널에 바로 작동하는 계산기, 퀴즈, 간단한 앱을 만들어 주는 기능입니다. 코딩을 몰라도 말로 설명하면 되고, 링크로 공유할 수도 있습니다. 업무용 소도구나 강의 자료용 위젯이 필요할 때 씁니다.

  1. Claude 채팅창에 만들고 싶은 도구를 한 줄로 요청합니다.
  2. 엔터를 치면 채팅 옆에 작동하는 결과가 아티팩트로 나타납니다.
  3. 우측 패널에서 만들어진 앱을 직접 사용해 봅니다.
  4. 고칠 부분이 있으면 채팅으로 수정을 요청합니다.
  5. 공유하려면 게시해 링크로 받습니다.
예시
내 1일 칼로리 계산기 만들어 줘
  • 퀴즈, 점수 측정기, 블로그 인포그래픽, 썸네일 여러 버전 비교에도 쓸 수 있습니다.
  • 새 아티팩트 → 처음부터 시작하기로도 시작할 수 있습니다.

2. Claude 화이트보드로 아이디어 펼치기

Artifacts의 화이트보드는 사업 아이디어, 워크플로, 행사 계획 같은 구상을 시각적으로 펼쳐 주는 기능입니다. 정리되기 전 단계의 생각을 한눈에 보며 다듬을 때 유용합니다.

  1. Artifacts로 이동합니다.
  2. Whiteboard를 클릭합니다.
  3. Ask Claude를 눌러 만들고 싶은 내용을 설명합니다.
  4. 배치된 화이트보드를 확인합니다.
  5. 스타일 변경, 차트 추가, 예산 같은 내용 수정을 요청합니다.
  • 화이트보드·시트·데이터는 모든 유료 플랜에서 쓸 수 있습니다.
  • 시트에는 피벗 테이블과 매크로가 없어 구글 시트를 대체하기는 어렵다는 평가가 있습니다.

3. 대화에서 문서·슬라이드 바로 만들기

Claude에서는 어떤 대화에서든 문서(Docs), 슬라이드(Slides), 디자인(Designs)을 만들 수 있고, 앞서 나눈 대화 내용이 그대로 재료가 됩니다. 직접 고치거나 드래그한 부분에 댓글을 달아 Claude에게 수정을 시킵니다.

  1. Opus 5.5로 보고서 등 내용을 먼저 대화로 정리합니다. 자료나 사진이 있으면 첨부합니다.
  2. 원하는 결과물을 설명해 Claude가 형식을 고르게 하거나, 형식을 안다면 /slides, /docs, /designs를 입력합니다.
  3. Docs가 열리면 Claude가 던지는 질문에 답해 초안을 받습니다.
  4. 고칠 부분을 드래그한 뒤 댓글을 눌러 지시를 입력합니다.
  5. Sonnet 5.5로 바꿔 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 반복합니다.
  6. 우측 상단 공유로 팀원을 초대하거나 내보내기로 파일을 저장합니다.
예시
첨부한 신메뉴 사진을 바탕으로 사장님 보고용 런칭 브리프 문서를 만들어 줘
  • Docs 내보내기는 Word, PDF, 마크다운, 노션, 구글 문서를 지원합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • 예전 방식: 채팅과 Cowork를 따로 골랐지만, 지금은 하나의 Claude로 합쳐져 모드를 고를 필요가 없습니다.

4. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 먼저 녹음해 두고 받아 적은 글을 Claude에게 넘겨 발표 자료로 만드는 방법입니다. 서식보다 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude에 보냅니다.
  4. 슬라이드 제작을 요청합니다.
  5. 작은 수정은 직접 고치고, 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트·템플릿을 따로 찾지 않아도 됩니다.

5. 아티팩트를 팀과 공유해 함께 편집하기

Claude에서 만든 문서, 슬라이드, 디자인, 트래커를 팀원과 공유해 함께 고칠 수 있습니다. 팀원마다 보기·댓글·수정 권한을 정하고, 댓글이 달리면 Claude에게 수정을 시킵니다.

  1. 채팅에서 필요한 문서를 Claude에게 요청해 만듭니다.
  2. 필요하면 Slack, Google Drive 같은 커넥터를 추가해 빈 부분을 채우게 합니다.
  3. 문서가 준비되면 조직의 팀원을 추가합니다.
  4. 팀원별로 보기, 댓글, 수정 등 접근 수준을 고릅니다.
  5. 댓글이 달리면 Claude에게 업데이트를 요청합니다.
  6. 트래커는 우선순위별 체크박스 목록을 요청하고, 입력·체크만 필요한 사람은 contributor로 지정합니다.
예시
이 문서를 바탕으로 우선순위별 체크박스가 있는 트래커를 만들어 줘. 체크 표시가 저장되어 모두에게 같은 목록이 보이게 해 줘.
  • 추가한 사람은 기본적으로 댓글 작성자(commenter)가 됩니다.
  • 스타일 수정을 요청해도 실제 내용과 상태는 그대로 유지됩니다.
  • 아티팩트 링크를 공유해 별도 웹페이지에서 보기·편집하게 할 수도 있습니다.

6. 디자인 시스템으로 같은 톤 PPT 만들기

AI가 만든 PPT가 들쭉날쭉한 이유는 기준이 없기 때문입니다. 색·글꼴·크기 같은 규칙을 디자인 시스템으로 정해 두면 매번 같은 톤의 PPT를 얻을 수 있고, 스킬로 저장해 반복할 수 있습니다.

  1. 클로드 디자인(claude.ai/design)에 접속해 디자인 시스템 탭에서 Create를 누릅니다.
  2. 회사 이름과 설명을 적고, 기존 자료가 있으면 깃허브 주소나 피그마 파일을 넣습니다. 또는 DESIGN.md 코드를 복사해 붙여 넣습니다.
  3. 쓸 폰트 파일을 업로드하고 Continue to generation을 눌러 약 5분간 기다립니다.
  4. 초기 화면에서 새 프로젝트를 만들 때 방금 만든 디자인 시스템을 선택합니다.
  5. Claude가 묻는 주제·대상·디자인 질문에 답하고 Continue를 누릅니다.
  6. 우측 상단 Share → Export에서 파워포인트를 고르고 커스텀 폰트 옵션으로 다운로드합니다.
  7. Claude Code로 작업했다면 끝난 뒤 지금까지의 작업을 스킬로 만들어 달라고 요청해 다음에 불러 씁니다.
예시
지금까지 작업한 모든 대화 내용과 결과물로 스킬로 만들어 줘
  • '깔끔하게', '세련되게' 같은 추상적 표현은 규칙이 아닙니다. 색 역할, 글씨 크기, 장당 글자 수를 수치로 적습니다.
  • PPTX 내보내기에서 커스텀 폰트는 업로드한 폰트가 유지되고, 유니버셜 폰트는 어디서나 열리지만 폰트가 바뀔 수 있으며, 스크린샷 베이스는 모양은 같지만 편집이 안 됩니다.
  • 디자인 시스템 없이 쓰면 결과물이 'AI스럽다'는 평가가 있습니다.
  • 예전 방식: 클로드 디자인 사용량이 따로 관리됐지만, 2026년 5월 말 업데이트로 Claude Code 사용량과 통합되었습니다.

7. Claude 디자인으로 시안에서 구현까지

코드를 짜기 전에 짧게 디자인 시안을 탐색하면 결과가 더 좋아집니다. 시안 → 댓글 피드백 → 직접 수정 → 클릭형 프로토타입 → 구현 순서로 진행합니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 만족하면 Claude에게 구현(build)을 지시합니다. 또는 Share에서 Handoff to Claude Code 명령어를 복사해 Claude Code에 붙여 넣습니다.
예시
현재 앱을 살펴보고 앱에 맞는 온보딩 디자인 시안을 여러 개 만들어 줘
  • Claude가 작업하는 동안 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • Tweaks로 화면의 여러 변형을 비교해 고를 수 있습니다.
  • Pro·Max·Team·Enterprise 구독이 필요하고 무료 플랜은 쓸 수 없습니다.

8. Word·Excel·PowerPoint 안에서 Claude 쓰기

Claude를 Office 앱의 패널이나 애드인으로 열면 문서를 읽고 실제 편집까지 맡깁니다. 모든 수정은 검토 카드나 추적 변경으로 나타나 직접 수락·거절할 수 있습니다.

  1. Word는 오른쪽 Claude 패널, Excel은 Control + Alt + C(Mac은 Control + Option + C) 사이드바, PowerPoint는 Claude 애드인을 엽니다.
  2. Word에서는 Turn on Track Changes and keep it on for everything you do in this document.라고 요청해 변경 내용이 남게 합니다.
  3. 목표를 구체적으로 적어 요청합니다. Excel은 목표를 말해 질문하고, 응답의 인용 상자를 눌러 근거 셀로 이동해 검증합니다.
  4. PowerPoint는 템플릿을 연 상태에서 슬라이드 수, 주제, 다룰 항목, 어조를 적어 요청하고, 끝에 "필요하면 질문하라"고 덧붙입니다.
  5. 고칠 슬라이드나 텍스트 상자를 선택한 뒤 요청하면 선택한 부분만 수정됩니다.
  6. Excel에서는 피벗 테이블과 차트를 요청한 뒤 차트 종류·제목을 수정시킵니다.

9. 제미나이 캔버스로 PPT 만들어 내보내기

제미나이의 캔버스와 사고 모델로 슬라이드를 만들고 구글 슬라이드를 거쳐 PPT로 저장하는 흐름입니다. 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트와 정렬은 PPT에서 마무리하는 분업이 좋습니다.

  1. 채팅창에서 도구를 눌러 캔버스를 선택합니다.
  2. 모델을 사고 또는 프로로 바꿉니다.
  3. +에서 파일 업로드로 자료를 첨부하거나 내용을 입력합니다.
  4. 대상과 톤, 슬라이드 총 장수를 적어 PPT 슬라이드 형식으로 요청합니다.
  5. 슬라이드로 내보내기를 누르고 완료되면 슬라이드 열기를 누릅니다.
  6. 구글 슬라이드에서 파일 → 다운로드 → pptx를 선택합니다.
  7. PPT에서 홈 → 바꾸기 → 글꼴 바꾸기로 폰트를 한 번에 바꾸고 배치를 확인합니다.
예시
첨부한 자료로 임원 보고용 PPT 슬라이드를 만들어 줘. 슬라이드 총 8장, 톤은 차분하게, 모든 슬라이드 좌상단에 제목을 넣어 줘.
  • 한 번에 전부 만들기보다 1~2장씩 나눠 만들고, 수정 요청 전에 미리 슬라이드로 내보내 백업합니다.
  • 색상은 이름 대신 정확한 컬러 코드로 지정합니다.
  • 레퍼런스 이미지 방식은 통이미지로 나와 글자 수정이 안 될 수 있습니다.
  • 예전 방식: 캔버스가 'PPT를 만들 수 없다'는 오류를 내는 경우가 있어, 그때는 구글 슬라이드를 열어 오른쪽 위 제미나이로 한 장씩 만든 뒤 파일 → 다운로드로 내보냅니다.

10. 젠스파크로 수정 가능한 PPT 만들기

젠스파크 AI 슬라이드는 주제만 넣어도 조사·기획·제작까지 자동으로 진행합니다. 첫 프롬프트에 목적·대상·분량·조건을 담고 수정 가능한 형태로 내보내라고 지정하는 것이 핵심입니다.

  1. 젠스파크에서 AI 슬라이드로 들어갑니다.
  2. 주제·목적·대상·분량·필수 조건이 담긴 프롬프트를 입력합니다.
  3. 프로페셔널을 선택하고 스탠더드 또는 울트라를 고릅니다.
  4. 가이드 모드를 켜고 전송합니다.
  5. 가이드의 질문에 답하고 전략·구성·디자인 단계를 승인합니다.
  6. 샘플 두 장을 확인한 뒤 나머지 전체 제작을 승인합니다.
  7. 보기 및 내보내기에서 내보내기→PPT로 받습니다.
예시
신입 사원 교육용 PPT 8장을 만들어 줘. 파워포인트에서 수정할 예정이니 텍스트 박스와 차트를 모두 수정 가능하게 만들어 줘.
  • 크리에이티브는 통 이미지로 나와 수정이 안 되므로 프로페셔널을 권합니다.
  • 처음엔 한두 장만 만들어 스타일을 확정한 뒤 확장하면 크레딧이 절약됩니다.
  • 작은 수정은 크레딧이 들기 때문에 파워포인트에서 직접 합니다.
  • 딥리서치로 출처 있는 보고서를 먼저 만든 뒤 슬라이드로 변환하면 근거가 탄탄해집니다.
