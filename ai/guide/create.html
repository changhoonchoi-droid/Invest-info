문서·슬라이드·디자인 만들기

이 분야에서는 대화 내용, 음성 메모, 보고서 파일을 슬라이드·문서·디자인으로 바꾸는 방법을 다룹니다. Word·Excel·PowerPoint 파일을 AI로 다듬는 방법과 사진으로 홍보 영상을 만드는 방법도 함께 담았습니다. 처음이라면 Claude 대화에서 결과물을 만들고 코멘트로 고치는 기초 가이드부터 보세요. 그다음 Office 연동, 영상 만들기, 디자인 시안에서 프로토타입까지 가는 응용 가이드로 넘어가면 됩니다.

최근 바뀐 점

  • Artlist의 Kling 4.0은 사진을 최대 10장까지 넣어 최대 30초(1080 해상도) 영상 한 편을 약 1분 만에 만들고, 배경 음악과 목소리도 함께 생성합니다.
  • Adobe Acrobat의 PDF 스페이스는 넣은 자료를 바탕으로 발표 슬라이드를 만들어 주며, 결과를 Adobe Express에서 고친 뒤 PPTX·PDF·JPG·PNG로 내려받을 수 있습니다.

1. 대화에서 슬라이드·문서 바로 만들기

Claude와 나눈 대화 내용을 바탕으로 발표 슬라이드, 문서, 디자인 결과물을 대화창을 벗어나지 않고 만드는 기능입니다. 출시 브리프 하나로 발표 자료, 소셜 이미지 세트, 한 장짜리 요약 문서를 한꺼번에 만들어야 할 때 쓰면 좋습니다.

  1. 모델을 Opus 5.5로 고르고 보고서나 브리프 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 말로 설명해 Claude가 형식을 고르게 합니다.
  3. 만들 형식이 정해져 있으면 /slides, /docs, /designs 중 하나를 입력합니다.
  4. 초안이 나오면 모델을 Sonnet 5.5로 바꿉니다.
  5. 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 요청하며 반복합니다.
  6. 완성되면 팀에 공유하거나 내보내기(export)합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • 방향을 잡을 때는 Opus 5.5, 빠른 수정은 Sonnet 5.5로 나눠 쓰기를 권합니다.
  • 예전 방식: 채팅과 Cowork 중 모드를 골라야 했지만, 이제는 하나의 Claude로 합쳐져 고를 필요가 없고 기존 Cowork 작업도 그대로 남아 있습니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때 하고 싶은 말을 휴대폰에 녹음하고, 받아 적은 글을 Claude에게 보내 발표 자료로 만드는 방법입니다. 서식 작업을 줄이고 내용에 집중하고 싶을 때 좋습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude 대화창에 붙여 넣습니다.
  4. 아래 예시 프롬프트처럼 슬라이드 제작을 요청합니다.
  5. 결과에서 오타 같은 작은 부분은 직접 고칩니다.
  6. 구성 변경 같은 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트나 템플릿을 따로 찾지 않아도 됩니다.

3. 코멘트로 결과물 부분 수정하기

Claude가 만든 슬라이드·문서·디자인 전체를 다시 만들지 않고, 원하는 부분에 코멘트를 달거나 그 부분을 선택해 그곳만 고치게 하는 방법입니다. 결과물이 대체로 마음에 드는데 일부만 바꾸고 싶을 때 씁니다.

  1. 만들어진 결과물에서 고치고 싶은 부분을 찾습니다.
  2. 간단한 문구는 슬라이드나 문서에서 직접 고칩니다.
  3. 큰 수정은 해당 부분에 코멘트를 달아 Claude에게 보냅니다.
  4. 문서에서는 특정 문단을 선택하고 바꿀 내용을 말하면 그 부분만 수정됩니다.
  5. Claude Docs에서 팀원과 함께 편집할 때는 코멘트에서 Claude를 멘션해 수정을 요청합니다.
  • Claude Docs에서는 팀원과 Claude가 같은 문서를 동시에 편집할 수 있습니다.
  • 작업이 클라우드에서 돌아가므로 기다리지 말고 다른 일을 하다가 돌아와 결과를 확인해도 됩니다.

4. Acrobat PDF 스페이스로 PPT 만들기

Adobe Acrobat의 AI 기반 PDF 스페이스에 보고서·기사 링크 같은 자료를 넣고, 핵심을 요약한 뒤 발표 PPT 초안까지 만드는 기능입니다. 요약 속 숫자를 누르면 원문의 근거 부분이 표시되므로 수치가 많은 보고서를 발표 자료로 옮길 때 유용합니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적, 청중, 뽑을 변화·수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기에서 프레젠테이션을 고르거나 채팅창에 프레젠테이션 생성을 요청합니다.
  7. 대상자·톤·길이·템플릿을 고르고 프레젠테이션 생성을 누릅니다.
  8. Adobe Express 편집 화면에서 글자·배경·아이콘을 고친 뒤 다운로드로 저장합니다.
  • PDF 스페이스에는 확장자와 관계없이 파일을 최대 100개까지 넣을 수 있습니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF 중에서 고를 수 있습니다.
  • 생성된 내용과 수치는 원문과 비교해 확인하고, 근거가 없는 내용은 '확인 필요'로 표시해 달라고 요청합니다.
  • 예상 질문과 답변도 정리해 달라고 하면 발표 준비까지 할 수 있습니다.

5. Word에서 Claude로 초안 다듬기

Claude for Word는 Microsoft Word 오른쪽 패널에서 문서를 읽고 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기, 교정까지 맡는 기능입니다. 모든 수정이 검토 카드와 변경 내용 추적으로 표시되어, 검토자 의견이 많은 초안을 최종본으로 다듬을 때 안전하게 쓸 수 있습니다.

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치하고, Word 오른쪽의 Claude 패널을 엽니다.
  2. Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?라고 요청해 댓글을 검토자별로 정리합니다.
  3. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고 확인창에서 Allow once를 누릅니다.
  4. Box 등에 있는 근거 문서와 대조해 성능·수치 주장을 확인하게 하고, 맞지 않는 내용은 고치게 합니다.
  5. 수정 카드를 하나씩 확인하고 적용해 추적 변경으로 반영합니다.
  6. 서식은 원하는 최종 상태를 구체적으로 말하고 Don't change anything else.를 덧붙입니다.
  7. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language.처럼 요청합니다.
  8. 분량을 줄일 때는 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  9. 패널에 /를 입력해 copy edit 스킬로 오탈자와 문법을 교정한 뒤 변경 사항을 모두 수락하게 합니다.
예시
We need to get this under 1,000 words, but don't cut any more than you need to.
  • Word 웹, Windows, Mac에서 쓸 수 있고 Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다. 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남아 팀이 변경 내용을 볼 수 있습니다.
  • 카드가 지나치게 많이 잘라 내면 이유를 말하고 다시 제안하게 합니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 두면 패널에서 바로 불러 쓸 수 있습니다.

6. Excel과 PowerPoint 한 대화로 잇기

Claude for Excel과 PowerPoint는 열려 있는 두 파일을 하나의 대화로 이어서 다룹니다. Excel의 실시간 셀 값을 읽어 분석표를 만들고, 그 결과를 슬라이드에 반영합니다. 앱을 오가거나 데이터를 다시 설명할 필요가 없어, 숫자 분석과 보고 자료를 함께 만들 때 유용합니다.

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치합니다.
  2. 작업할 Excel 파일과 PowerPoint 파일을 함께 엽니다.
  3. Claude에게 Excel에서 할 분석과 슬라이드에 넣을 내용을 한 번에 요청합니다. 예: 비교 기업 재무 자료로 Excel에 비교표를 만들고, 요약을 발표 자료에 넣고, 요약문까지 쓰게 합니다.
  4. Excel에 만들어진 표와 수치를 확인합니다.
  5. PowerPoint에서 갱신된 슬라이드를 확인합니다.
  6. 자주 반복하는 흐름이면 Skills로 저장해 두고 다음부터 한 번의 클릭으로 다시 실행합니다.
  • 유료 플랜 사용자 모두 Mac과 Windows에서 쓸 수 있습니다.
  • Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry를 통해서도 제공됩니다.

7. Kling 4.0으로 사진을 영상 만들기

Artlist에서 Kling 4.0을 쓰면 사진을 최대 10장까지 시작·중간·끝 프레임에 넣어 영상 한 편으로 만들 수 있습니다. 숙소·여행지 홍보 영상이나 광고처럼 여러 장면을 이어 붙여야 할 때 편집 프로그램 없이 끝낼 수 있습니다.

  1. Artlist에서 Kling 4.0을 고릅니다.
  2. 영상에 쓸 사진을 장면 순서대로 정리합니다(최대 10장).
  3. 사진을 시작·중간·끝 프레임에 순서대로 넣습니다.
  4. GPT나 Claude에 사진 순서를 보여 주고, 장면 흐름을 적은 프롬프트를 검토받아 다듬습니다.
  5. 다듬은 프롬프트를 넣고 영상을 생성합니다.
  6. 완성된 영상과 함께 생성된 배경 음악·목소리를 확인합니다.
  • 최대 30초 길이까지 만들 수 있고, 현재 해상도는 1080까지 지원합니다.
  • 영상에서는 30초 영상 생성에 약 1분이 걸렸습니다.
  • 예전 방식: 사진마다 영상을 따로 만들어 편집 프로그램에서 이어 붙였지만, 이제는 한 번에 만들어집니다.

8. Claude 디자인으로 시안부터 구현하기

앱 화면을 코드로 바로 만들기 전에 Claude 디자인으로 여러 시안을 살펴보고, 클릭해 볼 수 있는 프로토타입을 만든 뒤 구현까지 이어 가는 방법입니다. 작은 사이드 프로젝트의 화면 하나라도 짧게 디자인을 탐색하면 결과가 나아집니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 시안을 여러 개 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 보고 만족하면 Claude에게 구현(build)을 지시합니다.
  • 흐름은 시안 → 댓글 피드백 → 직접 수정 → 클릭형 프로토타입 → 구현 순서입니다.
  • Claude가 작업하는 동안 기다리지 않고 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
