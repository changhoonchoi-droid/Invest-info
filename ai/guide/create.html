문서·슬라이드·디자인 만들기

이 분야에서는 Claude 대화창, PowerPoint·Word·Excel 안의 Claude, Adobe Acrobat 같은 도구로 발표 자료·문서·디자인 시안을 만들고 다듬을 수 있습니다. 먼저 대화에서 슬라이드·문서를 바로 만드는 기초를 익힙니다. 그다음 PowerPoint·Word에서 기존 파일을 고치는 방법을 보고, 마지막으로 Excel 연동과 디자인 시안→구현 흐름으로 넘어가면 좋습니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 18개 기반 · 2026-10-29 갱신

최근 바뀐 점

  • Claude 채팅과 Cowork가 하나로 합쳐져 모드를 고를 필요가 없고, 작업이 클라우드에서 돌아 노트북을 닫아도 계속되며 휴대폰으로 진행 상황을 볼 수 있습니다.
  • 어떤 대화에서든 /slides, /docs, /designs를 입력해 그동안의 대화 내용을 바탕으로 슬라이드·문서·디자인을 만들 수 있습니다.
  • Claude Docs에서 팀원과 Claude가 같은 문서를 동시에 편집하고, 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.
  • Adobe Acrobat의 PDF 스페이스에 파일·링크를 최대 100개까지 넣고 요약한 뒤, 바로 프레젠테이션 초안을 만들어 PPTX로 내려받을 수 있습니다.

1. 대화에서 슬라이드·문서 바로 만들기

Claude와 대화로 정리한 내용을 그대로 발표 자료, 문서, 디자인 결과물로 바꾸는 기능입니다. 보고서 내용을 정리한 뒤 발표 자료나 한 장 요약 문서가 필요할 때 대화를 벗어나지 않고 만들 수 있습니다.

  1. Claude에서 Opus 5.5 모델을 골라 보고서 등 만들 내용을 먼저 대화로 정리합니다.
  2. 원하는 결과물을 설명해 Claude가 형식을 고르게 하거나, 형식을 정했다면 /slides, /docs, /designs 중 하나를 입력합니다.
  3. 결과물이 나오면 Sonnet 5.5로 바꿔 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 반복합니다.
  4. 특정 부분만 고치려면 슬라이드를 직접 고치거나, 문단을 선택해 바꿀 내용을 말합니다.
  5. 결과물의 고칠 곳에 코멘트를 달아 Claude에게 보내면 그 부분만 수정됩니다.
예시
/slides 지금까지 정리한 보고서 내용으로 팀 발표 자료를 만들어 줘
  • 방향을 잡는 단계는 Opus 5.5, 빠른 수정 단계는 Sonnet 5.5로 나눠 쓰기를 권합니다.
  • Docs, Slides, Design은 모든 유료 요금제에서 쓸 수 있습니다.
  • Claude Docs에서는 코멘트에서 Claude를 멘션해 수정을 요청하고, 팀원과 같은 문서를 동시에 편집할 수 있습니다.
  • 예전 방식: 9월 중순 베타 공개 때는 채팅과 Cowork 중 모드를 골라야 했지만, 이제 하나의 Claude로 합쳐져 기존 Cowork 작업도 그대로 이어집니다.

2. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 휴대폰에 녹음하고 그 받아쓰기 글을 Claude에게 보내 발표 자료로 만드는 방법입니다. 서식보다 내용에 집중할 수 있습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음의 텍스트 변환본(transcript)을 복사합니다.
  3. 변환본을 Claude 대화창에 붙여 넣어 보냅니다.
  4. 말한 내용 그대로 Claude 슬라이드로 만들어 달라고 요청합니다.
  5. 결과에서 작은 수정은 직접 고칩니다.
  6. 큰 수정은 댓글로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있으면 폰트·템플릿을 따로 찾지 않아도 됩니다.
  • 산책하면서 녹음하면 책상 앞보다 생각이 잘 풀린다는 것이 영상의 요령입니다.

3. Acrobat PDF 스페이스로 PPT 만들기

Adobe Acrobat의 PDF 스페이스에 보고서·기사 링크 등을 모아 AI로 핵심을 요약하고, 그 내용으로 프레젠테이션 초안까지 만드는 기능입니다. 요약 속 숫자를 누르면 원문 근거가 표시되어 사실 확인이 쉽습니다.

  1. 어도비 사이트에 로그인하고 PDF 스페이스에서 스페이스 사용하기를 누릅니다.
  2. 오른쪽 위 만들기에서 새 PDF 스페이스를 만듭니다.
  3. 장치, 웹링크, 텍스트 붙여 넣기로 보고서 파일과 기사 링크를 넣고 PDF 스페이스에 추가를 누릅니다.
  4. AI 어시스턴트에 발표 목적·청중·원하는 변화와 수치 개수를 적어 요약을 요청합니다.
  5. 요약 속 숫자를 눌러 원문에 표시된 근거 부분을 확인합니다.
  6. 왼쪽 만들기의 프레젠테이션을 선택하거나 채팅창에 프레젠테이션 생성을 요청합니다.
  7. 대상자·톤·길이·템플릿을 고르고 프레젠테이션 생성을 누릅니다.
  8. Adobe Express 편집 화면에서 글자·배경·아이콘을 수정한 뒤 다운로드로 저장합니다.
  • 파일·이미지·웹 링크·텍스트를 확장자와 관계없이 최대 100개까지 넣을 수 있습니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF입니다.
  • 생성된 내용과 수치는 원문과 꼭 비교하고, 근거가 없는 내용은 '확인 필요'로 표시해 달라고 요청할 수 있습니다.
  • 예상 질문과 답변도 정리해 달라고 하면 발표 준비까지 할 수 있습니다.

4. PowerPoint에서 Claude로 덱 만들기

PowerPoint 안의 Claude 애드인이 슬라이드 마스터·레이아웃·글꼴·색상을 읽고 회사 템플릿에 맞춰 덱 초안을 만드는 기능입니다. 보고서·데이터 파일을 올려 여러 자료를 한 번에 발표 자료로 묶을 때 유용합니다.

  1. 슬라이드 마스터·레이아웃·색상이 갖춰진 템플릿을 PowerPoint에서 엽니다.
  2. Claude 애드인을 엽니다.
  3. 필요하면 + 버튼을 눌러 리서치 보고서, 데이터 내보내기 파일, 내부 분석 자료 등을 올립니다.
  4. 슬라이드 수, 주제, 다룰 항목, 어조를 적어 덱 생성을 요청합니다.
  5. Claude가 변경 전에 허락을 구하면 매번 검토하거나 편집을 허용합니다.
  6. 생성된 덱의 구조와 Claude가 알려 주는 데이터 출처를 확인합니다.
예시
핀테크 산업을 평가하는 10장짜리 덱을 만들어 줘. 데이터 중심의 애널리스트 어조로 써 줘.
  • Claude 계정에 설정해 둔 Google Drive·Notion·Confluence 같은 커넥터가 애드인에도 그대로 적용되어 외부 자료를 읽고 쓸 수 있습니다.
  • 복잡하거나 많이 맞춤화된 템플릿은 결과가 브랜드 지침에 맞는지 꼭 직접 확인하세요.

5. 공유받은 덱 내용 물어보기

회의 전에 받은 PowerPoint 덱을 Claude에게 읽혀 슬라이드별 논지를 요약하고, 특정 슬라이드의 출처나 빠진 주제를 묻는 방법입니다. 긴 덱을 빨리 파악해야 할 때 씁니다.

  1. 회의 전에 공유받은 덱을 PowerPoint에서 엽니다.
  2. Claude 애드인을 열고 덱 전체의 논지를 슬라이드별로 요약해 달라고 요청합니다.
  3. 궁금한 점을 구체적으로 묻습니다. 예: 특정 슬라이드의 데이터 출처, 특정 리스크를 다루는지 여부.
예시
7번 슬라이드에 인용된 데이터 출처는?
  • 민감하거나 규제 대상인 내용은 조직의 데이터 취급 정책을 따르세요.

6. PowerPoint 슬라이드 골라 다듬기

이미 만든 덱에서 선택한 슬라이드나 개체만 고치고, 글머리표 슬라이드를 블록형 레이아웃·매트릭스·차트로 바꾸거나 슬라이드를 합치고 순서를 바꾸는 방법입니다. 결과물은 이미지가 아니라 직접 편집할 수 있는 기본 도형과 차트입니다.

  1. 수정할 슬라이드, 텍스트 상자 또는 제목을 선택합니다.
  2. Claude 채팅에 바꿀 내용을 요청합니다. 예: "이 섹션을 한 줄로 요약해 줘".
  3. 글머리표가 많은 슬라이드는 선택한 뒤 "4개 블록의 시각 레이아웃으로 바꿔 줘"라고 요청하고, 블록마다 넣을 항목(이름, 핵심 수치, 한 문장 설명)을 지정합니다.
  4. 겹치는 슬라이드는 "4번과 5번을 하나로 합쳐 줘"처럼 남길 내용과 함께 요청하고, 슬라이드를 지워도 되는지 묻는 Claude에게 답합니다.
  5. "규제 슬라이드를 시장 규모 바로 뒤로 옮겨 줘"처럼 순서 변경을 요청합니다.
  6. 빠진 슬라이드를 추가할 때는 요청 끝에 "필요하면 질문하라"는 문장을 붙이고 Claude의 질문에 답합니다.
  7. 선택하지 않은 부분이 그대로인지, 새 슬라이드가 덱의 글꼴·색상·간격과 맞는지 확인합니다.
예시
이 슬라이드를 4개 블록의 시각 레이아웃으로 바꿔 줘. 블록마다 이름, 핵심 수치, 한 문장 설명을 넣어 줘.
  • "필요하면 질문하라"를 붙이면 Claude가 바로 만들지 않고 기존 내용을 읽고 빠진 점을 먼저 파악합니다.
  • 표를 2x2 매트릭스(예: x축 매출 규모, y축 성장률)로, 막대 차트를 두 지표가 함께 보이는 묶음 가로 막대 차트로 바꿀 수도 있습니다.
  • 생성된 블록은 이동·크기 조정·색 변경을 개별로 할 수 있습니다.
  • 합치고 옮긴 뒤 흐름이 논리적으로 쌓이는지 확인하세요.

7. Word에서 Claude로 초안 다듬기

Claude for Word는 Word 패널 안에서 문서를 읽고 댓글 정리, 사실 확인, 서식 정리, 고쳐 쓰기, 분량 줄이기, 교정까지 실제로 편집합니다. 모든 수정이 검토 카드와 추적 변경으로 나타나 직접 수락·거절할 수 있어, 검토 의견이 달린 초안을 완성할 때 좋습니다.

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치하고, Word 오른쪽의 Claude 패널을 엽니다.
  2. 댓글을 검토자별로 정리하고 서로 충돌하는 요청이 있는지 물어봅니다.
  3. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고 확인창에서 Allow once를 누릅니다.
  4. Box 등 연결된 자료와 문서의 수치·주장을 대조하게 하고, 맞지 않는 내용은 고치게 합니다.
  5. 서식은 원하는 최종 상태를 말해 정리하고 Don't change anything else.를 덧붙입니다.
  6. 고칠 문단을 선택하고 Rewrite these in customer language.처럼 요청한 뒤 카드별로 확인해 적용합니다.
  7. 분량을 줄일 때는 목표 단어 수와 지킬 부분(인용문, 날짜)을 함께 알려 주고 화면 아래 단어 수를 확인합니다.
  8. 패널에 /를 입력해 스킬 목록에서 교정(copy edit) 스킬을 골라 오탈자를 고치고, 마지막에 변경 사항을 모두 수락하게 합니다.
예시
Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?
  • Word 웹·Windows·Mac에서 쓸 수 있고 Pro, Max, Team, Enterprise 유료 플랜에 포함됩니다.
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다. leave the comment threads open이라고 말하면 댓글 스레드가 남아 팀이 변경 내용을 볼 수 있습니다.
  • 카드가 지나치게 잘라 내면 이유를 말하고 다시 제안하게 하면 됩니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 패널에서 쓸 수 있습니다.

8. Excel과 PowerPoint 한 대화로 잇기

Claude for Excel과 PowerPoint가 열린 두 파일을 하나의 연속된 세션에서 다루는 기능입니다. Excel의 실시간 셀 값으로 분석표를 만들고 그 결과를 슬라이드에 반영하는 일을, 탭을 오가거나 데이터를 다시 설명하지 않고 한 번에 할 수 있습니다.

  1. 작업할 Excel 파일과 PowerPoint 덱을 함께 엽니다.
  2. Claude에게 한 번의 프롬프트로 Excel 분석표 작성, 슬라이드 반영, 요약문 작성까지 이어서 요청합니다.
  3. Excel에 만들어진 표와 계산 값을 확인합니다.
  4. PowerPoint 덱에 들어간 요약 슬라이드와 수치가 Excel 값과 일치하는지 확인합니다.
  5. 반복할 작업이면 Skills로 이 워크플로를 저장해 다음에 한 번에 다시 실행합니다.
  • 유료 플랜 사용자 모두 Mac·Windows에서 쓸 수 있습니다.
  • 영상 예시는 비교 기업 재무 자료로 Excel에 트레이딩 컴프스 표를 만들고, 밸류에이션 요약을 피치덱에 넣은 뒤 요약문까지 쓰게 한 것입니다.

9. Claude 디자인으로 시안부터 구현까지

Claude 디자인은 원하는 화면을 일상 언어로 설명하면 여러 디자인 시안을 만들고, 피드백·수정·클릭형 프로토타입을 거쳐 실제 구현까지 이어 주는 기능입니다. 앱 화면처럼 코드로 바로 들어가기 전에 짧게 디자인을 탐색하고 싶을 때 씁니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 여러 시안을 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 댓글로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 써 본 뒤 만족하면 Claude에게 구현(build)을 지시합니다.
예시
현재 앱을 살펴보고 이 앱에 맞는 온보딩 화면 시안을 여러 개 만들어 줘.
  • 작은 사이드 프로젝트의 일부 화면이라도 짧은 디자인 탐색을 거치면 결과가 나아집니다.
  • Claude가 작업하는 동안 기다리지 않고 다른 일을 하다 돌아와 결과를 확인해도 됩니다.
  • 출시 브리프 하나로 슬라이드, 소셜 이미지 세트, 한 장짜리 문서를 함께 만들 수도 있습니다.
