문서·슬라이드·디자인 만들기

이 분야에서는 대화 중에 바로 슬라이드, 문서, 디자인을 만들고, 코멘트로 원하는 부분만 고치고, Word·Excel·PowerPoint 안에서 Claude에게 실제 편집을 맡길 수 있습니다. 먼저 대화에서 결과물을 만들고 고치는 기본기를 익히세요. 그다음 음성 메모로 발표 자료 만들기, Office 앱 연동 순서로 넓혀 가고, 마지막에 Claude 디자인으로 시안부터 구현까지 이어 가는 고급 흐름을 보면 좋습니다.

Artifacts, 문서·엑셀·슬라이드·이미지·디자인·대시보드 생성 · 영상 8개 기반 · 2026-10-20 갱신

최근 바뀐 점

  • 채팅과 Cowork가 하나의 Claude로 합쳐져 모드를 고를 필요가 없어졌습니다. 기존 Cowork 작업은 그대로 유지됩니다.
  • 어떤 대화에서든 /slides, /docs, /designs로 지금까지 나눈 대화 내용을 바탕으로 슬라이드·문서·디자인을 바로 만들 수 있으며, 모든 유료 요금제에서 쓸 수 있습니다.
  • 작업이 클라우드에서 실행되어 노트북을 닫아도 계속되고, 휴대폰으로 진행 상황을 확인할 수 있습니다.
  • Claude Docs에서 팀원과 Claude가 같은 문서를 동시에 편집하고, 코멘트에서 Claude를 멘션해 수정을 요청할 수 있습니다.

입문

1. 대화에서 슬라이드·문서 바로 만들기

대화 화면을 떠나지 않고 지금까지 나눈 내용을 바탕으로 발표 자료, 문서, 디자인 결과물을 만드는 기능입니다. 보고서, 출시 안내, 한 장 요약처럼 내용은 정리됐는데 서식 작업이 부담될 때 씁니다.

  1. Docs, Slides, Design은 유료 요금제에서 쓸 수 있으니 먼저 요금제를 확인합니다.
  2. 모델을 Opus 5.5로 두고 보고서 등 만들 내용을 대화로 먼저 정리합니다.
  3. 형식을 정하지 않았다면 원하는 결과물을 설명하고 Claude가 알맞은 형식을 고르게 합니다.
  4. 형식을 정했다면 /slides, /docs, /designs 중 하나를 입력해 바로 요청합니다.
  5. 작업은 클라우드에서 실행되므로 노트북을 닫아도 계속되며, 휴대폰으로 진행 상황을 확인할 수 있습니다.
  6. 완성된 결과물을 열어 대화 내용이 제대로 반영됐는지 확인합니다.
예시
/slides 지금까지 정리한 내용으로 팀장 보고용 발표 자료를 만들어 줘
  • 출시 브리프 하나로 발표 자료, 소셜 이미지 세트, 현장용 한 장 요약 문서를 한 대화 안에서 모두 만들 수 있습니다.
  • 방향을 잡는 단계는 Opus 5.5, 빠르게 고치는 단계는 Sonnet 5.5로 나눠 쓰기를 권합니다.
  • 예전 방식: 채팅과 Cowork 중 모드를 골라야 했지만, 이제는 하나의 Claude로 합쳐져 그냥 원하는 것을 말하면 됩니다.

2. 코멘트로 결과물 일부만 고치기

만든 슬라이드나 문서에서 원하는 부분만 골라 직접 고치거나 코멘트로 수정을 요청하는 방법입니다. 전체를 다시 만들지 않고 문구, 차트, 색상 같은 세부 사항을 다듬을 때 씁니다.

  1. 다듬는 단계에서는 모델을 Sonnet 5.5로 바꿉니다.
  2. 오타나 단어 같은 작은 수정은 슬라이드·문서에서 직접 고칩니다.
  3. 바꾸고 싶은 문단을 선택하고 바꿀 내용을 말하면 그 부분만 수정됩니다.
  4. 큰 수정은 결과물의 해당 부분에 코멘트를 달아 Claude에게 보냅니다.
  5. 슬라이드 문구 다듬기, 차트 교체, 색상 팔레트 변경 같은 수정을 원하는 결과가 나올 때까지 반복합니다.
  6. Claude Docs에서는 팀원과 함께 같은 문서를 편집하면서 코멘트로 Claude를 멘션해 수정을 요청합니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
  • 작은 건 직접, 큰 건 코멘트로 나누면 수정이 빨라집니다.
  • 코멘트는 결과물의 어느 부분에든 달 수 있어서, 고칠 위치를 따로 설명하지 않아도 됩니다.

3. 음성 메모로 발표 자료 만들기

빈 슬라이드 앞에서 막막할 때, 하고 싶은 말을 음성으로 녹음하고 받아 적은 글을 Claude에게 보내 발표 자료로 만드는 방법입니다. 서식보다 내용에 집중하고 싶을 때 좋습니다.

  1. 휴대폰 음성 메모 앱을 켜고 발표하고 싶은 내용을 두서없이 모두 말해 녹음합니다.
  2. 녹음을 텍스트로 변환한 글(transcript)을 복사합니다.
  3. 변환한 글을 Claude에게 보냅니다.
  4. 말한 내용을 그대로 살려 Claude 슬라이드로 발표 자료를 만들어 달라고 요청합니다.
  5. 결과에서 작은 수정은 직접 고칩니다.
  6. 큰 수정은 코멘트로 남겨 Claude에게 보냅니다.
  7. 완성되면 팀에 공유하거나 내보내기(export)해서 전달합니다.
예시
Turn my exact words into a presentation using Claude's slides.
  • 메모가 엉망이어도 괜찮습니다. 나와 Claude만 보는 자료입니다.
  • Claude가 브랜드 스타일을 알고 있어 폰트나 템플릿을 따로 찾지 않아도 됩니다.
  • 한국어로 "내가 말한 그대로 살려서 Claude 슬라이드로 발표 자료를 만들어 줘"처럼 요청해도 됩니다.

4. Word에서 Claude로 초안 다듬기

Claude for Word는 Microsoft Word 오른쪽 패널에서 문서를 읽고 실제 편집까지 해 줍니다. 댓글이 많이 달린 초안을 정리하고, 사실을 확인하고, 서식·문장·분량을 다듬어 완성 문서로 만들 때 씁니다.

  1. Microsoft AppSource에서 Claude for Microsoft 365를 설치합니다. Pro, Max, Team, Enterprise 플랜에 포함되며 Word 웹, Windows, Mac에서 쓸 수 있습니다.
  2. Word 오른쪽의 Claude 패널을 열고 문서에 달린 댓글을 검토자별로 정리해 달라고 요청합니다.
  3. Turn on Track Changes and keep it on for everything you do in this document.라고 요청하고, 확인창에서 Allow once를 누릅니다.
  4. Box에 있는 근거 문서와 대조해 수치·주장을 확인하게 하고, 맞지 않는 내용은 고치게 합니다.
  5. 수정 카드를 확인하고 적용하면 변경 내용 추적으로 문서에 반영됩니다.
  6. 원하는 최종 서식을 말해 정리합니다(예: 번호를 1~5로 잇기, 표를 20단어 이하 글머리표로 바꾸기). 이때 Don't change anything else.를 덧붙입니다.
  7. 고쳐 쓸 문단을 선택하고 Rewrite these in customer language., Lead with what the reader gets.처럼 요청한 뒤 카드별로 확인합니다.
  8. 분량은 We need to get this under 1,000 words, but don't cut any more than you need to.처럼 요청하면서 지켜야 할 부분(인용문, 날짜)을 함께 알려 주고, 화면 아래 단어 수를 확인합니다.
  9. 패널에 /를 입력해 스킬 목록에서 copy edit 스킬로 오탈자와 문법을 교정한 뒤, 변경 사항을 모두 수락하게 합니다.
예시
Summarize the open comments in this document. Who's asking for what and do any of them conflict with each other?
  • 변경을 수락하면 되돌릴 수 없어서 Claude가 먼저 확인을 요청합니다.
  • 수락할 때 leave the comment threads open이라고 말하면 댓글 스레드가 남아 팀이 변경 내용을 볼 수 있습니다.
  • 카드가 지나치게 많이 잘라 내면 이유를 말하고 다시 제안하게 하면 됩니다.
  • /brand-guidelines 같은 나만의 스킬을 Claude 계정에서 만들어 두면 패널에서 바로 불러 쓸 수 있습니다.

5. Excel과 PowerPoint 한 대화로 잇기

Claude for Excel과 PowerPoint는 열려 있는 두 파일을 하나의 세션에서 이어서 다룹니다. Excel에서 분석한 결과를 슬라이드에 반영해야 할 때, 탭을 오가거나 데이터를 다시 설명하지 않고 한 번에 처리합니다.

  1. 유료 플랜으로 Mac 또는 Windows에서 Claude for Excel과 PowerPoint를 쓸 수 있게 준비합니다.
  2. 작업할 Excel 파일과 PowerPoint 파일을 둘 다 엽니다.
  3. 데이터 수집, Excel 표 작성, 슬라이드 반영, 요약문 작성까지 원하는 작업을 한 번의 프롬프트로 요청합니다.
  4. Claude가 실시간 셀 값을 읽어 분석을 만들고 슬라이드를 갱신했는지 두 파일에서 확인합니다.
  5. 추가 수정도 같은 세션에서 이어서 요청합니다. 앞의 데이터를 다시 설명하지 않아도 됩니다.
  6. 자주 반복하는 흐름은 Skills로 저장해 두고 다음부터 한 번의 클릭으로 다시 실행합니다.
예시
비교 기업들의 재무 자료를 가져와 Excel에 트레이딩 컴프스 표를 만들고, 밸류에이션 요약을 열려 있는 피치덱에 넣은 뒤 요약문도 작성해 줘.
  • 두 앱에 걸쳐 맥락이 유지되므로 Excel 숫자가 바뀌면 슬라이드도 같은 대화에서 바로 갱신하게 하면 됩니다.
  • Amazon Bedrock, Google Cloud Vertex AI, Microsoft Foundry로도 제공됩니다.
  • 2026년 3월에 공개된 기능이라 최신 메뉴 구성은 조금 다를 수 있습니다.

6. Claude 디자인으로 시안부터 구현하기

코드를 짜기 전에 Claude 디자인으로 화면 시안을 여러 개 만들어 보고, 피드백과 클릭형 프로토타입을 거쳐 구현까지 이어 가는 방법입니다. 앱 온보딩 화면처럼 일부 화면이라도 디자인을 짧게 탐색하면 결과가 좋아집니다.

  1. Claude Code를 열고 작업할 저장소(repo)를 연결합니다.
  2. Artifacts 탭으로 이동해 새 디자인을 만듭니다.
  3. 현재 앱을 살펴보고 시안을 여러 개 만들어 달라고 요청합니다.
  4. 결과가 나오면 잘 된 점과 아쉬운 점을 코멘트로 남깁니다.
  5. 마음에 들지 않는 세부 사항은 에디터에서 직접 고치고, 필요하면 새 시안을 더 요청합니다.
  6. 클릭해 볼 수 있는 프로토타입(click-through prototype)을 만들어 달라고 요청합니다.
  7. 프로토타입을 직접 써 보고 만족하면 Claude에게 구현(build)을 지시합니다.
예시
현재 앱을 살펴보고 이 앱에 어울리는 온보딩 화면 시안을 여러 개 만들어 줘.
  • Claude가 작업하는 동안 기다리지 말고 다른 일을 하다가 돌아와 결과를 확인해도 됩니다.
  • 작은 사이드 프로젝트라도 화면 하나에 짧은 디자인 탐색을 거치면 결과가 나아집니다.
  • Claude Design은 문서보다 프로토타입을 먼저 만드는 방식에 맞춰져 있으니, 말로 길게 설명하기보다 시안을 보며 고치세요.
