MCP·커넥터 연결

MCP·커넥터 연결은 AI가 Gmail, 캘린더, 노션, 브라우저 같은 외부 도구를 직접 다루게 해 주는 기능입니다. 먼저 구글·노션 같은 커넥터와 Gemini의 앱 연결로 감을 잡고, 그다음 크롬·어사이드 같은 브라우저 연결, 마지막으로 Claude Code의 MCP 서버 추가와 관리, 응용 사례로 넘어가면 좋습니다.

  • AI 웹 브라우저 어사이드(Aside)를 Codex 등에 연결해 로그인이 필요한 사이트에서도 AI가 클릭과 입력을 대신 하게 할 수 있습니다.

1. Gemini에 구글 앱 연결하기

Gemini에 구글 워크스페이스 같은 앱을 연결하면 메일 정리나 일정 등록을 프롬프트로 처리할 수 있습니다. 외부 도구 연결을 처음 경험해 보기에 가장 쉬운 방법입니다.

  1. Gemini 페이지 좌측 하단의 설정 및 도움말을 클릭합니다.
  2. 연결된 앱을 선택합니다.
  3. 연결할 앱(예: 구글 워크스페이스)을 골라 연결을 누릅니다.
  4. 어제 온 메일들 정리해 줘처럼 요청해 메일을 카테고리별로 정리합니다.
  5. 다음 주 화요일 2시 회의 일정 잡아줘로 캘린더 일정을 만듭니다.
예시
어제 온 메일들 정리해 줘
  • 기본값인 빠른 모드는 구형 2.5 모델입니다. 3 Pro를 쓰려면 사고 모드로 바꿔야 합니다.

2. 코워크에 커넥터 연결하고 예약하기

코워크에 Gmail, 구글 캘린더, 노션 같은 커넥터를 연결하면 내 업무 도구의 자료를 읽고 정리하는 일을 시킬 수 있습니다. 반복되는 일은 예약 작업으로 걸어 두면 정해진 시각에 자동으로 실행됩니다.

  1. 플러스 버튼에서 커넥터 → 커넥터 추가 → 커넥터 둘러보기로 들어갑니다.
  2. Gmail, 구글 캘린더, 노션 등을 검색해 플러스 버튼을 누르고 계정으로 로그인해 인증합니다.
  3. 새 작업에서 협업을 누르고 새 프로젝트를 만듭니다.
  4. 반복할 일을 요청 문장으로 적습니다(아래 예시 참고).
  5. 승인 버튼을 눌러 예약을 확정합니다.
  6. 좌측 코워크 탭에서 작업 내역과 결과를 확인합니다.
예시
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 이메일을 다루는 작업은 Gmail 같은 이메일 커넥터가 켜져 있어야 합니다.
  • 예약 작업은 실행마다 새 세션으로 돌며 설정해 둔 커넥터를 그대로 씁니다.
  • 2026년 7월 업데이트 이후 웹·모바일에서는 기기가 꺼져 있어도 클라우드에서 실행됩니다. 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 했습니다(6월 영상 기준).
  • 웹 버전은 로컬 파일 접근과 컴퓨터 조작이 안 되므로 그런 작업은 데스크톱 앱에서 합니다.

3. PowerPoint에서 커넥터로 자료 가져오기

Claude AI에 설정해 둔 커넥터는 PowerPoint 애드인에서도 그대로 적용됩니다. Google Drive, Notion, Confluence의 자료를 읽어 슬라이드를 만들고, 작업 후 해당 도구에 다시 쓸 수도 있습니다.

  1. Claude AI에서 쓸 커넥터(Google Drive, Notion, Confluence 등)를 미리 설정해 둡니다.
  2. PowerPoint의 Claude 애드인에서 + 버튼을 눌러 보고서·데이터 파일을 올리거나 커넥터 자료를 불러옵니다.
  3. 가져온 자료로 슬라이드를 만들어 달라고 요청합니다.
  4. 기존 덱이 있으면 슬라이드별 논지를 요약하거나 특정 슬라이드의 출처를 물어봅니다.
  • 슬라이드 마스터·레이아웃·글꼴·색상을 따르지만, 복잡한 템플릿은 브랜드 지침과 맞는지 직접 확인합니다.

4. Claude in Chrome 설치하고 연동하기

Claude in Chrome은 클로드가 웹페이지를 읽고 클릭·입력하게 해 주는 크롬 확장입니다. 코워크와 연결하면 크롬이 웹 데이터를 모으고 코워크가 엑셀·문서 보고서를 만드는 역할 분담이 됩니다.

  1. 크롬 웹스토어에서 클로드를 검색해 Claude in Chrome 베타를 찾습니다.
  2. Chrome에 추가를 누르고 승인 후 로그인합니다.
  3. 우측 상단 퍼즐 버튼에서 클로드 확장을 핀으로 고정합니다.
  4. 클로드 데스크톱의 설정 → 커넥터 탭에서 Claude in Chrome을 찾아 구성을 누릅니다.
  5. 커넥터를 활성화합니다.
  6. 코워크의 + 버튼 → 커넥터에서 Claude in Chrome을 켭니다.
  • Pro 플랜은 경량 모델만 쓸 수 있습니다. 복잡한 작업은 Sonnet 이상을 쓸 수 있는 Max·Team·Enterprise를 권합니다.
  • 민감한 작업에서는 실행 전에 확인하는 Ask before acting 모드를 켜세요.
  • 속도가 느리고 베타이며, 악의적 사이트의 숨은 지시(프롬프트 인젝션)에 100% 안전하지 않습니다.
  • 캡차나 로그인은 직접 처리해야 하므로 80% 자동화, 20% 사람 확인이 현실적입니다.

5. Codex에 어사이드 브라우저 연결하기

어사이드(Aside)는 AI가 클릭하고 입력하는 일을 대신 해 주는 AI 웹 브라우저입니다. Codex에 연결하면 말로 시켜 메일 확인이나 사내 사이트 확인 같은 일을 맡길 수 있고, 이미 GPT·Claude를 유료로 쓰고 있으면 어사이드에는 따로 비용이 들지 않는다고 소개됩니다.

  1. PC에 Claude 데스크톱 앱과 GPT의 Codex 앱을 설치합니다.
  2. 어사이드를 설치하고 쓰는 GPT와 Claude 계정을 연결합니다.
  3. 어사이드 하단에서 모델을 고릅니다. 낮은 요금제면 가성비 좋은 균형형 모델을 씁니다.
  4. 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져옵니다.
  5. Codex를 열고 시작하기를 진행하며 승인 요청에서 전체 액세스를 켭니다.
  6. 터미널을 열어 영상에서 안내한 어사이드 연결 문구를 복사해 붙여 넣습니다.
  7. Codex에 어사이드를 쓰라고 지정해 일을 시키고, 어사이드 창에서 실제 작동을 확인합니다.
  • 전체 액세스는 모든 권한을 여는 것이라 보안 리스크가 있습니다.
  • 시킬 때 어사이드를 활용하라고 지정할수록 정확해집니다.
  • 크롬 로그인 정보가 제대로 옮겨졌는지 확인하고, 안 됐다면 GPT에 시켜 연결합니다.

6. Claude Code에 MCP 서버 추가·관리하기

MCP는 Claude Code를 Linear, GitHub, 문서 서버 같은 외부 도구와 데이터에 연결하는 개방형 표준입니다. 서버를 추가하는 방법과 범위, 컨텍스트를 아끼는 관리법을 익히는 기본 가이드입니다.

  1. 원격 서비스면 HTTP, 내 PC에서 도는 프로세스면 STDIO 유형을 고릅니다.
  2. 터미널에서 claude mcp add 명령으로 서버를 추가합니다.
  3. Claude Code 세션 안에서 /mcp를 실행해 연결 상태를 확인합니다.
  4. 쓰지 않을 서버는 /mcp에서 비활성화합니다.
  5. 팀과 공유하려면 프로젝트 범위로 두어 .mcp.json을 버전 관리에 올립니다.
  • 범위는 local(현재 프로젝트, 나만), user(모든 프로젝트), project(.mcp.json, 팀 공유) 세 가지입니다.
  • MCP 도구 정의는 쓰지 않을 때도 컨텍스트를 차지합니다. 10%를 넘으면 Claude Code가 자동으로 도구 검색 모드로 전환합니다.
  • GitHub의 gh, AWS의 aws처럼 CLI가 있으면 상시 도구 정의가 없어 컨텍스트 효율이 더 좋고, CLI 사용법은 스킬에 넣어 두면 필요할 때만 불러옵니다.
  • 커넥터 목록은 claude.com/connectors에서 볼 수 있습니다.

7. NotebookLM MCP를 안티그래비티에 연결

NotebookLM은 올린 자료로만 답하고 출처를 달아 주는 구글의 AI 리서치 도구입니다. 구글 개발 환경 도구 안티그래비티의 에이전트에 MCP로 연결하면 노트북 생성, 소스 추가, 분석을 AI가 대신 합니다.

  1. 구글에서 안티그래비티를 검색해 사이트에서 다운로드로 내 운영체제에 맞게 설치합니다.
  2. 화면 오른쪽 위 토글 에이전트를 눌러 프롬프트 입력창을 엽니다.
  3. 검색창에 노트북 LM MCP를 검색해 첫 번째 사이트를 열고, 다른 MCP 클라이언트용 설정 코드를 전체 복사합니다.
  4. 에이전트의 점 세 개 Additional Options에서 MCP 서버를 열고 Manage MCP Servers를 누릅니다.
  5. View raw config 파일에 복사한 코드를 붙여 넣고 Ctrl+S로 저장합니다.
  6. Refresh를 눌러 NotebookLM이 연결된 것을 확인합니다.
  7. 프롬프트에 연결 확인을 요청하고, 이어서 인증 진행해 줘로 구글 계정 로그인을 마칩니다.
예시
노트북 LM MCP 연결되었는지 확인해 줘
  • 어떤 MCP를 연결하든 먼저 연결 확인을 요청해 보는 것이 좋습니다.
  • 안티그래비티는 NotebookLM MCP 안내 페이지에 목록이 없어 직접 설정 코드를 붙여 넣어야 합니다.

8. Playwright MCP로 기능 만들고 검증하기

Playwright MCP를 연결하면 Claude가 앱을 직접 실행하고 화면을 확인하면서 수정과 검증을 반복합니다. 낯선 코드에 새 기능을 붙일 때 결과를 눈으로 확인하게 시키는 방법입니다.

  1. 설계 문서(spec)가 있으면 읽도록 프롬프트에 지정합니다.
  2. Playwright MCP를 사용하라고 프롬프트에 명시합니다.
  3. 구현할 기능을 구체적으로 적어 요청합니다.
  4. Claude가 코드베이스를 읽고 앱을 실행해 현재 상태를 확인하는 것을 지켜봅니다.
  5. 파일 변경 권한 요청이 나오면 검토 후 허용합니다.
  6. Claude가 변경과 검증을 반복한 뒤 내놓는 요약으로 코드를 리뷰합니다.
  • 구현 전 현재 화면을 먼저 확인시키면 기준이 정확해집니다.
  • 측정 가능한 검증 기준을 줄수록 Claude가 더 멀리 혼자 갑니다.

9. n8n MCP로 자동화 워크플로우 만들기

Docker로 띄운 n8n에 MCP를 연결하면 자연어 요청만으로 챗봇 같은 자동화 워크플로우를 만들 수 있습니다. 개발 환경에 어느 정도 익숙한 분께 맞는 응용 단계입니다.

  1. n8n MCP를 검색해 GitHub 페이지에서 Claude Code 연결 방법을 엽니다.
  2. 전체 설정(full configuration)을 복사합니다.
  3. 클로드 코드 명령 입력 위치에 붙여 넣습니다.
  4. 설정 속 API URL을 localhost:5678 주소로, API 키를 발급받은 키로 바꿉니다.
  5. /mcp를 입력해 n8n MCP가 연결 상태인지 확인합니다.
  6. 워크플로우를 만들어 달라고 요청합니다.
예시
n8n MCP로 간단한 AI 챗봇 만들어 줘
  • 워크플로우의 OpenAI 모델 노드에는 OpenAI API 키 등록이 필요합니다.
  • MCP는 연결 즉시 도구 정의가 컨텍스트에 상주합니다. 토큰 최적화 규칙을 CLAUDE.md에 저장해 두고 시작하면 좋습니다.
  • 같은 작업을 스킬로 만들어 두면 시작 시 메타데이터만 로딩해 더 효율적입니다. 영상에서는 MCP를 해제하고 스킬로 재현합니다.
