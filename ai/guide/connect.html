MCP·커넥터 연결

이 분야에서는 Claude·ChatGPT·Gemini 같은 AI에 구글 드라이브, 노션, 메일 같은 외부 서비스를 연결하고, 브라우저를 직접 조작시키는 일까지 할 수 있습니다. 먼저 앱 안에서 누르기만 하면 되는 커넥터(1~5번)로 시작하고, 이어서 브라우저·컴퓨터 사용(6~7번)을 보세요. 마지막으로 개발 도구용 MCP 서버(8~12번)를 보시면 됩니다.

1. Claude에 구글 드라이브·Notion 연결하기

커넥터는 Claude가 구글 드라이브, Notion, Gmail 같은 서비스의 내 자료를 직접 읽고 쓰게 해 주는 기능입니다. 파일을 일일이 내려받아 올리지 않아도 되므로, 드라이브 문서를 바탕으로 메일을 쓰는 업무에 적합합니다. 가장 먼저 익혀 두면 좋은 기능입니다.

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가를 누릅니다.
  3. 커넥터 둘러보기를 누릅니다.
  4. 연결할 서비스(구글 드라이브, Notion, Gmail, 구글 캘린더 등)를 검색합니다.
  5. 서비스 옆 +를 누르고 내 계정으로 로그인해 인증합니다.
  6. 채팅에서 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청합니다.
  7. 초안을 수정한 뒤 Gmail로 보내기를 누르면 메일에 바로 붙습니다.
예시
구글 드라이브에서 지난주 회의록 파일을 찾아서, 참석자에게 보낼 요약 이메일 초안을 써 줘.
  • Gmail 같은 이메일 커넥터가 켜져 있어야 메일 관련 작업이 됩니다.
  • Claude와 제휴한 커넥터 기업은 200개가 넘습니다.
  • PowerPoint용 Claude 애드인에서도 Claude에 설정해 둔 커넥터가 그대로 적용됩니다.

2. Gemini에 구글 앱 연결하기

Gemini에 구글 워크스페이스 앱을 연결하면 메일 정리나 일정 등록을 프롬프트 한 줄로 처리할 수 있습니다. Gemini를 이미 쓰고 있다면 가장 쉽게 시작할 수 있는 연결입니다.

  1. Gemini 페이지 좌측 하단의 설정 및 도움말을 클릭합니다.
  2. 연결된 앱을 선택합니다.
  3. 연결할 앱(예: 구글 워크스페이스)을 골라 연결을 누릅니다.
  4. 어제 온 메일들 정리해 줘처럼 요청해 메일을 카테고리별로 정리합니다.
  5. 다음 주 화요일 2시 회의 일정 잡아줘로 캘린더 일정을 만듭니다.
예시
어제 온 메일들 정리해 줘
  • 영상 기준으로 기본값인 빠른 모드는 구형 2.5 모델이므로, 사고 모드로 바꿔야 Gemini 3 Pro를 씁니다.

3. Claude에 외부 서비스 MCP 연결하기

목록에 없는 서비스도 서비스가 주는 MCP 주소(URL)를 커스텀 커넥터로 등록하면 Claude에 연결됩니다. 영상에서는 이미지 서비스 Artlist와 영상 서비스 힉스필드를 연결해, 채팅에서 말로 이미지와 영상을 만들었습니다. 연결은 처음 한 번만 하면 됩니다.

  1. 연결할 서비스 사이트의 MCP 메뉴로 들어갑니다(Artlist는 Claude 선택, 힉스필드는 앱에서 연결하기).
  2. MCP URL 또는 MCP 링크 복사하기로 주소를 복사합니다.
  3. Claude 설정의 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  4. 이름 칸에 서비스 이름(Artlist, 힉스필드 등)을 씁니다.
  5. MCP 서버 URL 칸에 복사한 주소를 붙여 넣고 계속을 누릅니다.
  6. 채팅창의 + → 커넥터에서 서비스가 파란색(사용 중)인지 확인합니다.
  7. 채팅에서 만들고 싶은 이미지나 영상을 말로 요청합니다.
  • 커넥터 목록에서 회색이면 사용 안 함 상태입니다. 파란색으로 켜 주세요.
  • 영상에서는 힉스필드 공식 MCP만 쓰고 비공식 MCP는 쓰지 않는다고 했습니다.
  • 빠른 수정 작업에는 응답이 빠르고 사용량이 적은 Haiku 5.5가 유리하다고 합니다.

4. ChatGPT에 Artlist MCP 연결하기

ChatGPT에서도 Artlist MCP를 연결하면 한 채팅창에서 캐릭터 기획부터 이미지·영상 생성까지 할 수 있습니다. 기획은 ChatGPT 사용량, 생성은 Artlist 크레딧을 씁니다. 크레딧을 쓰기 전에 승인을 묻게 하고 단계를 나눠 진행하면 비용을 아낄 수 있습니다.

  1. ChatGPT 설정에서 개발자 모드를 켭니다(파란색으로 표시).
  2. Artlist 홈 아래쪽 Artlist MCP 페이지에서 URL을 복사합니다.
  3. ChatGPT에서 커넥터를 새로 만드는 창을 열고 이름을 Artlist로 입력합니다.
  4. 연결 칸에 복사한 URL을 붙여 넣고 인증은 기본값으로 둡니다.
  5. 체크 항목에 동의하고 만들기를 누릅니다.
  6. 새 채팅의 + 메뉴에서 Artlist가 보이는지 확인합니다.
  • 위험성 안내가 떠도 설치 과정의 일반 안내입니다.
  • ChatGPT 추론 단계를 높이면 사용량이 빨리 소모됩니다.
  • 수정 요청은 반영이 약할 때가 있어, 그럴 땐 재생성이 나을 수 있습니다.

5. 커넥터로 반복 업무 예약하기

Claude 코워크에서는 커넥터를 연결해 둔 뒤, 매주 같은 시각에 일을 자동으로 하도록 예약할 수 있습니다. 메일 정리, 미팅 브리핑 문서, 후속 메일 초안 같은 반복 업무에 알맞습니다.

  1. 플러스 버튼에서 커넥터 → 커넥터 추가 → 커넥터 둘러보기로 들어갑니다.
  2. Gmail, 구글 캘린더, 노션 등을 검색해 플러스 버튼을 누르고 계정으로 로그인해 인증합니다.
  3. 새 작업에서 협업을 누르고 새 프로젝트를 만듭니다.
  4. 언제, 무엇을 할지 예약 요청을 입력합니다.
  5. Claude가 만들어 준 프롬프트 초안과 주기를 확인하고 필요하면 고칩니다.
  6. 승인 버튼을 눌러 예약을 확정합니다.
  7. 좌측 코워크 탭에서 작업 내역과 결과를 확인합니다.
예시
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 예전 방식: 6월 영상에서는 예약 작업이 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있을 때만 실행된다고 했습니다. 7월 업데이트 이후에는 기기가 꺼져 있어도 클라우드에서 실행된다고 합니다.
  • 웹 버전은 로컬 파일 접근과 컴퓨터 직접 조작이 안 되므로 그런 작업은 데스크톱 앱에서 하세요.
  • 승인이 필요한 부분은 모바일에서도 요청이 옵니다.
  • 예약 작업은 실행마다 새 세션으로 돌아가 최신 파일과 도구 상태를 기준으로 합니다.

6. Claude in Chrome 설치하고 연동하기

Claude in Chrome은 Claude가 웹페이지를 읽고 클릭·입력하게 해 주는 크롬 확장입니다. 코워크와 연결하면 크롬이 웹 데이터를 모으고 코워크가 엑셀·문서 보고서를 만드는 식으로 역할을 나눌 수 있습니다. 아직 베타이고 속도가 느린 편입니다.

  1. 크롬 웹스토어에서 클로드를 검색해 Claude in Chrome 베타를 찾습니다.
  2. Chrome에 추가를 누르고 승인 후 로그인합니다.
  3. 우측 상단 퍼즐 버튼에서 클로드 확장을 핀으로 고정합니다.
  4. 클로드 데스크톱의 설정 → 커넥터 탭에서 Claude in Chrome을 찾아 구성을 누릅니다.
  5. 커넥터를 활성화합니다.
  6. 코워크의 + 버튼 → 커넥터에서 Claude in Chrome을 켭니다.
  • Pro 플랜은 경량 모델만 쓸 수 있습니다. 복잡한 작업은 Sonnet 이상을 쓸 수 있는 Max·Team·Enterprise를 권합니다.
  • 민감한 작업에서는 실행 전에 확인하는 Ask before acting 모드를 켜세요.
  • 악의적 웹사이트의 숨은 지시(프롬프트 인젝션)로 조작될 수 있어 100% 안전하지 않습니다.
  • 캡차와 로그인은 직접 처리해야 하므로 80% 자동화, 20% 사람 확인이 현실적입니다.

7. Codex에 어사이드 연결해 일 시키기

어사이드(Aside)는 AI가 클릭하고 입력하는 일을 대신 해 주는 AI 웹 브라우저입니다. 이미 GPT나 Claude를 유료로 쓰고 있으면 계정을 연결해 별도 비용 없이 쓸 수 있습니다. 크롬 로그인 정보를 가져오면 로그인이 필요한 사이트에서도 일을 시킬 수 있습니다.

  1. PC에 Claude 데스크톱 앱과 GPT의 Codex 앱을 설치합니다.
  2. 어사이드를 설치하고 쓰는 GPT와 Claude 계정을 연결합니다.
  3. 어사이드 하단에서 모델을 고릅니다. 낮은 요금제면 가성비 좋은 균형형 모델을 씁니다.
  4. 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져옵니다.
  5. Codex를 열고 시작하기를 진행하며 승인 요청에서 전체 액세스를 켭니다.
  6. 터미널을 열어 영상에서 안내한 어사이드 연결 문구를 복사해 붙여 넣습니다.
  7. Codex에 어사이드를 쓰라고 지정해 일을 시키고, 어사이드 창에서 실제 작동을 확인합니다.
  • 전체 액세스는 모든 권한을 여는 것이라 보안 리스크가 있습니다. 회사 PC에서는 특히 주의하세요.
  • 시킬 때 어사이드를 활용하라고 지정할수록 정확해집니다.
  • 크롬 로그인 정보가 제대로 옮겨졌는지 확인하고, 안 됐다면 GPT에 시켜 연결합니다.
  • 컴퓨터가 켜져 있으면 휴대폰 앱으로도 Codex에 일을 시킬 수 있습니다.

8. Claude Code에 MCP 서버 추가·관리하기

MCP는 Claude Code를 Linear, GitHub, 문서 서버 같은 외부 도구와 데이터에 연결하는 개방형 표준입니다. 서버는 쓰지 않을 때도 도구 정의가 컨텍스트를 차지하므로, 추가하는 것만큼 정리하는 것도 중요합니다.

  1. 원격 서비스면 HTTP, 내 PC에서 도는 프로세스면 STDIO 유형을 고릅니다.
  2. 터미널에서 claude mcp add 명령으로 서버를 추가합니다.
  3. Claude Code 세션 안에서 /mcp를 실행해 연결 상태를 확인합니다.
  4. 쓰지 않을 서버는 /mcp에서 비활성화합니다.
  5. 팀과 공유하려면 프로젝트 범위로 두어 .mcp.json을 버전 관리에 올립니다.
예시
/mcp
  • 범위는 local(현재 프로젝트, 나만), user(모든 프로젝트), project(.mcp.json, 팀 공유) 세 가지입니다.
  • MCP 도구 정의가 컨텍스트 창의 10%를 넘으면 Claude Code가 자동으로 도구 검색 모드로 전환합니다.
  • GitHub의 gh, AWS의 aws처럼 CLI가 있으면 상시 도구 정의가 없어 더 효율적입니다. CLI 사용법은 스킬에 넣어 두면 필요할 때만 불러옵니다.
  • 커넥터 목록은 claude.com/connectors에서 볼 수 있습니다.

9. Playwright MCP로 기능 구현·검증하기

  1. 설계 문서(spec)가 있으면 읽도록 프롬프트에 지정합니다.
  2. Playwright MCP를 사용하라고 프롬프트에 명시합니다.
  3. 구현할 기능을 구체적으로 적어 요청합니다.
  4. Claude가 코드베이스를 읽고 앱을 실행해 현재 상태를 확인하는 것을 지켜봅니다.
  5. 파일 변경 권한 요청이 나오면 검토 후 허용합니다.
  6. Claude가 변경과 검증을 반복한 뒤 내놓는 요약으로 코드를 리뷰합니다.

10. BigQuery MCP로 제품 데이터 분석하기

데이터 팀이 BigQuery MCP를 Claude Code에 연결해 두면, SQL을 몰라도 말로 제품 데이터를 조회하고 그래프를 만들 수 있습니다. 직접 하면 몇 시간 걸릴 분석이 몇 분으로 줄었다고 합니다. 연결 설정 자체는 데이터 담당자와 함께 하는 것이 좋습니다.

  1. 데이터 팀이 BigQuery MCP로 제품 데이터 테이블을 Claude Code에 연결해 둡니다.
  2. Claude Code에서 보고 싶은 지표와 기간을 말합니다.
  3. 조회할 데이터 테이블을 알려 줍니다.
  4. 만들어진 그래프를 확인합니다.
  5. '요금제별로 그려 달라'처럼 후속 요청을 합니다.
  6. 파일 수정 권한 요청이 나오면 허용합니다.
  • SQL 작성보다 결과를 해석하는 역할이 중요합니다.
  • 요청하지 않은 7일 이동평균 같은 요소가 추가될 수 있으니 확인합니다.

11. 안티그래비티에 NotebookLM MCP 연결하기

NotebookLM은 내가 올린 자료만으로 답하고 출처를 달아 주지만, 소스 추가와 결과 복사는 수작업입니다. 구글 개발 환경 도구 안티그래비티의 AI 에이전트에 NotebookLM MCP를 연결하면 노트북 생성, 소스 추가, 분석을 에이전트가 대신합니다.

  1. 구글에서 안티그래비티를 검색해 사이트에서 다운로드로 내 운영체제에 맞게 설치합니다.
  2. 화면 오른쪽 위 토글 에이전트를 눌러 프롬프트 입력창을 엽니다.
  3. 검색창에 노트북 LM MCP를 검색해 첫 번째 사이트를 열고, 다른 MCP 클라이언트용 설정 코드를 전체 복사합니다.
  4. 에이전트의 점 세 개 Additional Options에서 MCP 서버를 열고 Manage MCP Servers를 누릅니다.
  5. View raw config 파일에 복사한 코드를 붙여 넣고 Ctrl+S로 저장합니다.
  6. Refresh를 눌러 NotebookLM이 연결된 것을 확인합니다.
  7. 프롬프트에 연결 확인을 요청하고, 이어서 인증 진행해 줘로 구글 계정 로그인을 마칩니다.

12. 클로드 코드에 n8n MCP 연결하기

내 컴퓨터의 Docker 위에서 n8n을 실행하고, API 키로 n8n MCP를 클로드 코드에 연결하면 자연어로 자동화 워크플로우를 만들 수 있습니다. 개발 환경에 익숙하지 않다면 가장 어려운 단계이므로 마지막에 도전하세요.

  1. Docker Desktop 위에 n8n 컨테이너를 실행하고 API 키를 발급받습니다.
  2. n8n MCP를 검색해 GitHub 페이지에서 Claude Code 연결 방법을 엽니다.
  3. 전체 설정(full configuration)을 복사합니다.
  4. 클로드 코드 명령 입력 위치에 붙여 넣습니다.
  5. 설정 속 API URL을 localhost:5678 주소로, API 키를 발급받은 키로 바꿉니다.
  6. /mcp를 입력해 n8n MCP가 연결 상태인지 확인합니다.
  7. 요청을 입력해 워크플로우를 만듭니다.
예시
n8n MCP로 간단한 AI 챗봇 만들어 줘
  • n8n 기본 포트는 5678입니다.
  • 워크플로우의 OpenAI 모델 노드에는 OpenAI API 키 등록이 필요합니다.
  • MCP는 연결 즉시 도구 정의가 컨텍스트를 차지합니다. 반복 작업은 스킬로 바꾸면 토큰을 아낄 수 있습니다.
  • 토큰 최적화 규칙을 CLAUDE.md에 저장해 두고 시작하면 좋습니다.
