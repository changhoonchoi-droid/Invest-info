MCP·커넥터 연결

MCP와 커넥터는 Claude나 ChatGPT가 구글 드라이브·노션·Gmail 같은 외부 서비스와 브라우저를 직접 다루게 해 주는 연결 기능입니다. 먼저 앱에서 클릭만으로 끝나는 커넥터를 붙여 보고, 이어서 이미지·영상 서비스 MCP, 브라우저 자동화, 개발 도구 연결 순으로 따라가면 쉽습니다. 연결할수록 AI가 할 수 있는 일과 권한이 함께 늘어나므로 보안 주의점도 같이 확인하세요.

1. Claude 앱에서 커넥터 연결하기

커넥터는 구글 드라이브, Gmail, 구글 캘린더, 노션 같은 서비스를 Claude 채팅에 붙이는 기능입니다. 파일을 일일이 올리거나 복사하지 않고 채팅에서 바로 자료를 찾고 메일 초안까지 쓸 때 사용합니다.

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가, 커넥터 둘러보기를 차례로 누릅니다.
  3. 연결할 서비스(Gmail, 구글 캘린더, 노션, 구글 드라이브 등)를 검색해 옆의 +를 누릅니다.
  4. 해당 서비스 계정으로 로그인해 권한을 승인합니다.
  5. 채팅에서 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청합니다.
  6. 초안을 수정한 뒤 Gmail로 보내기를 눌러 메일에 바로 붙입니다.
예시
구글 드라이브에서 '11월 견적서' 파일을 찾아 내용을 요약하고, 거래처에 보낼 안내 이메일 초안을 써 줘.
  • 이 가이드의 이메일 초안 실습은 Gmail·드라이브 커넥터가 켜져 있어야 합니다.
  • 연결한 커넥터는 채팅창 + → 커넥터에서 켜짐·꺼짐 상태를 확인할 수 있습니다.

2. Gemini에 구글 앱 연결하기

Gemini에 구글 워크스페이스 앱을 연결하면 메일 정리나 일정 등록을 프롬프트 한 줄로 처리할 수 있습니다. 구글 서비스를 주로 쓰는 직장인에게 맞습니다.

  1. Gemini 페이지 좌측 하단의 설정 및 도움말을 클릭합니다.
  2. 연결된 앱을 선택합니다.
  3. 연결할 앱(예: 구글 워크스페이스)을 골라 연결을 누릅니다.
  4. 어제 온 메일들 정리해 줘처럼 요청해 메일을 카테고리별로 정리합니다.
  5. 다음 주 화요일 2시 회의 일정 잡아줘로 캘린더 일정을 만듭니다.
예시
어제 온 메일들 정리해 줘
  • 영상에서는 기본값인 빠른 모드가 구형 2.5 모델이라, 사고 모드로 바꿔야 Gemini 3 Pro를 쓴다고 했습니다(2025년 12월 영상 기준).

3. Claude에 힉스필드 MCP 연결하기

힉스필드는 이미지·영상 생성 모델을 한곳에서 쓰는 플랫폼입니다. MCP를 연결하면 복사·붙여넣기 없이 Claude가 직접 힉스필드를 조작해 영상을 만듭니다.

  1. 클로드 설정에서 커넥터로 들어갑니다.
  2. 추가를 누르고 커스텀 커넥터를 선택한 뒤 이름 칸에 힉스필드를 입력합니다.
  3. 힉스필드 웹사이트 상단의 MCP 메뉴로 들어가 Claude를 선택합니다.
  4. 힉스필드 연결하기 화면에서 웹에서 연결하기를 눌러 MCP 링크를 복사합니다.
  5. 클로드의 MCP 서버 URL 칸에 링크를 붙여 넣고 계속을 누릅니다.
  6. 내려받은 광고 영상의 경로를 복사해 Claude에 분석과 비슷한 영상 제작을 요청합니다.
예시
첨부한 경쟁사 광고 영상을 분석해서 구성과 후킹 방식을 정리하고, 힉스필드로 비슷한 분위기의 우리 제품 광고 영상을 만들어 줘.
  • 영상에서는 힉스필드 공식 MCP만 쓰고 비공식 MCP는 쓰지 않는다고 했습니다.
  • 품질·화질을 최대로 올리면 크레딧이 많이 소모됩니다. 진행자는 2K 정도의 중간값을 가성비 좋은 선택으로 추천했습니다.
  • 잘 된 과정은 스킬로 만들고 작업 기록을 마크다운이나 노션에 남기게 하면 자동화하기 쉽습니다.

4. Claude·ChatGPT에 Artlist 연결하기

Artlist를 커넥터로 붙이면 채팅 안에서 이미지와 영상을 만들고 고칠 수 있습니다. 상품 사진 한 장으로 상세페이지용 이미지를 만들 때처럼 기획과 생성을 한 채팅창에서 처리하고 싶을 때 씁니다.

  1. Artlist 사이트에서 MCP 메뉴로 들어가 Claude를 선택하고 MCP URL을 복사합니다.
  2. Claude에서 이름을 눌러 설정으로 들어갑니다.
  3. 맨 아래 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  4. 이름에 Artlist를 쓰고 URL을 붙여 넣은 뒤 계속을 누릅니다.
  5. 채팅창의 + → 커넥터에서 Artlist가 파란색(사용 중)인지 확인합니다.
  6. ChatGPT는 설정에서 개발자 모드를 켠 뒤 커넥터를 새로 만들어 이름을 Artlist로 하고 URL을 붙여 넣은 다음 만들기를 누릅니다.
예시
첨부한 운동화 사진으로 쇼핑몰 대표 이미지와 착용샷을 만들어 줘. 크레딧을 쓰기 전에 먼저 승인을 물어봐 줘.
  • 연결은 처음 한 번만 하면 되며, 회색으로 보이면 사용 안 함 상태입니다.
  • 크레딧을 쓰기 전에 승인을 묻게 하고 단계를 나눠 진행하면 비용을 아낄 수 있습니다.
  • ChatGPT에서 연결할 때 뜨는 위험성 안내는 설치 과정의 일반 안내입니다.
  • 생성에는 Artlist 크레딧, 기획에는 ChatGPT(또는 Claude) 사용량이 쓰이며, 영상에서 Seedance 2.5는 무제한 혜택에 포함되지 않았습니다.

5. Claude in Chrome으로 웹 작업 맡기기

Claude in Chrome은 Claude가 웹페이지를 읽고 클릭·입력하게 해 주는 크롬 확장입니다. 코워크와 연결하면 크롬이 웹 데이터를 모으고 코워크가 엑셀·문서 보고서를 만드는 식으로 역할을 나눌 수 있습니다.

  1. 크롬 웹스토어에서 클로드를 검색해 Claude in Chrome 베타를 찾습니다.
  2. Chrome에 추가를 누르고 승인 후 로그인합니다.
  3. 우측 상단 퍼즐 버튼에서 클로드 확장을 핀으로 고정합니다.
  4. 클로드 데스크톱의 설정 → 커넥터 탭에서 Claude in Chrome을 찾아 구성을 누릅니다.
  5. 커넥터를 활성화합니다.
  6. 코워크의 + 버튼 → 커넥터에서 Claude in Chrome을 켭니다.
  • 베타 기능이며 속도가 느립니다. 숨은 지시(프롬프트 인젝션)로 조작될 수 있어 100% 안전하지 않습니다.
  • 민감한 작업에서는 실행 전에 확인하는 Ask before acting 모드를 켜세요.
  • 캡차나 로그인은 직접 처리해야 하므로 80% 자동화, 20% 사람 확인이 현실적입니다.
  • Pro 플랜은 경량 모델만 쓸 수 있습니다. 복잡한 작업은 Sonnet 이상을 쓸 수 있는 Max·Team·Enterprise를 권합니다.

6. 어사이드로 Codex에 브라우저 일 시키기

어사이드(Aside)는 AI가 클릭하고 입력하는 일을 대신하는 AI 웹 브라우저입니다. GPT의 Codex 앱과 연결하면 말로 시켜서 메일 확인이나 로그인이 필요한 사내 사이트 확인까지 맡길 수 있습니다.

  1. PC에 Claude 데스크톱 앱과 GPT의 Codex 앱을 설치합니다.
  2. 어사이드를 설치하고 쓰는 GPT와 Claude 계정을 연결합니다.
  3. 어사이드 하단에서 모델을 고릅니다. 낮은 요금제면 가성비 좋은 균형형 모델을 씁니다.
  4. 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져옵니다.
  5. Codex를 열고 시작하기를 진행하며 승인 요청에서 전체 액세스를 켭니다.
  6. 터미널을 열어 영상에서 안내한 어사이드 연결 문구를 복사해 붙여 넣습니다.
  7. Codex에 어사이드를 쓰라고 지정해 일을 시키고, 어사이드 창에서 실제 작동을 확인합니다.
예시
어사이드를 활용해서 내 메일함을 열고 오늘 온 메일 중 답장이 필요한 것을 알려 줘.
  • 이미 GPT·Claude를 유료로 쓰고 있으면 어사이드에는 따로 돈을 내지 않아도 됩니다.
  • 전체 액세스는 모든 권한을 여는 것이라 보안 리스크가 있습니다.
  • 시킬 때 어사이드를 활용하라고 지정할수록 정확해집니다.
  • 크롬 로그인 정보가 제대로 옮겨졌는지 확인하고, 안 됐다면 GPT에 시켜 연결합니다.

7. 코워크 예약 작업으로 업무 자동화하기

커넥터를 연결한 뒤 코워크에 반복 업무를 예약하면 정해진 시각에 알아서 실행됩니다. 매주 월요일 받은 메일 정리나 미팅 브리핑 문서 작성 같은 정기 업무에 알맞습니다.

  1. 플러스 버튼에서 커넥터 → 커넥터 추가 → 커넥터 둘러보기로 들어갑니다.
  2. Gmail, 구글 캘린더, 노션 등을 검색해 플러스 버튼을 누르고 계정으로 로그인해 인증합니다.
  3. 새 작업에서 협업을 누르고 새 프로젝트를 만듭니다.
  4. 반복할 업무와 주기를 말로 요청합니다.
  5. Claude가 만든 프롬프트 초안과 주기를 확인·수정한 뒤 승인 버튼을 눌러 예약을 확정합니다.
  6. 좌측 코워크 탭에서 작업 내역과 결과를 확인합니다.
예시
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 이 실습은 Gmail 같은 이메일 커넥터가 켜져 있어야 합니다.
  • 예약 작업은 실행마다 새 코워크 세션으로 돌아가 최신 파일과 도구 상태를 기준으로 하며, 설정해 둔 커넥터도 쓸 수 있습니다.
  • 2026년 7월 7일 업데이트 이후 작업은 클라우드에서 돌아 기기가 꺼져 있어도 실행된다고 소개되었습니다. 예전 방식: 6월 영상에서는 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있을 때만 실행된다고 했습니다.
  • 웹 버전은 로컬 파일 접근과 컴퓨터 직접 조작이 안 되므로 그런 작업은 데스크톱 앱에서 하세요.

8. Claude Code에 MCP 서버 추가·관리하기

Claude Code를 Linear, GitHub, 문서 서버 같은 외부 도구와 데이터에 연결하는 개방형 표준이 MCP입니다. 서버를 추가하고 범위와 켜짐 상태를 관리하는 기본기를 익힙니다.

  1. 원격 서비스면 HTTP, 내 PC에서 도는 프로세스면 STDIO 유형을 고릅니다.
  2. 터미널에서 claude mcp add 명령으로 서버를 추가합니다.
  3. Claude Code 세션 안에서 /mcp를 실행해 연결 상태를 확인합니다.
  4. 쓰지 않을 서버는 /mcp에서 비활성화합니다.
  5. 팀과 공유하려면 프로젝트 범위로 두어 .mcp.json을 버전 관리에 올립니다.
  • 범위는 local(현재 프로젝트, 나만), user(모든 프로젝트), project(.mcp.json, 팀 공유) 세 가지입니다.
  • 서버는 쓰지 않을 때도 도구 정의가 컨텍스트를 차지합니다. 도구 정의가 컨텍스트 창의 10%를 넘으면 자동으로 도구 검색 모드로 전환됩니다.
  • GitHub의 gh, AWS의 aws처럼 CLI가 있으면 상시 도구 정의가 없어 컨텍스트 효율이 더 좋고, CLI 사용법은 스킬에 넣어 두면 필요할 때만 불러올 수 있습니다.
  • 커넥터 목록은 claude.com/connectors에서 볼 수 있습니다.

9. Playwright MCP로 화면 확인하며 개발하기

  1. 설계 문서(spec)가 있으면 읽도록 프롬프트에 지정합니다.
  2. Playwright MCP를 사용하라고 프롬프트에 명시합니다.
  3. 구현할 기능을 구체적으로 적어 요청합니다.
  4. Claude가 코드베이스를 읽고 앱을 실행해 현재 상태를 확인하는 것을 지켜봅니다.
  5. 파일 변경 권한 요청이 나오면 검토 후 허용합니다.
  6. Claude가 변경과 검증을 반복한 뒤 내놓는 요약으로 코드를 리뷰합니다.
  • 구현 전 현재 화면을 먼저 확인시키면 기준이 정확해집니다.

10. n8n MCP를 Claude Code에 연결하기

Docker로 실행한 n8n에 MCP를 붙이면 자연어로 자동화 워크플로우(예: AI 챗봇)를 만들 수 있습니다. 개발 지식이 어느 정도 필요한 고급 과정입니다.

  1. n8n MCP를 검색해 GitHub 페이지에서 Claude Code 연결 방법을 엽니다.
  2. 전체 설정(full configuration)을 복사합니다.
  3. 클로드 코드 명령 입력 위치에 붙여 넣습니다.
  4. 설정 속 API URL을 localhost:5678 주소로, API 키를 발급받은 키로 바꿉니다.
  5. /mcp를 입력해 n8n MCP가 연결 상태인지 확인합니다.
  6. 요청해 워크플로우를 만듭니다.
예시
n8n MCP로 간단한 AI 챗봇 만들어 줘
  • 워크플로우의 OpenAI 모델 노드에는 OpenAI API 키 등록이 필요합니다.
  • MCP는 연결 즉시 도구 정의가 컨텍스트에 상주해 토큰을 차지합니다. 같은 작업을 스킬로 만들고 MCP를 해제하면 효율적이라고 소개되었습니다.
  • 토큰 최적화 규칙을 CLAUDE.md에 저장해 두고 시작하면 좋습니다.

11. 안티그래비티에 NotebookLM MCP 연결하기

NotebookLM은 올린 자료만으로 답하고 출처를 달아 주는 구글의 리서치 도구입니다. MCP로 AI 에이전트에 연결하면 노트북 생성, 소스 추가, 분석을 에이전트가 대신합니다.

  1. 구글에서 안티그래비티를 검색해 사이트에서 다운로드로 내 운영체제에 맞게 설치합니다.
  2. 화면 오른쪽 위 토글 에이전트를 눌러 프롬프트 입력창을 엽니다.
  3. 검색창에 노트북 LM MCP를 검색해 첫 번째 사이트를 열고, 다른 MCP 클라이언트용 설정 코드를 전체 복사합니다.
  4. 에이전트의 점 세 개 Additional Options에서 MCP 서버를 열고 Manage MCP Servers를 누릅니다.
  5. View raw config 파일에 복사한 코드를 붙여 넣고 Ctrl+S로 저장합니다.
  6. Refresh를 눌러 NotebookLM이 연결된 것을 확인합니다.
  7. 프롬프트에 연결 확인을 요청하고, 이어서 구글 계정 로그인 인증을 마칩니다.
예시
노트북 LM MCP 연결되었는지 확인해 줘
  • 어떤 MCP를 연결하든 먼저 연결 확인을 요청해 보는 것이 좋습니다.
  • 안티그래비티는 NotebookLM MCP 안내 페이지에 목록이 없어 직접 설정 코드를 붙여 넣어야 합니다.
