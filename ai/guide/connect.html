MCP·커넥터 연결

이 페이지에서는 AI에 구글 드라이브·Gmail·노션 같은 업무 도구와 이미지·영상 서비스를 연결하고, 브라우저를 AI가 대신 조작하게 하는 방법을 다룹니다. 먼저 클릭만으로 끝나는 커넥터 연결과 예약 작업을 익히세요. 그다음 브라우저 자동화, 힉스필드·Artlist 같은 외부 서비스 연결, 마지막으로 Claude Code의 MCP 서버 설정 순서로 보면 따라가기 쉽습니다.

1. 커넥터로 구글 드라이브·노션 연결하기

커넥터는 Claude 채팅에 구글 드라이브, Gmail, 노션 같은 서비스를 붙이는 기능입니다. 연결해 두면 파일을 일일이 올리지 않고 채팅에서 바로 찾아 쓰고, 결과를 메일 초안으로 만들 수 있습니다.

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가, 커넥터 둘러보기를 차례로 누릅니다.
  3. 연결할 서비스(Gmail, 구글 캘린더, 노션, 구글 드라이브 등)를 검색해 옆의 +를 누릅니다.
  4. 계정으로 로그인해 인증합니다.
  5. 채팅에서 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청합니다.
  6. 초안을 수정한 뒤 Gmail로 보내기를 누르면 메일에 바로 붙습니다.
예시
구글 드라이브에서 계약서 파일을 찾아 내용을 요약하고, 담당자에게 보낼 이메일 초안을 써 줘
  • 연동 업체가 200개가 넘으니 쓰는 서비스가 있는지 먼저 검색해 보세요.
  • 타이핑 대신 마이크로 상황을 충분히 말하면 결과가 좋아집니다.

2. 제미나이에 Gmail·드라이브 연결하기

제미나이에 구글 앱을 연결하면 메일 정리, 일정 등록, 드라이브 파일 찾기를 말로 시킬 수 있습니다. 이미 구글 서비스를 업무에 쓰는 분께 가장 쉬운 연결 방법입니다.

  1. Gemini 페이지 좌측 하단의 설정 및 도움말을 클릭합니다.
  2. 연결된 앱을 선택합니다.
  3. 연결할 앱(예: 구글 워크스페이스)을 골라 연결을 누릅니다.
  4. 어제 온 메일들 정리해 줘처럼 요청해 메일을 카테고리별로 정리합니다.
  5. 다음 주 화요일 2시 회의 일정 잡아줘로 캘린더 일정을 만듭니다.
예시
어제 온 메일들 정리해 줘
  • 예전 방식: 질문칸에 @를 입력해 Gmail이나 구글 드라이브를 고른 뒤, 안내가 뜨면 계속 → 기능 사용 켜기 → 저장을 했습니다. 연결은 한 번만 하면 됩니다.
  • 모바일 앱에서도 메일 요약·답장 초안은 되지만, 메일을 직접 발송하는 기능은 영상 시점(2025년 5월)에 없었습니다.

3. 커넥터로 예약 작업 걸기

Cowork에서 커넥터를 연결해 두고 주기와 할 일을 말하면, 정해진 시각에 Claude가 자동으로 일을 처리합니다. 주간 메일 정리, 미팅 브리핑, 주간 리포트처럼 반복되는 업무에 맞습니다.

  1. Gmail, 구글 캘린더, 노션 등 필요한 커넥터를 먼저 연결해 둡니다.
  2. 새 작업에서 협업을 누르고 새 프로젝트를 만듭니다.
  3. 언제, 무엇을 할지 구체적으로 요청합니다.
  4. Claude가 만든 프롬프트 초안과 주기를 확인하고 필요하면 고칩니다.
  5. 승인 버튼을 눌러 예약을 확정합니다.
  6. 좌측 코워크 탭에서 작업 내역과 결과를 확인합니다.
예시
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘
  • Gmail 같은 이메일 커넥터가 켜져 있어야 이 예시가 동작합니다.
  • 승인이 필요한 부분은 모바일에서도 요청이 오며 데스크톱 앱과 동일하게 동작합니다.
  • 예약 작업은 실행마다 새 세션으로 돌아 최신 파일과 도구 상태를 기준으로 합니다.
  • 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행됐습니다. 7월 업데이트 이후 영상에서는 기기가 꺼져 있어도 클라우드에서 실행된다고 합니다. 웹 버전은 로컬 파일 접근과 컴퓨터 조작이 안 됩니다.

4. Claude in Chrome 설치하고 연동하기

크롬 확장 프로그램으로, Claude가 웹페이지를 읽고 클릭·입력하게 해 줍니다. 코워크와 연결하면 크롬이 웹 데이터를 모으고 코워크가 엑셀·문서 보고서를 만드는 식으로 역할을 나눕니다.

  1. 크롬 웹스토어에서 클로드를 검색해 Claude in Chrome 베타를 찾습니다.
  2. Chrome에 추가를 누르고 승인 후 로그인합니다.
  3. 우측 상단 퍼즐 버튼에서 클로드 확장을 핀으로 고정합니다.
  4. 클로드 데스크톱의 설정 → 커넥터 탭에서 Claude in Chrome을 찾아 구성을 누릅니다.
  5. 커넥터를 활성화합니다.
  6. 코워크의 + 버튼 → 커넥터에서 Claude in Chrome을 켭니다.
  • Pro 플랜은 경량 모델만 쓸 수 있습니다. 복잡한 작업은 Sonnet 이상을 쓸 수 있는 Max·Team·Enterprise를 권합니다.
  • 민감한 작업에서는 실행 전에 확인하는 Ask before acting 모드를 켜세요.
  • 속도가 느리고 악의적 웹사이트의 숨은 지시(프롬프트 인젝션)에 조작될 수 있습니다. 캡차·로그인은 직접 처리하고 80%만 자동화한다고 생각하세요.

5. 어사이드 브라우저를 Codex에 연결하기

어사이드(Aside)는 AI가 클릭하고 입력하는 일을 대신 하는 브라우저입니다. Codex에 연결하면 메일 확인이나 사내 사이트의 반품 확인 같은 일을 말로 시킬 수 있습니다.

  1. PC에 Claude 데스크톱 앱과 GPT의 Codex 앱을 설치합니다.
  2. 어사이드를 설치하고 쓰는 GPT와 Claude 계정을 연결합니다.
  3. 어사이드 하단에서 모델을 고릅니다. 낮은 요금제면 가성비 좋은 균형형 모델을 씁니다.
  4. 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져옵니다.
  5. Codex를 열고 시작하기를 진행하며 승인 요청에서 전체 액세스를 켭니다.
  6. 터미널을 열어 영상에서 안내한 어사이드 연결 문구를 복사해 붙여 넣습니다.
  7. Codex에 어사이드를 쓰라고 지정해 일을 시키고, 어사이드 창에서 실제 작동을 확인합니다.
  • 이미 GPT·Claude를 유료로 쓰고 있으면 어사이드에는 따로 돈을 내지 않아도 된다고 합니다.
  • 전체 액세스는 모든 권한을 여는 것이라 보안 리스크가 있습니다.
  • 시킬 때 어사이드를 활용하라고 지정할수록 정확해집니다.
  • 크롬 로그인 정보가 제대로 옮겨졌는지 확인하고, 안 됐다면 GPT에 시켜 연결합니다.

6. 클로드에 힉스필드 연결하기

힉스필드 MCP를 클로드에 연결하면 대화창 하나에서 기획부터 제품 이미지, 쇼츠 영상, 랜딩 페이지까지 만들 수 있습니다. 기획은 클로드가, 이미지·영상 생성은 힉스필드 크레딧이 맡습니다.

  1. 채팅창에서 +를 누릅니다.
  2. 커넥터에서 커넥터 추가 → 커넥터 둘러보기를 선택합니다.
  3. 검색창에 Higgsfield를 입력합니다.
  4. 클로드에 연결을 누르고 힉스필드 계정으로 로그인합니다.
  5. 크레딧 잔액과 요금제를 확인해 달라고 요청해 연결을 확인합니다.
  6. 원하는 이미지나 영상을 말로 요청합니다. 제품 이미지를 먼저 고정한 뒤 영상화하면 일관성이 유지됩니다.
예시
힉스필드 MCP로 크레딧 잔액과 요금제를 확인해 줘
  • 클로드 계정과 힉스필드 계정이 각각 필요합니다.
  • 예전 방식: 클로드 설정 → 커넥터 → 커스텀 커넥터 추가에 이름(힉스필드)을 넣고, 힉스필드 사이트의 MCP 메뉴에서 복사한 링크를 붙여 넣었습니다. 목록에 없을 때는 지금도 이 방법을 씁니다.
  • 공식 MCP만 쓰고 비공식 MCP는 피하세요. 품질·화질을 최대로 올리면 크레딧이 많이 소모됩니다.
  • 참고: 영상 한 편에서 사진 3장·쇼츠 3편·랜딩 페이지를 합쳐 79크레딧(약 4,900원)이 들었습니다.

7. Claude에 Artlist 커넥터 연결하기

Artlist를 커넥터로 붙이면 Claude 채팅 안에서 이미지를 만들고 고칠 수 있습니다. 운동화 사진 한 장으로 대표 이미지, 배너, 인스타그램용 이미지, 모바일 상세페이지 시안까지 만든 사례가 있습니다.

  1. Artlist 사이트에서 MCP 메뉴로 들어가 Claude를 선택합니다.
  2. 아래쪽의 MCP URL을 복사합니다.
  3. Claude에서 이름을 눌러 설정으로 들어갑니다.
  4. 맨 아래 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  5. 이름에 Artlist를 쓰고 URL을 붙여 넣은 뒤 계속을 누릅니다.
  6. 채팅창의 + → 커넥터에서 Artlist가 파란색(사용 중)인지 확인합니다.
  • 연결은 처음 한 번만 하면 됩니다.
  • 회색이면 사용 안 함 상태이니 눌러서 켜세요.
  • 빠른 수정 작업에는 Haiku 5.5가 속도와 사용량 면에서 유리합니다.

8. ChatGPT에 Artlist MCP 연결하기

ChatGPT에도 Artlist를 연결해 한 채팅창에서 캐릭터 기획, 레퍼런스 이미지, 영상 제작까지 할 수 있습니다. 기획은 ChatGPT 사용량, 생성은 Artlist 크레딧을 씁니다.

  1. ChatGPT 설정에서 개발자 모드를 켭니다(파란색으로).
  2. Artlist 홈 아래쪽 Artlist MCP 페이지에서 URL을 복사합니다.
  3. ChatGPT에서 커넥터를 새로 만드는 창을 열고 이름을 Artlist로 입력합니다.
  4. 연결 칸에 복사한 URL을 붙여 넣고 인증은 기본값으로 둡니다.
  5. 체크 항목에 동의하고 만들기를 누릅니다.
  6. 새 채팅의 + 메뉴에서 Artlist가 보이는지 확인합니다.
  • 설치 중 위험성 안내가 떠도 일반 안내입니다.
  • 크레딧을 쓰기 전에 항상 승인을 묻게 하고 단계를 나눠 진행하면 비용을 아낄 수 있습니다.
  • 수정 요청은 반영이 약해 다시 생성하는 편이 나을 때가 있습니다.
  • ChatGPT 추론 단계를 높이면 사용량이 빨리 소모됩니다.

9. Claude Code에 MCP 서버 추가·관리하기

MCP는 Claude Code를 Linear, GitHub, 문서 서버 같은 외부 도구와 데이터에 연결하는 개방형 표준입니다. 서버를 추가하고, 상태를 확인하고, 안 쓰는 서버를 꺼서 관리하는 기본 흐름을 익힙니다.

  1. 원격 서비스면 HTTP, 내 PC에서 도는 프로세스면 STDIO 유형을 고릅니다.
  2. 터미널에서 claude mcp add 명령으로 서버를 추가합니다.
  3. Claude Code 세션 안에서 /mcp를 실행해 연결 상태를 확인합니다.
  4. 쓰지 않을 서버는 /mcp에서 비활성화합니다.
  5. 팀과 공유하려면 프로젝트 범위로 두어 .mcp.json을 버전 관리에 올립니다.
  • 범위는 local(현재 프로젝트, 나만), user(모든 프로젝트), project(.mcp.json, 팀 공유) 세 가지입니다.
  • 서버는 쓰지 않을 때도 도구 정의가 컨텍스트를 차지합니다. 도구 정의가 컨텍스트 창의 10%를 넘으면 자동으로 도구 검색 모드로 전환됩니다.
  • GitHub의 gh, AWS의 aws처럼 CLI가 있으면 컨텍스트 효율이 더 좋고, 사용법은 스킬에 넣어 두면 필요할 때만 불러옵니다.
  • 커넥터 목록은 claude.com/connectors에서 볼 수 있습니다.

10. Playwright MCP로 화면 확인하며 개발하기

Playwright MCP를 연결하면 Claude가 앱을 직접 실행하고 화면을 확인하면서 수정과 검증을 반복합니다. 낯선 코드에 새 기능을 넣을 때 유용합니다.

  1. 설계 문서(spec)가 있으면 읽도록 프롬프트에 지정합니다.
  2. Playwright MCP를 사용하라고 프롬프트에 명시합니다.
  3. 구현할 기능을 구체적으로 적어 요청합니다.

  5. 파일 변경 권한 요청이 나오면 검토 후 허용합니다.
  6. Claude가 변경과 검증을 반복한 뒤 내놓는 요약으로 코드를 리뷰합니다.

11. Claude Code에 n8n MCP 연결하기

내 PC의 Docker에서 돌리는 n8n에 MCP를 연결하면 자연어로 자동화 워크플로우를 만들 수 있습니다. 다만 MCP는 연결 즉시 도구 정의가 컨텍스트에 상주해 토큰 부담이 큽니다.

  1. n8n MCP를 검색해 GitHub 페이지에서 Claude Code 연결 방법을 엽니다.
  2. 전체 설정(full configuration)을 복사합니다.
  3. 클로드 코드 명령 입력 위치에 붙여 넣습니다.
  4. 설정 속 API URL을 localhost:5678 주소로, API 키를 발급받은 키로 바꿉니다.
  5. /mcp를 입력해 n8n MCP가 연결 상태인지 확인합니다.
  6. 원하는 워크플로우를 말로 요청해 만듭니다.
예시
n8n MCP로 간단한 AI 챗봇 만들어 줘
  • 워크플로우의 OpenAI 모델 노드에는 OpenAI API 키 등록이 필요합니다.
  • 토큰 최적화 규칙을 CLAUDE.md에 저장해 두고 시작하면 좋습니다.
  • Skills는 시작 시 메타데이터만 읽고 필요할 때만 내용을 불러와 효율적입니다. 스킬 크리에이터로 n8n 작업을 스킬로 바꾼 뒤 MCP를 해제할 수 있습니다.

12. 안티그래비티에 NotebookLM MCP 연결하기

NotebookLM은 올린 자료로만 답하고 출처를 달아 주는 구글의 AI 리서치 도구입니다. MCP로 AI 에이전트에 연결하면 노트북 생성, 소스 추가, 분석을 에이전트가 대신합니다.

  1. 구글에서 안티그래비티를 검색해 다운로드로 내 운영체제에 맞게 설치합니다.
  2. 화면 오른쪽 위 토글 에이전트를 눌러 프롬프트 입력창을 엽니다.
  3. 검색창에 노트북 LM MCP를 검색해 첫 번째 사이트를 열고, 다른 MCP 클라이언트용 설정 코드를 전체 복사합니다.
  4. 에이전트의 점 세 개 Additional Options에서 MCP 서버를 열고 Manage MCP Servers를 누릅니다.
  5. View raw config 파일에 복사한 코드를 붙여 넣고 Ctrl+S로 저장합니다.
  6. Refresh를 눌러 NotebookLM이 연결된 것을 확인합니다.
  7. 프롬프트로 연결 확인을 요청하고, 이어서 구글 계정 인증을 마칩니다.
예시
노트북 LM MCP 연결되었는지 확인해 줘
  • 어떤 MCP를 연결하든 먼저 연결 확인을 요청해 보는 것이 좋습니다.
  • 안티그래비티는 NotebookLM MCP 안내 페이지에 목록이 없어 직접 설정 코드를 붙여 넣어야 합니다.
  • 인증 단계에서는 인증 진행해 줘라고 요청합니다.
