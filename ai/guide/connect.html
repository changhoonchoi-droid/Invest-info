MCP·커넥터 연결

MCP와 커넥터는 AI가 구글 드라이브·Gmail·노션·이미지 생성 서비스 같은 외부 도구를 직접 다루게 해 주는 연결 장치입니다. 먼저 목록에서 고르는 기본 커넥터를 연결해 보고, 그다음 주소(URL)를 붙여 넣는 커스텀 커넥터, 예약 작업, 브라우저 조작, 개발자용 MCP 순서로 보면 쉽게 따라갈 수 있습니다.

최근 바뀐 점

  • 구글 드라이브 커넥터와 예약됨 기능을 묶어, 새 영상이 올라오면 한 시간 간격으로 확인해 자동 편집하게 하는 흐름이 소개되었습니다.
  • 힉스필드 공식 MCP를 클로드에 연결하면 이미지·쇼츠·랜딩 페이지까지 한 대화창에서 만들 수 있다는 시연이 나왔습니다. 연결 경로는 커넥터 둘러보기와 커스텀 커넥터 추가 두 가지로 설명됩니다.
  • 클로드 데스크톱 앱에서 Claude Code 모드와 스타터 팩 폴더를 이용해 영상 편집을 자동화하는 사례가 나왔고, 직접 40분 걸린 작업이 약 15분으로 줄었다고 합니다.

1. 커넥터로 구글 드라이브·Gmail 연결하기

커넥터는 Claude가 구글 드라이브, Gmail, 구글 캘린더, 노션 같은 서비스의 내 자료를 읽고 쓰게 해 주는 기능입니다. 파일을 일일이 올리거나 복사하지 않고 대화창에서 바로 '드라이브에서 계약서 찾아 줘'처럼 시킬 때 씁니다.

  1. 대화창 아래 +를 누르고 커넥터를 선택합니다.
  2. 커넥터 추가를 누른 뒤 커넥터 둘러보기를 선택합니다.
  3. Gmail, 구글 캘린더, 노션, 구글 드라이브 등 연결할 서비스를 검색합니다.
  4. 서비스 옆 + 버튼을 누르고 내 계정으로 로그인해 인증합니다.
  5. 채팅에서 드라이브 파일을 찾아 이메일 초안을 써 달라고 요청합니다.
  6. 초안을 수정한 뒤 Gmail로 보내기를 누르면 메일에 바로 붙습니다.
예시
구글 드라이브에서 계약서 파일을 찾아 핵심 조건을 요약하고, 상대방에게 보낼 확인 메일 초안을 써 줘.
  • 연결은 처음 한 번만 하면 되고, 채팅창 + → 커넥터에서 켜짐·꺼짐을 바꿀 수 있습니다.
  • 여러 구글 계정을 쓴다면 연결된 계정이 어느 것인지 미리 확인하세요.

2. 서비스 주소로 커스텀 커넥터 추가하기

목록에 없는 서비스(힉스필드, Artlist 등)는 서비스 사이트에서 MCP 주소(URL)를 복사해 커스텀 커넥터로 직접 붙여 넣어 연결합니다. 한 번 연결하면 Claude가 그 서비스의 이미지·영상 생성 기능을 대화창에서 바로 부릅니다.

  1. 연결할 서비스 사이트(예: Higgsfield, Artlist)에서 MCP 메뉴로 들어가 Claude를 선택합니다.
  2. 안내된 MCP 링크(MCP URL)를 복사합니다. 힉스필드는 힉스필드 연결하기 → 웹에서 연결하기로 나온 링크입니다.
  3. Claude의 설정 → 커넥터에서 추가 → 커스텀 커넥터 추가를 누릅니다.
  4. 이름 칸에 서비스 이름을 쓰고 MCP 서버 URL 칸에 복사한 링크를 붙여 넣습니다.
  5. 계속을 누르고 서비스 계정으로 로그인해 연결합니다.
  6. 채팅창 + → 커넥터에서 해당 서비스가 파란색(사용 중)인지 확인합니다.
  7. '힉스필드 MCP로 크레딧 잔액과 요금제를 확인해 줘'처럼 요청해 연결을 시험합니다.
예시
힉스필드 MCP로 크레딧 잔액과 요금제를 확인해 줘.
  • Claude 계정과 서비스 계정이 각각 필요하며, 이미지·영상 생성은 서비스 쪽 크레딧이 소모됩니다.
  • 목록 검색(커넥터 둘러보기)에서 Higgsfield가 나오면 클로드에 연결로 더 간단히 연결할 수 있습니다.
  • 회색이면 사용 안 함 상태이니 켜 주세요.
  • 공식 MCP만 쓰고 출처 불분명한 비공식 MCP는 피하는 것이 안전합니다.

3. ChatGPT에 Artlist MCP 연결하기

ChatGPT에서도 개발자 모드를 켜면 외부 서비스 MCP를 커넥터로 붙일 수 있습니다. 한 채팅창에서 기획은 ChatGPT가 하고 이미지·영상 생성은 Artlist 크레딧으로 처리하게 할 때 씁니다.

  1. ChatGPT 설정에서 개발자 모드를 켭니다(파란색으로 바뀝니다).
  2. Artlist 홈 아래쪽 Artlist MCP 페이지에서 URL을 복사합니다.
  3. ChatGPT에서 커넥터를 새로 만드는 창을 열고 이름을 Artlist로 입력합니다.
  4. 연결 칸에 복사한 URL을 붙여 넣고 인증은 기본값으로 둡니다.
  5. 체크 항목에 동의하고 만들기를 누릅니다.
  6. 새 채팅의 + 메뉴에서 Artlist가 보이는지 확인합니다.
  • 위험성 안내가 떠도 설치 과정의 일반 안내입니다.
  • 생성 크레딧은 Artlist, 기획은 ChatGPT 사용량을 씁니다.
  • 크레딧을 쓰기 전에 항상 승인을 묻도록 하고 단계를 나눠 진행하면 비용을 아낄 수 있습니다.

4. 커넥터와 예약 작업으로 업무 자동화하기

Gmail·캘린더 같은 커넥터를 연결해 둔 상태에서 Cowork의 예약 작업을 걸면 정해진 시각마다 Claude가 알아서 일을 처리합니다. 매주 받은 메일 정리나 회의 브리핑처럼 반복되는 업무에 씁니다.

  1. + → 커넥터 → 커넥터 추가 → 커넥터 둘러보기에서 Gmail, 구글 캘린더, 노션 등을 연결합니다.
  2. 새 작업에서 협업을 누르고 새 프로젝트를 만듭니다.
  3. 반복할 일을 시각과 함께 구체적으로 요청합니다.
  4. Claude가 만든 프롬프트 초안과 주기를 확인하고 필요하면 고칩니다.
  5. 승인 버튼을 눌러 예약을 확정합니다.
  6. 좌측 코워크 탭에서 작업 내역과 결과를 확인합니다.
예시
매주 월요일 아침 7시에 지난 한 주 받은 이메일 중 답장이 필요한 것을 정리하고, 고객 미팅 브리핑 문서를 만들고, 필요한 후속 이메일은 초안으로 남겨 줘.
  • 이메일 커넥터가 켜져 있어야 실습이 동작합니다.
  • 승인이 필요한 부분은 모바일에서도 요청이 오며 데스크톱 앱과 동일하게 동작합니다.
  • 2026년 7월 업데이트 이후 예약 작업은 기기가 꺼져 있어도 클라우드에서 실행됩니다. 예전 방식: 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있어야 실행됐습니다.
  • 웹 버전은 로컬 파일 접근과 컴퓨터 직접 조작이 안 되므로 그런 작업은 데스크톱 앱에서 하세요.

5. 구글 드라이브로 영상 편집 자동화하기

구글 드라이브 커넥터와 예약됨 기능을 묶어, 드라이브 폴더에 새 영상이 올라오면 Claude가 정해 둔 스타일로 자동 편집하게 하는 방법입니다. 같은 형식의 영상을 반복해서 만드는 사람에게 맞습니다.

  1. 설정에서 구글 드라이브 커넥터를 연결합니다.
  2. 레퍼런스 편집본과 촬영 원본을 폴더에 넣고, 규칙을 CLAUDE.md에 적어 둡니다.
  3. 왼쪽 상단의 예약됨을 엽니다.
  4. 영상을 올리는 드라이브 폴더를 지정하고 한 시간마다 확인하도록 설정합니다.
  5. 새 영상이 올라오면 자동으로 편집하도록 지시합니다.
  • CLAUDE.md는 Claude가 명령을 받으면 가장 먼저 읽는 규칙 파일입니다.
  • 연결된 계정이 어느 것인지 미리 확인하세요.
  • 캡컷 레이어 템플릿을 많이 모아 둘수록 디테일 정확도가 올라갑니다.

6. Claude in Chrome으로 웹 작업 맡기기

Claude in Chrome은 Claude가 웹페이지를 읽고 클릭·입력하게 해 주는 크롬 확장입니다. 코워크와 연결하면 크롬이 웹 데이터를 모으고 코워크가 엑셀·문서 보고서를 만드는 식으로 역할을 나눌 수 있습니다.

  1. 크롬 웹스토어에서 클로드를 검색해 Claude in Chrome 베타를 찾습니다.
  2. Chrome에 추가를 누르고 승인 후 로그인합니다.
  3. 우측 상단 퍼즐 버튼에서 클로드 확장을 핀으로 고정합니다.
  4. 클로드 데스크톱의 설정 → 커넥터 탭에서 Claude in Chrome을 찾아 구성을 누릅니다.
  5. 커넥터를 활성화합니다.
  6. 코워크의 + 버튼 → 커넥터에서 Claude in Chrome을 켭니다.
  • Pro 플랜은 경량 모델만 쓸 수 있습니다. 복잡한 작업은 Sonnet 이상을 쓸 수 있는 Max·Team·Enterprise를 권합니다.
  • 민감한 작업에서는 실행 전에 확인하는 Ask before acting 모드를 켜세요.
  • 악의적 웹사이트의 숨은 지시(프롬프트 인젝션)로 조작될 수 있어 100% 안전하지 않고, 캡차나 로그인은 직접 처리해야 합니다.
  • 속도가 느리고 베타이므로 80% 자동화, 20% 사람 확인으로 생각하세요.

7. 어사이드 브라우저로 Codex에 일 시키기

어사이드(Aside)는 AI가 클릭하고 입력하는 일을 대신 해 주는 AI 웹 브라우저입니다. Codex 같은 앱과 연결하면 말로 시켜 메일 확인이나 로그인이 필요한 사이트의 작업을 맡길 수 있습니다.

  1. PC에 Claude 데스크톱 앱과 GPT의 Codex 앱을 설치합니다.
  2. 어사이드를 설치하고 쓰는 GPT와 Claude 계정을 연결합니다.
  3. 어사이드 하단에서 모델을 고릅니다. 낮은 요금제면 가성비 좋은 균형형 모델을 씁니다.
  4. 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져옵니다.
  5. Codex를 열고 시작하기를 진행하며 승인 요청에서 전체 액세스를 켭니다.
  6. 터미널을 열어 영상에서 안내한 어사이드 연결 문구를 복사해 붙여 넣습니다.
  7. Codex에 어사이드를 쓰라고 지정해 일을 시키고, 어사이드 창에서 실제 작동을 확인합니다.
  • 전체 액세스는 모든 권한을 여는 것이라 보안 리스크가 있습니다.
  • 시킬 때 어사이드를 활용하라고 지정할수록 정확해집니다.
  • 크롬 로그인 정보가 제대로 옮겨졌는지 확인하고, 안 됐다면 GPT에 시켜 연결합니다.
  • 이미 GPT·Claude를 유료로 쓰고 있으면 어사이드에는 따로 돈을 내지 않아도 된다고 소개됩니다.

8. 제미나이에 구글 앱 연결하기

제미나이는 Gmail, 구글 드라이브, 캘린더 같은 구글 서비스와 연결해 메일 정리, 파일 찾기, 일정 등록을 말로 처리합니다. 구글 서비스를 이미 많이 쓰는 직장인에게 가장 간단한 연결 방법입니다.

  1. Gemini 페이지 좌측 하단의 설정 및 도움말을 클릭합니다.
  2. 연결된 앱을 선택합니다.
  3. 연결할 앱(예: 구글 워크스페이스)을 골라 연결을 누릅니다.
  4. 어제 온 메일들 정리해 줘처럼 요청해 메일을 카테고리별로 정리합니다.
  5. 다음 주 화요일 2시 회의 일정 잡아줘로 캘린더 일정을 만듭니다.
예시
어제 온 메일들 정리해 줘.
  • 예전 방식: 질문칸에 @를 입력해 Gmail이나 구글 드라이브를 고르고, 설정이 꺼져 있다는 안내가 나오면 계속 → 기능 사용 켜기 → 저장 순서로 연결했습니다.

9. Claude Code에 MCP 서버 추가하기

MCP는 Claude Code를 Linear, GitHub, 문서 서버 같은 외부 도구와 데이터에 연결하는 개방형 표준입니다. 개발 업무에서 Claude가 외부 서비스의 정보를 직접 읽고 쓰게 할 때 씁니다.

  1. 원격 서비스면 HTTP, 내 PC에서 도는 프로세스면 STDIO 유형을 고릅니다.
  2. 터미널에서 claude mcp add 명령으로 서버를 추가합니다.
  3. Claude Code 세션 안에서 /mcp를 실행해 연결 상태를 확인합니다.
  4. 쓰지 않을 서버는 /mcp에서 비활성화합니다.
  5. 팀과 공유하려면 프로젝트 범위로 두어 .mcp.json을 버전 관리에 올립니다.
  • 범위는 local(현재 프로젝트, 나만), user(모든 프로젝트), project(.mcp.json, 팀 공유) 세 가지입니다.
  • MCP는 쓰지 않을 때도 도구 정의가 컨텍스트를 차지하므로 안 쓰는 서버는 꺼 두세요. 정의가 컨텍스트 창의 10%를 넘으면 도구 검색 모드로 자동 전환됩니다.
  • GitHub의 gh, AWS의 aws처럼 CLI가 있으면 상시 도구 정의가 없어 컨텍스트 효율이 더 좋고, CLI 사용법은 스킬에 넣어 두면 필요할 때만 불러옵니다.
  • 커넥터 목록은 claude.com/connectors에서 볼 수 있습니다.

10. n8n MCP를 클로드 코드에 연결하기

내 컴퓨터에서 돌리는 n8n 자동화 도구에 MCP를 연결하면 자연어로 워크플로우(자동화 시나리오)를 만들게 할 수 있습니다. 코딩 없이 챗봇이나 업무 자동화 흐름을 만들어 보고 싶을 때 씁니다.

  1. Docker Desktop 위에 n8n 컨테이너를 실행하고 API 키를 발급받습니다.
  2. n8n MCP를 검색해 GitHub 페이지에서 Claude Code 연결 방법을 엽니다.
  3. 전체 설정(full configuration)을 복사합니다.
  4. 클로드 코드 명령 입력 위치에 붙여 넣습니다.
  5. 설정 속 API URL을 localhost:5678 주소로, API 키를 발급받은 키로 바꿉니다.
  6. /mcp를 입력해 n8n MCP가 연결 상태인지 확인합니다.
  7. n8n MCP로 간단한 AI 챗봇 만들어 줘처럼 요청해 워크플로우를 만듭니다.
예시
n8n MCP로 간단한 AI 챗봇 만들어 줘.
  • 워크플로우의 OpenAI 모델 노드에는 OpenAI API 키 등록이 필요합니다.
  • MCP는 연결 즉시 도구 정의가 컨텍스트에 상주해 토큰을 차지하므로, 작업을 스킬로 만든 뒤 MCP를 해제하는 방법도 있습니다.
  • 토큰 최적화 규칙을 CLAUDE.md에 저장해 두고 시작하면 좋습니다.
  • 도커가 부담스러우면 클라우드 방식 n8n이 더 쉽지만 비용이 듭니다.

11. 안티그래비티에 NotebookLM MCP 연결하기

NotebookLM은 올린 자료로만 답하고 출처를 달아 주는 구글의 리서치 도구입니다. MCP로 AI 에이전트에 연결하면 노트북 생성, 소스 추가, 분석을 에이전트가 대신 해 주어 수작업 반복을 줄일 수 있습니다.

  1. 구글에서 안티그래비티를 검색해 사이트에서 다운로드로 내 운영체제에 맞게 설치합니다.
  2. 화면 오른쪽 위 토글 에이전트를 눌러 프롬프트 입력창을 엽니다.
  3. 검색창에 노트북 LM MCP를 검색해 첫 번째 사이트를 열고, 다른 MCP 클라이언트용 설정 코드를 전체 복사합니다.
  4. 에이전트의 점 세 개 Additional Options에서 MCP 서버를 열고 Manage MCP Servers를 누릅니다.
  5. View raw config 파일에 복사한 코드를 붙여 넣고 Ctrl+S로 저장합니다.
  6. Refresh를 눌러 NotebookLM이 연결된 것을 확인합니다.
  7. 프롬프트에 노트북 LM MCP 연결되었는지 확인해 줘라고 요청하고, 이어서 인증 진행해 줘로 구글 계정 로그인을 마칩니다.
예시
노트북 LM MCP 연결되었는지 확인해 줘.
  • 어떤 MCP를 연결하든 먼저 연결 확인을 요청해 보는 것이 좋습니다.
  • 안티그래비티는 NotebookLM MCP 안내 페이지에 목록이 없어 직접 설정 코드를 붙여 넣어야 합니다.
