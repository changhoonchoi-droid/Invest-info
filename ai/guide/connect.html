MCP·커넥터 연결

MCP·커넥터를 쓰면 Claude나 Codex 같은 AI가 구글 드라이브·노션·슬랙·이메일·캘린더 같은 업무 도구와 웹 브라우저를 직접 다룹니다. 그래서 자료를 복사해 붙이지 않아도 AI가 조사, 문서 작성, 클릭과 입력까지 대신 합니다. 처음이라면 클릭으로 끝나는 커넥터 연결과 AI 브라우저부터 해 보세요. 그다음 Cowork의 업무 위임과 예약 작업, 팀 채널 연결을 익히고, 마지막에 Claude Code의 MCP 서버와 브라우저 검증, 클라우드 연동으로 넘어가면 됩니다.

MCP 서버, 커넥터(구글·노션·슬랙 등), 브라우저·컴퓨터 사용, 외부 도구 연결 · 영상 17개 기반 · 2026-10-31 갱신

최근 바뀐 점

  • AI 웹 브라우저 '어사이드(Aside)'를 Codex 데스크톱 앱에 연결하면, 말로 시키는 것만으로 메일 확인이나 사내 사이트 조회 같은 클릭·입력 작업을 AI가 대신 합니다.
  • 이미 GPT나 Claude를 유료로 쓰고 있다면 그 계정을 어사이드에 연결해 별도 비용 없이 쓸 수 있습니다.
  • 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져오면 로그인이 필요한 사이트에서도 AI에게 일을 시킬 수 있습니다.
  • 컴퓨터가 켜져 있으면 휴대폰 앱으로도 Codex에 일을 시킬 수 있습니다.

1. 커넥터로 업무 자료 불러오기

커넥터는 Claude를 Google Drive·Notion·Confluence·Slack 같은 업무 도구에 연결하는 기능입니다. 파일을 일일이 내려받아 올리지 않아도 Claude가 외부 자료를 읽어 문서나 슬라이드를 만들고, 결과를 그 도구에 다시 쓸 수도 있습니다. 한 번 설정해 두면 PowerPoint 애드인과 Cowork 예약 작업에서도 그대로 쓸 수 있습니다.

  1. claude.com/connectors에서 연결할 수 있는 커넥터 목록을 확인합니다.
  2. Claude AI에서 자주 쓰는 도구(Google Drive·Notion·Confluence 등)의 커넥터를 설정합니다.
  3. PowerPoint에서 Claude 애드인을 열고 + 버튼으로 보고서·데이터·분석 파일을 올립니다.
  4. 커넥터로 연결한 외부 자료를 읽어 슬라이드를 만들어 달라고 요청합니다.
  5. 기존 덱이라면 슬라이드별 논지를 요약하게 하거나, 특정 슬라이드의 출처를 물어봅니다.
  6. 필요하면 작업 결과를 연결한 도구에 다시 저장해 달라고 요청합니다.
  7. 완성된 슬라이드가 회사 브랜드 지침에 맞는지 직접 확인합니다.
  • Claude AI에서 설정한 커넥터는 PowerPoint 애드인에도 그대로 적용됩니다.
  • Claude는 슬라이드 마스터·레이아웃·글꼴·색상을 따르지만, 템플릿이 복잡하면 브랜드 지침과 어긋날 수 있습니다.
  • 설정한 커넥터는 Cowork 예약 작업에서도 쓸 수 있습니다.

2. AI 브라우저 어사이드로 웹 일 맡기기

어사이드(Aside)는 크롬 같은 웹 브라우저인데, AI가 대신 클릭하고 입력합니다. Codex 데스크톱 앱에 연결하면 말로 시키는 것만으로 메일 확인, 사내 시스템 조회, SNS 계정 탐색 같은 반복 웹 작업을 맡길 수 있습니다.

  1. PC에 Claude 데스크톱 앱과 GPT의 Codex 앱을 설치합니다.
  2. 어사이드를 설치하고, 쓰고 있는 GPT와 Claude 계정을 연결합니다.
  3. 어사이드 하단에서 모델을 고릅니다. 낮은 요금제라면 가성비 좋은 균형형 모델을 고릅니다.
  4. 크롬의 비밀번호와 즐겨찾기를 어사이드로 가져옵니다.
  5. Codex를 열어 시작하기를 진행하고, 승인 요청에서 전체 액세스를 켭니다.
  6. 터미널을 열고 영상에서 안내한 어사이드 연결 문구를 복사해 붙여 넣습니다.
  7. Codex에 어사이드를 쓰라고 지정해 일을 시킨 뒤, 어사이드 창에서 실제로 작동하는지 확인합니다.
  • 이미 GPT·Claude를 유료로 쓰고 있다면 어사이드에 따로 돈을 내지 않아도 됩니다.
  • 전체 액세스는 모든 권한을 여는 설정이라 보안 위험이 있습니다. 회사 PC라면 보안 정책을 먼저 확인하세요.
  • 일을 시킬 때 어사이드를 쓰라고 분명히 말할수록 결과가 정확해집니다.
  • 크롬 로그인 정보가 제대로 옮겨졌는지 확인하고, 안 됐다면 GPT에 연결을 시켜 봅니다.

3. Cowork에 회의 준비 맡기기

Claude Cowork는 캘린더·Slack·이메일·CRM처럼 여러 곳에 흩어진 정보를 모아 회의 준비 문서나 후속 메시지를 만들어 주는 업무 위임 기능입니다. 작업 중간에 방향을 바꿔도 처음부터 다시 하지 않고 이어서 고칩니다.

  1. Cowork에 캘린더·Slack·이메일 커넥터를 연결합니다.
  2. 다가오는 회의를 위한 준비 문서를 만들어 달라고 요청합니다.
  3. 작업 도중 출처를 더하거나 고칠 점이 있으면 바로 말해 방향을 바꿉니다.
  4. 완성된 문서를 작업 폴더에서 확인하고 직접 다듬습니다.
  5. 회의가 끝나면 같은 세션에서 녹취록을 처리해 할 일, 내부 Slack 메시지, 고객 후속 메시지를 만들게 합니다.
  6. 메시지마다 내용과 근거 원문을 확인하고 승인한 뒤 보냅니다.
  • 최종 문서의 소유와 수정 책임은 사용자에게 있습니다.
  • 브리핑 내용은 발송 전에 원문에서 근거를 직접 확인하세요.
  • 영업 사례에서는 미팅 후속 작업이 약 30분에서 몇 분으로 줄었습니다.

4. Cowork 예약 작업으로 자동화하기

매일 아침 메일 정리나 매주 지표 리뷰처럼 반복되는 일을 정해진 시각에 Cowork가 알아서 실행하게 하는 기능입니다. 한 번 해 보고 결과가 마음에 들면 그 과정을 일정에 맡기면 됩니다.

  1. 자동화하고 싶은 작업을 Cowork에서 먼저 한 번 실행해 결과를 확인합니다.
  2. 이 작업을 정해진 주기로 실행하는 예약 작업으로 만들어 달라고 요청합니다.
  3. Claude가 만든 프롬프트 초안을 읽고 필요한 부분을 고칩니다.
  4. 실행 주기(매일 아침, 평일 오후 4시, 일요일 저녁 등)를 확인하고 수정합니다.
  5. 승인해 예약 작업을 등록합니다.
  6. 예약 시각에 컴퓨터가 켜져 있고 데스크톱 앱이 열려 있게 둡니다.
  • 예약 작업은 실행할 때마다 새 Cowork 세션으로 돌아, 그 시점의 최신 파일과 도구 상태를 기준으로 합니다.
  • 미리 설정한 커넥터를 예약 작업에서도 쓸 수 있습니다.
  • 데이터가 맞지 않으면 Claude가 추측하지 않고 질문하므로, 결과를 정기적으로 확인하세요.

5. 업무 절차를 스킬로 저장하기

스킬은 내가 일하는 순서와 기준을 저장해 두고 매번 같은 방식으로 실행하게 하는 기능입니다. 주간 리포트, 변경 사항 브리핑, 고객 정보 수집처럼 정해진 절차가 있는 일을 스킬로 만들면 팀원과도 공유할 수 있습니다.

  1. Cowork에서 반복할 업무를 처음부터 끝까지 한 번 진행합니다.
  2. 그 과정을 스킬로 저장해 달라고 요청합니다.
  3. 숫자마다 검증된 출처가 있는지 확인하는 교정 단계 같은 품질 기준을 스킬에 더합니다.
  4. 다음에는 저장한 스킬을 불러 같은 방식으로 실행합니다. 예: /brief
  5. 실행 후 배운 점을 스킬에 반영해 다음 회차를 개선합니다.
  6. 완성된 스킬을 팀과 공유합니다.
  • /brief는 Anthropic 법무팀이 만든 플러그인으로, 과거 검토 문서와 새 Slack·Gmail 대화를 읽어 무엇이 바뀌었는지 알려 줍니다.
  • 플러그인은 오픈 프로토콜이라 회사 업무에 맞게 고쳐 쓸 수 있습니다.
  • 스킬 하나로 CRM·데이터 웨어하우스·Slack·이메일·웹을 동시에 조회할 수도 있습니다.

6. Claude Tag로 팀 채널에 Claude 두기

Claude Tag는 Slack 같은 팀 워크스페이스 채널에 Claude를 추가해, 팀 대화를 실시간으로 따라가며 일하게 하는 기능입니다. 채팅 창을 오가거나 맥락을 복사할 필요 없이 채널에서 바로 정리, 문서 초안 작성, 도구 수정까지 요청할 수 있습니다.

  1. 회사 계정이 Claude Team 또는 Enterprise인지 확인합니다.
  2. 관리자가 Slack 등 팀 워크스페이스 채널에 Claude를 추가합니다.
  3. 채널마다 Claude가 맡을 일, 개입 빈도, 자율 범위를 정합니다.
  4. 다른 공개 채널의 정보를 참고하게 할지 정해 접근 권한을 줍니다.
  5. 채널에서 Claude에게 작업을 바로 요청합니다.
  6. 변경 내역과 요청자 기록을 확인합니다.
  • DM과 비공개 채널의 내용은 비공개로 유지됩니다.
  • Claude는 별도의 자체 계정으로 작업하고, 모든 변경과 요청자를 기록합니다.
  • 채널별 지침을 기억하므로 채널의 용도를 처음에 분명히 알려 두세요.

7. Claude Code에 MCP 서버 연결하기

MCP는 Claude Code를 GitHub·Linear·문서 서버 같은 외부 도구와 데이터에 연결하는 개방형 표준입니다. 서버를 한 번 추가해 두면 Claude가 그 도구를 직접 조회하고 다룹니다. 팀원과 같은 설정을 나눠 쓸 수도 있습니다.

  1. 연결할 서비스가 원격 서비스면 HTTP, 내 PC에서 도는 프로그램이면 STDIO 유형을 고릅니다.
  2. 범위를 정합니다. local은 현재 프로젝트에서 나만, user는 모든 프로젝트, project는 팀 공유입니다.
  3. 터미널에서 claude mcp add 명령으로 서버를 추가합니다.
  4. Claude Code 세션 안에서 /mcp를 실행해 연결 상태를 확인합니다.
  5. 쓰지 않는 서버는 /mcp에서 끕니다.
  6. 팀과 공유하려면 project 범위로 만든 .mcp.json을 버전 관리에 올립니다.
예시
/mcp
  • MCP 서버는 쓰지 않을 때도 도구 정의가 컨텍스트를 차지합니다. 도구 정의가 컨텍스트 창의 10%를 넘으면 Claude Code가 자동으로 도구 검색 모드로 바뀝니다.
  • GitHub의 gh, AWS의 aws처럼 CLI가 있는 도구는 CLI를 쓰는 편이 컨텍스트 효율이 더 좋습니다.
  • CLI 사용법을 스킬에 넣어 두면 필요할 때만 불러옵니다.
  • Context7 MCP 서버를 연결하면 쓰는 라이브러리의 최신 문서를 참고할 수 있습니다.

8. BigQuery MCP로 SQL 없이 분석하기

데이터 팀이 BigQuery MCP로 제품 데이터를 Claude Code에 연결해 두면, SQL을 몰라도 말로 지표를 조회하고 그래프를 만들 수 있습니다. 직접 하면 몇 시간 걸리던 분석이 몇 분으로 줄어듭니다.

  1. 데이터 팀에 BigQuery MCP로 제품 데이터 테이블을 Claude Code에 연결해 달라고 요청합니다.
  2. Claude Code에서 보고 싶은 지표와 기간을 말합니다.
  3. 조회할 데이터 테이블 이름을 알려 줍니다.
  4. 파일 수정 권한 요청이 나오면 허용합니다.
  5. 만들어진 그래프를 확인합니다.
  6. '요금제별로 나눠 그려 달라'처럼 이어서 요청합니다.
예시
지난 3개월 동안 다크 모드를 쓰는 사용자 비율을 그래프로 그려 줘. 그다음 요금제별로 나눠서 다시 그려 줘.
  • SQL을 짜는 일보다 결과를 해석하는 일이 더 중요합니다.
  • 요청하지 않은 7일 이동평균 같은 요소가 덧붙을 수 있으니 그래프를 꼼꼼히 확인하세요.
  • Google Cloud에서는 BigQuery와 Looker를 MCP 툴박스로 연결할 수 있습니다.

9. 브라우저 검증 루프 만들기

Claude Code가 브라우저에서 앱을 직접 실행하고 클릭해 보면서, 변경한 기능이 의도대로 동작하는지 스스로 확인하고 고치게 하는 방법입니다. 사람이 하던 수동 확인 절차를 스킬로 만들어 두면 Claude가 더 오래 혼자 작업합니다.

  1. Claude Code에 포함된 verify 스킬로 프로젝트용 확인 절차 스킬을 만듭니다.
  2. 만들어진 스킬에 성능 측정(레이아웃 시프트 등)처럼 측정할 수 있는 확인 항목을 더합니다.
  3. 기능을 요청할 때 설계 문서(spec)가 있으면 읽도록 지정하고, Playwright MCP를 쓰라고 명시합니다.
  4. 구현 전에 Claude가 앱을 실행해 현재 화면을 확인하게 합니다.
  5. 파일 변경 권한 요청이 나오면 검토한 뒤 허용합니다.
  6. Claude가 수정과 검증을 반복한 뒤 내놓은 요약으로 변경 내용을 리뷰합니다.
  • 테스트·타입 검사·린터만으로는 변경이 의도대로 동작한다는 증명이 되지 않습니다. 실제 화면 확인 절차를 꼭 넣으세요.
  • 웹은 브라우저, 백엔드는 엔드포인트 호출, 모바일은 iOS 시뮬레이터로 확인 절차를 만들 수 있습니다.
  • 검증 기준을 측정할 수 있게 정할수록 Claude가 사람 손을 덜 거치고 진행합니다.
  • 예전 방식: 요청할 때마다 프롬프트에 Playwright MCP를 쓰라고 지정했습니다. 지금은 확인 절차를 스킬로 저장해 두고 반복해서 씁니다.

10. 클라우드에서 Claude 에이전트에 도구 붙이기

Microsoft Foundry나 Google Cloud에서 Claude 모델을 배포하고, 커넥터·MCP 도구를 붙여 회사용 AI 에이전트를 만드는 방법입니다. 보안·거버넌스와 데이터 보관 위치를 회사 클라우드 안에서 관리해야 할 때 씁니다.

  1. aka.ms/cloudworkshop 실습 페이지를 열어 제공된 실습 환경을 준비합니다.
  2. Microsoft Foundry에서 Claude 모델을 배포합니다.
  3. 배포한 모델을 에이전트에 연결합니다.
  4. 에이전트에 필요한 커넥터나 MCP 도구를 붙입니다.
  5. Google Cloud를 쓴다면 애플리케이션 기본 자격 증명(ADC)으로 Claude 사용을 설정합니다.
  6. 보안 검토를 거친 뒤 운영 환경에 배포합니다.
  • Foundry는 1,400개 이상의 내장 커넥터·MCP 도구를 지원하고, Defender·Purview·Entra ID와 연동되는 보안 기능이 있습니다.
  • Google Cloud에서는 토큰 단위로 과금되어 메시지 한도가 없고, 데이터가 내 프로젝트 안에 머뭅니다.
  • ADC로 설정하면 API 키를 교체할 필요가 없습니다.
  • 원본 영상 자막이 일부 없거나 끊겨 세부 절차가 확인되지 않았습니다. 화면별 설정은 실습 페이지와 영상에서 직접 확인하세요.
