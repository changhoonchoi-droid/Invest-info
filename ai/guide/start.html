Claude 시작하기

Claude 시작하기에서는 가입과 요금제 선택, 모델 고르기, 웹·데스크톱·모바일 앱의 기본 사용, 개인정보 설정까지 다룹니다. 먼저 가입하고 대화를 시작한 뒤 요금제와 모델을 고르고, 맥락을 알려 주는 습관과 데이터 설정을 챙기면 됩니다. 이후 웹 검색·딥 리서치와 코워크로 넓혀 가면 좋습니다.

가입·요금제·모델 선택·앱(웹/데스크톱/모바일) 기본 사용·설정 · 영상 31개 기반 · 2026-11-21 갱신

최근 바뀐 점

  • 11월 12일 유료 플랜의 Claude에 새 모델 Fable 5.2가 출시되어 모델 전환 메뉴에서 고를 수 있습니다.
  • Claude 모바일 앱에서 업무용·개인 계정에 로그아웃 없이 동시에 로그인해 전환할 수 있게 되었고, 앱이 총 33개 언어를 지원합니다.
  • 10월 8일부터 Docs·슬라이드·디자인이 무료 플랜까지 확대되었고, 9월 16일에는 채팅과 코워크가 하나로 합쳐졌습니다.
  • Claude 개인 금융 기능이 베타로 추가되었지만 현재는 미국의 Pro·Max·Ultra 플랜에만 순차 제공됩니다.

1. Claude 가입하고 첫 대화 시작하기

Claude는 웹, 데스크톱 앱, 모바일 앱에서 쓸 수 있는 AI 어시스턴트입니다. 구글 계정이나 이메일만 있으면 무료로 가입해 바로 질문할 수 있습니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 누릅니다.
  3. 필요하면 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다(무료 사용자도 가능).
  4. 질문창에 하고 싶은 일을 친구에게 말하듯 적습니다.
  5. 타이핑이 번거로우면 질문창의 마이크를 눌러 말로 질문합니다.
  6. 답이 마음에 들지 않으면 답을 보고 고쳐 달라고 이어서 요청합니다.
  • 질문을 완벽하게 만들려 하지 말고, 처음에는 답장 초안·일정 정리 같은 작은 일부터 시작합니다.
  • 마이크로 맥락을 충분히 말하면 타이핑보다 결과가 좋아질 수 있습니다.
  • 코워크는 데스크톱 앱에서만 쓸 수 있으니 설치해 두면 좋습니다.

2. 요금제 고르고 구독 시점 정하기

Claude는 무료, Pro, Max 요금제가 있습니다. 금액보다 쓰다가 사용 한도에 막히는지를 기준으로 올리면 낭비 없이 시작할 수 있습니다.

  1. 먼저 무료 플랜으로 일주일 정도 업무에 써 봅니다.
  2. 사용 한도에 막혀 일이 끊기는지 확인합니다.
  3. 막히지 않으면 무료를 계속 씁니다.
  4. 자주 막히면 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다.
  5. Pro도 모자라면 Max(월 100달러 또는 200달러)를 검토합니다.
  6. 유료로 올린 뒤 한 달 정도 써 보고, 시간·성과가 나는지 따져 계속할지 정합니다.
  • 무료 플랜은 Opus 이상을 쓸 수 없고, Pro는 무료의 약 5배 사용량입니다.
  • Max는 Pro의 5배(월 100달러)와 20배(월 200달러) 두 가지입니다.
  • 코워크·코드·디자인 중 코워크와 코드는 Pro 이상이 필요하다고 소개되지만, 요금제별 제공 범위는 바뀔 수 있으니 공식 요금제 안내에서 다시 확인하세요.
  • 예전 방식: 8월 영상에서는 코워크·코드·디자인이 모두 프로 플랜 이상이라고 했지만, 10월 8일부터 Docs·슬라이드·디자인은 무료 플랜까지 확대되었습니다.

3. 작업에 맞는 모델과 노력 수준 고르기

Claude는 Haiku, Sonnet, Opus, Fable 등 여러 모델이 있고, 모델마다 속도와 성능이 다릅니다. 작업 성격에 맞게 고르면 시간과 사용량을 아낄 수 있습니다.

  1. 질문창의 모델 선택(모델 전환) 메뉴를 엽니다.
  2. 메일 초안·요약 같은 일상 작업은 Sonnet을 고릅니다.
  3. 복잡하고 긴 작업은 유료 플랜에서 Opus나 Fable을 고릅니다.
  4. 최신 모델을 쓰려면 유료 플랜으로 접속해 모델 전환 메뉴에서 Fable 5.2를 선택합니다.
  5. 품질이 중요한 작업(슬라이드 등)은 노력(effort) 수준을 높여 돌려 봅니다.
  • 모델 단계가 높을수록 똑똑하지만 시간이 오래 걸리니 복잡한 업무에만 씁니다.
  • 공식 안내에 따르면 심층 조사 같은 열린 작업은 중간 effort로 시작해 올리고, 반복 작업은 Opus나 Sonnet이 알맞습니다.
  • 더 똑똑한 모델이 적은 단계로 끝내 총비용이 낮아지는 경우도 있습니다.
  • 예전 방식: 5월 영상에서는 모델을 Haiku·Sonnet·Opus 세 가지로 소개했지만, 지금은 Fable이 추가되었습니다.

4. 나를 알려 주고 맥락 쌓기

AI에게 나에 대한 정보(맥락)를 주면 답이 훨씬 내 상황에 맞아집니다. 첫날 인터뷰 형식으로 맥락을 쌓는 방법입니다.

  1. Claude 데스크톱 앱을 설치하고 폴더 접근을 허락합니다.
  2. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  3. "너는 뭘 할 수 있니?"라고 묻습니다.
  4. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  5. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시
내 폴더를 읽기만 하고 고치지는 말고, 어떤 일을 하는 사람인지 파악해서 한 문단으로 설명해 줘. 그다음 나에 대해 궁금한 걸 질문해 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 답이 의심되면 근거 자료를 요구하거나 다른 AI로 교차 검증합니다.

5. 웹 검색과 딥 리서치 켜기

웹 검색은 최신 정보를 출처와 함께 가져오고, 딥 리서치는 시장 조사처럼 깊은 조사를 맡길 때 씁니다. 모델은 훈련 시점 이후의 일을 검색 없이는 확실히 모르므로 최신 사실에는 검색을 켜는 편이 좋습니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 검색을 켭니다(영상 기준 웹 탭).
  3. 질문하면 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 리서치(딥 리서치) 모드를 켭니다.
  5. 또는 입력창에 /딥리서치 명령을 사용합니다.
  6. 조사할 주제와 원하는 결과 형태를 적어 요청합니다.
예시
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 비교하고, 가격과 장단점을 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 메뉴 이름은 버전에 따라 리서치와 연구로 달리 표기될 수 있습니다.

6. 개인정보·학습·메모리 설정 점검하기

회사 일에 쓰기 전에 대화가 어디에 저장되고 학습에 쓰이는지 설정을 확인해야 합니다. 메모리와 학습 사용 설정을 직접 점검하는 방법입니다.

  1. 계정이나 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 데이터 컨트롤 쪽에서 대화가 모델 개선에 쓰이는 항목을 끕니다.
  3. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  4. 메모리를 활용하려면 설정에서 채팅 검색·참조와 메모리 생성을 켭니다.
  5. 메일 문구 다듬기처럼 실명이 필요 없는 경우 자리표시자로 바꿔서 입력합니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 확인합니다.
  • 메뉴 이름과 위치는 영상마다 다르게 소개되니, 설정 안에서 데이터 컨트롤·개인정보 부근을 찾아보세요.
  • 메모리는 모델이 아니라 계정에 저장된 정보이며, 새 대화는 빈 상태로 시작합니다.
  • 정책은 제공사마다 다르니 개인정보 처리방침을 직접 확인합니다.

7. 모바일 앱 업데이트 활용하기

Claude 모바일 앱은 업무용과 개인 계정 전환, 음성 모드, 다국어 지원이 개선되었습니다. 휴대폰에서 바로 쓸 수 있는 변화를 정리했습니다.

  1. iOS 또는 Android 앱을 최신 버전으로 업데이트합니다.
  2. 업무용 계정과 개인 계정을 모두 로그인해 둡니다.
  3. 로그아웃하지 않고 계정을 전환해 용도별로 씁니다.
  4. 음성 모드로 말로 질문합니다.
  5. iPad에서는 아티팩트가 대화 옆 열에 열리므로 두 창을 나란히 놓고 씁니다.
  • iPhone에서는 음성 모드가 Apple CarPlay를 지원합니다.
  • 앱 인터페이스는 24개 언어가 추가돼 총 33개 언어를 지원합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공될 예정입니다.

8. 코워크로 폴더 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만들어 주는 기능입니다. 코딩 없이 파일 정리나 보고서 작성에 쓸 수 있습니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 설치합니다.
  2. 앱에서 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 맡길 작업을 설명하면 Claude가 먼저 계획을 제안합니다.
  6. 계획을 확인하고 승인한 뒤 실행합니다.
예시
다운로드 폴더의 파일을 문서·이미지·기타로 분류해 폴더별로 정리하고, 이름을 바꾸기 전에 변경 목록부터 보여 줘.
  • Claude는 파일을 변경하기 전에 권한을 요청합니다.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • Pro, Max, Team, Enterprise에서 제공됩니다.

9. 글로벌 인스트럭션으로 규칙 고정하기

글로벌 인스트럭션은 역할, 보고서 톤, 날짜 형식 같은 규칙을 한 번 적어 두면 이후 모든 코워크 작업에 적용되는 설정입니다. 매번 같은 말을 반복하지 않아도 됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 눌러 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누릅니다.
예시
나는 마케팅 팀 과장이다. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적고, 파일을 삭제하기 전에는 반드시 나에게 확인해 줘.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가합니다.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.
