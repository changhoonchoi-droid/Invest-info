Claude 시작하기

Claude를 처음 쓰는 직장인을 위해 첫 대화 시작, 모델·요금제 고르기, 웹 검색, 앱 선택, 모바일 앱 활용, 개인정보 설정까지 순서대로 정리했습니다. 먼저 AI에게 나를 알려 주며 시작하고, 요금제와 모델을 고른 뒤, 기능과 앱을 익히고, 회사 일에 쓰기 전에 데이터 설정을 점검하는 순서로 보시면 좋습니다.

가입·요금제·모델 선택·앱(웹/데스크톱/모바일) 기본 사용·설정 · 영상 14개 기반 · 2026-11-07 갱신

  • 모바일 앱 음성 모드가 더 빨라지고 iPhone에서 Apple CarPlay를 지원하며, 앱 인터페이스가 총 33개 언어로 늘었습니다.

1. Claude에게 나를 알려 주며 시작하기

AI는 나에 대한 맥락을 알수록 더 쓸모 있는 답을 줍니다. 첫날 나를 소개하고 인터뷰를 받게 하면, 이후 업무 도움의 품질이 달라집니다.

  1. Claude 데스크톱 앱을 설치합니다.
  2. 폴더 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  4. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 AI가 나를 얼마나 아는지 확인합니다.
  5. "너는 뭘 할 수 있니?"라고 물어 가능한 일을 확인합니다.
  6. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  7. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시
이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던지고, 답을 보고 고쳐 달라고 주고받습니다.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 처음에는 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시작합니다.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓습니다. 영상에서는 AI를 전혀 모르면 ChatGPT 앱의 보이스 모드로 말하듯 시작하라고도 권합니다.

2. 요금제와 구독 시점 정하기

AI 구독료의 기준은 금액이 아니라 쓰다가 한도에 막히는지 여부입니다. 무료로 시작해 불편해질 때 유료로 올리면 됩니다.

  1. 먼저 무료 플랜으로 업무에 써 봅니다.
  2. 사용 중 한도(리밋)에 자주 막히는지 확인합니다.
  3. 한도에 막히면 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다. 무료의 약 5배 사용량입니다.
  4. Pro로도 부족하면 Max(월 100달러는 Pro의 5배, 월 200달러는 Pro의 20배)를 검토합니다.
  5. 쓴 만큼 돈·시간·성과가 나는지 따져 계속 쓸지 판단합니다.
  • 무료 플랜에서는 Opus를 쓸 수 없습니다.
  • 코워크·코드·디자인은 Pro 이상에서 사용할 수 있습니다.
  • 코딩 작업이 많다면 토큰이 더 싼 Claude를, 이미지 생성이 필요하면 ChatGPT를 추천하는 의견도 있습니다.

3. 작업에 맞는 모델과 노력 수준 고르기

작업 비용은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 작업 성격에 맞게 고르면 품질과 비용을 모두 잡을 수 있습니다.

  1. 모델의 성격을 이해합니다: Haiku는 빠르고 가볍고, Sonnet은 균형형이며, Opus는 가장 강력합니다.
  2. 심층 조사처럼 열린 작업은 Fable 5.1을 medium effort로 시작합니다.
  3. 결과가 부족하면 effort를 올립니다.
  4. 요약이나 메일 초안 같은 반복 작업은 Opus나 Sonnet을 씁니다.
  5. 무료·Pro 플랜의 claude.ai와 Cowork 기본 모델은 Sonnet 4.6임을 알아 둡니다.
  • 더 똑똑한 모델은 적은 단계로 끝내 총비용이 낮아질 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고 캐시 읽기 비용이 75% 낮습니다.
  • 조직 관리자는 모델 권한, effort 상한, 기본값을 역할별로 설정할 수 있습니다.

4. 웹 검색과 딥 리서치 켜기

웹 검색을 켜면 Claude가 외부 자료를 찾아 출처 링크와 함께 답합니다. 시장 조사나 경쟁사 분석처럼 깊은 조사에는 딥 리서치를 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 조사 주제와 원하는 결과 형태를 적어 요청합니다.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 모델은 훈련 시점 이후의 사실을 검색 없이는 확실히 알지 못하므로 최신 정보는 검색을 켜고 묻습니다.

5. 채팅·코워크·코드·디자인 고르기

Claude에는 목적이 다른 네 도구가 있어 용도에 맞게 골라 쓰면 됩니다. 어떤 일에 어떤 도구를 쓸지 기준을 잡는 가이드입니다.

  1. 생각 정리와 데이터 패턴 분석은 채팅으로 합니다.
  2. 파일 정리와 엑셀·워드 보고서 작성은 코워크로 합니다.
  3. 웹사이트·앱 제작(대시보드 등)은 코드로 합니다.
  4. 발표 자료(슬라이드)는 디자인으로 만듭니다.
  5. 하나의 자료로 채팅 → 코워크 → 코드 → 디자인 순서로 이어 가며 연습해 봅니다.
  • 채팅은 무료로 쓸 수 있지만 코워크·코드·디자인은 Pro(월 20달러) 이상이 필요합니다.
  • 코워크는 코드와 같은 엔진을 쓰는 사무용 버전입니다.
  • 코워크는 데스크톱 앱에서만 쓸 수 있으니 설치를 권장합니다.

6. 코워크로 폴더 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만드는 기능입니다. 단계별 대화 대신 작업 전체를 맡길 때 씁니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 설치합니다. Pro, Max, Team, Enterprise에서 쓸 수 있습니다.
  2. 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 작업을 설명하고 Claude가 제안하는 계획을 확인합니다.
  6. 계획을 승인해 실행합니다.
  7. 파일 변경 전 권한 요청이 오면 내용을 확인하고 허용합니다.
예시
다운로드 폴더의 파일을 종류별로 정리하는 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 영수증 이미지로 경비 보고서 만들기, 운영 비용 데이터 시각화 같은 작업에 적합합니다.
  • 처음에는 macOS 전용이었으나 2월 중순 업데이트로 윈도우에서도 쓸 수 있습니다.

7. 코워크 글로벌 인스트럭션 설정하기

자주 쓰는 규칙을 한 번 적어 두면 매번 같은 말을 반복하지 않아도 됩니다. 코워크의 모든 작업에 공통으로 적용됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 눌러 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누릅니다.
예시
나는 마케팅팀 직장인이다. 보고서는 간결한 존댓말로 쓰고, 날짜는 2026-11-07 형식으로 쓴다. 파일을 삭제하기 전에는 반드시 나에게 확인한다.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하거나 프롬프트로 지침을 넣습니다.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.

8. 모바일 앱 설치하고 계정 전환하기

Claude 모바일 앱은 iOS와 Android에서 쓸 수 있으며, 최근 업데이트로 업무용과 개인 계정을 오가기 편해졌습니다. 이동 중 음성으로 쓰거나 태블릿에서 아티팩트를 나란히 볼 때 유용합니다.

  1. iOS 또는 Android에 Claude 앱을 설치합니다.
  2. 업무용 계정으로 로그인합니다.
  3. 개인 계정도 추가로 로그인합니다. 로그아웃 없이 전환할 수 있습니다.
  4. 음성 모드로 말로 질문해 봅니다.
  5. iPad나 iPhone Duo에서는 Claude가 만든 아티팩트가 대화 옆 열에 열리는지 확인합니다.
  • 앱 인터페이스는 총 33개 언어를 지원합니다.
  • iPhone에서는 Apple CarPlay에서 음성 모드를 쓸 수 있습니다.
  • iPhone에서 사진을 고르면 업로드 중에도 바로 채팅에 표시됩니다.
  • 당겨서 검색은 iPhone·iPad에 곧 제공될 예정이며, 웹과 데스크톱에는 이미 있습니다(Mac은 Command K).

9. 내 정보 설정 점검하고 통제하기

AI에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습으로 갈 수 있습니다. 회사 일에 쓰기 전에 설정을 점검하는 습관을 들이면 정보 유출 걱정을 줄일 수 있습니다.

  1. 설정에서 계정이나 개인정보(데이터 컨트롤) 쪽 메뉴로 들어갑니다.
  2. 메모리, 대화 기록, 연결된 앱, 학습 관련 토글을 확인합니다.
  3. 학습 관련 항목(영상 속 이름: Improve the model for everyone)이 보이면 끕니다.
  4. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  5. 정보를 공유하기 전에 대화, 저장 메모리, 향후 학습 중 어디에 쓰일지 생각합니다.
  6. 메일 문구 다듬기처럼 필요 없는 실명은 빼고 자리표시자로 바꿉니다.
  7. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 문서에서 데이터 처리 조건을 확인합니다.
  • 영상에서도 메뉴 위치와 이름이 정확하지 않을 수 있다고 했으니, 설정 안에서 데이터 컨트롤 부근을 직접 찾아보세요.
  • 모델은 대화 중에만 맥락을 갖고 새 대화는 빈 상태로 시작합니다. 메모리는 계정에 저장된 정보이며 제품에 따라 기본값이 켜짐일 수 있습니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 정책은 제공사마다 다르니 쓰는 도구의 개인정보 처리방침과 데이터 보관 설정을 직접 확인합니다.

10. AI 답변 검증하며 쓰기

AI는 다음 단어를 예측해 답을 생성하므로 틀린 내용을 자신 있게 말할 수 있습니다. 업무에 쓰려면 근거를 요구하고 교차 검증하는 습관이 필요합니다.

  1. 답이 의심되면 검증 가능한 근거 자료에 기반해 답하도록 요구합니다.
  2. 웹 검색을 켜고 출처 링크를 확인합니다.
  3. 중요한 내용은 다른 AI에게 같은 내용을 검증시킵니다.
  4. 정해진 답을 꺼내는 것이 아니라 생성하는 것이므로, 여러 버전을 요청해 비교합니다.
예시
방금 답변의 근거가 되는 자료와 출처를 알려 줘. 확인되지 않는 내용은 확인되지 않았다고 표시해 줘.
  • 영상에서는 Codex가 한 일을 Claude가 검증하는 식으로 서로 다른 AI를 교차 활용하는 예를 듭니다.
  • 모델은 훈련 시점 이후의 사실을 검색 도구 없이는 확실히 알지 못합니다.
