Claude 시작하기

Claude를 처음 쓰는 직장인이 가입하고, 요금제와 모델을 고르고, 웹·데스크톱·모바일 앱을 익힌 뒤 개인정보 설정까지 점검하는 순서로 정리했습니다. 먼저 가입과 첫 대화로 감을 잡고, 검색·프로젝트 같은 기본 기능과 코워크로 넓혀 가세요. 회사 일에 쓰기 전에는 마지막 두 가이드(데이터 설정, 모델·비용 선택)를 꼭 확인하세요.

가입·요금제·모델 선택·앱(웹/데스크톱/모바일) 기본 사용·설정 · 영상 18개 기반 · 2026-11-10 갱신

최근 바뀐 점

  • Claude 모바일 앱에서 업무용과 개인 계정에 로그아웃 없이 동시에 로그인해 전환할 수 있습니다(iOS·Android).
  • 모바일 앱 음성 모드가 더 빨라지고 iPhone에서 Apple CarPlay를 지원하며, 인터페이스 언어가 24개 늘어 총 33개가 됩니다.
  • iPad와 iPhone Duo에서는 아티팩트가 대화 옆 열에 열려 두 창을 나란히 쓸 수 있습니다.
  • 개인 금융(Personal Finance) 기능이 베타로 추가됐습니다. 현재 미국의 Pro, Max, Ultra 플랜에 순차 제공됩니다.

1. Claude 가입하고 첫 대화 시작하기

Claude를 처음 쓸 때 계정을 만들고 질문창에서 모델을 고르는 기본 흐름입니다. 무료로 시작해 불편함이 없는지 먼저 확인해 보는 단계입니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 질문창의 모델 선택에서 일상 작업용으로 Sonnet을 고릅니다.
  4. 궁금한 것을 친구에게 말하듯 입력하고 전송합니다.
  5. 답이 아쉬우면 완벽한 질문을 다시 만들기보다 "이 부분을 이렇게 고쳐 줘"라고 이어서 요청합니다.
  6. 타이핑이 번거로우면 질문창의 마이크를 눌러 말로 질문합니다.
예시
내가 하는 일과 오늘 해야 할 일을 설명할 테니, 우선순위를 정하는 걸 도와줘. 필요하면 먼저 나에게 질문해 줘.
  • 무료로 시작해 사용 한도에 자주 막힐 때 유료로 넘어가면 됩니다.
  • 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시킵니다.

2. 요금제와 모델 고르기

무료·Pro·Max 중 어떤 요금제를 쓸지, 어떤 모델을 쓸지 정하는 기준입니다. 금액보다 쓰다가 한도에 막히는지를 기준으로 판단하면 됩니다.

  1. 먼저 무료 플랜으로 업무에 써 보며 불편한 점이 있는지 확인합니다.
  2. 일상적인 질문과 문서 작업은 Sonnet을 고릅니다.
  3. 복잡한 작업이 많아 Opus 이상이 필요하면 유료 플랜으로 올립니다.
  4. 사용 한도에 자주 막히면 Pro를, 그래도 부족하면 Max를 검토합니다.
  5. 쓴 만큼 돈·시간·성과가 나는지 따져 구독을 유지할지 정합니다.
  • 영상 기준 Pro는 월 20달러(연간 결제 시 월 17달러, 국내 약 3만 원)로 몇 시간 단위 사용 제한이 있고, Max는 월 100달러·200달러 두 가지입니다.
  • 모델 단계가 높을수록 똑똑하지만 시간이 오래 걸리니 복잡한 업무에만 씁니다.
  • 코워크·코드·디자인은 Pro(월 20달러) 이상에서 쓸 수 있습니다.
  • 예전 방식: 모델을 Haiku·Sonnet·Opus 세 가지로 설명했으나, 최근 영상에서는 Fable까지 네 가지이며 Sonnet까지 무료라고 안내합니다. 요금제별 제공 모델은 가입 화면에서 확인하세요.

3. AI에게 나를 알려 주며 맥락 쌓기

AI에게 나에 대한 정보(맥락)를 주면 답이 훨씬 내 상황에 맞게 나옵니다. 첫날 몇 가지 질문으로 AI가 나를 파악하게 하는 방법입니다.

  1. Claude에 "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 현재 얼마나 아는지 확인합니다.
  2. "너는 뭘 할 수 있니?"라고 물어 가능한 일을 파악합니다.
  3. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받고 답합니다.
  4. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
  5. 추천받은 일 중 작은 것 하나부터 실제로 시켜 봅니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 봐. 한 번에 하나씩 물어보고, 내 답을 바탕으로 마지막에 나를 도와줄 수 있는 일을 정리해 줘.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 답이 의심스러우면 근거 자료를 가져오게 하고, 다른 AI로 교차 검증합니다.
  • 영상에서는 ChatGPT 보이스 모드로 시작하라고 했지만 같은 방식을 Claude에서 그대로 쓸 수 있습니다.

4. 웹 검색과 딥 리서치 켜기

Claude가 최신 정보를 검색하고 출처를 달아 답하게 하는 기능입니다. 시장 조사나 경쟁사 분석처럼 깊은 조사가 필요할 때 딥 리서치 모드를 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 조사할 주제와 원하는 결과 형태를 적어 요청합니다.
예시
국내 중소기업용 협업 툴 시장의 주요 경쟁사 3곳을 조사해서, 가격·핵심 기능·장단점을 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 모델은 훈련 시점 이후의 사실을 검색 없이는 확실히 알지 못하므로 최신 정보는 검색을 켜고 묻습니다.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.

5. 프로젝트·스킬·커넥터·아티팩트 이해하기

Claude 채팅을 업무에 맞게 확장하는 핵심 기능 네 가지입니다. 프로젝트는 업무 공간(맥락), 스킬은 반복 작업 양식, 커넥터는 Google Drive·Notion 같은 외부 도구 연결, 아티팩트는 화면 분할로 결과물을 만드는 기능입니다.

  1. 업무별로 프로젝트를 만들어 관련 대화와 맥락을 분리합니다.
  2. 반복되는 업무 양식이 있다면 스킬로 고정해 둡니다.
  3. 필요한 서비스(Google Drive, Notion 등)를 커넥터로 연결합니다.
  4. 문서·웹페이지 같은 결과물을 요청하면 화면이 나뉘어 열리는 아티팩트에서 결과를 확인합니다.
  5. 결과를 보며 "이 부분을 이렇게 바꿔 줘"라고 고쳐 달라고 합니다.
  • 프로젝트는 맥락, 스킬은 작업 방식, 커넥터는 외부 도구, 코워크는 실행을 맡는다고 구분하면 쉽습니다.
  • 메모리 기능은 2026년 3월 무료 사용자까지 확대됐습니다.
  • 구체적인 메뉴 위치는 영상에서 자세히 다루지 않았으니 실제 화면에서 확인하세요.

6. 데스크톱 앱 설치하고 폴더 열어 주기

데스크톱 앱을 쓰면 컴퓨터 속 파일을 Claude에게 보여 주고 내 프로젝트를 파악하게 할 수 있습니다. 코워크 같은 기능은 데스크톱 앱에서만 쓸 수 있습니다.

  1. Claude 사이트 아래쪽의 데스크톱 앱 다운로드로 앱을 설치합니다(무료 사용자도 가능).
  2. 앱에 로그인합니다.
  3. Claude가 볼 폴더 접근을 허락합니다.
  4. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청합니다.
  5. 파악한 내용을 확인하고 틀린 부분을 바로잡아 줍니다.
예시
이 폴더의 파일을 읽기만 하고 절대 수정하거나 삭제하지 마. 내가 어떤 일을 하는 사람인지, 어떤 프로젝트가 있는지 정리해 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 코워크는 데스크톱 앱에서만 쓸 수 있으니 설치를 권장합니다.

7. 코워크로 폴더 업무 맡기기

코워크는 단계별 대화 대신 작업 전체를 맡기는 방식입니다. 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만듭니다.

  1. Pro 이상 요금제로 macOS 또는 Windows용 Claude 데스크톱 앱을 준비합니다.
  2. 앱의 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 작업을 설명하면 Claude가 먼저 제안하는 계획을 읽어 봅니다.
  6. 계획이 맞으면 승인해 실행시키고 결과물을 확인합니다.
예시
다운로드 폴더의 파일을 종류별로 정리할 계획을 먼저 세워 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • Claude는 파일을 바꾸기 전에 권한을 요청합니다.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 예전 방식: 코워크는 처음 macOS 전용이었고 Pro 등 일부 사용자에게만 열렸지만, 현재는 Windows에서도 쓸 수 있고 Pro, Max, Team, Enterprise에 정식 제공됩니다.
  • 코워크는 Claude Code와 같은 엔진을 쓰는 사무용 버전이라 문서·파일 업무에 맞습니다.

8. 코워크 글로벌 인스트럭션 설정하기

매번 같은 말을 반복하지 않도록 역할, 보고서 톤, 날짜 형식 같은 규칙을 한 번에 저장해 두는 설정입니다. 저장하면 이후 모든 코워크 작업에 적용됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 누릅니다.
  4. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  5. 저장을 누릅니다.
예시

10. 내 대화 데이터와 메모리 설정 점검하기

입력한 정보가 대화, 메모리, 제공사 시스템, 모델 학습 중 어디로 갈 수 있는지 알고 설정을 점검하는 방법입니다. 회사 일에 쓰기 전에 꼭 확인해야 합니다.

  1. 계정이나 개인정보 설정을 엽니다.
  2. 메모리, 대화 기록, 연결된 앱, 학습 토글을 하나씩 확인합니다.
  3. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  4. 모델 학습에 쓰이지 않도록 학습 관련 항목(Improve the model for everyone 등)을 끕니다.
  5. 정보를 넣기 전에 실명 같은 불필요한 정보는 자리표시자로 바꿉니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 문서에서 확인합니다.
  • 영상에서 메뉴 위치와 이름을 정확히 짚지 않았으니, 설정 안에서 데이터 컨트롤 부근을 찾아보세요.
  • 모델은 대화 중에만 맥락을 갖고 새 대화는 빈 상태로 시작합니다. 메모리는 계정에 저장된 정보입니다.
  • 정책은 제공사마다 다르니 개인정보 처리방침과 데이터 보관 설정을 직접 확인하세요.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.

11. 작업에 맞는 모델과 노력 수준 고르기

작업 비용은 모델, effort(추론 노력), 캐시로 정해집니다. 작업 성격에 따라 모델과 effort를 달리하면 같은 결과를 더 적은 비용으로 얻을 수 있습니다.

  1. 심층 조사처럼 열린 작업은 Fable 5.1을 medium effort로 시작합니다.
  2. 결과가 부족하면 effort를 한 단계씩 올립니다.
  3. 요약이나 메일 초안 같은 반복 작업은 Opus나 Sonnet을 씁니다.
  4. 조직 관리자는 모델 권한, effort 상한, 기본값으로 역할별 설정을 정합니다.
  • 더 똑똑한 모델은 적은 단계로 끝내 총비용이 낮아질 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고 캐시 읽기 비용이 75% 낮습니다.
  • 긴 열린 작업이 많은 역할은 Fable 5.1을 기본으로, 반복 작업이 많은 역할은 Opus·Sonnet을 기본으로 하고 Fable은 권한만 열어 둡니다.
