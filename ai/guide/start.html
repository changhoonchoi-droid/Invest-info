Claude 시작하기

Claude를 처음 쓰는 직장인이 가입부터 모델·요금제 선택, 데스크톱·모바일 앱 사용, 개인정보 설정, 메모리·프로젝트·코워크 같은 업무 기능까지 따라 할 수 있도록 정리했습니다. 먼저 가입하고 AI에게 나를 알려 주는 입문 가이드로 감을 잡은 뒤, 요금제와 모델 고르기, 데이터 설정을 확인하고, 마지막에 웹 검색·딥 리서치·코워크 같은 응용 기능으로 넘어가 보세요.

최근 바뀐 점

  • Fable 5.2가 유료 플랜에 출시되어 모델 전환 메뉴에서 선택할 수 있습니다(11월 12일 영상 기준).
  • Docs·슬라이드·디자인 기능이 10월 8일부터 무료 플랜까지 확대되었고, 9월 16일에 채팅과 코워크가 하나로 합쳐졌다고 합니다(11월 15일 영상 기준).
  • 모바일 앱에서 업무용·개인 계정에 로그아웃 없이 동시에 로그인해 전환할 수 있고, 앱 인터페이스가 총 33개 언어를 지원합니다(10월 29일 영상 기준).
  • 개인 금융 기능이 미국의 Pro·Max·Ultra 요금제에 베타로 순차 제공됩니다(국내 제공 여부는 확인되지 않았습니다).

1. Claude 가입하고 첫 질문하기

Claude 사이트에서 계정을 만들고 첫 질문을 던지는 가장 기본 단계입니다. 설치 없이 웹에서 바로 시작할 수 있고, 말로 질문하면 타이핑 부담이 줄어듭니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 누릅니다.
  3. 질문창 모델 선택에서 기본 작업은 Sonnet을 고릅니다.
  4. 질문창의 마이크를 눌러 말로 질문합니다.
  5. 답을 보고 "더 짧게 고쳐 줘"처럼 고쳐 달라고 이어서 요청합니다.
예시
내일 팀 회의에서 쓸 공지 메일 초안을 써 줘. 일정은 오후 3시이고, 말투는 정중하게 부탁해.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤 답을 보고 고쳐 달라고 하면 됩니다.
  • 처음에는 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시작합니다.
  • 타이핑 대신 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.

2. AI에게 나를 알려 주며 시작하기

AI에게 내 상황과 맥락을 알려 주면 답의 품질이 크게 달라집니다. 첫날 AI에게 인터뷰를 받게 하는 방식으로 맥락을 쌓는 방법입니다.

  1. AI를 전혀 모르면 ChatGPT 앱의 보이스 모드로 음성 대화를 시작합니다.
  2. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 AI가 나를 얼마나 아는지 확인합니다.
  3. 조금 써 봤다면 Claude 데스크톱 앱을 설치하고 폴더 접근을 허락합니다.
  4. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  6. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 봐. 그다음에 이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 답이 의심되면 근거 자료를 요구하거나 다른 AI로 교차 검증합니다.

3. 요금제 고르고 모델 선택하기

무료로 시작해 한도에 막힐 때 유료로 올리는 것이 기본 기준입니다. 모델마다 속도와 성능이 달라 작업에 맞게 골라 쓰면 사용량도 아낄 수 있습니다.

  1. 먼저 무료 플랜으로 업무에 써 보면서 한도에 막히는지 확인합니다.
  2. 자주 막히면 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다. 영상에 따르면 무료의 약 5배 사용량입니다.
  3. 사용량이 더 필요하면 Max(월 100달러 또는 200달러)를 검토합니다.
  4. 질문창의 모델 선택 메뉴를 엽니다.
  5. 일상 작업은 Sonnet, 복잡한 작업은 Opus 이상을 고릅니다.
  6. 유료 플랜이라면 모델 전환 메뉴에서 Fable 5.2를 선택해 품질이 중요한 작업에 써 봅니다.
  • 구독 기준은 금액이 아니라 쓰다가 한도에 막히는지, 쓴 만큼 돈·시간·성과가 나는지입니다.
  • 무료 플랜은 Opus를 쓸 수 없습니다. 영상에 따라 무료 범위 설명이 조금 다르니 앱 안의 요금제 화면을 확인하세요.
  • 슬라이드처럼 품질이 중요한 작업은 높은 노력 수준으로 돌리면 더 좋았다고 합니다(영상에서는 extra 설정).
  • 요약이나 메일 초안 같은 반복 작업은 Opus나 Sonnet, 심층 조사 같은 열린 작업은 Fable로 나눠 쓰는 것이 영상 권고입니다.
  • 예전 방식: 2026년 5월 영상에서는 모델을 Haiku·Sonnet·Opus 세 가지로 소개했으나, 이후 영상에서 Fable이 추가되어 네 가지입니다.

4. 대화가 학습에 쓰이지 않게 설정하기

회사 일에 AI를 쓰기 전에 대화가 모델 학습에 쓰이는지 확인하고 끄는 설정입니다. 메모리와 연결된 앱까지 함께 점검하면 내 정보 통제력을 지킬 수 있습니다.

  1. 계정이나 개인정보 설정에서 데이터 컨트롤 부근 메뉴를 찾습니다.
  2. 모델 학습에 대화를 쓰는 항목(영상에서는 Improve the model for everyone)을 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 설정을 함께 확인합니다.
  4. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  5. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 문서에서 데이터 처리 조건을 확인합니다.
  • 영상에서 메뉴 위치와 이름을 정확히 기억하지 못한다고 했으니, 설정 안에서 데이터 컨트롤 부근을 직접 찾아보세요. 영상은 ChatGPT 기준 설명이어서 Claude 화면의 항목 이름은 다를 수 있습니다.
  • 메일 문구 다듬기처럼 필요 없는 실명은 빼고 자리표시자로 바꿔 입력합니다.
  • 모델은 대화 안에서만 맥락을 갖고 새 대화는 빈 상태로 시작합니다. 기억처럼 보이는 것은 계정에 저장된 메모리입니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있다고 합니다.

5. 웹 검색과 딥 리서치 켜기

모델이 학습한 시점 이후의 정보는 검색 도구 없이는 알 수 없습니다. 웹 검색을 켜면 출처 링크와 함께 최신 정보를 받고, 딥 리서치는 시장 조사처럼 깊은 조사에 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구(최신 영상에서는 리서치)를 눌러 딥 리서치 모드를 켭니다.
  5. 조사 목적과 범위를 적어 요청합니다.
예시
국내 중소기업용 협업 툴 시장을 조사해 줘. 주요 제품 5개의 가격, 장단점, 도입 사례를 표로 정리하고 출처를 달아 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 최신 영상(11월)에서는 /딥리서치 명령으로도 실행한다고 설명합니다.
  • 예전 방식: 5월 영상에서는 + 버튼의 연구 메뉴로 딥 리서치를 켰습니다.

6. 모바일 앱 설치하고 활용하기

Claude 모바일 앱으로 이동 중에도 질문하고 음성으로 대화할 수 있습니다. 최근 업데이트로 계정 전환과 음성 모드가 편해졌습니다.

  1. iOS 또는 Android 앱 스토어에서 Claude 앱을 설치합니다.
  2. 가입한 계정으로 로그인합니다.
  3. 업무용과 개인 계정이 따로 있다면 두 계정을 모두 로그인해 두고 로그아웃 없이 전환합니다.
  4. 음성 모드로 말하듯 질문합니다.
  5. iPad나 iPhone Duo에서는 Claude가 만든 아티팩트를 대화 옆 열에 열어 두 창을 나란히 씁니다.
  • 앱 인터페이스는 총 33개 언어를 지원합니다.
  • iPhone에서는 음성 모드가 Apple CarPlay를 지원합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공 예정이며, 웹과 데스크톱에는 이미 있습니다(Mac은 Command K).
  • 계정 동시 로그인 등 최신 기능은 앱 버전에 따라 다를 수 있으니 앱을 최신으로 업데이트하세요.

7. 채팅·코워크·코드·디자인 골라 쓰기

Claude에는 목적이 겹치지 않는 네 가지 도구가 있어 일에 맞게 고르면 됩니다. 이 기준을 알면 어떤 도구를 열어야 할지 헷갈리지 않습니다.

  1. 생각 정리와 데이터 패턴 분석은 채팅에서 합니다.
  2. 파일 정리와 엑셀·워드 보고서 작성은 코워크에서 합니다.
  3. 웹사이트나 앱 제작은 코드에서 합니다.
  4. 발표 자료는 디자인에서 만듭니다.
  5. 하나의 자료(예: 고객 설문 데이터)를 채팅 → 코워크 → 코드 → 디자인 순으로 넘기며 써 봅니다.
예시
첨부한 고객 설문 데이터에서 눈에 띄는 패턴 3가지를 찾아 줘.
  • 채팅은 무료로 쓸 수 있지만, 영상(8월) 기준 코워크·코드·디자인은 프로 플랜(월 20달러) 이상이 필요하다고 했습니다.
  • 예전 방식: 8월 영상은 코워크·코드·디자인이 유료 전용이라고 했지만, 11월 영상에서는 Docs·슬라이드·디자인이 10월 8일부터 무료 플랜까지 확대되었다고 합니다.
  • 9월 16일 채팅과 코워크가 하나로 합쳐졌다고 하니, 화면 구성이 영상과 다를 수 있습니다.
  • 코워크는 코드와 같은 엔진을 쓰는 사무용 버전입니다.

8. 코워크로 폴더 업무 맡기기

코워크는 폴더 접근을 허용하면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만드는 기능입니다. 다운로드 폴더 정리, 영수증으로 경비 보고서 만들기 같은 반복 업무에 맞습니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 설치합니다(Pro, Max, Team, Enterprise 대상).
  2. 데스크톱 앱에서 코워크를 엽니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. Google Drive·Notion·Slack 같은 서비스가 필요하면 커넥터를 연결합니다.
  5. 작업을 구체적으로 설명하고 Claude가 제안하는 계획을 확인한 뒤 승인합니다.
  6. 파일을 바꾸기 전에 뜨는 권한 요청을 확인하고 결과물을 검토합니다.
예시
다운로드 폴더의 파일을 문서·이미지·기타로 분류해 폴더로 나누고, 실행 전에 이동 계획부터 보여 줘. 삭제는 하지 마.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • Claude는 파일 변경 전에 권한을 요청합니다.
  • 처음에는 중요하지 않은 폴더로 시험해 보세요.
  • 예전 방식: 코워크는 처음 macOS 전용이었으나 2월 중순부터 Windows에서도 쓸 수 있습니다.

9. 글로벌 인스트럭션으로 반복 지시 줄이기

역할, 보고서 톤, 날짜 형식 같은 규칙을 한 번 적어 두면 이후 코워크 작업에 모두 적용됩니다. 매번 같은 말을 반복하지 않아도 됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 눌러 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누릅니다.
예시
나는 마케팅 팀 과장이다. 보고서는 존댓말 개조식으로, 날짜는 YYYY-MM-DD 형식으로 쓴다. 파일을 삭제하기 전에는 반드시 나에게 확인한다.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하거나 프롬프트로 지침을 넣습니다.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다. 2월 영상 기준이라 최근 업데이트로 메뉴가 바뀌었을 수 있습니다.
