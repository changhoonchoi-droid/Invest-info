1. 무료로 시작해 요금제 고르기

Claude는 무료 플랜으로 채팅을 바로 써 볼 수 있고, 더 많이 쓰거나 Cowork·Code·Design 같은 도구가 필요할 때 유료 플랜으로 넘어가면 됩니다. 처음부터 결제하기보다 써 보면서 한도에 막히는 시점을 기준으로 정하는 것이 좋습니다.

  1. 무료 플랜으로 가입해 claude.ai에서 채팅을 먼저 써 봅니다.
  2. 매일 조금씩 쓰면서 사용 한도(리밋)에 자주 걸리는지 확인합니다.
  3. 한도에 자주 막히거나 파일·문서 작업을 맡기고 싶어지면 Pro 플랜(월 20달러부터)으로 올립니다.
  4. Cowork·Code·Design을 쓰려면 Pro 이상 플랜인지 확인합니다.
  5. 회사 기밀이나 규제 대상 데이터를 다룬다면 Team·Enterprise 같은 조직용 플랜을 검토합니다.
  • Free·Pro 플랜의 claude.ai와 Cowork 기본 모델은 Sonnet 4.6입니다(2026년 2월 기준).
  • Cowork는 macOS·Windows용 Claude 데스크톱 앱에서 Pro, Max, Team, Enterprise 사용자에게 제공됩니다.
  • 조직이 Claude를 도입하면 모델 학습 사용은 기본적으로 꺼져 있습니다.

2. 첫 대화로 Claude에게 나 알려 주기

AI는 나에 대한 맥락을 많이 알수록 쓸모 있는 답을 줍니다. 첫날 몇 가지 질문으로 Claude가 나를 파악하게 하면 이후 업무 요청의 품질이 올라갑니다.

  1. Claude에게 "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 지금 얼마나 아는지 확인합니다.
  2. 조금 써 봤다면 Claude 데스크톱 앱을 설치하고 작업 폴더 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 업무·프로젝트 맥락을 파악시킵니다.
  4. "너는 뭘 할 수 있니?"라고 물어 Claude가 할 수 있는 일을 확인합니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 하고 질문에 답해 줍니다.
  6. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 물어 활용 아이디어를 받습니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 봐
  • 질문을 완벽하게 다듬으려 하지 말고 친구에게 말하듯 던진 뒤, 답을 보고 고쳐 달라고 주고받으세요.
  • 폴더 접근을 허락할 때는 "파일은 읽기만 하고 고치지 마"라고 먼저 지시하는 것이 안전합니다.
  • 하루 30분, 매일 Claude에게 질문하고 Claude가 나에게 질문하게 하는 습관을 들이면 빨리 익숙해집니다.
  • AI가 처음이라 말로 하는 게 편하면 음성 모드로 대화를 시작해도 됩니다.

3. 대화 학습 끄고 개인정보 지키기

Claude에 입력한 정보는 대화, 계정 메모리, 제공사 시스템, 향후 모델 학습에 쓰일 수 있습니다. 회사 일에 쓰기 전에 학습 사용 설정을 끄고 메모리를 점검해 두면 정보 유출 걱정을 줄일 수 있습니다.

  1. Settings(설정)로 들어가 데이터 컨트롤 관련 메뉴를 찾습니다.
  2. Improve the model for everyone 항목을 찾아 끕니다.
  3. 개인정보 설정에서 메모리, 대화 기록, 연결된 앱 항목도 함께 확인합니다.
  4. 저장된 메모리 중 틀리거나 불필요한 것은 고치거나 지우고, 필요 없으면 메모리 자체를 끕니다.
  5. 정보를 입력하기 전에 이 내용이 대화·메모리·학습 중 어디에 쓰일지 한 번 생각합니다.
  6. 메일 문구 다듬기처럼 실명이 필요 없는 작업은 이름을 자리표시자(예: 홍길동 → [고객명])로 바꿔 입력합니다.
  • 영상에서도 정확한 메뉴 위치는 기억이 분명치 않다고 했으니, 설정 안의 데이터 컨트롤 부근을 찾아보세요.
  • 모델은 대화 안에서만 맥락을 기억하고 새 대화는 빈 상태로 시작합니다. 대화를 넘어 기억하는 것은 계정에 저장된 메모리입니다.
  • 메모리는 제품에 따라 기본값이 켜짐일 수 있으니 직접 확인하세요.
  • 기밀·규제 데이터는 Team·Enterprise 같은 조직용 플랜을 쓰고 데이터 처리 조건을 문서로 확인합니다.

4. Claude 답이 맞는지 검증하기

Claude는 학습한 내용을 바탕으로 답을 한 단어씩 생성하기 때문에 틀린 내용도 자신 있게 말할 수 있습니다. 근거를 요구하고 다른 AI로 교차 확인하는 습관을 들이면 업무에 안심하고 쓸 수 있습니다.

  1. 질문할 때 검증 가능한 자료에 근거해 답하고 출처를 함께 달라고 요청합니다.
  2. 최신 정보가 필요한 질문이면 입력창의 플러스 버튼에서 웹 검색을 켭니다.
  3. 받은 답과 출처를 다른 AI에 넣어 맞는지 검증시킵니다.
  4. 답이 마음에 들지 않으면 같은 요청으로 다른 버전을 여러 개 받아 비교합니다.
예시
검증 가능한 자료에 근거해서만 답해 줘. 각 주장마다 출처 링크를 붙이고, 확실하지 않은 내용은 확실하지 않다고 표시해 줘.
  • 모델은 훈련 시점 이후의 사실을 검색 도구 없이는 확실히 알지 못합니다.
  • 정해진 답을 꺼내는 게 아니라 새로 생성하는 것이라 같은 질문에도 매번 답이 달라질 수 있습니다.
  • 다른 AI가 한 작업을 Claude에게 검증시키는 것처럼, 서로 다른 AI끼리 교차 확인하면 효과적입니다.

5. 채팅·코워크·코드·디자인 골라 쓰기

Claude에는 채팅, 코워크(Cowork), 코드(Code), 디자인(Design) 네 가지 도구가 있고 목적이 겹치지 않습니다. 하려는 일에 맞는 도구를 고르면 같은 자료로도 분석부터 보고서·대시보드·발표 자료까지 이어서 만들 수 있습니다.

  1. 생각 정리·질문·데이터 패턴 분석처럼 대화로 할 일은 채팅을 씁니다.
  2. 엑셀·워드 보고서 작성이나 폴더 정리처럼 파일을 다루는 일은 코워크를 씁니다.
  3. 대시보드 웹사이트나 앱을 만드는 일은 코드를 씁니다.
  4. 발표 슬라이드처럼 보여 주는 자료는 디자인으로 마무리합니다.
  5. 채팅에서 외부 자료가 필요하면 플러스 버튼에서 웹 검색을 켜 출처와 함께 답을 받습니다.
  • 채팅은 무료로 쓸 수 있지만 코워크·코드·디자인은 Pro 플랜(월 20달러) 이상이 필요합니다.
  • 코워크는 클로드 코드와 같은 엔진을 쓰는, 문서·파일 업무에 맞춘 사무용 버전입니다.
  • 한 가지 자료(예: 고객 설문)로 채팅 분석 → 코워크 보고서 → 코드 대시보드 → 디자인 슬라이드 순으로 이어 가면 흐름을 익히기 좋습니다.

6. 작업에 맞는 모델과 effort 고르기

작업 비용과 품질은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 열린 조사 작업과 반복 작업에 맞는 모델을 따로 고르면 비용을 줄이면서 결과도 좋게 얻을 수 있습니다.

  1. 맡길 일이 심층 조사처럼 답이 열린 작업인지, 요약·메일 초안처럼 반복 작업인지 먼저 구분합니다.
  2. 열린 작업은 Fable 5.1을 medium effort로 시작합니다.
  3. 결과가 부족하면 effort를 한 단계씩 올려 다시 시킵니다.
  4. 요약·메일 초안 같은 반복 작업은 Opus나 Sonnet을 씁니다.
  5. 긴 문서를 다뤄야 하면 컨텍스트 윈도우가 큰 모델(Sonnet 4.6은 100만 토큰 베타)을 고려합니다.
  • 더 똑똑한 모델은 적은 단계로 일을 끝내 오히려 총비용이 낮아질 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같지만 캐시 읽기 비용이 75% 낮아, 일반 작업은 약 25%, 긴 에이전트 작업은 최대 약 45% 비용이 줄어듭니다.
  • 벤치마크에서 Fable 5.1 medium은 Fable 5 max와 비슷한 결과를 약 5분의 1 비용으로 냈습니다.
  • 예전 방식: Free·Pro 플랜은 Sonnet 4.6이 기본 모델이며(2026년 2월), 지금은 작업 성격에 따라 Fable 5.1·Opus·Sonnet을 나눠 쓰는 것이 권장됩니다.

Claude 모바일 앱(iOS·Android)으로 이동 중에도 대화·음성·사진 업로드를 할 수 있습니다. 최근 업데이트로 업무·개인 계정 동시 로그인, iPad 나란히 보기, CarPlay 음성 모드 등이 추가되었습니다.

  1. iPhone·iPad는 App Store, Android는 Play 스토어에서 Claude 앱을 설치합니다.
  2. 업무용 계정과 개인 계정에 모두 로그인해 두고, 로그아웃 없이 필요할 때 전환합니다.
  3. iPad 등 큰 화면에서는 Claude가 만든 아티팩트를 대화 옆 열에 열어 나란히 봅니다.
  4. 운전·이동 중에는 음성 모드로 말로 대화하고, iPhone은 Apple CarPlay에서도 씁니다.
  5. 사진을 골라 올리면 업로드 중에도 채팅에 바로 표시되니 이어서 질문합니다.
  6. 지난 대화를 찾을 때 웹·데스크톱에서는 검색을 쓰고, Mac에서는 Command K를 누릅니다.
  • 앱 화면은 총 33개 언어를 지원해 한국어로 쓸 수 있습니다.

  • iPhone·iPad의 당겨서 검색은 곧 제공될 예정입니다.

8. Cowork로 파일 작업 통째로 맡기기

Cowork는 단계마다 대화하는 대신 작업 전체를 맡기는 방식으로, 내 컴퓨터 파일과 Google Drive·Notion·Slack 같은 서비스, Chrome 브라우저까지 다룹니다. 폴더 정리, 보고서 작성처럼 여러 파일을 오가는 사무 업무에 적합합니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 설치하고 Pro 이상 계정으로 로그인합니다.
  2. Cowork에서 작업할 폴더(예: 다운로드 폴더) 접근을 허용합니다.
  3. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  4. 맡길 작업을 한 번에 설명합니다.
  5. Claude가 먼저 제안한 계획을 읽고 괜찮으면 승인합니다.
  6. 파일을 바꾸기 전 권한 요청이 뜨면 내용을 확인하고 허용합니다.

9. 관리자로 조직 모델 기본값 정하기

회사에서 Claude를 도입했다면 관리자가 직원이 쓸 수 있는 모델, 모델별 effort 상한, 새 대화의 기본 모델을 정할 수 있습니다. 역할별로 다르게 설정해 비용과 품질의 균형을 맞춥니다.

  1. 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)으로 모델별 최대 effort를 정합니다.
  3. 기본값(defaults)으로 새 대화가 시작될 때의 모델과 effort를 정합니다.
  4. 긴 조사·분석이 많은 역할은 Fable 5.1을 기본으로 하고 effort 상한을 검토합니다.
  5. 요약·메일 같은 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 두고 Fable은 권한만 열어 둡니다.
  • 이 설정들은 역할별로 따로 정할 수 있습니다.
  • 조직이 Claude를 도입하면 모델 학습 사용은 기본적으로 꺼져 있습니다.
