Claude 시작하기

Claude를 처음 쓰는 직장인이 가입부터 모델·요금제 선택, 앱 설치, 기본 기능, 개인정보 설정까지 따라 할 수 있도록 정리했습니다. 먼저 가입과 첫 대화로 익숙해진 뒤, 요금제와 모델을 고르고, 웹 검색·메모리 같은 기본 기능과 데스크톱·모바일 앱, 정보 보호 설정 순서로 보시면 좋습니다.

1. Claude 가입하고 첫 대화 시작하기

구글 계정이나 이메일로 Claude에 가입하고 첫 질문을 던지는 방법입니다. 무료로 시작해 써 본 뒤 한도에 막힐 때 유료로 넘어가면 됩니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 누릅니다.
  3. 질문창에서 모델 선택 메뉴를 열어 기본 작업용으로 Sonnet을 고릅니다.
  4. 질문창의 마이크를 눌러 말로 질문합니다. 맥락을 충분히 말할수록 결과가 좋아집니다.
  5. 답을 보고 "더 짧게", "표로 바꿔 줘"처럼 고쳐 달라고 이어서 요청합니다.
예시
나에 대해 아는 것을 한 문단으로 설명해 봐. 그리고 나에 대해 궁금한 것을 100개까지 물어봐 줘.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던지세요.
  • 처음에는 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시작하세요.
  • 답이 의심되면 근거 자료를 요구하거나 다른 AI로 교차 검증하세요.

2. 요금제 고르기: 무료에서 유료로

무료·Pro·Max 중 무엇을 쓸지 정하는 기준입니다. 금액보다 쓰다가 한도에 막히는지가 기준입니다.

  1. 먼저 무료 플랜으로 업무에 써 봅니다.
  2. 사용 한도에 자주 막히는지 확인합니다.
  3. 막히면 Pro로 올리고, 쓴 만큼 돈·시간·성과가 나는지 따져 봅니다.
  4. Pro로도 부족할 때만 Max를 검토합니다.
  • 영상 기준 Pro는 월 20달러(연간 결제 시 월 17달러)로 무료의 약 5배 사용량이며, 몇 시간 단위 사용 제한이 있습니다.
  • Max는 월 100달러(Pro의 5배)와 200달러(Pro의 20배) 두 가지입니다.
  • 코워크·코드·디자인은 Pro 이상이 필요합니다. 채팅은 무료로 쓸 수 있습니다.
  • 가격은 영상마다 표기가 달라(원화 약 3만 원 등) 가입 화면에서 최종 확인하세요.

3. 작업에 맞는 모델과 노력 수준 고르기

Claude의 여러 모델 중 작업에 맞는 것을 고르는 방법입니다. 더 똑똑한 모델이 적은 단계로 끝내 총비용이 낮아질 수도 있습니다.

  1. 질문창의 모델 전환(model switcher) 메뉴를 엽니다.
  2. 요약·메일 초안 같은 반복 작업은 Sonnet이나 Opus를 고릅니다.
  3. 심층 조사처럼 열린 작업은 최신 상위 모델을 고르고 노력(effort) 수준을 중간부터 시작해 올립니다.
  4. 유료 플랜이면 Fable 5.2를 선택해 슬라이드처럼 품질이 중요한 작업에 써 봅니다.
  5. 결과가 부족하면 노력 수준을 높여 다시 돌립니다.
  • 작업 비용은 모델, effort, 캐시 세 가지로 정해집니다.
  • Fable 5.2는 Opus 5.5보다 비싸지만 더 빠르게 끝난 사례가 있었습니다.
  • 슬라이드는 높은 노력 수준(영상에서는 extra)으로 돌리면 더 좋았다고 합니다.
  • 예전 방식: Sonnet까지 무료이고 Opus 이상은 유료입니다. 이 구분은 7월 영상 기준이니 현재 화면에서 확인하세요.

4. 웹 검색과 딥 리서치 켜기

최신 정보를 출처와 함께 받거나 깊은 조사를 맡길 때 쓰는 기능입니다. 시장 조사, 경쟁사 분석 등에 유용합니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 프롬프트를 작성해 요청합니다.
예시
국내 중소기업용 협업 툴 시장의 주요 서비스 5개를 가격, 장단점, 도입 사례 기준으로 비교해 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 모델은 훈련 시점 이후의 사실을 검색 없이는 확실히 알지 못합니다.
  • AI는 틀린 내용을 자신 있게 말할 수 있으니 출처를 확인하세요.

5. 프로젝트·스킬·커넥터로 업무 환경 만들기

반복 업무를 편하게 하는 기능 묶음입니다. 프로젝트는 맥락을, 스킬은 작업 방식을, 커넥터는 외부 도구 연결을 맡습니다. 결과물은 아티팩트로 화면 옆에 바로 확인합니다.

  1. 업무 공간을 나누고 싶을 때 프로젝트를 만들어 관련 맥락을 넣습니다.
  2. 반복 업무 양식을 고정하고 싶으면 스킬을 만듭니다.
  3. 구글 드라이브·Notion 등을 쓰려면 커넥터를 연결합니다.
  4. 작업을 요청하면 아티팩트가 화면 분할로 열려 결과물을 바로 확인합니다.
  5. 메모리 기능으로 나에 대한 정보를 쌓아 두고, 필요하면 수정하거나 끕니다.
  • 메모리 기능은 2026년 3월 무료 사용자까지 확대되었습니다.
  • 메뉴 이름과 위치는 앱 버전에 따라 다를 수 있습니다.

6. 채팅·코워크·코드·디자인 구분해 쓰기

Claude의 네 가지 도구를 용도별로 고르는 기준입니다. 목적이 겹치지 않아 상황에 맞게 고르면 됩니다.

  1. 생각 정리와 질문·분석은 채팅을 씁니다.
  2. 파일·문서 정리와 엑셀·워드 보고서는 코워크를 씁니다.
  3. 웹사이트나 앱 제작은 코드를 씁니다.

  • 같은 데이터를 채팅 분석 → 코워크 보고서 → 코드 대시보드 → 디자인 슬라이드로 이어 가는 흐름도 가능합니다.

7. 데스크톱 앱 설치하고 폴더 맡기기

Claude 데스크톱 앱에서 컴퓨터 속 폴더를 열어 주면 Claude가 내 파일과 프로젝트를 파악하고 작업합니다. 코워크는 데스크톱 앱에서만 쓸 수 있습니다.

  1. Claude 사이트 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다(무료 사용자도 가능).
  2. Pro 이상이면 앱에서 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허락합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 작업을 설명하면 Claude가 계획을 먼저 제안하니, 확인 후 승인합니다.
  6. 파일을 바꾸기 전에 권한을 요청하면 내용을 보고 허용합니다.
예시
다운로드 폴더의 파일을 종류별로 정리할 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • 처음에는 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 코워크는 Pro, Max, Team, Enterprise에서 macOS와 Windows용 앱으로 정식 제공됩니다.
  • 예전 방식: 코워크는 처음에 macOS 전용이었으나 2월 업데이트로 윈도우에서도 쓸 수 있습니다.

9. 모바일 앱과 계정 전환 활용하기

Claude 모바일 앱에서 음성 모드, 계정 전환, 아티팩트 분할 화면 등을 쓰는 방법입니다. 이동 중에도 질문하고 결과를 확인할 수 있습니다.

  1. iOS 또는 Android에 Claude 앱을 설치하고 로그인합니다.
  2. 업무용과 개인 계정 모두 로그인해 두면 로그아웃 없이 전환할 수 있습니다.
  3. 음성 모드로 말하면서 질문합니다.
  4. iPad나 iPhone Duo에서는 아티팩트가 대화 옆 열에 열려 두 창을 나란히 쓸 수 있습니다.
  • 음성 모드는 더 빨라졌고 iPhone에서 Apple CarPlay를 지원합니다.
  • 앱 인터페이스는 총 33개 언어를 지원합니다.

11. 관리자가 조직 모델 기본값 정하기

팀·조직 관리자가 사용자가 쓸 모델과 노력 수준을 역할별로 정해 비용과 품질을 조절하는 방법입니다.

  1. 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)으로 모델별 최대 effort를 정합니다.
  3. 기본값(defaults)으로 새 대화의 시작 모델과 effort를 정합니다.
  4. 긴 열린 작업이 많은 역할은 상위 모델을 기본으로 하고 effort 상한을 검토합니다.
  5. 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 하고 Fable은 권한만 열어 둡니다.
  • 역할별로 따로 설정할 수 있습니다.
  • 영상은 Fable 5.1 기준 설명이며, 최신 모델은 11월 영상의 Fable 5.2입니다.
