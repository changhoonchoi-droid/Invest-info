1. Claude 가입하고 첫 대화 시작하기

Claude는 웹에서 바로 쓸 수 있는 AI 어시스턴트입니다. 계정을 만들고 질문창에서 첫 대화를 해 보는 가장 기초 단계입니다. 무료로 시작해도 충분히 써 볼 수 있습니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 질문창 모델 선택에서 기본 작업용으로 Sonnet을 고릅니다.
  4. 질문창에 궁금한 것을 친구에게 말하듯 입력해 보냅니다.
  5. 타이핑이 번거로우면 질문창의 마이크를 눌러 말로 질문합니다.
  6. 답이 마음에 안 들면 고쳐 달라고 이어서 요청합니다.
예시
내 업무는 마케팅팀 보고서 작성이야. 내가 Claude에게 어떤 일을 맡기면 좋을지 5가지만 알려줘.
  • 질문을 완벽하게 만들려 하지 말고 답을 보고 고쳐 달라고 주고받으세요.
  • 처음에는 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시작하세요.
  • 마이크로 맥락을 충분히 말하면 타이핑보다 결과가 좋아질 수 있습니다.

2. AI에게 나를 알려 주며 시작하기

AI에게 나에 대한 맥락을 주면 답변이 내 업무에 맞게 달라집니다. 첫날 몇 가지 질문으로 AI가 나를 파악하게 만드는 방법입니다. 하루 30분 정도 서로 질문을 주고받는 습관이 맥락을 쌓아 줍니다.

  1. AI가 나를 얼마나 아는지 "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 확인합니다.
  2. Claude 데스크톱 앱을 설치하고 폴더 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  4. "너는 뭘 할 수 있니?"라고 묻습니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  6. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 봐. 하나씩 물어보고, 내가 답하면 다음 질문으로 넘어가 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 처음 접하는 분은 영상에서 ChatGPT 보이스 모드로 말을 거는 것부터 권했습니다.
  • 답이 의심되면 근거 자료를 요구하고 다른 AI로 교차 검증하세요.

3. 내 정보 보호 설정 점검하기

회사 일에 AI를 쓰기 전에 대화가 모델 학습에 쓰이는지, 메모리에 무엇이 저장되는지 확인하는 단계입니다. 정책은 제공사마다 다르므로 쓰는 도구의 설정을 직접 확인해야 합니다.

  1. 계정이나 개인정보 설정을 열어 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 설정의 데이터 컨트롤 부근에서 모델 개선(학습) 사용 항목을 찾아 끕니다.
  3. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  4. 정보를 넣기 전에 대화, 저장 메모리, 향후 학습 중 어디에 쓰일지 생각합니다.
  5. 필요 없는 실명은 빼고 자리표시자로 바꿔 입력합니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 문서로 확인합니다.
  • 영상에서 학습 끄기 메뉴 이름은 ChatGPT 기준(Improve the model for everyone)으로 소개되었고, 메뉴 위치가 화면과 다를 수 있으니 설정 안에서 데이터 컨트롤 부근을 찾아보세요.
  • 모델은 대화 안에서만 맥락을 가지며 새 대화는 빈 상태로 시작합니다. 메모리는 계정에 저장된 정보입니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있다고 설명합니다.
  • 일상적인 용도에는 일반 소비자용 버전으로 충분한 경우가 많습니다.

4. 요금제 고르고 모델 선택하기

Claude는 무료부터 Pro, Max까지 요금제가 있고 모델도 여러 가지입니다. 구독료의 기준은 금액이 아니라 쓰다가 한도에 막히는지입니다. 작업에 맞는 모델을 고르는 요령을 정리했습니다.

  1. 먼저 무료로 쓰면서 불편이 있는지 확인합니다.
  2. 한도에 자주 막힐 때 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다.
  3. 더 많이 쓰면 Max(월 100달러 또는 200달러)를 검토합니다.
  4. 질문창의 모델 선택에서 일상 작업은 Sonnet을 고릅니다.
  5. 복잡한 작업이나 품질이 중요한 작업은 유료 모델(Opus 등)로 바꿉니다.
  6. 쓴 만큼 돈·시간·성과가 나는지 한 달 정도 써 보고 계속할지 정합니다.
  • 모델은 Haiku(빠르고 가벼움), Sonnet(균형), Opus(가장 강력)로 나뉘며, 영상 기준 Sonnet까지 무료이고 Opus 이상은 유료입니다.
  • 모델 단계가 높을수록 똑똑하지만 시간이 오래 걸리니 복잡한 업무에만 쓰세요.
  • 예전 방식: 5월 영상에서는 무료 플랜에서 Opus를 쓸 수 없고 모델이 세 가지로 소개되었으나, 이후 영상에서는 Fable까지 네 가지로 나뉩니다.
  • 요금과 한도는 바뀔 수 있으니 공식 요금 페이지에서 다시 확인하세요.

5. Fable 5.2 모델로 전환하기

Fable 5.2는 유료 플랜에서 쓸 수 있는 새 모델로, 슬라이드·게임·시뮬레이션 같은 복잡한 결과물에 강하다고 소개됩니다. 모델 전환 메뉴에서 바로 고를 수 있습니다.

  1. 유료 플랜으로 Claude에 접속합니다.
  2. 모델 전환(model switcher) 메뉴를 엽니다.
  3. Fable 5.2를 선택합니다.
  4. 만들고 싶은 결과물을 한 번의 프롬프트에 구체적으로 적어 요청합니다.
예시
신제품 출시 보고용 슬라이드 덱을 만들어 줘. 대상은 임원진이고, 10장 안팎에 핵심 숫자와 다음 단계를 포함해 줘.
  • 슬라이드처럼 품질이 중요한 작업은 높은 노력 수준(영상에서는 extra 설정)으로 돌리면 더 좋았다고 합니다.
  • Opus 5.5보다 비싸지만 더 빠르게 끝난 사례도 있었습니다.
  • 영상 기준 슬라이드 한 개에 약 30분이 걸리고 사용량을 소모하므로 한도를 확인하세요.

6. 모델과 노력 수준 비용 맞추기

작업 비용은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 작업 성격에 따라 모델과 노력 수준을 다르게 잡으면 사용량을 아낄 수 있습니다. 조직 관리자는 기본값도 정할 수 있습니다.

  1. 작업이 심층 조사처럼 열린 작업인지, 요약·메일 초안 같은 반복 작업인지 구분합니다.
  2. 열린 작업은 Fable 5.1을 medium effort로 시작해 필요하면 올립니다.
  3. 반복 작업은 Opus나 Sonnet을 씁니다.
  4. 관리자라면 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  5. effort 상한(caps)으로 모델별 최대 effort를 정합니다.
  6. 기본값(defaults)으로 새 대화의 시작 모델과 effort를 정합니다.
  • 더 똑똑한 모델은 적은 단계로 끝내 총비용이 낮아질 수 있습니다.
  • 역할별로 따로 설정할 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고 캐시 읽기 비용이 75% 낮다고 소개됩니다.

7. 웹 검색과 딥 리서치 켜기

웹 검색을 켜면 Claude가 필요할 때 검색하고 출처 링크를 달아 줍니다. 딥 리서치는 시장 조사, 경쟁사 분석처럼 깊은 조사가 필요할 때 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 조사할 주제와 범위를 프롬프트로 작성해 요청합니다.
예시
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 비교해 줘. 가격, 강점, 약점을 표로 정리하고 출처를 붙여 줘.
  • 11월 영상에서는 /딥리서치 명령으로도 실행할 수 있다고 소개합니다. 예전 방식: + → 연구(5월 영상).
  • 모델은 훈련 시점 이후의 사실을 검색 없이는 확실히 모르니 최신 정보는 검색을 켜세요.

8. 데스크톱·모바일 앱 설치해 쓰기

웹 외에 데스크톱 앱과 모바일 앱으로도 Claude를 쓸 수 있습니다. 코워크 같은 일부 기능은 데스크톱 앱에서만 쓸 수 있어 설치를 권합니다. 모바일에서는 계정 전환과 음성 모드가 편해졌습니다.

  1. Claude 사이트 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다(무료 사용자도 가능).
  2. 데스크톱 앱에서 로그인하고 필요한 폴더 접근을 허락합니다.
  3. 스마트폰에는 iOS·Android용 Claude 앱을 설치해 로그인합니다.
  4. 업무용과 개인 계정이 따로 있으면 로그아웃 없이 둘 다 로그인해 전환합니다.
  5. 이동 중에는 음성 모드로 말로 질문합니다.
  6. Mac에서는 Command K로 대화를 검색합니다.

9. 채팅·코워크·코드·디자인 골라 쓰기

Claude에는 목적이 다른 네 가지 도구가 있어 용도에 맞게 골라 쓰면 됩니다. 11월 영상 기준 채팅과 코워크가 하나로 합쳐졌고 Docs·슬라이드·디자인이 무료 플랜까지 확대되었다고 하니 현재 화면에서 확인하세요.

  1. 생각 정리와 데이터 패턴 분석은 채팅에서 합니다.
  2. 엑셀·워드 보고서 등 파일 업무는 코워크에 맡깁니다.
  3. 웹사이트·앱·대시보드 제작은 코드를 씁니다.
  4. 발표 자료는 디자인에서 슬라이드로 만듭니다.
  5. 웹 검색이 필요하면 플러스 버튼에서 켭니다.

첨부한 고객 설문 데이터에서 눈에 띄는 패턴 3가지를 찾아 줘. 각 패턴마다 근거가 되는 숫자를 함께 보여 줘.
  • 예전 방식: 8월 영상에서는 코워크·코드·디자인이 프로 플랜(월 20달러) 이상 필요하다고 했으나, 11월 영상은 Docs·슬라이드·디자인이 무료까지 확대되었다고 합니다.
  • 코워크는 클로드 코드와 같은 엔진을 쓰는 사무용 버전입니다.
  • 같은 데이터를 채팅 → 코워크 → 코드 → 디자인 순으로 이어 쓰면 흐름을 이해하기 좋습니다.

10. 코워크로 폴더 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만드는 기능입니다. 코딩 없이 작업 전체를 맡길 수 있고, 파일을 바꾸기 전에 권한을 요청합니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 설치하고 코워크 탭을 엽니다.
  2. 작업할 폴더 접근을 허용합니다.
  3. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  4. 맡길 작업을 구체적으로 설명합니다.
  5. Claude가 제안한 계획을 확인하고 승인합니다.
  6. 결과물과 파일 변경 내역을 확인합니다.
예시
다운로드 폴더의 파일을 종류별로 폴더를 나눠 정리해 줘. 파일 이름을 바꾸거나 옮기기 전에 변경 목록을 먼저 보여 줘.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 영상 기준 Pro, Max, Team, Enterprise 사용자에게 제공됩니다. 요금제 조건은 바뀔 수 있으니 확인하세요.
  • 파일 삭제 전 확인 같은 규칙은 글로벌 인스트럭션으로 정해 두면 매번 말할 필요가 없습니다.

11. 코워크 글로벌 인스트럭션 설정하기

글로벌 인스트럭션은 모든 코워크 작업에 공통으로 적용되는 규칙입니다. 역할, 보고서 톤, 날짜 형식 같은 것을 한 번 적어 두면 매번 같은 말을 반복하지 않아도 됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 누릅니다.
  4. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  5. 저장을 눌러 이후 모든 코워크 작업에 적용합니다.
예시
나는 마케팅팀 과장이야. 보고서는 존댓말 개조식으로 쓰고, 날짜는 YYYY-MM-DD 형식으로 적어 줘. 파일을 삭제하거나 덮어쓰기 전에는 반드시 먼저 물어봐 줘.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하세요.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.
  • 2월 영상 기준 안내라 메뉴 구성이 이후 바뀌었을 수 있습니다.
