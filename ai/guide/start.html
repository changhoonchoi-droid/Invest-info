Claude 시작하기

Claude를 처음 쓰는 직장인이 가입부터 모델·요금제 선택, 앱 설치, 개인정보 설정, 기본 기능 활용까지 순서대로 따라 할 수 있는 가이드입니다. 앞쪽 가이드(가입, 요금제·모델 선택, 앱 설치, 개인정보 설정)를 먼저 마친 뒤, 맥락 알려 주기와 검색·딥 리서치, 도구 고르기, 코워크 순으로 넘어가면 좋습니다.

가입·요금제·모델 선택·앱(웹/데스크톱/모바일) 기본 사용·설정 · 영상 22개 기반 · 2026-11-16 갱신

  • 10월 8일부터 Docs·슬라이드·디자인 기능이 무료 플랜까지 확대되었습니다.

1. Claude 가입하고 첫 질문하기

Claude는 Anthropic이 만든 AI 어시스턴트로, 웹 브라우저에서 바로 쓸 수 있습니다. 구글 계정이나 이메일만 있으면 무료로 시작할 수 있습니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 누릅니다.
  3. 로그인 후 질문창에 하고 싶은 일을 입력합니다.
  4. 타이핑이 번거로우면 질문창의 마이크를 눌러 말로 질문합니다.
  5. 답을 보고 마음에 들지 않는 부분은 고쳐 달라고 이어서 요청합니다.
예시
내일 팀 회의에서 쓸 신제품 출시 일정 공지 메일 초안을 정중한 말투로 써 줘.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤 답을 보고 고쳐 달라고 하세요.
  • 타이핑 대신 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.

2. 요금제와 모델 고르기

무료로 시작해 한도에 막힐 때 유료로 올리는 것이 기본 원칙입니다. 작업 비용과 품질은 모델과 노력 수준(effort)에 따라 달라지므로 용도에 맞게 고르면 됩니다.

  1. 먼저 무료 플랜으로 업무에 쓰며 불편한지 확인합니다.
  2. 사용 한도에 자주 막히면 Pro(월 20달러, 연간 결제 시 월 17달러)를 검토합니다.
  3. 더 많은 사용량이 필요하면 Max(월 100달러·200달러)를 검토합니다.
  4. 질문창의 모델 선택 메뉴에서 일상 작업은 Sonnet을 고릅니다.
  5. 복잡하거나 품질이 중요한 작업은 유료 플랜에서 모델 전환 메뉴를 열어 Fable 5.2 같은 상위 모델을 선택합니다.
  6. 요약·메일 초안 같은 반복 작업은 Opus나 Sonnet을 쓰고, 심층 조사처럼 열린 작업은 상위 모델을 중간 effort로 시작해 필요하면 올립니다.
  • 구독료 기준은 금액이 아니라 쓰다가 한도에 막히는지, 쓴 만큼 시간·성과가 나는지입니다.
  • 모델은 Haiku(빠르고 가벼움)·Sonnet(균형)·Opus(가장 강력) 등이 있고, 영상 기준 Sonnet까지 무료입니다. 최신 플랜 구성은 직접 확인하세요.
  • 슬라이드처럼 품질이 중요한 작업은 높은 노력 수준으로 돌리면 더 좋았다는 사례가 있습니다.
  • 예전 방식: 2월에는 Sonnet 4.6이 무료·Pro의 기본 모델이었고, 이후 Fable 계열이 유료 플랜에 추가되었습니다.

3. 데스크톱·모바일 앱 설치하고 쓰기

웹뿐 아니라 데스크톱 앱과 모바일 앱으로도 Claude를 쓸 수 있습니다. 코워크 같은 파일 작업 기능은 데스크톱 앱에서만 쓸 수 있어 설치해 두면 좋습니다.

  1. Claude 사이트 아래쪽의 데스크톱 앱 다운로드를 눌러 앱을 설치합니다(무료 사용자도 가능).
  2. 설치한 앱에서 같은 계정으로 로그인합니다.
  3. 휴대폰 앱 스토어에서 Claude 앱을 설치하고 로그인합니다.
  4. 모바일 앱에서 업무용과 개인 계정을 쓴다면 로그아웃 없이 두 계정을 추가해 전환합니다.
  5. 음성 모드로 말하듯 질문해 봅니다.
  • 모바일 앱은 24개 언어가 추가되어 총 33개 언어를 지원합니다.
  • iPhone에서는 음성 모드가 더 빨라졌고 Apple CarPlay를 지원합니다.
  • 웹·데스크톱에서는 대화 검색이 가능하며 Mac은 Command K입니다.

4. 내 대화가 학습에 쓰이지 않게 설정하기

회사 일에 Claude를 쓰기 전에 대화가 모델 학습에 쓰이는지, 메모리에 무엇이 저장되는지 점검하는 단계입니다. 정책은 제공사와 플랜마다 다르므로 설정 화면에서 직접 확인해야 합니다.

  1. 계정 또는 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 관련 토글을 확인합니다.
  2. 데이터 컨트롤 부근에서 모델 개선(학습) 사용 항목을 찾아 끕니다.
  3. 저장된 메모리를 열어 잘못되었거나 불필요한 내용을 수정하거나 지웁니다.
  4. 필요 없으면 메모리 기능 자체를 끕니다.
  5. 메일 문구 다듬기처럼 실명이 필요 없는 작업은 이름을 자리표시자로 바꿔 입력합니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 문서에서 데이터 처리 조건을 확인합니다.
  • 메뉴 이름과 위치는 영상에서 정확히 확인되지 않았으니 설정 안에서 데이터 컨트롤 부근을 찾아보세요.
  • 모델은 대화 중에만 맥락을 갖고, 메모리는 모델이 아니라 계정에 저장된 정보입니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 답이 의심되면 근거 자료를 요구하거나 다른 AI로 교차 검증하세요.

5. Claude에게 나를 알려 주기

AI를 잘 쓰는 핵심은 나에 대한 맥락을 주는 것입니다. 첫날 몇 가지 질문으로 Claude가 내 업무와 상황을 파악하게 하면 이후 답이 훨씬 나아집니다.

  1. 나에 대해 아는 것을 한 문단으로 설명해 봐라고 물어 Claude가 나를 얼마나 아는지 확인합니다.
  2. 데스크톱 앱을 쓴다면 폴더 접근을 허락합니다.
  3. 컴퓨터 보고 나에 대해 파악해 줘라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  4. 나에 대해서 궁금한 거 100개까지 물어봐 봐라고 요청해 인터뷰를 받습니다.
  5. 이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?라고 묻습니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 봐. 한 번에 다섯 개씩 물어봐 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 메모리는 설정에서 채팅 검색·참조와 메모리 생성을 켜야 작동합니다.

6. 웹 검색과 딥 리서치 켜기

모델은 훈련 시점 이후의 사실을 검색 없이는 확실히 알지 못합니다. 웹 검색을 켜면 최신 정보와 출처 링크를 받을 수 있고, 딥 리서치는 시장 조사처럼 깊은 조사에 쓰입니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 검색을 활성화합니다.
  3. 질문하면 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 리서치(예전 표기 연구)를 눌러 딥 리서치를 켭니다.
  5. 조사 주제와 원하는 결과물 형식을 적어 요청합니다.
예시
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 가격·기능·장단점 기준으로 비교해 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 딥 리서치는 /딥리서치 명령으로도 실행할 수 있습니다.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 예전 방식: 5월 영상에서는 + 버튼의 웹 탭과 연구 메뉴로 소개되었습니다.

7. 채팅·코워크·코드·디자인 고르기

Claude에는 목적이 다른 도구가 여러 개 있어 용도에 맞게 골라 쓰면 됩니다. 어떤 일에 무엇을 쓸지 기준만 알면 헤매지 않습니다.

  1. 생각 정리와 질문·분석은 채팅에서 합니다.
  2. 파일 정리와 엑셀·워드 보고서 작성은 코워크를 씁니다.
  3. 웹사이트나 앱 제작은 코드를 씁니다.
  4. 발표 자료는 디자인에서 슬라이드로 만듭니다.
  5. 하나의 자료(예: 설문 데이터)를 채팅 분석 → 코워크 보고서 → 디자인 슬라이드 순으로 이어서 써 봅니다.
  • 8월 영상 기준 코워크·코드·디자인은 Pro(월 20달러) 이상이 필요했지만, 10월 8일부터 Docs·슬라이드·디자인은 무료 플랜까지 확대되었습니다.
  • 예전 방식: 채팅과 코워크는 별개 도구였지만 9월 16일 하나로 합쳐졌다고 소개되었습니다.
  • 코워크는 코드와 같은 엔진을 쓰는 사무용 버전입니다.

8. 코워크로 폴더 업무 맡기기

코워크는 폴더 접근을 허용하면 Claude가 계획을 세우고 파일을 읽어 엑셀·문서 같은 결과물을 만들어 주는 기능입니다. 코딩 없이 파일 정리, 보고서 작성 같은 작업 전체를 맡길 때 씁니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 설치하고 로그인합니다(Pro 이상 필요).
  2. 앱에서 코워크를 엽니다.
  3. 작업할 폴더에 대한 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 작업을 설명하면 Claude가 먼저 계획을 제안하므로 내용을 확인하고 승인합니다.
