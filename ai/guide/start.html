Claude 시작하기

Claude 가입부터 요금제·모델 선택, 웹·데스크톱·모바일 앱의 기본 사용과 개인정보 설정까지 처음 시작할 때 필요한 것을 모았습니다. 1~3번(가입·요금제·모델)을 먼저 하고, 4~6번으로 도구와 앱에 익숙해진 뒤, 7~8번으로 내 맥락을 알려 주고 검색·리서치를 켜 보세요. 마지막 9~10번은 파일 작업을 맡기고 규칙을 고정하는 응용입니다.

가입·요금제·모델 선택·앱(웹/데스크톱/모바일) 기본 사용·설정 · 영상 36개 기반 · 2026-11-25 갱신

최근 바뀐 점

  • Claude Fable 5.2가 모든 유료 플랜에 나왔고, 가장 어려운 장기 기술 작업용이며 Fable 5.1보다 빠릅니다(11월 23일 소식).
  • 먼저 말을 거는 에이전트 앱 Claude Duet이 리서치 프리뷰로 시작됐습니다. 매일 아침 브리핑을 보내며, 미국 Pro·Max·Ultra 구독자 대상 대기 명단으로 열립니다.
  • 모바일 앱(iOS·Android)에서 업무용과 개인 계정에 로그아웃 없이 동시에 로그인해 전환할 수 있고, iPhone은 Apple CarPlay를 지원하며 앱이 총 33개 언어를 지원합니다.
  • 계좌를 읽기 전용으로 연결해 지출·청구서·잔액을 설명해 주는 개인 금융 기능이 미국 Pro·Max·Ultra 플랜에서 베타로 시작됐습니다.
Claude 가입하고 첫 질문하기한도 기준으로 요금제 고르기작업에 맞는 모델 고르기채팅·코워크·코드·디자인 고르기내 정보와 메모리 설정 점검하기모바일 앱 기본 사용하기데스크톱 앱에 나를 알려 주기웹 검색과 딥 리서치 켜기코워크로 폴더 업무 맡기기글로벌 인스트럭션으로 규칙 고정하기

1. Claude 가입하고 첫 질문하기

Claude 웹사이트에서 계정을 만들고 첫 질문을 던지는 가장 기본 과정입니다. 설치 없이 웹에서 바로 시작할 수 있고, 필요하면 데스크톱 앱도 무료로 설치할 수 있습니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 질문창의 모델 선택에서 기본 작업용으로 Sonnet을 고릅니다.
  4. 질문창의 마이크를 눌러 타이핑 대신 말로 질문합니다.
  5. 컴퓨터에서 계속 쓸 계획이면 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다(무료 사용자도 가능).
  • 타이핑보다 마이크로 맥락을 충분히 말하면 결과가 더 좋아집니다.
  • 모델은 Haiku·Sonnet·Opus·Fable 네 가지이며, 영상 기준으로 Sonnet까지 무료입니다. Opus 이상은 유료입니다.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤, 답을 보고 고쳐 달라고 하세요.

2. 한도 기준으로 요금제 고르기

Claude는 무료·Pro·Max 등 요금제가 있습니다. 금액보다 '쓰다가 한도에 막히는지'를 기준으로 올리면 불필요한 지출을 막을 수 있습니다.

  1. 무료 플랜으로 먼저 시작해 업무에 불편이 있는지 살펴봅니다.
  2. 사용 한도에 막혀 일이 끊길 때까지는 무료를 유지합니다.
  3. 한도에 막히면 Pro로 올립니다(월 20달러, 연간 결제 시 월 17달러, 약 3만 원 안팎. 무료의 약 5배 사용량).
  4. Pro도 모자라면 Max를 검토합니다(월 100달러는 Pro의 5배, 월 200달러는 Pro의 20배 사용량).
  5. 한 달 정도 써 본 뒤 쓴 돈만큼 시간이 줄었는지, 성과가 났는지 따져 유지 여부를 정합니다.
  • Pro도 몇 시간 단위의 사용 제한이 있습니다.
  • 가격과 플랜 구성은 바뀔 수 있으니 결제 전 가입 화면에서 다시 확인하세요.
  • Fable 5.2는 모든 유료 플랜에서 쓸 수 있습니다.

3. 작업에 맞는 모델 고르기

Claude는 작업 난이도에 따라 모델을 바꿔 쓸 수 있습니다. 모든 일에 가장 강한 모델을 쓰기보다 일상 작업은 기본 모델로, 어려운 일에만 상위 모델을 쓰면 한도와 시간을 아낄 수 있습니다.

  1. 질문창의 모델 전환(모델 선택) 메뉴를 엽니다.
  2. 일상적인 코딩·지식 작업은 Opus 5.5로 시작합니다.
  3. 가장 어려운 장기 작업은 Fable 5.2로 바꿔 돌립니다(유료 플랜).
  4. 요약이나 메일 초안 같은 작은 작업은 Sonnet 5.5나 Haiku를 씁니다.
  5. 슬라이드처럼 품질이 중요한 작업은 노력 수준(effort)을 높여 다시 돌려 봅니다.
  • Fable 5.2는 Opus 5.5보다 비싸지만, 더 빨리 끝나 오히려 효율적이었던 사례가 소개됐습니다.
  • 예전 방식: 2월에는 Sonnet 4.6이 무료·Pro의 기본 모델이었습니다. 9월 자료는 열린 작업을 Fable 5.1 medium effort로 시작해 올리라고 했는데, 지금은 Opus 5.5 시작을 권합니다.
  • Fable 5.2로 만든 큰 결과물은 사용량을 많이 쓰니(슬라이드 한 개에 Ultra 사용량 약 1.5%) 필요한 때만 쓰세요.

4. 채팅·코워크·코드·디자인 고르기

Claude에는 목적이 다른 네 가지 도구가 있습니다. 용도를 구분해 두면 어떤 화면에서 시작할지 헤매지 않습니다.

  1. 생각 정리, 질문, 데이터 패턴 분석은 채팅에서 합니다.
  2. 파일 정리, 엑셀·워드 보고서 만들기는 코워크에서 합니다.
  3. 웹사이트·앱·대시보드 제작은 코드에서 합니다.
  4. 발표 자료와 슬라이드는 디자인에서 마무리합니다.
  5. 같은 자료 하나로 채팅 분석 → 코워크 보고서 → 코드 대시보드 → 디자인 슬라이드 순으로 이어 가 봅니다.
  • 코워크는 클로드 코드와 같은 엔진을 쓰는 사무용 버전입니다.
  • 예전 방식: 8월 영상은 코워크·코드·디자인에 Pro 이상(월 20달러)이 필요하다고 했지만, 10월 8일에 Docs·슬라이드·디자인이 무료 플랜까지 확대됐습니다.
  • 9월 16일에 채팅과 코워크가 하나로 합쳐져 화면 구성이 예전 영상과 다를 수 있습니다.

5. 내 정보와 메모리 설정 점검하기

회사 일에 Claude를 쓰기 전에, 대화가 어디에 저장되고 학습에 쓰이는지 설정을 확인해 두는 가이드입니다. 메모리와 학습 설정은 제품·플랜마다 달라서 직접 확인해야 합니다.

  1. 계정이나 개인정보 설정에서 데이터·개인정보 관련 메뉴를 엽니다(메뉴 이름은 버전에 따라 다를 수 있습니다).
  2. 내 대화가 모델 학습에 쓰이는지 확인하고, 원하지 않으면 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 항목을 함께 확인합니다.
  4. 메모리를 쓰고 싶다면 설정에서 채팅 검색·참조와 메모리 생성을 켭니다.
  5. 저장된 메모리를 열어 틀린 것은 고치고 필요 없는 것은 지우며, 원하지 않으면 메모리를 끕니다.
  6. 입력 전에 필요 없는 실명은 자리표시자로 바꾸고, 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 씁니다.
예시
이 메일 문구를 정중하게 다듬어 줘. 고객 이름은 [고객A], 회사명은 [회사B]로 바꿔 두었어.
  • 모델은 대화 중에만 맥락을 갖고, 새 대화는 빈 상태로 시작합니다. 메모리는 모델이 아니라 계정에 저장된 정보입니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 정책은 제공사마다 다르니 쓰는 도구의 개인정보 처리방침을 직접 확인하세요.

6. 모바일 앱 기본 사용하기

Claude 모바일 앱(iOS·Android)은 계정 전환, 음성 모드, 사진 첨부 같은 기능을 지원합니다. 출퇴근길이나 외근 중에 간단히 질문하고 이어서 PC에서 작업할 때 편합니다.

  1. iOS 또는 Android에 Claude 앱을 설치하고 로그인합니다.
  2. 업무용과 개인 계정을 쓴다면 두 계정을 로그아웃 없이 함께 로그인해 두고 전환합니다(메뉴 위치는 앱에서 확인).
  3. 음성 모드로 말로 질문합니다. 이전보다 빨라졌습니다.
  4. iPhone에서 사진을 고르면 업로드 중에도 바로 채팅에 표시됩니다.
  5. iPad나 iPhone Duo에서는 Claude가 만든 아티팩트가 대화 옆 열에 열려 두 창을 나란히 볼 수 있습니다.
  • iPhone은 Apple CarPlay에서 음성 모드를 쓸 수 있습니다.
  • 앱 인터페이스는 24개 언어가 추가돼 총 33개 언어를 지원합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공 예정이며, 웹과 데스크톱에는 이미 있습니다(Mac은 Command K).

7. 데스크톱 앱에 나를 알려 주기

AI는 나에 대한 맥락을 알수록 더 정확하게 돕습니다. Claude 데스크톱 앱에 폴더 접근을 허락하고 스스로 나를 파악하게 한 뒤, 질문을 주고받으며 맥락을 쌓는 방법입니다.

  1. Claude 데스크톱 앱을 설치합니다.
  2. 내 프로젝트가 있는 폴더 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청합니다.
  4. "너는 뭘 할 수 있니?"라고 물어 가능한 일을 확인합니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 질문에 답합니다.
  6. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
  7. 하루 30분씩 AI에게 질문하고 AI가 나에게 질문하게 하는 습관을 이어 갑니다.
예시
내 폴더를 읽기만 하고 파일은 절대 고치지 마. 폴더를 보고 나에 대해 파악한 내용을 한 문단으로 설명해 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 처음에는 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시킵니다.
  • 답이 의심되면 근거 자료를 가져오게 하거나 다른 AI로 검증하세요.

8. 웹 검색과 딥 리서치 켜기

Claude가 최신 정보를 검색해 출처 링크와 함께 답하게 하는 기능입니다. 시장 조사, 경쟁사 분석처럼 깊은 조사에는 딥 리서치를 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 질문하면 필요할 때 검색하고 출처 링크가 달립니다. 링크를 열어 확인합니다.
  4. 깊은 조사가 필요하면 /딥리서치 명령을 입력하거나 + → 리서치를 눌러 딥 리서치를 켭니다.
  5. 조사 주제와 원하는 결과 형태를 적어 요청합니다.
  6. 답이 의심되면 근거 자료를 요구하고 다른 AI로 교차 검증합니다.
예시

  • 예전 방식: 5월 영상은 + 버튼에서 연구를 눌러 켰습니다.
  • 검색 도구가 없으면 모델은 훈련 시점 이후의 사실을 확실히 알지 못합니다.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.

9. 코워크로 폴더 업무 맡기기

코워크는 단계별 대화 대신 작업 전체를 맡기는 방식입니다. 폴더 파일과 Google Drive·Notion·Slack 같은 서비스를 다루며, 계획을 먼저 제안하고 승인 후 실행합니다.

  1. Claude 데스크톱 앱(macOS 또는 Windows)을 설치합니다. Pro, Max, Team, Enterprise에서 제공됩니다.
  2. 코워크를 시작합니다(2월 영상 기준 코워크 탭).
  3. 작업할 폴더 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 맡길 작업을 구체적으로 설명합니다.
  6. Claude가 제안한 계획을 읽고 괜찮으면 승인합니다.
  7. 파일을 바꾸기 전에 Claude가 권한을 요청하면 내용을 확인한 뒤 허용합니다.
  8. 만들어진 엑셀·문서 같은 결과물을 확인하고 수정을 요청합니다.
예시
다운로드 폴더의 파일을 종류별로 정리하는 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 예전 방식: 코워크는 처음 macOS 전용이었다가 2월 중순 윈도우도 지원됐고, 9월 16일 채팅과 하나로 합쳐졌습니다.
  • 플러그인(스킬·커넥터·슬래시 명령어·서브에이전트 묶음)으로 전문 직무 지식을 한 번에 추가할 수 있습니다.

10. 글로벌 인스트럭션으로 규칙 고정하기

매번 같은 말을 반복하지 않도록, 역할·보고서 톤·날짜 형식 같은 규칙을 한 번 적어 두면 이후 코워크 작업에 모두 적용됩니다. 폴더별 규칙은 따로 줄 수도 있습니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 눌러 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누르면 이후 모든 코워크 작업에 적용됩니다.
예시
역할: 마케팅팀 보고서 담당자. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적어 줘. 파일을 삭제하기 전에는 반드시 나에게 확인해 줘.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하거나 프롬프트로 지침을 넣습니다.
  • 2월 영상 기준이라 메뉴 이름이 바뀌었을 수 있고, 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.
