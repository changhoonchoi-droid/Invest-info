Claude 시작하기

Claude 시작하기에서는 가입과 첫 대화, 모델·요금제 고르기, 웹 검색·딥 리서치 같은 기본 기능, 코워크와 설정까지 직장인이 바로 쓸 수 있는 내용을 다룹니다. 먼저 가입하고 나를 알려 주는 입문 가이드를 따라 한 뒤, 모델과 요금제 선택, 개인정보 설정, 응용 기능 순서로 보시면 좋습니다. 영상마다 메뉴 이름이 조금씩 다를 수 있으니 화면에 보이는 이름을 기준으로 따라 하세요.

가입·요금제·모델 선택·앱(웹/데스크톱/모바일) 기본 사용·설정 · 영상 41개 기반 · 2026-11-27 갱신

최근 바뀐 점

  • Claude Fable 5.2가 모든 유료 플랜에 나왔고, 모델 전환 메뉴에서 선택해 쓸 수 있습니다.
  • Claude Duet은 먼저 말을 거는 에이전트 앱으로, 미국 Pro·Max·Ultra 구독자 대상 리서치 프리뷰(대기 명단)로 시작합니다.
  • 모바일 앱에서 업무용과 개인 계정에 로그아웃 없이 동시에 로그인해 전환할 수 있게 되었습니다(iOS·Android).
  • 개인 금융 기능이 미국 Pro·Max·Ultra 플랜에 읽기 전용 베타로 제공됩니다.

1. Claude 가입하고 첫 대화 시작하기

Claude를 처음 쓰는 분이 가입하고 모델을 고른 뒤 말로 질문해 보는 가장 기초 과정입니다. 무료로도 시작할 수 있으니 먼저 써 보고 한도에 막힐 때 유료를 고민하면 됩니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 데스크톱 앱이 필요하면 아래쪽 데스크톱 앱 다운로드로 설치합니다(무료 사용자도 가능).
  4. 질문창의 모델 선택에서 기본 작업은 Sonnet을 고릅니다.
  5. 질문창의 마이크를 눌러 말로 질문합니다.
  6. 답을 보고 "더 짧게", "표로 정리해 줘"처럼 고쳐 달라고 이어서 요청합니다.
예시
나는 마케팅 팀 직장인이야. 오늘 팀장님께 보낼 주간 보고 메일 초안을 쓰려고 하는데, 먼저 필요한 정보를 3가지만 물어봐 줘.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤 답을 보고 고쳐 달라고 하세요.
  • 타이핑 대신 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.

2. Claude에게 나를 알려 주며 시작하기

AI에게 맥락, 즉 나에 대한 정보를 주면 답이 훨씬 내 상황에 맞아집니다. 첫날 AI가 나를 얼마나 아는지 확인하고, 인터뷰를 받게 해 맥락을 쌓는 방법입니다.

  1. AI가 나에 대해 아는 것을 한 문단으로 설명해 보라고 요청합니다.
  2. AI가 나를 얼마나 아는지 확인합니다.
  3. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  4. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
  5. 조금 익숙해지면 Claude 데스크톱 앱을 설치하고 폴더 접근을 허락한 뒤 "컴퓨터 보고 나에 대해 파악해 줘"라고 요청합니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 봐. 내 업무와 일하는 방식을 파악해서 나중에 도움이 되게 하고 싶어.
  • 폴더를 보여 줄 때는 "파일은 읽기만 하고 고치지 마"라고 지시하는 것이 안전합니다.
  • 하루 30분, 서로 질문을 주고받는 습관이 맥락을 쌓아 줍니다.
  • 영상에서 첫 도구로 ChatGPT 보이스 모드를 소개했지만 같은 방식으로 Claude 앱에서도 질문해 볼 수 있습니다.

3. 요금제와 모델 고르기

Claude는 무료로 시작해 한도에 막힐 때 유료로 넘어가는 것이 기본입니다. 모델은 작업 난이도에 따라 나눠 쓰면 비용과 시간을 아낄 수 있습니다.

  1. 먼저 무료 플랜으로 일주일쯤 써 보며 한도에 막히는지 확인합니다.
  2. 일상적인 글쓰기·요약은 Sonnet이나 Haiku로 처리합니다.
  3. 일상적인 코딩·지식 작업은 Opus 5.5로 시작합니다.
  4. 가장 어려운 문제나 긴 작업은 유료 플랜에서 모델 전환 메뉴를 열어 Fable 5.2를 선택합니다.
  5. 한도에 자주 막히고 쓴 만큼 시간·성과가 나온다면 Pro나 Max로 올립니다.
  • 구독료의 기준은 금액이 아니라 쓰다가 한도에 막히는지 여부입니다.
  • 영상 기준 무료는 Sonnet까지, Pro는 월 20달러(약 3만 원), Max는 월 100달러부터이며 요금은 바뀔 수 있으니 공식 페이지에서 확인하세요.
  • 모델 단계가 높을수록 똑똑하지만 시간이 오래 걸리니 복잡한 업무에만 쓰세요.
  • Fable 5.2로 품질이 중요한 작업을 할 때는 높은 노력 수준(영상에서는 extra)으로 돌리면 더 좋았다고 합니다.

4. 내 대화가 학습에 쓰이지 않게 설정하기

회사 일에 AI를 쓰기 전에 대화가 모델 학습에 쓰이지 않도록 설정을 점검하는 방법입니다. 메모리와 대화 기록도 함께 확인하면 내 정보를 통제하기 쉽습니다.

  1. Claude 설정에서 개인정보·데이터 컨트롤 관련 항목을 찾습니다.
  2. 모델 개선(학습) 사용 토글이 있으면 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 항목을 함께 확인합니다.
  4. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  5. 메일 문구 다듬기처럼 필요 없는 실명은 빼고 자리표시자로 바꿔서 입력합니다.
  • 영상에서 메뉴 위치와 이름이 정확하지 않다고 했으니 설정 안에서 데이터 관련 항목을 직접 찾아보세요.
  • 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 확인하세요.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 정책은 제공사마다 다르니 개인정보 처리방침을 직접 확인하세요.

5. 웹 검색과 딥 리서치 켜기

최신 정보가 필요하거나 시장 조사·경쟁사 분석처럼 깊은 조사가 필요할 때 쓰는 기능입니다. 웹 검색은 출처 링크를 달아 답하고, 딥 리서치는 더 길고 깊게 조사합니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 리서치(영상에 따라 연구로 표시)를 눌러 딥 리서치 모드를 켭니다.
  5. 조사할 주제와 원하는 결과 형태를 프롬프트로 적어 요청합니다.
예시
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 조사해서 가격, 강점, 약점을 표로 정리하고 출처 링크를 달아 줘.
  • 딥 리서치는 /딥리서치 명령으로도 실행할 수 있다고 소개됩니다.
  • 메뉴 이름이 화면마다 리서치·연구로 다를 수 있습니다.
  • 모델은 학습 시점 이후 사실을 검색 없이는 모르니, 최신 정보는 웹 검색을 켜세요.
  • 의심되는 답은 근거 자료를 요구하거나 다른 AI로 교차 검증하세요.

6. 채팅·코워크·코드·디자인 골라 쓰기

Claude에는 채팅, 코워크, 코드, 디자인 네 가지 도구가 있고 목적이 겹치지 않습니다. 일에 맞게 골라 쓰는 기준을 알면 헤매지 않습니다. 채팅은 무료지만 나머지는 유료 플랜이 필요합니다.

  1. 생각 정리와 질문·분석은 채팅에서 합니다.
  2. 폴더 속 파일 정리와 엑셀·워드 보고서 작성은 코워크에서 합니다.
  3. 웹사이트나 앱을 만들 때는 코드를 씁니다.
  4. 발표 자료와 슬라이드는 디자인에서 만듭니다.
  5. 코워크·코드·디자인이 안 보이면 요금제가 Pro(월 20달러) 이상인지 확인합니다.
  • 영상 기준으로 코워크는 클로드 코드와 같은 엔진을 쓰는 사무용 버전입니다.
  • 고객 설문 같은 데이터 하나로 분석(채팅) → 보고서(코워크) → 대시보드(코드) → 슬라이드(디자인) 순서로 이어 갈 수 있습니다.
  • 9월 16일 채팅과 코워크가 하나로 합쳐졌다고 소개되니 화면 구성이 영상과 다를 수 있습니다.

7. 프로젝트로 업무 공간 나누기

프로젝트는 업무별로 맥락을 모아 두는 공간입니다. 반복 업무마다 매번 배경을 설명하지 않아도 되어, 업무 공간을 분리해 쓰기 좋습니다.

  1. Claude에서 프로젝트를 열고 새 프로젝트를 만듭니다.
  2. 프로젝트 이름을 업무 단위로 정합니다(예: 주간 보고).
  3. 배경 설명이나 참고 파일을 프로젝트에 넣습니다.
  4. 프로젝트 안에서 새 대화를 시작해 작업을 요청합니다.
예시
이 프로젝트의 자료를 바탕으로, 이번 주 주간 보고 초안을 지난번과 같은 형식으로 써 줘.
  • 영상 구조 설명: 프로젝트는 맥락을, 스킬은 작업 방식을, 커넥터는 외부 도구를, 코워크는 실행을 맡습니다.
  • 메뉴 이름과 세부 단계는 화면에서 확인하며 따라 하세요.

8. 코워크로 폴더 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만드는 기능입니다. Claude 데스크톱 앱(macOS·Windows)에서 Pro, Max, Team, Enterprise 사용자에게 제공됩니다.

  1. Claude 데스크톱 앱을 설치합니다.
  2. 앱에서 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 작업을 말로 설명합니다.
  6. Claude가 제안하는 계획을 확인하고 승인합니다.
  7. 파일을 바꾸기 전 권한 요청이 오면 내용을 보고 허용합니다.
예시
