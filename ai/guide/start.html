Claude 시작하기

「Claude 시작하기」에서는 Claude가 답을 만드는 원리, 모델과 노력 수준(effort) 고르기, 메모리·학습 같은 개인정보 설정, 데스크톱 앱의 Cowork로 작업을 통째로 맡기는 방법까지 차례로 익힙니다. 처음이라면 답변 원리와 모델 선택부터 보고, 개인정보 설정을 점검한 다음 Cowork와 브라우저 연동으로 넘어가세요. 조직 관리자라면 마지막의 조직 기본값 설정 가이드도 함께 보세요.

1. Claude 답변 원리 알고 잘 묻기

Claude는 학습한 내용을 바탕으로 다음 단어를 예측해 답을 한 단어씩 씁니다. 이때 내 메시지뿐 아니라 업로드한 문서, 메모리, 대화 기록 전체를 함께 고려합니다. 이 원리를 알면 답을 여러 버전으로 받아 보고, 최신 사실은 따로 확인하는 습관을 들일 수 있습니다.

  1. 질문할 때 필요한 배경 자료(문서·이전 대화 내용)를 같은 대화 안에 함께 줍니다.
  2. 정해진 답을 꺼내는 게 아니라 새로 생성하는 방식이므로, 마음에 들지 않으면 다른 버전을 요청합니다.
  3. 주제가 바뀌면 새 대화를 시작합니다. 새 대화는 이전 맥락이 없는 빈 상태로 시작합니다.
  4. 최근 사건이나 수치처럼 학습 시점(training cutoff) 이후의 정보는 검색 도구를 쓰거나 직접 출처를 확인합니다.
  5. 답이 자신 있게 들려도 사실관계는 한 번 더 검증한 뒤 업무에 씁니다.
예시
아래 메일 초안을 더 정중한 버전, 더 간결한 버전, 더 친근한 버전으로 각각 써 줘.
  • AI는 틀린 내용도 자신 있게 말할 수 있으니 중요한 숫자·날짜·인용은 반드시 원문과 대조하세요.
  • Claude가 기억하는 범위는 지금 대화와 계정에 저장된 메모리까지입니다. 모델 자체가 지난 대화를 기억하는 것은 아닙니다.

2. 작업에 맞는 모델과 effort 고르기

Claude 작업의 비용과 품질은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 더 똑똑한 모델은 적은 단계로 일을 끝내서 오히려 총비용이 낮아질 수 있습니다. 작업 성격에 맞춰 모델과 effort를 고르면 품질과 비용을 함께 챙길 수 있습니다.

  1. 먼저 할 일이 '열린 작업'(심층 조사, 긴 분석)인지 '반복 작업'(요약, 메일 초안)인지 구분합니다.
  2. 심층 조사처럼 열린 작업은 Fable 5.1 모델을 medium effort로 시작합니다.
  3. 결과가 부족하면 effort를 한 단계씩 올려 다시 시도합니다.
  4. 요약이나 메일 초안 같은 반복 작업은 Opus나 Sonnet 모델을 고릅니다.
  5. 같은 종류의 작업을 몇 번 해 본 뒤, 품질과 사용량을 비교해 자주 쓸 조합을 정합니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같지만 캐시 읽기 비용이 75% 낮아, 일반 작업은 약 25%, 긴 에이전트 작업은 최대 약 45%까지 비용이 줄어든다고 소개됐습니다.
  • 공식 영상의 비교에서 Fable 5.1 medium은 Fable 5 max와 비슷한 결과를 약 5분의 1 비용으로 냈습니다. 처음부터 최고 effort를 쓸 필요는 없습니다.
  • 예전 방식: 2026년 2월에는 Sonnet 4.6이 Free·Pro 플랜의 claude.ai와 Cowork 기본 모델이었고, 100만 토큰 컨텍스트 윈도우를 베타로 제공했습니다.

3. 메모리·학습 설정 점검하기

Claude에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있습니다. 메모리는 모델이 아니라 계정에 저장되는 정보라서 대부분 편집·삭제하거나 끌 수 있습니다. 업무 자료를 다루기 전에 한 번 점검해 두면 내 정보를 직접 통제할 수 있습니다.

  1. 계정 또는 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 저장된 메모리 중 틀리거나 필요 없는 내용을 고치거나 지웁니다.
  3. 메모리가 필요 없다면 메모리 기능을 끕니다.
  4. 정보를 입력하기 전에 그 내용이 대화, 저장 메모리, 향후 학습 중 어디에 쓰일지 생각합니다.
  5. 메일 문구 다듬기처럼 실명이 필요 없는 작업은 이름을 자리표시자로 바꿔 입력합니다.
  6. 기밀·규제 데이터를 다뤄야 한다면 비즈니스나 엔터프라이즈 플랜을 쓰고, 문서에서 데이터 처리 조건을 확인합니다.
예시
[고객명]님께 보내는 납기 지연 안내 메일을 정중하게 다듬어 줘. 납기는 [날짜]로 바뀌었어.
  • 제품에 따라 메모리가 기본으로 켜져 있을 수 있으니 처음 쓸 때 꼭 확인하세요.
  • 조직이 Claude를 도입한 경우 모델 학습은 기본적으로 꺼져 있습니다.
  • 정책은 제공사마다 다르므로 쓰는 도구의 개인정보 처리방침과 데이터 보관 설정을 직접 확인하세요.
  • 일상적인 용도라면 일반 소비자용 버전으로도 충분한 경우가 많습니다.

4. Cowork로 작업 통째로 맡기기

Cowork는 단계별로 주고받는 대화 대신 작업 전체를 Claude에게 맡기는 기능입니다. 내 컴퓨터의 파일과 Google Drive·Notion·Slack 같은 서비스, Chrome 브라우저까지 다룰 수 있습니다. 파일 정리, 자료 모으기처럼 여러 단계가 필요한 일을 맡길 때 씁니다.

  1. Pro, Max, Team, Enterprise 플랜인지 확인합니다. Cowork는 이 플랜에서 제공됩니다.
  2. macOS 또는 Windows용 Claude 데스크톱 앱을 설치하고 로그인합니다.
  3. Cowork에서 Claude가 작업할 폴더 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 서비스를 커넥터로 연결합니다.
  5. 맡길 작업을 원하는 결과까지 구체적으로 설명합니다.
  6. Claude가 먼저 제안하는 계획을 읽고, 맞으면 승인해 실행시킵니다.
  7. 파일을 바꾸기 전에 Claude가 권한을 요청하면 내용을 확인하고 허용합니다.
예시
다운로드 폴더를 정리해 줘. 파일 종류별로 하위 폴더를 만들어 나누고, 실행 전에 계획부터 보여 줘.
  • 처음에는 다운로드 폴더처럼 망가져도 부담이 적은 폴더로 연습하세요.
  • 브라우저 작업까지 맡기려면 Claude in Chrome을 먼저 설정해야 합니다.
  • 계획 단계에서 범위가 넓다고 느껴지면 승인 전에 수정을 요청하세요.

5. 어사이드 브라우저에 Claude 연결하기

어사이드(Aside)는 크롬 같은 AI 웹 브라우저로, AI가 클릭하고 입력하는 일을 대신 해 줍니다. 이미 유료로 쓰는 Claude나 GPT를 연결하면 어사이드에는 따로 돈을 내지 않아도 된다고 소개됩니다. 메일 확인이나 사내 사이트 조회처럼 반복되는 브라우저 업무를 맡길 때 씁니다.

  1. Claude 데스크톱 앱을 설치하고 로그인합니다.
  2. 어사이드(Aside) 브라우저를 설치합니다.
  3. 어사이드에 이미 결제 중인 Claude(또는 GPT)를 연결합니다.
  4. 크롬의 로그인 정보를 어사이드로 가져와 로그인이 필요한 사이트도 쓸 수 있게 합니다.
  5. 할 일을 말로 설명해 AI에게 시키고, AI가 화면에서 클릭·입력하는 과정을 지켜봅니다.
  6. 결과를 확인하고 필요하면 이어서 다음 지시를 내립니다.
예시
받은 메일함에서 오늘 온 메일을 확인해서 답장이 필요한 것만 골라 정리해 줘.
  • 로그인 정보를 넘기는 만큼 회사 보안 규정에 맞는지 먼저 확인하세요.
  • 영상 실습에서는 메일 확인, 사내 물류 사이트의 반품 확인, 인스타그램 계정 탐색을 시켜 봤습니다. 이런 조회 업무부터 시작하면 좋습니다.
  • 어사이드는 한국인이 만든, YC 투자를 받은 실리콘밸리 스타트업의 제품으로 소개됩니다.

6. 관리자: 조직 모델 기본값 정하기

Team·Enterprise 관리자는 조직원이 쓸 수 있는 모델, 모델별 최대 effort, 새 대화의 기본 모델을 정할 수 있습니다. 역할에 맞게 설정하면 품질은 지키면서 불필요한 사용량을 줄일 수 있습니다.

  1. 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)으로 모델별 최대 effort를 정합니다.
  3. 기본값(defaults)으로 새 대화가 시작할 모델과 effort를 정합니다.
  4. 긴 열린 작업이 많은 역할은 Fable 5.1을 기본으로 하고 effort 상한을 검토합니다.
  5. 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 하고, Fable은 권한만 열어 둡니다.
  • 권한·상한·기본값은 역할별로 따로 설정할 수 있습니다.
  • 조직 도입 시 모델 학습은 기본적으로 꺼져 있다는 점도 구성원에게 함께 안내하면 좋습니다.
