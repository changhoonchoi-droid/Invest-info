Claude 시작하기

Claude 가입부터 요금제·모델 선택, 웹·데스크톱·모바일 앱 사용, 개인정보 설정까지 처음 쓸 때 필요한 것을 모았습니다. 앞쪽 가이드(가입 → 요금제 → 앱 설치 → 첫 대화)를 먼저 따라 하고, 이어서 모델 선택·검색·설정을 본 뒤, 마지막의 코워크 가이드로 넘어가면 좋습니다.

가입·요금제·모델 선택·앱(웹/데스크톱/모바일) 기본 사용·설정 · 영상 26개 기반 · 2026-11-18 갱신

최근 바뀐 점

  • 유료 플랜의 모델 전환 메뉴에서 새 모델 Fable 5.2를 고를 수 있게 되었고, 영상에서는 지식 노동 과제 완료율이 Opus 5.5의 21%에서 41%로 올랐다고 소개했습니다.
  • 9월 16일 채팅과 코워크가 하나로 합쳐졌고, 10월 8일부터 Docs·슬라이드·디자인이 무료 플랜까지 확대되었습니다.
  • 모바일 앱에서 업무용·개인 계정에 로그아웃 없이 동시에 로그인해 전환할 수 있고, 인터페이스가 총 33개 언어를 지원합니다.
  • 개인 금융 기능이 베타로 추가되었지만, 미국의 Pro·Max·Ultra 요금제에 순차 제공되는 단계입니다.

1. Claude 가입하고 첫 질문 해 보기

Claude는 Anthropic이 만든 AI 어시스턴트로, 글쓰기·요약·분석 같은 업무에 쓸 수 있습니다. 구글 계정이나 이메일만 있으면 무료로 바로 시작할 수 있습니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 누릅니다.
  3. 가입이 끝나면 질문창에 하고 싶은 말을 입력해 첫 질문을 보냅니다.
  4. 질문창의 마이크를 누르면 타이핑 대신 말로 질문할 수 있습니다.
  5. 답이 마음에 들지 않으면 처음부터 다시 쓰지 말고 고쳐 달라고 이어서 요청합니다.
예시
나는 마케팅 팀 직장인이야. 이번 주 회의 내용을 정리하려고 하는데, 어떤 정보를 알려 주면 정리를 잘해 줄 수 있어?
  • 말로 맥락을 충분히 설명할수록 결과가 좋아집니다.
  • 질문을 완벽하게 만들려 하지 말고, 친구에게 말하듯 던진 뒤 답을 보고 고쳐 달라고 하면 됩니다.

2. 내게 맞는 요금제 고르기

Claude는 무료, Pro, Max 등 요금제가 나뉘며 사용량과 쓸 수 있는 기능이 다릅니다. 금액보다 쓰다가 한도에 막히는지를 기준으로 고르면 낭비가 없습니다.

  1. 먼저 무료 플랜으로 업무에 며칠 써 봅니다.
  2. 사용 한도에 자주 막히는지 확인합니다.
  3. 한도가 불편해지면 Pro(월 20달러, 연간 결제 시 월 17달러, 약 3만 원)로 올립니다.
  4. Pro로도 부족하면 Max(월 100달러 또는 200달러)를 검토합니다.
  5. 유료로 올린 뒤 한 달 정도 써 보고, 시간·성과 면에서 본전이 나오는지 따져 계속 쓸지 정합니다.
  • Pro는 무료의 약 5배 사용량이지만, 몇 시간 단위의 사용 제한은 여전히 있습니다.
  • 코워크·코드·디자인 같은 도구는 Pro 이상에서 쓸 수 있다고 소개되었습니다. 다만 10월 8일부터 Docs·슬라이드·디자인은 무료 플랜까지 확대되었습니다.
  • 예전 방식: 몇 달 전 영상에서는 코워크·코드·디자인을 모두 Pro 이상 전용으로 안내했습니다.
  • 요금과 제공 범위는 바뀔 수 있으니 결제 전 공식 요금 페이지를 확인하세요.

3. 웹·데스크톱·모바일 앱 설치하기

Claude는 웹 브라우저, 데스크톱 앱, 모바일 앱에서 모두 쓸 수 있습니다. 파일 작업을 맡기는 코워크는 데스크톱 앱에서만 쓸 수 있어, 업무용이라면 데스크톱 앱 설치를 권합니다.

  1. 웹에서는 Claude 사이트에 로그인해 바로 씁니다.
  2. Claude 사이트 아래쪽의 데스크톱 앱 다운로드를 눌러 앱을 설치합니다(무료 사용자도 가능).
  3. 휴대폰에서는 앱 스토어(또는 Play 스토어)에서 Claude 앱을 설치하고 같은 계정으로 로그인합니다.
  4. 업무용과 개인 계정을 같이 쓴다면, 모바일 앱에서 로그아웃 없이 두 계정에 동시에 로그인해 전환합니다.
  5. Mac 데스크톱·웹에서는 대화 검색을 Command K로 열 수 있습니다.
  • iPad·iPhone Duo에서는 Claude가 만든 아티팩트가 대화 옆 열에 열려 두 창을 나란히 쓸 수 있습니다.
  • 모바일 음성 모드는 더 빨라졌고, iPhone에서는 Apple CarPlay를 지원합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공될 예정입니다.

4. Claude에게 나를 알려 주며 시작하기

AI를 잘 쓰는 핵심은 나에 대한 맥락을 주는 것입니다. 첫날 몇 가지 질문으로 Claude가 나와 내 일을 파악하게 하면 이후 답이 훨씬 맞춤형이 됩니다.

  1. Claude 데스크톱 앱을 설치하고, 필요하면 폴더 접근을 허락합니다.
  2. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 Claude가 나를 얼마나 아는지 확인합니다.
  3. 폴더 접근을 허락했다면 "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  4. "너는 뭘 할 수 있니?"라고 묻습니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  6. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시
이제 나를 알았으니까, 네가 내 업무에서 도와줄 수 있는 일을 5가지만 구체적으로 제안해 줘.
  • 파일은 읽기만 하고 고치지 말라고 미리 지시하는 것이 안전합니다.
  • 하루 30분씩 AI에게 질문하고 AI도 나에게 질문하게 하면 맥락이 쌓입니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.
  • 답이 의심스러우면 근거 자료를 가져오게 하거나, 다른 AI로 교차 검증하세요.

5. 작업에 맞는 모델 고르기

Claude는 Haiku(빠르고 가벼움), Sonnet(균형), Opus(가장 강력), Fable 등 여러 모델을 제공합니다. 작업 성격에 맞춰 고르면 속도와 사용량을 아낄 수 있습니다.

  1. 질문창의 모델 전환(model switcher) 메뉴를 엽니다.
  2. 메일·요약처럼 가벼운 일상 작업은 Sonnet을 고릅니다.
  3. 복잡하거나 열린 조사 작업은 유료 플랜에서 Fable 5.2 같은 상위 모델을 선택합니다.
  4. 품질이 중요한 작업(예: 슬라이드)은 노력 수준(effort)을 높여 돌려 봅니다.
  5. 결과가 부족하면 같은 질문을 상위 모델로 다시 돌려 비교합니다.
  • 무료 플랜은 Sonnet까지 쓸 수 있고, Opus 이상은 유료 사용자용입니다.
  • 상위 모델은 단가가 높아도 적은 단계로 끝내 총비용이 낮아지거나 더 빨리 끝나는 경우가 있습니다.
  • 반복 작업(요약, 메일 초안)은 Opus나 Sonnet으로, 심층 조사처럼 열린 작업은 상위 모델을 medium effort로 시작해 올리는 방식이 소개되었습니다.
  • 예전 방식: 2월에는 Sonnet 4.6이 무료·Pro의 기본 모델이었고, 현재는 유료 플랜에서 Fable 5.2도 선택할 수 있습니다.

6. 웹 검색과 딥 리서치 켜기

최신 정보가 필요하면 웹 검색을, 시장 조사나 경쟁사 분석처럼 깊은 조사가 필요하면 딥 리서치를 씁니다. 모델은 훈련 시점 이후 사실을 검색 없이는 확실히 알지 못하기 때문입니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 입력창에 /딥리서치를 입력하거나 + → 리서치를 선택합니다.
  5. 조사 목적과 범위를 적어 요청하고 결과를 기다립니다.
예시
/딥리서치 국내 중소기업이 쓰는 협업 툴 시장 현황과 주요 경쟁사 3곳을 비교해서 정리해 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 예전 방식: 5월 영상에서는 + 버튼의 연구 메뉴로 딥 리서치를 켰습니다.
  • 출처 링크를 열어 중요한 숫자는 직접 확인하세요.

7. 메모리·개인정보 설정 점검하기

AI에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습 중 한 곳 이상으로 갈 수 있습니다. 회사 일에 쓰기 전에 설정을 한 번 점검해 두면 안심하고 쓸 수 있습니다.

  1. 계정이나 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 메모리를 쓰려면 설정에서 채팅 검색·참조와 메모리 생성을 켭니다.
  3. 저장된 메모리 중 틀리거나 필요 없는 것은 수정하거나 지웁니다.
  4. 메모리가 필요 없으면 끕니다.
  5. 메일 문구 다듬기처럼 실명이 필요 없는 작업에서는 이름을 자리표시자로 바꿔 입력합니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 확인합니다.
  • 모델 자체는 대화 안에서만 맥락을 갖고 새 대화는 빈 상태로 시작합니다. 메모리는 계정에 저장된 정보를 참고하는 방식입니다.
  • 회사 일에 쓰기 전에 대화가 모델 학습에 쓰이지 않도록 설정을 확인하세요. 메뉴 이름은 앱 버전에 따라 다를 수 있습니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 메모리 기능은 2026년 3월 무료 사용자까지 확대되었습니다.

8. 채팅·코워크·코드·디자인 구분하기

Claude에는 목적이 다른 네 가지 도구가 있어, 용도에 맞게 골라 쓰면 됩니다. 처음에는 어떤 일에 어떤 도구를 쓸지만 알아 두면 충분합니다.

  1. 생각 정리, 아이디어, 데이터 패턴 분석은 채팅에서 합니다.
  2. 파일 정리와 엑셀·워드 보고서 작성은 코워크에서 합니다.
  3. 웹사이트·앱 제작은 코드에서 합니다.
  4. 발표 자료는 디자인에서 만듭니다.
  5. 하나의 자료(예: 고객 설문 데이터)를 채팅 분석 → 코워크 보고서 → 코드 대시보드 → 디자인 슬라이드 순으로 이어서 써 봅니다.
  • 코워크는 클로드 코드와 같은 엔진을 쓰는 사무용 버전입니다.
  • 9월 16일 채팅과 코워크가 하나로 합쳐졌고, 10월 8일 Docs·슬라이드·디자인이 무료 플랜까지 확대되었습니다.
  • 예전 방식: 8월 영상에서는 코워크·코드·디자인을 Pro 이상에서만 쓸 수 있다고 소개했으니, 내 플랜에서 되는지 직접 확인하세요.

9. 코워크로 폴더 업무 맡기기

코워크는 폴더 접근을 허용하면 Claude가 계획을 세워 파일을 읽고 정리하고, 엑셀·문서 같은 결과물을 만들어 주는 기능입니다. 다운로드 폴더 정리나 영수증 이미지로 경비 보고서 만들기 같은 일에 씁니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 설치하고 Pro 이상 플랜(Pro, Max, Team, Enterprise)으로 로그인합니다.
  2. 앱에서 코워크를 엽니다.
  3. 작업할 폴더에 대한 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 작업을 설명하면 Claude가 먼저 계획을 제안합니다. 계획을 확인하고 승인합니다.
  6. 파일을 바꾸기 전 권한 요청이 뜨면 내용을 확인한 뒤 허용합니다.
예시
다운로드 폴더의 파일을 종류별로 정리할 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 처음에는 macOS 전용이었으나 2월 중순부터 Windows에서도 쓸 수 있고, 5월에 정식 제공되었습니다.
  • 중요한 폴더는 처음에 복사본으로 시험해 보세요.

10. 글로벌 인스트럭션으로 규칙 고정하기

매번 같은 말을 반복하지 않도록, 역할·보고서 톤·날짜 형식 같은 규칙을 한 번 적어 두는 기능입니다. 코워크의 모든 작업에 적용됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 누릅니다.
  4. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  5. 저장을 눌러 이후 모든 코워크 작업에 적용합니다.
예시
너는 마케팅 팀의 업무 보조야. 보고서는 존댓말로 간결하게 쓰고, 날짜는 2026-11-18 형식으로 적어. 파일을 삭제하기 전에는 반드시 나에게 확인해.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하거나 프롬프트로 지침을 넣습니다.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.
