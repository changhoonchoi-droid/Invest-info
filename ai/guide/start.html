Claude 시작하기

Claude를 처음 쓰는 직장인이 알아야 할 기본기를 모았습니다. 대화할 때 Claude 안에서 어떤 일이 일어나는지, 작업에 맞는 모델과 effort(추론 노력)를 고르는 방법, 메모리와 개인정보 설정을 관리하는 방법, 관리자가 조직에서 쓸 모델을 정하는 방법을 다룹니다. 원리부터 읽고 모델 고르기와 개인정보 설정을 본 뒤, 팀을 관리한다면 마지막 관리자 가이드로 넘어가세요.

1. Claude가 답을 만드는 방식 알고 쓰기

Claude는 학습한 내용을 바탕으로 다음 단어를 예측해 답을 한 단어씩 만들어 냅니다. 이때 내 메시지만 보는 것이 아니라 업로드한 문서, 메모리, 대화 기록 전체를 함께 참고합니다. 이 원리를 알면 맥락을 어떻게 주고 답을 어떻게 확인해야 하는지 판단하기 쉬워집니다.

  1. 질문할 때 필요한 배경 설명이나 관련 문서를 함께 올려 Claude가 참고할 맥락을 줍니다.
  2. 같은 대화 안에서 이어서 질문하면 앞의 대화 내용이 함께 반영된다는 점을 활용합니다.
  3. 새 대화는 빈 상태로 시작하므로 필요한 맥락은 새 대화에서 다시 알려 줍니다.
  4. 답이 마음에 들지 않으면 다른 버전을 여러 개 요청해 비교합니다.
  5. 학습 시점(training cutoff) 이후의 최신 사실은 검색 도구 없이는 정확하지 않을 수 있으니 따로 확인합니다.
  6. 숫자, 이름, 인용처럼 중요한 내용은 원문과 직접 대조합니다.
예시
방금 쓴 답변을 더 간결한 버전, 더 공손한 버전, 핵심만 담은 버전으로 각각 다시 써 줘.
  • Claude는 저장된 답을 꺼내는 것이 아니라 새로 만들어 내기 때문에, 같은 질문에도 매번 조금씩 다른 답이 나올 수 있습니다.
  • 틀린 내용도 자신 있게 말할 수 있으니, 업무에 쓰는 결과물은 반드시 직접 검토합니다.
  • 모델은 사전 학습(다음 단어 예측 반복)과 미세 조정(답변 평가를 바탕으로 한 조정) 두 단계를 거쳐 만들어집니다.

2. 작업에 맞는 모델과 effort 고르기

작업 비용은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 더 똑똑한 모델은 적은 단계로 작업을 끝내기 때문에 오히려 총비용이 줄어들 수 있습니다. 작업이 얼마나 열려 있는지에 따라 모델과 effort를 고르면 결과물과 비용을 함께 챙길 수 있습니다.

  1. 먼저 할 작업이 심층 조사처럼 열린 작업인지, 요약이나 메일 초안처럼 반복 작업인지 나눕니다.
  2. 열린 작업이면 Fable 5.1을 고르고 effort를 medium으로 두고 시작합니다.
  3. 결과가 부족하면 effort를 한 단계씩 올려 다시 실행합니다.
  4. 요약이나 메일 초안 같은 반복 작업은 Opus나 Sonnet을 고릅니다.
  5. 긴 문서를 한꺼번에 다룰 때는 100만 토큰 컨텍스트(베타)를 지원하는 Sonnet 4.6을 고려합니다.
  • Fable 5.1은 Fable 5와 토큰 단가는 같지만 캐시 읽기 비용이 75% 낮아, 일반 작업은 약 25%, 긴 에이전트 작업은 최대 약 45%까지 비용이 줄어듭니다.
  • CursorBench 벤치마크에서 Fable 5.1 medium은 Fable 5 max와 비슷한 결과를 약 5분의 1 비용으로 냈습니다.
  • 2026년 2월 기준 Free·Pro 플랜에서는 claude.ai와 Claude Cowork의 기본 모델이 Sonnet 4.6입니다. 지금 쓰는 기본값은 앱에서 직접 확인하세요.

3. 메모리와 개인정보 설정 점검하기

Claude에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 향후 모델 학습 중 한 곳 이상에 쓰일 수 있습니다. 메모리는 모델 안이 아니라 계정에 저장되는 정보라서 편집하거나 지우거나 끌 수 있습니다. 업무 정보를 다루기 전에 한 번씩 설정을 점검해 두면 내 정보를 스스로 관리할 수 있습니다.

  1. 계정이나 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글이 어떻게 되어 있는지 확인합니다.
  2. 저장된 메모리 가운데 틀리거나 필요 없는 것은 고치거나 지웁니다.
  3. 메모리가 필요 없다면 메모리 기능을 끕니다.
  4. 정보를 입력하기 전에 그 정보가 이번 대화, 저장 메모리, 향후 학습 중 어디에 쓰일지 생각합니다.
  5. 메일 문구 다듬기처럼 실명이 필요 없는 작업에서는 이름을 [고객명] 같은 자리표시자로 바꿔 입력합니다.
  6. 기밀이거나 규제를 받는 데이터라면 비즈니스나 엔터프라이즈 플랜을 쓰고, 제공 문서에서 데이터 처리 조건을 확인합니다.
예시
아래 메일 문구를 정중하고 간결하게 다듬어 줘: [고객명]님, 요청하신 [제품명] 견적서를 첨부드립니다. 검토 후 회신 부탁드립니다.
  • 제품에 따라 메모리가 처음부터 켜져 있을 수 있으니 처음 쓸 때 꼭 확인합니다.
  • 조직이 Claude를 도입한 경우에는 모델 학습이 기본적으로 꺼져 있습니다.
  • 정책은 제공사마다 다르니 쓰는 도구의 개인정보 처리방침과 데이터 보관 설정을 직접 확인합니다.
  • 일상적인 용도라면 일반 소비자용 버전으로도 충분한 경우가 많습니다.

4. 관리자로 조직 모델 기본값 정하기

조직 관리자는 구성원이 쓸 수 있는 모델, 모델별 최대 effort, 새 대화의 기본 모델을 정할 수 있습니다. 역할마다 작업 성격이 다르기 때문에 이 값을 역할에 맞게 나눠 정하면 결과물과 비용의 균형을 맞출 수 있습니다.

  1. 모델 권한(entitlements)에서 구성원이 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)에서 모델별로 쓸 수 있는 최대 effort를 정합니다.
  3. 기본값(defaults)에서 새 대화를 시작할 때 쓸 모델과 effort를 정합니다.
  4. 긴 조사처럼 열린 작업이 많은 역할은 Fable 5.1을 기본으로 정하고 effort 상한을 검토합니다.
  5. 요약이나 초안 작성 같은 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 정하고, Fable은 필요할 때 고를 수 있도록 권한만 열어 둡니다.
  • 이 설정은 역할별로 따로 정할 수 있습니다.
  • 작업 비용은 모델, effort, 캐시 세 가지로 정해지므로 기본값을 바꾼 뒤에는 실제 사용량을 확인하며 조정합니다.
