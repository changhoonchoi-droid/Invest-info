1. Claude 가입하고 첫 대화 시작하기

Claude 사이트에 가입하고 모델을 골라 첫 질문을 던지는 가장 기본적인 과정입니다. 설치 없이 웹에서 바로 시작할 수 있고, 필요하면 데스크톱 앱을 추가로 설치합니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 필요하면 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다(무료 사용자도 가능).
  4. 질문창의 모델 선택에서 기본 작업용으로 Sonnet을 고릅니다.
  5. 질문창의 마이크를 눌러 말로 질문하거나 타이핑으로 질문합니다.
  • 타이핑 대신 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤, 답을 보고 고쳐 달라고 하세요.

2. AI에게 나를 알려 주며 시작하기

AI가 나에 대한 맥락을 알수록 답이 좋아지므로, 첫날 나를 알려 주는 대화를 나누는 방법입니다. 하루 30분씩 서로 질문을 주고받는 습관이 맥락을 쌓아 줍니다.

  1. Claude 데스크톱 앱을 설치하고 폴더 접근을 허락합니다.
  2. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  3. "너는 뭘 할 수 있니?"라고 물어 기능을 확인합니다.
  4. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  5. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시
컴퓨터 보고 나에 대해 파악해 줘. 파일은 읽기만 하고 절대 고치지 마.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 처음에는 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시작하세요.
  • 답이 의심스러우면 근거 자료를 가져오게 하거나 다른 AI로 교차 검증하세요.

3. 요금제 고르고 구독 시점 정하기

무료로 시작해 한도에 막힐 때 유료로 넘어가는 요금제 선택 기준입니다. 금액보다 쓰다가 한도에 막히는지, 쓴 만큼 돈·시간·성과가 나는지를 기준으로 판단합니다.

  1. 먼저 무료 플랜으로 업무에 써 봅니다.
  2. 사용 한도에 자주 막히는지 확인합니다.
  3. 막힌다면 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다. 무료의 약 5배 사용량입니다.
  4. Pro로도 부족하면 Max(월 100달러 또는 200달러)를 검토합니다.
  5. 구독한 만큼 돈·시간·성과가 나는지 따져 보고 유지 여부를 정합니다.
  • 코워크·코드·디자인은 Pro(최소 월 20달러) 이상에서 쓸 수 있고, 채팅은 무료로도 가능합니다.
  • Max 200달러는 Pro의 20배, 100달러는 5배 사용량입니다.
  • 국내 가격은 영상에 따라 Pro 약 3만 원, Max 최소 약 15만 원으로 소개됩니다.
  • 코딩 작업이 많으면 토큰이 더 저렴한 Claude를 추천한다는 의견이 있습니다.

4. 작업에 맞는 Claude 모델 고르기

Claude 모델은 작업의 성격에 따라 골라 쓰면 비용과 시간을 아낄 수 있습니다. 일상 작업은 가벼운 모델, 깊은 조사 같은 열린 작업은 상위 모델이 맞습니다.

  1. 질문창의 모델 선택 메뉴를 엽니다.
  2. 요약, 메일 초안 같은 반복 작업에는 Sonnet이나 Opus를 고릅니다.
  3. 심층 조사처럼 열린 작업에는 Fable 5.1을 medium effort로 시작합니다.
  4. 결과가 부족하면 effort를 한 단계씩 올립니다.
  5. 관리자라면 모델 권한(entitlements), effort 상한(caps), 기본값(defaults)으로 조직 설정을 정합니다.
  • 작업 비용은 모델, effort, 캐시 세 가지로 정해집니다.
  • 더 똑똑한 모델은 적은 단계로 끝내 총비용이 낮아질 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고 캐시 읽기 비용이 75% 낮습니다.
  • Sonnet까지 무료이고 Opus 이상은 유료입니다. 2월 이후 Free·Pro의 기본 모델은 Sonnet 4.6이었습니다(예전 방식).

5. 대화가 학습에 쓰이지 않게 설정하기

회사 일에 Claude를 쓰기 전에 대화가 모델 학습에 쓰이지 않도록 데이터 설정을 확인하는 방법입니다. 메모리와 연결된 앱도 함께 점검합니다.

  1. 설정(Settings)에서 데이터 컨트롤 또는 개인정보 관련 메뉴로 들어갑니다.
  2. 모델 개선·학습에 대화를 사용하는 토글(영상 속 이름: Improve the model for everyone)을 찾아 끕니다.
  3. 메모리, 대화 기록, 연결된 앱 설정을 함께 확인합니다.
  4. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  5. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 문서에서 확인합니다.
  • 영상에서 메뉴 위치와 이름이 정확하지 않을 수 있으니, 설정 안에서 데이터 컨트롤 부근을 직접 찾아보세요. (ChatGPT 기준 설명이 섞여 있습니다.)
  • 메일 문구 다듬기처럼 필요 없는 실명은 빼고 자리표시자로 바꿉니다.
  • 모델은 대화 안에서만 맥락을 갖고 새 대화는 빈 상태로 시작하며, 메모리는 계정에 저장된 정보입니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.

6. 웹 검색과 딥 리서치 켜기

Claude가 최신 정보를 찾고 출처를 달도록 웹 검색을 켜는 방법입니다. 시장 조사나 경쟁사 분석처럼 깊은 조사에는 딥 리서치 모드를 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 조사할 내용을 프롬프트로 작성해 요청합니다.
예시
국내 사무용 협업 도구 시장의 주요 경쟁사 세 곳을 비교하고, 출처 링크와 함께 표로 정리해 줘.
  • 모델은 훈련 시점 이후의 사실을 검색 도구 없이는 확실히 알지 못합니다.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.

7. 모바일 앱 새 기능 활용하기

Claude 모바일 앱의 최근 업데이트로 계정 전환, 음성 모드, 태블릿 화면 등이 좋아졌습니다. 출퇴근길이나 이동 중에도 업무 계정과 개인 계정을 오가며 쓸 수 있습니다.

  1. iOS 또는 Android에서 Claude 앱을 최신 버전으로 업데이트합니다.
  2. 업무용과 개인 계정을 로그아웃 없이 둘 다 로그인해 전환합니다.
  3. 음성 모드를 켜서 말로 질문합니다(iPhone은 Apple CarPlay 지원).
  4. iPad나 iPhone Duo에서는 Claude가 만든 아티팩트를 대화 옆 열에서 열고 두 창을 나란히 씁니다.
  5. iPhone에서 사진을 고르면 업로드 중에도 바로 채팅에 표시되는 것을 확인합니다.
  • 앱 인터페이스는 총 33개 언어를 지원합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공 예정이며, 웹과 데스크톱에는 이미 있습니다(Mac은 Command K).
  • Chromebook·폴더블의 Android 앱은 크기 조절 사이드바, 마우스 우클릭, Claude Desktop과 같은 단축키를 지원합니다.

8. 채팅·코워크·코드·디자인 구분해 쓰기

Claude에는 목적이 다른 네 가지 도구가 있어 용도에 맞게 고르면 됩니다. 생각 정리는 채팅, 파일 정리는 코워크, 웹사이트·앱 제작은 코드, 발표 자료는 디자인입니다.

  1. 생각 정리나 분석은 채팅에서 합니다.
  2. 엑셀·워드 보고서 같은 파일 업무는 코워크에서 합니다.
  3. 웹사이트나 앱, 대시보드 제작은 코드에서 합니다.
  4. 발표 슬라이드는 디자인에서 마무리합니다.
  5. 코워크·코드·디자인은 Pro 이상 플랜인지 확인합니다.
  • 코워크는 클로드 코드와 같은 엔진을 쓰는 사무용 버전입니다.
  • 코워크는 데스크톱 앱에서만 쓸 수 있습니다.
  • 프로젝트는 맥락을, 스킬은 작업 방식을, 커넥터는 외부 도구를, 코워크는 실행을 맡습니다.

9. 코워크로 폴더 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 계획을 세우고 파일을 읽어 엑셀·문서 같은 결과물을 만드는 기능입니다. 코딩 없이 파일 정리나 보고서 작성을 맡길 때 씁니다.

  1. Claude 데스크톱 앱(macOS 또는 Windows)을 설치합니다.
  2. 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. Google Drive, Notion, Slack 같은 서비스가 필요하면 커넥터를 연결합니다.
  5. 맡길 작업을 설명하면 Claude가 제안하는 계획을 확인합니다.
  6. 계획을 승인해 실행시키고, 파일 변경 전 권한 요청에 응답합니다.
예시

  • Pro, Max, Team, Enterprise 사용자에게 제공됩니다.

  • 예전 방식: 처음에는 macOS 전용이었으나 2026년 2월 중순부터 윈도우에서도 쓸 수 있습니다.

10. 글로벌 인스트럭션으로 규칙 정하기

매번 같은 말을 반복하지 않도록 역할, 보고서 톤, 날짜 형식 같은 규칙을 한 번 적어 두는 설정입니다. 저장하면 이후 모든 코워크 작업에 적용됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 누릅니다.
  4. 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  5. 저장을 누릅니다.
예시
나는 마케팅팀 직장인이야. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적어. 파일을 삭제하기 전에는 반드시 먼저 물어봐.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하거나 프롬프트로 지침을 넣습니다.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인하세요.
