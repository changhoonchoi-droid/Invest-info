Claude 시작하기

「Claude 시작하기」에서는 Claude가 답을 만드는 원리를 알아보고, 작업에 맞는 모델과 노력 수준을 고르는 법을 배웁니다. 내 정보가 어디에 저장되는지 확인하는 설정, 모바일·데스크톱 앱의 기본 기능, 작업을 통째로 맡기는 Cowork도 다룹니다. 원리 이해 → 모델 고르기 → 개인정보 설정 → 앱 사용 → Cowork 순서로 보면 좋습니다. 마지막 가이드는 조직 관리자용입니다.

최근 바뀐 점

  • Claude 모바일 앱(iOS·Android)에서 업무용 계정과 개인 계정에 함께 로그인해 두고, 로그아웃 없이 바꿔 가며 쓸 수 있습니다.
  • iPad에서는 Claude가 만든 아티팩트가 대화 옆 열에 열려 두 창을 나란히 볼 수 있습니다.

  • 앱에서 고를 수 있는 언어가 24개 늘어 모두 33개가 됐고, Chromebook·폴더블의 Android 앱은 크기 조절 사이드바, 마우스 우클릭, Claude Desktop과 같은 단축키를 지원합니다.

1. Claude가 답을 만드는 원리 알기

Claude는 정해진 답을 꺼내 오지 않고, 학습한 내용과 지금 대화의 맥락을 보고 다음 단어를 예측하며 답을 새로 씁니다. 이 원리를 알면 같은 질문에도 답이 달라지는 이유와, 틀린 내용을 자신 있게 말할 수 있는 이유를 이해할 수 있습니다. 처음 쓰기 전에 알아 두면 좋습니다.

  1. Claude는 내 메시지, 올린 문서, 메모리, 대화 기록 전체를 보고 답한다는 점을 기억합니다.
  2. 새 대화는 앞 대화를 기억하지 못한 채 시작하므로, 필요한 배경은 새 대화에서 다시 알려 줍니다.
  3. 답은 그때그때 새로 쓰는 것이니, 마음에 들지 않으면 다른 버전을 여러 개 써 달라고 합니다.
  4. 학습 시점(training cutoff) 이후의 일은 검색 도구가 없으면 확실히 모르므로, 최신 정보는 검색 결과나 원문으로 확인합니다.
  5. 자신 있게 말한 답도 틀릴 수 있으니, 숫자·사실·인용은 직접 확인한 뒤 업무에 씁니다.
예시
아래 메일 초안을 정중한 버전, 짧은 버전, 친근한 버전 세 가지로 다시 써 줘.
  • 학습은 다음 단어 맞히기를 반복하는 사전 학습과, 답을 평가해 더 유용하고 해롭지 않게 고치는 미세 조정 두 단계로 이뤄집니다.
  • Claude의 답은 휴대폰 키보드의 단어 추천과 달리 대화 맥락 전체를 반영합니다.

2. 작업에 맞는 모델과 effort 고르기

어떤 모델을 쓰는지, 얼마나 깊이 생각하게 하는지(effort)에 따라 답의 질과 비용이 달라집니다. 열린 조사 작업에는 상위 모델을, 요약·메일 초안 같은 반복 작업에는 가벼운 모델을 고르면 효율적입니다.

  1. 할 일이 심층 조사처럼 답이 열려 있는 일인지, 요약이나 메일 초안처럼 반복되는 일인지 먼저 나눕니다.
  2. 열린 작업이면 Fable 5.1 모델을 medium effort로 시작합니다.
  3. 결과가 부족하면 effort를 한 단계씩 올려 다시 시킵니다.
  4. 요약·메일 초안 같은 반복 작업은 Opus나 Sonnet 모델로 합니다.
  5. Free·Pro 플랜이라면 기본 모델이 Sonnet 4.6이므로, 일상 업무는 기본값으로 시작해도 됩니다.
  • 작업 비용은 모델, effort, 캐시 세 가지로 정해집니다. 더 똑똑한 모델은 적은 단계로 일을 끝내 총비용이 오히려 낮을 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고, 캐시 읽기 비용은 75% 낮습니다. 일반 작업은 약 25%, 긴 에이전트 작업은 최대 약 45%까지 비용이 줄어듭니다.
  • Sonnet 4.6은 100만 토큰 컨텍스트 윈도우를 베타로 제공해, 긴 문서를 다룰 때 좋습니다.

3. 메모리·개인정보 설정 점검하기

Claude에 입력한 정보는 대화, 제품 메모리, 제공사 시스템, 이후 모델 학습의 네 곳으로 갈 수 있습니다. 설정을 정기적으로 점검하고 민감한 정보를 덜어 내는 습관을 들이면, 업무에 쓰면서도 내 정보를 직접 관리할 수 있습니다.

  1. 계정이나 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 토글을 확인합니다.
  2. 저장된 메모리 중 틀리거나 필요 없는 것은 고치거나 지웁니다. 메모리가 필요 없으면 꺼 둡니다.
  3. 정보를 입력하기 전에 그 정보가 이 대화에만 쓰일지, 메모리에 남을지, 학습에 쓰일 수 있을지 생각합니다.
  4. 메일 문구 다듬기처럼 실명이 필요 없는 작업은 이름을 자리표시자로 바꿔 입력합니다.
  5. 기밀·규제 대상 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고, 문서에서 데이터 처리 조건을 확인합니다.
예시
[고객명]님께 납기 지연을 사과하는 메일을 정중하게 다듬어 줘. 지연 기간은 [N]일이야.
  • 메모리는 모델 안이 아니라 계정에 저장되는 정보입니다. 제품에 따라 처음부터 켜져 있을 수 있으니 꼭 확인합니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본으로 꺼져 있습니다.
  • 정책은 제공사마다 다르니, 쓰는 도구의 개인정보 처리방침과 데이터 보관 설정을 직접 확인합니다.
  • 일상적인 용도라면 일반 소비자용 버전으로 충분한 경우가 많습니다.

4. 모바일 앱 새 기능 활용하기

Claude 모바일 앱(iOS·Android)에서 업무용 계정과 개인 계정을 오가고, 태블릿에서는 아티팩트를 대화 옆에 띄워 볼 수 있습니다. 음성 모드와 CarPlay를 쓰면 이동 중에도 말로 Claude를 쓸 수 있습니다.

  1. 모바일 앱에서 업무용 계정과 개인 계정에 모두 로그인해 두고, 로그아웃 없이 필요한 계정으로 바꿔 씁니다.
  2. iPad에서는 Claude가 만든 아티팩트를 대화 옆 열에 열어 두 창을 나란히 봅니다.
  3. 운전 중이라면 iPhone을 Apple CarPlay에 연결해 음성 모드로 대화합니다.
  4. iPhone에서 사진을 고르면 업로드 중에도 채팅에 바로 보이므로, 기다리지 말고 이어서 질문을 씁니다.
  5. Chromebook이나 폴더블 기기의 Android 앱에서는 사이드바 크기를 조절하고 마우스 우클릭과 Claude Desktop 단축키를 씁니다.
  • 앱 화면 언어는 33개 언어를 지원합니다.
  • 지난 대화를 찾는 검색은 웹과 데스크톱 앱에 이미 있고(Mac은 Command K), iPhone·iPad의 '당겨서 검색'은 곧 나올 예정입니다.

5. Cowork로 작업 통째로 맡기기

Cowork는 한 단계씩 묻고 답하는 대신 작업 전체를 맡기는 방식입니다. Claude가 내 컴퓨터의 파일, Google Drive·Notion·Slack 같은 서비스, Chrome 브라우저까지 다룹니다. macOS·Windows용 Claude 데스크톱 앱에서 Pro, Max, Team, Enterprise 사용자가 쓸 수 있습니다.

  1. macOS나 Windows에 Claude 데스크톱 앱을 설치하고 Pro 이상 플랜으로 로그인합니다.
  2. Cowork를 열고, Claude가 작업할 폴더에 접근을 허용합니다.
  3. Google Drive, Notion, Slack처럼 필요한 서비스가 있으면 커넥터로 연결합니다.
  4. 브라우저 작업까지 맡기려면 Claude in Chrome을 설정합니다.
  5. 맡길 작업을 문장으로 설명합니다.
  6. Claude가 먼저 내놓는 계획을 읽어 보고, 괜찮으면 승인해 실행시킵니다.
  7. 파일을 바꾸기 전에 Claude가 권한을 물으면, 내용을 확인하고 허용할지 정합니다.
예시
다운로드 폴더에 있는 파일을 종류별로 하위 폴더를 만들어 정리해 줘. 실행하기 전에 계획부터 보여 줘.
  • Free·Pro 플랜에서 Cowork의 기본 모델은 Sonnet 4.6입니다.
  • 처음에는 다운로드 폴더 정리처럼 잘못돼도 되돌리기 쉬운 작업으로 연습합니다.

6. 조직의 모델 기본값 정하기(관리자)

Team·Enterprise 관리자는 직원이 고를 수 있는 모델, 모델별 최대 effort, 새 대화의 기본 모델과 effort를 정할 수 있습니다. 역할별로 따로 설정할 수 있어, 성능과 비용을 함께 관리할 수 있습니다.

  1. 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)으로 모델마다 최대 effort를 정합니다.
  3. 기본값(defaults)으로 새 대화가 어떤 모델과 effort로 시작할지 정합니다.
  4. 길고 답이 열린 작업이 많은 역할은 Fable 5.1을 기본으로 하고, effort 상한을 검토합니다.
  5. 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 하고, Fable은 권한만 열어 둡니다.
  • 역할별로 설정을 따로 할 수 있습니다.
  • CursorBench 결과로 보면 Fable 5.1 medium은 Fable 5 max와 비슷한 결과를 약 5분의 1 비용으로 냈습니다. 상한을 너무 높게 잡을 필요가 없을 수 있습니다.
