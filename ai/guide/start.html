Claude 시작하기

Claude를 처음 쓰는 직장인이 AI가 답을 만드는 방식을 알고, 내 정보와 메모리 설정을 점검하고, 작업에 맞는 모델을 고르는 법까지 순서대로 익히는 페이지입니다. 앞의 입문 가이드 두 개로 기본 사용 습관을 잡고, 모델·effort 고르기와 데스크톱 앱 연결로 넘어가세요. 조직 관리자라면 마지막 가이드에서 팀 전체의 모델 기본값을 정할 수 있습니다.

1. AI가 답을 만드는 원리 알고 질문하기

Claude는 정해진 답을 꺼내 오지 않습니다. 내 메시지, 올린 문서, 메모리, 대화 기록 전체를 보고 다음 단어를 예측하면서 답을 새로 씁니다. 이 원리를 알면 맥락을 충분히 주는 법, 여러 버전을 받아 보는 법, 틀린 답을 걸러 내는 법을 익힐 수 있습니다.

  1. 질문할 때 목적, 대상, 원하는 형식 같은 배경을 메시지에 함께 적습니다.
  2. 참고할 자료가 있으면 문서를 대화에 올려 Claude가 함께 보게 합니다.
  3. 답이 마음에 들지 않으면 같은 내용을 다른 버전으로 다시 써 달라고 합니다.
  4. 최근 사건이나 최신 수치는 모델이 학습 시점(training cutoff) 이후 내용을 확실히 모를 수 있으니 출처를 따로 확인합니다.
  5. 다른 주제를 시작할 때는 새 대화를 엽니다. 새 대화는 이전 맥락 없이 빈 상태로 시작한다는 점을 기억합니다.
예시
아래 메일 초안을 정중한 버전, 간결한 버전, 친근한 버전 세 가지로 다시 써 줘. 받는 사람은 거래처 담당자야.
  • AI는 틀린 내용도 자신 있게 말할 수 있으니 숫자·날짜·고유명사는 꼭 확인합니다.
  • 답은 매번 새로 만들어지므로 같은 질문에도 결과가 조금씩 다를 수 있습니다.

2. 메모리·개인정보 설정 점검하기

Claude에 입력한 정보는 대화, 계정에 저장되는 메모리, 제공사 시스템, 향후 모델 학습의 네 곳으로 갈 수 있습니다. 업무에 쓰기 전에 설정을 한 번 점검하고 정보를 공유하는 습관을 잡아 두면 회사 정보와 개인정보를 지킬 수 있습니다.

  1. 계정이나 개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 사용 토글을 확인합니다.
  2. 저장된 메모리 가운데 틀리거나 필요 없는 내용을 고치거나 지웁니다.
  3. 메모리가 필요 없으면 꺼 둡니다.
  4. 정보를 입력하기 전에 그 정보가 이번 대화에만 쓰일지, 메모리에 저장될지, 학습에 쓰일 수 있을지 생각합니다.
  5. 메일 문구 다듬기처럼 실명이 필요 없는 작업은 이름을 [고객명] 같은 자리표시자로 바꿔 입력합니다.
  6. 기밀이나 규제 대상 데이터는 비즈니스·엔터프라이즈 플랜을 쓰고, 문서에서 데이터 처리 조건을 확인합니다.
예시
[고객명]님께 보낼 납품 일정 변경 안내 메일을 정중하게 다듬어 줘. 변경된 날짜는 [변경일]이야.
  • 메모리는 모델 안이 아니라 계정에 저장되며, 제품에 따라 처음부터 켜져 있을 수 있습니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 정책은 제공사마다 다르니 쓰는 도구의 개인정보 처리방침과 데이터 보관 설정을 직접 확인합니다.
  • 일상적인 용도에는 일반 소비자용 버전으로 충분한 경우가 많습니다.

3. 작업에 맞는 모델과 effort 고르기

작업 비용은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 더 똑똑한 모델은 적은 단계로 일을 끝내서 총비용이 오히려 낮아질 수 있습니다. 작업 종류에 맞게 모델과 effort를 고르면 품질과 비용을 함께 챙길 수 있습니다.

  1. 할 일이 심층 조사처럼 열린 작업인지, 요약이나 메일 초안처럼 반복 작업인지 먼저 나눕니다.
  2. 열린 작업은 Fable 5.1을 고르고 effort를 medium으로 시작합니다.
  3. 결과가 부족하면 effort를 한 단계씩 올려 다시 시켜 봅니다.
  4. 요약, 메일 초안 같은 반복 작업은 Opus나 Sonnet을 고릅니다.
  5. 긴 문서를 한 번에 다뤄야 하면 컨텍스트 윈도우가 큰 모델을 고려합니다. Sonnet 4.6은 100만 토큰 컨텍스트를 베타로 제공합니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고 캐시 읽기 비용은 75% 낮아서, 일반 작업은 약 25%, 긴 에이전트 작업은 최대 약 45% 비용이 줄어든다고 합니다.
  • CursorBench에서 Fable 5.1 medium은 Fable 5 max와 비슷한 결과를 약 5분의 1 비용으로 냈습니다. 처음부터 최고 effort를 고를 필요는 없습니다.
  • 예전 방식: 2026년 2월에는 Free·Pro 플랜의 claude.ai와 Cowork 기본 모델이 Sonnet 4.6으로 바뀌었습니다. 지금의 기본 모델은 앱에서 직접 확인하세요.

4. Claude를 어사이드 브라우저에 연결하기

어사이드(Aside)는 크롬 같은 AI 웹 브라우저로, AI가 웹에서 클릭하고 입력하는 일을 대신 해 줍니다. Claude를 이미 유료로 쓰고 있다면 연결만 하면 되고 어사이드 비용은 따로 들지 않습니다. 메일 확인, 사내 사이트 조회 같은 반복적인 웹 작업을 말로 맡길 때 씁니다.

  1. Claude 데스크톱 앱을 설치하고 로그인합니다.
  2. 어사이드 브라우저를 설치합니다.
  3. 어사이드에 지금 결제 중인 Claude(또는 GPT)를 연결합니다.
  4. 로그인이 필요한 사이트에서도 일을 시키려면 크롬의 로그인 정보를 어사이드로 가져옵니다.
  5. 메일 확인처럼 간단한 일을 말로 시켜 보고 결과를 확인합니다.
예시
받은 메일함에서 오늘 온 메일을 확인해서 답장이 필요한 것만 골라 요약해 줘.
  • 어사이드는 한국인이 만들고 YC 투자를 받은 실리콘밸리 스타트업의 제품이라고 소개됩니다.
  • 로그인 정보를 넘기면 AI가 그 계정으로 작업할 수 있으니, 처음에는 조회처럼 위험이 적은 일부터 맡깁니다.

5. 조직의 모델 기본값 정하기

조직 관리자는 구성원이 쓸 수 있는 모델, 모델별 최대 effort, 새 대화의 기본 모델을 정할 수 있습니다. 역할마다 따로 설정할 수 있어서 팀의 업무 성격에 맞게 비용과 품질을 조절할 수 있습니다.

  1. 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)으로 모델별 최대 effort를 정합니다.
  3. 기본값(defaults)으로 새 대화의 시작 모델과 effort를 정합니다.
  4. 긴 열린 작업이 많은 역할은 Fable 5.1을 기본으로 하고 effort 상한을 검토합니다.
  5. 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 하고, Fable은 권한만 열어 둡니다.
  • 역할별로 따로 설정할 수 있습니다.
  • 작업 비용은 모델, effort, 캐시 세 가지로 정해지니 기본값을 바꾼 뒤 사용량을 함께 살펴봅니다.
