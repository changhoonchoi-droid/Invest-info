1. AI가 답하는 원리 이해하기

Claude 같은 AI는 학습한 내용을 바탕으로 다음 단어를 예측하며 답을 한 단어씩 씁니다. 이 구조를 알면 왜 새로운 글을 만들어 내는지, 왜 틀린 내용을 자신 있게 말하는지 이해하고 답을 걸러 읽을 수 있습니다.

  1. AI는 정해진 답을 꺼내는 것이 아니라 매번 새로 생성한다는 점을 기억합니다.
  2. 마음에 들지 않으면 같은 요청으로 여러 버전을 요청합니다.
  3. AI는 훈련 시점 이후의 사실을 검색 도구 없이는 확실히 모른다는 점을 염두에 둡니다.
  4. 최신 정보가 필요한 질문에는 웹 검색을 켜고 출처를 확인합니다.
  5. 의심스러운 답은 근거 자료를 가져오게 하고, 필요하면 다른 AI로 교차 검증합니다.
예시
이 내용의 근거가 되는 자료나 출처 링크를 함께 알려 줘. 확실하지 않은 부분은 모른다고 말해 줘.
  • 새 대화는 빈 상태로 시작하므로 필요한 배경은 매번 다시 알려 주거나 메모리·프로젝트를 활용합니다.
  • 학습은 다음 단어 예측을 반복하는 사전 학습과, 답변을 평가해 조정하는 미세 조정 두 단계로 이뤄집니다.

2. 무료로 시작해 요금제 고르기

AI 구독료의 기준은 금액이 아니라 쓰다가 한도에 막히는지 여부입니다. 무료로 먼저 써 보고 불편해질 때 유료로 올리면 됩니다.

  1. 무료 플랜으로 먼저 Claude를 일주일 정도 써 봅니다.
  2. 사용 한도에 자주 걸려 일이 막히는지 확인합니다.
  3. 한도에 막힌다면 Pro(월 20달러, 연간 결제 시 월 17달러)로 올립니다. 무료의 약 5배 사용량입니다.
  4. Pro로도 부족하면 Max(월 100달러는 Pro의 5배, 월 200달러는 Pro의 20배)를 검토합니다.
  5. 쓴 만큼 돈·시간·성과가 나는지 따져 보고 유지할지 정합니다.
  • 코워크·코드·디자인은 Pro 이상에서 쓸 수 있고, 채팅은 무료로도 가능합니다.
  • 이미지 생성이 필요하면 ChatGPT, 코딩이 많으면 토큰이 더 싼 Claude가 낫다는 의견이 있습니다.
  • 무료 플랜은 Opus를 쓸 수 없습니다.
  • 가격과 한도는 바뀔 수 있으니 결제 전에 공식 요금 페이지를 확인하세요.

3. Claude 모델과 노력 수준 고르기

작업 비용은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 작업 성격에 맞는 모델을 고르면 품질과 비용을 모두 챙길 수 있습니다.

  1. 모델은 Haiku(빠르고 가벼움), Sonnet(균형), Opus(가장 강력)로 나뉜다는 점을 확인합니다.
  2. 요약이나 메일 초안 같은 반복 작업에는 Opus나 Sonnet을 씁니다.
  3. 심층 조사처럼 열린 작업에는 Fable 5.1을 medium effort로 시작합니다.
  4. 결과가 부족하면 effort를 한 단계씩 올립니다.
  5. 관리자라면 모델 권한(entitlements), effort 상한(caps), 기본값(defaults)으로 조직 설정을 조정합니다.
  • 더 똑똑한 모델은 적은 단계로 끝내 총비용이 낮아질 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고 캐시 읽기 비용이 75% 낮습니다.
  • Free·Pro 플랜의 claude.ai와 Cowork 기본 모델은 Sonnet 4.6입니다(2026년 2월 기준).

4. 나를 알려 주며 첫 대화 시작하기

AI를 잘 쓰는 핵심은 나에 대한 맥락을 주는 것입니다. 첫날 몇 가지 질문만으로 AI가 나를 파악하고 도울 일을 제안하게 만들 수 있습니다.

  1. Claude 앱을 열고 "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 AI가 나를 얼마나 아는지 확인합니다.
  2. "너는 뭘 할 수 있니?"라고 묻습니다.
  3. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  4. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
  5. 답장 초안, 일정 정리, 장보기 목록 같은 작은 일부터 시켜 봅니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 줘. 내가 하나씩 답할게. 다 끝나면 네가 나를 도와줄 수 있는 일을 알려 줘.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던지고, 답을 보고 고쳐 달라고 주고받습니다.
  • 하루 30분 정도 서로 질문을 주고받는 습관이 맥락을 쌓습니다.
  • 영상에서는 완전 초보에게 ChatGPT 보이스 모드로 말하듯 시작하기를 권하지만, 같은 방식으로 Claude 앱에서도 해 볼 수 있습니다.

5. 대화 학습 끄고 개인정보 설정 점검하기

입력한 정보는 대화, 메모리, 제공사 시스템, 향후 모델 학습으로 갈 수 있습니다. 회사 일에 쓰기 전에 설정을 점검해 통제력을 지킵니다.

  1. 계정이나 개인정보 설정(Settings)에서 메모리, 대화 기록, 연결된 앱, 학습 관련 토글을 확인합니다.
  2. 데이터 컨트롤 부근에서 모델 개선에 대화를 쓰는 항목을 찾아 끕니다.
  3. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  4. 정보를 공유하기 전에 대화·저장 메모리·향후 학습 중 어디에 쓰일지 생각합니다.
  5. 메일 문구 다듬기처럼 필요 없는 실명은 빼고 자리표시자로 바꿉니다.
  6. 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 확인합니다.
  • 영상에서 메뉴 이름이 Improve the model for everyone(ChatGPT 기준)로 언급되었으며, Claude 화면의 항목명은 다를 수 있으니 설정 안에서 직접 찾아보세요.
  • 정책은 제공사마다 다르니 개인정보 처리방침과 데이터 보관 설정을 직접 확인합니다.
  • 조직이 Claude를 도입하면 모델 학습은 기본적으로 꺼져 있습니다.
  • 일상적인 용도에는 일반 소비자용 버전으로 충분한 경우가 많습니다.

6. 웹 검색과 딥 리서치 켜기

웹 검색을 켜면 Claude가 최신 정보를 찾아 출처 링크와 함께 답합니다. 시장 조사나 경쟁사 분석처럼 깊은 조사에는 딥 리서치 모드를 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 조사할 주제와 원하는 결과 형태를 프롬프트로 요청합니다.
예시
국내 사무용 협업 도구 시장의 주요 경쟁사 세 곳을 비교하고, 가격과 장단점을 표로 정리해 줘. 출처 링크도 붙여 줘.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 검색 결과의 출처 링크를 직접 열어 확인하는 습관을 들입니다.

7. 채팅·코워크·코드·디자인 골라 쓰기

Claude에는 목적이 겹치지 않는 네 가지 도구가 있습니다. 하려는 일에 맞춰 고르면 같은 자료로도 분석부터 보고서, 웹사이트, 발표 자료까지 이어 갈 수 있습니다.

  1. 생각 정리나 데이터 패턴 분석은 채팅에서 합니다.
  2. 파일 정리와 엑셀·워드 보고서 작성은 코워크에서 합니다.
  3. 웹사이트나 앱 제작은 코드에서 합니다.
  4. 발표 자료와 슬라이드는 디자인에서 마무리합니다.
  5. 코워크·코드·디자인은 Pro 이상 플랜인지 먼저 확인합니다.
  • 채팅은 무료로 쓸 수 있고, 나머지 셋은 Pro(월 20달러) 이상이 필요합니다.
  • 코워크는 클로드 코드와 같은 엔진을 쓰는 문서·파일 업무용 사무 버전입니다.
  • 같은 고객 설문 데이터를 채팅→코워크→코드→디자인 순으로 이어 쓰는 흐름이 영상에서 소개되었습니다.

8. 데스크톱 앱 설치하고 폴더 열어 주기

Claude 데스크톱 앱은 컴퓨터 속 파일을 보여 주며 나를 파악하게 하거나 작업을 맡길 때 씁니다. 코워크는 데스크톱 앱에서만 쓸 수 있어 설치를 권장합니다.

  1. Claude 데스크톱 앱을 설치하고 로그인합니다(macOS·Windows).
  2. 작업할 폴더에 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  4. 파일은 읽기만 하고 고치지 말라고 먼저 지시합니다.
  5. 결과를 확인한 뒤 필요한 작업을 하나씩 시킵니다.
예시

  • 읽기만 하도록 지시하는 것이 안전합니다.
  • Claude는 파일을 변경하기 전에 권한을 요청합니다.

9. 코워크로 폴더 업무 맡기기

코워크는 단계별 대화 대신 작업 전체를 맡기는 방식입니다. 폴더를 열어 주면 Claude가 계획을 제안하고, 승인하면 파일을 읽고 엑셀·문서 같은 결과물을 만듭니다.

  1. Claude 데스크톱 앱에서 코워크 탭을 엽니다.
  2. 작업할 폴더에 접근을 허용합니다.
  3. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  4. 작업을 말로 설명합니다.
  5. Claude가 제안한 계획을 읽고 승인합니다.
  6. 파일 변경 권한 요청이 오면 내용을 확인하고 허용합니다.
예시
다운로드 폴더의 파일을 종류별로 정리할 계획을 먼저 세워 줘. 내가 승인하기 전에는 파일을 옮기거나 삭제하지 마.
  • macOS와 Windows용 데스크톱 앱에서 Pro, Max, Team, Enterprise에 제공됩니다.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 예전 방식: 처음에는 macOS 전용이었으나 2026년 2월 중순 업데이트로 윈도우에서도 쓸 수 있게 되었고, 2026년 5월 영상 기준 정식 제공 상태입니다.

10. 코워크 글로벌 인스트럭션 설정하기

글로벌 인스트럭션은 매번 같은 말을 반복하지 않도록 모든 코워크 작업에 적용되는 규칙을 적어 두는 기능입니다. 역할, 보고서 톤, 날짜 형식 등을 한 번에 정해 둡니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 눌러 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누르면 이후 모든 코워크 작업에 적용됩니다.
예시
나는 마케팅팀 대리야. 보고서는 존댓말로 간결하게 쓰고, 날짜는 YYYY-MM-DD 형식으로 적어 줘. 파일을 삭제하기 전에는 반드시 나에게 확인해 줘.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하거나 프롬프트로 지침을 넣습니다.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.
  • 플러그인(스킬, 커넥터, 슬래시 명령어, 서브에이전트 묶음)으로 직무 지식을 한 번에 넣는 방법도 있습니다.
