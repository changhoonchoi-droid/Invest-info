Claude 시작하기

Claude를 처음 쓰는 직장인이 가입부터 모델·요금제 고르기, 데스크톱 앱 설치, 웹 검색, 개인정보 설정까지 순서대로 따라 할 수 있게 정리했습니다. 먼저 가입과 첫 대화로 익숙해진 뒤 AI에게 나를 알려 주고, 모델·요금제와 도구 선택, 마지막으로 개인정보 설정과 조직 관리자 설정까지 보시면 좋습니다.

1. Claude 가입하고 첫 대화 시작하기

Claude 사이트에서 계정을 만들고 데스크톱 앱까지 설치해 첫 질문을 해 보는 과정입니다. 무료로 시작할 수 있으니 부담 없이 써 보는 것이 입문의 첫걸음입니다.

  1. Claude 사이트에 접속합니다.
  2. 구글로 계속하기 또는 이메일로 계속하기를 눌러 가입합니다.
  3. 필요하면 아래쪽 데스크톱 앱 다운로드로 앱을 설치합니다(무료 사용자도 가능).
  4. 질문창의 모델 선택에서 기본 작업용으로 Sonnet을 고릅니다.
  5. 질문창의 마이크를 눌러 말로 질문해 봅니다.
  • 타이핑 대신 마이크로 맥락을 충분히 말하면 결과가 좋아집니다.
  • 처음에는 답장 초안, 일정 정리 같은 작은 일부터 시작하세요.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤, 답을 보고 고쳐 달라고 하면 됩니다.

2. AI에게 나를 알려 주며 시작하기

AI가 좋은 답을 하려면 나에 대한 맥락이 필요합니다. 첫날 몇 가지 질문으로 AI가 나를 파악하게 만드는 방법입니다. 하루 30분씩 서로 질문을 주고받는 습관이 맥락을 쌓아 줍니다.

  1. Claude 데스크톱 앱을 설치하고 폴더 접근을 허락합니다.
  2. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 AI가 나를 얼마나 아는지 확인합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 프로젝트 맥락을 파악시킵니다.
  4. "너는 뭘 할 수 있니?"라고 묻습니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 요청해 인터뷰를 받습니다.
  6. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 묻습니다.
예시
나에 대해서 궁금한 거 100개까지 물어봐 봐. 한 번에 다섯 개씩 물어봐 줘.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • AI를 전혀 모른다면 ChatGPT 앱의 보이스 모드로 말하듯 시작해도 좋습니다.
  • 답이 의심되면 근거 자료를 가져오게 하고, 다른 AI로 교차 검증하세요.

3. 모델과 요금제 고르기

Claude에는 여러 모델과 요금제가 있습니다. 구독 기준은 금액이 아니라 쓰다가 한도에 막히는지 여부이며, 무료로 불편이 없으면 무료를 쓰면 됩니다.

  1. 먼저 무료 플랜으로 일상 작업을 해 보며 Sonnet까지 써 봅니다.
  2. 한도(사용 제한)에 자주 막히는지 확인합니다.
  3. 막히면 Pro로 올립니다. Opus 이상 모델과 코워크·코드·디자인은 유료에서 쓸 수 있습니다.
  4. 복잡한 작업에만 더 높은 단계의 모델을 선택합니다.
  5. Pro로도 부족할 때 Max를 검토하고, 쓴 만큼 돈·시간·성과가 나는지 따져 봅니다.
  • 모델 단계가 높을수록 똑똑하지만 시간이 오래 걸리니 복잡한 업무에만 씁니다.
  • 요금은 영상마다 다르게 소개됩니다. Pro는 월 20달러(약 3만 원)이고 연간 결제 시 월 17달러, Max는 월 100달러(Pro의 5배)와 200달러(Pro의 20배)입니다. 가입 전 공식 요금 페이지에서 확인하세요.
  • Free·Pro의 claude.ai와 Cowork 기본 모델은 Sonnet 4.6으로 바뀌었습니다(2026년 2월). 예전 방식: 이전 기본 모델을 쓰던 설정은 그대로 둘 필요 없이 기본값을 따르면 됩니다.
  • 입문자가 이미지 생성이 필요하면 ChatGPT, 코딩이 많으면 토큰이 더 싼 Claude를 추천한다는 의견도 있습니다.

4. 웹 검색과 딥 리서치 켜기

Claude가 최신 정보를 검색해 출처와 함께 답하게 하는 기능입니다. 깊은 조사가 필요하면 딥 리서치 모드를 켭니다. 시장 조사, 경쟁사 분석에 유용합니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 활성화합니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 답니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 프롬프트를 작성해 요청합니다.
예시
국내 중소기업용 협업 툴 시장의 주요 경쟁사 5곳을 비교하고, 가격과 특징을 표로 정리해 줘. 출처 링크도 달아 줘.
  • 모델은 훈련 시점 이후의 사실을 검색 없이는 확실히 알지 못하므로 최신 정보는 웹 검색을 켜세요.
  • 다른 영상(채팅·코워크·코드·디자인 소개)에서는 웹 검색을 플러스 버튼에서 켠다고 하니, 화면에서 + 버튼을 찾으면 됩니다.

5. 채팅·코워크·코드·디자인 골라 쓰기

Claude에는 목적이 겹치지 않는 네 가지 도구가 있습니다. 용도에 맞게 골라 쓰면 같은 자료로 분석, 보고서, 웹사이트, 슬라이드까지 이어 갈 수 있습니다.

  1. 생각 정리와 데이터 패턴 분석은 채팅에서 합니다.
  2. 파일 정리와 엑셀·워드 보고서 작성은 코워크에서 합니다.
  3. 웹사이트·앱 제작은 코드에서 합니다.
  4. 발표 자료는 디자인에서 슬라이드로 마무리합니다.
  • 채팅은 무료로 쓸 수 있지만 코워크·코드·디자인은 Pro(월 20달러) 이상이 필요합니다.
  • 코워크는 클로드 코드와 같은 엔진을 쓰는 문서·파일 업무용 사무 버전입니다.
  • 코워크는 데스크톱 앱에서만 쓸 수 있으니 설치해 두세요.

6. 코워크로 폴더 업무 맡기기

코워크는 폴더를 열어 주면 Claude가 계획을 세워 파일을 읽고 엑셀·문서 같은 결과물을 만드는 도구입니다. 코딩 없이 작업 전체를 맡길 때 씁니다.

  1. Claude 데스크톱 앱(macOS 또는 Windows)을 설치합니다.
  2. 코워크 탭을 엽니다.
  3. 작업할 폴더 접근을 허용합니다.
  4. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  5. 하려는 작업을 설명하면 Claude가 먼저 계획을 제안합니다.
  6. 계획을 확인하고 승인하면 실행합니다.
예시
다운로드 폴더의 파일을 종류별로 정리할 계획을 먼저 보여 줘. 내가 승인하기 전에는 파일을 옮기거나 지우지 마.
  • Claude는 파일 변경 전에 권한을 요청합니다.
  • 브라우저 작업은 Claude in Chrome을 설정해야 쓸 수 있습니다.
  • 정식 제공 대상은 Pro, Max, Team, Enterprise입니다.
  • 예전 방식: 처음에는 macOS 전용이었으나 2026년 2월 중순부터 윈도우에서도 쓸 수 있습니다.

7. 코워크 글로벌 인스트럭션 설정하기

매번 같은 말을 반복하지 않도록 역할, 보고서 톤, 날짜 형식 같은 규칙을 한 번 적어 두는 설정입니다. 저장하면 이후 모든 코워크 작업에 적용됩니다.

  1. 왼쪽 위 클로드를 누르고 설정을 엽니다.
  2. Claude Code 아래의 협업 항목에서 지침 탭을 찾습니다.
  3. 편집을 눌러 역할, 보고서 톤, 날짜 형식, 파일 삭제 전 확인 같은 규칙을 적습니다.
  4. 저장을 누릅니다.
예시
나는 마케팅팀 대리야. 보고서는 간결한 존댓말로 쓰고, 날짜는 2026-11-09 형식으로 적어. 파일을 삭제하기 전에는 반드시 나에게 확인해.
  • 특정 폴더에만 규칙을 주려면 코워크가 만드는 CLAUDE.md 파일에 폴더 지침을 추가하거나 프롬프트로 지침을 넣습니다.
  • 영상 자막이 불분명해 지침 탭의 정확한 이름은 화면에서 확인이 필요합니다.

8. 대화가 학습에 쓰이지 않게 설정하기

회사 일에 쓰기 전에 대화가 모델 학습에 쓰이지 않도록 설정을 확인하는 방법입니다. 메모리와 연결된 앱도 함께 점검하면 내 정보를 직접 통제할 수 있습니다.

  1. 설정(Settings)에서 데이터 컨트롤 쪽 메뉴로 들어갑니다.
  2. 모델 개선(학습) 관련 항목(영상에서는 Improve the model for everyone으로 언급)을 찾습니다.
  3. 이 항목을 끕니다.
  4. 계정이나 개인정보 설정에서 메모리, 대화 기록, 연결된 앱 설정도 확인합니다.
  5. 저장된 메모리를 수정하거나 지우고, 필요 없으면 메모리를 끕니다.
  • 영상에서 메뉴 위치와 이름을 정확히 기억하지 못한다고 했습니다. 이 항목은 ChatGPT 기준으로 소개된 것이니, Claude 설정 화면에서 비슷한 항목을 찾아보세요.
  • 메일 문구 다듬기처럼 필요 없는 실명은 빼고 자리표시자로 바꿔 입력하세요.
  • 기밀·규제 데이터는 비즈니스나 엔터프라이즈 플랜을 쓰고 문서에서 데이터 처리 조건을 확인합니다.
  • 모델은 대화 안에서만 맥락을 가지며 새 대화는 빈 상태로 시작합니다. 메모리는 계정에 저장된 정보이고 제품에 따라 기본값이 켜짐일 수 있습니다.

9. 모바일 앱에서 계정 두 개 쓰기

Claude 모바일 앱은 업무용과 개인 계정에 로그아웃 없이 동시에 로그인해 전환할 수 있습니다. 회사 계정과 개인 계정을 섞지 않고 쓰고 싶을 때 유용합니다.

  1. iOS 또는 Android에서 Claude 앱을 최신 버전으로 업데이트합니다.
  2. 업무용 계정으로 로그인합니다.
  3. 개인 계정을 추가로 로그인합니다.

10. 관리자가 조직 모델 기본값 정하기

팀이나 조직에서 Claude를 도입할 때 관리자가 사용자가 쓸 모델과 추론 노력(effort)의 범위를 정하는 방법입니다. 역할별로 따로 설정할 수 있어 비용과 품질을 함께 관리합니다.

  1. 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)으로 모델별 최대 effort를 정합니다.
  3. 기본값(defaults)으로 새 대화의 시작 모델과 effort를 정합니다.
  4. 긴 열린 작업이 많은 역할은 Fable 5.1을 기본으로 하고 effort 상한을 검토합니다.
  5. 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 하고 Fable은 권한만 열어 둡니다.
  • 작업 비용은 모델, effort, 캐시 세 가지로 정해집니다.
  • 심층 조사처럼 열린 작업은 Fable 5.1을 medium effort로 시작해 올리고, 요약이나 메일 초안 같은 반복 작업은 Opus나 Sonnet을 씁니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같고 캐시 읽기 비용이 75% 낮습니다.
