1. 요금제 고르고 무료로 시작하기

Claude는 무료 플랜으로 바로 쓸 수 있고, 더 많이 쓰거나 코워크·코드·디자인 같은 도구가 필요하면 유료 플랜으로 올립니다. 처음에는 무료로 써 보다가 사용 한도에 자주 막힐 때 바꾸는 것이 가장 부담이 적습니다.

  1. 무료 플랜으로 가입해 채팅부터 써 봅니다.
  2. 매일 업무에 쓰다가 사용 한도에 막히는지 확인합니다.
  3. 한도에 자주 막히거나 코워크·코드·디자인이 필요하면 Pro 플랜(월 20달러, 연간 결제 시 월 17달러)으로 올립니다.
  4. Pro로도 사용량이 모자라면 Max 플랜(월 100달러는 Pro의 5배, 월 200달러는 Pro의 20배 사용량)을 검토합니다.
  5. 회사 기밀이나 규제 대상 데이터를 다뤄야 하면 Team·Enterprise 같은 조직용 플랜을 회사와 상의합니다.
  • Pro는 무료 플랜의 약 5배 사용량입니다.
  • 채팅은 무료로 쓸 수 있지만 코워크·코드·디자인은 Pro 이상에서만 쓸 수 있습니다.
  • 예전 방식: 2026년 5월 자료에서는 무료 플랜에서 Opus 모델을 쓸 수 없다고 안내했습니다. 지금 쓸 수 있는 모델은 앱의 모델 선택 메뉴에서 직접 확인하세요.

2. 웹·데스크톱·모바일 앱 골라 쓰기

Claude는 웹 브라우저, macOS·Windows 데스크톱 앱, iOS·Android 모바일 앱에서 쓸 수 있습니다. 가벼운 대화는 어디서나 되지만, 컴퓨터의 폴더를 다루는 코워크는 데스크톱 앱에서만 됩니다.

  1. PC에서는 macOS 또는 Windows용 Claude 데스크톱 앱을 설치합니다 (코워크를 쓰려면 꼭 필요합니다).
  2. 휴대폰에는 iOS 또는 Android용 Claude 앱을 설치하고 같은 계정으로 로그인합니다.
  3. 업무용과 개인 계정을 함께 쓰면 모바일 앱에서 두 계정에 동시에 로그인해 로그아웃 없이 전환합니다.
  4. 이동 중에는 모바일 앱의 음성 모드로 말로 대화합니다 (iPhone은 Apple CarPlay에서도 됩니다).
  5. 지난 대화를 찾을 때 웹과 데스크톱에서는 검색을 쓰고, Mac에서는 Command K를 누릅니다.
  • iPad에서는 Claude가 만든 아티팩트가 대화 옆 열에 열려 두 창을 나란히 볼 수 있습니다.
  • Chromebook·폴더블 기기의 Android 앱은 크기 조절 사이드바, 마우스 우클릭, 데스크톱 앱과 같은 단축키를 지원합니다.
  • iPhone·iPad의 당겨서 검색은 곧 제공될 예정입니다.

3. 첫 대화로 AI에게 나를 알려 주기

AI는 나에 대한 맥락을 알수록 쓸모 있는 답을 줍니다. 첫날에는 AI가 나를 얼마나 아는지 확인하고, 데스크톱 앱에 내 폴더를 보여 주며 나를 파악하게 한 뒤 무엇을 도와줄 수 있는지 묻습니다.

  1. "나에 대해 아는 것을 한 문단으로 설명해 봐"라고 물어 AI가 나를 얼마나 아는지 확인합니다.
  2. Claude 데스크톱 앱을 설치하고 업무 폴더 접근을 허락합니다.
  3. "컴퓨터 보고 나에 대해 파악해 줘"라고 요청해 내 업무 맥락을 파악하게 합니다.
  4. "너는 뭘 할 수 있니?"라고 묻습니다.
  5. "나에 대해서 궁금한 거 100개까지 물어봐 봐"라고 해서 AI의 질문에 답합니다.
  6. "이제 나를 알았으니까 네가 나를 도와줄 수 있는 게 뭐야?"라고 물어 쓸 곳을 찾습니다.
예시
컴퓨터 보고 나에 대해 파악해 줘. 파일은 읽기만 하고 절대 고치거나 지우지 마.
  • 파일은 읽기만 하고 고치지 말라고 지시하는 것이 안전합니다.
  • 질문을 완벽하게 만들려 하지 말고 친구에게 말하듯 던진 뒤, 답을 보고 고쳐 달라며 주고받습니다.
  • AI를 전혀 써 본 적 없다면 모바일 앱의 음성 대화로 말을 걸어 보는 것부터 시작해도 됩니다.
  • 하루 30분, 매일 AI에게 질문하고 AI가 나에게 질문하게 하는 습관을 들이세요.

4. 대화가 모델 학습에 쓰이지 않게 끄기

개인 계정에서는 대화 내용이 향후 모델 학습에 쓰일 수 있습니다. 회사 일을 Claude에 맡기기 전에 학습 사용 설정을 꺼 두는 것이 좋습니다.

  1. Settings(설정)를 엽니다.
  2. 데이터 컨트롤·개인정보 쪽 메뉴로 들어갑니다.
  3. Improve the model for everyone 항목을 찾습니다.
  4. 이 항목을 끕니다.
  • 영상에서도 메뉴 위치를 정확히 짚지 못했으니, 설정 안에서 데이터·개인정보 부근을 찾아보세요.
  • 회사가 조직용으로 Claude를 도입한 경우에는 모델 학습이 기본적으로 꺼져 있습니다.
  • 학습에 쓰이더라도 대화가 모델에 그대로 저장되어 다른 사용자에게 보이지는 않지만, 회사 정보라면 끄는 편이 안전합니다.

5. 메모리와 개인정보 설정 점검하기

모델 자체는 한 대화 안에서만 맥락을 기억하지만, 메모리 기능을 켜면 계정에 저장된 정보를 새 대화에서도 참고합니다. 무엇이 저장되는지 정기적으로 확인하고, 민감한 정보는 처음부터 덜 넣는 습관을 들입니다.

  1. 계정·개인정보 설정에서 메모리, 대화 기록, 연결된 앱, 학습 사용 토글을 확인합니다.
  2. 저장된 메모리 중 틀리거나 불필요한 것은 고치거나 지웁니다.
  3. 메모리가 필요 없으면 메모리 기능을 끕니다.
  4. 정보를 넣기 전에 이번 대화, 저장 메모리, 향후 학습 중 어디에 쓰일지 생각합니다.
  5. 메일 문구 다듬기처럼 실명이 필요 없는 일은 이름을 자리표시자로 바꿔 넣습니다.
예시
아래 메일을 정중하게 다듬어 줘. 받는 사람은 [고객사 담당자], 회사명은 [A사]로 표시했어.
  • 메모리 기능은 2026년 3월부터 무료 사용자에게도 열렸고, 제품에 따라 기본값이 켜져 있을 수 있습니다.
  • 새 대화는 빈 상태로 시작하므로, 메모리를 끈 상태라면 필요한 맥락을 매번 알려 줘야 합니다.
  • 기밀·규제 데이터는 비즈니스·엔터프라이즈 플랜을 쓰고 데이터 처리 조건을 문서로 확인합니다.

6. 작업에 맞는 모델과 노력 수준 고르기

답의 품질과 비용은 모델, effort(추론 노력), 캐시 세 가지로 정해집니다. 깊은 조사처럼 열린 작업에는 가장 똑똑한 모델을, 요약·메일 초안 같은 반복 작업에는 가볍고 빠른 모델을 고릅니다.

  1. 할 일이 심층 조사·복잡한 분석처럼 열린 작업인지, 요약·메일 초안처럼 반복 작업인지 먼저 나눕니다.
  2. 열린 작업이면 Fable 5.1을 고르고 effort를 medium으로 시작합니다.
  3. 결과가 부족하면 effort를 한 단계씩 올려 다시 시킵니다.
  4. 반복 작업이면 Opus나 Sonnet을 고릅니다.
  • 더 똑똑한 모델은 적은 단계로 일을 끝내 총비용이 오히려 낮아질 수 있습니다.
  • Fable 5.1은 Fable 5와 토큰 단가가 같지만 캐시 읽기 비용이 75% 낮아, 긴 작업에서 최대 약 45% 비용이 줄어듭니다.
  • 예전 방식: 2026년 5월 자료는 Haiku(빠르고 가벼움)·Sonnet(균형)·Opus(가장 강력) 세 모델 중에서 고르라고 안내했고, 2026년 2월에는 무료·Pro 플랜의 기본 모델이 Sonnet 4.6으로 바뀌었습니다.
  • 회사 계정이면 관리자가 고를 수 있는 모델과 effort 상한을 제한해 두었을 수 있습니다.

7. 웹 검색과 딥 리서치 켜기

Claude는 학습 시점 이후의 일을 검색 없이는 확실히 알지 못합니다. 최신 정보가 필요하면 웹 검색을 켜고, 시장 조사처럼 깊이 파야 하면 딥 리서치(연구) 모드를 씁니다.

  1. 프롬프트 입력창의 + 버튼을 누릅니다.
  2. 웹 탭을 눌러 웹 검색을 켭니다.
  3. 질문하면 Claude가 필요할 때 검색하고 출처 링크를 달아 답합니다.
  4. 깊은 조사가 필요하면 + 버튼에서 연구를 눌러 딥 리서치 모드를 켭니다.
  5. 조사할 내용을 프롬프트로 적어 요청합니다.
  • 딥 리서치는 시장 조사, 경쟁사 분석, 학술 리서치에 유용합니다.
  • 답에 달린 출처 링크를 눌러 실제 내용과 맞는지 확인하세요.

8. AI 답을 걸러 내고 검증하기

AI는 정해진 답을 꺼내는 것이 아니라 다음 단어를 예측하며 답을 만들어 내기 때문에, 틀린 내용을 자신 있게 말할 수 있습니다. 업무에 쓰기 전에 근거를 요구하고 다른 AI로 한 번 더 확인합니다.

  1. 질문할 때 검증 가능한 자료에 근거해 답하고 출처를 붙이라고 요청합니다.
  2. 최신 사실이 필요한 질문이면 웹 검색을 켜고 묻습니다.
  3. 답이 마음에 들지 않으면 여러 버전을 요청해 비교합니다.
  4. 중요한 결과는 다른 AI에게 맞는지 검증을 시킵니다.
예시
검증 가능한 자료에만 근거해서 답해 줘. 각 주장마다 출처 링크를 달고, 확실하지 않은 내용은 '확인 필요'라고 표시해 줘.
  • 모델은 훈련 시점 이후의 사실을 검색 도구 없이는 확실히 알지 못합니다.

9. 채팅·코워크·코드·디자인 골라 쓰기

Claude에는 채팅, 코워크, 코드, 디자인 네 가지 도구가 있고 목적이 겹치지 않습니다. 생각 정리는 채팅, 파일·문서 정리는 코워크, 웹사이트·앱 제작은 코드, 발표 자료는 디자인으로 고르면 됩니다.

10. 코워크로 폴더 업무 맡기기

코워크는 단계마다 대화하는 대신 작업 전체를 맡기는 방식으로, 열어 준 폴더의 파일을 읽고 엑셀·문서 같은 결과물을 만듭니다. Google Drive·Notion·Slack 같은 서비스와 Chrome 브라우저까지 다룰 수 있어 반복 사무 업무에 좋습니다.

  1. macOS 또는 Windows용 Claude 데스크톱 앱을 열고 코워크 탭으로 갑니다.
  2. 작업할 폴더를 고르고 접근을 허용합니다.
  3. 필요하면 Google Drive·Notion·Slack 같은 커넥터를 연결합니다.
  4. 맡길 작업을 구체적으로 설명합니다.
  5. Claude가 먼저 제안하는 계획을 읽고, 괜찮으면 승인합니다.
  6. 파일을 바꾸기 전에 묻는 권한 요청을 확인하고 허락합니다.
  7. 만들어진 결과물을 열어 확인합니다.
예시
다운로드 폴더의 파일을 종류별 하위 폴더로 정리해 줘. 실행 전에 계획을 먼저 보여 주고, 파일을 지우기 전에는 꼭 물어봐.
  • 코워크는 Pro·Max·Team·Enterprise 플랜에서 데스크톱 앱으로만 쓸 수 있습니다.
  • 브라우저 작업까지 맡기려면 Claude in Chrome을 먼저 설정해야 합니다.
  • 영수증 이미지 폴더로 경비 보고서를 만들거나 비용 데이터를 시각화하는 일에 써 볼 만합니다.
  • 예전 방식: 출시 초기에는 macOS 전용이었고, 2026년 2월 중순부터 Windows에서도 쓸 수 있습니다.

12. 관리자로 조직 모델 기본값 정하기

Team·Enterprise 관리자는 직원이 고를 수 있는 모델, 모델별 effort 상한, 새 대화의 기본 모델을 정할 수 있습니다. 역할별로 따로 설정해 품질과 비용을 함께 관리합니다.

  1. 모델 권한(entitlements)으로 사용자가 고를 수 있는 모델을 정합니다.
  2. effort 상한(caps)으로 모델별 최대 effort를 정합니다.
  3. 기본값(defaults)으로 새 대화의 시작 모델과 effort를 정합니다.
  4. 긴 조사·분석 같은 열린 작업이 많은 역할은 Fable 5.1을 기본으로 하고 effort 상한을 검토합니다.
  5. 요약·메일 초안 같은 반복 작업이 많은 역할은 Opus나 Sonnet을 기본으로 하고 Fable은 권한만 열어 둡니다.
  • 설정은 역할별로 따로 할 수 있습니다.
  • 벤치마크에서 Fable 5.1 medium이 Fable 5 max와 비슷한 결과를 약 5분의 1 비용으로 냈으니, 기본 effort를 무조건 높게 둘 필요는 없습니다.
