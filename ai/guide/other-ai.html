1. ChatGPT 가입하고 첫 질문하기

ChatGPT는 상황·대상·조건을 구체적으로 말할수록 원하는 답이 나오는 대화형 AI입니다. 처음 쓰는 분이 가입부터 첫 질문, 음성 입력까지 해 보는 가이드입니다. 무료로 먼저 익숙해진 뒤 유료는 한 달만 써 보고 정하라는 권고가 있습니다.

  1. 구글에서 챗GPT를 검색해 사이트에 들어갑니다.
  2. 회원 가입을 해서 채팅하세요를 누릅니다.
  3. 구글 계정이 있으면 구글로 계속하기를 누르고, 없으면 이메일을 입력하고 계속을 누릅니다.
  4. 이메일로 가입하면 12자 이상 비밀번호를 정하고 메일로 온 인증 코드를 입력합니다.
  5. 이름과 생년월일을 입력하고 동의합니다를 체크한 뒤 계속하기를 누릅니다.
  6. 왼쪽의 새 채팅을 누르고 질문을 입력하거나 음성으로 말합니다.
  • 이름은 계정용이라 본명이 아니어도 됩니다.
  • 챗GPT는 틀린 답을 할 수 있으므로 의료·법률·금융 정보는 다른 자료로 다시 확인합니다.
  • 무료 버전은 이미지 생성이 하루 3개까지로 제한됩니다.

2. ChatGPT에 한 번에 잘 묻기(POWER 원칙)

막연하게 물으면 뻔한 답이 나오므로, 프롬프트를 페르소나·아웃컴·와이(이유)·예시·제한 사항 다섯 요소로 구성하는 방법입니다. 일정 짜기, 식단·운동 계획 같은 업무·생활 요청에 쓸 수 있습니다.

  1. 페르소나: AI가 맡을 역할을 정합니다.
  2. 아웃컴: 원하는 결과물의 형태를 적습니다.
  3. 와이: 왜 필요한지 이유와 상황을 적습니다.
  4. 예시: 비슷한 사례나 원하는 느낌을 덧붙입니다.
  5. 제한 사항: 분량·예산·피할 것 등 조건을 적습니다.
  6. 한 번에 다 쓰기 어려우면 대화하듯 나눠 요청합니다.
  • 처음부터 구체적으로 쓸수록 한 번에 원하는 결과가 나올 가능성이 높습니다.
  • '이거 정말 맞아? 다시 확인해 봐'라고 물으면 스스로 틀린 부분을 찾기도 합니다.
  • 틀린 정보를 자신 있게 말할 수 있으므로 중요한 정보는 다른 출처로 재확인합니다.

3. Gemini 사고 모드로 바꿔 쓰기

Gemini 3 Pro를 쓰려면 기본값인 빠른 모드를 사고 모드로 바꿔야 합니다. 구글 워크스페이스를 연결하면 메일·일정·드라이브까지 프롬프트로 처리할 수 있어 업무에 유용합니다.

  1. Gemini 입력창 아래의 모드 선택 메뉴를 클릭합니다.
  2. 기본값인 빠른 모드를 사고 모드로 바꿉니다.
  3. 짧게 요청합니다.
  4. 정확한 답이 필요하면 깊게 생각해서 답변해 줘를 덧붙입니다.
  5. 화면 왼쪽 맨 아래 설정 → 연결된 앱에서 구글 워크스페이스를 켭니다.
  6. 요청할 때 @로 앱을 고른 뒤 무엇을, 어떻게 할지 적습니다.
예시
신제품 마케팅 전략을 짜 줘. 예산 500만 원, 타겟은 20대 여성. 깊게 생각해서 답변해 줘.
  • 빠른 모드로 두면 구형 Gemini 2.5를 쓰는 것이라 3의 성능을 느낄 수 없습니다.
  • 핵심은 어디서(@앱), 무엇을, 어떻게 세 가지를 말하는 것입니다.
  • 대화를 이어 가며 형식·분량·예시를 지정하면 결과가 좋아집니다.

4. Gemini 캔버스로 문서·슬라이드 다듬기

캔버스는 답변 옆에 작업창이 생겨 문서를 함께 편집하는 기능입니다. 원하는 구간만 드래그해 고치고, 완성한 문서를 구글 독스나 웹페이지·퀴즈 등으로 바꿀 수 있습니다. 슬라이드는 한 번에 만들지 말고 1~2장씩 나눠 만드는 편이 안정적입니다.

  1. 프롬프트를 쓰고 도구에서 캔버스를 선택해 제출합니다.
  2. 고치고 싶은 구간을 드래그합니다.
  3. 요청을 입력하거나 길이 변경, 어조 변경을 눌러 단계를 고릅니다.
  4. 문서 전체를 점검하려면 수정 제안을 누릅니다.
  5. 완성되면 만들기를 눌러 웹페이지, 인포그래픽, 퀴즈, 플래시 카드, AI 오디오 오버뷰 중 하나를 고릅니다.
  6. 생성이 끝나면 아래쪽 공유 버튼으로 링크를 만듭니다.
예시
이 구간을 앞뒤 맥락에 맞게 바꾸고 필요하면 앞뒤 내용도 같이 바꿔 줘.
  • 길이는 매우 짧게~매우 길게 5단계입니다.
  • 슬라이드는 1~2장씩 만들고 중간중간 구글 슬라이드로 내보내 백업합니다. 색상은 이름 대신 정확한 컬러 코드로 지정합니다.
  • 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리하는 분업을 권합니다.
  • 위쪽 공유는 대화 전체, 아래쪽 공유는 결과물만 공유합니다.

5. 노트북LM에 자료 넣고 질문하기

노트북LM은 내가 올린 자료만 근거로 답하고 출처 번호를 달아 주어 환각 걱정이 적은 구글 AI입니다. 보고서·링크·유튜브를 한곳에 모아 질문하거나 마인드맵·슬라이드 같은 결과물로 바꿀 때 씁니다.

  1. 구글에서 노트북LM에 접속해 새 노트 만들기를 누릅니다.
  2. 왼쪽 위 제목을 프로젝트 이름으로 바꿉니다.
  3. 소스 추가로 파일 업로드, 링크, 유튜브, 드라이브, 텍스트를 넣습니다.
  4. 채팅창에 질문하고 답변의 숫자를 눌러 출처를 확인합니다.
  5. 스튜디오에서 사용할 소스만 체크한 뒤 마인드맵, 인포그래픽, 오디오 오버뷰, 슬라이드 중 하나를 누릅니다.
  6. 생성된 결과를 점 세 개 메뉴로 다운로드합니다.
  • URL은 여러 개를 줄바꿈으로 한 번에 넣을 수 있습니다.
  • 웹 검색은 약하므로 최신 정보는 제미나이에서 노트북을 선택해 보완합니다.
  • 슬라이드를 파워포인트로 받으면 이미지라 수정이 안 됩니다.

6. ChatGPT로 사진을 캐릭터·이모티콘으로 만들기

내 사진을 캐릭터로 바꾸고 같은 캐릭터로 12칸짜리 이모티콘 시트를 만드는 방법입니다. 무료 버전으로도 가능하지만 이미지 생성 횟수 제한이 있습니다.

  1. 휴대폰에서 ChatGPT를 열고 + 버튼 → 사진에서 사진을 선택해 완료를 누릅니다.
  2. 사진 아래에 이 사진 캐릭터로 만들어 줘라고 입력해 보냅니다.
  3. 마음에 들지 않으면 눈 크기, 머리 스타일, 옷 스타일 등을 추가로 요청하고 완성된 캐릭터는 다운로드합니다.
  4. 캐릭터 이미지를 다시 첨부해 이모티콘 시트를 만들어 달라고 요청합니다.
  5. 가로 3칸 × 세로 4칸, 흰 배경의 12칸으로 지정하고 번호별로 표정과 문구를 적습니다.
  6. 3D 느낌을 원하면 같은 캐릭터를 3D 픽사풍 렌더링으로 다시 만들어 주세요라고 요청합니다.
예시
첨부한 캐릭터를 그대로 유지해서 이모티콘 시트를 만들어 주세요.
  • 무료 버전은 이미지 생성 횟수 제한이 있어, 걸리면 다음 날 다시 하거나 다른 AI를 씁니다.
  • 예전 방식: 이미지 속 한글은 잘 안 되고 영어가 더 잘 된다고 했으나(2025년 4월), 이후 Gemini 3 편에서는 한국어 글자 표현이 크게 개선됐다고 합니다.

7. Gemini 나노바나나로 이미지 만들고 고치기

Gemini의 이미지 생성·편집 기능(나노바나나)은 원본의 얼굴·포즈·배경을 유지하면서 요청한 부분만 고치는 일관성이 강점입니다. 제품 사진 배경 교체, 물체 제거, 인포그래픽 제작 등에 쓸 수 있습니다.

  1. Gemini에 접속해 로그인합니다.
  2. 제출 전에 도구를 눌러 이미지 생성을 선택합니다.
  3. 만들고 싶은 장면을 문장으로 요청합니다.
  4. 나온 이미지를 확인하고 다운로드로 저장합니다.
  5. 같은 대화창에서 수정 요청을 이어 갑니다.
  6. 편집할 때는 내 사진을 올리고 바꿀 부분을 문장으로 요청합니다.
  7. 여러 사진을 합칠 때는 사진을 함께 올리고 어떤 장면에 무엇이 들어갈지 적습니다.
예시
왼쪽 나무를 자연스럽게 지워 줘. 책상 위는 건드리지 말고.
  • 주인공·행동·배경·조명·분위기·카메라 6요소로 프롬프트를 구체화하면 한 번에 원하는 결과를 얻기 쉽습니다.
  • 바꾸지 않을 부분을 함께 적으면 일관성이 유지됩니다.
  • 인포그래픽은 입력하지 않은 정보도 검색해 채우므로 내용은 직접 확인합니다.
  • 예전 방식: 정식 출시 전에는 LM 아레나에서 무료로 써 보는 방법이 안내됐습니다. 나노바나나로 검색하면 스캠 사이트가 나올 수 있으니 주의합니다.

8. 힉스필드로 가상 모델 이미지·캐릭터 시트 만들기

영상을 일관되게 만들려면 이미지를 먼저 만드는 것이 좋습니다. 힉스필드에서 가상 모델 전신 이미지를 만들고 캐릭터 시트까지 만들어 두는 단계입니다. 다음 영상 가이드의 준비 단계입니다.

  1. 힉스필드에 로그인하고 상단에서 이미지를 선택합니다.
  2. 입력칸에 모델의 외모·의상·분위기를 구체적으로 적고 전신 사진을 요청합니다.
  3. 모델을 GPT Image 2.5로 고르고 비율·품질·해상도·생성 장수를 정한 뒤 생성하기를 누릅니다.
  4. 새 요청에 선택한 이미지를 기준으로 동일한 인물의 캐릭터 시트를 만들어 달라고 쓰고, 얼굴·헤어스타일·의상·신체 비율을 동일하게 유지하라고 덧붙입니다.
  5. +를 눌러 앞서 만든 이미지를 레퍼런스로 첨부하고 생성하기를 누릅니다.
예시

  • 영상에 쓸 모델은 전신으로 만들어야 하반신이 임의로 표현되지 않습니다.

9. 캐릭터 시트로 일관된 AI 영상 만들기

캐릭터 시트를 레퍼런스로 넣으면 얼굴과 의상이 바뀌지 않는 영상을 여러 장면으로 만들 수 있습니다. 광고·브이로그·숏폼 영상에서 같은 인물을 유지해야 할 때 씁니다.

  1. 상단에서 비디오를 선택합니다.
  2. 프롬프트에 이미지 1을 주인공으로 지정하고 원하는 동작을 적습니다.
  3. 레퍼런스에 캐릭터 시트를 첨부하고 프롬프트에서 @로 지정합니다.
  4. 모델을 Seedance 2.5로 고르고 길이·비율·품질을 정합니다.
  5. 생성하기를 누르고 마음에 들면 다운로드, 아니면 프롬프트를 고쳐 다시 생성합니다.
  6. 장소를 바꾸려면 첫 영상을 레퍼런스로 함께 넣고 장소만 프롬프트에서 바꿉니다.
  • 영상이 길거나 품질이 높을수록 크레딧과 생성 시간이 늘어납니다.
  • 스타터 요금제에서는 Seedance 2.5를 쓸 수 없고, 영상 속 추천은 플러스 요금제입니다.
  • 같은 프롬프트라도 결과가 매번 달라지므로 여러 번 생성해 고릅니다.
  • 다음 장면은 직전에 만든 영상을 레퍼런스로 함께 넣고 이어서 만들라고 적으면 이어집니다.

  8. 수정할 때는 먼저 만든 영상을 레퍼런스로 첨부하고 바꿀 부분만 프롬프트로 입력합니다.

15. GPT-6 아스트라로 업무 자동화하기

GPT 데스크탑 앱에서 채팅·Work·Codex를 오가며 문서·표·PPT 같은 실무 결과물을 만드는 방법입니다. 추론 레벨은 미디엄에서 시작해 결과가 부족하면 올리는 방식을 권합니다. ChatGPT Work의 파일·앱 조작 기능은 데스크탑 전용입니다.

  1. GPT 데스크탑 앱의 채팅 화면에서 프롬프트 입력창의 추론 수준 버튼을 누릅니다.
  2. 모델을 최신으로 선택하고 추론 수준을 프로로 설정합니다.
  3. 코딩형 작업은 좌측 상단 ChatGPT 버튼을 눌러 Codex로 바꿉니다.
  4. Codex에서 모델을 GPT-6 아스트라로 선택하고 추론 레벨을 미디엄으로 둡니다.
  5. 만들고 싶은 결과물을 디자인·조작 기능·제작 방식·검증 가이드까지 포함해 요청합니다.
  6. 결과가 만족스럽지 않으면 추론 레벨을 한 단계씩 높입니다.
예시
전문 3D 도구 없이 기본 도구만으로 3D 주택 웹 앱을 만들어 줘. 디자인, 조작 기능, 제작 방식, 검증 방법도 함께 알려 줘.
  • Work나 Codex에서는 모델 선택에서 바로 고를 수 있습니다.
  • 추론 레벨을 높일수록 비용도 늘어납니다.
  • Work의 예약 작업은 연결된 앱을 오가는 여러 단계 업무도 통째로 예약할 수 있습니다.
