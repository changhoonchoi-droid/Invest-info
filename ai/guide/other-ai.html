1. ChatGPT 가입하고 첫 질문하기

ChatGPT는 질문하면 답해 주는 대화형 AI입니다. 처음 쓰는 사람이 가입하고 질문하는 방법과, 상황·대상·조건을 구체적으로 적어야 원하는 답이 나온다는 기본 요령을 익힙니다.

  1. 구글에서 챗GPT를 검색해 사이트에 들어갑니다.
  2. 회원 가입을 해서 채팅하세요를 누릅니다.
  3. 구글 계정이 있으면 구글로 계속하기를 누르고, 없으면 이메일을 입력하고 계속을 누릅니다.
  4. 이메일로 가입하면 12자 이상 비밀번호를 정하고 메일로 온 인증 코드를 입력합니다.
  5. 이름과 생년월일을 입력하고 동의에 체크한 뒤 계속하기를 누릅니다.
  6. 왼쪽 새 채팅을 누르고 질문을 입력하거나 음성으로 말합니다.
예시
저는 직원 5명 규모 마케팅팀 팀장입니다. 신제품 출시 보도자료 초안을 A4 한 장 분량, 담백한 말투로 써 주세요. 제품 특징은 아래와 같습니다: …
  • 이름은 계정용이라 본명이 아니어도 됩니다.
  • 틀린 답을 할 수 있으니 의료·법률·금융 정보는 다른 자료로 다시 확인하세요.
  • 무료 버전은 이미지 생성 횟수 등에 제한이 있으니 익숙해진 뒤 유료는 한 달만 써 보고 정하세요.

2. POWER 5원칙으로 프롬프트 쓰기

막연하게 물으면 뻔한 답만 나오므로 질문 틀을 갖추는 방법입니다. 역할·결과·이유·예시·제한 사항 다섯 가지를 넣으면 한 번에 원하는 결과를 얻기 쉽습니다.

  1. 페르소나: AI에게 맡길 역할을 정합니다.
  2. 아웃컴: 원하는 결과물의 형태와 분량을 적습니다.
  3. 와이: 왜 필요한지 이유를 적습니다.
  4. 예시: 비슷한 사례나 원하는 느낌의 예를 줍니다.
  5. 제한 사항: 피해야 할 것, 분량·말투 조건을 적습니다.
  6. 한 번에 쓰기 어려우면 대화하듯 나눠서 요청합니다.
예시
당신은 10년 차 인사팀 담당자입니다(역할). 신입사원 온보딩 안내문을 한 페이지로 써 주세요(결과). 첫 주 적응을 돕기 위해서입니다(이유). 말투는 '환영합니다, 먼저 …'처럼 친근하게(예시). 전문 용어와 5개 초과 항목은 넣지 마세요(제한).
  • '이거 정말 맞아? 다시 확인해 봐'라고 물으면 스스로 틀린 부분을 찾기도 합니다.
  • 최신 정보 부족과 자신 있게 틀린 말을 하는 한계를 기억하세요.

3. 제미나이 사고 모드로 바꾸고 앱 연결하기

Gemini는 기본이 빠른 모드라 구형 모델이 쓰일 수 있습니다. 사고 모드로 바꾸고 구글 워크스페이스를 연결하면 메일·일정·드라이브까지 한 곳에서 처리합니다.

  1. Gemini 입력창 아래의 모드 선택 메뉴를 엽니다.
  2. 기본값인 빠른 모드를 사고 모드로 바꿉니다.
  3. 화면 왼쪽 맨 아래 설정에서 연결된 앱을 누릅니다.
  4. 구글 워크스페이스를 켜고 평소 쓰는 구글 계정인지 확인합니다.
  5. 질문에 @를 입력해 앱을 고르고 무엇을, 어떻게 할지 적어 요청합니다.
예시
@Gmail 어제 받은 메일 중 답장이 필요한 것을 우선순위 순으로 3개 정리하고, 첫 번째 메일의 답장 초안을 정중한 말투로 써 줘.
  • 일정 등록은 확인을 물은 뒤 응답해야 캘린더에 반영됩니다.
  • 정확한 답이 필요하면 깊게 생각해서 답변해 줘를 덧붙이세요.
  • 예전 방식: 영상(2025년 12월)에서는 11월 출시 Gemini 3 Pro 기준으로 설명했습니다. 모델 이름은 바뀔 수 있으니 화면의 모드 이름을 확인하세요.

4. 제미나이 캔버스로 문서 다듬기

캔버스는 답변 옆에 작업창이 열려 문서를 함께 고치는 기능입니다. 원하는 구간만 골라 다시 쓰거나 길이·어조를 바꾸고, 완성본을 웹페이지·퀴즈 등으로 바꿀 수 있습니다.

  1. 프롬프트를 쓰고 도구에서 캔버스를 선택해 제출합니다.
  2. 고치고 싶은 구간을 드래그합니다.
  3. 요청을 입력하거나 길이 변경, 어조 변경을 눌러 단계를 고릅니다.
  4. 바뀐 부분이 색으로 표시되는 것을 확인합니다.
  5. 전체를 점검하려면 수정 제안을 누릅니다.
  6. 완성 후 만들기에서 웹페이지, 인포그래픽, 퀴즈, 플래시 카드, AI 오디오 오버뷰 중 하나를 고릅니다.
예시
선택한 문단을 앞뒤 맥락에 맞게 더 짧고 단정한 어조로 바꾸고, 필요하면 앞뒤 내용도 같이 바꿔 줘.
  • 길이는 매우 짧게~매우 길게 5단계입니다.
  • 구글 독스로 내보내면 수정안이 먼저 보이고 삽입을 눌러야 반영됩니다.
  • 다른 형식을 또 만들려면 원래 텍스트 캔버스로 돌아와야 합니다.
  • PPT는 레이아웃은 캔버스, 이미지는 구글 슬라이드, 폰트·정렬은 PPT에서 마무리하는 분업이 권장됩니다.

5. 노트북LM에 자료 넣고 질문하기

노트북LM은 내가 올린 자료만 근거로 답하고 출처 번호를 달아 주는 구글 AI입니다. 보고서·기사·영상을 모아 두고 확인하며 질문하거나 슬라이드·마인드맵 등을 만들 때 씁니다.

  1. 구글에서 노트북LM에 접속해 새 노트 만들기를 누릅니다.
  2. 왼쪽 위 제목을 프로젝트 이름으로 바꿉니다.
  3. 소스 추가로 파일, 링크, 유튜브, 드라이브, 텍스트를 넣습니다.
  4. 채팅창에 질문하고 답변의 숫자를 눌러 출처를 확인합니다.
  5. 왼쪽에서 쓸 소스만 체크한 뒤 오른쪽 스튜디오에서 마인드맵·인포그래픽·오디오 오버뷰·슬라이드 중 하나를 누릅니다.
  6. 결과는 점 세 개 메뉴로 다운로드합니다.
예시
올려 둔 자료 3건을 교차 비교해서 공통 주장과 서로 다른 주장을 표로 정리하고, 각 항목마다 출처 번호를 달아 줘.
  • URL은 여러 개를 줄바꿈으로 한 번에 넣을 수 있습니다.
  • 구글 독스 링크를 넣으면 내용이 자동 업데이트됩니다.
  • 슬라이드를 파워포인트로 받으면 이미지라 수정이 안 됩니다.
  • 웹 검색은 약하므로 최신 정보는 제미나이에서 노트북을 선택해 보완하세요.

6. 제미나이·ChatGPT로 이미지 만들고 고치기

말 한두 문장으로 이미지를 만들고, 같은 대화에서 수정 요청을 이어 가며 다듬는 방법입니다. 프레젠테이션 이미지, 제품 사진 배경 교체, 캐릭터 만들기에 쓸 수 있습니다.

  1. Gemini 질문창에서 도구를 눌러 이미지 생성을 선택합니다.
  2. 주인공·행동·배경·조명·분위기·카메라 중 필요한 요소를 문장으로 적어 요청합니다.
  3. 나온 이미지를 확인하고 다운로드로 저장합니다.
  4. 같은 대화 아래에 '배경을 사무실로 바꿔 줘'처럼 수정 요청을 이어 갑니다.
  5. 사진을 고치려면 내 사진을 올리고 '왼쪽 나무를 자연스럽게 지워 줘'처럼 요청합니다.
  6. ChatGPT에서는 입력창의 +로 사진을 올리고 원하는 스타일로 바꿔 달라고 요청해 다운로드로 저장합니다.
예시
햇살 잘 드는 사무실 책상 위에서 노트북으로 일하는 30대 직장인, 따뜻한 오후 햇살, 차분하고 아늑한 분위기, 광각 렌즈로 찍은 듯한 구도. 책상 위 물건은 건드리지 말고 배경만 단정하게.
  • '바꾸지 않을 부분'을 함께 적으면 원본이 유지됩니다.
  • 결과가 매번 달라지므로 마음에 안 들면 같은 요청을 다시 시도하세요.
  • 비슷한 이미지를 올리고 '이 이미지의 프롬프트를 알려줘'라고 해서 수정해 써도 됩니다.
  • 무료 버전은 생성 횟수 제한이 있고, 이미지 속 한글은 최근 영상에서 크게 개선됐다고 하나 직접 확인하세요.

7. 힉스필드로 가상 모델 이미지·캐릭터 시트 만들기

영상의 얼굴과 옷을 일정하게 유지하려면 먼저 전신 이미지와 캐릭터 시트를 만들어 두는 것이 좋습니다. 힉스필드에서 GPT 이미지 모델로 모델을 만들고 이를 기준 자료로 씁니다.

  1. 힉스필드에 로그인하고 상단에서 이미지를 선택합니다.
  2. 입력칸에 모델의 외모·의상·분위기를 구체적으로 적고 전신 사진을 요청합니다.
  3. 모델을 GPT Image 2.5로 고르고 비율·품질·해상도·장수를 정한 뒤 생성하기를 누릅니다.
  4. 새 요청에 선택한 이미지를 기준으로 동일 인물의 캐릭터 시트를 만들라고 쓰고, 얼굴·헤어스타일·의상·신체 비율을 동일하게 유지하라고 덧붙입니다.
  5. +를 눌러 앞서 만든 이미지를 레퍼런스로 첨부하고 생성하기를 누릅니다.
예시
첨부한 이미지를 기준으로 동일한 인물의 캐릭터 시트를 만들어 줘. 얼굴, 헤어스타일, 의상, 신체 비율을 동일하게 유지하고 정면·측면·후면 전신을 한 장에 배치해 줘.
  • 영상에 쓸 모델은 전신으로 만들어야 하반신이 임의로 표현되지 않습니다.
  • 해상도·장수·품질을 올리면 크레딧이 더 듭니다.

8. 캐릭터 시트로 일관된 AI 영상 만들기

캐릭터 시트를 레퍼런스로 넣어 같은 인물이 여러 장면에 나오는 영상을 만듭니다. 광고·브이로그·숏드라마처럼 인물이 유지되어야 할 때 씁니다.

  1. 힉스필드 상단에서 비디오를 선택합니다.
  2. 프롬프트에 이미지 1을 주인공으로 지정하고 원하는 동작을 적습니다.
  3. 레퍼런스에 캐릭터 시트를 첨부하고 프롬프트에서 @로 지정합니다.
  4. 모델을 Seedance 2.5로 고르고 길이·비율·품질을 정합니다.
  5. 생성하기를 누르고 마음에 들면 다운로드, 아니면 프롬프트를 고쳐 다시 생성합니다.
  6. 장소를 바꾸려면 첫 영상을 레퍼런스로 함께 넣고 장소만 바꿔 요청합니다.
예시
@캐릭터시트 의 인물이 해 질 녘 서울 거리를 천천히 걸어오는 장면, 카메라는 정면에서 천천히 후진, 16:9, 15초.
  • 영상이 길거나 품질이 높을수록 크레딧과 시간이 늘어납니다.
  • 본 생성 전에 짧고 낮은 화질로 먼저 시험하면 비용을 아낄 수 있습니다.
  • 인물 묘사 문장은 모든 프롬프트에 똑같이 붙이면 일관성이 좋아집니다.
  • 생성 비용은 모델마다 크게 달라 1분 기준 약 7,500원~6만 원까지 차이 난다는 비교가 있습니다. 비싸다고 항상 좋은 것은 아니니 가성비 모델도 비교해 보세요.

9. Seedance 2.5로 긴 광고 영상 만들고 고치기

Seedance 2.5는 한 번에 최대 30초 영상을 만들고 이미지·영상·오디오 레퍼런스를 여러 개 넣을 수 있습니다. 광고 시안(프리비즈)을 빠르게 만들고, 피드백은 생성된 영상을 첨부해 부분 수정하는 데 적합합니다.

  1. 제품 사진을 정면·측면·후면 등 여러 각도로 준비합니다.
  2. Artlist AI 툴킷의 이미지에서 배경 장면 이미지를 생성합니다.
  3. 배경과 제품 이미지를 레퍼런스로 넣어 제품이 배경에 놓인 이미지를 만듭니다.
  4. 비디오로 바꾸고 올 모델스에서 Seedance 2.5를 선택한 뒤 유즈 모델을 누릅니다.
  5. 길이를 30초, 화질을 높게 설정하고 필요하면 오디오를 켭니다.
  6. +로 이미지 레퍼런스를 추가하고 프롬프트를 쓴 뒤 제너레이트를 누릅니다.
  7. 수정은 먼저 만든 영상을 레퍼런스로 첨부하고 바꿀 부분만 프롬프트로 적어 다시 생성합니다.
예시
앞부분을 더 따뜻한 분위기로 바꿔 줘. 나머지 장면과 제품 모습은 그대로 유지해 줘.
  • 시작·끝 프레임이 아니라 이미지 레퍼런스로 넣어야 합니다.
  • 영상 생성은 크레딧이 많이 들므로 이미지로 구도를 먼저 확정하세요.
  • 다음 장면은 이전 영상을 모두 레퍼런스로 넣고 '이전 장면에서 곧바로 이어져'라고 쓰면 이어 만들 수 있습니다.
  • 디테일이 어긋나거나 브랜드 가이드가 엄격한 광고는 실제 촬영이 필요할 수 있습니다.

  2. 모델 선택에서 올 모델을 열고 Kling 4.0을 선택한 뒤 유즈 모델을 누릅니다.

  5. 마지막 사진은 엔드 프레임으로 넣습니다.

11. ElevenLabs로 AI 음성 만들고 목소리 복제하기

ElevenLabs로 나레이션을 만들고 내 목소리를 복제하는 방법입니다. 영상·교육 자료·대사 제작에 쓰며, 감정은 파라미터가 아니라 프롬프트의 태그와 문장부호로 조절합니다.

  1. Claude에게 한글·영어 테스트 대사를 짧게 만들어 달라고 요청합니다.
  2. ElevenLabs에서 스피치 만들기 기능을 엽니다.
  3. 대사를 입력하고 Eleven v4로 생성해 들어 봅니다.
  4. 같은 대사를 Multilingual v2로도 생성해 억양·감정 차이를 비교합니다.
  5. 대사 안에 whispers, sarcastic, curious 같은 감정 태그를 넣고 말줄임표·느낌표로 억양을 보강합니다.
  6. 내 목소리는 Create Voice에서 Instant Voice를 고르고 약 30~40초 다양한 내용을 녹음해 만듭니다.
예시
[whispers] 아무도 모르게 준비했어요... [curious] 그런데, 혹시 알고 계셨나요?
  • 즉석 복제는 40초 녹음으로 약 70% 비슷한 수준이었고, 전문 복제(PVC)는 약 2시간 분량이 필요합니다.
  • 숫자·다양한 문장을 많이 녹음하고 톤을 일정하게 유지해야 품질이 안정됩니다.
  • 다른 사람의 목소리는 동의 없이 복제하지 마세요.
  • 예전 방식: Multilingual v2가 한글 표현용으로 주로 쓰였으나 최근 영상에서는 v4가 더 낫다고 평가했습니다.
