다른 AI 도구

ChatGPT·Gemini 같은 대화형 AI로 문서와 발표 자료를 만들고, ElevenLabs·Kling·Higgsfield 같은 생성 AI로 목소리와 영상까지 만들 수 있습니다. 먼저 모델 고르기와 자료 정리처럼 바로 업무에 쓰는 기능을 익히세요. 그다음 음성 생성, 사진 영상화, 에이전트 자동화를 거쳐 마지막에 여러 도구를 엮는 숏드라마 제작으로 넘어가면 됩니다.

  • Adobe Acrobat의 PDF 스페이스에 파일을 최대 100개까지 넣어 요약을 받고, 요약 속 숫자를 눌러 원문 근거를 확인한 뒤 PPTX 발표 자료로 내려받을 수 있습니다.

1. 채팅에서 GPT-6 아스트라 고르기

GPT-6 아스트라는 컴퓨터 조작과 문서·표·PPT 같은 실무 결과물, 추론에 강하다고 소개된 OpenAI 모델입니다. 어려운 분석이나 보고서 초안처럼 깊이 생각해야 하는 질문을 할 때 채팅에서 이 모델과 추론 수준을 골라 씁니다.

  1. GPT 데스크탑 앱을 열고 채팅 화면으로 갑니다.
  2. 프롬프트 입력창에 있는 추론 수준 버튼을 누릅니다.
  3. 모델을 최신 모델(GPT-6 아스트라)로 선택합니다.
  4. 추론 수준을 프로로 설정합니다.
  5. 평소처럼 질문을 입력하고 결과를 확인합니다.
  • Work나 Codex 화면에서는 모델 선택 메뉴에서 바로 GPT-6 아스트라를 고를 수 있습니다.
  • 작업용으로 쓸 때 권장 기본값은 미디엄입니다. 결과가 부족할 때 한 단계씩 올리세요. 추론 수준이 높을수록 비용도 늘어납니다.
  • 데스크탑 앱에는 채팅·Work·Codex가 한 앱에 들어 있고, macOS와 Windows를 지원합니다.

2. Acrobat AI로 자료 정리해 PPT 만들기

Adobe Acrobat의 AI 기반 PDF 스페이스에 보고서·기사 링크 같은 자료를 모아 넣으면 핵심 내용을 정리하고 발표 자료 초안까지 만들어 줍니다. 여러 자료를 읽고 보고용 슬라이드를 만들어야 할 때 씁니다.

  1. Adobe Acrobat에서 PDF 스페이스를 엽니다.
  2. 보고서 파일, 이미지, 웹 링크, 텍스트 등 분석할 자료를 넣습니다.
  3. AI에게 자료의 핵심 내용을 정리해 달라고 요청합니다.
  4. 요약에 붙은 숫자를 눌러 원문에서 해당 부분을 확인합니다.
  5. 정리된 내용으로 프레젠테이션 초안을 만들어 달라고 요청합니다.
  6. Adobe Express 편집 화면에서 글자·배경·아이콘을 하나씩 고칩니다.
  7. 완성된 슬라이드를 PPTX로 내려받습니다.
  8. 발표에서 나올 만한 예상 질문과 답변을 정리해 달라고 요청합니다.
  • PDF 스페이스에는 확장자와 관계없이 파일을 최대 100개까지 넣을 수 있습니다.
  • 다운로드 형식은 JPG, PNG, PPTX, PDF 중에서 고를 수 있습니다.
  • 요약 속 숫자로 근거를 꼭 확인한 뒤 보고서에 쓰세요.

3. ElevenLabs 모델별 음성 비교하기

ElevenLabs는 글을 사람 목소리로 읽어 주는 음성 생성 AI입니다. 같은 대사를 모델별로 만들어 비교하면 내 콘텐츠에 맞는 모델을 고를 수 있습니다.

  1. Claude 같은 AI에게 한글·영어 테스트 대사를 짧게 만들어 달라고 요청합니다.
  2. ElevenLabs에서 스피치 만들기 기능을 엽니다.
  3. 만든 한글·영어 대사를 함께 입력합니다.
  4. Eleven v4로 생성해 들어 봅니다.
  5. 같은 대사를 Multilingual v2로 생성합니다.
  6. 두 결과의 억양·감정·발음 차이를 비교해 쓸 모델을 정합니다.
예시
ElevenLabs로 음성 모델을 비교하려고 해. 억양과 감정 차이가 잘 드러나는 한글 대사 2줄과 영어 대사 2줄을 짧게 만들어 줘.
  • 영상에서는 Eleven v4의 감정 표현이 특히 좋고 영어도 매우 자연스럽다고 평가했습니다.
  • 예전 방식: 한글을 자연스럽게 읽히려고 주로 Multilingual v2를 썼습니다.

4. 즉석 복제로 내 목소리 만들기

짧은 녹음만으로 내 목소리를 닮은 AI 음성을 만드는 기능입니다. 내레이션이나 안내 음성을 내 목소리로 빠르게 만들어 보고 싶을 때 씁니다.

  1. ElevenLabs에서 Create Voice를 선택합니다.
  2. Instant Voice(인스턴트 보이스)를 고릅니다.
  3. 약 30~40초 동안 숫자와 여러 종류의 문장을 일정한 톤으로 녹음합니다.
  4. 만들어진 목소리로 대사를 생성해 들어 봅니다.
  5. 내가 직접 읽은 녹음과 같은 대사로 비교합니다.
  • 10초만 넣어도 된다고 안내되지만 영상에서는 약 40초를 썼고, 결과는 70% 정도 비슷했습니다.
  • 더 닮은 목소리가 필요하면 약 2시간 분량으로 학습시키는 전문 복제(PVC)를 씁니다. 계정당 하나만 만들 수 있고, 영상 속 요금제는 월 5만 원 안팎이었습니다.
  • 숫자와 다양한 문장을 많이 녹음하고 톤을 일정하게 유지해야 품질이 안정됩니다.

5. 감정 태그로 AI 목소리 연기시키기

ElevenLabs의 감정은 설정값보다 대사 안의 태그와 문장부호로 조절합니다. 속삭임, 비꼬기, 궁금해하는 말투처럼 연기가 필요한 내레이션이나 드라마 대사에 씁니다.

  1. 대사 앞에 대괄호로 연기 지시를 영어로 씁니다 (예: [whispers], [sarcastic], [curious]).
  2. 감정 이름보다 말투로 쓰고, 한 줄에 1~3개만 붙입니다.
  3. 말투를 바꾸고 싶은 곳에는 문장 중간에 대괄호를 하나 더 넣습니다.
  4. 한 박자 쉬어야 하는 곳에는 [beat]를 넣습니다.
  5. 말줄임표(…)와 느낌표로 억양을 보강합니다.
  6. 한글·영어 대사를 생성해 듣고, 직접 읽은 버전과 비교합니다.
예시
[curious] 여기가 정말 그 성이야? [beat] [whispers] 조용히 해… 누가 들을지도 몰라!
  • 대괄호 안의 말은 소리로 읽히지 않습니다. 뒤에 오는 대사를 어떻게 말할지만 정합니다.
  • 조절용 설정값이 거의 없어서 대부분 프롬프트로 연기를 조절합니다.
  • 어떤 태그가 잘 먹히는지 Claude 같은 AI에게 찾아 달라고 하면 설계 시간을 줄일 수 있습니다.

6. 제미나이 스파크로 반복 업무 맡기기

제미나이 스파크는 구글 클라우드에서 상시 일하는 개인 AI 에이전트로, Gmail·캘린더·독스·시트·드라이브를 따로 연결하지 않고 다룹니다. 무엇을 할지(태스크), 언제 할지(스케줄), 어떻게 할지(스킬)를 정해 메일 브리핑이나 조사 문서 작성을 맡길 때 씁니다.

  1. 제미나이 앱에서 스파크 탭을 엽니다.
  2. 태스크로 할 일을 요청합니다 (예: 세미나 주제를 조사해 문서로 만들기).
  3. 결과 문서가 구글 독스 등에 만들어졌는지 확인합니다.
  4. 받은 메일을 우선순위로 정리해 브리핑해 달라는 태스크를 줍니다.
  5. 자주 하는 태스크에는 스케줄을 붙여 매주 월요일처럼 자동 실행되게 합니다.
  6. 내 문체 같은 업무 방식을 스킬로 저장해 다음 작업에도 쓰게 합니다.
  • 구글 AI 프로 이상 구독자에게 순차 적용되며 한국어를 공식 지원합니다.
  • 브라우저를 닫거나 휴대폰을 잠가도 백그라운드에서 작업이 계속됩니다.
  • 데스크탑 앱은 현재 macOS만 지원하니 Windows에서는 웹이나 모바일로 쓰세요.

7. Kling 4.0으로 사진을 영상 만들기

Artlist에서 Kling 4.0을 쓰면 시작·중간·끝 프레임에 사진을 최대 10장 넣어 영상 한 편으로 만들 수 있습니다. 숙소·여행지 홍보, 광고, 영화 같은 장면을 사진 몇 장으로 빠르게 만들 때 씁니다.

  1. Artlist에서 AI 비디오로 이동합니다.
  2. 모델 선택에서 올 모델을 열고 Kling의 4.0을 고른 뒤 유즈 모델을 누릅니다.
  3. 스타트 프레임의 업로드 이미지로 첫 장면 사진을 넣습니다.
  4. 미들 프레임을 눌러 두 번째, 세 번째 장면 사진을 순서대로 넣습니다.
  5. 마지막 사진을 엔드 프레임에 넣습니다.
  6. 사진 순서에 맞춰 장면 흐름을 적은 프롬프트를 입력합니다.
  7. 비율과 영상 길이(최대 30초)를 정하고 제너레이트를 누릅니다.
예시
사진 6장을 이 순서로 넣어 30초 숙소 홍보 영상을 만들려고 해. 이 순서로 영상이 자연스럽게 나올지 검토하고, 장면 흐름을 담은 영상 생성 프롬프트를 제안해 줘.
  • GPT나 Claude에 사진 순서를 보여 주고 검토받은 프롬프트를 쓰면 편합니다. 장면이 너무 많으면 파트를 나눠 생성하세요.
  • 강조하고 싶은 장면(예: 물이 있는 공간)은 앞이나 뒤에 배치합니다.
  • 30초 영상이 약 1분 만에 만들어지고, 해상도는 현재 1080까지이며 배경 음악과 목소리도 함께 생성됩니다.
  • 예전 방식: 사진마다 영상을 따로 만든 뒤 편집 프로그램에서 이어 붙였습니다.

8. Codex로 평면도를 3D 앱 만들기

ChatGPT 데스크탑 앱의 Codex는 말로 요청하면 웹 앱을 만들어 주는 코딩 에이전트입니다. 개발 지식이 없어도 평면도 이미지로 둘러볼 수 있는 3D 주택 웹 앱을 만들 수 있습니다.

  1. GPT 데스크탑 앱 좌측 상단의 ChatGPT 버튼을 눌러 Codex로 바꿉니다.
  2. 모델을 GPT-6 아스트라로 고르고 추론 레벨을 미디엄으로 둡니다.
  3. 전문 3D 도구 없이 기본 도구만으로 3D 주택 웹 앱을 만들어 달라고 요청합니다.
  4. 결과 웹 뷰어에서 거실·작업실 등을 조작해 확인합니다.
  5. 평면도 이미지를 첨부하고 이 평면도를 바탕으로 3D 모델링을 해 달라고 요청합니다.
예시
전문 3D 도구 없이 기본 도구만으로 3D 주택 웹 앱을 만들어 줘. 디자인, 조작 기능, 제작 방식, 검증 가이드를 함께 알려 줘.
  • 결과가 만족스럽지 않으면 추론 레벨을 한 단계씩 높이세요. 비용도 함께 늘어납니다.
  • 같은 앱의 Work에서는 매물 수집·스프레드시트 정리나 기존 PPT 템플릿을 유지한 새 발표 자료 만들기도 할 수 있습니다.

9. AI로 숏드라마 1화 만들기

배우·세트·목소리를 모두 AI로 만들어 1분 남짓한 숏드라마를 완성하는 방법입니다. 대본, 얼굴, 목소리, 영상, 편집, 고치기의 6단계로 이미지 모델·ElevenLabs·Higgsfield를 엮어 씁니다.

  1. 작업 폴더를 만들고 단계가 끝날 때마다 결과 파일을 남깁니다.
  2. 대본을 표 하나로 씁니다. 한 줄이 한 컷이고, 칸은 컷 번호·샷 크기·인물·대사·길이입니다.
