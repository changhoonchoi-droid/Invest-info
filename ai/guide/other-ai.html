1. Gemini 사고 모드로 바꿔 쓰기

Gemini 3 Pro는 기본값인 빠른 모드에서는 구형 2.5 모델이 쓰입니다. 사고 모드로 바꿔야 3 Pro의 추론 성능을 쓸 수 있으니, 기획이나 분석처럼 깊은 답이 필요할 때 설정합니다.

  1. Gemini 입력창 아래의 모드 선택 메뉴를 클릭합니다.
  2. 기본값인 빠른 모드를 사고 모드로 바꿉니다.
  3. 짧게 요청합니다.
  4. 정확한 답이 필요하면 깊게 생각해서 답변해 줘를 덧붙입니다.
예시
신제품 마케팅 전략을 짜 줘. 예산 500만 원, 타겟은 20대 여성. 깊게 생각해서 답변해 줘.
  • 빠른 모드로 두면 Gemini 2.5를 쓰는 것이라 3의 성능을 느낄 수 없습니다.
  • 대화를 이어 가며 형식·분량·예시를 지정하면 결과가 더 좋아집니다.

2. Gemini로 긴 영상 타임라인 만들기

유튜브 전체 화면 영상에서 Gemini에게 시간대별 타임라인과 요약을 요청하는 기능입니다. 긴 강의나 영상에서 필요한 구간만 골라 볼 때 씁니다.

  1. 전체 화면 영상을 보다가 오른쪽 아래 Gemini 표시를 누릅니다.
  2. 이 영상 타임라인 만들어 줘라고 질문합니다.
  3. 나온 시간대를 누르면 해당 구간으로 이동합니다.
  4. 위쪽 동영상을 요약해 줘를 누르면 전체 내용을 요약해 줍니다.
예시
이 영상 타임라인 만들어 줘
  • 영상과 관련한 다른 질문도 Gemini에 할 수 있습니다.

3. 갤럭시 AI로 사진 글자 복사하기

엣지 패널의 셀렉트로 사진 속 글자를 복사하거나 화면 위에 고정할 수 있습니다. 원 UI 6.1.1 이상 갤럭시에서 쓸 수 있고, 메뉴 이름은 기기마다 다를 수 있습니다.

  1. 설정 → 디스플레이 → 엣지 패널에서 사용 중으로 바꿉니다.
  2. 패널 메뉴에서 셀렉트가 없으면 편집에서 추가합니다.
  3. 글자가 있는 사진을 열고 화면 끝 막대를 왼쪽으로 밀어 엣지 패널을 엽니다.
  4. 셀렉트를 누르고 글자 부분을 네모나게 그립니다.
  5. T 아이콘 또는 텍스트 추출을 누르면 복사됩니다.
  6. 원하는 앱에서 길게 눌러 붙여 넣기를 합니다.
  • 그린 영역 아래 핀 모양 버튼을 누르면 계좌번호 등을 화면 위에 띄워 둘 수 있습니다.
  • 복사·공유·저장 버튼으로 필요한 부분만 캡처할 수도 있습니다.
  • 버전 확인은 설정 → 휴대전화 정보 → 소프트웨어 정보입니다.

4. 사진 속 물건 검색·불필요한 대상 지우기

갤럭시에서 사진 속 궁금한 물건을 동그라미로 검색하고, 갤러리 편집으로 그림자나 불필요한 대상을 지우는 방법입니다. 쇼핑이나 사진 보정에 바로 쓸 수 있습니다.

  1. 갤러리에서 사진을 열고 홈 버튼을 2~3초 꾹 누릅니다.
  2. 구글 검색창이 뜨면 궁금한 부분에 동그라미를 그려 검색 결과를 확인합니다.
  3. 지우기는 사진을 열고 연필 모양 편집을 누릅니다.
  4. 그림자는 점 네 개 아이콘에서 AI 지우개 → 그림자 지우기를 선택합니다.
  5. 대상 지우기는 AI 편집 아이콘을 눌러 지울 부분을 따라 그립니다.
  6. 지우개 버튼과 생성을 차례로 누릅니다.
  7. 다른 파일로 저장을 눌러 원본을 보존합니다.
  • 검색창이 안 뜨면 구글 앱 로그인을 확인합니다.
  • 배경이 복잡하면 지우기 결과가 어색할 수 있습니다.

5. 말하는 번역기로 해외에서 대화하기

무료 앱 말하는 번역기로 100개 이상의 언어를 실시간으로 통역하고 메뉴판 사진도 번역합니다. 언어 팩을 미리 받으면 인터넷 없이도 쓸 수 있어 해외 출장·여행에 유용합니다.

  1. 플레이 스토어에서 말하는 번역기를 검색해 설치하고 엽니다.
  2. 알림 허용과 오디오 녹음 권한(앱 사용 중에만 허용)을 허용합니다.
  3. 아래쪽에 내 언어, 위쪽에 상대 언어를 설정합니다.
  4. 마이크를 누르고 말하면 상대 쪽 화면에 번역문이 표시되고 음성으로 나옵니다.
  5. 상대는 자기 쪽 마이크로 답하고, 번역 문장을 누르면 다시 들을 수 있습니다.
  6. 미리 언어 옆 다운로드 버튼으로 내 언어와 상대 언어를 모두 받아 둡니다.
  7. 메뉴판은 이미지 탭에서 촬영한 뒤 구간을 지정하고 번역하기를 누릅니다.
  • 이미지 번역은 베타 버전이라 중요한 내용은 다시 확인합니다.
  • 화살표 버튼으로 두 화면을 같은 방향으로 바꿀 수 있습니다.
  • 구독하지 않으면 하단에 작은 광고가 나옵니다.

6. 말로 입력하는 Typeless 사용하기

Typeless는 말한 내용에서 군더더기를 지우고 정리된 문장으로 입력해 주는 음성 입력 도구입니다. ChatGPT 등 여러 앱에서 프롬프트를 빠르게 쓸 때 편리합니다.

  1. Typeless를 설치하고 화면에서 사전을 엽니다.
  2. 단어 추가를 눌러 자주 틀리는 전문 용어를 등록합니다.
  3. 입력할 앱(구글 독스, 메모장, ChatGPT 등)을 열고 말로 내용을 입력합니다.
  4. 번호 목록으로 말하면 목록으로 정리되는지 확인합니다.
  • 직접 수정하면 용어가 자동으로 추가되기도 합니다.
  • 실시간 처리라 인터넷 연결이 필요합니다.
  • 단축키는 설정에서 바꿀 수 있습니다.
  • 무료 사용량은 주당 8,000단어입니다.

7. ChatGPT로 내 이모티콘 시트 만들기

무료 ChatGPT로 내 사진을 캐릭터로 바꾸고 12칸짜리 이모티콘 시트를 만드는 방법입니다. 같은 캐릭터로 여러 표정을 한 번에 얻을 수 있습니다.

  1. 휴대폰에서 ChatGPT를 열고 + 버튼 → 사진에서 사진을 선택해 완료를 누릅니다.
  2. 사진 아래에 이 사진 캐릭터로 만들어 줘라고 입력해 보냅니다.
  3. 마음에 들지 않으면 눈 크기, 머리 스타일, 옷 스타일 등을 추가로 요청합니다.
  4. 완성된 캐릭터를 다운로드합니다.
  5. 캐릭터 이미지를 다시 첨부해 이모티콘 시트를 요청합니다.
  6. 가로 3칸 × 세로 4칸, 흰 배경의 12칸으로 지정하고 번호별로 표정과 문구를 적습니다.
  7. 3D 느낌을 원하면 3D 픽사풍 렌더링으로 다시 만들어 달라고 요청합니다.
예시
첨부한 캐릭터를 그대로 유지해서 이모티콘 시트를 만들어 주세요.
  • 무료 버전은 이미지 생성 횟수에 제한이 있어, 제한이 걸리면 다음 날 다시 하거나 다른 AI를 씁니다.

8. GPT-6 아스트라와 Codex로 앱 만들기

GPT 데스크탑 앱에서 GPT-6 아스트라 모델을 고르고 Codex로 평면도를 3D 주택 웹 앱으로 만드는 실습입니다. 추론 레벨을 조절하며 결과와 비용의 균형을 잡습니다.

  1. GPT 데스크탑 앱의 채팅 화면에서 프롬프트 입력창의 추론 수준 버튼을 눌러 최신 모델을 선택합니다.
  2. 좌측 상단 ChatGPT 버튼을 눌러 Codex로 바꿉니다.
  3. 모델을 GPT-6 아스트라로 선택하고 추론 레벨을 미디엄으로 둡니다.
  4. 전문 3D 도구 없이 기본 도구만으로 3D 주택 웹 앱을 만들어 달라고 요청합니다.
  5. 결과 웹 뷰어에서 거실·작업실 등을 조작해 확인합니다.
  6. 평면도 이미지를 첨부하고 평면도 기반 3D 모델링을 요청합니다.
  • 결과가 만족스럽지 않으면 추론 레벨을 한 단계씩 높입니다. 비용도 함께 늘어납니다.
  • Work나 Codex에서는 모델 선택에서 바로 고를 수 있습니다.

9. Codex 플러그인으로 페이지 배포하기

Codex 플러그인을 설치해 만든 웹 페이지를 Vercel에 바로 배포하는 방법입니다. 목표 설정 모드를 쓰면 길고 복잡한 작업도 맡길 수 있습니다.

  1. Codex 좌측 상단의 플러그인 탭에서 플러스 버튼을 눌러 Vercel을 설치합니다.
  2. 새 채팅에서 새 프로젝트 추가, 처음부터 시작을 누르고 프로젝트 이름을 입력해 저장합니다.
  3. 포트폴리오 랜딩 페이지를 만들고 Vercel 플러그인으로 배포한 뒤 URL을 알려 달라고 요청합니다.
  4. 결과의 프리뷰와 배포 URL을 눌러 페이지를 확인합니다.
  5. 수정이 필요하면 같은 대화에서 추가로 요청합니다.
  6. 긴 작업은 입력창의 플러스 버튼에서 목표를 켜고 달성할 목표를 입력합니다.
예시
포트폴리오 랜딩 페이지를 만들고 Vercel 플러그인으로 배포한 뒤 URL을 알려 줘.
  • 수정을 요청하면 그대로 반영되고 배포까지 이어집니다.
  • 목표 설정 모드는 길고 복잡한 작업에 맞고, Notion 플러그인을 미리 연결해야 합니다.

10. 힉스필드로 이미지에서 영상 만들기

Higgsfield에서 이미지를 먼저 만든 뒤 영상으로 바꾸는 기본 흐름입니다. 이미지로 일관성을 먼저 잡으면 릴스·쇼츠용 영상을 안정적으로 만들 수 있습니다.

  1. Higgsfield 웹사이트에서 Create Image로 들어갑니다.
  2. 참고할 사진을 +로 첨부하고 같은 얼굴을 유지하라는 프롬프트를 씁니다.
  3. 모델(GPT 이미지 2), 퀄리티 High, 화질 4K, 비율을 고르고 Generate를 누릅니다.
  4. 마음에 안 들면 Recreate로 다시 만듭니다.
  5. Turn to Video를 눌러 이미지를 영상으로 넘깁니다.
  6. Seedance를 고르고 길이와 화질을 정한 뒤 Generate를 누릅니다.

  2. 대본을 표 하나로 씁니다. 한 줄이 한 컷이고 칸은 컷 번호, 샷 크기, 인물, 대사, 길이입니다.
  3. 인물마다 캐릭터 시트 한 장, 세트 한 장, 컷마다 시작 스틸을 이미지 모델로 만듭니다.
  4. 인물마다 ElevenLabs 보이스 라이브러리에서 목소리를 골라 대사 파일을 만들고 파일 이름을 컷 번호와 맞춥니다.
  5. Higgsfield에서 Seedance 2.5를 레퍼런스 모드로 두고 시작 스틸, 캐릭터 시트, 대사 오디오를 넣어 컷을 생성합니다.
  6. 생성된 영상의 목소리를 기준으로 컷을 자르고, 입과 소리가 맞는지 검사합니다.
  7. 고칠 컷만 같은 시작 스틸과 시트로 다시 만들고, 이전 버전은 새 이름으로 남깁니다.
예시
대사 앞에 연기 지시를 붙입니다: [softly, tired] 오늘은 정말 길었어. [beat] 그래도 왔네.
  • 본 생성 전에 480p 짧은 시험으로 입 모양과 대사를 먼저 확인합니다.
  • 인물 묘사 문장은 모든 프롬프트에 한 글자도 바꾸지 않고 붙입니다.
  • 연기 지시는 영어 대괄호로 쓰고, 감정 이름보다 말투로, 한 줄에 한 개에서 세 개까지만 붙입니다.
  • 제출 전에 비용 견적 기능으로 크레딧을 확인합니다. 한 클립에 세 줄·10초 이하로 묶으면 대사 타이밍이 덜 흔들립니다.

20. Flova 스킬로 AI 드라마 시리즈 만들기

Flova AI에서 제작 방식을 스킬로 저장하고 캐릭터·배경을 Asset Library에 저장해 다음 화에도 불러 씁니다. 얼굴·목소리·공간이 바뀌지 않아 시리즈 제작에 유리합니다.

  1. Flova AI 왼쪽 메뉴의 스킬에서 기존 스킬을 고르거나 새 스킬을 만듭니다.
  2. 스킬에 사용 시점, 제작 순서, 스토리보드·프롬프트·편집 규칙을 적습니다.
  3. 스킬을 선택한 뒤 장면 아이디어, 비율(9:16), 길이(60초)를 입력하고 스토리보드부터 설계해 달라고 요청합니다.
  4. 모델을 Seedance 2.5로 설정하고 생성하기를 누릅니다.
  5. 캐릭터 시트와 사무실 이미지, 샷별 스토리보드를 확인하고 하단 입력창으로 수정을 요청합니다.
  6. 괜찮으면 진행해 줘라고 요청해 8개 샷 영상과 배경음악·대사 타임라인을 만듭니다.
  7. 마음에 들면 동영상 내보내기로 다운로드합니다.
  • 스킬에 '바로 생성하지 말 것'을 적어 두면 스토리보드 확인 단계를 거칩니다.
  • 시나리오가 약하면 수정 요청으로 코미디 요소를 강화할 수 있습니다.
  • 1화 8개 샷 생성에 1860 크레딧이 사용되었습니다.

21. YouMind로 자료 모아 대본 만들기

YouMind는 크롬 확장 프로그램으로 웹페이지·유튜브·캡처를 보드에 모으고, 예시 대본의 형식과 말투로 대본을 만들어 주는 도구입니다. 영상 기획이나 발표 준비에 씁니다.

  1. YouMind에 가입하고 로그인합니다.
  2. 크롬 웹스토어에서 YouMind 확장 프로그램을 Chrome에 추가로 설치합니다.
  3. 확장 프로그램 관리에서 툴바에 고정합니다.
  4. 참고 페이지에서 확장 프로그램을 열고 새 보드 만들기로 보드를 만듭니다.
  5. 필요한 부분을 드래그해 YouMind에 저장을 누르고, 이미지는 캡처로 저장합니다.
  6. 예시 대본을 같은 보드에 넣습니다.
  7. 새 작업에서 자료와 예시 형식을 따라 대본을 써 달라고 요청합니다.
  • Pick과 Annotate로 자료마다 메모를 달아 둘 수 있습니다.
  • 만든 대본으로 슬라이드를 만들고 PPT로 내려받을 수도 있습니다.
