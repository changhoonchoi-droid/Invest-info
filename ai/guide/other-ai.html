1. Gemini 사고 모드로 바꿔 질문하기

Gemini의 기본 빠른 모드는 구형 2.5 모델이라, 사고 모드로 바꿔야 Gemini 3 Pro를 쓰게 됩니다. 기획·분석처럼 생각이 필요한 업무를 맡길 때 설정해 두면 좋습니다.

  1. Gemini 입력창 아래의 모드 선택 메뉴를 클릭합니다.
  2. 기본값인 빠른 모드를 사고 모드로 바꿉니다.
  3. 목적·예산·대상 정도만 넣어 짧게 요청합니다.
  4. 정확한 답이 필요하면 깊게 생각해서 답변해 줘를 덧붙입니다.
예시
신제품 마케팅 전략을 짜 줘. 예산 500만 원, 타겟은 20대 여성이야. 깊게 생각해서 답변해 줘.
  • 빠른 모드로 두면 Gemini 2.5를 쓰는 것이라 3의 성능을 느낄 수 없습니다.
  • 대화를 이어 가며 형식·분량·예시를 지정하고 부분 수정을 요청하면 결과가 좋아집니다.

2. 제미나이에 구글 워크스페이스 연결하기

제미나이에 지메일·캘린더·드라이브를 연결해 메일 답장 초안, 일정 등록, 문서 기반 학습 자료 만들기를 한 번에 처리합니다. 앱을 @로 지정해 요청하는 것이 핵심입니다.

  1. 제미나이 화면 왼쪽 맨 아래 설정으로 들어갑니다.
  2. 연결된 앱을 누릅니다.
  3. 아래쪽 구글 워크스페이스를 켜짐으로 바꿉니다.
  4. 평소 쓰는 구글 계정으로 로그인되어 있는지 확인합니다.
  5. 질문에서 @를 입력해 앱을 고른 뒤 무엇을, 어떻게 할지 적습니다.
  • 어디서(@앱), 무엇을, 어떻게 세 가지를 말하면 됩니다.
  • 일정 등록은 확인을 물은 뒤 응답하면 캘린더에 반영됩니다.
  • 설정은 모바일 앱에도 연동됩니다.

3. 제미나이 캔버스로 문서 고쳐 쓰기

캔버스는 답변 옆에 작업창이 생겨 문서를 함께 편집하는 기능입니다. 원하는 구간만 고치고, 완성한 문서를 웹페이지·퀴즈·오디오 등으로 바꿀 수 있습니다.

  1. 프롬프트를 쓰고 도구에서 캔버스를 선택해 제출합니다.
  2. 고치고 싶은 구간을 드래그합니다.
  3. 요청을 입력하거나 길이 변경, 어조 변경을 눌러 단계를 고릅니다.
  4. 문서 전체를 점검하려면 수정 제안을 누릅니다.
  5. 문서가 완성되면 만들기를 눌러 웹페이지, 인포그래픽, 퀴즈, 플래시 카드, AI 오디오 오버뷰 중 고릅니다.
  6. 생성이 끝나면 아래쪽 공유 버튼으로 링크를 만듭니다.
예시
이 부분을 앞뒤 맥락에 맞게 바꾸고 필요하면 앞뒤 내용도 같이 바꿔 줘.
  • 길이는 매우 짧게~매우 길게 5단계입니다.
  • 위쪽 공유는 대화 전체, 아래쪽 공유는 결과물만 공유합니다.
  • 다른 형식을 또 만들려면 원래 텍스트 캔버스로 돌아와야 합니다.

4. 노트북LM에 자료 넣고 질문하기

노트북LM은 내가 올린 자료만 근거로 답하고 출처 번호를 달아 주는 구글 AI입니다. 보고서·영상·링크를 모아 요약하거나 마인드맵 등으로 정리할 때 씁니다.

  1. 구글에서 노트북LM에 접속해 새 노트 만들기를 누릅니다.
  2. 왼쪽 위 제목을 프로젝트 이름으로 바꿉니다.
  3. 소스 추가로 파일 업로드, 링크, 유튜브, 드라이브, 텍스트를 넣습니다.
  4. 채팅창에 질문하고 답변의 숫자를 눌러 출처를 확인합니다.
  5. 오른쪽 스튜디오에서 사용할 소스만 체크하고 마인드맵, 인포그래픽, 오디오 오버뷰, 슬라이드 중 하나를 누릅니다.
  • URL은 여러 개를 줄바꿈으로 한 번에 넣을 수 있습니다.
  • 구글 독스 링크를 넣으면 내용이 자동 업데이트됩니다.
  • 슬라이드를 파워포인트로 받으면 이미지라 수정이 안 됩니다.
  • 웹 검색은 약하므로 최신 정보는 제미나이에서 노트북을 선택해 보완합니다.

5. ChatGPT로 내 사진 카톡 이모티콘 만들기

ChatGPT에 사진을 올려 캐릭터로 바꾸고, 12칸 이모티콘 시트까지 만듭니다. 무료 버전으로도 가능합니다.

  1. 휴대폰에서 ChatGPT를 열고 + 버튼 → 사진에서 사진을 선택해 완료를 누릅니다.
  2. 사진 아래에 이 사진 캐릭터로 만들어 줘라고 입력해 보냅니다.
  3. 마음에 들지 않으면 눈 크기, 머리 스타일, 옷 스타일 등을 추가로 요청하고 완성된 캐릭터는 다운로드합니다.
  4. 캐릭터 이미지를 다시 첨부해 이모티콘 시트를 요청합니다.
  5. 가로 3칸 × 세로 4칸, 흰 배경의 12칸으로 지정하고 번호별로 표정과 문구를 적습니다.
  6. 3D 느낌을 원하면 3D 픽사풍으로 다시 만들어 달라고 요청합니다.
예시
첨부한 캐릭터를 그대로 유지해서 이모티콘 시트를 만들어 주세요. 가로 3칸 × 세로 4칸, 흰 배경으로 하고 번호별로 표정과 문구를 넣어 주세요.
  • 무료 버전은 이미지 생성 횟수 제한이 있어 걸리면 다음 날 다시 하거나 다른 AI를 씁니다.
  • 크기는 20% 정도로 줄여 다른 파일로 저장하면 이미지로 쓰기 좋습니다.

6. ChatGPT Work·Codex에서 GPT-6 아스트라 쓰기

GPT 데스크탑 앱에서 채팅·Work·Codex를 오가며 GPT-6 아스트라로 문서·표·앱 제작 같은 실무를 맡깁니다. 추론 수준은 비용과 연결되므로 단계적으로 올리는 것이 좋습니다.

  1. GPT 데스크탑 앱의 채팅 화면에서 프롬프트 입력창의 추론 수준 버튼을 누릅니다.
  2. 모델을 최신으로 선택합니다.
  3. Work나 Codex에서는 모델 선택에서 바로 GPT-6 아스트라를 고르고 추론 레벨을 미디엄으로 둡니다.
  4. 코드 작업은 좌측 상단 ChatGPT 버튼을 눌러 Codex로 바꿉니다.
  5. 만들 결과물(예: 3D 주택 웹 앱)을 디자인·조작 기능·검증 방법까지 적어 요청하고, 평면도 같은 이미지를 첨부합니다.
  6. 결과가 부족하면 추론 레벨을 한 단계씩 높입니다.
예시
전문 3D 도구 없이 기본 도구만으로 3D 주택 웹 앱을 만들어 줘. 디자인, 조작 기능, 제작 방식, 검증 방법을 함께 알려 줘.
  • 추론 레벨을 높일수록 비용도 늘어납니다.
  • ChatGPT Work는 7월 9일 출시되었고 파일·앱을 다루는 기능은 데스크탑 전용입니다.
  • Codex의 Record & Replay(화면 보여 주고 스킬 만들기)는 현재 macOS에서만 쓸 수 있습니다.

7. 이미지 먼저 만들고 AI 영상으로 바꾸기

영상 AI는 이미지로 장면을 먼저 확정한 뒤 영상으로 바꾸면 얼굴과 분위기가 안정됩니다. 힉스필드·Artlist·Pollo AI 등 어느 서비스든 같은 흐름으로 쓸 수 있습니다.

  1. Higgsfield 웹사이트에서 Create Image로 들어갑니다.
  2. 참고할 사진을 +로 첨부하고 같은 얼굴을 유지하라는 프롬프트를 씁니다.
  3. 모델(GPT 이미지), 퀄리티 High, 화질, 비율을 고르고 Generate를 누릅니다.
  4. 마음에 안 들면 Recreate로 다시 만듭니다.
  5. Turn to Video를 눌러 이미지를 영상으로 넘깁니다.
  6. 영상 모델을 고르고 길이와 화질을 정한 뒤 Generate를 누릅니다.
예시
같은 사람을 유지해 줘. 같은 얼굴, 같은 아이덴티티. 한국인 여자.
  • 얼굴·로고는 원본 그대로 100% 유지, 다시 그리거나 변형하지 마라고 못 박습니다.
  • 같은 프롬프트라도 매번 결과가 달라 여러 번 생성해 고릅니다.
  • 4K는 1080보다 크레딧이 훨씬 듭니다(8초 기준 72 대 176).
  • 앱스토어·플레이스토어의 Higgsfield는 정식 앱이 아니므로 웹사이트에서 사용합니다.

8. 여러 AI 영상 모델 비교해 고르기

같은 프롬프트로 여러 영상 모델을 돌려 보고 점수와 가격으로 나에게 맞는 모델을 고르는 방법입니다. 비싸다고 항상 좋은 것은 아닙니다.

  1. 힉스필드에서 비교할 모델들을 고릅니다.
  2. 상황만 담은 프롬프트 하나를 준비하고 대사와 연출은 AI에 맡깁니다.
  3. 모델이 지원하는 길이와 화질에 맞춰 생성합니다.
  4. 다시 뽑지 않고 첫 결과만 확인합니다.
  5. 영상미·연기·구성·재미를 각 10점으로 채점합니다.
  6. 모델마다 길이가 달라 1분 기준 가격으로 환산해 비교합니다.
  • 빠른 대사 장면은 그록·플럭스, 영화 같은 영상미는 씨댄스, 가성비는 미니맥스가 추천되었습니다.
  • 1분 기준 가격이 최대 약 8배 차이 납니다.
  • 생성이 실패하면 크레딧이 환불됩니다.
  • 씨댄스가 생성되지 않으면 장면을 초 단위로 나누고 누가 언제 말하는지 정해 줍니다.

  4. 미들 프레임을 눌러 중간 장면 사진을 순서대로 넣습니다.
  5. 마지막 사진은 엔드 프레임으로 넣습니다.
  6. 사진 순서에 맞춰 장면 흐름을 적은 프롬프트를 입력합니다.
  7. 비율과 길이(최대 30초)를 정하고 제너레이트를 누릅니다.
  • 프롬프트는 GPT나 Claude에 사진 순서를 보여 주고 검토받아 다듬어도 됩니다.
  • 장면이 너무 많으면 파트를 나눠 생성합니다.
  • 예전 방식: 사진마다 영상을 따로 만들어 편집 프로그램에서 이어 붙였습니다.

10. Seedance 2.5로 긴 광고·장면 영상 만들기

Seedance 2.5는 한 번에 최대 30초, 레퍼런스를 여러 개 넣어 제품·배경·인물을 반영합니다. 수정은 만든 영상을 레퍼런스로 넣어 바꿀 부분만 지시합니다.

  1. 제품 사진을 정면·측면·후면 등 여러 각도로 준비합니다.
  2. Artlist AI 툴킷의 이미지에서 배경 장면 이미지를 만들고, 제품과 합친 렌더링 이미지도 만듭니다.
  3. 비디오로 바꾸고 올 모델스에서 Seedance 2.5를 선택한 뒤 유즈 모델을 누릅니다.
  4. 길이를 30초로, 화질을 높게 설정하고 소리가 필요하면 오디오를 켭니다.
  5. +를 눌러 이미지 레퍼런스로 제품·배경·렌더링 이미지를 추가합니다.
  6. 프롬프트를 쓰고 제너레이트를 누릅니다.
  7. 수정할 때는 만든 영상을 레퍼런스로 첨부하고 바꿀 부분만 프롬프트로 적어 다시 생성합니다.
  • 시작·끝 프레임이 아니라 이미지 레퍼런스로 넣어야 합니다.
  • 영상 생성은 크레딧이 많이 들어 이미지로 구도를 먼저 확정합니다.
  • 디테일이 어긋나거나 엄격한 브랜드 가이드가 필요하면 실제 촬영이 필요할 수 있습니다.
  • Artlist 연간 플랜의 무제한 혜택에는 Seedance 2.5가 포함되지 않습니다.

11. 같은 인물로 장면 이어 영상 만들기

캐릭터 시트나 이전 영상을 레퍼런스로 넣어 얼굴·옷이 바뀌지 않는 여러 장면을 만듭니다. 브이로그·단편·숏드라마에 쓰는 핵심 방법입니다.

  1. 전신 이미지로 인물을 만든 뒤, 그 이미지를 기준으로 얼굴·헤어·의상·체형을 유지한 캐릭터 시트를 만듭니다.
  2. 비디오에서 모델을 Seedance 2.5로 고르고 캐릭터 시트를 레퍼런스로 첨부해 @로 지정합니다.
  3. 원하는 동작을 프롬프트에 적고 길이·비율·품질을 정해 생성하기를 누릅니다.
  4. 다음 장면은 직전에 만든 영상을 레퍼런스에 함께 넣고 이전 장면에서 곧바로 이어져라고 쓴 뒤 새 상황을 적습니다.
  5. 장소만 바꾸려면 첫 영상을 레퍼런스로 넣고 프롬프트에서 장소만 바꿉니다.
  6. 마음에 들면 다운로드하고 모든 장면을 이어 붙입니다.
예시
이전 장면에서 곧바로 이어져. 20대 후반의 한 여성이 카페에서 창가 자리에 앉아 커피를 마신다. 컷 전환 없이 이어지게 해 줘.
  • 프롬프트에 인물 이름을 쓰면 생성이 안 될 수 있어 '20대 후반의 한 여성'처럼 씁니다.
  • 이전 영상을 모두 넣는 편이 일관성에 좋고, 레퍼런스를 많이 넣어도 크레딧은 늘지 않았습니다.
  • 숏드라마처럼 대사가 있으면 한 클립에 세 줄·10초 이하로 묶어야 대사 타이밍이 흔들리지 않습니다.
  • 제출 전에 비용 견적을 확인합니다.

12. Newtake로 영상 만들고 일부만 바꾸기

Newtake는 아이디어를 넣으면 각본·샷·프롬프트를 자동으로 만들고, 만든 영상의 바꿀 구간만 다시 생성할 수 있는 캔버스형 도구입니다. 광고 영상 제작에 적합합니다.

  1. 로그인 후 제작 시작을 눌러 캔버스를 엽니다.
  2. 스토리 생성의 각본 노드를 더블클릭해 광고 아이디어를 입력합니다.
  3. 스크립트 노드 열기로 샷별 내용을 확인하고 필요하면 고칩니다.
  4. 다음 단계의 자산 준비에서 인물·장면·소품 이미지를 업로드하거나 AI 생성으로 만듭니다.
  5. 프롬프트 합성으로 프롬프트를 확인하고 전체 프롬프트 합성과 합성 확인으로 장면별 영상을 생성합니다.
  6. 바꿀 부분이 있으면 영상을 선택하고 왼쪽 위 구간 리메이크를 누릅니다.
  7. 바꿀 구간을 지정하고 새 제품·모델 이미지를 연결한 뒤 바꿀 내용을 입력해 생성합니다.
  8. 일괄 다운로드로 장면 영상을 받아 이어 붙입니다.
예시
선글라스를 안경으로 바꿔 줘.
  • 영상보다 이미지로 먼저 테스트하면 크레딧이 덜 듭니다.
  • 구간이 길수록 크레딧이 많이 듭니다.
  • 프롬프트에 어떤 이미지의 인물인지 구체적으로 써야 엉뚱한 인물이 섞이지 않습니다.
  • AI가 다시 생성하는 방식이라 모든 세부가 완전히 같지는 않습니다.

13. ElevenLabs로 AI 목소리 만들고 복제하기

ElevenLabs로 대본을 AI 목소리로 읽히고, 내 목소리를 복제해 영상 나레이션에 씁니다. 감정은 파라미터가 아니라 프롬프트의 태그로 조절합니다.

  1. Claude에게 한글·영어 테스트 대사를 짧게 만들어 달라고 요청합니다.
  2. ElevenLabs에서 스피치 만들기 기능을 열고 대사를 입력합니다.
  3. Eleven v4로 생성해 듣고, 같은 대사를 Multilingual v2로도 생성해 비교합니다.
  4. 대사 안에 whispers, sarcastic, curious 같은 감정 태그를 넣고 말줄임표·느낌표로 억양을 보강합니다.
  5. 내 목소리를 쓰려면 Create Voice에서 Instant Voice를 고릅니다.
  6. 약 30~40초 동안 다양한 내용을 녹음하고, 만들어진 목소리로 대사를 생성해 들어 봅니다.
  • 즉석 복제는 약 70% 비슷한 수준이고, 더 높은 품질은 약 2시간 분량으로 학습하는 전문 복제(PVC)가 필요합니다.
  • 숫자·다양한 문장을 많이 녹음하고 톤을 일정하게 유지해야 품질이 안정됩니다.
  • 예전 방식: 한글 표현에는 주로 Multilingual v2를 썼지만, 최근 영상에서는 v4가 감정 표현이 더 좋다고 평가합니다.
  • 대안으로 Fish Audio의 즉시 음성 복제도 있습니다(샘플 10초 이상, 비공개 권장).

14. Artlist 아바타·립싱크로 말하는 영상 만들기

사진 한 장과 음성 파일만으로 말하는 아바타 영상을 만들고, 다른 언어 더빙이나 기존 영상에 음성 입히기까지 처리합니다.

  1. Artlist에서 AI 툴킷을 열고 아래쪽을 비디오로 바꿉니다.
  2. 이미지 레퍼런스에서 업로드 이미지로 사진을 넣습니다.
  3. 오디오 파일에서 업로드 오디오로 미리 녹음한 음성을 넣습니다.
  4. 모델이 헤이젠 아바타 4인지 확인하고 비율·화질을 설정한 뒤 제너레이트를 누릅니다.
  5. 다른 언어로 바꾸려면 영상 오른쪽 유즈에서 트랜슬레이트 비디오를 선택하고 언어를 고릅니다.
  6. 기존 영상에 음성을 입히려면 쇼 올에서 립싱크 V2 프로를 선택하고 영상과 음성을 넣습니다.
  • 프롬프트가 아니라 음성 파일의 내용이 대사가 됩니다.
  • 영상 길이와 음성 길이를 맞추지 않으면 중간에 끊깁니다.
  • 얼굴이 작거나 화면 녹화라면 입 모양은 건드리지 않는 일레븐랩스 트랜슬레이트가 크레딧이 덜 듭니다.
